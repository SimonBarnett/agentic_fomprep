Domestic Reverse Charge Procedure 
Requirements 
https://www.gov.uk/guidance/the-vat-domestic-reverse-charge-procedure-notice-735 
 
 
Note: The following document describes how to apply reverse charge to an invoice on a line level. To apply reverse 
charge to a whole invoice, instead use the reverse charge entry code. The setup for this is described in the instructions for 
Postponed VAT Accounting. 
 
VAT Code Definitions 
Financials > Maintenance of Financials > Basic Data > Financial Attributes > Value Added Tax 
 
Create a new VAT Code for “Reverse Charge”. Set the Reverse Charge Tax as the VAT code for domestic purchases. 
In this example, the VAT code for domestic purchases is 002: 
 
 
 
Box Definitions 
Financials > Nominal Ledger > Financial Statements > Taxes > VAT Reports > VAT Report Box Definitions 
 
Add definitions for the reverse charge VAT Code to boxes 1, 4, and 7. Include definitions for CRV and DEB entry codes and 
tick these as Reverse Sign:
