# Email Synchronisation (003)

- **Source:** `Email Synchronisation (003).docx`

Right Click in Priority to Sync with Outlook.

In the All programs, Start up make sure you have a shortcut to olsync in the correct Priority folder. Also make sure the tabula.ini reference at the end of the line matches the reference in your Priority shortcut. Eg C:\priority-emerge\bin.95\olsync.exe -t tabula2.ini –r

In outlook go to Tools, Trust Centre, Add Ins

Check OlPri is listed and looking at the correct Priority\bin.95 directory.

If it is missing or incorrect select COM add-ins and click the Go button.

Remove if wrong and then add it.

In Priority Set your Priority Language to American English

Shut and re-start Priority

Run Office Management > Mail > Synchronize With MS-Outlook > Update Data for Synch w/Outlook

Choose the second option - Update data manually (by running this program) and approve. (So that you do not reset the settings when you next login in British English)

Close and re-open Outlook.

Set your Priority language back to British English and re-start

You should now be able to right click in outlook and get the option to synchronise with Priority.

The synchronisation happens the next time Outlook and priority synchronise either automatically or by synchronise now.
