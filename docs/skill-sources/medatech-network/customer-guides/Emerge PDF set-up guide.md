# Emerge PDF set-up guide

- **Source:** `Emerge PDF set-up guide.docx`

Each document that converts to PDF must be written by Medatech staff on an as needed basis.

NB. All PC’s using this module must have PDF reader software installed as associated with the .pdf file extension.

emgPDF Install – On the Priority SQL Server

Copy the file [R:\Emerge-IT EXE Setup\setup_emgPDFx86.exe or setup_emgPDFx64.exe] into a valid directory then execute

Click next

Check this is the appropriate Priority directory (uses the value from tabula.ini) and adjust if necessary, click next

NB. For Web interface sites this must be under the bin.95 directory on the application server.

Adjust the start menu name if you need to, click next

Click Install

Click Finish
