HOW TO COPY COMPANIES IN 
PRIORITY  
CREATING  COMPANIES  
Note: No users should be working in the company that is to be copied. 
Run System Management > System Maintenance > Companies > Copy Company  
 
Enter the following information: 
Full Company Name: Write the name of the company you want to copy, EXACTLY as it appears – you 
can F6 into the form (if the form is blank, press F11 and * to return all companies), use F8 on the Full 
Company Name field to select the relevant company, and pull it back to your Parameter Input. 
 
New Company: Choose the code for the new company. This should be all lower case. We 
recommend leaving this blank so that Priority generates a unique code. 
New Co. – Full Name: Write the name of your new company. This is how the company will appear in 
the dropdown list.
