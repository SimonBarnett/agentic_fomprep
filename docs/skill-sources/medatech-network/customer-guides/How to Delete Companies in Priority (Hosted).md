HOW TO DELETE COMPANIES IN PRIORITY  
DELETING COMPANIES  
Note: No users should be working in the company that is to be deleted. 
Deleting companies should be done by your system administrator. 
If your server is hosted by Medatech or Priority, please let Medatech know when you delete any companies so 
that we can delete the associated backups. 
Note: before deleting a company, check whether any tasks in the tabula task scheduler are running for that 
company: System Management > System Maintenance > Tabula Task Scheduler > Define TTS Tasks and change 
to an active company if necessary. 
e.g. 
 
Go to System Management > System Maintenance > Companies > Companies and untick "active" for the 
company you wish to delete. 
Copy the Full Company Name. Make note of the Company Code.  
 
Then run System Management > System Maintenance > Companies > Delete Company

DELETING BACKUPS  
Deleting companies does not remove the backups for that company. Tell Medatech the company codes for 
the companies you have deleted, and we will delete the backups.
