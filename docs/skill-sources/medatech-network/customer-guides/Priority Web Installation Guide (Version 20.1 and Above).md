PRIORITY WEB INSTALLATION GUIDE  
Before you begin installing Priority Web, make sure you are login into Windows as 
ADMINISTRATOR (do not run the installation file as ADMINISTRATOR, this is not enough.)  
STEP 1 : PRIORITY INSTALLATION PAGE  
Note: You will already be able to log into Priority without installing it, but some features will be 
unavailable. 
Add “?_installpage=1” to your Priority URL to reach the install page.  
E.g., https://priority.YOURCOMPANY.com/?_installpage=1
