2. Description 
 
This module enables a journal entry to be defined as repeating based on numerous criteria. The system can be set-up to automatically post these journals 
when then become due. 
 
 
3. Creating a Repeating Journal Sequence 
 
3.1. Journal Template. 
 
Financials > Nominal Ledger > Entry Journal > Entry Journal 
 
 
Enter the details of the journal to be repeated 
 
It is not important if the date of this journal matches the repeating sequence required but it is used as the default start of the sequence of journals. 
However you Must flag this journal as a Recurring Template

3.2. Repeating Journal sub-level 
Enter the Repeating Journal sub-level and enter the sequence required (Daily, Weekly, Monthly or Year)

which the sequence should end.  NB. Starting date cannot be set to a date earlier than that controlled by System Management > System Maintenance >

3.3. Number of future dates to flag 
You may set the number of days in advance of the system date you wish to have Temporary Journals created allowing review and adjustment of these 
journals before they are posted when actually due.   
 
  
 
3.4.  Notify Upon Posting 
You may set a user who will receive a priority mail message when any journal in the sequence is posted by the system.

3.6.  Weekly 
You may repeat individual days of the week every set number of weeks, the day of the journal template is ticked by default for you. 
 
 
3.7.  Monthly 
You may enter specific day of month every set number of months, the day of the journal template is defaulted for you. 
 
NB. Enter a day of the month greater than 28, if the month has less than the day entered the last day of the month is used. 
NB2. Quarterly can be achieved by using the monthly tab repeating every 3 months. 
 
Or occurrence  of a day in a month every set number of months, the values for the journal template are defaulted for you. 
 
 
3.8.  Yearly 
You may specify every set number of years 
 
   
On either a specific day of the year, the month/day of the journal template is defaulted for you.

4. Repeating Journal Dates Sub-level 
This shows the sequence of journals planned. NB. If the starting date of the sequence does not match the requested sequence I.E. Starting date a week-
end but only week days requested then the first date will not be the starting date! 
 
NB. The final date always posts the template journal itself with the new dates shown. The checking flag is removed and journal posted. 
 
4.1.  Manually adjusting Create Journal flag 
You may manually change the dates marked. 
 
 
4.2.  Ignore date flag 
You may mark an individual date to be ignored thus preventing any journal being created or posted for this date.

4.3.   Schedule Lock flag 
You may mark an individual date to be locked thus preventing it being removed or changed should the repeating schedule be changed. 
 
NB. If the new schedule includes a schedule locked date, a new entry will not be created for this date. 
5. Manually Creating Temporary Journals 
 
You may manually create the temporary journals for any dates marked using the Update Journals direct activation. 
 
 
The temporary journals will show in the Repeating journals dates sub-level and you can use F6 to access them.

6. Manually Posting Temporary Journals 
 
You must first ensure the repeating journal is at the approved status. 
 
 
You may then manually post any due temporary journals (I.E. Those dated prior or equal to the system date) using the Post Journals direct activation. 
NB. Journals dated in the future may be included by adjusting the System Management > System Maintenance > Constant Forms > Emerge Company 
Constants “Datesfutr”
