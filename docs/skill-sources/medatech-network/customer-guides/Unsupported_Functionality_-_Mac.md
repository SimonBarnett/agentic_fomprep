Unsupported Functionality in Priority – Macintosh 
(Version 19.1) 
 
The following functionality is not supported in Priority on the web for Macintosh users: 
 Skype, Dialer and Calculator 
 Synchronization with Gmail 
 You cannot choose a print format when running reports that are not procedures by Direct 
Activation from a specific form. This is relevant only to Direct Activations and not when 
running the report from the menu. 
 Printouts: Print Including Attachments, Quick Print, Print Original 
 Use of clipboard 
o Paste and Import of files (CMD+V) to Attachments: 
 Only supported in Chrome for image files (imported as .PNG files) 
o Paste file into text form: 
 Supported in Safari and Chrome (the file names is pasted into the form) 
o Paste image into text form: 
 Only supported in Safari  
o Copy Record Link 
o Copy/Paste Privileges using the Privilege Explorer 
o Copy/Paste BPM 
 Opening entities and records in Priority from external links 
 Report Generators 
 Spell Check in the Text Editor 
 Automatic save of attachments after editing 
 Help Wizards 
 Sending an alert by e-mail when a user approves a warning message in a specific form. 
 Working with Outlook 
 The History of User Logins form does not display the name of the workstation from which 
users have logged in. 
 
Data Export 
 You cannot create Word templates with Office 2016 or with earlier versions of Office (not 
supported by Word for Macintosh users). 
 
As part of the service packs for V. 17 and higher, support was added for data export to other 
programs for Macintosh users. 
 Data export in V.18.2: 
o US only - You can print checks via Word. 
 Data export in V.17.3: 
o You can export data to MS Word and to spreadsheet applications.
