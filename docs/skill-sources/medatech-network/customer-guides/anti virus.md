EXCLUDING BIN.95 FROM YOUR ANTI -VIRUS  
Intro:  
Bin.95 contains the executable files, which Priority software needs to operate. 
Bin.95 folder in Priority works in conjunction with the SQL server and this can 
be located on the client version of Priority, and on the web server when using 
the Rich Interface. Sometimes the bin.95 directory and files within can be 
identified by virus checkers with a false positive result. This can stop priority 
working correctly. To resolve you should carry out the steps below.  
Method:  
Log in to your antivirus software (on your Priority Server, Web Server, and any 
machines using client server Priority)  
Exclude the directory from AV scans.  
C:\Priority\bin.95 
Where C:\priority is the path of the local priority installation.
