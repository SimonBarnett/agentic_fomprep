End of Fiscal Year Process  
 
 
1. Review all Pending Documents and finalise them or change dates accordingly. The report detailing 
Pending documents is located in Inventory > Warehouse Control > Past Balances > Past Balances 
Reports > Pending Documents up to Date.  
 
2. Review unbilled GRV’s a nd raise invoices if the relevant invoice has arrived from the supplier. The 
report is located in Financials > Accounts Payable > Accounts Payable Reports > Purchasing Analysis 
Reports > Vendor Analysis Reports > Unbilled GRV's. Run the report up to the en d of the current 
month. 
 
 
3. Review unbilled Customer shipping documents and raise invoices accordingly. The report is located 
in Inventory > Inventory Transactions > Sales Inventory Transactions > Unbilled Shipmt/S. Call 
Reports > Unbilled Docs. by Customer No. 
 
4. Carry out any inventory counts if you have any identified i.e. if you had a stock discrepancy and you 
want to record the inventory change in the current month, although this is not mandatory. Then run 
the calculate balance for date program which is lo cated in Inventory > Warehouse Control > Past 
Balances > Calculate Balance for Date. Run this on the last day of the month. Be careful when you 
run this i.e. if you run the program at the start of the day then you will not be able to carry out any 
inventory based transactions as the report runs on the basis of calculating for midnight on that day. 
So always run this either at the end of the day or on the following day dated for yesterday. 
 
 
5. Run the Transfer Prepaid Expenses program, Financials > Maintenance of Financials > Auxiliary 
Programs > Transfer Prepaid Expenses . This really should be set to run in the task scheduler every 
night. 
 
6. If you are working with shipping vouchers then these should be closed, where all invoices have been 
received. Financials > Accounts Payable > Shipping Expense Burdening > Shipping/Import Vouchers. 
 
 
7. Calculate and Post Exchange Rate Adjustments if applicable, this is  Financials > Nominal Ledger > 
Exchange Rate Adjustments. 
 
8. Run the costing program and enter the past balance date i.e. end of the month date. The costing 
program is in Financials > Cost Analysis for Manufacturers > Costing Programs > Costing for Past 
Balance Date. This can take several minutes to complete. 
 
 
9. If you are working with COGS, firstly run the details of COGS transactions report to check that the 
entries are ok. The report is in Financials > Inventory > COGS Posting > Details of COGS Transactions. 
Once you are happy you will need to run the  COGS program Financials > Inventory > COGS Posting > 
Post Cost of Goods Sold.

10. Close the fiscal period and only have authorised personnel allowed to post journals in the period 
that you have closed. The authorisation is carried out in the sub -level of the fiscal periods form 
which is located in Financials > Nominal Ledger > Fiscal Periods> Define Fiscal Years. To close the 
period run the close fiscal period program which is located in Financials > Nominal Ledger > Fiscal 
Periods > Close Fiscal Period.  
 
11. Once you have closed a period you can review final account balances for the period in the Account 
Balances form which is located in Financials > Nominal Ledger > Financial Statements > Trial Balance 
> Account Balances.
