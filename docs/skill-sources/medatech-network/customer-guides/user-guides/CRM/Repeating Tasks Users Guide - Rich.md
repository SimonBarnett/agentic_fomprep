2. Description 
 
This module enables a priority task to be defined as repeating based on numerous criteria in a similar way to that available in other calendar programs E.G. Outlook.  
Any modifications to details of a task which is part of such a repeating sequence are automatically copied to the other tasks in the sequence. 
Tasks may be moved within the sequence or removed from it or the whole sequence removed in one procedure. 
 
 
 
 
3. Starting a Repeating Sequence 
2.1. Enter the details for the first task of the sequence. 
CRM > Customer Relations Management > Tasks 
 
It is not important if the date of this task matches the repeating sequence but any sequence you define would start after the date of this task; you are warned if you 
enter a repeating sequence that does not include the date of this task. 
 
 
2.2. Repeating Task sub-level 
Enter the Repeating Task sub-level and enter the sequence required (Daily, Weekly, Monthly or Year) 
 
Enter either the number of task in the sequence NB. This includes the task entered so 1 occurrence is just this task! Or enter a date after which the sequence should 
end. NB. No tasks will be created with a date greater than this date.

2.2.1.  Daily 
You may enter details to repeat the task every set number of days. 
 
 
Or just every weekday. 
 
2.2.2.  Weekly 
You may repeat individual days of the week every set number of weeks, the day of the current task is ticked by default for you. 
 
 
2.2.3.  Monthly 
You may enter specific day of month every set number of months, the day of the current task is defaulted for you. 
 
NB. Enter a day of the month greater than 28, if the month has less than the day entered the last day of the month is used. 
 
Or occurrence  of a day in a month every set number of months, the values for the current task are defaulted for you.

You may specify every set number of years

4. Viewing tasks in the same sequence 
3.1. To find the tasks in a sequence search by Repeating Task ID  
NB. F4 used to change form view so showing the repeating tasks clearer. 
 
NB. Original Task shows the task ID of previous task in the sequence. 
 
3.2. Amend details on one task 
Amend any details other than Start Date, Start Time, End Date, End Time, Closed or Status, Remind? And Hrs/Mins in Advance and the changes are repeated on all 
tasks within the sequence. These other values are unchanged and should be maintained for each individual task. 
 
3.3. Amend date/times on one task 
Amend the Start Date, Start Time, End Date or End Time and you are given a warning. 
Click OK to continue and change this tasks date/times but if you wish to keep the task but remove it from the sequence use the direct activation shown.

7. Changing repeated tasks sequence 
 
6.1. Amending the repeating task details 
Ideally do this for the first task in the sequence. However, you will be warned that if you do not then your sequence will now start from the date of the current task 
being viewed. 
All existing tasks (including any exceptions to the sequence) are removed and new tasks matching the change in sequence created. 
 
 
6.2. Amending the recurrence type 
Again ideally do this for the first task in the sequence; you asked to confirm the change and if OK then existing details are cleared for fresh details to be entered.
