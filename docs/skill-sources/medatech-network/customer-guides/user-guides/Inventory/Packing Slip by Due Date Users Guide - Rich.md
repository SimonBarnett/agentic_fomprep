Packing Slips by Due Date  Users Guide 
1. Description 
 
This module will allow you to create packing slips for Sales order based on the due date of the order lines. 
Either run from the menu to select multiple sales orders or as a direct activation on the sales order form 
for individual order. 
2. Set-up Constants 
 
System Management > System Maintenance > Constant Forms > Medatech Company Constants 
 
Set one or both the constants to control system behavior.

3. Run Procedure from Menu. 
 
Inventory > Inventory Transactions > Sales Inventory Transactions > Create Packing Slips by Due Date  
3.1. Enter Sales Order No. or F6 to select multiple Sales orders. 
 
3.2. Enter the Due Date up to which you want order lines included. 
 
3.2.1.  A list of the packing slips created is displayed.
