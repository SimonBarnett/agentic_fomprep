1. Description 
 
The part average usage module enables the user to see the monthly average usage of a part within the Part Availability form with a sub-level showing a 
breakdown over different document types. The user may define which document types are included in the calculation and the number of months over which 
the average is taken. 
2. How to set up 
 
2.1. The Document Types to include in the calculation should be set-up. 
Inventory > Inventory Maintenance > Inv. Transaction Documents 
 
Tick the flag for the documents to be included in the calculation.
