1. Description 
 
The shipping document currency invoice module enables the user to raise an Invoice in the currency displayed on the shipping document where it differs to 
the customer's default currency. 
2. How to set up 
 
2.1. The Document Types to use when creating the invoice should be set-up. 
Inventory > Inventory Maintenance > Inv. Transaction Documents
