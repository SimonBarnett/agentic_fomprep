1. Description 
 
The user text as mail text module enables maintenance of text against each user and the option to copy this 
text when the user uses the Priority Compose Mail form. 
2. How to set up 
 
2.1. A  System constant should be set for module operation. 
 
System Constants must be set up in the form: 
System Management > System Maintenance > Constant Forms > Medatech System Constants
