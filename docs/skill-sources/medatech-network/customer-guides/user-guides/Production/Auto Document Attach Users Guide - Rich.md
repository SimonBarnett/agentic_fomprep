various places within the system. E.G. Quotations, Sales Order or Work Orders etc. See below

3. Example Documents Auto Attaching to Customer Quotation 
 
This functionality is the same for all the documents to which part documents can be auto attached. 
a. After adding part to a quotation 
 
 
 
b. Ticked documents for this part are added as attached to a quotation. 
c. If the same part is added more than once to a quotation the linked documents for the part are 
only added once. 
d. If all the quotations lines for this part are removed from the quotation , any linked attachments 
will also be removed.  
4. Work Orders 
 
a. The documents auto attached to the work order are those for the part specified on the work 
order. 
5. ECO’s 
 
a. The documents for the parts referenced in the Parts in the ECO sublevel are auto attached to 
each part referenced in the ECO.
