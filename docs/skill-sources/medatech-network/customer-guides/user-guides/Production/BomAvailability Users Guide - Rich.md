1. Description 
 
The BOM availability module adds new “Purch. On-Hand Date” and “Max Can Make” fields to Sales Order Items and Quotation Items forms, plus a new series 
of BOM availability sub-level forms to Sales Order Items and Quotation Items forms.  These sub-levels display availability details of the child parts of the 
ordered item. In addition, it introduces 'Required for Issues' and 'Open Work Orders’ fields to the Part Availability form. 
2. Quotation and Sales Order Items BOM Availability 
 
1. Purch. On-Hand Date and Max Can Make 
Two new fields showing the On-Hand date if purchased today and the maximum quantity that can be made from existing child part availability, both values updated whenever sales order 
quantity is entered or amended.

Fields shown: - 
 
 
1. Parent No. 
a. Parent part number. 
2. Parent Des. 
a. Displays a brief description of the parent part. 
3. Child Part Number 
a. The number of the child part that joins this parent part. 
4. Part Description 
a. Displays a brief description of the child part. 
5. Type 
a. Child part type. 
6. Coefficient 
a. A numerical value representing the required ratio of child parts to the parent part. 
7. Qty Required 
a. Quantity of child parts is required to produce the ordered quantity of parent parts. 
8. Inventory Quantity 
a. Inventory quantity of child part last time values calculated. 
9. Lead Time 
a. Lead time for this part. 
10. Info 
a. A check mark that indicates that the child part is recorded only for informative purposes. 
11. Shortage/Surplus 
a. Quantity shortfall or surplus of this part.
