1. Description 
 
Disposes of any stock reported as rejected in Production > Production Control > Reporting Production or Production > Production Control > Reporting Production 
Details. Warning, if you have stock of rejected parts that you intend to rework then carry out the relevant rework procedure before running the Bulk Disposal of 
Rejected Stock procedure.  Disposal only occurs if enough stock is still in the Floor (Flr) warehouse at the Rejected status and matching work order/operation unless 
Company Constant “BulkInvDispA" is changed.  NB. It is very strongly recommended no reporting production is performed whilst this procedure runs.
