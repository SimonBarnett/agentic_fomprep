Copy Part – Replace in BOM  Users Guide 
1. Description 
 
This module will allow you to copy a Part, make changes to the copy (such as changing the part type) and 
then replace the copied part with new one. All occurrences of the 'From Part' will be replaced by the 'To 
Part'. 
2. Run Procedure from Menu. 
 
Production > Factory Modelling > Parts > Replace Part - Occurences in BOM or 
Inventory > Parts > Part Maintenance > Replace Part - Occurences in BOM
