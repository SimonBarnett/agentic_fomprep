1. Description 
 
This new procedure will update the part and operation processing parameters for all parts, based upon the values in their 
routing. Therefore, ensuring that standard costing picks up the correct values. 
2. Update Part Processing Parameters 
Production > Factory Modelling > Routings > Update Part Processing Parameter 
 
Select Routing and part (you may F6 to select multiple records)
