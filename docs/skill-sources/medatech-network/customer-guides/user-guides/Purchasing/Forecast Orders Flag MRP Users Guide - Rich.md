Forecast Sales Order MRP Flag  Module  
Users Guide 
1. Description 
 
New version of Purchasing > Demand Forecasts > Prepare Orders from Forecast called Purchasing > Demand Forecasts > 
Prepare Orders from Forecast-MRP which will also update the MRP flag on the Forecast Sales Order Items based on a  user 
settable  constant with options:- 
 
0 = Set to Blank (even if Part Flag for MRP module is installed) 
1 = Set the MRP Flag to Y 
2 = Set the MRP flag to N 
3 = Follow Part MRP Flag rules (if Part Flag for MRP module is installed)
