Purchase Order Authorisation Summary User Guide 
1. Description. 
This adds a sub-level form “Authorisation Summary” to the Order Authorisation sub-level form on Purchase Orders. It shows summary information regarding the items 
on the PO and is useful when wanting an overview for authorisation purposes. To ensure that the PO is well priced and sensible quantities are used etc.
