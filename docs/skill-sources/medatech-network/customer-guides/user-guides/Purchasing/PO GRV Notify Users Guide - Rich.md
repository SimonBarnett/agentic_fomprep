Purchase Order GRV Notify User Module Users Guide 
1. Description 
 
Add the ability to flag a Sales Order line so if a purchase order is created based on the sales order, when that purchase order is goods 
receipted the purchase order assigned user is notified the GRV has occurred. 
 
Also adds the ability to flag a manually created Purchase Order line so when that purchase order is goods receipted the purchase order 
assigned user is notified the GRV has occurred. 
2.  Sales Order – Purchase Order Notify Flag

4. GRV Mail Messages 
 
When Quantity entered or approved and record saved/updated the appropriate mail message is sent. 
 
 
 
Message would read either 
 
Part MADEBYSUB, requisitioned in sales order PO13000006, has arrived. It appears in GRV GR13000017. 
 
Or 
 
Part 112-001, in purchase order PO13000008, has arrived. It appears in GRV GR13000019.
