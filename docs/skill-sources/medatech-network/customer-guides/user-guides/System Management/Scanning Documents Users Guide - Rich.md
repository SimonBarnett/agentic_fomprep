5. Multi-Document Scanning 
 
Additional Module add-on for scanning in documents procedure from priority and attaching the scanned document to the 
originating entity. NB. Requires document enhancements so documents produced from priority can then be scanned back-
in. 
 
Office Management > Scan Batch of Barcoded Documents 
 
NB. Any documents to be scanned back in must have been modified to print the appropriate bar code at the appropriate 
size at the top of the document so this procedure can scan them back in and attach correctly. 
 
Documents modifiable to print Scanning barcode and thus use with multi-scanning 
Procedure Title 
WWWSHOWDOC_C Print Inventory Count Form 
WWWSHOWDOC_D Print Shipping Document Supports Proof of Delivery 
WWWSHOWDOC_N Print Customer Return Doc. 
WWWSHOWDOC_O Print Inventory Disposal Doc. 
WWWSHOWDOC_P Print GRV 
WWWSHOWDOC_Q Print Service Call Form 
WWWSHOWDOC_W Print Return to Vendor 
WWWSHOWDOC_Z Print Service Contract 
WWWSHOWAIV Print Sales Invoice Supports Proof of Delivery 
WWWSHOWPROJTEXT Print Planning Document 
WWWSHOWRPROJ Print Scope of Work (SOW) 
Proof of Delivery 
Documents which Support Proof of Delivery will print a bar code that causes that document to be attached to the linked 
Sales Order if one is defined for that document.
