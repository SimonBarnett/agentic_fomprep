# Financials II part 2exercises

- **Source:** `Financials II part 2exercises.docx`

Financials part 2 exercises

Set up a new customer group and assign 5 customers to the group.

Create your own credit card company in the payment means form. Create two lines for it, each with different payment terms.

Set up tax codes for Input UK, Input EU, Input Rest of World, Output UK, Output EU, Output Rest of World and assign an up to date default group to the UK Input and UK Output.

Define a new tax group and add it to the Output EU tax code.

Assign your new tax group to a part.

Set up a cashier to hold your cheques.

Set up a new bank with 1 branch.

Set up a bank account for this branch and create a GL account for the bank account.

Go to V:\DOCUMENTATION\SOP and read the document about intrastat. Also refer to the intrastat wizard within Priority.
