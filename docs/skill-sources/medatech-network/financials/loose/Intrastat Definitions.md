# Intrastat Definitions

- **Source:** `Intrastat Definitions.docx`

Intrastat Definitions

-Record an appropriate intrastate code against each EU country in the countries form. This is usually the same as the country code.

Record delivery terms and assigns an intrastate code to each. Do this in the Terms of Delivery form.

In the Itemized Customs Rates form define the appropriate customs items

For each item:

-Flag incl in instrastat

-If supplementary units are required, flag the sup units – intrastat

-Make sure each customer has a country

-If customer has more than one site in more than one country you should define a country for each site.
