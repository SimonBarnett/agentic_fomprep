/******************************************************************/
/* ZEMG_DAYOFMONTH Return the 1st,2nd,3rd,4th or Last given       */
/*                 day of the week in a month.                    */
/*                                                                */
/* INPUT: :i_STARTDATE = Date of month required but also the      */
/*                       Earliest Date to Return                  */
/*        :i_OCCUR = 'First','Second','Third','Fourth' or 'Last'  */
/*        :i_DAYOFWEEK = Day of Week 1 = Sun, 2 = Mon ... 7 = Sat */
/*                                                                */
/* OUTPUT: :o_MONTHDATE = Date8 of the required day of the Month  */
/******************************************************************/
