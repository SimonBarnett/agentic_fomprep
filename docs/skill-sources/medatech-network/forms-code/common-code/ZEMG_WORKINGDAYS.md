# ZEMG_WORKINGDAYS

- **Source:** `ZEMG_WORKINGDAYS.txt`

~~~
/******************************************************************/
/* func/ZEMG_WORKINGDAYS                                          */
/* Returns the number of working days inclusive between two dates */
/* Only works on whole days so any entry matching day of week in  */
/* Office Management > Appointments & Office Hours > Office Hours */
/* is counted as a working day.                                   */
/*                                                                */
/* INPUT: :i_FROMDATE (DATE8) = Start date to count working days  */
/*        :i_TODATE (DATE8) = End date to count working days upto */
/*                                                                */
/* OUTPUT: :o_WORKINGDAYS = Number of working days                */
/******************************************************************/
~~~
