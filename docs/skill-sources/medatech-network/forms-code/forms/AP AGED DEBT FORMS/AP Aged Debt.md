# AP Aged Debt

- **Source:** `AP Aged Debt.docx`

Accounts Payable Aged Debt User Guide

Description.

This adds a sub-level form “AP Aging” to the Chart of Accounts Payable and Financial parameters for vendors’ forms. It shows the unreconciled transaction totals by aged debt. Sub-levels to this form show the transaction making up the values for each debt period.

Financials > Nominal Ledger > Chart of Accounts > Chart of Accounts Payable

Financials > Maintenance of Financials > Basic Data > Default Values > Financial Parameters for Vendors
