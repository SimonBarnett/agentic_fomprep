# Currencies Wizard

 

 Priority comes equipped with an extensive list of currencies, which may be revised or added to as needed. In order to record financial transactions in multiple currencies, you need to fill in the current exchange rates for the currencies in which you intend to work, and maintain those rates on a daily basis. 
 

The Priority dual-currency system allows you to define an official second currency , in which financial data can be recorded instead of or in addition to the local currency. This is particularly useful if your major trading partners use a common foreign currency (e.g., the Euro). The second currency appears in transaction documents, financial reports and costing results. 
 

In a multi-company setting, different local and second currencies can be set up per company, and exchange rates can be shared so that they only need to be updated once for the entire system. You can also copy past exchange rates in a batch from an external source, using an MS-Excel spreadsheet.
