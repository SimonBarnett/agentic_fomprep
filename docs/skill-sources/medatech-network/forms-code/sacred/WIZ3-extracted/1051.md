# Profitability Wizard

 

When recording prices in price quotations and sales orders, it is important to be able to gauge the profitability of the part relative to the part's cost. 
 

 Priority offers powerful on-line calculations of profitability, determining the difference between the part's cost and price while taking into account discounts awarded, sales rep commissions and shipping costs. For example, if you resell parts purchased from a vendor, Priority can calculate a recommended price when you prepare a quote, based on the desired markup. 
 

Profit calculations also take into account an ordered/quoted part's customized bill of materials, calculating its item cost accordingly. Furthermore, you can set up the system so that the item price is also based on the custom BOM, rather than derived from the usual sources (e.g., price list, order price).
