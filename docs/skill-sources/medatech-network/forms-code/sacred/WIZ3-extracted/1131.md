# Open Customers Wizard

 

New customers are usually recorded in Priority as potential customers, for use in the CRM module. Potential customers do not receive A/R accounts until they are converted into regular customers. It is also possible to open a customer record and A/R account directly, without first opening a potential customer. The methods for doing so differ according to the setting of the IdentCustAcc constant. 
 

If you work with subsidiaries, this constant will already have been set; if not, you may need to adjust the setting before you begin opening customer records. For more information about the constant and its effect on subsidiary accounts, run the Subsidiaries Wizard . 
 

In addition to potential and regular customers, you can also create a single account for all walk-in customers , create a customer from an existing vendor and assign your customers representative and/or billing customers. 
 
## Note:

 

 Priority allows you to define a GL account so that it also functions as an A/R account (for example, to allow you to invoice an employee who makes a purchase from the factory store). For details, run the Converting Accounts Wizard .
