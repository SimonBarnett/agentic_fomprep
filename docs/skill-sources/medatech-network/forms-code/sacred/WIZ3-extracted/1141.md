# Open Vendors Wizard

 

New vendor records can be numbered automatically on the basis of user-defined numeration templates. The method of opening A/P accounts is based on the setting of the IdentCustAcc constant. 
 

If you work with subsidiaries, this constant will already have been set; if not, you may need to adjust the setting before you begin opening vendor records. For more information about the constant and its effect on subsidiary accounts, run the Subsidiaries Wizard . 
 

In addition to regular vendors, you can also create a single account for all one-time vendors , and create a vendor from an existing customer. 
 
## Note:

 

 Priority allows you to define a GL account so that it also functions as an A/P account. For details, see the Converting Accounts Wizard .
