# Library Wizard

 

Using Priority ’s Library module, you can keep track of publications in your company library. You can also record general information about each publication (e.g., subject, date created). Library publications can then be linked to various system documents, projects and customers via their library catalogue record. Priority also allows you to maintain multiple versions of any library publication with different dates of publication.
