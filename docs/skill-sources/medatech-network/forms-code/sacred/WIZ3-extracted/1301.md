# Taxes Wizard

 

Taxes in Priority are maintained by tax codes and tax groups . When a given tax is made up of two different taxes, you can create tax components to reflect this in the system. 
 

When a sales document (e.g., price quotation, sales order, customer shipment, service call) is prepared for a given customer, Priority automatically calculates the correct amount of tax and adds it to the document. Each document “inherits” the tax from the previous document (sales order from a price quotation, for example). You can manually change the tax rate at any point. 
 

For dual-currency users, the same is true for purchasing documents (whereas in the U.S. package, tax is included in the unit price). That is, tax is calculated automatically and copied from one document to the next. Again, it can be changed manually. 
 

Dual-currency users assign default tax codes to vendors as well as customers, and work with taxes differently than users in the U.S.
