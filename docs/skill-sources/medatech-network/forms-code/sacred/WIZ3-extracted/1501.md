# Open GL Accounts Wizard

 
## What do you want to do?

 

 Open GL accounts automatically 
 

 Open GL accounts manually 
 
## Notes: 

 

 ·        If you work with subsidiaries, use this wizard to create the full complement of GL accounts for the main company, then run the Subsidiaries Wizard . 
 

 ·        If you mistakenly recorded GL accounts in the Chart of Accounts Payable or Chart of Accounts Receivable, you can run the Converting Accounts Wizard to convert them into GL accounts. 
 

 ·        To define secured accounts and restrict access to them, run the Data Authorization Wizard .
