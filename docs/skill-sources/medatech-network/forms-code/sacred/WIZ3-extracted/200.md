# Troubleshooting Costing Wizard

 

This wizard is helpful when you have received incorrect or missing costing data for one or more parts. It will guide you through a series of questions regarding your working methodology and the costing components of the parts in question, in order to identify the source of the problem. 
 

Once you have found and corrected the erroneous data, rerun the costing program and check the results. If you do not succeed in solving the problem in question, contact the Eshbel support staff.
