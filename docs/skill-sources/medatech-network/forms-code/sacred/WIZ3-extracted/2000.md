# Report Generators Wizard

 

 Priority ’s report generators allow you to design and produce customized reports, save them for future use, share them with other users and run them for different types of input data. 
 

Each Priority module contains one or more report generators covering different cross-sections of system data. You can run the appropriate generator from the modular menu, or run the Customized Report Generator , which contains them all. Once you’ve chosen the type of report you want to create, you can select the data columns you want it to include. You can then arrange the columns in the desired order, define input columns and pre-sort the report’s results. Finally, you can determine whether the report is available for general use, or for your eyes only. 
 
## To design a report in the Report Generator:

 

 1 .  Run the Customized Report Generator . 
 

 2 .  Select the type of report that you want to produce and click Next . 
 

 3 .  In the screen that opens, click New to design a new report. 
 

 4 .  Use the mouse to drag the desired columns into the Displayed Fields area.
 Notes: 
 

 ·     To display multiple descriptions of the same part number, select the Multiple Part Descr. column rather than the Part Description column. 
 

 ·     Certain columns can be displayed either with or without column totals. 
 

 ·     To display separate lines corresponding to the lines in the document on which the report is based (e.g., order, invoice), select the appropriate line column (e.g., Order Line , Line (in Inv.) ). 
 

 ·     When the report is based on a document originating in a sales or purchase order, you can display each line in the document as a separate line in the report by including the Line Order column. 
 

 ·     If you want to add an expression column to your report, drag an Add Expression column to the Displayed Fields area, as well as the columns to be represented in the expression. The expression itself will be defined in the next screen. 
 

 ·     Rearrange the order of your chosen columns by dragging them higher or lower on the list.
