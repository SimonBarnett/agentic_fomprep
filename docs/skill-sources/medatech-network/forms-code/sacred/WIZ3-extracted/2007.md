# Ledger Report Generator Wizard

 

 Priority 's ledger report generators allow you to design and produce customized reports, save them for future use and share them with other users. 
 

You can select the data columns you want it to include from the predefined list appearing in the sub-level form, create expression columns , and pre-sort the report results by arranging the columns in the desired order. Finally, you can determine whether the report is available for general use, or for your eyes only. 
 
## Note:

 

This wizard refers to report generators in Priority : Ledger Rep Generator(Trans Date) and Ledger Rep Generator (Ref Date) . The instructions for the use of these wizards are identical. 
 
## What do you want to do?

 

 Create a customized ledger report 
 

 Add a column to an existing report 
 

 Run a customized ledger report
