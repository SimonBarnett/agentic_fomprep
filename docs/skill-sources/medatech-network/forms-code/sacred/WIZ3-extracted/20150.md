# Service Contract Wizard

 
## Overview

 

Service contracts apply to individual parts in a customer's possession. The contract determines which services for this part (work hours, replacement parts and so on) are offered. It also determines which services are exempt from payment and which are billable. Example. 
 
## What do you want to do?

 

 Define service costs for parts 
 

 Prepare contracts 
 

 Add items to an active contract 
 

 Calculate total contract cost 
 

 Calculate payment installments 
 

 Prepare invoices for contracts 
 

 Renew contracts 
 

 View expected revenues from service contract payments
