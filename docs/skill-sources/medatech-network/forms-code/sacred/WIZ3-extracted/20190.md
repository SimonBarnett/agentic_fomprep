# Serial Numbers Wizard

 
## Overview

 

By assigning serial numbers, you can designate exactly which serialized parts are involved in specific inventory transactions. You can also trace a part throughout its entire course of inventory transactions . 
 

More specifically: As a serialized part undergoes successive inventory transactions, you attach the serial number to each of these transactions. This creates a chain of transactions, which you can later trace. 
 
## Notes: 

 

 ·        This wizard does not cover the recording of serialized parts in warehouse assemblies and service calls, where you can record the serialized parts and their child parts directly in the document. For more information, run the Warehouse Assembly Wizard or the Service Call Wizard . 
 

 ·        For routine servicing of serialized parts, run the Service Call Wizard . 
 

 ·        Assigning serial numbers has no effect on inventory balances. These balances are maintained per part number (not per serial number), and are updated when the inventory transaction is recorded.
