# Manual Journal Entries Wizard

 

Most financial transactions in Priority (e.g., invoices, payments) automatically create journal entries. Sometimes, however, you need to write entries manually (e.g., payroll). 
 

Journal entries can be divided into two types: 
 

 Simple entries generally contain two lines, one debiting the debit account and the other crediting the credit account. When recording the entry, you designate the debit and credit accounts, and the entry is itemized automatically. 
 

 Complex entries have no set pattern. They are of varying lengths, generally with many lines that you fill in manually. 
 

If you find yourself recording the same long complex entry every month or quarter with minor variations, you can copy its details into a new entry and revise it as necessary. 
 
## Note: 

 

Normally, you cannot post a journal entry to a closed fiscal period. However, if the need arises, you can be authorized to record journal entries for a period that has already been closed. For details, run the Fiscal Periods Wizard .
