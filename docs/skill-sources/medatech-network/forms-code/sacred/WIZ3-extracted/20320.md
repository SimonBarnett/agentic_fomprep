# Set Up Payment Terms Wizard

 

Payment terms agreed upon with the customer or vendor determine the payment dates appearing in invoices. 
 

 Priority provides a predefined set of payment terms. You can define as many additional payment terms as necessary. The terms assigned to customers and/or vendors will be the default payment terms whenever an invoice is recorded for the customer/vendor. Payment terms can always be revised in individual invoices.
