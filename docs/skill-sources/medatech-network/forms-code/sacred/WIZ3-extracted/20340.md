# Branches Wizard

 

 Priority 's branch module is used by companies that maintain different physical branches. By using branches, you can distinguish between financial and/or inventory transactions carried out in different branches. 
 

If you work with subsidiaries, branches also determine the subsidiary for which inventory and financial transactions are recorded. When a branch is specified in a document, the printout of that document displays its subsidiary's logo and contact information. Furthermore, the branch in a financial document affects the accounts in the journal entry, which will be taken from the corresponding subsidiary. 
 

You can assign default branches to users, customers, vendors and warehouses that will appear automatically in transaction documents. You can also assign the user to multiple branches, and define the default settings for documents opened by that user for each branch. 
 

If your company maintains a large number of branches, it is advisable to group them into areas. You can define these areas at your convenience and then assign each of your branches to the appropriate area.
