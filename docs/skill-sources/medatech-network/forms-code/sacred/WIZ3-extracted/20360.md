# Fiscal Periods Wizard

 
## Overview

 

 ·        Fiscal Years
 Priority maintains multi-year data. At the start of each year, open a new fiscal year and define its fiscal periods. Also transfer opening balances to the new year. 
 

 ·        Fiscal Periods
 The easiest way to work with fiscal periods is to use 12 per year, one for each full month. If you want, you can instead define up to 15 fiscal periods a year. You can also set periods that are shorter or longer than a month.
