# Set Up Entry Codes Wizard

 

 Journal entry codes determine how accounts are credited and debited in journal entries. Priority provides a predefined entry code for each type of financial transaction (e.g., vendor invoice, receipt), which serves as the default. The entry code assigned to any given document determines the structure of the journal entry that is created when the document is finalized. 
 

Sometimes a given transaction requires a different type of journal entry than the one assigned automatically (e.g., Purchasing 60-40 ). When this occurs regularly (as opposed to a one-time transaction), you should design your own entry code for it. Whenever you record such a transaction, assign your user-designed entry code to the document in question. 
 

You can also create your own entry codes for transactions involving a particular customer or vendor with unusual transaction terms. These codes will serve as the default for all financial documents recorded for that customer/vendor. Similarly, if you work with branches, you can define special entry codes that apply to each branch. This allows you to easily create different types of journal entries for documents recorded in different branches.
