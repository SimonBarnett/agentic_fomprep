# Journal Entry Batches Wizard

 

A batch is a group of journal entries recorded manually by a particular user. Batches help you organize journal entries efficiently. You are not required to work with batches, and when working with batches, you do not have to include every manual journal entry in a batch. 
 
## What do you want to do?

 

 Create an entry batch 
 

 View entry batches 
 

 Close entry batches
