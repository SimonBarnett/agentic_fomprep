# Set Up Default Accounts Wizard

 

To set up default accounts, you need to assign them GL accounts. 
 

Click to run the Open GL Accounts Wizard , if you have not yet defined GL accounts. 
 

For certain types of financial transactions (List) , a GL account is automatically debited or credited when you finalize the financial document. Examples.
