# Set Up Accounting Families Wizard

 

In Priority , you can group parts together into accounting families for various financial purposes. Then, you can use the families to: 
 

 ·        Assign a common GL account to all parts in the family. Example. 
 

 ·        Assign a profit or cost center to all parts in the family 
 

 ·        Create reports by family. 
 

You can also define family types, and assign each accounting family a type. This will enable you to categorize accounting families according to your needs for effective grouping and retrieval. 
 
## Note:

 

Accounting families, which are used to group parts by a financial parameter (e.g., parts that do not incur taxes when sold), should not be confused with part families, which are used in purchasing and sales (e.g., for giving a customer a discounted price for all parts in a given part family). Hence, while accounting family X may include the same parts as part family Y, their function in the system is entirely different.
