# Printing Wizard

 

 Priority allows you to assign a specific printer to individual reports and other printouts. Example. Such reports can then be printed without user intervention. 
 

In addition, you can define whether each document will display the company logo, the company's name and address or no header (when output is on pre-printed paper). 
 
## Notes: 

 

 ·        In order to link a report to a printer, you must first define the printer in Priority . 
 

 ·        In order to use the company logo, you must first install the appropriate logo file in Priority (you can install several logos in a multi-company setting). 
 
## What do you want to do?

 

 Define a printer in Priority 
 

 Link a report to a printer 
 

 Enable printing without user intervention 
 

 Install a logo file 
 

 Set a header style for a document (logo, name and address, or no header)
