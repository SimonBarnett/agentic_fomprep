# Initial Inventory Count Wizard

 

One of the first things you have to do when you begin to work with Priority is to record initial inventory counts. It is assumed that a physical count was performed in all warehouses immediately before beginning to use this system . 
 
## Note: 

 

Do not record any inventory transactions before recording an initial count, since this count initializes inventory. If such transactions have been recorded before the initial count, they must be canceled.
