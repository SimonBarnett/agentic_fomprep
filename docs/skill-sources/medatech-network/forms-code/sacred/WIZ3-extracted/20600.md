# Inventory Count Wizard

 

Inventory counts in Priority serve two main purposes: 
 

 ·        to enter initial inventory levels into the system when first installed and whenever a new warehouse is acquired with inventory 
 

 ·        to record routine physical counts and compare them to calculated inventory levels, making adjustments to the database when necessary.
