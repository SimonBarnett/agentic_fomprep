# Bank Loans Wizard

 

Use Priority 's loans facility to handle all aspects of bank loans that you receive. 
 
## What do you want to do?

 

 Set up the Loans module 
 

 Experiment with various parameters (e.g., interest rate, number of payments) before approaching the bank 
 

 Record a new loan 
 

 Prepare the amortization schedule 
 

 Make loan payments 
 

 Repay an entire loan early 
 

 Record changes in base interest rates (e.g., the prime rate) 
 

 Postpone loan payments 
 
## For dual-currency users:

 

 Record changes in the exchange rate of the linked currency 
 

 Record changes to the Last Known Index
