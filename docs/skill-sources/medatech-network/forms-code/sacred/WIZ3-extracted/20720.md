# Set Up Cashiers Wizard

 

You need to set up cashiers so that you can record cash transactions in Priority . There are several predefined cashiers, but you can define additional ones. You also need to define a GL account for each cashier. 
 
## Note: 

 

If you ran the Account Initialization program (in the U.S. package) or the Account Initialization-Intl program (in the dual-currency package), GL accounts were set up automatically for the predefined cashiers. 
 
## What do you want to do?

 

 Complete the set up of a predefined cashier 
 

 Define a new cashier 
 

 Initialize cashiers
