# Deposits Wizard

 

Deposits can be recorded manually or prepared automatically in a batch. A deposit slip should be created whenever funds are withdrawn from a cashier and transferred to a bank account, a credit card company, another cashier or some other account. 
 
## What do you want to do?

 

 Set up deposits 
 

 Record a deposit slip 
 

 Finalize and print a deposit slip 
 

 Revise a final deposit slip 
 

 Cancel a deposit slip 
 

 Delete a pending deposit slip
