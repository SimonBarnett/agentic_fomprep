# Returned Payments Wizard

 

If the bank or credit card company returns a customer's payment, you need to do the following: 
 

 ·        Record the return of the payment, including any fee that you were charged and that you are passing on to the customer. 
 

 ·        Print a returned payment notice for the customer. 
 

 ·        If desired, prepare an invoice to bill the customer for the return fee and/or finance charges for the returned payment. 
 

 ·        When appropriate, remove returned payments from the Returned Payments Cashier and transfer them to the customer's account (thereby debiting the customer), back to the bank (for redeposit) or to a third party (e.g., a collection agency).
