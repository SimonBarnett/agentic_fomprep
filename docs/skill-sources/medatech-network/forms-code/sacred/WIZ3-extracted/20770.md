# Personnel Setup Wizard

 

Before you begin working with the Human Resources module, you need to establish work processes and build basic data tables (e.g., departments, positions, qualifications) for use in the routine management of human resources. 
 
## You need to set up the following: 

 

 Business processes (BPM) for human resources (statuses) 
 

 Company departments 
 

 Recruitment of employees 
 

 Positions 
 

 Qualifications 
 

 Employee data 
 
## Note:

 

Click to perform additional setups for human resources.
