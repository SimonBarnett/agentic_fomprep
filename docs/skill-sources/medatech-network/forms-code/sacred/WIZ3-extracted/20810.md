# Employee Wizard 

 

 Priority allows you to record and view various types of information about your employees. 
 
## Notes:

 

 ·        Some personnel data is shared by all companies, some is specific to the current company and the rest is recorded/displayed in multi-company forms. 
 

 ·        It is likely that personnel files were opened, with preliminary data, during the initial stages of working with the system (with the help of the Open Personnel File Wizard ). In that case, you should use the current wizard to “fill in the blanks”. 
 

 ·        If you do not work with Windows Active Directory, your system manager can load employee and user data from external sources into Priority . For further information on loading data from external sources, see the Data Migration Wizard . 
 
## What do you want to do?

 

 Set up the personnel file (when beginning work with Priority ' s Human Resources module) 
 

 Record a new employee 
 

 Handle employee evaluations 
 

 Record an employee applying for a new job within the organization 
 

 Record an employee ' s new position within the organization 
 

 Flag an employee as inactive
