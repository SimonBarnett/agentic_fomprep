# Budgets Wizard

 

The Priority Budgets module allows you to perform detailed planning of your company’s annual expense and sales budgets, and track the usage of budget items in real time. You can also define a multi-year budget for special projects, which is integrated into the regular annual budget. 
 

Specific budget items are divided into categories within a budget version . You can draft any number of budget versions for a given year, though only one version can be in effect at any given time. 
 

The budget is composed of three major elements: main categories, which represent the most basic compartmentalization of the organization’s expenses or income (e.g., branches, departments); optional sub-categories, which can divide each main category into more specific groupings (e.g., structural costs, salaries, sales of a specific fashion line); and the specific budget item , which is either an expense to which funds are appropriated, or a target sum for sales of a given part or part family. 
 

This wizard provides detailed instructions for all of the stages involved in building and tracking an annual budget.
