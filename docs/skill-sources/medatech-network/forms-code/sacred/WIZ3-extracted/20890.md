# Job Openings Wizard

 

 Priority 's Human Resources module provides you with the tools you need to define new jobs, identify suitable applicants and fill positions in your company. 
 

In addition, you can plot your company's organizational structure, define hierarchical relationships between positions and display the hierarchy graphically. 
 
## What do you want to do? 

 

 Define a new job 
 

 Open a new job on the basis of an existing one 
 

 Select suitable applicants 
 

 Record the f ill ing of a position 
 

 Plot the company ' s organizational structure
