# Privilege Explorer Wizard

 

Use Priority 's Privilege Explorer , which works similarly to the Windows Explorer, to assign privileges to the users of the system. You can assign read/write privileges for menus, forms, programs, reports and/or wizards. You can also affect usage of individual form columns, control access to print formats, and change how the user sees warning messages. 
 

To assign privileges, organize users into groups and assign the privileges to group leaders . All users who are members in a given group automatically “inherit” privileges from their group leader. Users can also be assigned to a few different groups, depending on the company in which they are working. 
 

Privileges take effect only for the company in which you are running the Privilege Explorer . A user who lacks privileges for a given company will not be able to select that company (i.e., it will not appear in the list). 
 

In addition to assigning privileges to work within the system, other privileges can also be assigned, such as: the privilege to perform system customizations ( SQL ), to access Priority data via external programs (e.g., MS-Access ), to customize the design of forms, menus and documents, to send data to MS-Excel or to print to a file. In most of these cases, privileges are assigned per user; in some, they may only be assigned to privilege group leaders. 
 
## Notes:

 

 ·        Only users with system manager privileges and users who are defined as managing privileges (in the Permissions tab of the User Permissions form) can assign or modify user privileges for other users/user groups. 
 

 ·        Click if you do not wish to work with privileges. 
 

 ·        You can also restrict user access to specific types of data (selected accounts, customers and vendors; documents recorded in selected branches or for selected sales reps). For details, run the Data Authorization Wizard . 
 

 ·        You can also assign privileges to an individual user who is not assigned any group leader.
