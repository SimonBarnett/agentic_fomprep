# Troubleshooting MRP Wizard

 

This wizard is helpful for resolving problems and analyzing results of the Material Requirements Planning (MRP) program (for example, issue quantities). It will guide you through a series of questions regarding part definitions and current part balances resulting from sales and production demands. 
 

Once you have found and corrected the erroneous data, rerun the MRP program and check the results. If you do not succeed in solving the problem in question, contact Customer Support. 
 

Choose from the following options: 
 
## Preliminary Checks

 

 Check if the part is subject to inventory control 
 

 Check the part's replenishment type 
 
## Demand Analysis

 

 De mand for parts of replenishment type R (or no defined type) 
 

 D emand for parts of replenishment type B 
 

 D emand from sales orders and forecast orders 
 

 D emand for assemblies 
 

 Production demands 
 

 Dem and generated by safety stock levels
