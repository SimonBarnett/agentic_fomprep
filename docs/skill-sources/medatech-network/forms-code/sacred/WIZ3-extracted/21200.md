# Restricting Customers Wizard

 

In Priority , you can use customer statuses to restrict a customer that has exceeded the credit limit or whose payment has been returned. As a result, users will not be able to record certain transactions with this customer (e.g., orders, shipments, invoices), as defined in the status properties. 
 

You can also use statuses to place a customer under warning, so that users will receive a warning message whenever they open a document for that customer. 
 

For more information about customer statuses, how to create and revise them, run the Open Customers Wizard .
