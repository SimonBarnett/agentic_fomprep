# Troubleshooting Purchase Planning Wizard

 

This wizard allows you to analyze the method used to calculate the quantities in purchase requisitions generated automatically for specific parts. 
 
### Before you begin:

 

 1 .  Run the appropriate MRP program for your company (Distributors/Manufacturers). 
 

 2 .  Run the Purchase Planning program.
