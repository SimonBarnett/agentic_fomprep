# Troubleshooting Backflush Wizard

 

This wizard is helpful for locating and resolving problems of inventory management in the floor warehouse resulting in missing issues. It will guide you through a series of questions regarding the relevant inventory and production definitions, the transfer (issue) of raw materials to floor warehouses, and production reporting, in order to identify the source of the problem. 
 

Once you have found and corrected the erroneous data, rerun the Backflush program and check the results. If you do not succeed in solving the problem in question, contact Customer Support. 
 

As a preliminary step, run the Backflush program from the last past balance. 
 

Choose the option that best resembles your scenario: 
 

 ·        Missing issues result ing from production reports 
 

 ·        Missing issues for parts produced by subcontractors, result ing from non-production inventory transactions on the plant floor
