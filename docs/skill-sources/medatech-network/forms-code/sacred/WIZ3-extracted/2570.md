# Financial Statement Generator Wizard

 

The Financial Statement Generator allows you to generate all basic types of financial statements: balance sheets, profit and loss reports, trial balances, and account trees. You can create regular statements and more detailed schedules. You can then customize the data displayed in the statement by adding totals and sub-totals at various levels of the statement; comparing financial data between subsidiaries, companies and divisions; comparing data between different periods within the fiscal year or across different years; and so on. This ensures that you can view all of your essential financial data in the desired format within the financial statements generated in Priority . 
 

The sums appearing in each report column are defined separately — in a column bar — from the items in the report itself. This enables you to mix and match type of statement and column bar when running the report. 
 

For instance: 
 

 ·        A column bar that compares YTD with last year's figures can be used with both a balance sheet and a P&L report. 
 

 ·        You can create consolidated statements via a column bar that displays sums for each company, together with a grand total.
