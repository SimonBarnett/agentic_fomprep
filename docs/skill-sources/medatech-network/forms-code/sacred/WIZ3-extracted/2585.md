# Set Up Financial Statements Wizard

 

 Priority provides a predefined hierarchy of headings and items for your balance sheet and profit & loss report ; however, you can change the order in which they appear in your financial reports, and add new items. 
 

 Trial balance items are created when accounts are set up automatically, though you can also record them manually. 
 

You should review the list of items defined for the balance sheet and P&L report and make any necessary changes before defining the GL accounts, since you need to define a balance sheet/P&L report item for each new account. 
 

Trial balance items can be defined later on (for example, before running a trial balance report), since a general trial balance item appears automatically for every new account. 
 
## Notes:

 

 ·        The setup of financial statements affects all balance sheet reports, profit & loss reports and trial balance reports provided by the system. In addition, Priority offers a financial statement generator for customized reports. For more information, run the Financ. Statemt Generator Wizard . 
 

 ·        Dual-currency users: If you are working in a language other than English and change the system language to English (in the Options menu of the main menu bar), financial statements appear in English. 
 

 ·        Click if you work in a multi-company setting.
