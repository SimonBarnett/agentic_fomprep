# Set Up Financial Documents Wizard

 

Financial transactions are recorded in various documents in Priority . Before you can record such transactions, you have to define attributes of the documents (e.g., whether to post journal entries automatically to the ledger when a sales invoice is finalized). You can also record set text for any type of financial document. 
 

Numeration templates are used to assign numbers to every type of financial document. If you work with branches, they can be defined per document type and branch. These templates need to be set up at the start of each year and when you begin to work with the system. It is also advisable to set up new templates when you install a new financial module and when you receive a new software release that includes new financial documents. 
 
## Notes:

 

 ·        Every transaction type is assigned a predefined journal entry code. Example . When you open a financial document, the code defined for that type of transaction is automatically assigned. If you require an entry code other than the default, you can record alternate codes or create new ones (see the Set Up Entry Codes Wizard ). If you work with branches, entry codes can be set per document type and branch. Example (see the Branches Wizard ). 
 

 ·        To set up printouts of documents, run the Printing Wizard .
