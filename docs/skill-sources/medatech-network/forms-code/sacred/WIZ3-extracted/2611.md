# Set Up Documents Wizard

 

Inventory and other transactions are recorded in various documents in Priority . Before you can record such transactions, you have to define attributes of the documents. 
 

Numeration templates are used to assign numbers to every type of document in the system. If you work with branches, they can be defined per document type and branch. Templates need to be set up at the start of each year and when you begin to work with the system. It is also advisable to set up new templates when you install a new module and when you receive a new software release that includes new documents. 
 
## Tips:

 

 ·        To set up printouts of documents, run the Printing Wizard . 
 

 ·        For more information on working with branches, run the Branches Wizard .
