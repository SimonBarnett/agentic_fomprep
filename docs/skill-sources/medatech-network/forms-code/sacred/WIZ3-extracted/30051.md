# Exchange Rate Adjustment Wizard

 

All accounts in Priority can be maintained in up to three different currencies: the local currency, the second currency (for dual-currency users) and the account currency (if different from the first two). In addition, dual-currency users can flag an account as multi-currency, so that reconciliations can be made in the transaction currency. 
 

Fluctuations in exchange rates between currencies may result in variance between account balances in the different currencies. The exchange rate adjustment programs are designed to correct for exchange rate variance in the relevant currency. Example . 
 

You need to define which accounts will be adjusted, as well as designate the contra accounts that will be affected in the process. 
 

For greater accuracy, run the exchange rate adjustment programs prior to running financial statements.
