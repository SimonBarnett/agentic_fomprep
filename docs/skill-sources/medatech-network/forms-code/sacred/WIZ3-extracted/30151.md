# Indexing Wizard

 

 Priority allows you to run financial statements with data linked to the price index. Accounts included in the same balance sheet item or P&L item can be flagged for inclusion in (or exclusion from) indexing calculations. You can also view indexed account balances and individual indexed transactions. 
 

In order to view data linked to the index, you must first run a program that adjusts transaction amounts to the price index currently in effect. The initial price index, to which the current index is compared, is taken from the one in effect on each journal entry’s reference date. There is one exception to the rule: if indexed sums are recorded directly in the journal entry, the program does not calculate new values. 
 

The program in question does not carry indexed balances over from one fiscal year to the next. Since you usually calculate linkage to the index for a given year at the beginning of the following year, after opening balances have already been transferred, it is necessary to transfer them again. In this way, you will have the correct indexed opening balances for the next year. 
 
## Notes: 

 

 ·        As index calculations are based on values assigned to the price indexes recorded in the system, it is important to update those values on a monthly basis. 
 

 ·        On linking order prices to the index, run the Price Adjustment Wizard . 
 

 ·        On recording indexed opening balances when beginning to work with the system, run the Opening Balances Wizard . 
 

 ·        On recording indexed values for depreciation purposes, run the Fixed Assets Wizard . 
 

 ·        On linking a bank loan to the price index, run the Bank Loans Wizard .
