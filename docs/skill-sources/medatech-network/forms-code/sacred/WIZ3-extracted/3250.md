# Check Payments Wizard

 

In order to prepare check payments to vendors, you need to open a payment document that determines which invoices will be paid, the amount involved and the bank account from which payment will be made. 
 

 Priority offers two options for recording check payments: 
 

 ·        Preparing in a batch: to prepare check payments to many vendors simultaneously. 
 

 ·        Preparing single checks: to prepare a check payment to one vendor. 
 
## Notes: 

 

 ·        To refund a customer by check, run the Refunds/Credit Vouchers Wizard . 
 

 ·        If you work with subsidiaries, the payment may not debit the A/P account recorded in the invoice, but rather another vendor account in a different subsidiary. Similarly, a payment may cover several invoices billing different subsidiaries. In this case you must prepare single checks, in order to allow all accounts to be reconciled.
