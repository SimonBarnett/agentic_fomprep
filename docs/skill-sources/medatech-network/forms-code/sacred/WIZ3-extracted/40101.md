# Working with Cashiers Wizard

 

 Priority provides you with various tools to manage cashiers and to monitor cash transactions. 
 
## What do you want to do?

 

 View the balance of a cashier 
 

 Confirm a receipt to a cashier 
 

 Revise details of checks and credit card vouchers 
 

 Close a cashier 
 

 Dual-currency users: Record postdated checks 
 
## Notes:

 

 ·        On how to make deposits to a cashier, see the Deposits Wizard . 
 

 ·        On how to handle payments received from customers, see the Customer Receipts Wizard . 
 

 ·        On how to handle returns of customer payments (e.g., checks that did not clear), see the Returned Payments Wizard .
