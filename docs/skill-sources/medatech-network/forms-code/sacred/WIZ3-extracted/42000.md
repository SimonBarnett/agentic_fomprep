# Costing for Businesses Wizard

 

 Priority 's Costing Analysis for Businesses module enables you to calculate and analyze part costs, transaction costs and inventory valuations. Costing for Businesses only calculates the costs of purchased goods and warehouse assemblies (materials and labor); to calculate the cost of goods manufactured in an industrial process, use the Costing for Manufacturers Module. 
 

There are two ways to calculate costs: for the date on which past balances were last calculated and for the current date. 
 

The first method calculates cost on the selected past balance date, based on all inventory transactions recorded in the system since the previous past balance. The values for that past balance period remain in the system, allowing you to maintain a history of part costs. 
 

The second method calculates cost on the day the program is run, based on all inventory transactions recorded in the system between the last past balance and the current date. Running this program ensures that programs using costing data will have access to the most up-to-date figures (for example, costing data are used to calculate sales order profitability and project costs). Each time you run costing for the current date, costs are recalculated according to the most recent data, and overwrite the program’s previous results.
