# Product Bundles Wizard

 

A product bundle is defined as any sold part that actually comprises an assortment of products (such as a gift basket). 
 

If your company sells such parts, you can define each one along with its components as a product bundle. Thereafter, when a quote or order is placed (whether a regular sale or a commission sale ), you can base it on a product bundle, and the sales document in question will be itemized with the bundle's component parts. 
 

Each component part in a given bundle can have defined substitutes. For instance, if a gift basket includes a bottle of wine, you can create a list of wines out of which to choose the proper one for any specific basket. 
 

If you do not wish to allow a given bundle to be recorded in quotes or orders for a given time period (e.g., because it is meant for the holiday season), you do not have to delete it. Simply define it as out of use. In the future, you can reactivate it, as needed. 
 
## Note:

 

This wizard explains how to define product bundles. For instructions on recording regular quotes, commission sale quotes and regular sales orders for a product bundle, run the Price Quotations Wizard , Commission Sales Wizard or Sales Order Wizard , respectively.
