# Project Management Wizard

 

The Project Management module enables you to: 
 

 ·        Record and update your customer's objectives in a Scope of Work (SOW) document 
 

 ·        Plan a project and its activities 
 

 ·        Assign personnel to each activity 
 

 ·        Plan the required materials for the project/activity 
 

 ·        Schedule the assigned personnel 
 

 ·        Track the work done for a project/activity 
 

 ·        Plan and track costs 
 

 ·        Schedule payments for the project 
 

 ·        Bill the customer for the project, or, when working on a cash basis, record a pro forma invoice for it 
 

 ·        Open service contracts for the project's finished products 
 

 ·        Run a wide variety of project reports 
 

Project planning in Priority is compatible with MS-Project; you can plan the project's activities and human resources in MS-Project and import the data into Priority . You can then continue to use the MS-Project file and regularly import the updated planning data into Priority . You can also export planning data from Priority to MS-Project.
