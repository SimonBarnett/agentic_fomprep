# Receipt/Return of Goods Wizard

 

 Priority enables you to record the receipt of goods from vendors in two different ways, according to the vendor's shipping method. 
 

 ·        If the shipment was accompanied by an invoice, you can record it in a vendor invoice. The invoice triggers an inventory transaction in addition to charging you for the received goods. 
 

 ·        If the shipment was accompanied by the vendor's shipping document, you can record it in a Goods Receiving Voucher (GRV). The GRV triggers an inventory transaction, but does not charge you for the shipment; this will occur when you record a multi-GRV invoice at a later date. 
 

Along similar lines, the return of goods to a vendor can be recorded in one of three ways: 
 

 ·        In the Returns to Vendor form. 
 

 ·        As line items in a GRV (using negative quantities). 
 

 ·        As line items in a vendor invoice (using negative quantities). 
 
## Notes:

 

 ·        This wizard does not discuss the receipt and return of goods in a vendor invoice. For information on this topic, see the Purchase Invoices Wizard . 
 

 ·        If you are working with the Fashion module and you need to itemize a receipt or return document manually, run the Fashion Wizard to learn how to record style assortments.
