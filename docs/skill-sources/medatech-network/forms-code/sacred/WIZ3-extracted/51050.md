# Work Orders Wizard

 

Work orders are used to document and track the production of a specific quantity of a processed part. Each work order contains data regarding the quantity of parts to be produced, the child parts required, the work order's routing and its progress. 
 
## Stages of work order management in Priority :

 

 1 . Opening a work order: Work orders can be opened automatically (using Production Planning or MRP for Manufacturers ) or manually. Programs are also available by Direct Activation to facilitate the opening of work orders involving byproducts and to open work orders based on a sales order item. 
 

 2 . Releasing the work order: Before production can begin, the work order must be released (i.e., authorized for execution). Once it is released, you can issue the required materials to the plant floor and report the execution of production operations. Release of the work order is automatically considered the first operation in the routing. 
 

 3 . Planning the kit list: Once the work order has been released, the system automatically compiles the kit list, a list of the parts and their quantities required to execute the work order, according to the BOM of the part being produced. You can revise this list for a specific work order, if necessary. 
 

 4 . Reviewing the work order routing: Release of the work order also causes the system to automatically record the operations in its routing. You can revise the operations in the routing for a specific work order, if necessary.
