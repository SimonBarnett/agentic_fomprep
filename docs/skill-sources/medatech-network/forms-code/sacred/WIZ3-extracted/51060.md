# Issues Wizard

 

This wizard deals with the transfer of raw materials or other parts required for production to the plant floor. 
 

 Priority supports several types of issues: 
 

 ·        Bulk issues 
 

 ·        Issues to kits 
 

 ·        Manual issues 
 

 ·        Issue of supplies 
 

The type to use depends mainly on the part to be issued and its role in the production of the parent part.
