# Production Report Wizard

 

Production reports record the execution of an operation on a specific quantity of processed parts, usually for a particular work order. 
 

For each production report, the Backflush program creates three automatic inventory transactions: 
 

 ·        Removes inventory of any child parts used in the operation 
 

 ·        Adds to inventory the quantity of the part produced in the reported operation (with the corresponding reduction of parent parts in the previous operation) 
 

 ·        Transfers a finished part to the appropriate warehouse (if applicable). 
 

If you need to rework any parts, you flag the operation as rework, thereby preventing an additional reduction of child parts. 
 

If it is important to document the exact child parts taken from inventory for an operation on the parent, you can record this as a manual issue in the production report. If a certain manufactured part is issued raw materials in bulk from another plant floor, you can assign the part a child-part warehouse (in the Backflush From Other Floors sub-level of the Warehouses form); consequently, Backflush will reduce its child parts from that warehouse. Other types of issues are recorded elsewhere in the system. For more information, run the Backflush Wizard and the Issues Wizard .
