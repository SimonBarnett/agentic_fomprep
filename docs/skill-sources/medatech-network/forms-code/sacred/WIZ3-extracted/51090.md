# Backflush Wizard

 

Backflush is the mechanism by which the inventory balances in plant floor warehouses are updated. Unlike regular warehouses, in which inventory balances are updated online, immediately following the recording of inventory transactions, it is not possible to achieve precise data for parts on the plant floor until the full Backflush program is run. Nonetheless, it is possible to set a constant that allows a simplified Backflush to calculate running estimates of plant-floor inventory. 
 

The Backflush program performs floor inventory updates in two major steps: 
 

 ·        It records automatic inventory transactions resulting from production reports and inventory transactions involving subcontractors . 
 

 ·        It calculates floor inventory balances on the basis of all inventory transactions involving floor warehouses (including automatic transactions recorded by the program itself). 
 

When discrepancies are discovered in floor inventory balances, the program records them as missing issues or as negative inventory . This wizard suggests a variety of ways to resolve both problems. 
 

 Note: The Backflush is sometimes activated from within other programs. For instance, both the Prepare Issues to Floor Stock program and MRP (when run with the option of calculating floor inventory) run the Backflush to update floor inventory, although they do not warn of missing issues and negative inventory.
