# Material Requirements Planning (MRP) for Manufacturers Wizard

 

 MRP for Manufacturers calculates the demand generated by sales, plans work orders and calculates the quantities of materials required for production. These materials can be purchased items, or they can be manufactured items for which separate work orders must be planned. When running the MRP program, you can choose to run Purchase Planning as well. 
 

When properly set up, MRP opens unreleased work orders, as dictated by the planning results, and creates a detailed work plan according to the parameters defined for the various production operations.
