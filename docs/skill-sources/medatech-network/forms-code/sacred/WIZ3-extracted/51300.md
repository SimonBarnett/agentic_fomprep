# Shipping Expenses Wizard

 

When purchasing parts, there are often added expenses beyond the cost of the part, for services such as shipping, storage and, for dual-currency users, customs or import duties. Accurate calculation of a part's cost must include the distribution of additional expenses among the purchased parts. 
 

 Priority provides several methods of distributing expenses, which enable you to handle a variety of billing scenarios: 
 

 ·        Recording expenses as line items in the purchase invoice – this method is useful when the vendor bills you for parts and expenses in the same invoice. 
 

 ·        Linking an invoice for additional expenses to a single purchase invoice – this method is useful when a vendor bills you separately for expenses incurred by parts for which you have already been billed in a previous invoice. 
 

 ·        Recording a shipping voucher – this method is useful in more complex scenarios, such as when you want to distribute expenses from multiple invoices among parts billed in more than one invoice. 
 

 ·        Dual-currency users only: Using a release form in conjunction with a shipping voucher to distribute shipping costs and import duties among goods stored in a bonded warehouse . 
 

In addition to documenting actual expenses, you need to define standard shipping costs: an estimated percentage of the part's purchase price for each relevant shipping type (air, land, sea). These costs can be defined per part or per vendor and part. They are taken into account during standard costing, and serve as default values for actual costing when no other data is available.
