# Customer Receipts Wizard

 

 Priority enables you to document payments received from customers, and link these payments to invoices by recording customer receipts . Receipts are linked to the invoices whose payment they record. Furthermore, when several receipts record payments for the same invoice, you can link them all to the invoice, thus enabling you to document partial payments. You can also record receipts that are not linked to any invoice or order. 
 

The receipt documents the amount of payment, the payment means (e.g., cash, check, bank transfer) and the payment terms awarded to the customer. 
 

Authorization and finalization of a receipt automatically generates a journal entry, which credits the customer`s account. The system automatically reconciles the debit entry, created by the original invoice(s), with the credit entry, created by the receipt. The same reconciliation number appears for all of these entries in the customer`s account. 
 
## Notes: 

 

 ·        If you work on a cash basis, you can prepare receipts on the basis of pro forma invoices. For more information, run the Cash-Based Accounting Wizard . 
 

 ·        You can also reconcile receipts and invoices retroactively, in the receipt`s journal entry. For more information, run the Account Reconciliation Wizard . 
 

 ·        You can also issue over-the-counter invoices, which debit the customer (and update the inventory) as well as document receipt of payment. For more information, see the Customer Invoices Wizard .
