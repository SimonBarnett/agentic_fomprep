# Sales Order Wizard

 

 Priority enables you to open a sales order on the basis of: 
 

 ·        One or more price quotes 
 

 ·        A blanket sales order 
 

 ·        A specific price list 
 

 ·        One or more product bundles 
 

 ·        Defined customer prices (standard order) 
 
## Notes:

 

 ·        If you are working with consignment warehouses, run the Consignments Wizard to learn how sales orders are recorded to and from consignment warehouses. 
 

 ·        If you are working with the Fashion module, run the Fashion Wizard to learn how sales orders are recorded for style assortments. 
 

 ·        To open a sales order from a sales opportunity, run the CRM Wizard .
