# Packing Slip Wizard

 

Goods may be packed and set aside prior to their shipment. When you record a packing slip in a customer's name, the goods involved will be reserved for that customer. Consequently, when a shipment is recorded, the packed goods will be the first inventory included. Alternatively, you can pack goods for stock, without specifying a customer. Furthermore, you can include several crates, each with its own packing slip, in a main packing crate, and attach to it a principal packing slip. 
 
## Notes:

 

 ·        Click to view the effects of packing on inventory. 
 

 ·        In addition to a simple shipment of packed goods, you can create a bill of lading. This is made up of a number of packed crates, each with its own packing slip, that are shipped together. For details, see the Customer Shipment/Return Wizard and Customer Invoices Wizard . 
 

 ·        You can also ship packed goods to another warehouse (e.g., to fill a branch order). See the Warehouse Transfers Wizard for details. 
 

 ·        If you are working with the Fashion module and you need to itemize a packing slip manually, run the Fashion Wizard to learn how to record style assortments.
