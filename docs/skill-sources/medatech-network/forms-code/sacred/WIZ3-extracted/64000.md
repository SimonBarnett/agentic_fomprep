# Warehouse Transfers Wizard

 

Use the Warehouse Transfer form to record movement of inventory from one warehouse to another or from one bin to another. 
 

Also use it to fill internal orders of stock from branches of your own company (e.g., so that they can use the transferred goods to fill sales orders). 
 

The transfer document automatically reduces the balance in the warehouse (and/or bin) from which the goods are transferred, and increases the balance in the warehouse (and/or bin) that receives them. 
 
## Notes:

 

 ·        If you use warehouse transfers to fill internal branch orders, make sure branches have been properly set up. See the Branches Wizard for details. 
 

 ·        If you are working with the Fashion module, run the Fashion Wizard to learn how warehouse transfers are recorded for style assortments. 
 

 ·        Do not use warehouse transfers to record issues to the plant floor. To deal with issues, run the Issues Wizard . 
 

 ·        It is usually unnecessary to record the transfer of finished products from the plant floor to a warehouse, as this is generally defined during the production process.
