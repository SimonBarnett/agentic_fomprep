# Opening a User Wizard

 

In order to allow your employees access to Priority , you need to assign them user names and passwords. There are three methods you can use to define new users: 
 

 ·        If you run Priority on SQL Server , you can synchronize Priority with the Windows Active Directory, so that user records and personnel files are created automatically when new users first enter the system. 
 

 ·        If you do not work with Windows Active Directory, your system manager can load employee and user data from external sources into Priority . For further information on loading data from external sources, see the Data Migration Wizard . 
 

 ·        You can run a program that simultaneously opens a new user name and personnel file for a new employee. 
 

 ·        You can open a user record manually, independently of the personnel file. This is useful if the human resources manager has opened a personnel file in the absence of the system manager, or when defining a fictitious user to serve as a privilege group leader.
