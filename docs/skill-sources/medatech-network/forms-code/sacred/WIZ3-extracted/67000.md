# Costing for Manufacturers Wizard

 

 Priority 's Costing Analysis for Manufacturers module enables you to calculate and analyze part costs, production and transaction costs and inventory valuations for manufactured parts. By contrast, the Costing for Businesses module only calculates the costs of warehouse assemblies (materials and labor). 
 

There are two ways to calculate costs: for the date on which past balances were last calculated and for the current date. 
 

Costing for a past balance date calculates costs on the selected past balance date, based on all inventory transactions recorded in the system and all work orders closed since the previous past balance. The values for that past balance period remain in the system, allowing you to maintain a history of part costs. 
 

Costing for the current date calculates cost on the day the program is run, based on all inventory transactions recorded in the system and all work orders closed between the last past balance and the current date. Running this program ensures that programs using costing data will have access to the most up-to-date figures (for example, costing data are used to calculate sales order profitability and project costs). Each time you run costing for the current date, costs are recalculated according to the most recent data, and overwrite the program's previous results.
