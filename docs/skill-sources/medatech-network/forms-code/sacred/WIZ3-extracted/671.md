# Open a Warehouse Wizard

 

 Priority provides three predefined warehouses : Plant Floor, Main (Factory Warehouse) and Warehouse Outlet. 
 

In addition to these, you can define as many warehouses as you need. In deciding whether you need to define additional warehouses, the main thing to consider is that transferring a part from one warehouse to another requires documentation. 
 

You can also subdivide any warehouse (except on the plant floor) into bins. However, you should only maintain bins if you intend to fully document the transfer of parts from one bin to another. 
 

You can also define new warehouses for special purposes, such as: 
 

 ·        a sales warehouse 
 

 ·        a holding warehouse 
 

 ·        a kit warehouse 
 

 ·        an issuing warehouse 
 

 ·        a consignment/loan warehouse 
 

 ·        a vendor consignment warehouse 
 

 ·        a transit warehouse 
 

 ·        a fashion outlet or franchise warehouse 
 

 ·        a repairs warehouse 
 

 ·        a project warehouse 
 

 ·        a warehouse for each subcontractor 
 

 ·        a bonded warehouse (for dual-currency users)
