# Companies Wizard

 

When the Priority system is installed, it automatically sets up a dummy company containing minimal data, for demonstration purposes. Your first action before you can record actual data in the system is to open a real company that will store this data. 
 

You can open as many companies as you wish, now and in the future. The available forms, reports and programs will be the same for all companies, but the data that is stored and displayed will be unique to each one. The system allows you to open a new company on the basis of an existing one, clear data from a given company (in order to start again) or delete from the database companies you no longer need. User privileges are assigned separately for each company. 
 

The ability to store data separately for several companies is particularly important in a multi-company business, but can also prove useful in small companies as well. For example, you can use this tool to create a simulated work environment, in which you can perform various experiments with the system without affecting your company's real data.
