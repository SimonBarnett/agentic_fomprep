# Delivery Scheduling Wizard

 

 Priority ' s Delivery Scheduling module organizes the delivery of goods to customers by efficiently scheduling delivery dates and distribution routes based on sales orders. You can utilize the automatic scheduling utility or schedule delivery manually. 
 

 Note: The scheduling facility opens shipping documents or sales invoices for each customer, to accompany the deliveries. It is therefore important to complete all setups for customer shipments and/or sales invoices before you begin to use the Delivery Scheduling module. For full details: 
 

 ·        Click to run the Customer Shipment/Return Wizard . 
 

 OR 
 

 ·        Click to run the Customer Invoices Wizard . 
 

In both cases, select the setup option.
