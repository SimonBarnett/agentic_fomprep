# Price Quotations Wizard

 

 Priority allows you to create and print out price quotations in a variety of formats, providing the precise level of detail required for each customer. A number of forms and programs are available to help you arrive at prices and analyze costs, compare prices with previous quotes, maintain versions of quotes and customize bills of materials for special requests. 
 

When recording a quote, you can calculate how much profit will be made on the sale. Or you can record your desired markup percentage and view a recommended price for each item.
