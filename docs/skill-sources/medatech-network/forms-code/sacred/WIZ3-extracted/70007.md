# Part Definition Wizard

 

 Priority provides several methods of defining new parts in the system, which can then be assigned to user-defined part families and linked to base products . In addition, you can use part specifications to classify parts into numerous categories and sub-categories for efficient retrieval. 
 

Using the Part Specs Work Area, you can use part specifications to compose new parts, creating composite catalogue numbers and part descriptions from the part's component specifications. 
 

Finally, you can create bills of materials for assembled and manufactured parts.
