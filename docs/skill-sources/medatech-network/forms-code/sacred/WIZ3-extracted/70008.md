# Aging Receivables Wizard

 

 Priority provides numerous reports that display different cross-sections of data pertaining to outstanding customer debt and the open transactions on which it is based. 
 

You can also load the aging data of specific customers into an Aging Work Area, where you can analyze it according to several parameters, access the customer or customer account, view customer credit data, as well as unbilled documents and project reports, and view recent billing tasks or open new ones for further handling of your customers. 
 
## What do you want to do?

 

 Exclude specific accounts from aging reports 
 

 Run aging reports 
 

 Use the Aging Work Area
