# Account Reconciliation Wizard

 

Account reconciliation is the process by which journal entries for the same account (e.g., a customer or vendor account; a prepaid expenses account) are reconciled with each other. Most entries in customer and vendor accounts are reconciled automatically when payments are made against invoices. Under certain conditions, customer invoices and receipts can be reconciled retroactively in the entry journal or chart of accounts. The remaining entries may be reconciled, automatically or manually, using the Reconciliation Worksheet. 
 
## Notes:

 

 ·        You can avoid inadvertent cancelation of large batches of final reconciliations by defining a maximum batch size in the CancelFinalRecons constant (in the Financial Constants form). 
 

 ·        In cash-based accounting, you can also use the Reconciliation Worksheet to reconcile pro forma entries. For more on pro forma entries, run the Cash-Based Accounting Wizard . 
 
## This wizard guides you through the following tasks:

 

 ·        Setting up the method of reconciling invoices with payments. Explanation. 
 

 ·        Reconciling customer invoices with receipts retroactively. Explanation. 
 

 ·        Using the Reconciliation Worksheet.
