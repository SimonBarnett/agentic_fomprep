# Reconciliation Codes Wizard

 

 Priority supports the reconciliation of account items by an automated multi-step process, represented by a reconciliation code . Two default reconciliation codes are provided by the system, one for bank reconciliation and one for account reconciliation , while an infinite number of custom reconciliation codes can be defined by the user. 
 

Reconciliation is carried out in a series of steps, each of which attempts to reconcile an increasingly narrow selection of unreconciled items by applying broader criteria than the previous ones. Each step employs one of a set of predefined reconciliation methods (e.g., match by amount, match by reference number) whose functional parameters (e.g., date range, permitted variance) are set specifically for the relevant step in the reconciliation process. 
 

Proper use of well-defined reconciliation codes minimizes the remainder of odd items that need to be reconciled manually.
