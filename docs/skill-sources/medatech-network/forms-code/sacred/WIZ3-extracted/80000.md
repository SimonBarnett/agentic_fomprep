# MRB Wizard

 

 Priority ' s MRB module is used to keep track of malfunctions that were detected during production and of malfunctioning parts in inventory. Example. It deals mainly with those malfunctions that are handled by a quality appointee and then sent to review boards. The quality appointee and\or the review boards are responsible for checking the malfunction and making a decision with regard to its solution and repair. Following the quality appointee/review board's decision, or in order to save the information regarding the malfunctioning part, the malfunction document is linked to inventory transactions involving the malfunctioning part. Example. The closing of this document ends the process of handling the malfunction. 
 
## What do you want to do?

 

 Set up the MRB module 
 

 Record a malfunction 
 

 Record the quality appointee ' s decision 
 

 Record the review board ' s handling of the malfunction 
 

 Link the malfunction document to inventory transactions 
 

 Close the malfunction document
