# Purchase Order Wizard

 

 Priority enables you to open a purchase order on the basis of: 
 

 ·        A price quote 
 

 ·        A purchase requisition 
 

 ·        A blanket purchase order 
 

 ·        A sales order 
 

 ·        Defined vendor prices (standard order) 
 
## Notes:

 

 ·        You can automatically prepare purchase orders for a project. For more information, see the Project Management Wizard . 
 

 ·        If you are working with the Fashion module, run the Fashion Wizard to learn how purchase orders are recorded for style assortments. 
 

 ·        You can also maintain versions of any purchase order.
