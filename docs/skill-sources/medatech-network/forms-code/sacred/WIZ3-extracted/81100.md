# Vendor Price Quotations Wizard

 

 Priority enables you to prepare requests for price quotations (RFQs) either manually or automatically, based on purchase requisitions (PRs), purchase demand documents or customer sales orders. 
 

Once a price quotation is received from a vendor, it is recorded into the system, either manually or based on the original RFQ. It is then possible to compare the prices offered by various vendors, and send a purchase order to the chosen vendor.
