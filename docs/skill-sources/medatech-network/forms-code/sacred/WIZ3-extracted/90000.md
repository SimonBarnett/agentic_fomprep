# To Do List and Calendar Appointments Wizard

 

 Priority provides a variety of ways to maintain control over business processes: 
 

 ·        a To Do List compiled from all transactions for which a given employee is responsible 
 

 ·        a current To Do Item for any given transaction, and a history of previous statuses and assigned users 
 

 ·        an interactive color-coded Calendar that allows you to keep track of and revise all appointments of any user or group, including scheduled service calls and all tasks whose start time differs from their end time 
 

 ·        concentration of all customer- and vendor-related tasks in the Tasks form 
 

 ·        the ability to generate business rules based on values recorded in a specific form 
 

 ·        BPM flow charts for each type of document that set up rules, properties and permitted sequences of statuses 
 

 ·        the capability to assign a status and a user to each transaction.
