# Prices and Discounts Wizard

 

 Priority allows you to define prices and discounts for every sold part. These default values are then used in sales documents (e.g., price quotes, orders), where they are applied according to a set hierarchy. They can be revised in each individual document, as necessary. 
 
## Prices

 

Price lists are the main tool for determining customer prices in Priority . There are several kinds: 
 

 ·        Base price list 
 

 ·        Customer price list 
 

 ·        Special price list 
 

 ·        Cost price list 
 

 ·        Retail price list 
 

You can maintain a history of customer price lists by creating new versions with different list dates (only one version is valid at any given time). In addition, each customer can be assigned several price lists, each for a different group of items and/or in a different currency. You can also create a price list for a representative customer , which then applies to all customers to which the representative is assigned, and another for the predefined general representative , which automatically applies to all customers, according to the price and discount hierarchy defined in the system. If you work with base products , you can automatically update the list price of all attached parts in the part catalogue, or in a specific price list version. 
 

In a buy-resell setting, Priority offers the option of using a vendor price list as a sales price source. In this case, a defined percentage is added to the preferred vendor's price, and this serves as the default sales price when no other prices are available in the system. Another option is to create a price list on the basis of a vendor price list (with a markup), and then assign it to a customer, just like any other customer price list. 
 

Aside from maintaining price lists, you can offer each customer special part prices which are valid for a limited period. 
 

 Priority also allows you to enforce a minimum price for every sold part. The minimum price appears automatically in sales documents recorded for the part (e.g., price quotes, orders), allowing you to ensure that the final part price does not deviate from this value.
