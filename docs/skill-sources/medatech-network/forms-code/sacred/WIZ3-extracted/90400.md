# Consignments Wizard

 

This wizard concerns the maintenance of remote warehouses that store company inventory on consignment, either for a single customer or for multiple end customers. It will help you define consignment warehouses, track and replenish inventory levels as needed and record inventory transactions involving consigned goods.
