# Open Personnel File Wizard

 

This wizard will assist you in recording personnel files for company employees in the first stages of working with the system. Only information that is vital for getting started with the system is covered here. For more extensive treatment of personnel files, run the Employee Wizard . 
 
## Notes:

 

 ·        Some personnel data is shared by all companies, some is specific to the current company and the rest is recorded/displayed in multi-company forms. 
 

 ·        If you do not work with Windows Active Directory, you can load employee and user data from external sources into Priority . The necessary setups and the actual load procedure can only be performed by the system manager. For further information on loading data from external sources, run the Data Migration Wizard .
