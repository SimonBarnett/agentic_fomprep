# Factory Modeling Wizard

 

The process by which a part is manufactured involves the following key elements: 
 

 ·        Bill of Materials: The list of components required to produce the part, their relative quantities and the average percentage of scrap. 
 

 ·        Operation: An action performed by a worker and/or a machine on a part. 
 

 ·        Work Cell: A location on the plant floor where a particular operation is performed. For greater efficiency, work cells are grouped into departments . 
 

 ·        Routing: The full series of operations required to produce a complete part. 
 

Factory modeling is the process by which these elements are defined and the system is configured to support each company's particular manufacturing methods.
