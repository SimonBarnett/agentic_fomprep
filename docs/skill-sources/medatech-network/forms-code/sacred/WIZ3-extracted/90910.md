# Subsidiaries Wizard

 

 Priority 's subsidiaries feature provides a solution for companies whose various divisions function as independent companies vis-a-vis the tax authorities. Each subsidiary maintains its own ledger, against a common Priority company shared by all subsidiaries. 
 

After defining the main company and its subsidiaries, you can use several methods to open GL, A/R and A/P accounts for each subsidiary. 
 

Transactions are linked to subsidiaries via branch offices. Sales, purchasing and financial documents recorded for customers or vendors that have been linked to a specific branch are printed with the subsidiary's logo and contact information. Financial transactions are recorded against the accounts of the subsidiary linked to that branch. 
 

When the same journal entry is recorded for accounts in different subsidiaries, predefined transfer accounts can be used to automatically balance each subsidiary's ledger.
