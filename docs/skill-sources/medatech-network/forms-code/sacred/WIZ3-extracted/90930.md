# Data Migration Wizard

 

The Data Migration module allows you to import data from external systems into Priority . The data are first loaded into an intermediary work area called the interim table , where they can be adjusted and errors can be corrected, before they are transferred to the actual system database. 
 

Before migrating all of your data from your previous system into Priority , perform the process described in this wizard with a small sample of data, in order to learn the process and identify potential difficulties. 
 
## Notes:

 

 ·        When loading data into Priority for the first time, it is recommended to proceed according to the order of topics displayed in the Data Migration menu. Loading your data in the proper order ensures that each round of data is integrated smoothly with the data from previous rounds. 
 

 ·        Reloading the database from the same interim table is liable to overwrite data already loaded into the system, and should therefore be executed with caution.
