# Data Authorization Wizard

 

If you choose to use the Data Authorization mechanism, you can: 
 

 ·        hide secured accounts (GL, A/R and A/P), as well as customer and vendor information, from all but a select group of users 
 

 ·        restrict the documents that users can access, based on the branch in which they were recorded, the allocated budget, the sales opportunity type, and/or the sales rep who performed the transaction. 
 

 ·        restrict employee access to payroll data to those payroll groups for which the employee is authorized. 
 

There are several types of data authorizations: 
 

 ·        Secured Accounts 
 

 ·        Secured Customers 
 

 ·        Secured Vendors 
 

 ·        Branches 
 

 ·        Budgets 
 

 ·        Sales Opportunity Types 
 

 ·        Sales Reps 
 

 ·        Subsidiaries 
 

 ·        Payroll Groups 
 

 ·        Projects 
 

You can activate any of the above types – separately or in combination with others. To activate data authorization for secured accounts, customers or vendors, all you need to do is begin defining these records as secured. A special program allows you to activate the mechanism for all other types of data, or to disable the mechanism (for each type of data authorization). 
 
## Note:

 

Secured data is nonetheless available to all users in BI reports and in the forms displaying monthly data in the Executive Reports menu. You should therefore ensure that privileges are carefully assigned to these reports and forms in all their respective menu trees.
