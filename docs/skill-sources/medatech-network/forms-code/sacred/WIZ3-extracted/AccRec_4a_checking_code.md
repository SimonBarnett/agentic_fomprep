# Checking the Reconciliation Code

 

The first time you reconcile entries within a specific account, make sure that you are satisfied with the reconciliation code used. If not, cancel all reconcilations and do one of the following: 
 

 Redo the reconciliation, using a different reconciliation code , OR 
 

 Revise the default reconciliation code , OR 
 

 Create a new code .
