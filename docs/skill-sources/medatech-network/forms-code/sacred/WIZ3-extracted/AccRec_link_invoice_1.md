# Setting Up the Method of Reconciling Invoices With Payments

 

 Priority supports three methods of reconciling invoices with the payments made against them: 
 

 ·        Reconcile by “First Invoice First” – reconciliations are handled within each account ledger. Explanation. 
 

 ·        Reconcile “By Invoice” – full tracking of partial payments. Explanation. 
 

 ·        Reconcile “By Order” – for walk-in customers. Explanation. 
 

After designating a default reconciliation method, you can assign a specific reconciliation method to particular customers (e.g., walk-in customers), which overrides the general default.
