# To work in the entry journal:

 

 1 .  From the Journal Entry No. column, zoom (press F6 ) to the Entry Journal form. This form details the journal entry recorded for the receipt. 
 

 2 .  Enter the Amounts for Reconciliation sub-level form to access the reconciliation data. This form displays all amounts to be reconciled. Explanation . 
 

 3 .  Move to the line for the receipt amount you wish to reconcile.
