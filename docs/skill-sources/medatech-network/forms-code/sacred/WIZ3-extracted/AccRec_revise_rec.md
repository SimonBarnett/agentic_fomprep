# Revising the Reconciliation Data

 

For any given invoice or receipt entry, you can continue to work with unreconciled entry amounts as needed. Example . 
 

You can also undo any changes in reconciliation data that you performed earlier. For any entry amounts that have already been reconciled, you must first undo the reconciliation. You can then undo the previous reconciliation update, restoring data to their former state. 
 
## To undo the reconciliation:

 

 1 .  Enter the Entry Journal form and retrieve the desired entry. 
 

 2 .  Enter the Amounts for Reconciliation sub-level form. 
 

 3 .  Move to one of the entry amounts that was reconciled during the last reconciliation update and select Cancel Reconciliation of Amount from the list of Direct Activation s . 
 

 4 .  Repeat the previous step for all entry amounts that were reconciled during the last reconciliation update.
 Tip: If you are unsure, do so for all entry amounts. Alternatively, do so for any amounts you are sure were affected; you will be notified of any other reconciliations you need to undo by error message.
