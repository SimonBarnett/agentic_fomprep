# To undo the last reconciliation data update:

 

 1 .  Select Cancel Recon. Amount Update from the list of Direct Activation s . 
 

 2 .  Retrieve the line again, and make the necessary revisions. You can update the reconciled sums (flag invoices for payment and/or change amounts) or leave the screen, leaving the entry amount unreconciled.
 Note : If you are updating the reconciliation again, remember to select Update Reconciliation Amounts from the list of Direct Activation s when you are done.

Click to return to the main screen .
