# Viewing Reconciliation Data

 

 Priority provides a variety of reports that enable you to view fully reconciled account transactions, partially reconciled account transactions (e.g., customer invoices against which partial payment was received) and unreconciled transactions. 
 
## To view unreconciled transactions:

 

 ·        Run the Unreconciled Entries or Open Transactions as of Date report. The latter allows you to view unreconciled transactions up to a designated date. 
 
## To view partially reconciled transactions:

 

 ·        Run one of the reports in the Aging and Open Invoices sub-menu, accessible from either the Accounts Receivable Reports or Accounts Payable Reports menu.
 Note: Aging reports only display the unreconciled amount of each invoice. 
 

 To view fully reconciled transactions: 
 

 ·        Run the Final Reconciliations by Number or Final Reconciliations by Date report.
