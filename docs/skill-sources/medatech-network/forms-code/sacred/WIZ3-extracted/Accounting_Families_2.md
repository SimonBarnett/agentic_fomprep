# Defining Accounting Families

 

The predefined 00 accounting family is automatically assigned to all parts. 
 
## To create additional accounting families:

 

 1 .  Enter the Accounting Families form. 
 

 2 .  Fill in the Family and Family Description columns.
 Note to dual-currency users: If you are working in a language other than English and want to produce reports in English that include the accounting family, record an English name for each family in the Family Desc (Lang 2) column. 
 

 3 .  Record a Family Type , if desired.
 Tip: Click to define a new family type. 
 
## Notes:

 

 ·        Click to assign parts to the new family. 
 

 ·        Click to return to the main screen.
