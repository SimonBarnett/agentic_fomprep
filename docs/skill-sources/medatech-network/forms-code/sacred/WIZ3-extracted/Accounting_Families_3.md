# Assigning Parts to Accounting Families

 

All parts are automatically assigned to the predefined general accounting family ( 00 ). However, this can be changed as needed, per part or in a batch. 
 
## To assign one part to a family:

 

 1 .  Enter the Financial Parameters for Parts form. 
 

 2 .  Retrieve the desired part. 
 

 3 .  Click the General tab. In the Accounting Family column, choose the desired family. 
 
## To assign a batch of parts to a family:

 

 ·        Run the Add Parts to Accounting Family program. 
 
## Notes:

 

 ·        To delete a batch of parts from a part family, run the Remove Parts from Acc't Family program. 
 

 ·        Click to run the Set Up Default Accounts Wizard , which explains how to assign default accounts to accounting families. 
 

 ·        Click to return to the main screen.
