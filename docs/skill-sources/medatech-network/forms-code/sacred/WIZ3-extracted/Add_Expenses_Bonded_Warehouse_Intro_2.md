Shipping Expenses - Bonded Warehouse: Intro.2 
 
 
- 
 
 
 
## Note:

 

When working with a bonded warehouse, the customs invoice (which bills you for customs duties and related expenses) is not linked to the shipping voucher, but is dealt with later when releasing goods from the bonded warehouse. 
 

Imported goods may be released from the bonded warehouse in installments, each of which must be recorded in a Release from Bonded Warehouse document. Each release document is linked to the shipping voucher and customs invoice, by which it calculates the amount of customs duties and various expenses due for the recorded quantities of goods to be released. 
 

Consequently, if any changes are made to the shipping voucher after goods have been released from the bonded warehouse, you must recalculate the expenses for the released goods according to the new data. If costing was run after one or more release documents were recorded, you will need to run costing again after the voucher has been reopened and the expense burden recalculated for each release document; otherwise the new data will not be taken into account. 
 

Keep in mind that imported goods stored in a bonded warehouse are not subject to costing or inventory valuation. They are only considered to have entered inventory when they are released from the bonded warehouse.
