# Printing an Order of Goods Document

 

There are actually two different versions of the printed Release from Bonded Warehouse document, each represented by a different print format. The Order of Goods format displays the quantities of goods awaiting release from the bonded warehouse, as recorded in the Balance to Release or Crates to Release columns of the Released Items form. 
 
## To print an Order of Goods document:

 

 1 .  Enter the Release from Bonded Warehouse form and retrieve the desired release document. 
 

 2 .  Select Print Receipt from Bonded Warehs from the list of Direct Activations . 
 

 3 .  When the Print/Send Options dialogue box appears, select the Order of Goods format.
