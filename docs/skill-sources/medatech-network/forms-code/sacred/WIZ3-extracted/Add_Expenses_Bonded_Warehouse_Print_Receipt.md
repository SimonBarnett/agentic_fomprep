# Printing a Receipt of Goods Document

 

There are actually two different versions of the printed Release from Bonded Warehouse document, each represented by a different print format. The Receipt of Goods format displays the quantities of goods that were actually released, as recorded in the Quantity or Packed Crates (No.) columns of the Released Items form. 
 
## To print a Receipt of Goods document:

 

 1 .  Enter the Release from Bonded Warehouse form and retrieve the desired release document. 
 

 2 .  Select Print Receipt from Bonded Warehs from the list of Direct Activations . 
 

 3 .  When the Print/Send Options dialogue box appears, select the Receipt of Goods format.
