# To update the cost of goods released from the bonded warehouse:

 

 1 .  Enter the Release from Bonded Warehouse form. 
 

 2 .  Retrieve all release documents linked to the updated shipping voucher. 
 

 3 .  To reopen a release document with a Final status, click Reopen Document on the Direct Activation bar. 
 

 4 .  For each release document, enter the Released Items sub-level form. 
 

 5 .  For each item in the document, enter the Import Costs per Line Item sub-level form. 
 

 6 .  Flag the Recalculate column and refresh the screen ( Ctrl+F11 ). The new value appears in the General Import Costs column, and the Recalculate column is cleared for future use. 
 

 7 .  Change the Status of any documents you would like to finalize. 
 

 8 .  To print the document, select Print Receipt from Bonded Warehs from the list of Direct Activations . 
 

 9 .  If necessary (i.e., if costing was run before the new expenses were recorded), rerun the costing program.
 Tip: For assistance, run the Costing for Businesses Wizard or the Costing for Manufacturers Wizard .

Click to return to the bonded warehouse menu.
