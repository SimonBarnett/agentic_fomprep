# Receiving Imported Goods Into a Bonded Warehouse

 

Imported goods are assigned to a bonded warehouse in a shipping voucher. However, this is not an inventory transaction, and the parts still need to be recorded in a GRV (or vendor invoice). 
 
## To record the receipt of imported goods:

 

 1 .  Enter the Goods Receiving Vouchers form and record a regular GRV for the received shipment. 
 Tip: For assistance, run the Receipt/Return of Goods Wizard . 
 

 2 .  Specify the code of the bonded warehouse in the Receiving Warehouse column (in the General tab).
 Tip: Click if you have not yet defined the bonded warehouse . 
 

 3 .  If you have already received an invoice for the shipped goods, click the References tab and record the number of the vendor's invoice in the Vendor Invoice column. 
 
## Note:

 

In the event that the shipment and its invoice are received together, use the Vendor Invoices form instead, and specify the bonded warehouse in the Warehouse column (in the References tab).
