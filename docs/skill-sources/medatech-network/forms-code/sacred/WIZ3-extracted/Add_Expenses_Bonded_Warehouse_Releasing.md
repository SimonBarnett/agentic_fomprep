# Releasing Goods from a Bonded Warehouse

 

To release goods from the bonded warehouse, you need to open a Release from Bonded Warehouse document. This document, which links to both the shipping voucher and the customs invoice , automatically distributes the burden of customs duties and additional expenses among the released goods. 
 

You may open several release documents for the goods recorded in one shipping voucher, each for part of the goods stored in the bonded warehouse. In this case, customs and expenses are distributed proportionally to those goods that are to be released. It follows that the costing program takes the cost of the released goods from the release document, rather than calculating cost according to the shipping voucher. 
 

The Release from Bonded Warehouse document can be printed in two distinct formats: the Order of Goods document, which displays the balance of unreleased items, and the Receipt of Goods document, which displays the items that were actually released.
