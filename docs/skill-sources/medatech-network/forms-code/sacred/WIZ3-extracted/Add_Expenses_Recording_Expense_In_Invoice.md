# Recording Expenses Within a Purchase Invoice

 

Sometimes a purchase invoice received from a vendor contains one or more lines for expenses (e.g., shipment, storage), which need to be distributed among the purchased parts billed in the invoice. 
 

When this is the case, you record and finalize the purchase invoice in the usual manner. As long as the expense items are defined in the system (i.e., have been assigned a burden type), they will be distributed automatically among the costs of the rest of the billed parts when you run the costing program. 
 
## Notes:

 

 ·        Click to define an expense in the system. You can define a new expense item even after the invoice in which it is billed has been finalized. 
 

 ·        For assistance in recording a purchase invoice, run the Purchase Invoices Wizard .
