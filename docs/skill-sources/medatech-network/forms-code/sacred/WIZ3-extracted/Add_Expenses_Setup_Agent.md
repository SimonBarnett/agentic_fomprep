# Defining a Customs Agent

 

You can define a customs agent to issue invoices and handle payment of customs duties. In Priority , customs agents are defined as vendors. 
 

In order for customs agent contacts to appear by default in the shipping voucher, record them as vendor contacts and flag the Ship Voucher option. 
 

To open a vendor record and A/P account for a customs agent, run the Open Vendors Wizard .
