# To define a bonded warehouse:

 

 1 .  Enter the Warehouses form and define a new warehouse.
 Tip: For assistance in defining a warehouse, run the Open a Warehouse Wizard . 
 

 2 . In the General tab, set the Type to D. 
 

 3 . Flag the Bonded Warehouse column.
