# Defining a Checklist for Shipping Vouchers

 

 Priority enables you to define a checklist of shipping voucher tasks for each vendor. 
 
## To define a task checklist:

 

 1 . Enter the Vendors form. 
 

 2 . Enter the Shipping Voucher Checklist sub-level form. 
 

 3 . Record a Subject , Task Code , and Task Type for any tasks you wish to include in the checklist. 
 

 4 . Add details in the Remarks sub-level form, as desired.
