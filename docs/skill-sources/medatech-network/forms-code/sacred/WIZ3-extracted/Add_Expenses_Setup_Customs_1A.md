# Setting Up Customs Items 

 

Customs items are assigned to imported parts, so as to enable the system to estimate the customs duties due for part shipments from different countries (customs estimates are not, however, available when working with a bonded warehouse). 
 

Each item contains estimated customs rates for the three principal customs categories (North America, European Union, Rest of the World), beyond which you can assign separate rates to specific countries. Customs rates are defined as percentages of the part price. 
 

Customs items are used in the preparation of Intrastat reports. For more information, run the Taxes Wizard . 
 
## Before you begin:

 

 ·        Enter the Countries form and assign a Customs Category to each country in North America or the European Union with which you intend to do business. 
 
## To define a customs item:

 

 1 .  Enter the Itemized Customs Rates form. 
 

 2 .  Record the Customs Item number and a Description for the item. 
 Note : EU countries use a common list of predefined customs items to determine customs duties. 
 

 3 .  Specify the default customs rate for each category, as a percentage of part prices: 
 

 ·     For parts imported from the European Union, use the Customs % - EU column. 
 

 ·     For parts imported from North America, use the Customs % - NAFTA column. 
 

 ·     For parts imported from anywhere else in the world, use the Customs % - RoW column. 
 

 4 .  To record separate duties for specific countries, use the Special Customs Rates sub-level.
