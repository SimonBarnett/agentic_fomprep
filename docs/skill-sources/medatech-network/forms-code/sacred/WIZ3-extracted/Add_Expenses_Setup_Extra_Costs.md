# Setting the Rate for Extra Costs Incurred by Goods in a Bonded Warehouse

 

Goods stored in a bonded warehouse usually incur additional expenses (e.g., transportation costs, storage costs) that are not recorded in the shipping voucher. The system can calculate these expenses automatically, as a user-defined percentage of the value of the imported goods recorded in the customs manifest. 
 
## To set the rate for extra costs:

 

 ·        Run the Set Extra Import Costs (%) program, and specify the percentage of the part value that will be charged as extra expenses when goods are released from the bonded warehouse. This percentage will then be copied to the release documents of all imported parts, although you can revise the rate in each individual document. 
 
## Note:

 

The value of each imported part, as it appears in the customs manifest, is recorded manually in the release document.
