# Setting Up Expenses

 

In order to record an expense in an invoice, you need to define it as a non-inventory part. The manner in which such expenses are distributed among purchased parts is determined by their assigned burden type . The burden type is what distinguishes expense items from other types of parts. 
 

If you want certain expenses to be distributed among parts on the basis of their weight or volume, you need to define these parameters for the purchased parts in question. You can also determine whether shipping expenses are distributed among parts according to their buy/sell units or factory units. 
 

You should also define standard shipping costs (an estimated percentage of each part's purchase price). The costing program takes these percentages into account during standard costing, and uses them as defaults during actual costing when no expenses have been recorded by other means, or when the shipping voucher has not yet been closed. 
 

You can also define statuses for shipping vouchers and use them to indicate the progress of each voucher.
