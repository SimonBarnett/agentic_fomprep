Shipping Expenses - Setup: Intro.2 
 
 
- 
 
 
 

If you are using the dual-currency package, you need to define customs items and assign them to the parts you import. You also need to define the shipping company that acts as your customs agent, and set up a bonded warehouse, if necessary. In addition, you must define whether currency conversions in shipping vouchers are calculated according to the exchange rate on the invoice date, or on the date the goods enter inventory. 
 

If you work with bonded warehouses, you need to set up business processes (BPM) for the documents that record the release of goods from those warehouses – i.e., define statuses. You should also record the costs associated with the release of each item (in addition to its shipping costs and customs duties). These additional costs (e.g., transportation expenses, storage fees) are usually calculated as a fixed percentage of the part price.
