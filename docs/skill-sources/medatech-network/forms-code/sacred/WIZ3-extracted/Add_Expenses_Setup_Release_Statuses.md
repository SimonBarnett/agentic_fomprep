# Setting Up Business Processes for Release from Bonded Warehouse Documents

 

You set up business processes by defining statuses in a BPM flow chart. 
 

There are several predefined statuses for release documents, to which you can add as many statuses as you like. You can define paths between these statuses, create workflow rules and set status properties . 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Bonded Releases program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Release from Bonded form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
