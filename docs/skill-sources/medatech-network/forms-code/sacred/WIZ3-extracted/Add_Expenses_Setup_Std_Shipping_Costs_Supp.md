Shipping Expenses - Setup: Standard Shipping Costs for Vendor Parts 
 
 
- 
 
 
 
# To define standard shipping costs for parts purchased from a given vendor:

 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the desired vendor. 
 

 2 .  Enter the Shipping Costs per Part sub-level form and move to the desired part. 
 

 3 .  Record a standard Air Cost (%) , Sea Cost (%) and/or Land Cost (%) , as appropriate, as a percentage of the part's unit price. 
 

 4 .  Select the appropriate default cost type in the Shipping Cost Type column. This value will appear as the default for this part in any purchase document that you open, but may be revised. 
 

 Notes: 
 

 ·        The costing program will not take standard shipping costs into account unless the Shipping Cost Type column is filled in. 
 

 ·        If you want to define a different shipping cost type for a part purchased from a certain vendor, while using the standard costs that were defined for the part, just specify the Shipping Cost Type in this form and leave the remaining shipping cost columns empty.
