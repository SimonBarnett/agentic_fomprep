Shipping Expenses - Shipping Vouchers: Intro.2 
 
 
- 
 
 
 

If you receive additional invoices containing expense items (or incur additional expenses that need to be recorded manually) after the shipping voucher is closed, you need to reopen the voucher, add the new expenses and close it again. If the costing program was run after the voucher was closed, it will need to be run again after the voucher is updated and closed; otherwise, the new data will not be taken into account. 
 

 Important: The cancellation of an invoice does not automatically affect the shipping voucher – the invoice continues to be part of the voucher and included in costing calculations. To remove the invoice, either add the cancellation invoice to the voucher or delete the original invoice from it.
