# Closing a Shipping Voucher

 

As long as a shipping voucher remains open, the costing program will only take into account expense items included in the same invoice as the purchased parts, or else the defined standard shipping costs. Closing the voucher allows the costing program to distribute the actual shipping expenses. 
 

You cannot revise any details in a closed shipping voucher; in particular, you cannot add or remove purchase invoices or expense items. If you receive additional expense invoices after the voucher is closed, you will need to reopen it, add the new expense items, and close it again. If the costing program was run after the voucher was first closed, it will need to be run again after the voucher is updated and closed again; otherwise, the new data will not be taken into account. 
 
## To close a shipping voucher:

 

 1 .  Enter the Shipping Vouchers form and retrieve the desired voucher. 
 

 2 .  Select Close Shipping Voucher from the list of Direct Activations . The document status will change to a final status and the Closed column (in the References tab) will be flagged automatically.
