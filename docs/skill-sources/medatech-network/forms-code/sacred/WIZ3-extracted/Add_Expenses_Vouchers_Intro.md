# Working With Shipping Vouchers

 

Shipping vouchers are used to document and track incoming shipments and record the accompanying expenses. When you add invoices for purchased parts and invoices for shipping and other expenses to the same voucher, the costing program automatically distributes the expenses among the purchased parts, according to defined parameters. You can also add expenses to the voucher manually. Example. 
 

In the dual-currency package, vouchers provide an estimate of the customs duties to be paid for imported parts, according to the customs items assigned to those parts. This allows you to compare the estimated duties with the actual duties recorded in the invoice from the customs agent. 
 

The costing program only takes closed shipping vouchers into account; as long as a voucher remains open, costing will only take into account expense items included in the same invoice as the purchased parts, or else the defined standard shipping costs. Before closing a voucher, you can run a program that allows you to preview the distribution of shipping expenses in that voucher.
