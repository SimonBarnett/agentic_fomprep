# Manually Distributing an Expense Item

 

You can override an expense item's assigned burden type by manually defining the ratio by which it is to be distributed among the purchased parts in the shipping voucher. You can also target expenses to one or more specific invoices. 
 
## To manually distribute an expense item:

 

 1 .  Enter the Manual Distrib of Added Expenses sub-level of the Additional Expenses form (for actual expenses) or the Projected Expenses form (for projected expenses). Each purchased part in the shipping voucher appears in a separate line. 
 

 2 .  For each item, if you want a certain portion of the expenses to be added to a specific invoice, record the number of the Invoice in question. Examples. 
 

 3 .  For each item, fill in the Proportion of Burden column with a value representing the relative portion of the expense to be added to that purchased item. Example. 
 
## Notes:

 

 ·        You can record multiple lines for a single part, specifying a different invoice in each line. 
 

 ·        When the shipping voucher is closed, the expenses added to each purchased part include both the specified portion of each expense that is distributed to that part throughout the voucher and the specified portion of each expense that is assigned directly to a particular invoice. 
 
## To view the results of manual distribution:

 

 1 .  Return to the Shipping Vouchers form. 
 

 2 .  Select Calculate Expense Burdening from the list of Direct Activations . 
 

 3 .  Return to the Manual Distrib of Added Expenses form. The exact amount of the expense assigned to each part appears in the Expenses column.
