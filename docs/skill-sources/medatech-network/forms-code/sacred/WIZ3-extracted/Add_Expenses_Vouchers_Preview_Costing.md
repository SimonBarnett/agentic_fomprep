Shipping Expenses - Previewing Costing Results 
 
 
- 
 
 
 
# To preview costing results before closing the voucher:

 

 1 .  Run the Calculate Expense Burdening program. 
 

 2 .  Run the Shipping Expense Burden or Part Invoices in Ship Voucher report. 
 

 3 .  To view a comparison between the projected and actual burden on shipped parts, run the Projected/Actual Burden report. 
 

 4 .  If necessary, make adjustments to the voucher and run the program again, until you have achieved satisfactory results. 
 
## Tips:

 

 ·        If you have defined a status for vouchers that have been previewed, change the voucher status. 
 

 ·        Run this program after every major change to the shipping voucher.
