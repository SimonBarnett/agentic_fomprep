# Adjusting Variance in Multi-Currency Accounts (dual-currency users only)

 

For each entry recorded in a transaction currency that differs from the account currency, the system records a separate exchange rate adjustment. An additional adjustment entry is recorded to correct balances in the local and second currencies, based on the current balance in the account currency. 
 

 Note : 
 

Make sure that exchange rates have been updated before running the program. 
 
## To check for variance in multi-currency accounts:

 

 ·        Run the Adjustments to Multi-Curr Accts report.
