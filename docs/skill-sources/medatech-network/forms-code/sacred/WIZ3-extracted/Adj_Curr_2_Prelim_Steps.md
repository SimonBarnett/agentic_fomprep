# Defining Exchange Rate Adjustment Accounts

 

Before running the exchange rate adjustment programs, you need to flag the GL accounts to be affected and indicate the contra accounts against which adjustments are made. 
 
## To flag accounts that will be affected by exchange rate adjustments:

 

 1 .  Enter the Exch. Rate Adjustment Definition form. 
 

 2 .  Retrieve the desired accounts. 
 

 3.  For each account that will be affected, flag the Make Exch Adjstmnts column.
