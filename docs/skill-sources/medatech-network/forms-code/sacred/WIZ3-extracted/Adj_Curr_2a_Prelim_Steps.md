# To define a contra account for each account:

 

 1 .  Enter the Exch. Rate Adjustment Definition form. 
 

 2 .  Retrieve the accounts for which you want to assign a specific contra account. 
 

 3.  Record the number of each contra account in the Adjustment Account column. 
 
## Notes:

 

 ·        To set up a new account, use the Chart of Accounts form. For help, run the Open GL Accounts Wizard . 
 

 ·        The same contra account can be assigned to several different accounts. 
 

 ·        Click to return to the main screen.
