# Defining Contra Accounts

 

When an adjustment is made that corrects for changes in exchange rates, an adjustment entry is recorded in the journal for the account and the defined contra account. If a specific contra account has not been defined, an entry will be recorded in a general contra account. 
 

If the Initializing Accounts program was run, a general contra account has already been defined. 
 

Click to define a different contra account for each account . 
 
## To define a general contra account manually:

 

 1 .  Enter the Default Accounts form. 
 

 2 .  Move to the “Exchange Rate Adjustments” line. 
 

 3.  In the Account No . column, record the number of the account to be used as a general contra account.
