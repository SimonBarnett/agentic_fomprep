# Adjusting Variance in Local-Currency Accounts (dual-currency users only)

 

When a journal entry is created to adjust the variance in a local-currency account, its second-currency balance is adjusted automatically according to the specified exchange rate. 
 

 Note : 
 

Make sure that exchange rates have been updated before running the program. 
 
## To check for variance in local-currency accounts:

 

 ·        Run the Adjustments to Local-Curr Accts report. 
 

Record the exchange rate between local and second currencies with which to calculate the variances. This should be the rate in effect on the date for which you plan to create the adjustment entry. 
 

 Tip : 
 

Leave the column blank to use the rate in effect at the end of the previous fiscal period.
