# Adjusting Variance in Foreign-Currency Accounts

 

When a journal entry is created to adjust the variance in a foreign-currency account, its local-currency balance (and second-currency balance for dual-currency users) are adjusted automatically, according to the specified exchange rates for the foreign currency.
 Note : 
 

Make sure that exchange rates have been updated before running the program. 
 
## To check for variance in foreign-currency accounts:

 

 1 .  Run the Adjustments to Foreign Accounts report for a given account currency. 
 Note: Rerun the report for each foreign currency. 
 

 2.  Record the exchange rate between the local currency and this account currency with which to calculate the variances. This should be the rate in effect on the date for which you plan to create the adjustment entry. 
 Tip: Leave the column blank to use the rate in effect at the end of the previous fiscal period.
