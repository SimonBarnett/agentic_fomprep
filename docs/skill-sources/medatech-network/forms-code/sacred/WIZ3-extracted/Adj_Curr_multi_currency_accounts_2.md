# To correct for variance in all multi-currency accounts:

 

 ·        Run the Record Adjs for Multi-Curr Accts program. 
 
## Notes:

 

 ·        The variance will only be corrected when the journal entries created by the program are posted. If you choose not to automatically post those entries, do not rerun the program before posting or deleting them. If the entries were not posted, then the original variance still exists and rerunning the program will create duplicate entries. 
 

 ·        To view the journal entries that were created, enter the Entry Journal form, retrieve records by the date for which the Record Adjs for Multi-Curr Accts program was run (today's date or the last date in the previous fiscal period), and look for transaction types of EXC . 
 

 ·        For technical reasons, a value of –1 will appear in the Acct Reconcil. No. column for the entry item after you run the Record Adjs for Multi-Curr Accts program. This value does not represent an actual reconciliation number assigned to the entry item. 
 

 ·        Click to return to the main screen.
