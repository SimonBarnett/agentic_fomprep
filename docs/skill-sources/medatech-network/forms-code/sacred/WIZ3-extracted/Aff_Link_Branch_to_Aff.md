# Linking a Branch to a Subsidiary

 

Each subsidiary is usually associated with one or more company branches. Consequently, the subsidiary for which a transaction document is being recorded is determined by specifying the appropriate branch. You first need to link each branch to its subsidiary. 
 
## To link a branch to a subsidiary:

 

 1 .  Enter the Branches form and retrieve the desired branch. 
 

 2 .  Click the Financial Data tab and specify the Subsidiary to which to link the branch. 
 
## Notes:

 

 ·        In transaction documents, the customer's or vendor's default branch appears automatically. If no default branch was defined, the document is assigned the branch defined for the user who opened it. For more information, run the Branches Wizard .
