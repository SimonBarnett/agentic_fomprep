## To define the transfer account for each subsidiary:

 

 1 .  Enter the Subsidiaries form. 
 

 2 .  For each subsidiary, designate a Transfer Account . 
 
## To flag an entry code for multiple subsidiaries:

 

 1 .  Enter the Journal Entry Codes form. 
 

 2 .  Move to the desired entry code (or create a new one), and flag the Auto Balance Affils column.
 Tip: To create new entry codes, run the Set Up Entry Codes Wizard . 
 
## Notes:

 

 ·        In the case of a payment or receipt involving multiple invoices, it is also necessary to flag the Copy to J. Entry column of the receipt/payment so that each invoice amount appears on a separate line in the journal entry. 
 

 ·        Click to return to the main screen.
