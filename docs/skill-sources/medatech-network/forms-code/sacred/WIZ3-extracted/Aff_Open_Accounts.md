# Opening GL Accounts for Subsidiaries

 

In order to record transactions for subsidiaries within a single database, it is necessary to open separate sets of accounts for each subsidiary. Accounts that are unique to each subsidiary (e.g., bank accounts, cashiers) are opened manually, whereas sets of accounts (e.g., income accounts, expense accounts, tax accounts) can be opened automatically.
