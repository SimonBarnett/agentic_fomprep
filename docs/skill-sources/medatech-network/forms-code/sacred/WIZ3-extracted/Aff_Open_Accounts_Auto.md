# Copying GL Accounts Automatically

 
## Before you begin:

 

 1 .  Enter the Subsidiaries form and retrieve the subsidiaries for which you are opening GL accounts. 
 

 2 .  Click the Account Defs tab and make sure that a prefix and/or suffix was defined for the subsidiaries in question.
 Note: Where accounts are maintained in more than one subsidiary for the same customer or vendor (i.e., when the IdentCustAcc constant is set at 2 ), the prefix/suffix is used to identify the subsidiary to which each account belongs. 
 
## To copy accounts to a subsidiary:

 

 ·        Run the Open Subsidiary Accounts program. In the form that opens, retrieve the main company accounts you want to copy, then exit the form. The new accounts will have the same numbers as the original accounts, with the addition of the prefix or suffix defined for the subsidiary to which they are being copied. 
 
## Notes:

 

 ·        You can also open duplicate GL accounts for subsidiaries manually (in the Chart of Accounts form), if necessary. In this case, specify both the Subsidiary Code and the original Account in Main Company . 
 

 ·        Click to set up journal entry codes for transactions that involve more than one subsidiary .
