# To open a subsidiary:

 

 1 .  Enter the Subsidiaries form. 
 

 2 .  Record a Subsidiary Code and Subsidiary Name . 
 Note to dual-currency users: If you are working in a language other than English and want to produce reports in English that include the subsidiary name, record an English name for each subsidiary in the Name (Lang 2) column. 
 

 3 .  Click the Account Defs tab, and designate an Account Prefix and/or Account Suffix . 
 Note: The prefix/suffix identifies the subsidiary to which each account belongs, when main company accounts are copied to subsidiaries. 
 

 4 .  Click the Address and Phone tab and fill in the subsidiary's contact info, which will appear in documents printed for the subsidiary.
