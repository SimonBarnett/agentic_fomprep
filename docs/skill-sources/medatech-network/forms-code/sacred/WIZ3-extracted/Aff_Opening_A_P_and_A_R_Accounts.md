# Opening A/R and A/P Accounts for Subsidiaries

 

The method you use to create A/R and A/P accounts depends on the way in which you intend to work with vendors and customers. After choosing the desired method, you need to set up the system by assigning the appropriate value to a financial constant. 
 
## What do you want to do?

 

 Assign each customer and vendor to a specific subsidiary 
 

 Open accounts for customers and vendors in multiple subsidiaries
