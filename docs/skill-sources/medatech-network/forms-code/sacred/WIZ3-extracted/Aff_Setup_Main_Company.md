# Setting Up the Main Company

 

Before opening subsidiaries, you need to define the main company to which they are attached. This company is called the Main Subsidiary . 
 
## To record the main subsidiary:

 

 1 .  Enter the Subsidiaries form. 
 

 2 .  Leave the default Subsidiary Code of 000 and record a Subsidiary Name . 
 

 3 .  Make sure the Main Subsidiary column is flagged. Your company's existing GL, A/R and A/P accounts will now be linked to the main subsidiary. 
 

 4 .  Click the Address and Phone tab and fill in the necessary contact info. These values will appear in documents printed for the main subsidiary.
 Tip: You can copy most of these columns from the Company Data form.
