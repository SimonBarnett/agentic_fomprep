# Aging Reports

 

The Aging and Open Invoices menu contains reports on outstanding customer debt (per customer or per invoice), open transactions and restricted customers. 
 

It is advisable to reconcile your customer accounts before you run any of these reports, as unreconciled receipts are not taken into account when calculating customer debt. 
 
## Which kind of report do you want to run?

 

 Aging per customer 
 

 Detailed aging (per invoice) 
 

 Consolidated aging 
 

 Open transactions 
 

 Restricted customers
