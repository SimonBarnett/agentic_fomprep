# Customer Aging Reports

 
## Daily Aged Receivables 

 

Run this report to display the amount owing from individual customers on a daily basis, together with the number of days payment is overdue. 
 
## Weekly Aged Receivables 

 

Run this report to display the amount owing from individual customers on a weekly basis, together with the number of days payment is overdue. 
 
## Monthly Aging by Account 

 

Run this report to view the amounts owed by individual customers per month, based on due dates. 
 
## Aging by 30-Day Period 

 

Run this report to display the amount owed by individual customers per 30-day aging period (i.e., current debt, 1-30 days, 31-60 days, 61-90, and 90+), starting from a designated date. 
 
## Monthly Aging by Trial Bal. Item 

 

Run this report to display the amount owed, per month, by a group of related customer accounts (that appear on the same line in trial balance reports). 
 
## Aging by Period-Billing Followup 

 

Run this report to display the amount owed by individual customers per 30-day aging period (i.e., current debt, 1-30 days, 31-60 days, 61-90, and 90+), sorted by the employee responsible for billing. 
 
## Outstand Debts-Bill Follow (No.) 

 

Run this report to display outstanding customer debts for specified billing contacts, broken down by invoice and sorted by A/R account number (usually the customer number). 
 
## Outstand Debts-Bill Follow(Desc) 

 

Run this report to display outstanding customer debts for specified billing contacts, broken down by invoice and sorted by A/R account description (usually the customer name).
