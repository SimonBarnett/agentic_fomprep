# Multi-Company Aging Reports

 

These reports will include those companies that have been selected in the Define Multiple Companies dialog box (accessed via the upper File menu). If no companies have been selected, reports are limited to those companies flagged as Multi-company in the Companies form. 
 
## Consolidated Monthly Aging 

 

Run this report to display the monthly amounts owed by individual customers in all companies. 
 
## Consolidated Aging by Invoice 

 

Run this report to display the details of outstanding invoices recorded in all companies, as well as early payments (identified by a minus sign).
