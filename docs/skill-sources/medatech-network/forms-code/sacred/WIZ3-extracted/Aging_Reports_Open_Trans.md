# Open Transactions

 
## Open Trans.- Monthly Summaries 

 

Run this report to view monthly summaries of specified A/R accounts (for example, for each of the previous four months). For each month, the report displays the total owed by the customer on open invoices dated in that month. 
 
## Open Transacts as of Date-Detail 

 

Run this report to display all invoices that have not been paid as of a designated date.
