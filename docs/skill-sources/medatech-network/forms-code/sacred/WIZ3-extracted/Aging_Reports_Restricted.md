# Restricted Customers

 

Run the Restricted Customers report to display the list of restricted customers, the date of their restrictions, whether they are full restrictions or warnings, and the balance of their A/R accounts. 
 
## Notes:

 

 ·        On how to impose and lift restrictions, run the Restricting Customers Wizard . 
 

 ·        Click to return to the main screen.
