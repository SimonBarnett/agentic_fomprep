# The Aging Work Area

 

In the Aging Work Area, you can view outstanding customer debts in 30-day periods, view customer credit data and ledger transactions, as well as unbilled documents and project reports, and view recent billing tasks or open new ones. 
 

You can also view customer receipts, multi-shipment invoices and journal entries, or record new ones, by selecting the appropriate form from the list of Direct Activations. 
 

It is advisable to reconcile your customer accounts before loading data into the work area, as receipts that have not been linked to invoices are not taken into account. 
 
## To use the work area:

 

 1 .  Run the Load Aging Work Area program. 
 

 2 .  Enter the Aging Work Area form. 
 

 3 .  Click any column title to sort the displayed data according to the values in that column. 
 

 4 .  Use the sub-level forms to view the customer's total credit status, ledger transactions, unbilled documents and project reports, and to view (as well as open) tasks relating to this customer. 
 

 5 .  Run the Clear Aging Work Area program to clear all data from the work area. 
 
## Notes:

 

 ·        To view the balance of the A/R account, move to the Account No. column and press F6 . 
 

 ·        To view details of the last open billing task for this customer, enter the Explanation of Task sub-level form. 
 

 ·        To print a report containing data similar to that displayed in the work area, run the Aging by 30-Day Period report.
