# Printing a Certificate of Analysis

 
## Before you begin

 

 ·        Click if you have not yet defined set text for COAs. 
 

 ·        Dual currency users: if you are working in a different language and wish to print the COA in English, make sure you have defined English descriptions and remarks in the relevant setup forms. 
 
## To print a single COA:

 

 1 .  Enter the appropriate form and retrieve the desired document. 
 

 2 .  Select Print Certificate of Analysis from the list of Direct Activations .
 Dual-currency users: If you wish to print the COA in English and are working in another language, select Print COA in Foreign Language instead. 
 
## To print multiple COAs for inventory documents:

 

 ·        Run the Print Certificate of Analysis report and select the documents for which you want to print a COA.
 D ual-currency users: Run the Print COA in Foreign Language report to print multiple documents in English when working in another language. 
 
## To print multiple COAs for production reports:

 

 ·        Run the Print COA - Production Report report and select the production reports for which you want to print a COA.
 D ual-currency users: Run the Print COA Prod. Rep-Foreign Lang report to print in English when working in another language.
