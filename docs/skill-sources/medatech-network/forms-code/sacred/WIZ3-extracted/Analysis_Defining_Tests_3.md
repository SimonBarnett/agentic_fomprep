# To define the test parameters:

 

 1 .  For each test, specify the type of test in the Analysis Code column. The remaining columns appear automatically.
 Tip: Click to define a new test type . 
 

 2 .  The Display in Printout column is flagged by default. Remove the check mark if you want to exclude the current test from the part's COA printout. 
 

 3 .  Do one of the following, if necessary: 
 

 ·      Revise the Minimum Value and/or Maximum Value to the appropriate values. 
 

 ·      Enter the Possible Results sub-level form and revise the possible test results. 
 

 Reminder: Do not record possible numerical results if you want to perform multiple runs of the test and obtain an average score.
