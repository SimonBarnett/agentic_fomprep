# Extending Lot and Work Order Expiration

 

If a shelf life has been defined for a given part, its expiration date is calculated from the date a lot\work order is opened until the end of the designated period. Shelf life may be extended for additional periods, up to a specified maximum number of extensions. 
 
## Note:

 

To define the shelf life and maximum number of extensions for a specific part, run the Part Definition Wizard . 
 
## To view lots/work orders that are about to expire:

 

 ·        Run the Plan for Expir. Date Extensions report, which displays all lots/work orders that are scheduled to be issued to the plant floor after their expiration date has passed. 
 
## To view expiration and extension histories:

 

 ·        Run the Expirations and Extensions report, which displays all expiration and extension dates that fall within a designated period. 
 
## To extend the shelf life of a lot or work order:

 

 1 .  Enter the Expirations and Extensions form. 
 

 2 .  Retrieve the desired lot or work order (e.g., by number or expiration date).
 Tip: To extend the shelf life of a number of lots whose expiration dates fall within the same month, retrieve them by the month. Example. 
 

 3 .  Make sure that it is possible to extend the shelf life of the lot or work order. Explanation. 
 

 4 .  Enter the Expiration Date Extensions sub-level form. 
 

 5 .  Specify the date from which the shelf life is to be renewed. 
 

 6 .  If a shelf life has been defined for the part, the new expiration date is calculated automatically. In such a case, make sure that it is correct. Otherwise, specify the new expiration date.
