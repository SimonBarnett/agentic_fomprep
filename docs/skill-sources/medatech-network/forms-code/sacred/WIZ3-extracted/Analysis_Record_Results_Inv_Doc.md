# Recording Test Results in an Inventory Transaction Document

 

The itemization form of all of the major inventory transaction documents contains a sub-level called Analysis Results , which lists the tests the items recorded in the document are required to pass in order to enter inventory. 
 

This form is used to record the test results, thus determining whether or not the parts are acceptable. 
 

 Tip : To enable analysis reporting in a document that has been finalized, make sure the the Allow Analysis (COA) column is flagged for the status that is assigned to final documents. 
 
## To record the results of a laboratory test:

 

 1 .  Enter the appropriate inventory document (e.g., Goods Receiving Voucher). 
 

 2 .  Enter the itemization sub-level form and move to the desired part. 
 

 3 .  Enter the Analysis Results sub-level form. The laboratory tests required for the current part (at the highest possible level of the test hierarchy) appear automatically. Revise any of the test details, delete existing tests or add new ones, as needed. These changes are only valid for the current document. 
 

 4 .  Move to the line displaying the test that was just conducted. 
 

 5 .  Do one of the following: 
 

 ·      If the test was performed once, specify the result in the Result column. 
 

 ·      If the test was performed more than once, enter the Additional Results sub-level form and specify all of the test results. The average result and standard deviation appear in the upper-level form in the Result and Standard Deviation columns, respectively.
 Note: You cannot record multiple results if a list of possible results has been defined for the test.
