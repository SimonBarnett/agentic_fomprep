# To record a release document based on another document:

 

 1 .  Enter the Laboratory Release form. 
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the General tab). 
 

 2 .  Specify the Date testing was done for the items that are to be listed in the document. The Document Number is filled in automatically. 
 

 3 .  In the Document Type column (in the General tab), select the code representing the type of document on which the laboratory release is based ( GRV, Customer Return or Warehouse Transfer ).
 Note: To base the release on a vendor invoice, leave this column blank. 
 

 4 .  Specify the relevant document number in the Receiving Document column or the relevant invoice number in the Vendor Invoice column.
 Note: In the case of a receiving document, the Choose list includes all final documents with the designated code from the current year. 
 

 5 .  The warehouse recorded in the original document or invoice overwrites the default testing warehouse in the Warehouse column. Revise it if necessary.
