 7 .  Enter the Analysis Results sub-level of Tested Items . The laboratory tests required for the current part appear automatically. Revise any of the test details, delete existing tests or add new ones. These changes are only valid for the current document. 
 

 8 .  For each test, do one of the following: 
 

 ·      If the test was performed once, specify the result in the Result column. 
 

 ·      If the test was performed more than once, enter the Additional Results sub-level form and specify all of the test results. The average result and standard deviation appear in the upper-level form in the Result and Standard Deviation columns, respectively.
 Note: You cannot record multiple results if a list of possible results has been defined for the test. 
 

 9 .  Return to the upper-level form, and record a new status for the released part (e.g., Goods , Reject ) in the To Status column. 
 

 10 .  If the part is rejected, specify the appropriate Defect Code .
 Tip: To define additional defect codes, use the Defect Codes form. 
 

 11 .  To record remarks pertaining to the current document, enter the Remarks sub-level form. 
 

 12 .  To update the expiration date of the lot or work order, enter the Expiration Date Extensions sub-level form. 
 

 13 .  To finalize the release document, return to the upper-level form and assign a status flagged for the Final Document attribute (in the Statuses for Laboratory Releases form).
 Note : To enable analysis reporting after the document has been finalized, make sure the final status is also flagged in the Allow Analysis (COA) column. 
 
## Notes:

 ·        To print the document, select Print Laboratory Release Doc. from the list of Direct Activations .
