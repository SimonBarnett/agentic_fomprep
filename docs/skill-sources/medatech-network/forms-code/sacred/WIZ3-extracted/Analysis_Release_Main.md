# Recording a Laboratory Release Document

 

When you document the release of parts from laboratory testing, new statuses are assigned to the tested goods. The recorded quantity of tested parts is added to the part's inventory balance (for the specified status, lot/work order and warehouse). 
 

If testing is conducted on parts received in a single inventory receipt (GRV, Customer Return, Warehouse Transfer or Vendor Invoice), you can itemize the laboratory release document by linking it to the original document. In such cases, only received parts that require testing (as determined by their status) and have not yet been tested will appear automatically in the release document.
