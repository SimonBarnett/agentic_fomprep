# To view test results for parts in all documents (except production reports):

 

 ·        Enter the View Results of Analysis form and retrieve by part number, document type, analysis code and the like. All test details and results appear in this query form. 
 
## To view test results for parts in production reports:

 

 ·        Enter the View Analysis Results-Production form and retrieve by part number, analysis code and the like. All test details and results appear in this query form. 
 
## To view test results for parts recorded in laboratory release documents:

 

 ·        Enter the View Items Released from Lab form and retrieve by part number, date and the like. View the test results in the sub-level form. 
 
## To view test results for parts in sampling documents:

 

 ·        Enter the View Sampled Items form and retrieve by part number, date and the like. View the test results in the sub-level form.
