 7 .  If the sampled parts have serial numbers, use the Serial Numbers in Transaction or Auto Recording of Serial Nos. sub-level form.

 8 .  Enter the Analysis Results sub-level form. The laboratory tests required for the current part appear automatically. Revise any of the test details, delete existing tests or add new ones. These changes are only valid for the current document. 
 

 9 .  For each test, do one of the following: 
 

 ·      If the test was performed once, specify the result in the Result column. 
 

 ·      If the test was performed more than once, enter the Additional Results sub-level form and specify all of the test results. The average result and standard deviation appear in the upper-level form in the Result and Standard Deviation columns, respectively.
 Note: You cannot record multiple results if a list of possible results has been defined for the test. 
 

 10 .  If necessary, return to the Sampled Items form and record a new Status for the sampled part (e.g., Goods , Reject ). 
 

 11 .  To record remarks pertaining to the current document, move to the Remarks sub-level form. These remarks will appear on the printout. 
 

 12 .  To finalize the sampling document, return to the upper-level form and assign the document a status flagged for the Final Document attribute (in the Statuses for Sampling Documents form). 
 
## Notes:

 

 ·        To reopen a final document, select Reopen Document from the list of Direct Activations . 
 

 ·        To print the document, select Print Sampling Document from the list of Direct Activations . 
 

 ·        Click to return to the main screen.
