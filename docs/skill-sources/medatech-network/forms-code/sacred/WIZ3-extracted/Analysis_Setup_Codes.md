# To define types of laboratory tests and their possible results:

 

 1 .  Enter the Lab Analysis Codes form. 
 

 2 .  For each type of test, specify an Analysis Code and Analysis Description .
 Tip for dual-currency users : If you are working in a language other than English, and want to print COAs in English, record an English description in the Analysis Desc(Lang2) column. 
 

 3 .  Select the Method of Analysis to be used to execute the current test. 
 

 4 .  Do one or both of the following: 
 

 ·      Record a Minimum Value and Maximum Value within which a laboratory result will be considered acceptable for this test.
 Note: You can also record one of these values without the other, such that all results that are over or under the given value are acceptable. 
 

 ·      Enter the Possible Results sub-level form and select all possible result values from the Choose list. Specify whether each value is Acceptable or Unacceptable .
 Note: Do not record possible numerical results if you want to perform multiple runs of the test and obtain an average score; instead, record minimum and maximum values. 
 

 5 .  Flag the Display in Printout column in the upper-level form to include the current test in the COA for the tested part. 
 
## Note:

 

The values in this form create a template that is automatically imported whenever the test is assigned to a manufacturing operation or part, and when itemizing the test in an inventory document or production report. This template can then be revised for a specific operation, part or transaction.
