# Setting Up Defect Codes

 

If, as a result of testing, a certain quantity of parts is rejected, you use defect codes to record the cause. 
 
## To define defect codes:

 

 1 .  Enter the Defect Codes form. 
 

 2 .  For every possible cause of rejection, record a code and description. Example. 
 
## Notes:

 

 ·        You can define additional codes when needed. 
 

 ·        The sub-level form displays parts that are generally assigned this defect code when production is reported. It is irrelevant for laboratory testing.
