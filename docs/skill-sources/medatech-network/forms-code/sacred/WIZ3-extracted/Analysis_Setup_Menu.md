# Setting Up Analysis

 

Before you can begin to work with laboratory analysis, you need to define the following parameters: 
 

 Methods of analysis 
 

 Possible values for test results 
 

 Types of laboratory tests and their possible results 
 

 Defect codes 
 

 Default statuses for incoming inventory 
 

 Business processes (BPM) for laboratory releases and part sampling (statuses) 
 

 Default warehouses for testing and sampling 
 

 Set text for COAs
