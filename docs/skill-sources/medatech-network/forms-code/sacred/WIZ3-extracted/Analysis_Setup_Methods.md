Lab Analysis: Setting Up Analysis Methods 
 
 
- 
 
 
 
# To define analysis methods:

 

 1 .  Enter the Methods of Analysis form. 
 

 2 .  List all of the methods used to perform laboratory tests. 
 

 3 .  In the Methods of Analysis - Text sub-level form, record a comment relating to each analysis method. This comment will appear in a sub-level of the Analysis Results form, whenever the method in question is used. 
 

 Notes: 
 

 ·        You can add new methods to this list at any time. 
 

 ·        Click to define possible values for test results.
