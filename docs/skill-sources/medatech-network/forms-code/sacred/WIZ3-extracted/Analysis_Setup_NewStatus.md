# Defining Default Inventory Statuses

 

If a certain part always requires testing before use, you can define a corresponding default status that will be assigned automatically to the part when it is received into inventory. 
 
## To define statuses as requiring laboratory testing:

 

 1 .  Enter the Inventory Statuses form. The existing statuses appear automatically. 
 

 2 .  For every status for which testing is required, flag the Laboratory Testing column.
 Note: You can define new statuses as needed. 
 

 3 .  To prevent the accidental shipment or issuance to the plant floor of goods that require testing, make sure the Available for Sale and Available for Issue columns are empty for these statuses. 
 

 4 .  To allow for part sampling, flag the Disposable column. 
 
## To assign a default entry status to a specific part:

 

 1 .  Enter the Inventory Parameters for Parts form. 
 

 2 .  Retrieve the desired part. 
 

 3 .  In the Entry Status column, choose the desired status. Whenever receipt of this part is recorded, it will automatically receive the assigned status (which may be revised).
