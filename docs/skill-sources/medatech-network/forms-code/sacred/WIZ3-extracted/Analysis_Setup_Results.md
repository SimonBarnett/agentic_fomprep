- 
 
 
 
# To define possible values for analysis results:

 

 1 .  Enter the Possible Results - Choose List form. 
 

 2 .  List all values that can be used to describe the results of any laboratory tests. These values will appear in the Choose list when defining the possible results of a given test in the Lab Analysis Codes form. 
 

 Note: 
 

You can record numerical values as well as logical values (e.g., crumbly, soft, clear, muddied). However, if a particular test can yield a range of numerical values, it is advisable to define minimum and maximum values in the Lab Analysis Codes form instead. Only then will you be able to perform multiple runs of the same test for the same part and obtain an average score (and standard deviation).
