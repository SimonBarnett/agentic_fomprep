# To define set text for Certificates of Analysis (COA):

 

 1 .  Enter the Set Text for COA Item form. 
 

 2 .  Enter the Set Text - Acceptable COA Item sub-level form and record remarks that you want to appear in COAs, alongside parts that were found to be acceptable in all their tests.
 Tip for dual-currency users : If you are working in a language other than English, and want to print a COA in English, record remarks in English in the parallel Text-Acceptable COA Item-Lang2 sub-level form. 
 

 3 .  Enter the Set Text - Unacceptable COA Item sub-level form and record remarks that you want to appear in COAs, alongside parts that were found to be unacceptable in at least one of their tests.
 Tip for dual-currency users: If you are working in a language other than English, and want to print a COA in English, record remarks in English in the parallel Text-Unacceptable COA Item-Lang2 sub-level form.
