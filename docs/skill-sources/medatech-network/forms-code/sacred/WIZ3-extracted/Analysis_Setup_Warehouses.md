# Defining Default Warehouses

 

If the testing of parts takes place primarily in a single warehouse, you can define it as the default warehouse for laboratory release documents. Similarly, if part sampling takes place mainly in a single warehouse, you can define it as the default for sampling documents. In both cases, the warehouse will appear automatically when a new document is opened (though it may be revised). 
 
## To define a default warehouse for testing:

 

 1 .  Enter the Inv. Transaction Documents form. 
 

 2 .  Move to the Lab Release line. 
 

 3 .  In the Default Warehouse column, choose the appropriate warehouse.
 Tip: To define a new warehouse, use the Open a Warehouse Wizard . 
 
## To define a default warehouse for sampling:

 

 ·        Repeat the above process on the Inv. Sampling line.
