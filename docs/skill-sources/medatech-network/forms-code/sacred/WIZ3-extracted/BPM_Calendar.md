# To use your Calendar:

 

 1 .  Run the Calendar . 
 

 2 .  In the View menu, click Select Employee s and choose your own user name. 
 
## Tips:

 

 ·        Use the options in the Top Bar or Tool Tray to change how data are displayed. For instance, you can change the range of dates and fine-tune the level of detail (number of days displayed and their division into hours or minutes). 
 

 ·        You can save up to five different view settings (e.g., timescale, number of columns and resources) for future retrieval. To save the current setting in a buffer, select Save View Settings (in the View menu). To retrieve saved settings, select Get View Settings (in the View menu). 
 

 ·        To change the date or time of an appointment, drag it to the desired slot. 
 

 ·        To quickly locate a specific appointment, press Ctrl+F3 and record a key word (or string). Press Ctrl+F to perform additional searches for the same key word.
 Windows users: Press F3 instead of Ctrl+F to perform additional searches for the same key word. 
 

 ·        To add an appointment, double click in the appropriate time slot. The Tasks form opens with certain data already filled in. Complete the necessary information and exit the form. The new appointment will automatically appear in the calendar. (Click fo r instructions on working with the Tasks form.) 
 

 ·        To view the details of an appointment, click in the time slot and press F11 . To change those details, double click on it or press F6 . 
 

 ·        To print an appointment, right-click its time slot and select Print Task . 
 

 ·        To color a specific task in the Calendar, right-click the task in question and choose Select Color .
 Note: Whatever color is selected is seen by all users who access that task.
