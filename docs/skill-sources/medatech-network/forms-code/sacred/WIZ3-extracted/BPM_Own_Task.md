# Recording a Task For Yourself

 

The Tasks form is mainly used to record tasks for customers and vendors, but it can also be used for internal tasks. 
 
## Notes:

 

 ·        A task is recorded automatically whenever an appointment is opened in your Calendar, and whenever an order, project activity, warehouse assembly or service call is scheduled for you. 
 

 ·        All your tasks whose start time differs from their end time appear in your Calendar. 
 

 ·        All open tasks for which you are responsible appear in your To Do List.
