# To record a task:

 

 1 .  Enter the Tasks form. 
 

 2 .  Record a Subject for the new task. A Task No. appears automatically. 
 

 3 .  Your default Task Code and Task Type appear automatically. Revise them if necessary.
 Tip: Defaults are defined in your Personnel File . 
 

 4 .  Click the Definitions tab. The current date and time appear automatically in the Start Date/Time and End Date/Time columns. Fill in the correct values.
 Note: For a task that does not have a set time (e.g., a phone call), leave the default time. 
 

 5 .  To set a reminder for yourself, move to the References tab and flag the Remind column. In the Hrs/Mins in Advance column, specify the desired number of hours and/or minutes in advance you wish to receive the reminder (e.g., 00:30). The system will send you an e-mail. 
 

 6 .  To record additional instructions or comments about the task, enter the Notes sub-level form.
