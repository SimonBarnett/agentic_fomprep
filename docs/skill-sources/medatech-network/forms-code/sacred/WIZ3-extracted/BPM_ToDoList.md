# To access your To Do List:

 

 1 .  From the pull-down Mail menu, select the To Do List . 
 

 2 .  Retrieve by your own user name in the Assigned to column. 
 
## To obtain a printed copy of your list: 

 

 ·        Select To Do List from the list of Direct Activations or run the To Do List report. 
 
## To print a list of To Do items that are being taken care of (or are completed):

 

 ·        Run the Reported To-Do Items report.
 Note: This report displays only the most recent status and assigned user for each To Do item. 
 
## Tips:

 

 ·        To view each document for which you are responsible, move to the Document Number column and press F6 . 
 

 ·        Each document has a sub-level To Do Item form, in which you can record pertinent information, such as expected start and end dates, and brief details. 
 

 ·        Each document has the sub-level form History of Statuses , in which you can view previous statuses and assigned users. This form has its own sub-level, To Do List - Remarks , in which you can view and record remarks regarding any changes in the task. 
 

 ·        You can view and/or update remarks for each document for which you are responsible in a sub-level of the To Do List form. 
 

 ·        You can update the status of each document or assign it to a different user directly from the To Do List form. If the value of the TODOREVISE constant is defined as 1 (in the System Constants form), other changes to the To Do item will also affect the original document. 
 

 ·        To attach files to a To Do item, use the Attachments sub-level of the To Do List form. 
 

 ·        When synchronizing with MS-Outlook, you can update your Outlook tasks with all items assigned to you in your To Do List. For details, run the CRM Wizard .
