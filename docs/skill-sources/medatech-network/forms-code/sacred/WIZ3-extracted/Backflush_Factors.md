# Factors Affecting Backflush

 

Parameters that fine-tune the basic workings of the Backflush program include: 
 

 ·        Inventory/costing control settings. Click for a detailed explanation . 
 

 ·        Assignment of a child-part warehouse. Explanation 
 

 ·        Assignment of a subcontractor to a work order. 
 

 ·        The type of issue assigned to the child part in the kit list (or, if work orders are not used, in the BOM). Explanation. 
 

 ·        The percentage of scrap. Explanation. 
 

 ·        The percentage of inventory cleaning. Explanation. 
 

 ·        The Rework flag on production reports/GRVs. Explanation. 
 

 ·        The production constant that determines whether missing issues to kit can be completed by other inventory balances on the plant floor (the TakeNonKit constant). 
 

 ·        The production constant that determines whether to round fractional inventory balances when calculating floor inventory (the RoundBalance constant). Explanation. 
 

 ·        Parameters affecting the automatic entry of fully processed parts into the factory warehouse. Explanation.
