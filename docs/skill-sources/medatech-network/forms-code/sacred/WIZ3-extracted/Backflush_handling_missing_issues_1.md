# Handling Missing Issues

 

At the close of the Backflush program, you are informed of any missing issues . To view these problematic cases, open the Missing Issues form. 
 
## Causes of missing issues

 

Missing issues are usually caused by discrepancies between the quantity of child parts issued and the quantity needed for the parent parts recorded in production reports, or by changes in the attributes of the part or the work cell in which the production operation is performed (e.g., the child’s part type or issue type , the part’s production routing or the work cell warehouse . 
 

This can also be caused by inventory transactions involving floor warehouses, which are not directly linked to production (that is, they do not result from production reports, subcontractor GRVs or issues). Example.
