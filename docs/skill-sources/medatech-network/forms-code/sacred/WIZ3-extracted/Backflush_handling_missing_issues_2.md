# Resolving Missing Issues

 

 ·        Missing issues can be resolved by correcting the original production reports or inventory transactions (e.g., the quantity of reported parent parts, an incorrect or missing issue transaction) or by performing an inventory count prior to recording the past balance . Afterwards, run the Backflush program again.
