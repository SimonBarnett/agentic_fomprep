## III. Check the accuracy of part issues:

 

 1 .  Return to the current line in the Missing Issues form. 
 

 2 .  Move to the For Work Order column and press F6 to access the work order in question. 
 

 3 .  Enter the Kit List sub-level and move to the Issued to Kit column. 
 

 4 .  Do one of the following: 
 

 ·      Click if the Issued to Kit column is flagged. 
 

 ·      Click if the Issued to Kit column is empty.
