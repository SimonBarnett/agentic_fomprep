## IIIb. If the part is defined as issued in bulk:

 

Check that sufficient issues to the floor were recorded. This depends on how required quantities of bulk issues are calculated (based on the setting of the IFloorInv constant): 
 

 ·        If required quantities are determined by the Issue Plan generated by MRP , run the View Dates & Chosen Options program and check the following details: 
 

 ·      The last time MRP was run 
 

 ·      The target date for which the program was run 
 

 ·      Whether the program was set to take all released, open work orders into account (the Consider Work Ords option). 
 

If MRP was not run for the correct end date, try rerunning MRP and then preparing new issues of floor stock. 
 

 ·        If required quantities are determined by minimum floor stock , they may not have been sufficient for actual work orders. If this is the case, try preparing new issues of floor stock. 
 

 ·        If required quantities are determined by open, released work orders, check whether issues were planned after the work order was released. 
 
## Notes:

 

 ·        To see if this has resolved the missing issue, rerun the Backflush program. 
 

 ·        Click if the problem was not resolved. 
 

 ·        If the problem was resolved: 
 

 ·      Click to handle additional missing issues. 
 

 ·      Click to handle negative inventory. 
 

 ·      Click to return to the main screen.
