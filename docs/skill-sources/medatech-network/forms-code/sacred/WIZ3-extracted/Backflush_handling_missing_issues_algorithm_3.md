## IV. Check for erroneous inventory transactions from the floor warehouse involving the part in question:

 

Run the Inv Journal - Materials on Floor report for the part. Check for any erroneous inventory transfers out of the relevant floor warehouse (i.e., transactions that are not directly related to production, such as a warehouse transfer or an inventory count that was not immediately followed by a past balance ). 
 

 ·        If an erroneous transaction has been recorded: Revise or delete it, as needed. 
 
## Notes:

 

 ·        To see if this has resolved the missing issue, rerun the Backflush program. 
 

 ·        Click if the problem was not resolved. 
 

 ·        If the problem was resolved: 
 

 ·      Click to handle additional missing issues. 
 

 ·      Click to handle negative inventory. 
 

 ·      Click to return to the main screen.
