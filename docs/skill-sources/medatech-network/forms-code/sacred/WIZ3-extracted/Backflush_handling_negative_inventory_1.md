# Handling Negative Inventory Balances

 

At the close of the Backflush program, you are informed of any negative inventory balances. Negative balances can be viewed in any warehouse inventory form (e.g., Current Warehouse Inventory ), and are generally the result of missing production reports or undocumented inventory transactions. 
 
## Tip: 

 

To view all negative balances, run the Current Inventory by Warehouse report for all warehouses, specifying < 0 in the Balance (Fact. Unit) input column. 
 
## Causes of negative floor inventory balances:

 

 ·        In the case of child parts, recording a past balance when missing issues remain uncorrected in the system. 
 

 ·        In the case of processed parts, errors in production reporting and/or the inventory/costing control settings of operations. Explanation. 
 

 ·        Errors in recording inventory transactions from the floor warehouse that are not directly related to the production process. Explanation.
