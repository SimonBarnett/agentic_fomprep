# Troubleshooting Negative Inventory

 
## I. If the negative balance is not for a child part, click to continue . If it is for a child part:

 

 1 .  Enter the Past Balances form and retrieve the part’s inventory balance as it was calculated in the last past balance.
 Tip: Use the Date , Warehouse and Part Number columns to retrieve the balance. 
 

 2 .  If the balance is negative, delete the last past balance and rerun the Backflush program.
 Note: For more information regarding past balances, run the Past Balances Wizard . 
 

 3 .  Check the Missing Issues form for missing issues of the part in the relevant floor warehouse. 
 

 ·      If missing issues are recorded for the part: Resolve the missing issues, rerun the Backflush program and calculate a new past balance for the same date as the previous one. Check again for a negative balance – there may be other problems in addition to the missing issues. If so, continue to the next step. 
 
## Notes:

 

 ·        Click if the problem was not resolved. 
 

 ·        If the problem was resolved: 
 

 ·      Click to handle missing issues. 
 

 ·      Click to return to the main screen.
