## II. If the negative balance is for a raw material, click to continue . If it is for a processed part: 

 

 1 .  Note the work order number, warehouse and operation in which the negative balance occurs.
 Tip: To view all negative balances, run the Current Inventory by Warehouse report for all warehouses, specifying < 0 in the Balance (Fact. Unit) input column. 
 

 2 .  Enter the Work Orders form and retrieve the desired work order. 
 

 3 .  Enter the Routing for the Work Order sub-level form and note the following details: 
 

 ·      The inventory/costing control setting specified for the operation 
 

 ·      The operation following that in which there is a negative balance 
 

 ·      The inventory/costing control setting specified for the subsequent operation. 
 

 4 .  Enter the parallel Progress Report sub-level form and note the quantity of the part recorded in the production report of the operation in which the negative balance occurs, and the quantity recorded in the production report of the following operation.
