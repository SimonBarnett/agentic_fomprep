Backflush - Troubleshooting Negative Inventory.4 
 
 
- 
 
 
 

  
 

 ·        If the problematic operation or the following one is performed by a subcontractor, is the correct warehouse linked to the subcontractor (in the Vendors form? 
 

If the wrong warehouse is designated in the relevant document, correct the document.
 Notes: 
 

 ·      If the document is a final shipment to subcontractor document, you must first reopen it by selecting Reopen Document from the list of Direct Activations . 
 

 ·      If the document is a final subcontractor GRV, reopen it by selecting Reopen Document from the list of Direct Activations . If the GRV has already been billed, it cannot be reopened and updated. In this case, you need to either record an additional GRV correcting the error, or perform a warehouse transfer. 
 

 ·        Are goods received from the subcontractor recorded to the correct floor warehouse? 
 

If not, correct the GRV.
 Note: If the document is a final subcontractor GRV, reopen it by selecting Reopen Document from the list of Direct Activations . If the GRV has already been billed, it cannot be reopened and updated. In this case, you need to either record an additional GRV correcting the error, or perform a warehouse transfer.
