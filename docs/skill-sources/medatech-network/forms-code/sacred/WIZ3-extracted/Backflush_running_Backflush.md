# Performing a Backflush

 

When you run the Backflush program, you are required to choose whether the program will only take into account new production reports, issues and other plant-floor transactions (i.e., that were not included in the previous run of the program), or to include all floor transactions recorded since the last calculation of past balances. 
 

Normally, it is sufficient to choose the first option; however, if you want a more thorough update of floor inventory, choose the second option, so that the Backflush program will take into account all floor transactions recorded since the last calculation of past balances. This option entails a considerable amount of data processing, and should be used sparingly. 
 
## To perform a Backflush:

 

 ·        Run the Backflush program. 
 
## To view the child parts reduced from inventory by the Backflush program:

 

 ·        Enter the Backflush Transactions form. 
 
## Notes:

 

 ·        Click to handle missing issues. 
 

 ·        Click to handle negative inventory.
