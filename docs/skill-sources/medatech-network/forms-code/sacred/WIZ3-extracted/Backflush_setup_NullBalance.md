# Setting Up Deletion of Zero Inventory Balances

 

You can set the Backflush program to automatically delete all inventory balances of 0 . 
 
## To determine how zero inventory balances will be handled:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the NullBalance constant and select the appropriate value. 
 
## Note:

 

If this constant is set to delete all zero balances, they will also be deleted when inventory counts are automatically prepared and when past balances are calculated.
