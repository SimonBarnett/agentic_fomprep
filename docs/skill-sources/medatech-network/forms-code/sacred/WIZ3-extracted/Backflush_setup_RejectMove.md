# Setting Up the Scope of Automatic Warehouse Entry

 

If a factory warehouse is designated for a reported operation of a work order (usually the last operation in the routing), the Backflush program automatically transfers the parts from the plant floor to that warehouse. You need to define whether all of the parts will automatically enter the factory warehouse, including rejected parts and parts referred to MRB, or only parts that have been assigned the Goods status. 
 
## To determine the scope of the automatic warehouse entry facility:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the RejectMove constant and select the appropriate value.
