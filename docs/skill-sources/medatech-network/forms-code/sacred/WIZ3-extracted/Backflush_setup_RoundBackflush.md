# Rounding Deducted Quantities of Child Parts

 

You can set the Backflush program to automatically round quantities when deducting child parts measured in whole units in backflush transactions. 
 
## To determine whether rounding will be used:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the RndBackflush constant and select the appropriate value.
 Note: This constant only affects child parts whose factory unit is " ea ".
