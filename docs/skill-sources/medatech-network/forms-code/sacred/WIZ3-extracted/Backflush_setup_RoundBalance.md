# Setting Up Automatic Rounding 

 

You can set the Backflush program to automatically round fractional inventory balances on the plant floor. Explanation. 
 
## To determine whether rounding will be used:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the RoundBalance constant and select the appropriate value.
 Note: This constant only affects parts measured in the " ea " unit.
