# Completing Issues to Kits from Floor Inventory

 

You can set the Backflush program to complete needed issues to kits with inventory from the plant floor. Note, however, that this may result in missing issues, as the Backflush program may use inventory issued to another kit or otherwise intended for a particular work order. 
 
## To determine whether floor inventory will be used to complete kits:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the TakeNonKit constant. 
 

 3 .  Select the appropriate value.
