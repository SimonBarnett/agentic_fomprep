# Setting Up Inventory/Costing Control 

 

Inventory/costing control settings are defined according to the following hierarchy: 
 

 ·        by work cell – affecting all operations in that work cell 
 

 ·        by operation – affecting a specific operation and overriding the work cell flag 
 

 ·        by work order routing – affecting a specific operation in the routing of a particular work order and overriding the other two flags. 
 
## Notes:

 

 ·        Changes in the setting for a work cell or operation will not affect the operations in the routing of a work order that has already been released.
