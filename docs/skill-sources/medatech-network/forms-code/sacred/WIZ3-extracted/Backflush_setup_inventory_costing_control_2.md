# To set the work cell flag:

 

 1 .  Enter the Work Cells form and retrieve the desired work cell. 
 

 2 .  Select the desired setting in the Inv./Costing Control column. 
 Note: When you define a new work cell, the default inventory/costing control setting is R . 
 
## To set the flag for a single operation:

 

 1 .  Enter the Operations form and retrieve the desired operation. 
 

 2 .  Select the desired setting in the Inv./Costing Control column. 
 Note: If you leave the Inv./Costing Control column empty for a given operation, the operation automatically receives the setting for the work cell in which it is executed.
