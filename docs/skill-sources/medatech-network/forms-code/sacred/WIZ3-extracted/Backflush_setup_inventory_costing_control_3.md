# To define the setting in a work order routing:

 

 1 .  Enter the Work Orders form and retrieve the desired work order. 
 

 2 .  Enter the Routing for the Work Order sub-level form. 
 

 3 .  Move to the desired operation. The Inv./Costing Control setting appears automatically, but may be revised. 
 Note: You cannot revise this setting once a production report/GRV has been recorded for this work order and operation.
