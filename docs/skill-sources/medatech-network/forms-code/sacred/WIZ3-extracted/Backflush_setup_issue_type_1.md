# Setting Up Types of Issues 

 

The type of issue determines how materials required for production are transferred to and utilized on the plant floor. Explanation. This can be defined on two levels: 
 

 ·        for the part in general 
 

 ·        for the part in a specific work order 
 

In the latter case, you can only change the type from an issue of bulk to an issue to a kit. For more information, run the Issues Wizard . 
 
## To set the standard issue type for a part:

 

 1 .  Enter the Parts form and retrieve the desired part. 
 

 2 .  Do one of the following: 
 

 ·      If the part is to be issued to a kit, make sure a check mark appears in the Issued to Kits column. 
 

 ·      To issue in bulk, remove the check mark. 
 

 ·      If the part is to be issued manually, remove the check mark, and flag the Manual Issue column.
