# To change the issue type for a specific work order:

 

 1 .  Enter the Work Orders form and retrieve the desired work order. 
 

 2 .  Enter the Kit List sub-level form, and move to the desired child part (that is usually issued in bulk). 
 

 3 .  Flag the Issued to Kit column. 
 
## Notes:

 

 ·        Changing the issue type does not affect the backflush. That is, after the part is issued to the kit, production reports will reduce its inventory on the plant floor as with any bulk part; that is, for any work order that requires them, not only for the current work order. 
 

 ·        Click to perform additional setups.
