# Troubleshooting Missing Issues

 
## I. Check the accuracy of the reported quantity of parent parts

 

 1 .  Enter the Missing Issues form and retrieve all records. 
 

 2 .  In the first line, move to the For Work Order column and press F6 to access the work order in question. 
 Tip: First make a note of the operation and date. 
 

 3 .  Enter the Progress Report sub-level form, and move to the relevant production report or GRV (for the operation and date recorded in the missing issue). 
 

 4 .  Do one of the following: 
 

 ·      For a production report, press F6 in the Date of Report column to access the document and check the accuracy of the data. 
 

 ·      For a receipt from a subcontractor, press F6 from the GRV/Shipment Number column. 
 

 5 .  The first item to check is quantity; however, a mistake in the work order or operation numbers can also be a cause of missing issues. 
 

 If there are errors in the document : Correct the erroneous data.
 Notes: 
 

 ·      If the document is a final production report, reopen it by removing the check mark from the Final column. 
 

 ·      If the document is a final subcontractor GRV, reopen it by selecting Reopen Document from the list of Direct Activations . If the GRV has already been billed, it cannot be reopened and updated. In this case, you need to either record an additional GRV correcting the error, or perform a warehouse transfer. 
 

 If the report itself is erroneous (i.e., it should not have been recorded): Delete the report. 
 
## Notes:

 

 ·        To see if this has resolved the missing issue, rerun the Backflush program. 
 

 ·        Click if the problem was not resolved. 
 

 ·        If the problem was resolved: 
 

 ·      Click to handle negative inventory. 
 

 ·      Click to return to the main screen.
