# Running the Online Program

 

Online Backflush provides you with a rough estimate of the current floor inventory without tying up the resources required to run the full program. The online program adjusts floor inventory balances on the basis of the following events: 
 

 ·        Raw materials entering or leaving the plant floor (e.g., via a warehouse transfer) 
 

 ·        Automatic transfer of completed parts from the plant floor upon execution of their final operation 
 

 ·        Production reports. 
 

When the full Backflush is subsequently run, it confirms or adjusts these online estimates. 
 
## To activate the online program:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the OnlineBF constant and change the value to 1 .
