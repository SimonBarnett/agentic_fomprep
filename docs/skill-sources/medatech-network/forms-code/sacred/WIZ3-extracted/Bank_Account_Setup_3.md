# To create a list of bank branches:

 

 1 .  Enter the Bank Branches form. 
 

 2 .  Specify the Bank Code of the bank in question. 
 

 3 .  Record the Branch Number and Branch Name . 
 

 4 .  Record the address of the bank branch in the relevant columns.
