# Printing Bank Transfer Documents

 
## Before You Begin

 

The remarks recorded in each transfer document appear on the notifications issued to the vendor and to your bank. 
 
## To check remarks:

 

 1 .  In the Payments by Bank Transfer form, retrieve the desired documents. 
 

 2 .  Enter the Bank Transfer - Remarks sub-level form. Make sure the text recorded there is correct. 
 
## To print notifications to vendors that their accounts were credited:

 

 ·        Run the Print Bank Transfer (Vend Copy) report.
 Dual-currency users: If you wish to print the document in English when working in another language, run the Print BkTransf(Vend)-ForeignLang report instead. 
 
## To print letters requesting that your own bank transfer funds:

 

 ·        Run the Print Bank Transfers (Bank Copy) report.
 Dual-currency users: To print in English when working in another language, run the Print BkTransf(Bank)-ForeignLang report.
