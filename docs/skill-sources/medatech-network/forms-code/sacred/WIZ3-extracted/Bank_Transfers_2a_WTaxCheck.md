# Setting the WTaxCheck Constant

 

The WTaxCheck constant determines whether the system will check if the withholding tax authorization for the vendor has expired prior to recording a payment (by bank transfer or check). 
 
## To set the withholding tax vendor authorization check for payments:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the WTaxCheck constant and choose the desired value. 
- Specify 0 to prevent the system from checking, or
- Specify 1 to enable the vendor withholding tax authorization check prior to recording payments.
