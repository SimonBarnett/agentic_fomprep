# Setting Up Bank Transfers

 

Before you begin working with bank transfers, you need to: 
 

 ·        determine the method of reconciling invoices with payments 
 

 ·        create a variance account to which small differences between reconciled amounts will be transferred 
 

 ·        set up business processes (BPM) for bank transfers – i.e., define statuses 
 

 ·        make sure your vendors' banks and your own banks are set up 
 

 ·        make sure each of your vendors' and your own bank accounts are set up 
 

 ·        flag those vendors that always receive payment by bank transfer (optional) 
 

 ·        record set text that will appear on your bank transfer printouts (optional) 
 

 ·        U.S. users: set up for Form 1099. 
 

In addition, dual-currency users need to: 
 

 ·        define how payment sums will be adjusted when the payment currency differs from the invoice currency, and 
 

 ·        set the WTaxCheck constant to determine whether the system checks if the withholding tax authorization for the vendor has expired.
