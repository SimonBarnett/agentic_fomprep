# To define vendor accounts:

 

 1 .  Enter the Chart of Accounts Payable form and retrieve the relevant accounts. 
 

 2 .  Make sure that the Bank Account Details sub-level form has been filled in.
 Note to dual-currency users: For vendors residing in a foreign European country, record their IBAN in the Bank Account column and their Bank Identifier Code in the BIC - Bank ID Code column. Then use the RIB Control Key column to check the validity of these numbers.
