# Set Text for Bank Transfers

 

If you want certain remarks to appear on all (or most of) the printouts of bank transfers, you can designate set text for this purpose. You can also designate set text specific to a particular branch and entry code. Such set text will appear on bank transfers assigned to this branch and entry code, instead of the general set text for bank transfers. 
 
## To record set text for bank transfers:

 

 1 .  Enter the Financial Documents form. 
 

 2 .  Move to the line for Bank Transfers . 
 

 3 .  Specify the set text in the Set Text for Document sub-level form. This text will automatically appear as remarks for newly opened bank transfers (in the Bank Transfer - Remarks sub-level form), but may be revised there. Any remarks appearing in this sub-level form are automatically included in bank transfer printouts (both the bank's notification and the vendor's copy).
 Tip: For dual-currency users working in a language other than English, if you also print transfer notices in English, record your set text in English in the Set Text for Document - Lang2 sub-level form. This text will appear in transfer notices printed out for vendors that have been flagged for Printouts in Lang 2 (in the Vendors form). 
 
## To record set text for bank transfers per branch and entry code:

 

 1 . Enter the Financial Documents form. 
 

 2 . Move to the line for Bank Transfers . 
 

 3 . In the Journal Entry Codes per Branch sub-level form, move to the line containing the designated branch. 
 

 4 . Specify the set text in the Set Text for Branch sub-level form. 
 

 Tip: For dual-currency users working in a language other than English, if you also print transfer notices in English, record your set text for a specific branch and entry code in English in the Set Text for Branch - Lang2 sub-level form. This text will appear in transfer notices printed out for vendors that have been flagged for Printouts in Lang 2 (in the Vendors form).
