# Preparing Payment Documents – Before You Begin

 

If set text has been defined for bank transfers, it will be included in the prepared payment documents and therefore will appear on printouts. If you designated set text for bank transfers assigned to a specific branch and entry code, that text will override the default set text for the document. 
 

If you want to prepare bank transfers for some vendors and check payments for others, make sure that the former are flagged as always receiving payment by bank transfer (and the latter are not). Then select By Vendor Definition when running the preparation program. 
 
## To check the set text defined for bank transfers:

 

 1 .  Enter the Financial Documents form and move to the line for Bank Transfers . 
 

 2 .  In the Set Text for Document sub-level form (and the Set Text for Document - Lang2 sub-level form, for dual-currency users), make sure the set text meets your needs. 
 
## To check the set text defined for bank transfers according to branch and entry code:

 

 1 . Enter the Financial Documents form and move to the line for Bank Transfers . 
 

 2 . Select the relevant branch in the Journal Entry Codes per Branch sub-level form. 
 

 3 . In the Set Text for Branch sub-level form (and the Set Text for Branch - Lang2 sub-level form, for dual-currency users), make sure the set text meets your needs. 
 
## To check that vendors are flagged to receive bank transfers:

 

 ·        Retrieve them in the Financial Parameters for Vendors form and make sure the Pay by Bank Transfer column (in the Invoice Data tab) is flagged.
