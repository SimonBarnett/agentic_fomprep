# Flagging Vendors to Receive Bank Transfers

 

When payments are prepared in a batch, users have the option of creating check payments only, bank transfers only or payment by vendor definition. The last option allows you to simultaneously prepare check payments for some vendors and bank transfers for others. 
 
## To define a vendor as always receiving payment by bank transfer:

 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the vendor in question. 
 

 2 .  Click the Invoice Data tab and flag the Pay by Bank Transfer column. 
 
## Note:

 

Vendors for which this column is not flagged will be defined as receiving check payments.
