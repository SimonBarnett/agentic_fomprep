# Printing Form 1099

 
## Before you begin:

 

 1 .   Make sure the correct Form 1099 category has been assigned to each payment during the period in question.
 Tip: Open the Revision of Payment Details form and retrieve by payment date; revise as necessary in the 1099 Category Code column. 
 

 2 .  Make sure any vendors that are to be included in the report are defined as such in the Financial Parameters for Vendors form ( General tab). 
 
## To print Form 1099:

 

 ·        Run the Form 1099 report.
