# Keeping Track of Blanket Orders

 

Each time a sales order is opened on the basis of a blanket order, the remaining quantity or monetary value of goods that the customer is obligated to buy is reduced accordingly. This amount appears in the Balance to Order column of the Itemized Blanket Order sub-level form, for each ordered item in a quantity-based order, and in the Value of Balance column in the upper-level form in orders based on monetary value-. 
 

When all of the order items are closed, the blanket order is closed automatically, and a check mark appears in the Closed column of the upper-level form (in the Follow-up tab). You can also close the blanket order at any time by flagging the Closed column manually. 
 

 Priority also provides the Status of Blanket Orders report, which displays part quantities and prices in open blanket orders, as well as all balances left to be ordered and their monetary value.
