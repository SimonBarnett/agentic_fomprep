# Printing a Blanket Order Confirmation

 
## Before you begin:

 

 1 .  In the Blanket Sales Orders form, retrieve the desired blanket sales order. 
 

 2 .  Enter the Blanket Sales Orders - Remarks sub-level form. The text appearing in this form will appear as a remark on the printout. Make sure that it is correct. 
 
# To print one order:

 

 ·        Select Blanket Order Confirmation from the list of Direct Activations .
 D ual-currency users: If you wish to print the order in English and are working in another language, select BlanketOrder Confirm-ForeignLang instead. 
 
## To print more than one order:

 

 ·        Run the Blanket Order Confirmation report.
 D ual-currency users: To print in English when working in another language, run the BlanketOrder Confirm-ForeignLang report.
