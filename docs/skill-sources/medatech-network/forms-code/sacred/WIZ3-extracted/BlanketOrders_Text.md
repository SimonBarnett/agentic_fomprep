# Assigning Set Text to Blanket Orders 

 

Create set text so that certain remarks always appear in the printouts of blanket sales orders. You can later change or delete this text for each specific order. 
 
## To assign set text:

 

 1 .  Enter the Set Text for Blanket Sales Ords form. 
 

 2 .  Record the desired text in the Set Text for Blanket Sales Ords sub-level form.
 Dual-currency users: If you are working in a language other than English, and wish to print out order confirmations in English, record set text in the Set Text Blanket Sales Ords(Lg2) sub-level form. Any orders opened for customers defined as receiving Printouts in Lang 2 will contain set text in English.
