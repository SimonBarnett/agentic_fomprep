# Viewing Reports on Bonuses

 

 Priority offers a report for each kind of bonus. 
 
## To view regular bonuses for a single part:

 

 ·        Run the Bonuses for Ordering Parts report. 
 
## To view regular bonuses for a part family:

 

 ·        Run the Bonuses for Ordering from Family report. 
 
## To view special bonuses for a single part:

 

 ·        Run the Special Part Bonuses for Custs report. 
 
## To view special bonuses for a part family:

 

 ·        Run the Special Family Bonuses for Custs report.
