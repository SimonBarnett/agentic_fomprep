# To open branches:

 

 1 .  Enter the Branches form. 
 

 2 .  For each branch, record a Branch Code and Branch Name . 
 

 3 .  Click the Address and Phone tab and fill in the relevant contact information. These values will appear in printouts of financial and inventory documents recorded in this branch, instead of the general contact information recorded for the company.
 Tip: You can link to a file containing the branch logo, in the Logo column. This logo will then appear in branch documents instead of the company logo. 
 

 4 .   D ual-currency users: If you are working in a language other than English, record the name of the branch in English in the Name (Lang 2) column. Then click the Info for Exports tab and record the branch contact information in English. You can also attach a logo that will appear on all printouts from the branch to foreign contacts. 
 

 5 .  Click the Branch Details tab and specify a Warehouse to serve as the default in any inventory document (e.g., customer shipment) recorded by a user in this branch. 
 

 6 .  If relevant, specify the branch's default walk-in customer account in the Branch Walk-in Cust column. 
 

 7 .  If your branches are divided into areas, specify the Area to which the branch is assigned. 
 

 8 .  Click the Financial Data tab. As needed, specify the default Branch Cashier . 
 

 9 .  If you work with subsidiaries, select the Subsidiary to which the branch belongs.
