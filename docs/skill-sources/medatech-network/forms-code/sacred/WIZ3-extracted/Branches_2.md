# Creating Numeration Templates per Branch

 

The number of a financial or an inventory document can indicate the branch in which it was opened. In order to use this feature, you need to assign branch identifiers and then create templates per branch. 
 
## To assign branch identifiers:

 

 ·        For each branch in the Branches form, record a Branch Identifier . 
 
## To create templates for numbering documents by branch:

 

 1 .  Run the Open Numeration Templates program. 
 

 2 .  Enter the Document Numeration Templates form. Make any necessary changes in the results of the program. For example, for any document type that you do not want the branch identifier to appear, enter the Prefix column (which by default includes the branch identifier and the year) and delete the branch identifier. 
 
## To create templates for numbering journal entries by branch:

 

 1 .  Enter the Define Fiscal Years form. 
 

 2 .  Flag the Number by Branch column for the desired fiscal year. 
 

 3 .  Enter the Entry Numbers by Branch sub-level form and change the Prefix as desired. For example, if you want the branch identifier to appear, enter the Prefix column (which by default contains the general prefix for entry numbers defined for the year in question) and add the branch identifier. 
 
## Tip:

 

For more details, run the Set Up Financial Docs Wizard or the Set Up Documents Wizard .
