# Assigning Users to Branches

 

When you assign a user to a main branch, this branch can serve as the default in any document opened by that user. 
 

You can also assign the user to additional branches, and define the default settings for documents opened by that user for each branch that the user belongs to. 
 
## Note:

 

Click for an explanation of how branches are assigned to documents. 
 
## To assign users to a main branch:

 

 1 .  Enter the Personnel File form. Retrieve the user in question. 
 

 2 .  Enter the Company-Specific Information sub-level form. In the Main Branch column, choose the main branch that the user belongs to. 
 
## To assign users to additional branches and define default settings for each branch:

 

 1 .  Enter the Branches form. Retrieve the branch in question. 
 

 2 .  Enter the Employees in Branch sub-level form and indicate the user name of each employee who works at this branch. For each employee, specify the default Task Code and Task Type to be assigned to tasks opened by this user at the current branch. 
 

 3 .  If the default task code is defined as an Appointment (in the Task Codes form), indicate the default Appointment Duration for tasks opened for this employee at this branch. This value will appear as the appointment's duration in the Calendar and the Appointment Calendar . 
 
## Tip:

 

Use the Branch Employees form to view the employees that are associated with different branches, or to link an employee to a branch.
