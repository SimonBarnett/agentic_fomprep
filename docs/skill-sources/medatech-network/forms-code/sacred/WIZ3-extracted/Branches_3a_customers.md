# Assigning Customers to Branches

 

When you assign a customer to a branch, the branch can serve as the default in any document opened for that customer. 
 
## Note:

 

Click for an explanation of how branches are assigned to documents. 
 
## To assign customers to branches:

 

 1 .  Enter the Customers form. Retrieve the customer in question. 
 

 2 .  Click the Details tab. In the Branch column, choose the branch that works with the customer.
