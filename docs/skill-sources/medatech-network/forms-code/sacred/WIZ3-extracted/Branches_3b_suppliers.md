# Assigning Vendors to Branches

 

When you assign a vendor to a branch, the branch can serve as the default in any document opened for that vendor. 
 
## Note:

 

Click for an explanation of how branches are assigned to documents. 
 
## To assign vendors to branches: 

 

 1 .  Enter the Vendors form. Retrieve the vendor in question. 
 

 2 .  Click the Details tab. In the Branch column, choose the branch that works with the vendor.
