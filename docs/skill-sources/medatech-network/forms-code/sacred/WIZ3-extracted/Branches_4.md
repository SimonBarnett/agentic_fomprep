# Replenishing Inventory Levels in a Remote Branch Warehouses

 

 Priority provides a special program that calculates the quantities of all goods that are required to maintain inventory levels in remote branch warehouses operating on consignment (that is, warehouses flagged in the For Consignment column and linked to a customer). After calculating these levels, the program produces a report detailing the required quantities and the resulting new inventory balances. You can also set up the program to open sales orders for all parts that require replenishment. 
 

To learn how to set up and run the Replenish Consignment Warehouses program, run the Consignments Wizard . 
 
## Note:

 

To record minimum and maximum inventory levels per part in the branch warehouse, retrieve the branch in question in the Branches form and enter the Warehouse Inventory Levels sub-level form.
