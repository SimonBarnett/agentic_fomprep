# Assigning Journal Entry Codes to Branches

 

You can create special journal entry codes that apply only to a particular branch (e.g., ROS = Receipt Out-of-State ), and then assign them to that branch. As a result, whenever a user in that branch records a financial document for which a special entry code has been defined, the document will automatically be assigned this entry code. 
 

Moreover, whenever this user records a journal entry manually, those entry codes defined for the user's branch are displayed in the Choose list. 
 
## To assign an entry code to a branch:

 

 1 .  Create a special entry code that applies to a given branch.
 Tip: For detailed information on defining entry codes, run the Set Up Entry Codes Wizard . 
 

 2 .  Enter the Branches form and retrieve the desired branch. 
 

 3 .  Enter the Journal Entry Codes for Branch sub-level form. 
 

 4 .  On the appropriate line, choose the entry code to be applied to the current branch. When a user assigned to that branch opens a financial document for which this entry code has been defined, the document will automatically be assigned this entry code.
