# Assigning Budget Items to Transactions

 

In order to compare budget appropriations with actual expenses or income, you need to assign budget items to specific transactions. There are various ways to do this: 
 

 ·        You can assign a given budget item to virtually any item in a document which generates a financial transaction . This budget item will then appear automatically in any related transaction document. Example. Once the invoice is finalized and a journal entry is opened for it, the budget item will appear automatically in the Itemized Entry form. 
 

 ·        You can assign a budget item to a financial transaction directly in the journal entry; you can even change the budget item in a journal entry after it has been posted to the ledger. 
 

 ·        Depending on how you’ve set up GL accounts for budgets, you can designate the account in a financial document (e.g., an invoice), which will then attach the correct budget item to the transaction. 
 
## Tips:

 

 ·        To prevent users from assigning a budget item that is no longer in use, click to flag it as inactive. 
 

 ·        The easiest way to find the appropriate budget item is to search for it within the budget trees displayed in the Budget Explorer. To access the Explorer, press Shift+F6 from within any Budget Item form column.
