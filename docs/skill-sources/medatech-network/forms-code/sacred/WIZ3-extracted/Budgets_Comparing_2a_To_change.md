Budgets - Changing the Budget Item in a Posted Journal Entry 
 
 
- 
 
 
 
## To change the budget item after the journal entry is posted:

 

 1 .  Enter the Entry Revisions form and retrieve the desired journal entry. 
 

 2 .  Enter the Itemized Revisions sub-level form and move to the desired line. 
 

 3 .  Choose the desired budget item.
 Tip: Use the Budget Explorer to select the budget item. That is, press Shift+F6 from within the Budget Item column. 
 

 Note :  
 

If the Bud NoChange constant is set to 1, you will not be able to change the budget item in entries that fall in a closed fiscal period.
