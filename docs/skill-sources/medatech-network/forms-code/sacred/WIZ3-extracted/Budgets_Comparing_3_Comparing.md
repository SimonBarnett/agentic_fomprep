# Comparing Budgeted vs. Actual Expenses/Income

 

Once budget items have been assigned to transactions for a period of time, you can compare appropriations for budget items with the total sum of actual transactions for that item. 
 
## Notes:

 

 ·        “Actual” expenses/income can include expected expenses/income (e.g., for orders). 
 

 ·        Comparisons are only available for a budget version that is currently in effect. 
 

 ·        To ensure the accuracy of budget usage calculations, it is recommended to run the Calculate Budget Usage program on a daily basis, using the Tabula Task Scheduler. 
 

 ·        In order to compare budgeted vs. actual expenses/income in the format of a P&L report, you must assign budget items to the proper P&L (or balance sheet) item. Click to perform the setup. 
 

 ·        Click for information on how Priority handles end-of-year transactions.
