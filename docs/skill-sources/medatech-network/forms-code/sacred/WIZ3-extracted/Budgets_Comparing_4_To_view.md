# Viewing Budgeted vs. Actual Expenses/Income

 

 For one budget item: 
 

 1 .  Enter the Budget Items form and retrieve the desired item. 
 

 2 .  Do one of the following: 
 

 ·      To view total annual budget usage, enter the Budgeted vs. Actual sub-level form. 
 

 ·      To view monthly budget usage for the current year, enter the Monthly Budget vs Actual-This Yr sub-level form. 
 

 ·      To view monthly budget usage for the previous year, enter the Monthly Budget vs Actual-Last Yr sub-level form. 
 

 Note: Any pending purchasing invoices are included under the category of Unbilled Transactions . 
 
## For all the budget items in a budget:

 

 ·        Do either of the following: 
 

 ·      Prepare one of the Budgeted vs. Actual reports on the Budget Reports menu.
 Note for dual-currency users: If you're working in a language other than English and you change the system language to English (from the Options menu), the report data will appear in English. 
 

 ·      Or run the Budget Explorer . 
 
## To view budgeted vs. actual in a P&L format:

 

 ·        Run the Profit and Loss for Budgets report. 
 

 Tip: Click if you have not yet assigned P&L items to budget items. 
 
## To compare budget items in all companies:

 

 ·        Run the Consolidated Budgeted vs Actual report. 
 
## To view budgeted vs. actual usage in all companies:

 

 ·        Run the Budgeted vs Actual as of Date report. 
 
## Notes : 

 

 ·        D ual-currency users: Click to add VAT to calculations of purchase budget usage (for non-profit organizations) . 
 

 ·        Click to return to the main screen.
