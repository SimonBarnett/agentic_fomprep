# Transferring Budget Balances from the Previous Year

 

You can transfer budget balances from the previous year to the current one. You can also transfer negative balances (for budget items that exceeded their appropriation), thus reducing the appropriation for this item in the current year. 
 

If you want, you can designate certain budget items as multi-year. Then, when running the program that transfers budget balances, you can limit the transfer to those items.
