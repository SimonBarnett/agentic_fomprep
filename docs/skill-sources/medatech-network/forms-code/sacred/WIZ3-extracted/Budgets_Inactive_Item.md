# To flag a budget item as inactive:

 

 1 .  Enter the Budget Items form. 
 

 2 .  Retrieve the budget item in question, making sure it is located at the lowest level of the tree.
 Tips: 
 

 ·      Such an item has a Budget Item Suffix . 
 

 ·      Use the Budget Explorer to select the item. That is, press Shift+F6 from within the Budget Item column. 
 

 3 .  Move to Full-Record Display Mode and click the Definitions tab. Flag the Inactive column. The item will no longer appear in Choose lists of budget items and users will receive a warning message if they try to record it. 
 
## Tip:

 

To turn the warning into an error message, use the Privilege Explorer program. See the Privilege Explorer Wizard for details.
