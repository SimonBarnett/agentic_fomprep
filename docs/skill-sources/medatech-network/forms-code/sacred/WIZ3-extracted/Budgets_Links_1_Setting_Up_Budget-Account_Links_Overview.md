# Linking Budget Items to GL Accounts

 

You can link budget items (i.e., items on the lowest level of the budget tree) to GL accounts in a number of different ways: 
 

 ·      one GL account per budget item 
 

 ·      the same account for several budget items 
 

 ·      the same budget item for several accounts 
 

 ·      one budget item per GL account and profit/cost center 
 

In addition, for any given GL account, you can require users to record a budget item in any financial transaction (e.g., invoice, manual journal entry) involving that account. 
 
## What do you want to do?

 

 Link a single GL account to each budget item 
 

 Link the same GL account to several budget items 
 

 Link the same budget item to several GL accounts 
 

 Link a budget item to a GL account and profit/cost center 
 

 Require users to record the budget item in transactions involving a GL account
