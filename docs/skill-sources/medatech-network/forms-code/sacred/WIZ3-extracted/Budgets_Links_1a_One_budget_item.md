# Assigning One Budget Item to Several GL Accounts – Overview

 

You can assign a single budget item to multiple GL accounts. Example. 
 

If you designate an account when recording a financial transaction (e.g., an invoice), this determines which budget appears as the default to be charged for the journal entry. 
 
## Note:

 

When you work this way, actual expenses/income are only tracked from the time they are recorded in a billed transaction (e.g., the invoice). This is because the account determines the budget item that is charged, rather than the other way around. 
 

This means, for example, that an expense item is not charged to the relevant budget until its invoice is received.
