# One Budget Item per GL Account – Overview

 

If you designate a budget item when recording a transaction (e.g., in a purchase order), this determines which account appears as the default to be debited/credited (e.g., in the invoice). 
 

Similarly, if you designate the account when recording a financial transaction (e.g., in an invoice), the corresponding budget item appears as the default for the journal entry of this transaction. 
 

 Note: 
 

If you also set up default income or expense accounts for families, warehouses, families within warehouses or customer groups, these are overridden by what you set up here.
