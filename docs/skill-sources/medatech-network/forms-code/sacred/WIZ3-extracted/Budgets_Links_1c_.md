# Assigning One GL Account to Several Budget Items – Overview

 

You can assign a single GL account to multiple budget items. Example. 
 

If you designate a budget item when recording a transaction (e.g., a purchase order), this determines which account appears as the default to be debited/credited (e.g., in the invoice). 
 
## Note: 

 

If you also set up default income or expense accounts for families, warehouses, families within warehouses or customer groups, these are overridden by what you set up here.
