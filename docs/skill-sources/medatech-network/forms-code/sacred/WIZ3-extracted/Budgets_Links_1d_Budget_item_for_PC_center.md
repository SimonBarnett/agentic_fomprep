# Linking a Budget Item to a GL Account via a Profit/Cost Center

 

When you link a GL account to a budget item via a profit/cost center, whenever the profit/cost center is specified in a document (e.g., purchase order), the GL account and budget item automatically appear in the financial document (e.g., vendor invoice) based on it. 
 

Similarly, if you specify the profit/cost center when recording a financial document (e.g., sales invoice), this determines the GL account and budget item that appear as the default in the journal entry for that transaction.
