## To link one GL account to several budget items:

 

 1 .  Enter the Budget Items form and retrieve the desired budget items.
 Tip: Use the Budget Explorer to select the budget items. That is, press Shift+F6 from within the Budget Item column. 
 

 2 .  Move to Full-Record Display Mode and click the Definitions tab. For each budget item, in the Account No. column, choose the desired GL account. 
 
## Notes : 

 

 ·        Click to require users to record a budget item in any financial transaction (e.g., invoice, manual journal entry) involving this account. 
 

 ·        Click to return to the main screen.
