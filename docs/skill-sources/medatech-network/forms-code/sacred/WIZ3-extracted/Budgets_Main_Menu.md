# To work with budgets in Priority , you need to perform the following steps:

 

 Define budget constants 
 

 Define business processes (BPM) for budget versions (statuses) 
 

 Build a budget tree 
 

 Link budget items to GL accounts 
 

 Create one or more budget versions and appropriate funds to budget items 
 

 Define checks of budgetary deviation for individual items in a budget version, which override the general default check . 
 

 Authorize the budget and put it into effect 
 

 Assign budget items to transactions 
 

 Manage the transition between fiscal years 
 

 View budget usage (appropriations vs. actual expenses/income) 
 
## Notes:

 

 ·        Click to revise a budget already authorized or in effect 
 

 ·        Click to retroactively update the description of a budget item after revising the level of items in the budget 
 

 ·        Click to define and maintain a special budget.
