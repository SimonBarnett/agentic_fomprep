# To require users to record a budget item:

 

 1 .  Enter the Chart of Accounts form and retrieve the desired GL account. 
 

 2 .  Move to Full-Record Display Mode and then click the Add'l Definitions tab. 
 

 3 .  Flag the Budget Mandatory column. Users will not be able to finalize any document or post any journal entry for this account unless a budget item has been recorded.
