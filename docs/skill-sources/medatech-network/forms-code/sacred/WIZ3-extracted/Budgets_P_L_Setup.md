# Setting Up for the Profit and Loss for Budgets Report

 

In order to compare budgeted and actual expenses/income in a P&L format, you must first assign the appropriate P&L item to each budget item. You have several options: 
 

 ·        You can automatically copy the P&L item from the budget item’s default GL account. 
 

 ·        You can assign a P&L item to each budget item suffix and then copy it to all budget items sharing that suffix. 
 

 ·        You can record the P&L item manually. 
 
## Notes:

 

 ·        Use the same methods to assign any budget item a balance sheet item. Such balance sheet items can then be included with the P&L items in the same report. 
 

 ·        Use the same methods to change the assigned P&L/balance sheet item, if necessary.
