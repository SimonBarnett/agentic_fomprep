Budgets - Setting Up for the Profit & Loss for Budgets Report.2 
 
 
- 
 
 
 
## To copy the P&L item from the default GL account:

 

 ·        Run the Update Budgets' P&L/Bal Sht Item program for the Budget ’s GL Account . 
 
## To assign the P&L item via the budget item suffix:

 

 1 .  Enter the Budget Item Suffixes form. 
 

 2 .  For each suffix, specify a Bal Sheet/P&L Item . 
 

 3 .  Run the Update Budgets' P&L/Bal Sht Item program for the Budget Item Suffix . 
 
## To assign a P&L item manually to individual budget items:

 

 1 .  Enter the Budget Items form. 
 

 2 .  Retrieve the budget item in question, making sure it is located at the lowest level of the tree.
 Tips: 
 

 ·      Such an item has a Budget Item Suffix . 
 

 ·      Use the Budget Explorer to select the item. That is, press Shift+F6 from within the Budget Item column. 
 

 3 .  Move to Full-Record Display Mode and click the Definitions tab. Specify the Bal Sheet/P&L Item .
