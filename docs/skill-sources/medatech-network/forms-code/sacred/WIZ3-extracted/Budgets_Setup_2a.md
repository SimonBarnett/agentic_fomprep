# Comparing Actual With Budgeted Usage

 

You can determine which accounts are considered when the system compares actual usage (journal entries linked to budget items) against the budget appropriation. You can choose to consider all accounts, all P&L accounts, or all P&L accounts plus any balance sheet accounts that are flagged for inclusion in budget calculations. 
 
# To determine which accounts to consider: 

 

 1 .  Move to the BudExpensesOnly constant. 
 

 2 .  Choose the appropriate value from the Choose list.
