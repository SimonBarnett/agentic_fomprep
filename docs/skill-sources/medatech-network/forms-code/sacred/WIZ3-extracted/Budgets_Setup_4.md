# Defining the Budget Currency

 

You can choose to maintain your company budget in either the local or the second currency. 
 
## To define the budget currency:

 

 1 .  Move to the BudgetCurr constant. 
 

 2 .  Do one of the following: 
 

 ·      Leave the default value of 0 to maintain the budget in the local currency. 
 

 ·      Change the value to 1 to maintain the budget in the second currency (e.g., dollars).
