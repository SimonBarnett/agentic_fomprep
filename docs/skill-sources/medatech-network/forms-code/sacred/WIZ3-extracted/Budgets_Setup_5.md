# Modifying Budget Items in Journal Entries from Closed Fiscal Periods

 

You can choose to prevent changes to budget items in journal entries from closed periods. 
 
## To prevent changes to budget items:

 

 1 .  Move to the Bud NoChange constant. 
 

 2 .  Change the value of the constant to 1 . 
 
## Note:

 

The constant also prevents changes to profit/cost centers recorded in journal entries from closed periods.
