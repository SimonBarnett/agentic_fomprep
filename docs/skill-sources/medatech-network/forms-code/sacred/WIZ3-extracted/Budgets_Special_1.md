# Maintaining a Special Budget

 

A special budget is usually a multi-year budget created for a special project (e.g., adding a new wing to a hospital or school). To create a special budget in Priority , you need to define special budget items, appropriate funds and authorize the appropriations. A program is then run periodically to add special budget items to the current budget version and update special budget appropriations, so that each year's special budget appropriations are maintained within the regular budget. You can appropriate further funds for the special budget at any time.
