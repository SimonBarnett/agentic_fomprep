# Defining Special Budget Items

 

Special budget items are defined in the same manner as regular budget items, then flagged in the Special Budget column. 
 

You can then assign the items to main categories or sub-categories in an existing budget, or create new categories for them. 
 

Click to define special budget categories and items.
