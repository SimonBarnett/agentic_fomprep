# Authorizing a Special Budget Appropriation

 

When authorization of special budget appropriations is driven by BPM statuses, you can define rules by which each authorizer is notified when it is his or her turn to sign off. All the authorizer needs to do is to enter the appropriation in question and adjust its status. The next authorizer will automatically be assigned to it and notified. 
 

Alternatively, Priority provides an authorizer list that determines the sequence of authorizations and the persons whose signatures are required.
