# Authorizing a Special Budget Appropriation via an Authorizer List

 

Just as with BPM statuses, the first user on the authorizer list is automatically notified by e-mail when the relevant status is assigned to a special budget appropriation. When the first authorizer signs, the second user is notified and so on. Larger appropriations usually require the signature of senior authorizers, whereas the signatures of users at the top of the list will suffice for smaller ones. Furthermore, it is not mandatory to sign in sequence. Once a senior authorizer signs the appropriation, users appearing earlier in the list need not sign. 
 

The default 00 authorizer list is used automatically. If you work with multiple authorizer lists, you need to revise this value. 
 
## To change the authorizer list:

 

 1 .  Retrieve the appropriation in question in the Special Budget Appropriations form and click the Authorization tab. 
 

 2 .  Choose the appropriate list in the Authorizer List Code column. 
 
## Tip:

 

Click to create a new authorizer list.
