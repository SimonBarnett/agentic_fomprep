Budgets - Adding an Authorizer List for Special Budget Appropriations 
 
 
- 
 
 
 
# To add an authorizer list:

 

 1 .  Enter the Auth. Lists for Special Budgets form. 
 

 2 .  Record a code and a short description for the new list. 
 

 3 .  Enter the Special Budget Authorizers sub-level form and record each authorizer' s username, an alternate authorizer (where applicable) and the amount above which this user’s authorization is required.
 Note: The amount specified in the Starting From (Amt) column is checked against the value in the Appropriated Amount column of the budget item in the Special Budget Appropriations form.
