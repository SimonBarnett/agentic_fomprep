# Building a Budget Tree

 

Budget planning in Priority is executed by appropriating funds to budget items in a budget version. Each budget version represents a different variation of the organization’s annual budgetary plan. Budget items represent the organization’s specific expenses or revenues, which form the bottom level of the budget’s hierarchical structure, known as the budget tree . 
 

As stated previously, the budget tree consists of three major elements: main categories (corresponding to Priority ’s Level 1 budget values); optional sub-categories (Levels 2-4); and budget items, which are specified by adding user-defined suffixes to the code of the budget category to which they are assigned. Budget items can be assigned directly to a main budget category, or to a sub-category on any level of the hierarchy. Example. 
 

The appropriation of funds and tracking of budget usage take place on the lowest level of the budget tree, that of the specific budget items. Since each level of the budget tree is linked directly to the levels immediately above and below it, the system can display the total allocation and usage for each category and sub-category in the tree. 
 

The first step in building a budget tree is defining the values that will be assigned to each level of the tree, including the suffixes that distinguish the actual expenses or revenues.
