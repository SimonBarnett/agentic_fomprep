# Setting Up Item Suffixes

 

Suffixes are used to distinguish the lowest level of the budget tree, which contains the actual budget items. These are usually items that are repeated among the tree’s various sub-categories. In order to increase the efficiency of both budget maintenance and financial reporting, Priority allows you to create a uniform set of suffixes for these items, so they are easily recognized wherever they occur. 
 

For example, if the lowest sub-category in the tree corresponds to the company’s branch offices (that is, each office is allocated its own budget), you can define suffix 001 for salaries, 002 for office expenses, 003 for network maintenance, etc. 
 

You can further categorize budget item suffixes into suffix types ; for example, 01 could represent all domestic expenses, 02 all international expenses and 99 all revenues. 
 
## To define budget item suffix types:

 

 1 .  Enter the Budget Suffix Types form. 
 

 2 .  Define a code and description for each possible budget type.
 Note to dual-currency users: If you are working in a language other than English, and want to produce budget reports in English, record an English description in the Type Desc ( Lang 2) column. 
 
## To define budget item suffixes:

 

 1 .  Enter the Budget Item Suffixes form. 
 

 2 .  Define a code and description for each possible budget item suffix.
 Notes: 
 

 ·      This code serves as a component in budget item codes. It is advisable to take this into consideration now, as the number of characters used for budget items is limited to the width of the Budget Item column in the Budget Items form. 
 

 ·      D ual-currency users: If you are working in a language other than English, and want to produce budget reports in English, record an English description in the Suffix Desc ( Lang 2) column. 
 

 3 .  Assign a Budget Suffix Type , if desired.
