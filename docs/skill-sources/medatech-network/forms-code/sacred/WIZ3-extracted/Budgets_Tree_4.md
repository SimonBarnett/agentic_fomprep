# Defining a Budget Tree

 

When defining a budget in Priority , start at the top with the main budget categories, then expand downwards to sub-categories and actual budget items. 
 
## To define main categories:

 

 1 .  Enter the Budget Items form and move to Full-Record Display Mode . 
 

 2 .  In the Level 1 column (in the Budget Structure tab), select one of your predefined values from the Choose list. The value’s description will appear automatically. 
 

 3 .  Flag the Generate Budget Item column and move to any other column. The Budget Item and Description columns are filled in automatically. 
 

 4 .  Do one of the following: 
 

 ·      If the current category is for a sales budget, specify S in the Type of Budget column. 
 

 ·      If the current category is for a purchasing budget, specify P in the Type of Budget column. 
 

 ·      If you are planning to assign to this category sub-categories that include both sales budget and purchasing budget items, specify B in the Type of Budget column.
 Note: You can only specify B in a main category, or a sub-category directly under another Type B category.
