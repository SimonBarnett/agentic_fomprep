# To define sub-categories:

 

 1 .  Open a new record in the Budget Items form. 
 

 2 .  In the Level 1 column, press F10 to copy the value that you selected for the main category in the previous record. 
 

 3 .  In the Level 2 column, select one of your predefined values from the Choose list. The value’s description will appear automatically. 
 

 4 .  Flag the Generate Budget Item column and move to any other column. The Budget Item and Description columns are filled in automatically, and the Type of Budget column is copied from the previous record.
 Note: If the budget type of the main category is B , you can use any one of the three budget types ( S , P or B ) to define this sub-category. 
 

 5 .  Repeat these steps for each Level 2 sub-category of the current main category. 
 

 6 .  Open records for any additional sub-categories of the current main category, using the Level 3 and Level 4 columns.
