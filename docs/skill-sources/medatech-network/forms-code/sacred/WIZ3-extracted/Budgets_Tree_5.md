# To define budget items:

 

 1 .  Open a new record in the Budget Items form. 
 

 2 .  In the Level 1 column, fill in the main category to which the current expense or revenue is assigned. 
 

 3 .  Use the remaining columns to fill in any intervening sub-categories between the main category and the item. 
 

 4 .  In the Suffix column, select the appropriate value from the Choose list. The suffix description appears automatically. 
 

 5 .  Flag the Generate Budget Item column and move to any other column. The Budget Item and Description columns are filled in automatically, and the Type of Budget column is copied from the main category.
 Note: If the budget type of the category to which this item belongs is B , you can use either the S (sales) or P (purchasing) budget type. 
 

 6 .  If the budget item is for a special budget, flag the Special Budget column.
