# Putting a Budget Version into Effect

 

Only one version of a budget can be in effect at a time for any given fiscal year. All other versions are considered to be drafts. Consequently, putting a given version into effect invalidates the existing version for that fiscal year. You can only make limited changes to a version that is in effect. 
 

 Priority calculates comparisons of budget appropriations with actual expenses/income only for the version that is in effect, even if it has replaced a different version that had been in effect for that fiscal year. 
 
## To put a budget version into effect:

 

 1 .  Enter the Budget Versions form and move to the desired budget version. 
 

 2 .  Change the version status to In Effect . The version that was previously in effect will automatically be assigned the Out of Effect status. 
 
## Notes : 

 

 ·        To add special budget items to the current budget version, and to routinely update special budget appropriations in the budget version, select Update Special Budget Items from the list of Direct Activations. 
 

 ·        Use the Change Version in Effect/Auth'd form to revise an authorized budget version. 
 

 ·        To view a history of all budget versions that were in effect for any given fiscal year, move to a budget version from that year in the Budget Versions form and enter the History of Versions in Effect sub-level form.
