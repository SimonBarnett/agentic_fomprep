# Creating Budget Versions and Appropriating Funds – Overview

 

You can create an unlimited number of versions of any budget. Only one of these versions can be in effect in any given fiscal year. 
 

Budget versions are generally distinguished by their monetary appropriations. 
 

Using budget versions allows you to be flexible about changing and planning budgets. For example, you can decide halfway through the year to revise the current budget if one division overspends. Or you can plan the budget for the coming fiscal year based on this year’s budget. 
 
## Note:

 

Since appropriations are made for each budget version, you must define a budget version even if you only plan to use one.
