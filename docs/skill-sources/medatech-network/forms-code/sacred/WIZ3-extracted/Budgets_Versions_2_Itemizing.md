# Itemizing the Budget Version

 

Itemizing a budget version consists of the following steps: 
 

 ·        Specifying which budget items are included in the budget version 
 

 ·        Defining top-down target sums for main and sub-categories (optional) 
 

 ·        Appropriating funds to each budget item. 
 

The method to use depends on how similar this budget version is to an existing one – either you are itemizing the budget for the first time, copying the budget items from an existing version and recording appropriations manually, or copying an entire version and revising the appropriations. 
 
## What do you want to do?

 

 Itemize the budget version manually 
 

 Copy the budget items from an existing budget version 
 

 Copy the budget items with their appropriations from an existing version
