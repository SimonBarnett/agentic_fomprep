Budgets - Creating a New Budget Version.1 
 
 
- 
 
 
 
## To create a new budget version:

 

 1 .  Enter the Budget Versions form. 
 Note: At any point in the following process, you can transfer handling of the version to another employee, by specifying his/her username in the Assigned to column. 
 

 2 .  Record a fiscal year, a code representing the version (e.g., 2005a, 2006) and a description. 
 

 3 .  Leave the line. 
 
## Note: 

 

To delete a budget version, run the Delete Budget Version program.
