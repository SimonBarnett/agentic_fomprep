## To include budget items in the version:

 

 1 .  Run the Add Budget Items to Version program. 
 

 2 .  Enter the Budget Versions form and move to the new version. 
 

 3 .  Enter the Appropriations for Budget Items sub-level form to view and revise budget items in the new version. 
 

 4 .  Click to define budget targets for the new version .
