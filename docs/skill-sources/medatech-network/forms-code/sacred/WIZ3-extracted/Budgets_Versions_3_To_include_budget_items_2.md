# To appropriate funds to budget items:

 

 1 .  Enter the Budget Appropriations form and retrieve the desired budget items.
 Tip: Retrieve by the version. 
 

 2 .  Do one of the following: 
 

 ·      If monthly appropriations are identical, in the Sum column, record an appropriation for the entire year. OR 
 

 ·      If appropriations differ from one month to another, record each monthly appropriation in columns Period 1 through Period 12 . 
 

 3 .  Run the Print Budget Version (Tree) report to view budget appropriations and compare them with the targeted amounts. 
 

 4 .  If adjustments are required, return to the Budget Appropriations form and revise the appropriations in question. 
 

 5 .  When all appropriations have been made, return to the Budget Versions form and change the Status of the new version (e.g., to Ready, so it can be authorized). 
 
## Notes:

 

 ·        To compare appropriations in different versions of the same budget, run the Comparison of Budget Versions report. 
 

 ·        Click to return to the main screen.
