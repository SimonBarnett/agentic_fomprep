## To copy items and appropriations automatically:

 

 1 .  Run the Copy Version Incl. Appropriation program. 
 

 2 .  Enter the Budget Versions form and move to the new version. 
 

 3 .  Click to define budget targets for the new version . 
 

 4 .  Run the Print Budget Version (Tree) report to view budget appropriations and compare them with the targeted amounts. 
 

 5 .  Do one of the following: 
 

 ·      If the results are satisfactory, return to the Budget Versions form and change the Status of the new version (e.g., to Ready, so it can be authorized). 
 

 ·      Click if you need to make any changes to the results of the program (add/remove budget items; change appropriations). 
 
## Notes:

 

 ·        To compare appropriations in different versions of the same budget, run the Comparison of Budget Versions report. 
 

 ·        Click to return to the main screen .
