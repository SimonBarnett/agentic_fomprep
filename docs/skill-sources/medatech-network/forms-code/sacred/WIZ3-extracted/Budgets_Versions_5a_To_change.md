# Changing the Results of the Program

 
## To add or remove budget items:

 

 1 .  Enter the Budget Appropriations form and retrieve the desired budget items.
 Tip: Retrieve by the version. 
 

 2 .  Remove any budget items you do not need, and add any that you need.
 Note: If you add items, remember to record appropriations for them. 
 
## To change budget appropriations:

 

 1 .  In the Budget Appropriations form, retrieve the desired budget items. 
 Note: If you need to see appropriations for the same item in different versions, instead enter the Budget Items form, retrieve the desired item and enter the Appropriation per Budget Version sub-level form. 
 

 2 .  Change appropriations, as needed. 
 

 3 .  Run the Print Budget Version (Tree) report to compare appropriations with budget targets. 
 

 4 .  If additional adjustments are required, return to the Budget Appropriations form and revise the appropriations in question. 
 

 5 .  When all appropriations have been made, return to the Budget Versions form and change the Status of the new version (e.g., to Ready, so it can be authorized). 
 
## Notes:

 

 ·        To compare appropriations in different versions of the same budget, run the Comparison of Budget Versions report. 
 

 ·        Click to return to the main screen .
