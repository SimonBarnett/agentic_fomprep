# Budgets_Versions_6_To_copy

Budgets - Creating a New Budget Version.5 
 
 
- 
 
 
 
## To copy budget items from an existing budget version:

 

 1 .  Run the Copy Version W/out Appropriation program. 
 

 2 .  Enter the Budget Versions form and move to the new version. 
 

 3 .  Enter the Appropriations for Budget Items sub-level form to view and revise the budget items. 
 

 4 .  Click to define budget targets for the new version . 
 
## To appropriate funds to the budget items:

 

 1 .  In the Appropriations for Budget Items form, do one of the following: 
 

 ·      If monthly appropriations are identical, in the Sum column, record an appropriation for the entire year. OR 
 

 ·      If appropriations differ from one month to another, record each monthly appropriation in columns Period 1 through Period 12 . 
 

 2 .  Run the Print Budget Version (Tree) report to view budget appropriations and compare them with the targeted amounts. 
 

 3 .  If adjustments are required, return to the Appropriations for Budget Items form and revise the appropriations in question. 
 

 4 .  When all appropriations have been made, return to the upper-level Budget Versions form and change the Status of the new version (e.g., to Ready, so it can be authorized). 
 
## Notes:

 

 ·        To compare appropriations in different versions of the same budget, run the Comparison of Budget Versions report. 
 

 ·        Click to return to the main screen .
