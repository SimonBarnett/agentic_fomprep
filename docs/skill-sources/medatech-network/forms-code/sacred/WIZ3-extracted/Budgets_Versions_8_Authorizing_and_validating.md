# Authorizing and Validating Budget Versions

 

 Priority offers you the option of requiring budget versions to be authorized. Specifically, the budget version must be authorized before it can be put into effect. You can set up a single authorizer, or multiple authorizers with a designated sequence in which they must sign. 
 
## What do you want to do?

 

 Define budget authorizers 
 

 Authorize a budget version 
 

 Put a budget version into effect (if it has been fully authorized or does not require authorization) 
 

 Revise a budget version that has been authorized or put into effect
