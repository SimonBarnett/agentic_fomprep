# Defining Targets for Budget Categories

 

 Priority provides a form in which upper management can outline the company’s budget from the top down, starting with the total annual budget and dividing it among the various main and sub-categories. This is particularly useful for companies in which middle managers are responsible for appropriating funds to their own departmental budgets. After the funds have been appropriated, you can run a report comparing budget targets to the actual appropriated sums. 
 
## To define budget targets:

 

 1 .  Enter the Budget Target (Top Down) sub-level of the Budget Versions form. 
 

 2 .  In the Budget Item column, select a main category (e.g., 1) from the Choose list. 
 

 3 .  Specify a Targeted Amount representing the desired sum total for all budget items within the current main category. 
 

 4 .  If desired, open a new line and select a sub-category of the current main category (e.g., 1.1). 
 

 5 .  Flag the Bal of Upper Level column and move to the adjacent Targeted Amount column, which now displays the remainder of the main category’s target amount that is available to the current sub-category (if this is the first sub-category you are defining, the full amount appears). Revise it to the desired target. 
 

 6 .  Open a new line for each parallel sub-category (e.g., 1.2, 1.3) and lower-level sub-category (e.g., 1.2.1, 1.2.1.1) and repeat Step 5.
