# Retroactively Updating a Budget Item Description 

 

When budget items are generated, the budget item description is filled in automatically, based on the descriptions of the upper-level categories to which it is assigned (e.g., "Level 1 Description," "Level 2 Description"), separated by commas. If you later revise the level of the items in a given budget, you can run a special program that updates the description of the affected budget items automatically. 
 
## To update a budget item description:

 

 ·        Run the Update Budget Item Desc by Level program, and specify the budget item(s) whose description you want to update.
