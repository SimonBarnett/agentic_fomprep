# Revising a Budget Version Already Authorized or in Effect 

 

Once a budget version has been authorized and/or is in effect, you need to use a special form to revise it. 
 
## Note:

 

If the version in effect is next year’s budget, it is not necessary to use this special form. Instead, you can take the version out of effect, make the necessary changes in the regular form and then put the version back into effect. 
 
## To revise a budget version once it is in effect/authorized:

 

 1 .  Enter the Change Version in Effect/Auth'd form. 
 

 2 .  Retrieve by the Budget Item and the Version Number .
 Tip: Use the Budget Explorer to select the budget item. That is, press Shift+F6 from within the Budget Item column. 
 

 3 .  Change appropriations, as needed.
 Note: You can also delete items, if no appropriations have yet been recorded for them.
