# Defining Deviation Checks

 

Beyond the default definition of budgetary deviation checks, as determined by the BudCheck constant, you can define the type of checks to be made against: 
 

 ·        specific budget items 
 

 ·        the parent category of a given item (i.e., the category one level above). Example. 
 

 ·        the category two levels above a given item. 
 

In the latter two cases, when the item to be checked deviates from its appropriation, the entire category to which it is assigned is checked in turn. If the sum total of expenses or revenues does not deviate from the appropriations for that category, no error or warning is issued. 
 
## Note:

 

If the budget is exceeded, users who have been authorized to deviate from it (in the Users Authorized for Deviation form) will receive a warning rather than an error message. 
 
## To revise the default deviation methods:

 

 1 .  Enter the Budget Items form and move to the item in question: either a specific budget item you want to check, or any budget item in a category you want to check. 
 

 2 .  Move to Full-Record Display Mode . 
 

 3 .  Click the Definitions tab, and select the appropriate value in the Check Budget Deviatn column. 
 

 4 .  Select the appropriate value in the Budget Check Level column. 
 
## Note: 

 

To prevent checks of a given budget item, select 0 in the Check Budget Deviatn column.
