# Distributing Shipping and Other Expenses 

 

When the costing program calculates the cost of a purchased part, it also takes into account expenses related to the receipt of the part (e.g., shipping, storage). 
 

Additional expenses are defined in the part catalogue as non-inventory parts, and assigned a burden type . 
 

You can distribute additional expenses in a variety of ways: 
 

 ·        Include the expense as an item in the purchase invoice itself. 
 

 ·        Record the expense as in item in a separate invoice, linked to the purchase invoice. 
 

 ·        Record a shipping voucher , linked to the purchase invoice and expense invoice (shipping vouchers allow for a more complex distribution of costs). 
 

 ·        Dual-currency users only: Link shipping costs and import duties to the release of goods from a bonded warehouse . 
 
## Notes:

 

 ·        If no additional costs are recorded using any of the above methods, the standard shipping cost, defined in the system as a percentage of the part's purchase price, is added to the cost of the inventory receipt transaction (and to the part's calculated standard cost). 
 

 ·        For detailed information regarding the distribution of expenses, run the Shipping Expenses Wizard .
