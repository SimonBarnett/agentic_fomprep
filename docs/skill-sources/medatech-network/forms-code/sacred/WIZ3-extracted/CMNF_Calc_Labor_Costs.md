# Labor Costs

 

Labor costs are calculated on the basis of the actual number of employees and work hours recorded in production reports, taking into account the following factors: 
 

 ·        Unskilled employees: Direct and indirect work hour costs for unskilled employees are taken from the standard costs recorded for a given work cell or for all work cells in a given department. 
 

 ·        Skilled Employees: The costing program takes into account the skill defined for each employee involved in the work order and calculates the direct and indirect cost of work hours for each skill. 
 

 ·        Shifts: If a special rate of cost is defined for a certain shift, labor costs are adjusted for the production report, operation or employee for which the shift is reported. If, for example, a rate of 150% is defined for the night shift, and an operation is reported for that shift, the total labor cost of the operation is multiplied by 1.5. 
 
## Step 1: Actual Cost Per Work Order 

 

 Work Order 0011 requires two skilled engineers and is manufactured during a regular shift. If the direct cost of an engineer work hour is $25, and each engineer devotes 2 hours to the production operation, the direct cost of labor calculated for the work order will be $100. If the indirect cost of an engineer work hour is $1, the indirect cost of labor calculated for the work order will be $4. The labor cost for the work order will thus be $104. 
 
## Step 2: Actual Cost Per Work Order Item 

 

Labor cost per part unit is calculated by dividing the overall cost of labor for the work order by the quantity of finished parts. If 150 units are manufactured for this work order, the labor cost will be $0.69 (104/150) per unit. 
 
## Step 3: Average Labor Cost 

 

The actual labor cost for one part unit is determined by calculating the total labor cost of all closed work orders for the part, and dividing it by the number of finished parts.
