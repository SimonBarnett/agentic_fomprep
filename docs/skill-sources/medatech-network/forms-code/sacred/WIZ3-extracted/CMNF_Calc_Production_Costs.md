# Calculating Actual Production Costs 

 

There are five basic categories of production costs: machine cost, labor cost, setup cost, rework cost and additional costs – which together comprise the actual production cost of a part or work order. The same method is used to calculate each type of cost, as illustrated in the following example, which applies the method to setup costs : 
 

 1 .  The setup costs of each closed work order and its child work orders are totaled separately. 
 

 2 .  To calculate the work order setup cost per part unit, the total setup cost is divided by the finished quantity (the quantity used is the greatest number of parts reported as completed in one of the routing operations). 
 

 3 .  The average setup cost per part unit is calculated on the basis of the sum total of setup costs for all closed work orders. The result is the part's actual (average) setup cost. 
 

Machine, labor, rework and additional costs are calculated in the same manner for all work orders and all parts.
