# Setup Costs

 

Setup costs are composed of direct and indirect costs, related to both the machine time and labor time required for setup operations. 
 

 ·        Costing calculates actual setup cost on the basis of production reports marked with an S in the Set-up/Break column, multiplying machine time by setup cost, and labor time by each employee's direct and indirect labor cost, as recorded in production reports. 
 

 ·        Costing calculates standard setup cost on the basis of setup time (as a fixed percentage of machine time) and the mount and dismount times defined as parameters for the manufactured part. The total time is then multiplied by the defined hourly setup cost.
