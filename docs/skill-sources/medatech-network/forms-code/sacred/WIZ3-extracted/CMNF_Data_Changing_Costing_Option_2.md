# To change a part's costing option:

 

 1 .  After you have determined a date for the transition, record a past balance and run costing for that date . 
 

 2 .  Enter the Parts - Std Costs form and retrieve the desired part.
 Tip: To retrieve all manufactured parts, use P in the Type (P/R/O) column. 
 

 3 .  For each part whose calculation method you want to change, specify the desired method in the Costing Option column.
