# Viewing and Updating Last Prices 

 

The last recorded part price can be used to update a part's standard cost. Last prices can be updated manually, automatically by a special program (in the case of processed parts) or by Direct Activation from transaction documents (e.g., purchase order, purchase invoices, GRV), even before they are finalized. 
 
## To view and update last prices:

 

 1 .  Enter the Part Prices form and retrieve the desired parts. 
 

 2 .  Record a new value in the Last Price column. If the price is in a foreign currency, specify the Currency . 
 
## To calculate and update the last price of specific processed parts:

 

 ·        Run the Calculate/Update Last Price program for the desired part(s). 
 
## To analyze the last price of specific processed parts, including the last prices of all child parts:

 

 ·        Run the Analysis of Last Price report for the desired part(s).
