# Updating Lot Costs 

 

The cost of a lot is calculated according to the purchase price recorded in the invoice in which the lot is billed. It can be updated manually. 
 
## Note: 

 

If you want to update the cost of a part as of a previous past balance (not the last), you need to cancel all costing runs since the date of that past balance, and run costing again for all intervening past balances. You should consult with implementation or support personnel before making any such deletions. 
 
## To update lot costs:

 

 1 .  Enter the Lot Costing form and retrieve the desired part or part lot. 
 

 2 .  Record a new value in the Cost/Costing Unit column. Dual-currency users can choose either the local- or second-currency Cost/Costing Unit columns, according to their company's method of price management; the corresponding Cost/Lot column will then be updated. 
 Note: If you specify the cost of a part in both the local- and second-currency Cost/Costing Unit columns, you thereby set the exchange rate for that part. That is, costing reports will display its local-currency costs according to the exchange rate derived from the values recorded here, and not according to the exchange rate in effect on the report date. 
 
## Note:

 

Manual revisions of the cost of a raw material lot only affect incoming inventory cost, part cost and inventory value if the Consider Lots option was chosen when the Set Costing Parameters program was run. In such cases, the cost source of the lot cost changes from "Invoice" to "Lot".
