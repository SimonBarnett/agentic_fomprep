# Maintaining Costing Data

 

 Costing Analysis for Manufacturers uses a wide variety of data in its calculations. Generally, these data are recorded during initialization of the costing system; however, these initial definitions can be updated at any time, for example, when standard costs or shipping costs are revised. Sometimes new data is required, such as standard costs for new parts, standard labor and machinery costs and times for a new work cell, or costing settings for a new warehouse. You can also change the costing option by which the actual cost of any given manufactured part is calculated. 
 

If the costing program produced an inaccurate cost, you can try to identify the source of the error (e.g., an incorrect standard cost, an error committed when recording an invoice or defining processing parameters), and correct the error manually. Then run costing again to recalculate the part cost correctly.
