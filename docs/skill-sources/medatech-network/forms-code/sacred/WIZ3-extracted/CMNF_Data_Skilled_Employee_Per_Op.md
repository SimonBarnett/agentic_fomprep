# To define skilled employees for the operation: 

 

 1 .  Enter the Skilled Labor for Operation sub-level of the Operations form. 
 

 2 .  For each Skill , specify the number of skilled employees required to perform the operation in the No. Skilled Workers column.
 Note: Use the Skills form to record additional skills. 
 
## Note:

 

Skilled employee work time is calculated by multiplying the machine time ( T ) by the number of skilled employees. If several employees with the same skill can perform a number of operations simultaneously, the recorded number of employees is relative to the number of operations they perform. Example . Similarly, if skilled employees are only required for part of the time the machine is running, the recorded number of employees is relative to the machine time. Example.
