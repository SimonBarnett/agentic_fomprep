# Standard Labor and Machine Settings

 

Select one of the following options to update the standard cost and/or time of labor and machinery in existing work cells, or to define these parameters for new work cells. 
 
## Tip:

 

Click for a detailed explanation of standard labor/machinery definitions. 
 
## What do you want to do?

 

 Define or update standard costs for unskilled employees and machines 
 

 Define or update standard costs for skilled employees 
 

 Define standard labor and machine time for a new operation 
 

 Define standard labor and machine time for an operation, per part 
 

 Update the cost of work shifts 
 

 Record a time factor 
 
## Notes:

 

 ·        Click to update the cost of work shifts (affects actual labor cost) 
 

 ·        Click to return to the Costing Data Menu.
