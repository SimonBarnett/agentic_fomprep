Costing for Manufacturers - Data: Updating the Cost of a Work Shift 
 
 
- 
 
 
 
# To update the cost of a work shift:

 

 1 .  Enter the Shifts form and retrieve the desired shift. 
 

 2 .  In the Rate (%) column, revise the percentage by which to multiply actual labor costs for employees working this shift (e.g., 125% , 150% ).
