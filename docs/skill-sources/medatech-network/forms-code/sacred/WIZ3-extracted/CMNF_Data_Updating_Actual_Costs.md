# Correcting Actual Costs Calculated in the Last Costing Run

 

 Priority offers a mechanism that allows you to correct the actual costs of processed parts in the latest costing run. 
 
## To correct actual costs:

 

 1 .  Enter the Initial Product Costs form and retrieve the desired part or parts. 
 

 2 .  Record new part costs per costing unit. Dual-currency users can choose either the local- or second-currency Cost columns, according to their company's method of price management.
 Note: If you specify the cost of a part in both the local- and second-currency Cost columns, you thereby set the exchange rate for that part. That is, costing reports will display its local-currency costs according to the exchange rate derived from the values recorded here, and not according to the exchange rate in effect on the report date. 
 

 3 .  Run the Update PartCost by Initial Costs program.
 Note: Running costing again for the previous past balance date will overwrite any values updated by the Update PartCost by Initial Costs program in the current costing period.
