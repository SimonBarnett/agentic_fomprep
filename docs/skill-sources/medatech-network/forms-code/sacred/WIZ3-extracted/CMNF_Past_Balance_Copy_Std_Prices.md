# To copy standard costs: 

 

 1 .  Run the Update Part Costs program and select the Std by Vendor Prices , Std by Last Price or Std by Actual Cost option.
 Notes: 
 

 ·              To update standard costs that were recorded manually, flag the Update User-Defined input column. 
 

 ·              In the case of the Std by Vendor Prices option, choose between using the preferred vendor's price list or a specific user-defined price list. For assistance in setting up preferred vendors, run the Vendor Parts and Prices Wizard . 
 

 2 .  After running the program, enter the Parts - Std Costs form and retrieve all raw materials ( R in the Type (P/R/O) column). 
 

 3 .  Check the standard part prices in the Std Cost column. Fill in any missing prices.
