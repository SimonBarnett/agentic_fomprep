# Rerunning Costing for an Early Date

 

Sometimes costing for a past balance can produce inaccurate data. This might be the case, for instance, if, at the time of past balance calculations, there is a work order that has been begun but not completed. Thus, the finished parts are assigned the average part cost rather than the proper work order cost. To rectify this problem once the work order is closed, you need to rerun costing as of the earliest past balance date for which costing data requires revision. 
 

In order to solve the problem, you first need to determine the past balance as of which to rerun costing. You then need to rerun costing for that date, deleting and recalculating all subsequent costing data. 
 
## To run costing for an early date:

 

 1 .  Enter the View Reported Production form, and move to the Date Closed column. 
 

 2 .  Retrieve the production reports recorded for work orders that were closed recently. 
 

 3 .  Sort the production reports by D ate , in order to identify the earliest report date for the recently closed work orders. 
 

 4 .  Run costing for the date of the past balance covering the period in which the earliest production report was recorded. Flag the All Past Balances column to rerun costing for all subsequent past balance dates.
