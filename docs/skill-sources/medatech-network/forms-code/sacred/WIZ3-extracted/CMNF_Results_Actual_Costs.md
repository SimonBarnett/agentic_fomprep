# Actual Costing of Manufactured Parts

 

The actual cost of each manufactured part is determined by the method of cost calculation assigned to that part: 
 

 ·        By work orders: By default, cost is based on all work orders closed since the last costing run. If no work order was closed, the cost of the part is taken from the previous run. If there are no closed work orders the first time costing is run, the BOM method is used. 
 

 ·        By BOM: In this method, the standard quantities of child parts (i.e., those recorded in the BOM) are multiplied by their actual costs, and added to the standard production costs. 
 

Usually, you assign W to all parts for which work orders are maintained. This method is most effective when work order definitions, part issues and production reports are orderly and complete. If they are not, you should use option T to calculate actual costs. It is advisable to use option T when you first begin to work in the system, then switch to option W when your company's production control system is running smoothly. 
 Note: You should only switch the costing option at the beginning of a new costing period .
