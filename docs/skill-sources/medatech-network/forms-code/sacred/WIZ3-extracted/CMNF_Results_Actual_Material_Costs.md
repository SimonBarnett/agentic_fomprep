# Viewing Actual Raw Material Costs

 

The actual cost of raw materials is calculated on the basis of the transactions by which they enter and leave inventory, according to the defined costing method ( Moving Average or FIFO ). If no incoming inventory transactions were recorded for an item, or if all such transactions were recorded with no cost, the part's cost in the previous past balance is used. If no cost was calculated for the part in the previous past balance, then its actual cost is taken from its standard cost. 
 

If you chose to take lots into account when defining costing parameters, you can view the cost of each purchased raw material lot. The costing program assigns these costs as inventory values to the part balance in each lot. 
 
## To view raw material costs:

 

 ·        Enter the Material Costing form and retrieve the desired parts. Retrieval tips. 
 

 OR 
 

 ·        Run the Material Costing report. 
 
## Notes:

 

 ·        In the dual-currency package, the form displays the local-currency cost, the second-currency cost, and the average adjusted cost calculated by costing (which may be revised, if necessary). Click for more information on indexing and price adjustment . 
 

 ·        To view the inventory transactions used to calculate the cost of a raw material, use the Material Transactions sub-level of the Material Costing form. 
 
## To view lot costs:

 

 ·        Enter the Lot Costing form and retrieve the desired part or part lot. 
 

 OR 
 

 ·        Run the Lot Costing report. 
 
## Note:

 

If you have set the costing program to ignore lot costs , the form and the report do not reflect the calculation of inventory value performed by the costing program.
