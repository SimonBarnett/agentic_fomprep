# Viewing Actual Costs of Manufactured Parts

 
## To view a part's total actual cost:

 

 ·        Enter the Product Costing form and retrieve the desired parts. Retrieval tips. 
 

 OR 
 

 ·        Run the Product Costing report. 
 
## To view the breakdown of component costs:

 

 ·        Enter the Product Cost Components sub-level of the Product Costing form. 
 

 OR 
 

 ·        Run the Product Cost Components report. 
 
## To analyze actual cost calculations for manufactured parts with costing option W:

 

 ·        Enter the Product Cost Components sub-level of the Product Costing form. This form displays the work orders by which each part was manufactured, and their costs. 
 
## To analyze actual cost calculations for manufactured parts with costing option T:

 

 ·        You can view an approximation of actual costing calculations for T parts by running the Standard Cost Analysis report, when Actual Material Cost is the defined standard costing option. 
 Tip: Run the Set Costing Parameters program to check the defined option. If the Std Material Cost option is defined, change it for the sake of this analysis, and run the report. Then return to the previous option.
