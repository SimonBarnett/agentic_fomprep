# Viewing Work Order Costs

 

You can view the total cost of a work order, as well as the breakdown into its various component costs. 
 
## To view total work order costs:

 

 ·        Enter the Work Order Costing form and retrieve the work order in question, or run the Work Order Costing report. 
 
## To view the work order's actual production costs:

 

 ·        Enter the Work Order Cost Components sub-level of the Work Order Costing form.
 Note: Click for detailed information regarding the calculation of production costs. 
 
## To view the child parts issued to the work order:

 

 ·        Enter the Issues to Work Order sub-level form of the Work Order Costing form, or run the Issues to Work Orders report.
 Note: Both the form and the report display each part in the work order kit list that was reduced from inventory, as well as its cost . If a part was not reduced for some reason (e.g., missing issues were created), it does not appear and will not affect the work order cost.
