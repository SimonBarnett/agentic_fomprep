# Viewing Inventory Transaction Costs 

 
## To view the cost of a particular inventory transaction:

 

 1 .  Enter the Audit Trail form. 
 

 2 .  Retrieve the inventory transaction in question (e.g., by document number, document date, part number), and move to the Cost Source column to view the source of the inventory transaction cost. 
 
## Note: 

 

Transaction costs recorded manually in the Audit Trail form are not updated by the costing program. 
 
## To view the inventory transaction costs used to calculate the cost of a raw material:

 

 ·        Run the Actual Cost Analysis report. 
 

 OR 
 

 1 .  Enter the Material Costing form. 
 

 2 .  Retrieve the desired part, by Part Number and Costing Date . 
 

 3 .  Enter the Material Transactions sub-level form. This form displays the inventory transactions included in calculations of the part cost. 
 

 4 .  For each inventory transaction, check the Cost and Cost Source .
 Notes: 
 

 ·              To view an explanation of each cost source, press F6 to enter the Cost Sources form. 
 

 ·              If you encounter an unusual transaction cost (for example, the cost is unusually high), press F6 from the Document Number column to check the original financial document. 
 

 ·              If documents are recorded in the system for which pending multi-GRV invoices were opened, or for which no invoices were opened, when costing was run, initial costs are calculated according to the hierarchy of cost sources. If you costing again for the same date after invoices have been closed for these documents, the cost of the inventory transaction is updated accordingly.
