# Inventory Valuation

 

For each manufactured part, the costing program calculates three different inventory values: standard, costing and materials, as displayed in the Product Inventory Valuation form: 
 

 ·        Standard value = the part's inventory balance on the costing date ´ the part's standard cost.
 Note: In this case, the standard cost of purchased parts is calculated during each costing run on the basis of the standard costs recorded in the Part Catalogue or Parts - Std Costs form, and the standard cost of manufactured parts is calculated on the basis of material costs and standard production costs. Manual revision of the standard cost of manufactured parts does not affect their calculated standard costs and inventory values. 
 

 ·        Costing value = the part's inventory balance on the costing date ´ the part's actual cost. 
 

 ·        Materials value = the part's inventory balance on the costing date ´ the actual cost of the part's component materials.
