# Inventory Valuation for Open Work Orders

 

The value of an open work order is determined by calculating the sum total of production costs for the entire work order, including those of its child parts on every level of its bill of materials, and subtracting the actual cost of the completed parts. 
 
## To view the inventory valuation of open work orders on the plant floor:

 

 ·        Run the Inv Val - Open Work Orders (WIP) report.
