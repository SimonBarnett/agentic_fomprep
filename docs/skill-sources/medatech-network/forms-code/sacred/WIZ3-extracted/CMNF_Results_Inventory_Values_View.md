# To view inventory values for a specific part:

 

 1 .  Enter the Materials Inventory Valuation or Product Inventory Valuation form, according to the type of part. 
 

 2 .  Do one of the following: 
 

 ·              If you want to view the part's inventory valuation for a certain past balance date, retrieve the data according to the Part Number and Date for which the balance was recorded. 
 

 ·              If you want to view the part's inventory valuation for various points in time, retrieve the data according to the Part Number alone. 
 

 3 .  View the inventory values calculated for the part: 
 

 ·              For a raw material, in the Std Value and Actual Value columns. 
 

 ·              For a manufactured part, in the Std Value , Actual Value and Materials Value columns. 
 
## To view various cross-sections of inventory values:

 

 ·        Run the reports in the Inventory Valuation Reports menu to view inventory values on a given costing date. 
 

 ·        Run the reports in the Time-phased Inv. Valuation Reps. menu to view a history of inventory values during a given period.
