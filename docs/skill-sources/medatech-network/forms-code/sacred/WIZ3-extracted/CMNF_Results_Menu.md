# Analyzing Costing Results

 

The costing program calculates the actual and standard costs of purchased and manufactured parts. It is recommended to look into any significant difference between the standard cost and the actual cost; this is usually an indication of unrealistic standard costs. 
 
## What do you want to do?

 

 View standard costs of raw materials and manufactured parts 
 

 View actual costs of raw materials and lots 
 

 View actual costs of manufactured parts 
 

 View outlay for manufactured parts and work orders 
 

 View inventory transaction costs 
 

 View inventory values 
 

 View inventory aging 
 
## Notes:

 

 ·        To view the methods of calculating standard and actual costs that were used by the costing program, run the View Costing Parameters program.
