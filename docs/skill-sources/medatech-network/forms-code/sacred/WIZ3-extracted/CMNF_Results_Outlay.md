# Viewing the Outlay of Parts and Work Orders

 

In addition to calculating a part's average production costs, you can also view data regarding the part's cumulative outlay since the previous costing run. These calculations include the part's own production costs as well as those of all top-level child parts (i.e., direct components). 
 

Furthermore, whereas the calculation of actual cost only takes into account closed work orders (for the greatest precision), the calculation of outlay also includes open work orders, thus providing an up-to-date estimate of total production costs since the previous costing run. 
 
## To view the outlay for a certain part:

 

 ·        Retrieve the part in the Product Costing form and enter the Part Outlays per Period sub-level form. 
 

 OR 
 

 ·        Run the Work Order Outlays per Period report for the part, without specifying a work order.
 Note: Unlike the above form, which displays the costs incurred by a part's processed child parts, this report displays the total cost of processed child parts, together with the direct production costs incurred by the parent work order. The actual costs of processed child parts are displayed in the child part's work order. This prevents the child part's costs from appearing twice in the same report, which would result in erroneous totals. 
 
## To view the cumulative production cost of a specific work order:

 

 ·        Retrieve the work order in the Work Order Costing form and enter the Work Order Outlays per Period sub-level form. 
 

 OR 
 

 ·        Run the Work Order Outlays per Period report for the desired work order.
