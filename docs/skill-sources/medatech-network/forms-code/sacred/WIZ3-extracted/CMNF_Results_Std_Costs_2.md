# Viewing Standard Costs

 
## To view the standard cost of a raw material:

 

 ·        Enter the Material Costing form and retrieve the desired parts. Retrieval tips. 
 

 OR 
 

 ·        Run the Material Costing report. 
 
## To view the standard cost of a manufactured part:

 

 ·        Enter the Product Costing form and retrieve the desired parts. Retrieval tips. 
 

 OR 
 

 ·        Run the Product Costing report. 
 

 ·        For a breakdown of the cost components, view the data in the Std Cost line of the Product Cost Components form (sub-level of the Product Costing form) or run the Product Cost Components report. 
 
## To analyze the calculations of standard cost for manufactured parts:

 

 ·        Run the Standard Cost Analysis report. This report expands the part's bill of materials, listing the costs of the materials used on every level of the BOM, as well as the standard production costs of the part and its manufactured child parts, if any.
