# To assign or revise the costing option for manufactured parts:

 

 1 .  Enter the Parts - Std Costs form and retrieve the desired part.
 Tip: To retrieve all manufactured parts, use P in the Type (P/R/O) column. 
 

 2 .  Select the desired option in the Costing Option column. 
 

 3 .  Enter the Logistic Constants form and move to the PActCostType constant. 
 

 4 .  Select the desired constant value, which will affect all future parts.
