# Inventory and Costing Control for Work Cells and Operations

 

Inventory/costing control settings determine how production reports and subcontractor GRVs affect the part's inventory or costing calculations. 
 

These settings, when defined for each work cell, serve as the default for each operation performed in that cell, though you can change the setting for a specific operation. Furthermore, you can change the inventory/costing control assigned to an operation within a specific work order routing. 
 

If no Inventory/Costing Control setting is defined on any of the above levels, the standard cost of that operation is automatically added to the work order cost whether or not the operation is reported.
