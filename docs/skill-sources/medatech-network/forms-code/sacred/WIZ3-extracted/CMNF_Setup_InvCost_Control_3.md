# To set up Inventory/Costing Control for work cells in your company:

 

 1 .  Enter the Work Cells form. 
 

 2 .  Retrieve all existing work cells. 
 

 3 .  For each work cell, choose the appropriate setting in the Inv./Costing Control column. 
 
## To set up Inventory/Costing Control for a specific operation:

 

 1 .  Enter the Operations form. 
 

 2 .  Retrieve the desired operation. 
 

 3 .  Choose the appropriate setting in the Inv./Costing Control column.
 Note: An empty column indicates that the work cell setting applies to this operation. 
 
## Notes:

 

 ·        To change an operation's Inventory/Costing Control setting for a specific work order, use the Routing for the Work Order form, sub-level of the Work Orders form. For more information, run the Work Orders Wizard . 
 

 ·        For assistance in defining operations performed by a subcontractor, run the Working w/Subcontractors Wizard .
