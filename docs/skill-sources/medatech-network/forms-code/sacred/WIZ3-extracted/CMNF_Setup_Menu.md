# Setting Up Costing for Manufacturers

 

Before you begin working with costing, you need to define the following: 
 

 Warehouse costing settings 
 

 Inventory and costing control settings for work cells and operations 
 

 Standard costs of raw materials, labor, shipping and additional expenses 
 

 Cost calculation method for manufactured parts 
 

 Cost calculation method for parent parts with processed child parts
