# Defining Standard Shipping Costs 

 

You can define standard costs for shipment by air, land or sea, and designate a default shipping cost type . This will affect standard costing of the shipped part. In addition, if actual shipping costs have not been defined for a purchased part (i.e., in a shipping voucher or purchase invoice), the costing program automatically uses the standard shipping cost to calculate the actual cost of purchase transactions. 
 

Standard shipping costs can be defined on three levels: 
 

 Part family – use this option when all parts in the family have the same shipping cost 
 

 Part – use this option for parts whose shipping costs differ from those of other parts in the same family (but do not vary according to vendor). 
 

 Vendor part – use this option when the cost of shipping the part from a particular vendor differs significantly from the part's standard shipping cost. 
 

 Important: 
 

The standard shipping costs defined for a vendor are added to the cost of the purchase transaction, provided no shipping voucher was recorded, and thus affect the part's actual cost (which is based on inventory transaction costs). They do not affect the calculation of the part's standard cost.
