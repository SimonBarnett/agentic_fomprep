# Defining Hourly Costs of Employees and Machines 

 

For each work cell in the factory (or for all work cells in a certain department), you need to define the standard hourly cost of employing unskilled labor and running machines. You can also define standard setup costs, as a percentage of the work time of each employee and machine, and mount/dismount times for each work cell, as well as any indirect costs incurred by the employee or machine. If an operation requires skilled labor, you can define special standard costs for each skill type, and track the history of changes to the cost. 
 

Labor and machinery costs will be taken into account both by standard and actual costing: 
 

 ·        In standard costing, you need to define standard work times for employees and machines, which are multiplied by the corresponding standard costs. 
 

 ·        In actual costing, labor and machinery costs are multiplied by reported production times. You can also define work shifts, in order to multiply actual labor costs automatically by a given percentage, for work performed under special circumstances (e.g., at night, during holidays).
