# Defining Work Shifts

 

You can define work shifts in order to multiply the actual labor cost of employees working a given shift by a designated percentage. You can report shifts for all employees recorded in a production report, for all employees working on a specific operation, or for specific employees in the operation, using the Reporting Production form and its sub-levels. 
 
## To define a shift:

 

 1 .  Enter the Shifts form. 
 

 2 .  Record a code and description for the shift (e.g., PM , Night shift ) 
 

 3 .  In the Rate (%) column, record the percentage by which to multiply actual labor costs for employees working this shift (e.g., 125% , 150% ).
