# To define standard labor and machine time per operation: 

 

 1 .  Enter the Operations form and retrieve the desired operation. 
 

 2 .  Enter the Operation Processing Parameters sub-level form. 
 

 3 .  In the Parameter column, specify E for employee time or T for machine/skilled employee time. To add mounting time and dismounting time to the standard machine time, specify L and U , respectively. The operation code will appear automatically In the Variable column. 
 

 4 .  In the Operand(C/M/D) column, specify C (for Constant ). Explanation. 
 

 5 .  In the Coefficient column, record the standard employee or machine time. 
 

 6 .  Click to define skilled employees for this operation. 
 

 7 .  Click to set up time factoring.
