# To initialize the variable for a part:

 

 1 .  Enter the Parts form and retrieve the desired part. 
 

 2 .  Enter the Part Processing Parameters sub-level form. Move to the variable you defined and specify the appropriate Value . 
 
## Notes:

 

 ·        The time required to perform an operation on this part will now be calculated by multiplying or dividing the operation's coefficient (as per the defined operator) by the variable value defined for the part, multiplied by the time factor (if one is defined). 
 

 ·        Click to define standard labor and machine time per operation. 
 

 ·        Click to perform more setups.
