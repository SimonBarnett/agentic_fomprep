# Setting Up Time Factoring

 

Time factoring allows you to revise employee time, machine time (as well as skilled employee time, which is based on machine time), mounting and dismounting time for an operation without permanently changing its standard work time parameters. Example. 
 

When a time factor is specified, employee/machine time is calculated by multiplying the factor by the standard time defined for the operation or part. 
 
## To define a time factor:

 

 1 .  Enter the Operations form and retrieve the desired operation. 
 

 2 .  In the Time Factor column, specify the desired value.
