# Costing History

 

The History of Costing Runs form displays a log of each costing program that was run (including the Delete Costing Results and Set Costing Parameters programs), the date and time it was run, the user who ran it, and the costing date for which it was run. 
 
## To view the costing history:

 

 ·        Enter the History of Costing Runs form and run a query by costing date, user name or run date.
