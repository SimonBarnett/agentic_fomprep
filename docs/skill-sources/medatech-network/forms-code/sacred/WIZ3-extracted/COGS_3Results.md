# Viewing Periodic COGS Results

 

To analyze the results of the Post Cost of Goods Sold program: 
 

 1 .  Run the inventory valuation reports for the current costing period (the one for which COGS was run) and for the previous costing period. The account balance of the P&L COGS account (i.e., COGS – Materials , COGS – Other Inventory ) should equal the difference between previous inventory values and current ones.
 Note: For details on inventory valuations, run the Costing for Manufacturers Wizard or the Costing for Businesses Wizard . 
 

 2 .  Run the COGS Details per Part report.
 Note: Run this report only after past balances have been calculated and costing has been run for a past balance date. 
 

 3 .  Run the Periodic COGS-Unbilled Purchases report.
