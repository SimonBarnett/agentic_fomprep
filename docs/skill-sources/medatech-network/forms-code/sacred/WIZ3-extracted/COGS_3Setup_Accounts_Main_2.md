# Defining the Accounts

 

The accounts to be defined are: 
 

 ·        Balance sheet inventory accounts: Materials Inv – Bal Sheet and Other Inv – Bal Sheet 
 

 ·        P&L inventory accounts: COGS – Materials and COGS – Other Inventory (despite the name, the account balance represents only part of the cost of goods sold) 
 

 ·        Purchases 
 

 ·        Purchases Not Yet Billed 
 

Accounts can be defined at several levels. The hierarchy is as follows, in ascending order: 
 

 ·        company-wide (in the Default Accounts form). Details. 
 

 ·        per warehouse (in the Warehouse Accounts-Periodic COGS form). Details. 
 

 ·        per accounting family (in the Family Accounts - Periodic COGS form) 
 

 ·        per accounting family within a given warehouse (in the Warehouse Accounts-Periodic COGS form and its sub-level, Ware/Family Accts-Periodic COGS ). 
 

If no accounts are defined at any of these levels, journal entries will not be posted. 
 
## Notes:

 

 ·        Purchases Not Yet Billed may only be defined at the company-wide level.
