# Viewing COGS Results

 

You can view the results of running COGS in the entry journal. If the COGSPost constant is set to 0 , pending entries are recorded, which then need to be checked and posted to the ledger. 
 

 Priority also provides a number of reports that display details of the journal entries posted (or opened temporarily) by the Post Cost of Goods Sold program. These reports are useful for understanding the entry sums. 
 

Another set of reports explains the variance entries that are recorded when the Post Cost of Goods Sold program is run. 
 

Finally, you should check that the balances of inventory accounts match standard inventory valuations. 
 
## To view COGS results in the entry journal:

 

 ·        Enter the Entry Journal form and retrieve the journal entries recorded by the Post Cost of Goods Sold program.
 Tip: If the entries were not posted to the ledger, retrieve them by specifying " T* " ( T is the prefix assigned to all pending entries). 
 
## To view the journal entries created by COGS: 

 

 ·        Run the following reports: 
 

 ·      COGS Transactions 
 

 ·      COGS Transactions per Account 
 

 ·      COGS Details per Part 
 

 ·      Details of COGS Transactions 
 
## To analyze variance entries:

 

 ·        Run any of the reports in the Variance Analyses - Std Costing menu (sub-menu of COGS Posting ). 
 
## Notes:

 

 ·        For details on inventory valuations, run the Costing for Manufacturers Wizard or the Costing for Businesses Wizard 
 

 ·        Click to return to the main Perpetual COGS screen.
