## Running the COGS Program

 
## Before You Begin

 

 1 .  Calculate a past balance for the last day of the fiscal period that precedes the period for which you are running COGS, and run costing.
 Notes: 
 

 ·      The system should be set up so that the calculation of standard costs is based on standard material costs. To check and update costing definitions, run the Set Costing Parameters program. 
 

 ·      You can view the dates of the fiscal periods defined for a given fiscal year in the Define Fiscal Years form. 
 

 ·      You can view the dates of previous past balances, and the costing runs executed for them, in the Dates of Calculated Balances form. 
 

 2 .  Calculate a past balance for the last day of each fiscal period in the range of dates in question, up to the last period for which you are running COGs, and run costing for each past balance. 
 

 3 .  Run the Details of COGS Transactions report. The report displays, by date, the journal entries that will be opened for the inventory transactions recorded during the COGS period, as well as details of the transactions themselves. Check that desired results are obtained before actually running the Post Cost of Goods Sold program.
 Notes: 
 

 ·      If no debit or credit account appears for a given transaction in the report, no journal entry will be recorded. Ensure that an account has been defined at one of the levels of default GL accounts and rerun the report. 
 

 ·      Entries for which debit and credit accounts are identical will not be recorded. 
 

 ·      Entry sums are calculated from the standard costs of transactions. For an analysis of transaction costs, run the Costing for Manufacturers Wizard or the Costing for Businesses Wizard . 
 

 ·      See also the other reports in the COGS Posting menu.
