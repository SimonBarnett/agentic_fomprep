# To run COGS:

 

 ·        Run the Post Cost of Goods Sold program. 
 
## Notes:

 

 ·        If you ran COGS previously for the same period, and posted the journal entries that were created, an additional run for the same period will create adjustment entries to cover any changes in the costs since the previous run. For example, recording an invoice and linking it to a GRV that was included in the previous COGS run will update the cost of the inventory transaction when COGS is run again for that period, and an adjustment entry will be created for the difference.
