# Variance Entries

 

Variance entries are recorded for the end date of the COGS period. They are created so that inventory values reflected in the balance of inventory accounts at the end of the period match standard inventory valuations calculated by costing for the past balance that parallels the COGS period. 
 

Variance entries are recorded in the following instances: 
 

 ·        when a purchase invoice is finalized and there is variance between the part's invoice price and its standard cost. Explanation. 
 

 ·        when the kit list of a released work order was changed. The variance entry is recorded for the transaction of completed production for that work order. Explanation. 
 

 ·        when a production report for a given operation reports employee time that differs from the standard labor time defined for the operation. Explanation. 
 

 ·        when a production report for a given operation reports machine time that differs from the standard machine time defined for the operation. Explanation. 
 

 ·        when inventory transactions charge work orders for parts that are not in the BOM, where the actual cost of such parts differs from Non-Std C osts defined for the work order part. Explanation. 
 

 ·        when a given part's standard cost is updated. Explanation. 
 
## Note:

 

To view details of recorded costs and resulting variance, run the COGS Details per Part report.
