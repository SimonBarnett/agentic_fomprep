# Finalizing Receipts

 
## Before you begin:

 

 1 .  Enter the Receipts form and retrieve the desired receipt. 
 

 2 .  Click the Receipt Data tab, and check the value of the Difference column. Click if the receipt amount differs, even slightly, from the total payment due. 
 

 3 .  Click the References tab. Make sure the Entry Code is correct. 
 

 4 .  Check the receipt`s Status . You will only be able to finalize the receipt if its current status allows for finalization (e.g., it is assigned the Authorized status).
 Note: You must also be authorized to change the status of receipts to Final . 
 

 5 .  Enter the Receipt - Add'l Details sub-level form. Make sure that the Transaction Date is correct. 
 
## To finalize the receipt:

 

 ·        Select Finalize Receipt from the list of Direct Activations . 
 
## To finalize and print the receipt:

 

 ·        Select Finalize & Print Receipt from the list of Direct Activations . 
 
## To finalize a group of receipts:

 

 ·        Run the Finalize Receipts program.
 Tip: Run the Finalize Receipts - Errors report to view any problems that came up when running the program.

Click to return to the main screen.
