# Canceling a Final Receipt

 

You can cancel a final receipt by opening a new receipt that will cancel out the original one, prepare a reversing journal entry and cancel any reconciliation involving the original entry. The cancellation receipt can be recorded for the current date or the date of the original receipt. 
 
## To cancel a final receipt:

 

 1 .  Enter the Receipts form and retrieve the desired receipt. 
 

 2 .  Do one of the following: 
 

 ·              Select Cancel Document For Date from the list of Direct Activations to create a cancellation receipt and reversing journal entry for a designated date. 
 

 ·              Select Cancel Document (Original Date) from the list of Direct Activations to create a cancellation receipt and reversing journal entry for the same date as the original receipt. 
 
## Notes: 

 

 ·        You must be authorized to change the status of receipts to Canceled . 
 

 ·        Click to return to the main screen.
