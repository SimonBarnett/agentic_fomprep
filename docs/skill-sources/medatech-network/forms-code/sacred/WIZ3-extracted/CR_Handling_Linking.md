# Linking a Final Receipt

 

You can link a final receipt to an order recorded for a walk-in customer (e.g., if the order was recorded after the receipt). The financial status of the order will be updated, but the receipt will not be reconciled automatically with the order`s invoices; you will need to perform account reconciliation for the walk-in customer account. 
 
## Tip:

 

For more information, run the Account Reconciliation Wizard . 
 
## To link a final receipt to a walk-in customer order:

 

 1 .  Enter the Tie Order to Final Receipt form and retrieve the desired receipt. 
 

 2 .  In the For Order column, choose the number of the order to which you want to link the receipt. 
 Tip: Alternatively, you can record the sales rep`s order number or the customer`s purchase order number, and the internal order number will be filled in automatically.
