# Viewing Recorded Receipts

 

Run a variety of reports to view information regarding customer payments over specified periods. You can view the details of all receipts and over-the-counter invoices recorded over a specified period (including the total amount), as well as all payments received by designated cashiers, banks (for bank transfers) or credit card companies. You can also view all invoices and receipts recorded for walk-in customers. 
 
## To view all receipts over a specified period:

 

 ·        Run the List of Receipts report to view receipt information only. 
 

 ·        Run the Receipt Details - Paid Invoices report to view receipt information together with data on paid invoices. 
 
## Notes: 

 

 ·        You have the option to exclude pending and/or canceled receipts from these reports. 
 

 ·        To view invoice data together with information on any receipts recorded against the invoice, run the Invoices and Their Payment report.
