# Partial Payments by "First Invoice First"

 

When you record a partial payment using the “First Invoice First” method, the customer`s debt is not linked to the invoice from which it originates, but rather to the last invoice you pay; it is therefore difficult to arrive at accurate aging data. If you nonetheless decide to record partial payments in this manner, proceed as if full payment were received. That is, after flagging the invoices for payment, record the payment details but revise the sum appearing for each invoice to match the received amount. Priority will automatically reconcile all the flagged invoices with the receipt, such that an adjustment entry will be created for the difference. This entry will be recorded against the customer`s account both as a debit and a credit, so as to create an outstanding debt. 
 

If you do not want to create such a debt, do the following: 
 

 1 .  Enter the Adjustment Entry Details sub-level form and specify the desired reconciliation account in the Adjustment Entry column. The system will create an adjustment entry that credits the customer`s account and debits the adjustment account. 
 

 2 .  Return to the upper-level form.
