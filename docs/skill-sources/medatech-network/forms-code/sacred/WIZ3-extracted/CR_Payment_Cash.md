# To record payment in cash:

 

 ·        Move to the Receipt Data tab, and record the sum in the Cash Receipts column. 
 
## Notes: 

 

 ·        If the receipt needs to be checked before it is sent to the customer, assign it the Checking status (in the References tab). In the Assigned to column, specify the username of the person who is responsible for checking the document. The receipt cannot be finalized until this status is changed. 
 Tip: You can define work flow rules so that the assigned user changes automatically when the status is assigned. 
 

 ·        Depending on how receipts are set up, you may be required to finalize the receipt before you can leave the form. Explanation. 
 

 ·        Click to finalize the receipt. 
 

 ·        Click to return to the main screen.
