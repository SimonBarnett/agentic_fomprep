# Printing Receipts

 
## To print a single receipt:

 

 1 .  Enter the Receipts form and retrieve the desired receipt. 
 

 2 .  Select Print Receipt from the list of Direct Activations . 
 

 Notes: 
 

 ·              D ual-currency users: If you wish to print the receipt in English and are working in another language, select Print Receipt in Foreign Lang. instead. 
 

 ·              To simultaneously finalize and print the receipt, select Finalize & Print Receipt from the list of Direct Activations . 
 
## To print a group of receipts:

 

 ·        Run the Print Receipt report.
 D ual-currency users: To print in English when working in another language, run the Print Receipt in Foreign Lang. report. 
 
## Dual-currency users: To print an invoice with a receipt for a service contract:

 

 ·        Run the Print Invoice With Receipt report. 
 Note: Data must first be recorded in the Credit Card to Charge form, a sub-level of the Multi-Shipment Invoices form.
