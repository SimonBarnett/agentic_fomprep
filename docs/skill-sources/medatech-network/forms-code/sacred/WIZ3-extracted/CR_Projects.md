# Linking the Receipt to a Project

 

Project linkage appears automatically in the following cases: 
 

 ·        If the customer in question has opened a single project. 
 

 ·        If the receipt is based on an invoice that is linked to a project. 
 
## To check or record linkage of the receipt to a project:

 

 1 .  Move to the Project tab. 
 

 2 .  If a project number appears, make sure it is the correct project. Otherwise, choose the appropriate project from the Choose list.
