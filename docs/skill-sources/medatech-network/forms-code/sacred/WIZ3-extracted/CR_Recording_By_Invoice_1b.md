 6 .  By default, the journal entry that is created when the receipt is finalized contains one line crediting the customer`s account with the receipt`s total sum. If you prefer to itemize the entry according to the lines of the receipt (e.g., so that each invoice amount appears on a separate line in the entry), check the Copy to Journal Entry column (in the Check Invoice Data tab).
 Note: If you work with subsidiaries, flag this column when the invoices covered by the receipt are for accounts belonging to different subsidiaries, or when the account debited in an invoice belongs to a different subsidiary than the account credited in the receipt.
