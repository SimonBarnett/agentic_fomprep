# Recording a Receipt for a Walk-in Customer

 
## Before You Begin

 

Since all walk-in customers share the same GL account, reconciliation of a receipt from a walk-in must be “By Order”. 
 
## To check the reconciliation method:

 

 ·        If all customers are walk-ins, enter the Financial Constants form, and check that the value of the AutoRecon constant is 1 . 
 

 ·        Otherwise, enter the Chart of Accounts Receivable form and make sure that the Receipt Recon Method column is set at 1 for this walk-in customer. 
 
## To view outstanding debts for a particular order:

 

 ·        Run the Outstanding Debts by Orders report.
