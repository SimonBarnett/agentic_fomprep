# To define cashiers:

 

 ·        Enter the Cashiers form and check that the cashiers into which payments are transferred are properly defined. 
 
## Tip: 

 

For help in recording cashiers, run the Set Up Cashiers Wizard . 
 
## To define payment means:

 

 1 .  Enter the Payment Means form. Make sure that the main means of payment used by your customers are listed. 
 

 2 .  Assign to each means of payment, as needed, the cashier, bank account or credit card account to which received payments will automatically be directed: 
 

 ·              If all receipts by this means of payment go to a single cashier, bank account or credit card account, regardless of the receiving company branch, specify the appropriate code in the Cash/Bank/Credit Cd column. This account will serve as the default for all received payments in all branches. 
 

 ·              If the cashier, bank account or credit card account are determined by the branch receiving payment, enter the sub-level form, Cashier/Bk Acc/CredCd for Branch , and specify the appropriate code for each branch.
