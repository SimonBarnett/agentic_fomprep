# Parameters for Dating Checks

 

You can define a maximum range of days before and after the receipt date, within which checks must be dated. If a check is dated beyond this range, the system issues a warning. This will help prevent errors when recording check dates. 
 
## To define the maximum range before the receipt date:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  The preset value of the ChkMinDays constant is 90 days. Adjust it to suit your needs. 
 
## To define the maximum range after the receipt date:

 

 ·        Repeat the above process for the ChkMaxDays constant (preset to 364 days).
