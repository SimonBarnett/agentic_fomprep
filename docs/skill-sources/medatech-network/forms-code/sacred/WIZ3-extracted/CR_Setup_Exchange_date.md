# Setting Payment Adjustments

 

When the currency of the received payment differs from the currency of the invoice being paid, you need to determine the exchange rate date to be used when adjusting the payment sum. You can use the exchange rate in effect on the date of the invoice, or the one in effect on the date of the receipt. In the latter case, an exchange rate adjustment entry will be created automatically to cover the difference, when necessary. 
 
## To set the exchange rate date for adjustments:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the InvPayExch constant and choose the desired value. 
 
## Notes:

 

 ·        The constant also affects all types of vendor payments. 
 

 ·        If you want the adjustments in a specific receipt to be calculated according to the other date (i.e., the date that was not chosen for this constant), you can indicate this in the receipt.
