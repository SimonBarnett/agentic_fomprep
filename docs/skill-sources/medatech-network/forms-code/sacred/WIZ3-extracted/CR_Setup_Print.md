# Printing Parameters

 

If you want certain remarks to appear on all (or almost all) the printouts of receipts, you can designate set text for this purpose. Alternatively, you can record set text per branch and entry code. Any text recorded for a specific branch and entry code will override the default text for that document type. You can later change or delete this text for each individual receipt. 
 
## To record set text for receipts:

 

 1 .  Enter the Financial Documents form and move to the Receipt line. 
 

 2 .  Enter the Set Text for Document sub-level form and record the desired set text. This will appear automatically in the Receipt - Remarks sub-level form of each new receipt, but may be revised there. Any remarks appearing in the sub-level form are automatically included in the printout of the receipt.
 
 

 To record set text for receipts per branch and entry code : 
 

 1 . Enter the Financial Documents form and move to the Receipt line. 
 

 2 . In the Journal Entry Codes per Branch sub-level form, move to the relevant branch. 
 

 3 . In the Set Text for Branch sub-level form, record the desired set text. 
 

  
 

 Note: 
 

 ·      D ual-currency users: If you are working in a language other than English, you can record set text in English in the Set Text for Document - Lang2 sub-level form. You may also record set text for specific branches and entry codes by moving to the appropriate line in the Journal Entry Codes per Branch sub-level form, and recording the set text in the Set Text for Branch - Lang2 sub-level form. This text will appear in receipts for customers that have been defined to receive Printouts in Lang 2 (in the Customers form).
