# To define general receipt attributes:

 

 1 .  Enter the Financial Documents form. 
 

 2 .  Move to the Receipt line. 
 

 3 .  Make sure that the document attributes suit your needs. For example, you can set whether a journal entry created on the basis of a receipt will be closed when the receipt is closed, whether the prices in the receipt will be rounded, and whether users can finalize a receipt whose sum is zero.

 ·        For more information, see the Set Up Financial Docs Wizard .
