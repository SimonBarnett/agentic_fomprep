# Reconciliation Parameters

 

 Priority supports three methods of reconciling receipts with invoices. The method you choose will affect the manner in which the receipt is recorded. After designating a default reconciliation method, you can assign a specific reconciliation method to specific customers (e.g., walk-in customers), which overrides the general default. 
 

The three methods of receipt linkage are as follows: 
 

 ·        Reconcile by “First Invoice First” – reconciliations are handled within each account ledger. Explanation. 
 

 ·        Reconcile “By Invoice” – full tracking of partial payments. Explanation. 
 

 ·        Reconcile “By Order” – for walk-in customers. Explanation.
