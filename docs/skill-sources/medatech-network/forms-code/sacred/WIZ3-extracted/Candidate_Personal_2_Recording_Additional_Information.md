# Recording Qualifications

 

Defining the applicant's qualifications allows the system to automatically retrieve those applicants that are most eligible to fill a given job (this process is described in the Job Openings Wizard ). 
 
## To define a candidate's qualifications:

 

 1 .  Retrieve the desired candidate in the Job Candidates form. 
 

 2 .  Enter the Qualifications sub-level form. 
 

 3 .  For each qualification, select a relevant Qualification Code . The description appears automatically. 
 

 4 .  Select the Value that best describes the candidate in regards to the qualification. 
 
## Tip:

 

To define qualifications and their possible values, run the Personnel Setup Wizard .
