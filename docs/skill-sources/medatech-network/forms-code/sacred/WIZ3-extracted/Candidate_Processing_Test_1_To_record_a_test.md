# To record a test taken by a job applicant:

 

 1 .  Do one of the following: 
 

 ·              If this is an external candidate, enter the Job Candidates form. 
 

 ·              If this is a current employee, enter the Personnel File form. 
 

 2 .  Retrieve the desired applicant and enter the Tests Taken by Job Applicant sub-level form. 
 

 3 .  Record the date of the test and choose the number of the job opening for which the test was given. 
 

 4 .  Record the applicant's grade on the test and whether he/she passed. 
 

 5 .  Attach any documentation related to the test. 
 
## Notes: 

 

 ·        Click to schedule an interview for the applicant. 
 

 ·        Click to record results of the applicant ' s interview.
