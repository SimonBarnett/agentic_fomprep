- 
 
 
 
# To maintain the candidate's status: 

 

 1 .  Do one of the following: 
 

 ·              If this is an external candidate, enter the Job Candidates form. 
 

 ·              If this is a current employee, enter the Personnel File form. 
 

 2 .  Retrieve the desired candidate or employee. 
 

 3 .  Select the desired status in the Status column. 
 
## Notes: 

 

 ·        To set up statuses, run the Personnel Setup Wizard . 
 

 ·        If you assign the Inactive status, the candidate/employee is flagged as Inactive . Details.
