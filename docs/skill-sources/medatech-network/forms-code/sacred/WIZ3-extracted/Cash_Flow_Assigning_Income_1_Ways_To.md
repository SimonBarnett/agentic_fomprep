# Ways to Assign Cash Flow Codes to Income Transactions

 

There are four ways to assign cash flow codes to income transactions. Two of these involve setting up default codes, which the system then assigns to transactions; the other two involve direct assignment while recording a transaction or a journal entry. 
 
## Two ways to set up default codes:

 

 ·        Assign default codes per customer . The code appears as the default in any journal entry created for a receipt involving this customer. 
 

 ·        Assign default codes per type of cash intake (receipt, returned check, over-the-counter invoice or deposit). The default code appears for any transaction involving that type of cash intake. 
 Notes: 
 

 ·      The default does not appear in the transaction document itself, but rather in the transaction's journal entry. 
 

 ·      A default code does not accompany a payment beyond the type of transaction for which it was defined. If you want the default to accompany a payment further, you need to specify the code manually in subsequent transaction documents (e.g., if a payment received by a cashier is then deposited in a bank, you need to specify the cash flow code defined for receipts manually in the deposit slip). 
 
## Two ways to assign while recording a transaction or journal entry:

 

 ·        Assign a code to an individual transaction . This overrides any default defined for the transaction. 
 

 ·        Assign a code in a journal entry . This overrides any default that appears in the entry. For example, you could do this if you forgot to assign the code in the transaction.
 Note: You usually assign codes in journal entries when you manually record a provisional journal entry before producing a cash flow forecast report.
