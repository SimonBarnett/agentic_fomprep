# To assign a cash flow code to a transaction:

 

 1 .  Enter one of the following forms: 
 

 ·      Check Payment (Details) (sub-level of Receipts ) 
 

 ·      Check Details (sub-level of Over-the-Counter Invoices ) 
 

 ·      Deposited Items (sub-level of Deposit Slips ) 
 

 ·      Returned Payments 
 

 2 .  Retrieve the desired transaction. 
 

 3 .  In the Cash Flow Code column, choose the desired code.
