# To record a cash flow code for a posted entry:

 

 1 .  Enter the Entry Revisions form. 
 

 2 .  Retrieve the desired entry. 
 

 3 .  Enter the Itemized Revisions sub-level form. 
 

 4 .  Move to the line for the bank account or the cashier. 
 

 5 .  In the Cash Flow Code column, choose the desired code.
