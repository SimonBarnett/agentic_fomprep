# Ways to Assign Cash Flow Codes to Withdrawal Transactions

 

There are four ways to assign cash flow codes to withdrawal transactions. Two of these involve setting up default codes, which the system then assigns to transactions; the other two involve direct assignment while recording a transaction or a journal entry. 
 
## Two ways to set up default codes:

 

 ·        Assign default codes per vendor . The code appears as the default in any journal entry created for a payment involving this vendor. 
 

 ·        Assign default codes per type of payment (bank transfer and check payment). The default code appears for any transaction involving that type of payment. 
 Note: The default code assigned to a transaction does not appear in the transaction document itself, but rather in the transaction's journal entry. 
 
## Two ways to assign while recording a transaction or journal entry:

 

 ·        Assign a code to an individual transaction . This overrides any default defined for the transaction. 
 

 ·        Assign a code in a journal entry . This overrides any default that appears in the entry. For example, you could do this if you forgot to assign the code in the transaction.
 Note: You usually assign codes in journal entries when you manually record a provisional journal entry before producing a cash flow forecast report.
