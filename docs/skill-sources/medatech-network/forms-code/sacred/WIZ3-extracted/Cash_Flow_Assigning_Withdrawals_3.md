# To assign a default cash flow code to a vendor: 

 

 1 .  Enter the Chart of Accounts Payable form and retrieve the desired vendor. 
 

 2 .  Move to Full-Record Display Mode and click the Additional Definitions tab. In the Cash Flow Code column, choose the desired code.
