# To assign a cash flow code to a transaction:

 

 1 .  Enter one of the following forms: 
 

 ·      Check Payments 
 

 ·      Payments by Bank Transfer 
 

 2 .  Click the References tab and retrieve the desired transaction.
 Note: If the transaction is final, click to record the cash flow code in the corresponding journal entry . 
 

 3 .  In the Cash Flow Code column, choose the desired code.
