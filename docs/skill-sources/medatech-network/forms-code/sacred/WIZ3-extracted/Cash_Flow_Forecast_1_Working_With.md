# Viewing Cash Flow Forecasts

 

You can run the Cash Flow Forecast report for any or all of the following: 
 

 ·        Customers 
 

 ·        Vendors 
 

 ·        Bank accounts, credit card accounts and cashiers. 
 

This report displays the anticipated cash flow in and out of the accounts in question over a designated time period. 
 

Before running the report, you need to perform certain setups involving your ledger accounts and budget items. You can also create provisional journal entries for open/unbilled transactions, unused sums in the budget or miscellaneous income/expenses, and define detailed payment installments for purchase orders or expected payment delays – from customers or to vendors – that the report will take into account. 
 
## What do you want to do?

 

 Set up ledger account s and budget item s 
 

 Create provisional journal entries 
 

 Define payment installments for purchase orders 
 

 Define expected payment delays 
 

 Run the cash flow forecast
