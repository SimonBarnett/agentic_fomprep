# Creating Provisional Journal Entries for Open or Unbilled Transactions

 

You can create provisional entries for open purchase requisitions, open sales orders and/or open purchase orders, as well as unbilled inventory transactions. 
 
## Before you begin:

 

 ·        If there are certain purchase requisitions or purchase orders that you do not want to include in the cash flow forecast, enter the Purchase Orders or Purchase Demands form and retrieve them, then flag each one in the Omit from Cash Flow column. 
 
## To create provisional entries:

 

 ·        Run the Create Provisional Entries program, indicating the types of transaction for which to create entries. 
 
## Notes: 

 

 ·        If payment terms have been recorded for a given purchase order in the Payment Terms for Order sub-level of the Purchase Orders form, forecast sums for the expected payment will be distributed accordingly. 
 

 ·        Click to return to the Cash Flow Forecast menu.
