# Creating Provisional Journal Entries for Unused Budget Sums

 

You can create provisional entries for sums that were appropriated to the budget for a designated fiscal year but have not yet been used. These entries will be added to the Cash Flow Forecast Sums form and will subsequently appear in the Cash Flow Forecast report, until they are deleted. 
 
## Before you begin:

 

 ·        Make sure that a cash flow code has been assigned to each budget item that you want to include in the cash flow forecast.
 Tip: Click to assign cash flow codes to budget items . 
 
## To create provisional entries for unused budget sums:

 

 ·        Run the Prep CashFlow Sums by Budget Bal program, indicating the fiscal year for which to create entries, and specifying the desired payment terms, if any. 
 
## To delete provisional entries for unused budget sums:

 

 ·        Run the Delete Cash Flow Sums by Budget program. The entries will be deleted from the Cash Flow Forecast Sums form. 
 
## Notes: 

 

 ·        These entries will not appear in the entry journal; they will only appear in the Cash Flow Forecast report. 
 

 ·        Click to return to the Cash Flow Forecast menu.
