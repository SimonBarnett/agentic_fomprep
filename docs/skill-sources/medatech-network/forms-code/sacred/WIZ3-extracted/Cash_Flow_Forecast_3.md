# Creating Provisional Entries for Miscellaneous Income/Expenses

 

To include expected cash intake and outflow not related to particular orders or invoices, you need to create provisional journal entries for these transactions. 
 

You have two options: 
 

 ·        You can record them manually in the entry journal, and later delete them or convert them into regular entries. 
 

 ·        You can create a set of forecasted sums that can be reused, in the form of provisional entries. These entries will not appear in the entry journal; they will only appear in the Cash Flow Forecast report. 
 
## Note:

 

The two types of provisional entries are distinguished in the report by their prefix. Those recorded in the entry journal have a prefix of A ; those recorded as forecast sums have a prefix of a .
