Cash Flow - Manually Creating a Provisional Entry 
 
 
- 
 
 
 
## To manually create a provisional entry: 

 

 1 .  Enter the Entry Journal form. 
 

 2 .  Record a manual journal entry. (For help, see the Manual Journal Entries Wizard .) Remember to record a cash flow code in the Itemized Entry sub-level form, on the desired line. 
 

 3 .  Select Convert to Provisional Entry from the list of Direct Activations . 
 
## Note: 

 

Click to return to the Cash Flow Forecast menu.
