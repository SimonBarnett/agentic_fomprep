Cash Flow - Creating a Set of Forecast Sums 
 
 
- 
 
 
 
## To create a set of forecast sums:

 

 1 .  Enter the Cash Flow Forecast Sums form. 
 

 2 .  In the Date column, record the date of the provisional entry. The entry will be assigned a number with the prefix a .
 Note: If this is a reusable monthly entry, the forecasted sum will be included in the report on this day of each month. 
 

 3 .  Record the details of the provisional entry. 
 

 4 .  If you want the entry to be included in the Cash Flow Forecast report every month (or every X number of months), flag the Monthly Entry column. 
 

 5 .  If you flagged the Monthly Entry column, use the Interval in Months column to indicate the frequency with which to include the entry in the report (i.e., indicate the value of X). To include the entry every month, leave the default value of 1 . 
 

 6 .  If you flagged the Monthly Entry column and you want the entry to stop appearing in the report at some point (e.g., Dec. 31 of the current year), indicate an end date in the To Date column. 
 

 7 .  If you want the provisional entry to be recorded against a GL account other than the one assigned to the designated bank account, specify the Account No. 
 

 8 .  Specify the Cash Flow Code . 
 
## Note: 

 

Click to return to the Cash Flow Forecast menu.
