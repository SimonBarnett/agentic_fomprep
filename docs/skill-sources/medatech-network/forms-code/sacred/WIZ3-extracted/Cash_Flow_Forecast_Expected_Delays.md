# Defining Expected Payment Delays

 

When running the cash flow forecast, you can choose to take into account the average number of days that payments are late, both from customers and to vendors. Example. To do so, you need to define the expected delay for each customer and vendor. 
 
## To define expected delays:

 

 1 .  Open the relevant form: 
 

 ·      Financ. Parameters for Customers or 
 

 ·      Financial Parameters for Vendors 
 

 2 .  For each customer and vendor, define the Average Late Payments (in number of days).
