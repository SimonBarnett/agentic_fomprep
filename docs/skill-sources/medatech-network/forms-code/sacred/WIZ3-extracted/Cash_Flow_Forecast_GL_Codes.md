# Assigning Cash Flow Codes to GL Accounts

 

Assign cash flow codes to GL accounts when you intend to run forecasts using the "Flow Code Details" runtime option. 
 
## To assign a cash flow code to a GL account:

 

 1 .  Enter the Chart of Accounts form and retrieve the desired GL account. 
 

 2 .   Move to Full-Record Display Mode and click the Add ' l Definitions tab. In the Cash Flow Code column, choose the desired code.
