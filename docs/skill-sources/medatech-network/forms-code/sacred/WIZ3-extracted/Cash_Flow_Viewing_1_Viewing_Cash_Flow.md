# Viewing Cash Flow (1)

 

The Cash Flow report displays cash flow for one or more bank accounts, sorted by cash flow code. The report gives you many options for displaying this data: 
 

 Time frame 
 

 ·        Yearly 
 

 ·        Monthly OR 
 

 ·        Quarterly 
 

 Account display 
 

 ·        Each account separately (with opening balances) 
 

 ·        Combine all accounts and display opening balances OR 
 

 ·        Combine all accounts but do not display opening balances 
 

 Note: When you choose one of the Combine options, the report output includes the Acct/Cash Flow Code column. Where the report displays opening and closing balances, this column shows the bank account. Where it displays “Cash Flow in Period”, this column shows the cash flow code. 
 

 Date determining the year/month/quarter in which the transaction is included 
 

 ·        Due date 
 

 ·        Transaction date OR 
 

 ·        Reference date
