# Viewing Cash Flow (2)

 
## Detailed Report

 

Another report option (instead of choosing the time frame and account display) is Detailed . Each account is shown separately per month and each transaction is displayed separately. You choose the type of date (due date, transaction date or reference date) by which to determine the month into which each transaction falls. 
 
## Notes: 

 

 ·        The Detailed report output includes the Trans/Ref Date column. If you ran the report by reference date, the column shows that date. Otherwise, it shows the transaction date. 
 

 ·        Click to return to the main screen.
