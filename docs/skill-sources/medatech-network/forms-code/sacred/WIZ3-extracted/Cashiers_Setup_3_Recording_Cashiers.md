# To record cashiers:

 

 1 .  Enter the Cashiers form. 
 

 2 .  Record a code and description for the new cashier. 
 

 3 .  Make sure that the cashier currency is correct. 
 

 4 .  In the GL Account column, record the number of the account you opened for the cashier. 
 

 5 .  As a default, a check mark appears in the Automatic Receipt column. If you want transfers from any cashier to the new cashier to be manually confirmed at the new cashier, remove the check mark. Example. 
 

 6 .  As a default, each check or credit card slip transferred into or out of the cashier is recorded on a separate line in the ledger. To record all the items in a transfer as a total sum on one line, flag the Receive/Dep Lump Sum column. 
 

 7 .  If the cashier belongs to a branch, specify the Branch Code . Consequently, when you record a receipt for that branch, this cashier appears automatically.
 Note: If you work with subsidiaries and want to link the cashier to a subsidiary, link the cashier to a branch office that is linked to the subsidiary. 
 

 8 .  By default, all receipts are recorded to the Primary Cashier. If you want receipts of a particular payment type to always be recorded for the current cashier instead, enter the Payment Means form, move to the line for the form of payment in question, and specify this cashier in the Cash/Bank/Cred Cd column.
