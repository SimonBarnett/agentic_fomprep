# Initializing Cashiers – Preliminary Step

 

 ·        Before beginning to work in Priority , make sure the cashiers in your previous system are as empty as possible. 
 
## Initializing Cashiers

 

To initialize each cashier, you need to record its closing balance. Do this by recording the cashier's contents as a “customer receipt” in which the Opening Balances account is used instead of the customer's account. As a result, the cashier balance is recorded in the general ledger and the contents of the cashier are recorded.
