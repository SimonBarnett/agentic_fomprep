# Recording Data for a Predefined Cashier

 
## Before You Begin

 

Unless you ran the Account Initialization or Account Initialization-Intl program, you need to set up GL accounts for the predefined cashiers. 
 
## To check if the program was run: 

 

 1 .  Enter the Cashiers form. All predefined cashiers appear automatically. 
 

 2 .  If the GL Account column is filled in for these cashiers, that means GL accounts have already been set up. Click if GL accounts have not been set up.
