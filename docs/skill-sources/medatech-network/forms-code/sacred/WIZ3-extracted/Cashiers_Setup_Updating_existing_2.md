## To record data for a predefined cashier:

 

 1 .  Move to the desired cashier in the Cashiers form, and make sure that its Currency is correct. 
 

 2 .  A check mark appears in the Automatic Receipt column by default. If you want to manually confirm all transfers to this cashier from other cashiers, remove the check mark. Example. 
 

 3 .  By default, each check or credit card slip transferred into or out of the cashier is recorded on a separate line in the ledger. To record all the items in a transfer as a total sum on one line, flag the Receive/Dep Lump Sum column. 
 

 4 .  If the cashier belongs to a branch, specify the Branch Code . Consequently, when you record a receipt for that branch, this cashier appears automatically. 
Note: If you work with subsidiaries and want to link the cashier to a subsidiary, link the cashier to a branch office that is linked to the subsidiary. 
 

 5 .  By default, all receipts are recorded to the Primary Cashier. If you want receipts of a particular payment type to always be recorded for the current cashier instead, enter the Payment Means form, move to the line for the form of payment in question, and specify this cashier in the Cash/Bank/Cred Cd column.
