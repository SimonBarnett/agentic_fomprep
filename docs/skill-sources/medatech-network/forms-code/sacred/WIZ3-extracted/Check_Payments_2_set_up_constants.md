# Setting Up Check Printing Properties

 

Before printing checks with Priority , you must set up a number of constants that determine how Priority handles check printing. 
 

 To define printing properties: 
 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the CheckCopies constant and record the number of copies of a check to be printed (where 1 refers to the original only, 2 refers to the original and one copy, and so on). 
 

 3 .  Move to the PrintOrder constant and select the type of order in which checks are printed (i.e., either sequentially or alphabetically, according to the customer/vendor name).
