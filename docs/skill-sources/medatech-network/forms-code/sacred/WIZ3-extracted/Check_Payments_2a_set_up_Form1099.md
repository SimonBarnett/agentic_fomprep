# To set up for Form 1099:

 

 1 .  Enter the Form 1099 Categories form and make sure all the categories you need appear. Add as necessary. If desired, record a threshold for each category.
 Note: In order for the thresholds to affect the Form 1099 report, you must flag the Apply Thresholds column when running it. 
 

 2 .  Enter the Financial Parameters for Vendors form and retrieve all vendors. For each vendor that should appear in the report, make sure their Federal Tax ID and default Form 1099 Category are recorded, and that the Include in 1099 column has been flagged ( General tab).
 Note: You can override the default Form 1099 category in individual check payments.
