# Adjusting Payment Amounts 

 

Click if you do not need to adjust payment amounts. 
 
## There are two reasons for making adjustments to payments:

 

 When the invoice calls for payment installments and yet you want to pay several installments together 
 

 When the invoice calls for a lump sum, but you are paying in installments (partial payment)
