# Printing Checks

 

Before you begin printing checks in Priority , you need to design a Word template to match the format of your checks (e.g., adjust the page layout and other template attributes in Word) and try printing a test check to make sure that the template has been configured properly. 
 

Alternatively, if you are working in a Windows-based system, you can choose to print checks without using a Word template. In such a case, you must first set up the printer to match the format of your checks. 
 
## Notes: 

 

 ·        Priority checks that are printed without a Word template conform to the letter-size check format provided by Intuit QuickBooks. Contact your distributor to receive a sample check form. 
 

 ·        To print information about one or more check payments, run the View Check Payment program. 
 
## What do you want to do?

 

 Design a check template in MS-Word 
 

 Windows only: Configure the printer for check printing without a Word template
