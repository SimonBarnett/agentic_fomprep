# Configuring the Printer

 

If you plan to print checks without using a Word template (i.e., using the Print Checks program), you need to set up the printer to match the format of your checks. Please note that this option is only available in the Windows interface. In order to configure your printer to print checks, you need at your disposal at least one final payment document that does not yet have a check number, for testing purposes. 
 
## To configure your printer:

 

 1 .  Run the Print Checks program. Ignore the help text in the first two screens and continue to the Checks to Print form.
 Note: The help text is relevant to the printing of actual checks. 
 

 2 .  Retrieve a check payment to print as a test, then exit the form and continue running the program. 
 

 3 .  Make sure that the date falls in the correct place. If it deviates to the right or left, you can correct it by repositioning the page in the printer. If it falls too high or too low, run the Definitions for Check Printing program and change the Space Above Header value.
 Tip: To print another test of the same check, you must first enter the Revision of Checks form and delete the Check Number . 
 

 4 .  Make sure that the amount of the check falls in the correct place. If the amount is too low or too high, or too large to fit in the allotted space, run the Definitions for Check Printing program to change the Space After Header value, or to redefine the size and width of the printed characters. 
 

 5 .  Once the printer has been properly configured, enter the Revision of Checks form and delete the Check Number , so you can later print an actual check for the payment.
