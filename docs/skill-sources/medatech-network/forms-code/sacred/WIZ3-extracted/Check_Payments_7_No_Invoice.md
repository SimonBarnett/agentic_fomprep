# Payments Not Applied to Invoices

 
## To prepare a payment without reference to an invoice:

 

 1 .  Enter the Payment Details form (sub-level of the Check Payments form). 
 

 2 .  Record the amount of payment in the Sum column. 
 

 3 .  Record any reference numbers. 
 

 4 .  Return to the upper-level form. 
 

 5 .  If the payment document needs to be approved before the check is printed, return to the upper-level form and assign the document the Checking status (in the References tab). In the Assigned to column, specify the username of the person who is responsible for checking the document. The document cannot be finalized until this status is changed.
 Tip: You can define work flow rules so that the assigned user changes automatically when the status is assigned.
