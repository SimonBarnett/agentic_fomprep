Preparing Check Payments in a Batch 
 

When preparing checks in a batch, you have to do the following: 
 

 ·        flag outstanding invoices, adjusting payment amounts where applicable 
 

 ·        prepare the payment documents 
 

 ·        review the prepared check payments 
 

 ·        finalize the payment documents 
 

 ·        print the checks. 
 
## What do you want to do?

 

 Flag invoices and prepare the payment documents 
 

 Review the prepared check payments 
 

 Finalize the check payment documents 
 

 Print the checks
