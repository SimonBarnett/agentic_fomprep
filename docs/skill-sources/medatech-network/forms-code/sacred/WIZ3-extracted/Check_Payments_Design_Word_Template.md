# Designing a Word Template for Printing Checks

 
## Creating a New Word Template

 

To create a new template, you need to copy an existing Word template into a new one and then modify the new template as needed. 
 
## To copy the template:

 

 1 .   Enter the Word Templates - Check Printing form. 
 

 2 .  Move to the line that contains the template to be copied. 
 

 3 .  Select Copy Template from the list of Direct Activations, specifying the desired name and description for the new template. 
 
## To modify the new template:

 

 1 .   Run the Design Word Template for Checks program and select the template in question in the input screen. The template will open in Word. 
 

 2 .  Make any desired changes in the Word template. When finished, save and close the file. 
 
## Designing a Word Template and Printing a Test Check

 

Before printing checks from an existing template for the first time, it is recommended that you print a test check to make sure that the template has been configured properly. In order to do so, you need at your disposal at least one final payment document that does not yet have a check number, for testing purposes. 
 
## To design and test your check printing template:

 

 1 .  Run the Print Checks Via Word Template program, selecting the template in question. 
 

 2 .  The Checks to Print form opens. Retrieve a check payment to print as a test, then exit the form and continue running the program. 
 

 3 .  Make sure that the various fields fall in the correct place on the printed check. If not, modify the page layout and other template attributes by running the Design Word Template for Checks program. 
 

 4 .  The template opens in Microsoft Word. Make the required changes and save the template, then print a new test check. 
 Tip: To print another test of the same check, you must first enter the Revision of Checks form and delete the Check Number . 
 

 5 .  Once the template has been properly configured, enter the Revision of Checks form and delete the Check Number , so you can later print an actual check for the payment.

 Note: Click to print prepared checks. from a Word template.
