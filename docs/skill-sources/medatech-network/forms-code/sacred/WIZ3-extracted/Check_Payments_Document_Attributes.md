# To set up document attributes:

 

 1 .  Enter the Financial Documents form. 
 

 2 . Move to the line for Check Payments . 
 

 3 . Check the attributes that have been defined and revise as necessary. 
 
## Tip:

 

For detailed instructions on setting up the attributes of check payments, run the Set Up Financial Docs Wizard .
