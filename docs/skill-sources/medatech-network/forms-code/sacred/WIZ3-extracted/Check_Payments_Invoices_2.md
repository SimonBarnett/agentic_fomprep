 4 .  If you want to cancel the remainder of your debt, how you proceed depends on how invoices and payments are reconciled (determined by the value of the AutoRecon constant): 
 

 ·      If you reconcile "By Invoice", specify the number of the Adjustment Account for the invoice in question. 
 

 ·      If you reconcile "First Invoice First", enter the parallel Adjustment Entry Details sub-level form and specify the desired reconciliation account in the Adjustment Entry column. 
 

 5 .  Move to the parallel Check Payment - Add'l Details sub-level form. Verify that the correct address for the printed check appears and make sure the Form 1099 category is correct. 
 

 6 .  If the payment document needs to be approved before the check is printed, return to the upper-level form and assign the document the Checking status (in the References tab). In the Assigned to column, specify the username of the person who is responsible for checking the document. The document cannot be finalized until this status is changed.
 Tip: You can define work flow rules so that the assigned user changes automatically when the status is assigned.
