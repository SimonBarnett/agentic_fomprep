# Defining Reconciliation Adjustments

 

Sometimes there is a small discrepancy between the amount of the invoice (or invoices) and the amount of the check. Priority allows you to define a threshold for such discrepancies, within which the system will automatically proceed with reconciliation. 
 

To do so, you must specify the maximum variance that will still allow reconciliation and define a default account for reconciliation variances. Consequently, when recording a check payment, if you change an invoice amount slightly to match the payment amount, the system will nevertheless reconcile the journal entries (ignoring the small balance in the invoice) and record the variance in the default account.
