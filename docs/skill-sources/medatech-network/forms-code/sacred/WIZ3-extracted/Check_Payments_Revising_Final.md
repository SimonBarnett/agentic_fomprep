# Revising a Final Check Payment

 

Final check payments cannot be revised, with the exception of certain columns (e.g., Details , 1099 Category Code ). 
 
## To revise a final check payment:

 

 1 .  Enter the Revision of Payment Details form and retrieve the desired document. 
 Tip : Retrieve by Payment Number together with Payment Type ( Check ). 
 

 2 .  Make the necessary revisions.
