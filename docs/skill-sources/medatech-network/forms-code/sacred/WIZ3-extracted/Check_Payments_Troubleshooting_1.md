# What should I do if a check has been handwritten or created by other software?

 

If you have not yet recorded a payment document, record one and fill in the check number manually before you finalize the document.
 Tip: On recording check payments, see the Check Payments Wizard . 
 

If the payment document has already been recorded and finalized, do the following: 
 

 1 .  Enter the Update Check Numbers form and retrieve the payment document in question. 
 

 2 .  Write in the check number manually.
