# What should I do if I want to cancel the check?

 

 1 .  Enter the Check Payments form, and retrieve the payment document in question. 
 

 2 .  Select either Cancel Document (Original Date) or Cancel Document For Date from the list of Direct Activations . 
 
## Note:

 

In order to run these programs, you must be authorized to change the status of check payment documents to Canceled .
