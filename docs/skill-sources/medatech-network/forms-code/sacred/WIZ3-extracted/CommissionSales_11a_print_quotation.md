# Printing the Price Quote

 
## To print one quote:

 

 ·        Retrieve the quote in the Price Quotes for Commiss'n Sales form and select Print Quote for Commission Sales from the list of Direct Activations .
 D ual-currency users: If you wish to print the quote in English when working in another language, select Print CommSale Quote-ForeignLang instead. 
 
## To print more than one quote:

 

 ·        Run the Print Quote for Commission Sales report.
 D ual-currency users: To print in English when working in another language, run the Print CommSale Quote-ForeignLang report. 
 
## Notes: 

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen.
