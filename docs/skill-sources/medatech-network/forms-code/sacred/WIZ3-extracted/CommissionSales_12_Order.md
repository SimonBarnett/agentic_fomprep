# Recording a Commission Order

 

A commission order is generally recorded on the basis of a price quote for a commission sale that was sent to a customer. Recording an order on the basis of a price quote automatically changes the status of the quote to Order Placed . This status renders the quote inactive and prevents its revision. 
 

When you open a commission order, the balance of each line (the quantity of parts pending delivery) equals the ordered quantity. This balance is updated when delivery is reported. When the ordered quantity is supplied in full, the balance reaches 0 and the line closes. When all lines are closed, the order itself is closed automatically.
