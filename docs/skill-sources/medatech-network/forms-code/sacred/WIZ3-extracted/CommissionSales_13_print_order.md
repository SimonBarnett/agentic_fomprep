# Printing a Commission Order: Before You Begin

 
## To check remarks:

 

 1 .  Enter the Commission Order - Remarks sub-level form. The remarks recorded there will appear on all order printouts. Make sure they are correct. 
 

 2 .  If you print orders with item remarks , return to the upper-level form, and enter the Commission Order Items form. 
 

 3 .  For each item, make sure that the remarks displayed in the Commission Order Items - Remarks sub-level form are correct. Explanation. Revise them if necessary. 
 
## To verify the vendor`s address:

 

 ·        Make sure the details of the vendor`s address are correctly defined in the Vendors form. 
 
## Verifying the Customer`s Addresses

 

Printouts of the order display both the customer`s mailing and shipping addresses (the latter is determined by customer site). 
 
## To verify the customer`s mailing address:

 

 ·        Enter the Customers form and check that the customer`s main address is correct. 
 
## To verify the customer`s shipping address:

 

 ·        If the goods are to be delivered to a site other than the customer`s main address, make sure that site is correctly defined in the Shipping Address form (sub-level of the Commission Orders form).
