## To print a single order confirmation that can be sent to the customer:

 

 1 .  Enter the Commission Orders form and retrieve the desired order. 
 

 2 .  Select Print Confirmation of Comm Order from the list of Direct Activations .
 D ual-currency users: If you wish to print the order in English when working in another language, select Print CommOrd Confirm-ForeignLng instead. 
 
## To print multiple purchase orders that can be sent to the vendor:

 

 ·        Run the Print Confirmation of Comm Order report.
 D ual-currency users: To print in English when working in another language, run the Print CommOrd Confirm-ForeignLng report. 
 
## Notes: 

 

 ·        To change the current format for either type of printout, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen.
