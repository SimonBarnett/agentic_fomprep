# To record the journal entry for the credit note:

 

 1 .  Enter the Entry Journal form. Record a manual journal entry, debiting the vendor`s account for the total amount of the commission. 
 Tip: For help in recording the entry, run the Manual Journal Entries Wizard . 
 

 2 .  Return to the Credit Notes form, and specify the number of the journal entry in the Vend Debit Entry No. column.
