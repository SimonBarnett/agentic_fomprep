# Setting Up the Commission Sales Module

 

Before you begin working with the Commission Sales module, you need to set up the following: 
 

 Constants affecting commission sales 
 

 Set text for price quotes 
 

 P art remarks for RFQs, price quote s and order s 
 

 Types of sales 
 

 Business processes (BPM) for price quotes, orders and invoices (statuses)
