# Copying Set Text from Price Quotes to Sales Orders

 

The SCommissRem constant determines whether set text is copied automatically from price quotes for commission sales to the commission orders based on them. 
 

 ·        To copy the set text automatically, leave the preset value of 1 . 
 

 ·        Otherwise, change the value to 0 . 
 
## Notes:

 

 ·        Set text copied from a price quote is overwritten by set text defined for orders of a given commission sale type. 
 

 ·        Click to perform additional setups .
