# Copying Part Remarks to RFQs, Price Quotes and Orders

 

You can set up RFQs, price quotes and orders for commission sales so that part remarks are recorded automatically for individual items when a part number is manually recorded or revised in an itemized document. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "Quote-Comm Sales" and/or "Commission Order", flag the Copy Part Remarks column.
 Note: Flagging the line for "Quote-Comm Sales" affects both RFQs and price quotes.
