# Set Text for Price Quotes

 

If you want certain remarks to appear on all (or most of) the printouts of price quotes and RFQs for commission sales, you can designate set text for this purpose. 
 
## To designate set text:

 

 1 .  Enter the Set Text for Comm Sales Quotes form. 
 

 2 .  Record the desired remarks in the sub-level form. These will automatically appear in the Price Quote (Commission)-Remarks sub-level form of each new price quote or RFQ, but may be revised there. Any remarks appearing in this sub-level form are automatically included in the printout of the quote or RFQ.
 Tip for dual-currency users: If you are working in a language other than English, and want to print out price quotes and RFQs in English, record set text in the parallel Set Text for Comm Quotes - Lang2 sub-level form. Set text in English will appear in any quote/RFQ opened for a customer or vendor defined to receive Printouts in Lang 2 . 
 
## Note: 

 

Set text for price quotes is overwritten by set text defined for quotes of a given commission sale type.
