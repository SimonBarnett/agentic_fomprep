# Setting Up Business Processes for Commission Sales

 

You set up business processes for by defining statuses in BPM flow charts. 
 

There are several predefined statuses for quotes, orders and invoices recorded for commission sales, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 
## To use the flow charts:

 

 ·        Run the following programs: 
 

 ·      BPM Flow Chart-Commiss'n Quotes 
 

 ·      BPM Flow Chart-Commiss'n Orders 
 

 ·      BPM Flow Chart-Commission Invs . 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the following forms: 
 

 ·      Statuses for Comm. Sale Quotes 
 

 ·      Statuses for Commission Orders 
 

 ·      Statuses for Invs (Comm Sales) . 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
