# Printing the RFQ

 
## To print one RFQ:

 

 ·        Retrieve the RFQ in the Price Quotes for Commiss'n Sales form and select Print RFQ to Vendor (Comm Sales) from the list of Direct Activations .
 D ual-currency users: If you wish to print the RFQ in English when working in another language, select Print RFQ(CommSales)-ForeignLang instead. 
 
## To print multiple RFQs:

 

 ·        Run the Print RFQ to Vendor (Comm Sales) report.
 D ual-currency users: To print in English when working in another language, run the Print RFQ(CommSales)-ForeignLang report. 
 
## Notes: 

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen.
