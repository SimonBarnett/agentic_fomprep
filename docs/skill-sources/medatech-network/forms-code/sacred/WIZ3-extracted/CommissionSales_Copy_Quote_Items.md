# To check the items in the price quote:

 

 1 .  Enter the Quoted Items (Commission Sales) sub-level form. 
 

 2 .  Check the list of items copied from the original price quote. Delete any unnecessary lines. 
 

 3 .  If the new quote is for a different customer than the original quote, specify the customer`s part number, if desired. 
 

 4 .  Check each item`s details (e.g., quantity, unit price, discount, delivery time). Make any necessary revisions. The Total Commission is updated automatically according to any changes in the price or discount.   
 Note: You can also check the commission for each quoted item. 
 

 5 .  Return to the upper-level form and click the Follow-up tab. Adjust the Status of the price quote (e.g., to Ready ).
