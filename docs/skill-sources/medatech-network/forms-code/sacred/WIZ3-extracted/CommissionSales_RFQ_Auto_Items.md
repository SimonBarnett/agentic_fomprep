# To check the items in the RFQ:

 

 1 .  Enter the Quoted Items (Commission Sales) sub-level form. 
 

 2 .  Check the list of items copied from the original RFQ. Delete any unnecessary lines. 
 

 3 .  For each item, specify the delivery time, in days or weeks. Flag the Days or Weeks column accordingly. 
 

 4 .  Check the requested Quantity . Revise if necessary.
 Note: To receive different price quotes for different quantities of the same part, record a new line for each quantity. 
 

 5 .  If the unit price appears automatically, delete it. 
 

 6 .  Specify the target price for this item, if desired. 
 

 7 .  Return to the upper-level form.
