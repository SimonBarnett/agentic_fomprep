Though each company stores its own data independently, there are certain forms and settings (e.g., mailbox, appointment journal, personal form design) that it would be impractical or inconvenient to maintain separately. Click to view a list of settings that affect all companies simultaneously . 
 

When the various divisions of a company function as independent companies vis-a-vis the tax authorities, Priority allows you to designate them as subsidiaries . Each subsidiary maintains its own ledger, against a common Priority company shared by all subsidiaries, and its own branch office. For more information, run the Subsidiaries Wizard . 
 
## Note:

 

Programs can only be run on the server, by users with system manager privileges and users who are flagged to Manage Companies (in the Permissions tab of the User Permissions form).
