# Multi-Company Settings 

 

Most settings and constants in Priority affect only the company environment in which they are defined. However, a number of settings affect all of the companies in your system simultaneously. The following is a list of multi-company settings in Priority : 
 

 ·        Users – users defined in one company appear as users in all companies. 
 

 ·        Employees – personnel data defined in one company appears in all companies; however, a sub-level of the personnel file allows you to add employee details specific to the company in which you are working. 
 

 ·        Appointments – each user has one appointment journal, regardless of the company for which each appointment is made. 
 

 ·        Mail – each user has one mailbox, which functions according to the mail options defined in the main menu, regardless of the company in which you are working. 
 

 ·        Personal design of forms, menus and reports – any changes that you make to the design of a Priority entity in one company (e.g., hidden fields, custom tabs, menu item order) appear in the same entities in all companies. 
 

 ·        Color conditions in forms – if you link the color of a form column to a specific value or range of values, the same condition applies to that form column in all companies. 
 

 ·        Print formats – If you customize the print format of a given document or report, or duplicate an existing print format, these changes appear for that document or report in all companies. 
 

 ·        Private customizations – any system customizations provided by Eshbel directly to your company apply to all companies within your system.
