# To open a new company:

 

 1 .  Run the Add Company program.
 Note: This program must be run from the server by the superuser. 
 

 2 .  In the Company column, specify the desired company code. Or leave this column empty to obtain a company code automatically. This code also serves as the name of the sub-directory in which the company's data is stored.
 Note: The company code must be made up of lower-case letters and/or digits. 
 

 3 .  In the Full Company Name column, specify the name of the company. This will appear in the Choose list when selecting which company to work with. 
 

 4 .  Click OK . 
 
## Notes: 

 

 ·        The Add Company program takes a long time to complete. To avoid data errors in the company you are opening, DO NOT close the program window until the program is finished and you have received a message to that effect on the screen. 
 

 ·        This program can only be run on the server, by users with system manager privileges and users who are flagged to Manage Companies (in the Permissions tab of the User Permissions form). 
 

 ·        Click to record company details.
