# Clearing Company Data

 

In certain cases (e.g., when useless data accumulates in a demo environment), you can clear company data. This deletes all data recorded in the company, but not the privileges defined for it. 
 
## Warning!!

 

This data is deleted permanently, and is very hard to recover. Therefore, you must always consult with the implementation engineer/customer support before clearing a company that contains actual data. 
 
## To clear a company's data:

 

 ·        Run the Delete Company Data program. 
 
## Notes: 

 

 ·        This program can only be run on the server, by users with system manager privileges and users who are flagged to Manage Companies (in the Permissions tab of the User Permissions form). 
 

 ·        The Delete Company Data program takes a long time to complete. To avoid data errors in the company you are handling, DO NOT close the program window until the program is finished and you have received a message to that effect on the screen.
