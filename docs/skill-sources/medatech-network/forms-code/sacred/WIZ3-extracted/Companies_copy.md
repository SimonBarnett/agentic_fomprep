# Copying a Company

 

You can copy all the data from one company to another, or only the basic data (such as user profiles, the chart of accounts, parts, warehouses, branches, customers, vendors and the like). 
 

 Note: Both programs described below must be run from the server by the superuser. 
 
## To copy all data:

 

 1 .  Make sure that you have enough disk space to copy all the data of the existing company. 
 

 2 .  Run the Copy Company program. 
 
## To copy only the basic data:

 

 1 .  Make sure that you have enough disk space to copy the basic data of the existing company. 
 

 2 .  Run the Add Company & Copy Basic Data program. 
 
## Notes: 

 

 ·        Both programs take a long time to complete. To avoid data errors in the company you are opening, DO NOT close the program window until the program is finished and you have received a message to that effect on the screen. 
 

 ·        These programs can only be run on the server, by users with system manager privileges and users who are flagged to Manage Companies (in the Permissions tab of the User Permissions form). 
 

 ·        Click to record company details.
