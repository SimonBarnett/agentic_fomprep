# Deleting a Company

 
## Warning!!

 

This data is deleted permanently, and is very hard to recover. Therefore, you must always consult with the implementation engineer/customer support before deleting a company that contains actual data. 
 
## Before you begin:

 

 1 .  Make sure that you are presently in a different company from that which you want to delete. 
 

 2 .  Make sure that all users have exited the company that you want to delete. 
 
## To delete a company:

 

 ·        Run the Delete Company program. The program deletes the selected company and all of its data. 
 

 Notes : 
 

 ·        This program can only be run on the server, by users with system manager privileges and users who are flagged to Manage Companies (in the Permissions tab of the User Permissions form). 
 

 ·        To make sure that you are deleting the correct company, click the magnifying glass to enter the Companies form. Move the cursor to the line for the company designated for deletion, then press F8 to exit the form and return to the program.
