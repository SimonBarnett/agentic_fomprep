# Recording Company Details

 

After opening a company, you need to record some basic information about it (e.g., address, phone number, path to the logo file). This information will appear in the heading of all printouts intended for the company's customers and vendors. 
 

Dual-currency users can also define the company's primary language (in which routine data is recorded), if it differs from the base language of the system, as well as any logo, phone or fax number used exclusively for exports. 
 
## To record company details:

 

 1 .  Make sure you are in the correct company. 
 

 2 .  Enter the Company Data form. 
 

 3 .  Fill in all columns. If values already appear in the form, replace them with your own company information. 
 

 4 .  Enter the Companies form. 
 

 5 .  To assign a color to the title bar of this company, move to the appropriate line and select a Color . 
 

 6 .  If the company's primary language differs from the base language of the system, specify the appropriate Language Code . 
 
## Notes:

 

 ·        For more on installing logo files, run the Printing Wizard . 
 

 ·        Run the Privilege Explorer Wizard to define user privileges specific to this company. 
 

 ·        Click to return to the main screen.
