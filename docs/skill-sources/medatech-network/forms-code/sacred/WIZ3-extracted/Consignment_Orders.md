# Ordering Goods from a Consignment Warehouse

 

When recording sales orders to customers for goods in a consignment warehouse, you need to specify the warehouse in the order heading. This allows the Replenish Consignment Warehouses program to identify open sales orders to customers when calculating inventory levels in the consignment warehouse. 
 
## To record a sales order from a consignment warehouse:

 

 1 .  Enter the Sales Orders form. 
 

 2 .  Record the order in the normal fashion.
 Tip: For more information, run the Sales Order Wizard . 
 

 3 .  Click the Shipment tab, and specify the consignment warehouse in the Sending Warehouse column. 
 
## Note:

 

This parameter is only necessary if you plan to take open sales orders from customers into account when calculating inventory replenishment levels (by flagging the + Consign Wareh Ords input column when running the Replenish Consignment Warehouses program).
