# Setting up Consignment Warehouses

 

One of the most important aspects of maintaining a consignment warehouse is determining when its inventory needs to be replenished. The Replenish Consignment Warehouses program calculates existing inventory levels and compares them with the minimum and maximum allowable level defined for each part in the warehouse. It also takes into account any open sales orders to the consignment warehouse, including those that display a transit warehouse (a virtual warehouse used to document goods that have been shipped to the consignment warehouse but will take a significant amount of time to arrive). 
 

If you so choose, the program can open sales orders for all parts whose inventory requires replenishing, in accordance with the replenishment minimum and increment defined for each part in the warehouse.
