# To define a consignment warehouse:

 

 1 .  Enter the Warehouses form and open a new warehouse of Type D in the normal fashion.
 Tip: For help with opening warehouses, run the Open a Warehouse Wizard . 
 

 2 .  In the General tab, flag the For Consignment column, and make sure that the Inventory Valued column is also flagged. 
 

 3 .  The Inv. by Customer column is flagged automatically, to allow the consigned goods to be recorded separately for multiple customers. Remove the check mark if the warehouse is intended to serve a single customer. 
 

 4 .  Click the Consignment tab. In the Customer Number column, select the customer at whose site the warehouse is located.
