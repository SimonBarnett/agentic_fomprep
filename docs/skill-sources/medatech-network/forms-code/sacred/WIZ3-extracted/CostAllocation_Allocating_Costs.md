# Allocating Costs and Viewing Results

 
## To allocate indirect costs among profit centers:

 

 ·        Run the Allocate Costs program. 
 
## To view the results of cost allocation:

 

 Priority offers a number of reports that allow you to analyze the results of cost allocation. 
 

 ·        To view a profit and loss report broken down by profit center, run the P&L Statement per Profit Center report. 
 

 ·        To view a consolidated profit and loss report broken down by company, run the Consolidated P&L per Profit Ctr report. 
 

 ·        To view a profit and loss report broken down into direct production costs and indirect costs, run the Profit & Loss Summary report.
 Note: Direct production costs are taken from those accounts that fall under the Cost of Goods Sold heading in the P&L report, or any other heading flagged as direct production costs in the Bal. Sheet/P&L Report Headings form.
