Cost Allocation - Allocating Costs and Viewing Results.2 
 
 
- 
 
 
 

  
 

 ·        To view a breakdown of profit center data into direct costs, indirect costs and revenue, run the Profit Center Analysis report. If you work with profit center trees, run the Profit Center Tree Analysis report instead. 
 

 ·        To view a breakdown of costs (direct and indirect) for individual profit centers, run the Profit Center Costs report. 
 

 ·        To view a breakdown of profit center costs (direct and indirect) by expense account, run the Profit Ctr Costs by Expense Acct report. 
 

 ·        To view how the costs of given cost centers are allocated to profit centers, run the Cost Center Analysis report. 
 

 ·        To view a summary of costs per cost center, run the Cost Summary report. If you work with cost center trees, run the Cost Summary by Tree report instead. 
 

 ·        To view the BI report for profit and cost centers, run the Executive Reports Wizard for detailed instructions.
