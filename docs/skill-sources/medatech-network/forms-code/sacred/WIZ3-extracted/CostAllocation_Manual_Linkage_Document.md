# To link transaction items to a single profit/cost center: 

 

 1 .  Enter the transaction document (e.g., Sales Orders ). 
 

 2 .  Enter the sub-level form in which the document is itemized (e.g., Order Items ). 
 

 3 .  For each item, specify the desired Profit/Cost Center .
