# Setting Up Profit/Cost Center Rules for Specific Accounts

 

There are several ways to set the profit/cost centers that should be recorded in entries involving a given account: 
 

 ·        You can define default profit/cost centers (one per group) for a given GL account. These will be assigned to any entries for the account unless a different profit/cost center is manually recorded.
 Note: If a profit/cost center is assigned to a GL account, this takes precedence over any other entities to which it has been linked (e.g., linkage to a warehouse, customer or branch). 
 

 ·        You can require transactions for a given account to be restricted to profit/cost centers from a specific tree (in invoices and journal entries, this feature only applies to the first profit/cost group). 
 

 ·        You can require users to designate a profit/cost center when recording transactions for the account. Consequently, they will not be permitted to leave the Profit/Cost Center column blank when recording transactions for that account. 
 
## To set up profit/cost center rules:

 

 1 .  Enter the Chart of Accounts form and move to Full-Record Display Mode . 
 

 2 .  Retrieve the desired account. 
 

 3 .  Click the Profit/Cost Ctrs tab and do one of the following: 
 

 ·              To set a default for each profit/cost group, record the desired profit/cost centers. 
 

 ·              To require users to designate a profit/cost center from a given tree, specify its tree code in the Profit/Cost Ctr Tree column. 
 

 ·              To require users to designate any profit/cost center, record *** in the same column.
 Note: Make sure that the tree code “***” has been defined in the Profit/Cost Center Trees form; if it has not, add it.
