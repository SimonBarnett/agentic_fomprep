# Defining Bases of Cost Allocation

 

Cost allocation bases determine the method by which each indirect cost is distributed among the designated profit centers. There are three methods of cost allocation: 
 

 ·        By weighted parameter : Each profit center is assigned a numerical value, which determines its proportional share of the indirect cost. Example. 
 

 ·        By direct cost: The indirect cost is distributed among the profit centers in the same proportion as their direct costs (e.g., purchase invoices). This method is useful when there is a simple relation between the direct and indirect costs. Example. 
 

 ·        By weighted direct costs: The indirect cost is distributed among the profit centers according to a combination of weighted parameter and direct costs. Example.
