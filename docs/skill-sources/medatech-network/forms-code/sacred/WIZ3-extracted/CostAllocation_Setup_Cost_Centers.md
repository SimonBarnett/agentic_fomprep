# Defining Cost Centers

 

Each profit group must have a corresponding cost group, even if the same cost centers are used in each group. This is because the allocation of each cost center is handled separately for each profit group. Consequently, if you intend to distribute the same indirect costs to profit centers in five different profit groups, you need to define each cost center five times, once for each profit group. Example. 
 
## To define a cost center:

 

 1 .  Enter the Cost Centers form. 
 

 2 .  Record a code in the Cost Center column, and a Description . Example. 
 Note: You cannot assign the same code to both a profit center and a cost center. 
 

 3 .  Assign the cost center to a cost Group , determined by the profit group to which these costs are to be allocated (e.g., if the costs are to be allocated to profit centers in Group 2, designate 2 ). 
 
## Tips:

 

 ·        To view the cost centers in each cost group, enter the appropriate form in the Profit/Cost Centers-Aux. Forms menu. 
 

 ·        To view all cost centers, run the List of Cost Centers report.
