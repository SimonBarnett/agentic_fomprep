# Setting Up Cost Allocation

 

In addition to profit and cost centers, groups and trees, you need to define bases of allocation, which determine the method by which indirect costs are distributed among the designated profit centers. 
 
## What do you want to do?

 

 Define profit centers and groups 
 

 Define cost centers and groups 
 

 Define bases of cost allocation 
 

 Define profit and cost center trees 
 

 Set up automatic links to profit and cost centers 
 

 Set up profit and cost center rules for specific accounts
