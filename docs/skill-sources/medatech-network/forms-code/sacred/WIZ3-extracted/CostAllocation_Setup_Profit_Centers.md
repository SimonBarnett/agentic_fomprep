# Defining Profit Centers

 

Before you begin defining profit centers, it is recommended to plan your desired profit groups, in order to code their respective profit centers accordingly (i.e., profit centers per accounting family in Group 1; profit centers per customer group in Group 2). Keep in mind that when you specify a profit center in an invoice, you can only do so in its designated column (i.e., a Group 3 profit center can only be specified in the Profit Center 3 column). 
 
## To define a profit center:

 

 1 .  Enter the Profit Centers form. 
 

 2 .  Record a code in the Profit Center column, and a Description . Example. 
 

 3 .  Select the Group to which to assign the profit center. Example .
 Note: This is a mandatory field, whether or not you are planning to use multiple profit groups. 
 
## Tips:

 

 ·        To view the profit centers in each profit group, enter the appropriate form in the Profit/Cost Centers-Aux. Forms menu. 
 

 ·        To view all profit centers, run the List of Profit Centers report.
