# Defining Profit and Cost Center Trees

 

Trees are hierarchies of profit or cost centers, which allow you to analyze cumulative profit data on up to three levels. 
 
## To build a tree:

 

 1 .  Enter the Profit/Cost Center Trees form. 
 

 2 .  Record a code and description for the tree's top level, consisting of a number and two asterisks (e.g., 1** – All Warehouses). 
 

 3 .  Record codes and descriptions for the branches on the second level, each consisting of two numbers and an asterisk (e.g., 11* - East Coast Warehouses, 12* - West Coast Warehouses). 
 

 4 .  Record codes and descriptions for the sub-branches on the third level, each consisting of three numbers (e.g., 111 – New York Warehouses, 112 – Boston Warehouses). 
 
## Note:

 

If you plan to set rules that force users to assign any profit/cost center to all entries for a given GL account, add the *** tree code to this list.
