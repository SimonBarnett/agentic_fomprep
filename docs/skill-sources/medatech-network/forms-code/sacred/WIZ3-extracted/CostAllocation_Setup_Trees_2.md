# To assign profit or cost centers to the tree:

 

 1 .  Do one of the following: 
 

 ·              If the tree is for profit centers, enter the Profit Centers form. 
 

 ·              If the tree is for cost centers, enter the Cost Centers form. 
 

 2 .  Retrieve the profit/cost centers you want to assign to the tree. 
 

 3 .  For each profit/cost center, select the Tree Code of the appropriate branch on the tree's lowest level . 
 
## Notes:

 

 ·        Example of a three-level profit center tree . 
 

 ·        To view all profit centers and their tree codes, run the List of Profit Centers report. 
 

 ·        Click to perform additional setups.
