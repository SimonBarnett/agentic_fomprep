# Running Costing for the Current Date 

 

Costing for the current date calculates part costs on the basis of inventory transactions recorded since the last past balance until today. Every time you run this program, the new results overwrite the existing ones; that is, no history is maintained of previous results. When costing is run for a past balance date, these results are deleted . 
 
## To calculate costs for the current date:

 

 1 .  Run the Costing for Current Date program. 
 

 2 .  If the costing program encounters problems, it will notify you at the end of its run. If this occurs, run the Warning Messages - Costing report to view the list of problems.
 Tip: Most problems are caused by insufficient data. Example.
