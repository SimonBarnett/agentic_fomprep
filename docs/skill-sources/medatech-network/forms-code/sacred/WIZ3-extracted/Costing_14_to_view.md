# Analyzing Costing Results

 

The costing program determines the actual and standard costs of purchased and assembled parts. It is recommended to look into any instances of significant difference between the standard cost and the actual cost; this is usually an indication of unrealistic standard costs. 
 
## What do you want to do?

 

 View part costs (standard, actual and lots) 
 

 View inventory transaction costs 
 

 View inventory values 
 

 View inventory aging 
 
## Notes:

 

 ·        To view the methods of calculating standard and actual costs that were used by the costing program, run the View Costing Parameters program.
