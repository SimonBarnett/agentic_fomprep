# Viewing Standard and Actual Part Costs 

 

The costing program calculates the standard cost of both raw materials and assembled parts. The standard cost of a raw material is taken directly from the standard price defined for it when the program is run, together with shipping costs, according to the quantity defined for the part's costing unit. The standard cost of an assembled part is determined by calculating the total cost of its child parts, according to its standard bill of materials. 
 

If you chose to take lots into account when defining costing parameters, you can view the cost of each purchased raw material lot. The costing program assigns these costs as inventory values to the part balance in each lot.

## To view lot costs:

 

 ·        Enter the Lot Costing form and retrieve the desired part or part lot.
