# Viewing Inventory Transaction Costs 

 
## To view the cost of a particular inventory transaction:

 

 1 .  Enter the Audit Trail form. 
 

 2 .  Retrieve the inventory transaction in question (e.g., by document number, document date, part number), and move to the Cost Source column to view the source of the inventory transaction cost. 
 
## Note: 

 

Transaction costs recorded manually in the Audit Trail form are not updated by the costing program.
