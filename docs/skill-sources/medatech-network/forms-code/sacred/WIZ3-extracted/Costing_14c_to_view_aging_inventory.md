# Inventory Aging 

 

To view the inventory age of a part as of a given costing date, you can run an inventory aging report, in two formats: 
 

 ·        A summarized report, which displays the weighted average inventory age on the costing date, or 
 

 ·        A detailed report, which displays the age of the most recent inventory receipts, as well as the weighted average age. 
 

The weighted average age is calculated according to the average ages of the most recent inventory receipts, such that the weight of each transaction in the calculation is determined according to the transaction quantity, divided by the total inventory balance on the costing date. 
 

The report calculates inventory values on the designated costing date. The calculation method is similar to the method used by costing, although there are differences (that is, the resulting inventory values are not necessarily identical). 
 
## To view inventory aging:

 

 ·        When working with the FIFO costing method, run the Inventory Aging report. This report displays the average age (in days) and value of the existing inventory of specified parts. 
 

 ·        To view inventory aging for one or more specific warehouses, regardless of the costing method, run the Inventory Aging per Warehouse report. This report displays the average age (in days) and value of the existing inventory of specified parts in the specified warehouse(s).
