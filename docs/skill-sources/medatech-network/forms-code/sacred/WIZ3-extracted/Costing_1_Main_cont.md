In addition to these two procedures, Priority also provides online costing , which automatically updates the cost of purchased and assembled parts in the part catalogue between costing runs, on the basis of purchase invoices and GRVs finalized between costing runs. As this feature does not take all of the relevant data into account (e.g., shipping expenses, outgoing inventory transactions), online costing only provides a rough estimate of the part's cost, until the next costing run. 
 

Your company's specific needs determine how often to run costing; however, it is sound practice to calculate past balances and run costing at the end of each quarter. 
 
## Notes:

 

 ·        If you are costing manufactured parts, use the Cost Analysis for Manufacturers Module . 
 

 ·        Costing results can be used as input to profit calculations and pricing recommendations. For more information, run the Profitability Wizard . 
 

 ·        If you are using the dual-currency system, costing data columns are doubled, allowing you to view results in both the local currency and the system's second currency .
