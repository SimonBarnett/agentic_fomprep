# Initializing the Costing System 

 

If you have performed the necessary setups, the system now contains standard costs for all purchased parts as well as standard shipping costs, if any. You should now update the initial inventory balance of each part and its initial cost, in order to calculate its initial inventory values. 
 
## To initialize costing:

 

 1 .  Record a past balance for your designated costing initialization date.
 Tip: For assistance, run the Past Balances Wizard . 
 

 2 .  Run the Costing for Past Balance Date program for the same date. 
 

 3 .  Record your initial inventory count for the day after the costing initialization date. 
 

 4 .  While recording your inventory of raw materials, do one of the following: 
 

 ·              If you possess a list of actual values for your raw materials, designate the value of each batch in the Cost column. Dual-currency users can choose either the local- or second-currency Cost columns, according to their company's method of price management. 
 Tip: For assistance, run the Initial Inventory Count Wizard . 
 

 ·              Otherwise, leave the Cost column empty. During the next costing run, it will be filled in according to the default standard costs used to calculate the transaction cost. 
 

 5 .  Record a past balance for the day of the inventory count, and run the Costing for Past Balance Date program again for the same day. You can now work in Priority and run costing again at whatever interval your company records past balances.
