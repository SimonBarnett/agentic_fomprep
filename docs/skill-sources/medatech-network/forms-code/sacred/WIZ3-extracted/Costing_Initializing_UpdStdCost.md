# Setting the UpdStdCost Constant 

 

The UpdStdCost constant determines whether the latest standard costing results for assembled parts overwrite current standard cost definitions for those parts (e.g., the Std Cost appearing in the Part Catalogue form). When set to 1 , standard costs of assembled parts are updated at the end of every costing run. 
 
## To set the constant:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the line for the UpdStdCost constant and select the desired value.
