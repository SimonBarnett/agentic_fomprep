# Recording Standard Costs of Assembled Parts

 

Standard costs of assembled (Type P ) parts are calculated by the costing program, on the basis of child part costs, using either the Std Material Cost or Actual Material Cost method. These are the values that are used by the system in costing reports, and in calculations of inventory values. 
 

Note that you can define a standard cost in the Part Catalogue form for Type P parts. By default, this value is not updated by the standard cost calculated by the costing program, and is not taken into account in costing and inventory valuation reports based on calculated standard costs, unless the UpdStdCost constant is set to 1 .
