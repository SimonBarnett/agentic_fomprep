# Costing History

 

The History of Costing Runs form displays a full history of all costing-related programs, including Delete Costing Results and Set Costing Parameters , providing such details as who ran them, for what date, and when. 
 
## To view the costing history:

 

 ·        Enter the History of Costing Runs form and run a query by costing date, username or run date.
