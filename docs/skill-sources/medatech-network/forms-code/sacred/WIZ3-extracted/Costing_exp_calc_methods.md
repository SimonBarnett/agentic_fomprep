# Methods of Costing Calculation

 

 Priority offers you a choice between two methods of calculating cost: Moving Average and FIFO . 
 

In the dual-currency package, the system automatically links the cost of all inventory transactions to the index for both methods. You also have the option of choosing FIFO Adjusted , which uses the FIFO method and adjusts local-currency costs as follows: costs that were initially converted from the second currency are adjusted according to the exchange rate on the costing date, while costs that were initially recorded in the local currency are adjusted according to the index on the costing date.
