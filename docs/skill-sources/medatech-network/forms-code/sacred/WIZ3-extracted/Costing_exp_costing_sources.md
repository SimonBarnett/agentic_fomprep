# Costing Parts and Inventory Transactions

 

The costing program calculates the part costs and inventory transaction costs of purchased parts on the basis of a variety of sources, according to a defined hierarchy. This hierarchy is determined by the reliability and accuracy of the cost source. For instance, the price appearing in a purchase invoice is more accurate than the vendor's list price, as it reflects the price that is actually paid. 
 

When a part enters inventory, the cost of the transaction is determined immediately, according to the most accurate cost source available at the time. Later, when you run costing, the program updates the transaction cost according to the most accurate source available then. Example .
