# Maintaining Costing Data

 

 Costing Analysis for Businesses uses a wide variety of data in its calculations. Generally, these data are recorded during initialization of the costing system; however, these initial definitions can be updated at any time, for example, when standard costs or shipping costs are revised, or in order to define new warehouses that were added to the system. 
 
## What do you want to do?

 

 View and update standard part costs 
 

 Define standard shipping costs 
 

 Define warehouse settings 
 

 Update lot costs 
 

 View costing data for transactions recorded since the last costing run
