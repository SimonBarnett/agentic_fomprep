# Unlocking a Costing Run

 

When one user runs costing, no one else can run it until the first user is done. Sometimes, a costing run may become frozen and/or is unable to end properly. When this happens, no one can run costing until the program is unlocked. 
 
## To unlock a costing run:

 

 ·        Run the Unlock Costing Run program.
