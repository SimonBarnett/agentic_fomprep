# Viewing Transaction Costing Data 

 

 ·        Run the Actual Cost Analysis report to view the costs of the inventory transactions used to calculate a given part's actual cost. The report also displays the part's average unit price after each transaction, according to the defined costing method: FIFO or Moving Average.
