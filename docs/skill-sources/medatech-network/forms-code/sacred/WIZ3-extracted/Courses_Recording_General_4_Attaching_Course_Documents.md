# Attaching Course Documents

 

You can attach files containing documents associated with the course (e.g., a syllabus, a reading list). 
 
## To attach course documents: 

 

 1 .  Enter the Documents for the Course form (another sub-level of the Courses of Study form). 
 

 2 .  In the File Name column, attach the file. 
 

 3 .  Record a date and description of the document.
