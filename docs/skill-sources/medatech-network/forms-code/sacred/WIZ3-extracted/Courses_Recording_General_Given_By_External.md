# If the course is being given by an external organization, do the following: 

 

 1 .  Make sure a vendor record exists for the external organization in the Vendors form.
 Note: For information on how to open a vendor record, see the Open Vendors Wizard . 
 

 2 .  The external instructor needs to be recorded in the system as a contact. If you are not sure that he/she has been recorded, do the following: 
 

 a. Enter the Vendors form and retrieve the record for the external organization. 
 

 b. Enter the Vendor Contacts sub-level form and press F4 . If the external instructor does not appear, record his/her name and any other desired information.
