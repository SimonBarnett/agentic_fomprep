# Recording Positions Requiring the Course

 

If employees must take the course in order to be able to hold certain job positions at your company, you can record this. 
 

 To record positions requiring the course: 
 

 ·        Enter the Positions Requiring the Course form (a sub-level of the Courses of Study form) and choose the position code.
