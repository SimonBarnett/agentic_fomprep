# Setting Up Business Processes for Courses

 

You set up business processes by defining statuses in a BPM flow chart. This helps you keep track of what stage each course is in. 
 

You can create statuses , define paths between them, create work flow rules and set status properties . 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Courses program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Courses form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
