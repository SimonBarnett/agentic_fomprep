# Defining Course Credits

 

If participants earn credits for courses, create a list of the various levels of credit that can be earned. 
 
## To define course credits:

 

 1 .  Enter the Course Credits form. 
 

 2 .  Record a Code for each level of credit. 
 

 3 .  In the Description(Credits) column, record the amount of credit in words (e.g., one credit, six credits). 
 

 4 .  In the Credits column, record the amount of credit as a decimal number (e.g., 1.00, 0.50).
