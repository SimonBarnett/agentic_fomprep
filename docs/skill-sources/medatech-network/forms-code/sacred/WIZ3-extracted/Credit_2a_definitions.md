# Setting Up Customer Credit

 

Before you begin working with customer credit, you must take the following steps: 
 

 ·        Define parameters that determine when warning and error messages appear for customers that have exceeded their credit 
 

 ·        Define whether tax is included in credit calculations 
 

 ·        Define the type of message received when the customer exceeds the credit limit 
 

 ·        Define how sales orders are handled during credit calculations 
 

 ·        For dual-currency users: Define the validation period for postdated checks that come due. 
 
## What do you want to do?

 

 Define warning and error message parameter s 
 

 Define how tax is handled 
 

 Define the type of message 
 

 Determine how sales orders are handled 
 

 Determine how service calls are handled 
 

 Define the check validation period
