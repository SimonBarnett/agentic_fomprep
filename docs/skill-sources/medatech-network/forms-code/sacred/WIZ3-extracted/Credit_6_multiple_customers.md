# Updating Liability Data Before Viewing

 

While all credit data (orders, shipments, open debt) is calculated on-line, postdated check data is not. Thus, in order to view up-to-date liability amounts, you must run a program that calculates data for postdated checks. 
 
## To calculate data for postdated checks:

 

 ·        Run the Calculate Credit program. 
 
## Tip: 

 

It is recommended to use the Tabula Task Scheduler to run this program overnight.
