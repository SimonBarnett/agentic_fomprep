# To set up a credit card account:

 

 1 .  Enter the Credit Card Accounts form. 
 

 2 .  Record a code. You should use the account number of the matching GL account. 
 

 3 .  Record the name of the credit card company. 
 

 4 .  If you opened ledger accounts automatically, the number of the account defined for this credit card company appears in the GL Account column. Otherwise, do one of the following: 
 

 ·      If you opened general ledger accounts manually, specify the number of the account defined for this credit card company. 
 

 ·      Click if you haven ' t yet opened the GL account. 
 

 5 .  In the Payment Code column, choose the payment means code you created for this credit card company.
 Notes: 
 

 ·      If you created more than one payment means for this credit card company, leave this column blank. 
 

 ·      Click to define a new means of payment. 
 

 6 .  Fill in the Fee (%) column with the percentage of payment that the credit card company charges as its fee.
 Note: When incoming credit card vouchers are recorded in the system, the fee is computed automatically on the basis of this value. 
 

 7 .  If the credit card account is used by a particular branch, specify the Branch Code . 
 Note: If you work with subsidiaries and want to link the credit card account to a subsidiary, link the account to a branch office that is linked to the subsidiary.
