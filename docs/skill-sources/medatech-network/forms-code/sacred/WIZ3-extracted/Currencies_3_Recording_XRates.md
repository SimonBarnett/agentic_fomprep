# Recording Exchange Rates

 

Exchange rates are recorded for specific dates. In this manner, Priority maintains a history of rates for reference. 
 
## To record exchange rates:

 

 1 .  Enter the Exchange Rates form and specify the date for which you are recording exchange rates. 
 

 2 .  Enter the Itemized Rates sub-level form. For each currency you work with, record the Exchange Rate . Example. 
 Notes : 
 

 ·                  To avoid errors, the system issues a warning message if the new exchange rate deviates from the permitted percentage of fluctuation defined for the MaxCurrAdj constant in the Financial Constants form. 
 

 ·                  The system notifies you if exchange rates haven't been updated in the last few days, as defined for the ExchangeUpdDays constant in the Financial Constants form. 
 

 ·                  You only need to record a new exchange rate for those currencies whose rates have changed. If the rate is the same, leave 0 in the column. Priority will continue to use the previous rate. 
 

 3 .  You can view the current exchange rate in the Current Rate column. This column is updated automatically with the new exchange rate when you leave the line.
