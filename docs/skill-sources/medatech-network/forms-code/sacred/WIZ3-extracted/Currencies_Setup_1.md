# Setting Up Currencies

 
## Note:

 

Click to set up currencies in a multi-company system. 
 
## For dual-currency users only:

 

 ·           Run the Update Local & Second Currencies program to select your local and second currencies. 
 
## For both single- and dual-currency users:

 

 1 .  Enter the Currencies form. The full list of currencies is displayed. 
 

 2 .  Make sure that the smallest unit of the local currency appears in the Subdivision column (e.g., cents). This value appears in various documents (e.g., check printouts).
