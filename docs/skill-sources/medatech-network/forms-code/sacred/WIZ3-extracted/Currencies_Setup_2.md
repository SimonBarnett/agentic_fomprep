# Setting Up the MaxCurrAdj Constant

 

The MaxCurrAdj constant determines the accepted range of fluctuation in exchange rate updates. If a new rate is recorded that deviates from the defined fluctuation percentage in either direction, a warning message is received. Example. 
 
## To set the constant:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the MaxCurrAdj constant. 
 

 3 .  Record the percentage of an exchange rate within which the rate may fluctuate without generating a warning.
