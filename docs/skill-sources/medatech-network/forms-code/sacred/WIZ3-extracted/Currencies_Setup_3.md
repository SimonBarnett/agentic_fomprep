# Setting Up the ExchangeUpdDays Constant

 

The ExchangeUpdDays constant determines the number of business days that should pass before you receive notification that exchange rates should be updated. 
 
## To set the constant:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the ExchangeUpdDays constant. 
 

 3 .  Choose a value between 0 and 5. If you don't want exchange rates to be checked at all, specify a value of 999.
