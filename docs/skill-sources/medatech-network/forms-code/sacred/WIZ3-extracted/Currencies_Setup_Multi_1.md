# Currencies and Exchange Rates in a Multi-Company Environment

 

Financial data is managed independently for each company in a multi-company environment. You can, however, view financial reports that include data from some or all of the companies at once. 
 

Exchange rates can be set up once and updated automatically across all companies. Whenever you update exchange rates in one of the companies, the rates are updated automatically in the entire system. 
 
## To set up currencies and exchange rate sharing:

 

 1 .  Enter the company you want to set up. 
 

 2 . Dual-currency users only: Run the Update Local & Second Currencies program to select your local and second currencies.
 Note: Financial reports will only contain meaningful information if all companies share at least one common currency – either the local currency or the second currency must be identical in all companies. 
 

 3 .  Enter the Currencies form. The full list of currencies is displayed. 
 

 4 .  Make sure that the smallest unit of the local currency appears in the Subdivision column (e.g., cents). This value appears in various documents (e.g., check printouts). 
 

 5 .  Enter the Companies form and flag the MultiCo Exch Rates column to share updated exchange rates with other companies in the system. 
 
## Note:

 

If you do not have privileges to work in the Companies form, ask your System Manager to set this up for you.
