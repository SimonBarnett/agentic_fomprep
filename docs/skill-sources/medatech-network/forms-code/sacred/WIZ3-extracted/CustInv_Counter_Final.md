# Finalizing Over-the-Counter Invoices

 

When you finalize an over-the-counter invoice, the following occurs: 
 

 ·        A unique internal invoice number is generated, which replaces the temporary number that appeared when the invoice was opened. 
 

 ·        The balance of the designated cashier is updated. 
 

 ·        A journal entry is recorded for the invoice. 
 

 ·        The status of the invoice is set to Final . 
 
## Notes:

 

 ·        If you did not flag the Post Journ. Entries column for over-the-counter invoices (in the Financial Documents form), the journal entry created is only temporary. That is, it needs to be checked and posted. 
 

 ·        Inventory levels are adjusted when line items are recorded in the invoice, NOT when the invoice is finalized.
