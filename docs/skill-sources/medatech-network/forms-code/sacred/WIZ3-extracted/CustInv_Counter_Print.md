# Printing Over-the-Counter Invoices

 
## Before you begin: Checking remarks

 

 1 .  Enter the Over-the-Counter Invoices form and retrieve the desired invoice. 
 

 2 .  Enter the Invoice/Memo - Remarks sub-level form. Check the text recorded there, which will appear in the invoice printout. Revise it if necessary. 
 

 3 .  If you are printing invoices with item remarks , move to the parallel Invoice Items sub-level form. For each item, make sure that the remarks recorded in the Invoice Item - Remarks sub-level form are suitable. Explanation. Revise them if necessary.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 4 .  Return to the Over-the-Counter Invoices form. 
 
## To print a single invoice:

 

 ·        Select Print Over-the-Counter Invoice from the list of Direct Activations .
 Note: To simultaneously finalize and print the invoice, select Finalize & Print Invoice from the list of Direct Activations . 
 
## To print a batch of invoices:

 

 ·        Run the Print Over-the-Counter Invoice program. 
 
## Notes:

 

 ·        When the invoice is for an order with a customized bill of materials, use the With Custom BOM print format to include child parts in the printout. 
 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to set up sending invoices as e-documents. 
 

 ·        Click to return to the Over-the-Counter Invoices menu .
