# Viewing Payments Recorded in Over-the-Counter Invoices

 

You can run a report that displays payments recorded in over-the-counter invoices (and customer receipts), sorted into those received by cashiers, banks (for bank transfers) and credit card companies. 
 
## To view payment details:

 

 ·        Run the Receipts by Cashier report. 
 
## Note: 

 

This report only includes final over-the-counter invoices and receipts.
