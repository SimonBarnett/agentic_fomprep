# Canceling a Final Credit Memo

 

If errors are discovered in a final memo, you can create a new memo that cancels the original one and creates a reversing journal entry. 
 
## To cancel a final credit memo:

 

 1 .  Enter the Multi-Shipment Invoices form and retrieve the desired memo. 
 

 2 .  Do one of the following: 
 

 ·              Select Cancel Document (Original Date) from the list of Direct Activations to create a cancellation memo and reversing journal entry dated to the original memo date. 
 

 ·              Select Cancel Document For Date from the list of Direct Activations to create a cancellation memo and reversing journal entry for a designated date. 
 
## Notes:

 

 ·        In order to cancel a final memo whose journal entry is still pending, you must post the entry before running the cancellation program. 
 

 ·        You must be authorized to change the status of credit memos (and multi-shipment invoices) to Canceled . 
 
## To view cancellation results:

 

 ·        Every canceled memo and the memo that canceled it are flagged in the Canceled column of the Price tab. Both memos will be for the same amount, one with positive values and the other negative.
