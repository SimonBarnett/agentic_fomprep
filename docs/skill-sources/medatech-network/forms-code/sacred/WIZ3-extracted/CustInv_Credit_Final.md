# Finalizing Credit Memos

 

When you finalize a credit memo, the following occurs: 
 

 ·        A unique internal memo number is generated, which replaces the temporary number that appeared when the memo was opened. 
 

 ·        If the memo is based on a return document, the Credited column in the document is flagged. 
 

 ·        A journal entry is recorded for the memo. 
 

 ·        The memo is automatically reconciled, either partially or fully, with the original invoice. 
 

 ·        The status of the memo is set to Final . 
 
## Note:

 

If the Post Journ. Entries column is not flagged for credit memos (in the Financial Documents form), the journal entry created is only pending. That is, it needs to be checked and posted.
