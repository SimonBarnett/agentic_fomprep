# To record additional details:

 

 1 .  Return to the Export Invoices upper-level form. 
 

 2 .  Click the Price tab. The Total Before Discount , Overall Discount and Amount Owing appear automatically, according to the itemized memo. If necessary, revise the overall discount or the amount owing. 
 

 3 .  If the credit memo needs to be checked before it is sent to the customer, assign it the Checking status (in the References tab). In the Assigned to column, specify the username of the person who is responsible for checking the document. The memo cannot be finalized until this status is changed. 
 Tip: You can define work flow rules so that the assigned user changes automatically when the status is assigned. 
 

 4 .  Move to the Invoice - Add'l Details sub-level form. 
 

 5 .  Make sure that the Entry Code and Transaction Date are correct.
