# Printing Export Credit Memos - Before You Begin

 
## To check remarks: 

 

 1 .  Enter the Export Invoices form and retrieve the desired memo. 
 

 2 .  Enter the Invoice/Memo - Remarks sub-level form. Check the text recorded there, which will appear in the memo printout. Revise it if necessary. 
 

 3.  Return to the Export Invoices form. 
 
## To verify the customer's mailing address:

 

 ·        Move to the Invoice - Add'l Details sub-level form. Check the recorded address. If you want to send the memo to a different address, change the address details in this form.
 Tip: To permanently change the customer's mailing address, use the Customers form.
