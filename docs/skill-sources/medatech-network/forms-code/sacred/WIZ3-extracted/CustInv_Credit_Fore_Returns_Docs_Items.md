# To itemize the credit memo:

 

 1 .  Enter the Invoice Items sub-level form. The parts, with their quantities, prices and discounts, are filled in automatically according to the original return document(s). 
 

 2 .  If the item was linked to a budget item in the original document, it appears automatically in the Budget Item column. If necessary, you can revise this value or add a new one.
 Tip: To view information on usage of this budget item, enter the Budgeted vs. Actual sub-level form. 
 

 3 .  Click to link a line item to a project or project activity . 
 

 4 .  Check the Income Account . Revise it if necessary. Explanation.
