# Preparing an Export Credit Memo for Returned Goods

 

As credit memos have no effect on inventory levels, memos for returns are always based on one or more (final) return documents, recorded in the Customer Returns form. 
 

There are several ways to prepare credit memos: 
 

 ·        You can record an export credit memo manually, itemizing it on the basis of one or more return documents. 
 

 ·        You can use a program to prepare a batch of credit memos for designated return documents.
 Note: If you run the program for shipments as well as returns, separate credit memos will only be opened if there are no shipped items for this customer. Otherwise, credit for the returned goods will appear within the invoice for the shipments (with negative quantities). 
 

 ·        You can prepare an export credit memo automatically for a single return document, from within that document. 
 
## Note:

 

An export credit memo will only be prepared in the latter two instances if the customer is defined as a foreign customer . 
 
## What do you want to do?

 

 Record an export credit memo based on one or more return documents 
 

 Prepare a batch of export credit memos (and export invoices) automatically 
 

 Prepare an export credit memo for a single return document 
 
## Tip:

 

For information on recording a return document, see the Customer Shipment/Return Wizard .
