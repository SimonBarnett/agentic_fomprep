# To print a credit memo:

 

 1 .  Enter the Multi-Shipment Invoices form and retrieve the desired memo. 
 

 2 .  Select Print Invoice/Credit Memo from the list of Direct Activations .
 Note: To simultaneously finalize and print the memo, select Finalize & Print Invoice/Memo from the list of Direct Activations . 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to set up sending credit memos as e-documents. 
 

 ·        Click to return to the Credit Memos menu .
