# To check the memo items:

 

 1 .  Enter the Invoice Items sub-level form. The parts, with their quantities, prices and discounts, are filled in automatically according to the original return document. 
 

 2 .  If the item was linked to a budget item in the original document, it appears automatically in the Budget Item column. If necessary, you can revise this value or add a new one.
 Tip: To view information on usage of this budget item, enter the Budgeted vs. Actual sub-level form. 
 

 3 .  Click to link a line item to a project or project activity . 
 

 4 .  Check the Income Account . Revise it if necessary. Explanation. 
 

 5 .  Enter the Invoice Item - Remarks sub-level form and check the remarks that appear there. Revise or add to them, as desired.
 Notes: 
 

 ·              The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 ·              To include these remarks in the printout of the invoice, select a suitable print format .
