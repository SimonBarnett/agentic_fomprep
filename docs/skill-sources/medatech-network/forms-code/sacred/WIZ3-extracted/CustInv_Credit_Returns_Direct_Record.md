# To prepare a credit memo for a specific return document:

 

 1 .  Enter the Customer Returns form and retrieve the desired return document. 
 

 2 .  Select Prepare Invoice/Credit Memo from the list of Direct Activations . 
 

 3 .  Select Multi-Shipment Invoices from the list of Direct Activations to retrieve the memo opened by the program. The number of the original document appears in the Document column (in the References tab).
 Notes: 
 

 ·              If the document is linked to a project, the project number appears in the Project tab. More details. 
 

 ·              At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column. 
 

 4 .  Check the Contact column to make sure that the relevant memo contact appears. Change it if necessary.
 Tip: To define new contacts for the customer or to assign a default contact for invoices (which also affects credit memos), use the Customer Contacts form, a sub-level of the Customers form. For more information, see the Open Customers Wizard . 
 

 5 .  Click the Financial Terms tab. Make sure that the Tax Code is correct (for dual-currency users: VAT Code ).
