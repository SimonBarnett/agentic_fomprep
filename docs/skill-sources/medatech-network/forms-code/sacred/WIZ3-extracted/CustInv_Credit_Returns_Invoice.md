# Recording a Credit Memo Against a Sales Invoice

 

If the returned goods were originally billed in a sales invoice, you record the credit memo in the same form, designating negative quantities. As a result, the customer account is credited and the returned goods are added to inventory. 
 
## Note:

 

In order to assign such credit memos a separate number from regular sales invoices, make sure the Negative Sum Counter option is flagged in the Financial Documents form. Printouts of such memos will display credits as positive amounts. 
 

As with a regular sales invoice, the memo can be based on one or more sales orders, so that it is itemized automatically, or recorded manually.
