# Manually Recording Credit for Returned Parts

 

You can record credit for returned goods by recording the credit memo manually. 
 
## To open the credit memo:

 

 1 .  Enter the Sales Invoices form.
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column. 
 

 2 .  Specify the number of the customer to which credit is due. 
 Notes: 
 

 ·              Click if there is a billing customer . 
 

 ·              In the case of a walk-in customer, record the walk-in customer number. Then revise the name in the Cust. Name column, and fill in the address and other details in the Invoice - Add'l Details sub-level form. 
 

 ·              A temporary memo number (prefixed with a T ) is filled in automatically in the Invoice No. column when you leave the field. It will be replaced by a permanent number when the document is finalized. This will serve as the credit memo number in the printout. 
 

 3 .  Check the Contact column to make sure that the relevant contact appears. Change it if necessary.
 Tip: To define new contacts for the customer, use the Customer Contacts form, a sub-level of the Customers form. For more information, see the Open Customers Wizard . 
 

 4 .  Today's date is filled in automatically as the memo date. Change it if necessary.
 Note: The memo date determines the reference date in the journal entry for the credit memo. 
 

 5 .  In the Details column, record a brief remark regarding the credit. 
 

 6 .  If the credit is against a project, record the project number in the Project tab. More details. 
 

 7 .   Click the Financial Terms tab. Make sure that the Tax Code is correct (for dual-currency users: VAT Code ). 
 

 8 .  Click the Shipment tab. The default Warehouse and Bin appear automatically. Revise them if necessary with the warehouse into which goods were returned.
 Note: If goods were returned to more than one warehouse (or bin), designate the main one here. When itemizing the credit memo, indicate the warehouse for each part.
