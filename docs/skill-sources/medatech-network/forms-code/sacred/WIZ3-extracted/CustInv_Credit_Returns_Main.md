# Preparing a Credit Memo for Returned Goods

 

If the goods were originally billed in a multi-shipment invoice, the credit memo is recorded in the same form and thus will have no effect on inventory levels. Such credit memos are always based on one or more (final) return documents, recorded in the Customer Returns form. 
 

There are several ways to prepare credit memos: 
 

 ·        You can use a program to prepare a batch of credit memos for designated return documents.
 Note: If you run the program for shipments as well as returns, separate credit memos will only be opened if there are no shipped items for this customer. Otherwise, credit for the returned goods will appear within the invoice for the shipments (with negative quantities). 
 

 ·        You can record a credit memo manually, itemizing it automatically on the basis of one or more return documents. 
 

 ·        You can prepare a credit memo automatically for a single return document, from within that document. 
 
## What do you want to do?

 

 Prepare a batch of credit memos (and multi-shipment invoices) automatically 
 

 Record a credit memo based on one or more return documents 
 

 Prepare a credit memo for a single return document automatically 
 
## Tip:

 

For information on recording a return document, see the Customer Shipment/Return Wizard .
