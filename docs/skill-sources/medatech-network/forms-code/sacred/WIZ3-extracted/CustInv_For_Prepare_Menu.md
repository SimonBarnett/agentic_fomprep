# Recording an Export Invoice 

 
## There are various ways to record an export invoice:

 

 ·        You can use a program to prepare a batch of invoices for groups of documents or for transactions linked to a given project. 
 Note: This method should be used when working with projects (though it is also useful where projects are not involved). 
 

 ·        You can prepare an export invoice for a single document from within that document. 
 

 ·        You can open an export invoice manually, itemizing it automatically on the basis of one or more documents. 
 

 ·        You can record an export invoice manually for charges that are unrelated to any inventory transaction (e.g., to bill for consultations or training). 
 
## What do you want to do?

 

 Prepare a batch of invoices automatically 
 

 Prepare an invoice for a single document automatically 
 

 Record an invoice based on one or more documents 
 

 Record an invoice manually
