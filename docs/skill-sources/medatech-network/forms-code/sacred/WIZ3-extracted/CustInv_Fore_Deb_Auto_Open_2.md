# To prepare invoices/memos automatically:

 

 ·        Run the Prepare Invoices program. 
 
## Tips:

 

 ·        If you were unable to clear all pending invoices/memos prior to running the program, make a note of the invoice/memo numbers in the message appearing at the completion of the program. 
 

 ·        Run the Prepare Invoices - Errors report to view documents for which invoices/memos could not be prepared. 
 

 ·        The Prepare Invoices program simultaneously prepares multi-shipment invoices (and credit memos) for local customers.
