# Deleting a Pending Export Invoice

 

Pending invoices are invoices that have not yet been finalized and can be deleted from the system. 
 
## To delete a pending invoice:

 

 1 .  Enter the Export Invoices form and retrieve the desired invoice. 
 

 2 .  Select Delete Pending Invoice/Memo from the list of Direct Activations . 
 
## Note:

 

Click to return to the Export Invoices menu .
