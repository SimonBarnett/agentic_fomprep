 6 .  Do one of the following: 
 

 ·              To base the invoice on one document, click the References tab and fill in the Document column with the document number and type. Details are filled in automatically from the document, but may be revised. 
 

 ·              To base the invoice on multiple documents, leave the Document column blank, and enter the Documents for Invoice sub-level form.  7 .  If the invoice has already been recorded externally by a sales rep, specify the document number in the Rep Inv. No. column. Because the external document has already been issued, the Printed column in the Price tab is flagged. 
 

 8 .  The overall discount, applied to the entire invoice, is calculated automatically from the overall discounts assigned to each document. If you want to override that discount, or if no discount was given in any document and you want to award one now, use the Set Overall Disc. % column in the Payment Info tab.
