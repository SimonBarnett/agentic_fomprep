# Notes:

 

This wizard does not cover cash-based accounting, in which you prepare pro forma invoices and later prepare multi-shipment invoices based on receipts. If you work on a cash basis, click to run the Cash-Based Accounting Wizard instead. 
 

For information on distributing shipping and other expenses among sold parts, run the Outgoing Shipping Voucher Wizard . 
 

If you are working with the Fashion module and you need to itemize an invoice or memo manually, run the Fashion Wizard to learn how to record style assortments. 
 

 Dual-currency users: Prices are adjusted in invoices/credit memos when the original order is linked to a foreign currency, price index or currency basket. User-defined parameters determine the date for which linkage is calculated, whether linked amounts are added to part prices or displayed on a separate line in the invoice/memo, and whether a drop in the exchange rate or index should lower invoice/memo prices or leave them as is. For details, run the Price Adjustment Wizard .
