# To check the results of the program:

 

 1 .  Enter the Multi-Shipment Invoices form and retrieve each invoice opened by the program.
 Notes: 
 

 ·              Credit memos are retrieved in the same form. They are distinguished by a C in the Debit/Credit column. 
 

 ·              To assign handling of an invoice (or memo) to another employee, specify his/her username in the Assigned to column. If you have done so for all prepared documents, you can exit the form and ignore the following instructions. 
 

 2 .  Check the Contact column to make sure that the relevant invoice contact appears. Change it if necessary.
 Tip: To define new contacts for the customer or to assign a default contact for invoices, use the Customer Contacts form, a sub-level of the Customers form. For more information, see the Open Customers Wizard . 
 

 3 .  Click the Financial Terms tab. Make sure that the Tax Code is correct (for dual-currency users: VAT Code ). 
 

 4 .  The overall discount, applied to the entire invoice, is calculated automatically from the overall discounts assigned to each document. If you want to override that discount, or if no discount was given in any document and you want to award one now, use the Set Overall Discount % column. 
 
## Notes:

 

 ·        If the invoice/credit memo was created for a project, the project number appears in the Project tab. More details. 
 

 ·        All documents billed by this invoice (or credited by this memo) can be viewed in the Documents for Invoice sub-level form. If the documents were linked to a project, these links are maintained per line item. 
 

 ·        Click to troubleshoot automatic preparation of invoices.
