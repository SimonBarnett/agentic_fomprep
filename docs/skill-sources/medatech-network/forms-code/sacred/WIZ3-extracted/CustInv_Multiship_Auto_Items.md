# To check the invoice items:

 

 1 .  Enter the Invoice Items sub-level form. The parts, with their quantities and other details, are filled in automatically according to the document(s) linked to the invoice/memo. 
 Note: If you revise the invoiced quantity manually, the original document (e.g., shipping document, service call) will be flagged as billed, even though it was only partially invoiced. To access such documents for later billing, run the Partially Billed Documents report. 
 

 2 .  Make sure that prices and discounts are correct.
 Note: If you set the percentage of overall discount in the upper-level form, the new discount percentage appears here. 
 

 3 .  If the item was linked to a budget item in the original document, it appears automatically in the Budget Item column. If necessary, you can revise this value or add a new one. 
 Tip: To view information on usage of this budget item, enter the Budgeted vs. Actual sub-level form. 
 

 4 .  Click to link this line item to a project or project activity . 
 

 5 .  Check the Income Account . Revise it if necessary. Explanation. 
 

 6 .  The sales rep and the commission percentage due for the line item appear automatically. Revise them as necessary. 
 

 7 .  Enter the Invoice Item - Remarks sub-level form and check the remarks that appear there. Revise or add to them, as desired.
 Notes: 
 

 ·              The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 ·              To include these remarks in the printout of the invoice, select a suitable print format .
