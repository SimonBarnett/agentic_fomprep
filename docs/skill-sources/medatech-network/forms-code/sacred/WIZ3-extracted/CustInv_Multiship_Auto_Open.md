# Preparing a Batch of Multi-Shipment Invoices and Credit Memos Automatically

 

The Prepare Invoices program automatically opens multi-shipment invoices (and credit memos): 
 

 ·        for selected documents 
 

 ·        for all documents within a given period 
 

 ·        for a project 
 
## Note:

 

If customer returns are included together with shipments to this customer, they will appear (with negative quantities) alongside the shipped items in the same invoice. If there are only returns for a given customer, they will be included in a separate credit memo. 
 
## Before you begin:

 

 1 .  Make sure you have performed all setups for multi-shipment invoices and credit memos. Most of these setups directly affect the outcome of this program.
 Tip: Click to access the setup menu . 
 

 2 .  If possible, finalize or delete all pending invoices/memos (run the Finalize Invoices or Delete Pending Invoices program, respectively). This will make it easier to retrieve the invoices/memos opened by the program, as only the new ones will have temporary numbers (with the prefix T ). 
 
## Tip:

 

If you want to bill a particular shipment on a separate invoice regardless of system configurations, flag the Separate Invoice column in the Customer Shipments or Revision of Final Shipping Doc. form.
