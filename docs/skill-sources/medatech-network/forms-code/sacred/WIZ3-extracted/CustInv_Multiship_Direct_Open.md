# To prepare a multi-shipment invoice for a specific document:

 

 1 .  Enter the appropriate form for the document you wish to bill: 
 

 Customer Shipments 
 

 Service Calls 
 

 Service Contracts 
 

 2 .  Retrieve the desired document. 
 

 3 .  Select Prepare Invoice/Credit Memo from the list of Direct Activations . 
 

 4 .  Select Multi-Shipment Invoices from the list of Direct Activations to retrieve the invoice opened by the program. The number and type of the original document appears in the Document column (in the References tab).
 Notes: 
 

 ·              If the document is linked to a project, the project number appears in the Project tab. More details. 
 

 ·              At any point in the following process, you can transfer handling of the invoice to another employee, by specifying his/her username in the Assigned to column.
