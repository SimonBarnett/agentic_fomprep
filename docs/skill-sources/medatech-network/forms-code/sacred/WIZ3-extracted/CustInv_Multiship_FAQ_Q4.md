# Opening an Invoice for All Project Documents

 

Yes. You can set a financial constant that causes the Prepare Invoices program to create one invoice for all open project documents. 
 

 1 .  Enter the Financial Constants form. 
 

 2 .  Set the OneInvPerPrj constant to 1 . 
 
## Note:

 

 ·        A few conditions must be met in order for the transactions to be billed together in the same invoice: 
 

 ·        They must have the same tax code (for dual-currency users: VAT code). 
 

 ·        They must generate the same branch in the invoice (as determined by the InvoiceBranch constant).
