# Finalizing Multi-Shipment Invoices

 

When you finalize a multi-shipment invoice, the following occurs: 
 

 ·        A unique internal invoice number is generated, which replaces the temporary number that appeared when the invoice was opened. 
 

 ·        If the invoice is based on documents, the Billed column in each document is flagged. 
 

 ·        A journal entry is recorded for the invoice. 
 

 ·        The status of the invoice is set to Final . 
 
## Note:

 

If the Post Journ. Entries column is not flagged for multi-shipment invoices (in the Financial Documents form), the journal entry created is only pending. That is, it needs to be checked and posted.
