# Before you begin:

 

 1 .  Enter the Multi-Shipment Invoices form and retrieve the desired invoice. 
 

 2 .  Click the References tab and check the invoice's Status . You will only be able to finalize the invoice if its current status allows for finalization (e.g., it is assigned the Approved status).
 Note: You must also be authorized to change the status of multi-shipment invoices/credit memos to Final . 
 
## To finalize the invoice:

 

 ·        Select Finalize Invoice/Memo from the list of Direct Activations . 
 
## To finalize and print the invoice:

 

 ·        Select Finalize & Print Invoice/Memo from the list of Direct Activations . 
 
## To finalize a batch of invoices:

 

 ·        Run the Finalize Invoices program. 
 
## Notes:

 

 ·        If any of the invoices were not finalized by the program, run the Finalize Invoices - Errors report to find out why. 
 

 ·        Click to return to the Multi-Shipment Invoices menu .
