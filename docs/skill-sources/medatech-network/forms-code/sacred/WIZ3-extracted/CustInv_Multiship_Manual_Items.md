# To itemize the invoice:

 

 1 .  Enter the Invoice Items sub-level form. 
 

 2 .  Specify the Part Number of a non-inventory part (e.g., the predefined “000” part) and change its Part Description as necessary.
 Note: Click to define a new general-purpose non-inventory part . 
 

 3 .  Record the Quantity to be billed. 
 

 4 .  Make sure that prices and discounts are correct.
 Note: If you set the price list for this invoice, prices will be taken from there but may be revised. 
 

 5 .  If you work with budgets, specify a Budget Item . 
 Tip: To view information on usage of this budget item, enter the Budgeted vs. Actual sub-level form. 
 

 6 .  Click to link this line item to a project or project activity . 
 

 7 .  Check the Income Account . Revise it if necessary. Explanation. 
 

 8 .  Enter the Invoice Item - Remarks sub-level form and check the remarks that appear there. Revise or add to them, as desired.
 Notes: 
 

 ·              Any part remarks recorded in the part catalogue appear in this form automatically if Copy Part Remarks has been flagged for multi-shipment invoices (in the Copy Part Remarks to Document form). 
 

 ·              The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 ·              To include these remarks in the printout of the invoice, select a suitable print format .
