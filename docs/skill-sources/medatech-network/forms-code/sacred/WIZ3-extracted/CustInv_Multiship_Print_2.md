# Printing Multi-Shipment Invoices

 
## To print a single invoice:

 

 1 .  Enter the Multi-Shipment Invoices form and retrieve the desired invoice. 
 

 2 .  Select Print Invoice/Credit Memo from the list of Direct Activations .
 Note: To simultaneously finalize and print the invoice, select Finalize & Print Invoice/Memo from the list of Direct Activations . 
 
## To print a batch of invoices:

 

 ·        Run the Print Invoice/Credit Memo program. 
 
## Notes:

 

 ·        When the invoice is for an order with a customized bill of materials, use the With Custom BOM print format to include child parts in the printout. 
 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to set up sending invoices as e-documents. 
 

 ·        Click to return to the Multi-Shipment Invoices menu .
