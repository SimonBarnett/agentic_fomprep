# Finalizing Sales Invoices

 

When you finalize a sales invoice, the following occurs: 
 

 ·        A unique internal invoice number is generated, which replaces the temporary number that appeared when the invoice was opened. 
 

 ·        A journal entry is recorded for the invoice. 
 

 ·        The status of the invoice is set to Final . 
 
## Notes:

 

 ·              If you did not flag the Post Journ. Entries column for sales invoices (in the Financial Documents form), the journal entry created is only pending. That is, it needs to be checked and posted. 
 

 ·              Inventory levels are adjusted when line items are recorded in the invoice, NOT when the invoice is finalized. 
 

 ·              Any invoice containing negative quantities (that serves as a credit memo) will be numbered separately, provided the Negative Sum Counter option is flagged in the Financial Documents form for sales invoices.
