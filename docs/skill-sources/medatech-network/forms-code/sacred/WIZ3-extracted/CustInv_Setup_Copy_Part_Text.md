# Copying Part Remarks to Invoices/Memos

 

You can set up customer invoices and credit memos so that part remarks are recorded automatically for individual items when a part number is recorded or revised in an itemized invoice or memo. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for each desired document type, flag the Copy Part Remarks column.
