# Listing Customer Credit Cards and Banks

 

When recording receipt of payment by credit card or check, it is necessary to indicate the type of credit card in question or the bank against which the check is issued. Although this may be done while you are recording the invoice, it is helpful to set up a list of commonly used credit cards and banks where this is feasible. 
 
## To record credit cards:

 

 1 .  Enter the Payment Means form. 
 

 2 .  Make sure that the credit cards you expect customers to use appear in the list. Add as necessary. 
 
## Note:

 

For more details, run the Set Up Credit Card Accts Wizard . 
 
## To record customer banks:

 

 1 .  Enter the Banks form. 
 

 2 .  Make sure that the banks against which customers will be issuing checks are listed. Add new banks as necessary.
