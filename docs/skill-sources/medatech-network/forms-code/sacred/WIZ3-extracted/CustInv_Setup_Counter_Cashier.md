# To check the receiving cashier:

 

 1 .  Enter the Cashiers form. 
 

 2 .  Make sure that a record exists for the cashier to which payment is to be transferred. 
 
## Tip:

 

To open a new cashier, run the Set Up Cashiers Wizard .
