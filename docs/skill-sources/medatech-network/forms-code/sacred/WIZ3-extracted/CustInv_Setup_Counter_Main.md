# Settings for Over-the-Counter Invoices

 

The following setups need to be performed if you record over-the-counter invoices: 
 

 Define a receiving cashier 
 

 List customer credit cards and banks 
 

 Define a default warehouse and bin 
 

 Set how to itemize the invoice when based on an order 
 

 Define packing crates 
 

 Define a holding warehouse (if you record holding invoices ) 
 

 Set the Check SerialNum Qty constant 
 

 Set whether cancellation of an invoice reopens the original order 
 

 Set whether credit card authorization is required before invoices can be finalized
