# To define a default warehouse and bin for over-the-counter invoices:

 

 1 .  Enter the Inv. Transaction Documents form. 
 

 2 .  Move to the Over-the-Counter line. 
 

 3 .  In the Default Warehouse column, choose the desired warehouse. 
 

 4 .  To define a default bin, choose the appropriate value in the Bin column. 
 
## Tip:

 

To define additional warehouses, run the Open a Warehouse Wizard .
