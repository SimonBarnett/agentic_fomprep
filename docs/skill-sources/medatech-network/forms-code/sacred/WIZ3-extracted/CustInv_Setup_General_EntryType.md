# Defining Journal Entry Codes per Customer

 

Entry codes determine how accounts are credited and debited in journal entries. Priority provides a predefined entry code for each type of invoice and for credit memos. 
 

However, you can override the predefined default code for any specific customer, by defining a debit entry code (for invoices) and a credit entry code (for credit memos). 
 
## To define a debit/credit entry code for a customer:

 

 1 .  Enter the Financ. Parameters for Customers form, and retrieve the desired customer. 
 

 2 .  Click the Invoices tab and select the appropriate values in the Debit Entry Code and Credit Entry Code columns. 
 
## Tip:

 

For more details on journal entry codes, run the Set Up Entry Codes Wizard .
