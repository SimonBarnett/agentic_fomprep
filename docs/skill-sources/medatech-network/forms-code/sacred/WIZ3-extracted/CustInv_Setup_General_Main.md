# General Settings for Customer Invoices and Memos

 

Before you can record any kind of invoice (or credit memo), you need to set up: 
 

 Price sources for invoices/memos 
 

 Business processes (BPM) for invoices and credit memos (statuses) 
 

 Invoice/memo properties 
 

 Journal entry types for customers 
 

 How branches are assigned to invoices/memos 
 

 Billing customers 
 

 The employee account for employees who are invoiced 
 

 P art remarks for invoices/memos 
 

 Which customers receive electronic invoices/memos via e-mail
