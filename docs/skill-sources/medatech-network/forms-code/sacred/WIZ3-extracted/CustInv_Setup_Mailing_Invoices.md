# Sending Electronic Invoices/Memos via E-mail

 

Electronic invoicing eliminates the need to mail and archive paper invoices. All electronic documents (e-documents) that are sent to customers must be digitally signed. Before sending e-documents to a given customer, you must obtain their permission, and record this in the system. 
 
## To set up e-documents:

 

 ·        In the Mail menu on the Priority Top Bar, select Mail Options and flag the Are sent e-mails digitally signed by Outlook option.
 Note: If you want these e-mails to be recorded in the system as marketing tasks, make sure the Record e-mail as customer/vendor tasks option is flagged and the MAILCRM constant is set to 1 (in the System Constants form). 
 

 ·        Enter the Financ. Parameters for Customers form. For each customer that has agreed to receive e-Documents, flag the Receives e- D ocuments column.
