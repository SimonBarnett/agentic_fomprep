# Preparing Invoices by Customer Site

 

When working with sales to multiple customer sites, you can decide whether to issue an invoice for each customer site or bill all sites together. 
 

Depending on the value of the OneInvPerS ite constant, the Prepare Invoices program automatically opens one of the following: 
 

 ·        one invoice for all sites (constant = 0 ). 
 

 ·        one invoice per customer site (constant = 1 ). 
 
## Note: The number of invoices opened for the customer is also impacted (among other things) by the OneInvPerSalesRep constant, which can be set to create one invoice per sales rep. 

 
## To set the constant:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the OneInvPerS ite constant and select the appropriate value.
