# Defining Foreign Customers

 

When invoices are prepared automatically, a multi-shipment invoice or credit memo is opened for local customers and an export invoice or export credit memo is opened for foreign customers. You must specify which invoice/memo type to prepare, thereby defining the customer as local or foreign (the default is local customer). 
 
## To define a foreign customer:

 

 1 .  Enter the Financ. Parameters for Customers form and retrieve the desired customer. 
 

 2 .  Click the Invoices tab and change the C to F in the Invoice Type column.
