# Settings for Multi-Shipment Invoices, Export Invoices and Credit Memos

 

Multi-shipment invoices, export invoices (for dual-currency users) and credit memos can be prepared manually or automatically. In the latter case, they can be prepared in a batch by the Prepare Invoices program, or one at a time by direct activation from within a specific document (shipping document, service call, service contract, customer return). 
 

The first setup needs to be performed if you record multi-shipment invoices based on sales orders. The remaining setups need to be performed if you prepare multi-shipment invoices, export invoices and/or credit memos automatically . Some only affect the Prepare Invoices program: 
 

 Determine whether to include closed order items in multi-shipment invoices 
 

 Set invoice/memo date 
 

 Define bank accounts to receive payment for export invoices 
 

 Address invoices and credit memos to billing customer 
 

 Set how documents are invoiced 
 

 Define customers as entitled to delayed billing 
 

 Define customers that receive periodic invoices 
 

 Prepare invoices by sales rep 
 

 CustInv_Setup_Multi/Export_AutoSite Prepare invoices by customer site CustInv_Setup_Multi/Export_AutoSite 
 

 Set which project transactions are invoiced together 
 

 Set up the tax code for invoice preparation 
 

 Define foreign customers (dual-currency users only) 
 

 Set up IBAN and BIC (dual-currency users only)
