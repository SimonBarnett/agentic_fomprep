# Reopening the Original Sales Order When the Invoice is Cancelled

 

You can determine whether cancellation of an invoice will reopen the original sales order. 
 
## To select the desired option:

 

 1 . Enter the Logistic Constants form. 
 

 2 .  Choose the appropriate value for the SOpenOrder constant. 
 
## Note:

 

The constant value also determines whether a customer return will reopen the sales order.
