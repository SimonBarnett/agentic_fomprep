# Settings for Sales Invoices

 

The following setups need to be performed if you record sales invoices: 
 

 Define the default warehouse and bin from which goods are shipped 
 

 Set how to itemize the invoice when based on an order 
 

 Define packing crates 
 

 Define a holding warehouse (if you want to record holding invoices ) 
 

 Set the Check SerialNum Qty constant 
 

 Set how the system determines the order items that are billed 
 

 Indicate whether cancellation of a sales invoice should reopen the original order
