# Set Up Shipment of Ordered Items

 

When shipping goods on the basis of sales orders, you must decide how to itemize the invoice: one line per order item OR multiple lines. Explanation . 
 
## To set this parameter:

 

 1 . Enter the Logistic Constants form. 
 

 2 .  Check the value of the SOnlyOneLine constant and change it, if necessary.
