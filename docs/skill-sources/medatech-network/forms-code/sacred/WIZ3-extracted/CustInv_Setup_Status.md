# Setting Up Business Processes for Invoices and Memos

 

You set up business processes by defining statuses in BPM flow charts. 
 

There are several predefined statuses for each type of customer invoice and for credit memos, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 
## To use the flow charts:

 

 ·        Run one of the following programs: 
 

 BPM Flow Chart-Multi Shipmt Invs (for multi-shipment invoices and credit memos) 
 

 BPM Flow Chart-Sales Invoices 
 

 BPM Flow Chart-Over Counter Invs 
 

 BPM Flow Chart-Export Invoices (for dual-currency users). 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To automatically block finalization until invoices/memos have been checked, flag the predefined Draft status in the Checking column. 
 

 ·        To view the defined properties of all statuses together, enter one of the following forms: 
 

 Statuses for Multi-Shipment Invs (for multi-shipment invoices and credit memos) 
 

 Statuses for Sales Invoices 
 

 Statuses for Over-the-Counter 
 

 Statuses for Export Invoices (for dual-currency users). 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
