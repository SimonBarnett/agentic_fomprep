# Setting Up the Tax Code for Invoice Preparation

 

If you generally ship goods to a customer other than the billing customer, it is recommended that you set the system to apply the tax code of the billing customer, as opposed to the shipping customer, during automatic invoice preparation (using the Prepare Invoices program). In any event, the tax code may be revised manually. 
 
## To determine that the tax code will be taken from the customer appearing in the invoice: 

 

 1 .  Enter the Financial Constants form and move to the InvoiceTaxCode constant. 
 

 2 .  Change the value to 1 .
