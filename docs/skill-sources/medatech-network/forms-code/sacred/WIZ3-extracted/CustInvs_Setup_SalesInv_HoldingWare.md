# Defining a Holding Warehouse

 

If you work with holding invoices , you need to define a holding warehouse . 
 
## Note:

 

You must define a special holding warehouse even if there is no specific physical area in which you store invoiced goods held for a customer. One way to handle such a situation is to use an existing warehouse and add a fictitious bin. 
 
## To define a holding warehouse:

 

 1 .  Enter the Warehouses form. 
 

 2 .  Retrieve the warehouse (and bin) you want to use or record a new one. 
 

 3 .  Leave the Inventory Valued and Transaction Costing columns unchecked, and flag the Ignored by Planning column. 
 
## Tip:

 

For more information, run the Open a Warehouse Wizard .
