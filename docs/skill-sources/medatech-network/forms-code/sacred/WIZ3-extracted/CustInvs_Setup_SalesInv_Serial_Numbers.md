# Setting the Check SerialNum Qty Constant

 

If you are billing for serialized parts, you can set this constant to prevent invoices from being finalized if the quantity of billed parts differs from the quantity of open serial numbers. 
 
## To set the constant:

 

 1 .  Enter the Inv. Transaction Documents form. 
 

 2 . Move to the Sales Invoice ( INV ) or Over-the-Counter ( OVR ) line, as required. 
 

 3 . In the Check SerialNum Qty column: 
 

 ·              Select Y to prevent finalization if the quantities differ. 
 

 ·              Select P to prevent finalization if the quantities differ, unless the invoice is a holding invoice. 
 

 ·              Select N if you do not want to run the check. 
 

 Note: As this check is time-consuming, you should only run it if you work with serial numbers.
