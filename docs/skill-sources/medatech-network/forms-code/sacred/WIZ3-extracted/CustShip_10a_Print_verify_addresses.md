# Verifying the Customer's Addresses

 

The shipping document printout displays both the customer's mailing and shipping addresses (the latter is determined by the specified site). 
 

 To verify the customer ' s mailing address: 
 

 ·        Enter the Customer Details sub-level form. Make sure that the address recorded is correct.
 Tip: To update the address of a regular customer (as opposed to a walk-in customer), use the Customers form. 
 

 To verify the customer ' s shipping address: 
 

 ·        If the goods are to be delivered to a site other than the customer's main address, make sure that the site is correctly defined in the Name column of the Shipping Address sub-level form.
 Tip: To add to the list of customer sites, use the Customer Sites form, a sub-level of the Customers form.
