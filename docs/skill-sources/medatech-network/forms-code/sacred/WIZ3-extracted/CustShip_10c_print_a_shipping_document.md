# Printing a Shipping Document

 
## To print a single shipping document:

 

 ·        Retrieve the document in the Customer Shipments form and select Print Shipping Document from the list of Direct Activations .
 D ual-currency users: If you wish to print the document in English and are working in another language, select Print Shipping Doc-Foreign Lang. instead. 
 

  
 
## To print multiple shipping documents:

 

 ·        Run the Print Shipping Document report.
 D ual-currency users: To print in English when working in another language, run the Print Shipping Doc-Foreign Lang. report. 
 
## To print a bill of lading:

 

 ·        Retrieve the document in the Customer Shipments form and select Print Bill of Lading from the list of Direct Activations . 
 
## Notes:

 

 ·        To change the current print format for a shipping document, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        In case incorrect data were detected in the printout, click to revise the shipping document . 
 

 ·        Click to return to the main screen .
