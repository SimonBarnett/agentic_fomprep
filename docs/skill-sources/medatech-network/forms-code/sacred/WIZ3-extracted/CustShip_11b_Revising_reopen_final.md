# Reopening a Final Shipping Document

 
## Note: 

 

Do not reopen a document if it has already been printed and you want to cancel it. Instead, click to record a parallel return document . 
 
## To reopen a final document:

 

 1 .  Enter the Customer Shipments form, and retrieve the shipping document in question. 
 

 2 .  Select Reopen Document from the list of Direct Activations . The document will return to its initial status. 
 
## Notes:

 

 ·        Click to revise or cancel the pending document . 
 

 ·        Click to return to the main screen .
