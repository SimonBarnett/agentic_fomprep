# Canceling a Customer Shipment with a Return Document

 

You can effectively cancel a customer shipment by automatically creating a customer return document for the same items. If the shipping document is linked to an invoice, you must cancel the invoice before canceling the shipment. 
 
## To cancel a final shipping document:

 

 1 .  Enter the Customer Shipments form, and retrieve the shipping document in question. 
 

 2 .  Select Cancel Final Document by Return from the list of Direct Activations . 
 
## Notes:

 

 ·        The program prevents the billing of the shipping document and the crediting of the return document by removing the checkmark from the Billable and Credit Customer columns, respectively. 
 

 ·        Click to return to the main screen .
