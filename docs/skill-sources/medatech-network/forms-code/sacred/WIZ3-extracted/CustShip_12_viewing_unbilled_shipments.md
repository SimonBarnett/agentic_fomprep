# Viewing Unbilled Shipments and Uncredited Returns

 

 Priority offers several reports that keep track of unbilled shipments and uncredited returns: 
 

 ·        Run the Unbilled Docs. by Customer No. report to view all shipping documents to designated customers which have not yet been billed (as well as returns which have not yet been credited), sorted by customer number. 
 

 ·        Run the Unbilled Docs.-Details per Cust. report to view the same information broken down by individual transactions and parts. 
 

 ·        Run the Unbilled Docs. by Customer Name report to view the same information, sorted by customer name. 
 

 ·        Run the Unbilled Docs. by Document No. report to view the same information, sorted by document number. 
 

 ·        Run the Unbilled Docs.-Details per Doc. report to view the same information sorted by document and broken down by part. 
 

 ·        Run the Unbilled Docs. by Sales Rep report to view all unbilled shipments (and uncredited returns) recorded for customers assigned to each designated sales rep. Customers that have not been assigned a sales rep are not taken into account. 
 

 ·        Run the Partially Billed Documents report to view shipping documents that have not been fully billed.
