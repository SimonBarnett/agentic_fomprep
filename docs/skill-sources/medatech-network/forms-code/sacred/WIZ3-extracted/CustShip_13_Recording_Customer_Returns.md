# Recording Customer Returns

 

In Priority , you can record a customer return in one of the following ways: 
 

 ·        Record a return document independently of a credit memo (or an invoice that credits the transaction). Use this method, for instance, when you want to create a credit memo for several returns together.
Click to record a return document . 
 

 ·        Include the return in a shipping document (using negative quantities), independent of an invoice crediting the transaction. Use this method when you do not want to open a separate document for the return.
Click to record a shipping document that includes returns . 
 

 ·        Include the return (with negative quantities) in a sales invoice, which credits the transaction and affects inventory simultaneously. Use this method when customer shipments are recorded in a sales invoice.
See the Customer Invoices Wizard for details.
