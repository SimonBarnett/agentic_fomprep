# Recording a Return Document

 

Return documents may be itemized automatically, based on an earlier shipment (recorded in a customer shipment or sales invoice), sales order or packed crates sent with a bill of lading. You can also prepare a return document manually. 
 
## What do you want to do?

 

 Record a return on the basis of a single shipment 
 

 Record a return on the basis of several shipments (for the same sales order) 
 

 Record a return of packed crates 
 

 Prepare the return document manually
