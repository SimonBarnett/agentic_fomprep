# To itemize the return:

 

 1 .  Click the References tab. 
 

 2 .  Specify the number of the original Ship Doc. or Sales Invoice . 
 

 3 .  Click if the returned goods were for a project. 
 

 4 .  The return document is itemized according to the designated document. Enter the Returned Items sub-level form, and make any necessary changes. 
 

 5 .  If you work with projects, click to link the returned item to a project or project activity. 
 

 6 .  The Warehouse and Bin to which each part has been returned are taken from the upper-level form. If goods are returned to several different warehouses or bins, make the necessary changes next to the appropriate line item. 
 

 7 .  Specify the From Status of the returned part (e.g., Damaged), as well as the exact Quantity being returned. 
 Notes : 
 

 ·              Click if the part in question was shipped in crates (i.e., a value appears in the Packing Crates (No.) column). 
 

 ·              Parts that are not assigned a quantity will be deleted from the return document once it is finalized. Explanation .
