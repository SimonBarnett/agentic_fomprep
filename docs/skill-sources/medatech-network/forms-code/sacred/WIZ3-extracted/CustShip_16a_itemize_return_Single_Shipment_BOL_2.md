# To itemize the return:

 

 1 .  Enter the Packing Slips in Document sub-level form and choose the returned crates (by their packing slip numbers). 
 

 2 .  The return document will be itemized automatically with the contents of the crates. Enter the Returned Items sub-level form to view the returned parts. 
 

 3 .  For each shipped item, approve the shipped quantities: 
 

 ·              If the SCratesQuant constant is set at 1 , the Approve column is flagged automatically, and the quantity is filled in automatically. 
 

 ·              Otherwise, flag the Approve column manually, and the quantity will appear automatically. 
 

 Tips: 
 

 ·              To change the value of the SCratesQuant constant, which will affect future bills of lading, enter the Logistic Constants form. 
 

 ·              For help in revising/canceling a final packing slip, run the Packing Slip Wizard . 
 

 4 .  If the return is for parts with serial numbers, use the Serial Numbers in Transaction or the Auto Recording of Serial Nos. sub-level forms. 
 Tip : For more information on working with serialized parts, run the Serial Numbers Wizard . 
 

 5 .  Return to the upper-level form. 
 
## Notes:

 

 ·              Click to finalize and credit the return document . 
 

 ·              Click to return to the main screen .
