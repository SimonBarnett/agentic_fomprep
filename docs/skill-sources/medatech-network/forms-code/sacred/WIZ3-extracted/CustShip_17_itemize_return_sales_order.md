# To record a return on the basis of a sales order:

 

 1 .  Enter the Customer Returns form. 
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the General tab). 
 

 2 .  In the Customer No. column, choose the customer that returned the goods. A document number is assigned automatically.
 Notes: 
 

 ·              In the case of a walk-in customer, record the walk-in customer number. Then revise the name in the Customer Name column, and fill in the address and other details in the Customer Details sub-level form. 
 

 ·              If this return will be credited to a customer other than the usual billing customer (as defined for the current customer in the Financ. Parameters for Customers form), specify the appropriate customer number in the Billing Customer No. column of the Customer Details sub-level form. This customer's account will appear automatically in the journal entry that will open when a credit memo for this return is finalized. 
 

 3 .  Today's date is filled in automatically as the return date. Change it if necessary. 
 

 4 .  Click the General tab. The warehouse to which the goods are being returned is filled in automatically, but this may be revised. Designate a warehouse bin, if desired.
 Notes: 
 

 ·              If goods are returned to more than one warehouse (or bin), designate the main one here. When itemizing the document, indicate the target warehouse of each part. 
 

 ·              Click to change the default warehouse for future return documents .
