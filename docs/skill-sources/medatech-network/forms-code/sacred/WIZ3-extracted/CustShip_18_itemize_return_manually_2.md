# To list the returned parts:

 

 1 .   Enter the Returned Items sub-level form. 
 

 2 .  For each returned item, specify the Part Number . 
 

 3 .  If you work with projects, click to link the item to a project or project activity. 
 

 4 .  The Warehouse and Bin to which each part is returned are taken from the upper-level form. If goods are returned to several different warehouses or bins, make the necessary changes next to the appropriate line item. 
 

 5 .  Specify the From Status of the returned part (e.g., Damaged), as well as the exact Quantity being returned. 
 Notes : 
 

 ·              If the part is returned in crates, designate the Crate Type Code and the number of crates. The returned quantity will be calculated automatically, based on crate capacity. 
 

 ·              Parts that are not assigned a quantity will be deleted from the return document once it is finalized. Explanation .
