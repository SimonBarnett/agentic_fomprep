Customer Shipment/Return - Crediting a Customer Only for Certain Returned Items 
 
 
- 
 
 
 
# To credit the customer only for certain returned items:

 

 ·        For each item whose return should not be credited, leave the Credit Customer column blank or remove the check mark. 
 
## Remember:

 

The Credit Customer column in the upper-level form (in the Price tab) must remain flagged.
