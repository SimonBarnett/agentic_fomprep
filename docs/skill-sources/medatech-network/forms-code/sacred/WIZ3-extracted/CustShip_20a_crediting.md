# Crediting the Customer

 

You can credit a return in a credit memo or within an invoice (using negative quantities). Once a memo or an invoice is created for the transaction (and finalized), its number will appear in the Credit Memo/Invoice column of the Returned Items form. 
 

If you wish to credit the return immediately, you can record a credit memo as soon as the return document is finalized. 
 
## To credit the return immediately:

 

 1 .  Select Prepare Invoice/Credit Memo from the list of Direct Activations . 
 

 2 .  A credit memo is created. Select Multi-Shipment Invoices from the list of Direct Activations .
