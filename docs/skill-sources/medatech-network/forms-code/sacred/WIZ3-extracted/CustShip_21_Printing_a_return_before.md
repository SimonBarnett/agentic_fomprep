# Printing a Return Document: Before You Begin

 
## To check remarks:

 

 1 .  In the Customer Returns form, retrieve the desired document. 
 

 2 .  Enter the Remarks sub-level form. The text recorded here will appear as a remark on the document printout. Make sure it is correct. 
 

 3 .  If you are printing return documents with item remarks , move to the parallel Returned Items sub-level form. Make sure that the remarks displayed in its sub-level, Line Items - Remarks , are correct for each item. Explanation. Change them as necessary.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 4 .  Return to the Customer Returns form.
