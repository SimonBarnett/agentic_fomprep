# To print a return document:

 

 ·        To print one return document, retrieve the document in the Customer Returns form and select Print Customer Return Doc. from the list of Direct Activations . 
 

 ·        To print more than one return document, run the Print Customer Return Doc. report. 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        In case incorrect data were detected in the printout, click to revise the return document . 
 

 ·        Click to return to the main screen .
