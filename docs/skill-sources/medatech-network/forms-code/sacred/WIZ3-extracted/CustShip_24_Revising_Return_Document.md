# Revising an Existing Return Document

 

While you are free to revise or cancel pending return documents, final documents cannot be revised or canceled, with the exception of certain details (e.g., part prices, Checking flag, billing status). However, as long as the document has not been credited, you can reopen it and make any needed revisions. 
 
## What do you want to do?

 

 Change details of a final return document 
 

 Reopen a final return document (to allow its revision or cancellation) 
 

 Revise or cancel a pending return document
