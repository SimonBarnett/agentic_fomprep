# Revising a Final Return Document

 

After a return document is final, you can still change certain details, such as its billing status (i.e., whether or not the return will be credited); the price, discount and billing status of individual items; and (for dual-currency users) the exchange rate – all of which will affect the document's total price. In addition, you can flag a returned item for checking, to prevent its accidental crediting, or delete an existing checking flag. 
 

 Note: 
 

You can change the status of a final return document (to another final status) or the name of the user responsible for handling it, in the Customer Returns form. 
 
## To revise a final document:

 

 ·        Use the Revision of Final Return Doc. form and its sub-level, Revision of Return Details .
