# Revising a Pending Return Document

 

As long as a return document is not final, it may be revised or canceled. 
 
## To revise a pending return document:

 

 1 .  Enter the Customer Returns form, and retrieve the return document in question. 
 

 2 .  Make all necessary changes. You can add, delete or update items in the document. 
 

 3 .  Click to finalize and print the document . 
 
## To cancel a pending return document:

 

 1 .  Enter the Customer Returns form, and retrieve the return document in question. 
 

 2 .  Enter the Returned Items sub-level form and check that all quantities are zero. 
 

 3 .  Return to the upper-level form, and change the status to Canceled .
