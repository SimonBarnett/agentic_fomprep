# Setting Up Customer Shipments and Returns

 
## What do you want to do?

 

 Set how prices are displayed 
 

 Set up the shipment of ordered items 
 

 Determine whether orders are reopened by a customer return 
 

 Set up business processes (BPM) for shipping and return documents (define statuses) 
 

 Record set text for shipping documents 
 

 Set up part remarks for shipping and return documents 
 

 Set up general shipping definitions and customers ' shipping profiles 
 

 Define a default warehouse for customer shipments and returns 
 
## Notes:

 

 ·        Once you have completed all setups, if customer shipments are opened automatically when scheduling the delivery of ordered goods, click to run the Delivery Scheduling Wizard . 
 

 ·        Click to return to the main screen .
