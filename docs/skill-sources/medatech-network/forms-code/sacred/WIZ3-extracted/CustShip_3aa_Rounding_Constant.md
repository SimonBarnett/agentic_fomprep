# Setting the Display of Prices 

 

Total prices can be rounded in sales documents, including customer shipments. You can set this as the default for the entire system, and/or define rounding per customer (which overrides the default). Specifically, you can round the total price of sales documents to the nearest whole unit of currency, or to the nearest ten sub-units. Example. 
 

You can also hide your own prices from printouts of shipping (and return) documents for specific customers, regardless of the selected print format.
