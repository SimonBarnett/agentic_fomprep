# Setting Up the Shipment of Ordered Items

 

When shipping goods on the basis of sales orders, you must decide: 
 

 ·        whether to copy order remarks from the order to the shipping document (order item remarks are copied automatically); 
 

 ·        how to itemize the shipping document: one line per order item OR multiple lines. Explanation ; 
 

 ·        how to link shipped parts to their corresponding order items. 
 
## To set these parameters:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Check the values of the SCopyOrdText , SOnlyOneLine and SAutoFindOrd constants, respectively, and change where necessary.
