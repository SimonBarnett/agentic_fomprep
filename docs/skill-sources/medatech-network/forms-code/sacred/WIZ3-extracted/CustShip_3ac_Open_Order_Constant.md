# Reopening Orders After a Return

 

You can set up the system so that order items for which returns are recorded can be reopened automatically once the customer return is finalized. 
 
## To determine whether to reopen orders automatically:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Choose the appropriate value for the SOpenOrder constant. 
 
## Note:

 

The constant value also determines whether a cancelled sales invoice or over-the-counter invoice will reopen the sales order.
