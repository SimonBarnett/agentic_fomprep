# Set Text for Shipping Documents

 

If you want certain remarks to appear on all printouts of shipping documents, you can designate set text for this purpose. 
 
## To designate set text:

 

 1 .  Enter the Set Text for Customer Shipments form. 
 

 2 .  Record the desired remarks in the Set Text for Customer Shipments sub-level form.
 D ual-currency users: If you are working in a language other than English, and wish to print out shipping documents in English, record set text in the Set Text for Shipments - Lang 2 sub-level form. Any documents opened for customers defined as receiving Printouts in Lang 2 will contain set text in English. 
 

These remarks will automatically appear in the Remarks sub-level form of each new shipping document, but may be revised there. Any remarks appearing in that sub-level form appear automatically in the printout of the shipping document. 
 
## Note: 

 

Shipping documents based on sales orders may also inherit remarks from the order (depending on the value of the SCopyOrdText constant).
