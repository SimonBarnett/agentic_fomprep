# Copying Part Remarks to Shipping/Return Documents

 

You can set up shipping and/or return documents so that part remarks are recorded automatically for individual items when a part number is recorded or revised in an itemized document. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "Customer Shipment" and/or "Customer Return", flag the Copy Part Remarks column.
