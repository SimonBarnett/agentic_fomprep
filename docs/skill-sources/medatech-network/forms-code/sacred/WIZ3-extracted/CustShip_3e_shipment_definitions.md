# To list the vehicles used by this shipper:

 

 1 .  Enter the Transports form. 
 

 2 .  For each vehicle, designate the license number and a brief description. 
 

 3 .  In the Shipper/Driver No. column, choose the number of the shipper. 
 

 4 .  In the Vehicle Type Code column, choose the vehicle's type. 
 
## Note:

 

The designation of a vehicle number in a shipping document may affect prices for this shipment. Explanation .
