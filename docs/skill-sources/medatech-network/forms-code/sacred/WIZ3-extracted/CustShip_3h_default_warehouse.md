# Setting Default Warehouses

 
## To define a default warehouse for customer shipments:

 

 1 .  Enter the Inv. Transaction Documents form and move to the Customer Shipmt line. 
 

 2 .  In the Default Warehouse column, choose the default warehouse (i.e., the warehouse from which goods are usually shipped). You may also specify a warehouse bin. 
 
## To define a default warehouse for customer returns:

 

 ·        In the same form, move to the Customer Return line and choose the warehouse to which goods are usually returned. 
 
## Tip:

 

To define additional warehouses, run the Open a Warehouse Wizard .
