# Recording a Shipping Document

 

You have several options for recording a shipping document and linking it to the orders it fills (and thereby reducing the order balance): 
 

 ·        If each shipment fills one or more specific sales orders, you can have the system itemize the shipping document automatically with all ordered parts. All you then need to do is approve (or revise) the shipped quantities. 
 

 ·        If each shipment partially fills a specific sales order, and you want to determine which of the ordered parts are being shipped, you can designate the order but record the shipped parts manually. The system will fill in the proper order line number for each recorded item. 
 

 ·        If you are unaware of which orders are being filled by each shipment, you can record the shipped parts manually and have the system fill in the proper order number and line number. 
 
## Notes: 

 

 ·        Bills of lading are always itemized automatically, according to the packing crates they include. 
 

 ·        You can also record a shipping document manually, without linking it to any order.
