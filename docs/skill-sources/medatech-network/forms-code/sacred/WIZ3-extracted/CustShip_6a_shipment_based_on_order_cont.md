Customer Shipment/Return - Itemizing a Shipping Document Automatically.4 
 
 
- 
 
 
 

 4 .  The shipping document is itemized according to the designated sale order(s). Enter the Shipped Items sub-level form, and make any necessary changes. For each item, make sure that the Unit Price and % Discount are correct.
 Note: Items from sales orders that were marked for return in the Sales Orders for Document form will appear with quantities of zero. 
 

 5 .  If you work with projects, click to link the item to a project or project activity. 
 

 6 .   From Status , To Status , Work Order , Warehouse and Bin are filled in automatically. Make sure they are correct.
 Notes: 
 

 ·              To check available inventory, use the Inventory for Part and the Available Inventory in Warehouse sub-level forms. 
 

 ·              If the SOnlyOneLine constant is set to zero, one order item may be split into multiple lines (one for each receiving status, work order and bin).
