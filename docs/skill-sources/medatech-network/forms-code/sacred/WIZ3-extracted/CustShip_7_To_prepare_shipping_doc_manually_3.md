# To list the shipped parts:

 

 1 .   Enter the Shipped Items sub-level form. 
 

 2 .  Specify the Part Number of the shipped item. 
 

 3 .  Make sure that the part description is suitable.
 Tip: You can change the description of any part that is flagged in the Change Desc. column of the Part Catalogue form. 
 

 4 .  If you work with projects, click to link the item to a project or project activity. 
 

 5 .  Specify the Work Order to which the part belongs.
 Tip: To check available inventory, use the Inventory for Part and the Available Inventory in Warehouse sub-level forms. 
 

 6 .  Make sure the From Status , To Status , Warehouse and Bin are correct.
 Note : The balance of this part for the designated Work Order , To Status , Warehouse and Bin is displayed in the Warehouse Balance column.
