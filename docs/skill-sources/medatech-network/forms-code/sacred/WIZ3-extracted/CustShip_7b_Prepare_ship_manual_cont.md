Customer Shipment/Return - Preparing a Shipping Document Manually.4 
 
 
- 
 
 
 

 7 .  Do one of the following: 
 

 ·              If you are shipping packed goods, designate the Crate Type Code and the number of crates. The shipped quantity will be calculated automatically, based on crate capacity. 
 

 ·              Otherwise, specify the shipped quantity manually in the Quantity column. 
 

  Note: If the part is a customer return, designate a negative quantity. 
 

 8 .  The Unit Price and % Discount are filled in automatically. Revise them, if necessary. 
 

 9 .  If there is an order for this shipped part, the Order and Ln are filled in automatically. To revise them, first delete the line number. 
 Note: When the system finds more than one order and line number for the part, it takes the order item whose due date is closest to the date of shipment. 
 

 10 .  To record serial numbers for the shipped part, use the Serial Numbers in Transaction or the Auto Recording of Serial Nos. sub-level forms. 
 Tip : For more information on working with serialized parts, run the Serial Numbers Wizard. 
 

 11 .  Enter the Line Items - Remarks sub-level form and check the remarks appearing there. Revise them or add to them, as needed.
 Notes: 
 

 ·              Any part remarks recorded in the part catalogue appear in this form automatically if Copy Part Remarks has been flagged for customer shipments (in the Copy Part Remarks to Document form). 
 

 ·              The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 ·              To include these remarks in the printout of the shipping document, select a suitable print format .
