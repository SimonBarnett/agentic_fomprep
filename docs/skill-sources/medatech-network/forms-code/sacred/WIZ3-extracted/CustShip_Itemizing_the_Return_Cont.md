# Itemizing the Return (Cont.)

 

 1 .  If the return is for parts with serial numbers, use the Serial Numbers in Transaction or the Auto Recording of Serial Nos. sub-level forms. 
 Tip : For more information on working with serialized parts, run the Serial Numbers Wizard . 
 

 2 .  Click if the customer is to be credited only for certain returned items . 
 

 3 .  To record remarks pertaining to this returned item, use the Line Items - Remarks sub-level form.
 Notes: 
 

 ·              Any part remarks recorded in the part catalogue appear in this form automatically if Copy Part Remarks has been flagged for customer returns (in the Copy Part Remarks to Document form). 
 

 ·              The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 
## Notes:

 

 ·              Click to finalize and credit the return document . 
 

 ·              Click to return to the main screen .
