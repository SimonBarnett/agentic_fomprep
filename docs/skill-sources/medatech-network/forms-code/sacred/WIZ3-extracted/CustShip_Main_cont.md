## Notes: 

 

 ·        This wizard does not cover the option of recording shipments in a sales invoice. Click to run the Customer Invoices Wizard instead. 
 

 ·        This wizard also does not cover the scheduling of deliveries to customers when your own company delivers the goods. Complete the setups for customer shipments and then run the Delivery Scheduling Wizard . 
 

 ·        Nor does this wizard cover the topic of shipping goods on consignment or loan to customers. Click to run the Consignments Wizard instead. 
 

 ·        If you are working with the Fashion module and you need to itemize a shipment or return manually, run the Fashion Wizard to learn how to record style assortments.
