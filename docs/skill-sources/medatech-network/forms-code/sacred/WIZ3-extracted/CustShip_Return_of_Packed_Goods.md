# Return of Packed Goods

 

When the original quantity of the shipped part was specified in terms of packed crates, you should do one of the following: 
 

 ·        If the entire shipped quantity is being returned, flag the Approve column. The Quantity column will be filled in automatically. 
 

 ·        If only some of the shipped crates are being returned, change the value in the Packing Crates (No.) column. This will update the value in the Quantity column. 
 

 ·        If individual parts are being returned, as opposed to whole crates, delete the value from the Packing Crates (No.) column and specify the exact quantity of units returned in the Quantity column.
