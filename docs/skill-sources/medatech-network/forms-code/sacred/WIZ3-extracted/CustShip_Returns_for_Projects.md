# Returns for Projects

 

You can link a customer return to a project or to a specific project activity (when the entire return is for a single activity). The cost of the transaction is added to the cost of the activity or project to which it is linked. 
 

Once the transaction is linked to a project or activity, you can change the income account attached to the return if it differs from the project's default income account. 
 

Project information will appear automatically in the following cases: 
 

 ·        When a single project has been recorded for the customer. 
 

 ·        When the return document is based on a single sales order or shipping document linked to a project. 
 
## Notes:

 

 ·        When itemizing the return, you will also be able to link individual items to a project activity. 
 

 ·        When you specify a project, the main warehouse defined for the project appears automatically in the Receiving Warehouse column (in the General tab). 
 
## What do you want to do?

 

 Link the document to the entire project or check the linked project 
 

 Link the document to a project activity or check the linked activity 
 

 Change the attached income account
