# Shipments for Projects

 

You can link a customer shipment to a project or to a specific project activity (when the entire shipment is for a single activity). The cost of the transaction is added to the cost of the activity or project to which it is linked. 
 

Once the transaction is linked to a project or activity, you can change the income account attached to the shipment if it differs from the project's default income account. 
 

Project information will appear automatically in the following cases: 
 

 ·        When a single project has been recorded for the customer, and the SLinkProject constant is set to 1 . 
 

 ·        When the shipping document is based on a single sales order linked to a project. 
 
## Notes:

 

 ·        When itemizing the shipment, you will also be able to link individual items to a project activity. 
 

 ·        When you specify a project, the main warehouse defined for the project appears automatically in the Sending Warehouse column (in the General tab). 
 
## What do you want to do?

 

 Link the document to the entire project or check the linked project 
 

 Link the document to a project activity or check the linked activity 
 

 Change the attached income account
