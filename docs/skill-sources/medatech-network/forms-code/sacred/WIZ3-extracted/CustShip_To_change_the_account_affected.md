Customer Shipment/Return - Changing the Account for a Project Transaction 
 
 
- 
 
 
 
# To change the income account attached to the transaction:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  Choose/check the project number. The default income account of the project appears in the Account Number column. 
 

 3 .  Choose the income account to attach to the current transaction. 
 

 4 .  Return to the upper-level form.
