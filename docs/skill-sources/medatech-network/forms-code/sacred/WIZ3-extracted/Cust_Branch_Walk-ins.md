# Opening Walk-in Records per Branch

 

If you work with branches, you can assign a separate walk-in customer to each branch. When a user associated with a particular branch opens an order or invoice, the corresponding walk-in customer appears automatically. 
 
## To assign a walk-in customer to a branch:

 

 1 .  Enter the Branches form and retrieve all records. 
 

 2 .  For each branch, click the Branch Details tab and specify the appropriate customer in the Branch Walk-in Cust column.
