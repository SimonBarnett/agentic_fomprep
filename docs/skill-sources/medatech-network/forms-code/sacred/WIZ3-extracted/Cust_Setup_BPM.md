# Setting Up Business Processes for Customers

 

You set up business processes by defining statuses in a BPM flow chart. 
 

There are several predefined statuses for customers, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 
## Note:

 

Click for an explanation of how BPM statuses and rules affect the To Do list of employees assigned to specific customers. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Customers program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Customers form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
