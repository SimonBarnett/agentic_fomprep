# Working with Walk-in Customers

 

You can record price quotes, sales orders, invoices and receipts for walk-in customers. 
 
## To open a document for a walk-in customer:

 

 1 .  In the Customer Number column, choose the walk-in customer number. In the Customer Name column, change the description to the walk-in customer's name. 
 

 2 .  In the Customer Details sub-level form, record the customer's address and phone number. This information will appear on the printout of the document. 
 
## Notes:

 

 ·        When preparing invoices and receipts, make sure to fill in the order number, so that the journal entries can be reconciled. 
 

 ·        You can run the Outstanding Debts by Orders report to view your walk-in customers' outstanding debts. 
 

 ·        Click to return to the main screen.
