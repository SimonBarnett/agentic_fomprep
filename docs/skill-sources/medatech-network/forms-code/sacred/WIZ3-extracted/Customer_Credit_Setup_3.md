# Defining the Check Validation Period

 

When postdated checks come due, they must usually undergo a validation process before the company account is credited. Within that period, the bank can choose to return the check. The sums of invalidated checks (whether or not they were originally postdated) are included in credit and/or liability calculations. 
 
## To define the validation period:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the CreditCheckDays constant and define the desired number of days.
