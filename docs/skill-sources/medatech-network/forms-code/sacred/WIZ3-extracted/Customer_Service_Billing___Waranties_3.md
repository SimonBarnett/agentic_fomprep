# Service Terms

 

The service terms of warranties and service contracts indicate the kinds of service provided. Examples. The service terms also determine which families (e.g., particular part families; work hours) are billed in service calls and which are not. 
 

A warranty can have two different service terms: one for an initial warranty period and another for a second warranty period. Example.
