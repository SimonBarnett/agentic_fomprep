# Setting Up Service Terms 

 

 Priority provides two predefined service terms: Full Payment and Project . You can work with these, or you can define as many additional types as you need. 
 

You can also specify a part number for each type of service terms, that will appear in invoices opened automatically for service contracts. 
 
## To define additional service terms:

 

 1 .  Enter the Service Terms form. 
 

 2 .  On a new line, record a code and description of the terms.
 Tip: You can add more service terms later, as you need them. 
 
## To assign a part number to service terms:

 

 ·        Specify the desired part in the Part No. For Invoice column.
 Note: To set the system to use the part numbers designated in this form as the default parts to charge in service contract invoices, enter the Financial Constants form and change the value of the InvContPart constant to 2 . These parts can be replaced manually in individual service contract payments.
