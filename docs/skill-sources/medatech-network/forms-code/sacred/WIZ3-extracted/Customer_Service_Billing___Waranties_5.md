# Warranties

 

You can define as many different warranties as you need. A warranty is characterized by: 
 

 ·        The amount of time in effect, and 
 

 ·        Which parts are billable (i.e., what service terms apply). 
 

A warranty can be split into two periods of varying lengths, each having different service terms.
