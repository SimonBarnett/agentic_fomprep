# Recording Warranties

 

 1 .  Enter the Warranty Codes form. 
 

 2 .  Record a code and description for the warranty. 
 

 3 .  Indicate how long the first warranty period lasts and what service terms apply. If necessary, do the same for a second warranty period.

 Tip: Click to add new service terms. 
 
## Notes:

 

 ·        If you want warranties to start when parts are installed rather than when they are shipped to the customer, in the Logistic Constants form, set the value of the CAutoWarrant constant to 0 . 
 

 ·        When warranties are extended, the new expiration date is calculated by adding the value of the CExtWarranty constant to the original expiration date. The default value of the constant is 12 months; you can change this in the Logistic Constants form.
