# Setting Up Automatic Part Remarks in a Service Call

 

You can set up service call documents so that part remarks for serviced items are recorded automatically when a part number is recorded in the service report for parts. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks to service calls:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "Service Call", flag the Copy Part Remarks column.
