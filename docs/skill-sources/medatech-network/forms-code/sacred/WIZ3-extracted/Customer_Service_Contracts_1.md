# Setting Up Business Processes for Contracts

 

You set up business processes by defining statuses in a BPM flow chart. The status of a contract determines the stage it is in (e.g., whether it is final) and whether or not you can calculate payments based on the contract. 
 

There are several predefined statuses for contracts, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Service Contracts program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Service Contracts form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
