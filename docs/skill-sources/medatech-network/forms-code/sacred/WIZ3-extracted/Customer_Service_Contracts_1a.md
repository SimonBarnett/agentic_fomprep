# Setting the InvContPart Constant

 

The InvContPart constant affects the part number that appears by default in invoices opened automatically for service contracts. Such parts can be replaced manually in individual service contract payments. 
 
## To set the constant:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the InvContPart constant and do one of the following: 
 

 ·              Leave the pre-set value of 0 to use the standard “Contract Paymnt” part. 
 

 ·              Change the constant to 1 to use the part number of the first line item in the service contract. 
 

 ·              Change the constant to 2 to use the part number defined for the service terms assigned to the contract.
 Note: To define parts for service terms, enter the Service Terms form and specify the relevant parts in the Part No. for Invoice column.
