# Setting the Payment Installment Date Option 

 

As a default, Priority 's automatic utility calculates payment installments for set dates. Example. You can calculate them instead for different dates within the payment period. Example. 
 
## To calculate payment installments for varying dates:

 

 1 .  Enter the Logistic Constants form. The CContPayPrd constant is pre-set to 1 . 
 

 2 .  Change the value of the CContPayPrd constant to 0 . 
 
## Note:

 

You can override the constant in individual contracts, by flagging (or unflagging) the Set Pay Date column in the Service Contracts form.
