# Set Text for Service Contracts

 

You can record set text to appear on printouts of service contracts for all customers. 
 
## Note:

 

When you prepare a particular contract, you can override the set text. 
 
## To record set text:

 

 1 .  Enter the Set Text for Service Contracts form. 
 

 2 .  Record the desired text in the Set Text for Service Contracts sub-level form.
 Tip for dual-currency users: If you are working in a language other than English and wish to record set text in English, use the Set Text for Contracts - Lang 2 sub-level form. Any contracts opened for customers defined as receiving Printouts in Lang 2 will contain set text in English.
