# Cost Per Mile

 

 Priority provides one predefined mileage charge part. To set it up, simply fill in the charge per mile. 
 
## Note:

 

When you set this up, keep in mind that the same defaults are also used for projects. 
 
## To set up the mileage charge part:

 

 1 .  In the Part Catalogue form, retrieve the Miles part. 
 

 2 .  Click the Prices & Costs tab. In the List Price column, record the charge per mile. 
 
## Note: 

 

To assign different costs per mile to different customers, include the mileage charge part in customer price lists instead.
