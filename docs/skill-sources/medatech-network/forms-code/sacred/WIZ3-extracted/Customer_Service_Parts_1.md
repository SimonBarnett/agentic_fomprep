# Setting Up Serviced Parts

 
## For each part that you service, you need to designate a number of parameters:

 

 1 .  Enter the Service Parameters for Part form and retrieve the desired part (or parts). 
 

 2 .  If you will assign serial numbers to the part, flag the Maintain Serial Nos column. Note: You can only assign serial numbers to parts whose buy/sell unit and factory unit are both ea (a single whole unit). Check the units in the Part Catalogue form (under the Additional Details tab). 
 

 3 .  In the Warranty Code column, select the warranty normally given to the part.
 Note: Click if you have not yet set up warranties. 
 

 4 .  In the Maximum Repair Price column, specify the maximum price that can be charged to customers without their authorization. This will appear as the default maximum repair price in any new service call opened for the part.
