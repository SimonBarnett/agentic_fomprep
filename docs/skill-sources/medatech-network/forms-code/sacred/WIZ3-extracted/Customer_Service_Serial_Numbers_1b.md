# Opening Serial Numbers

 

 Priority offers the option of opening a serial number for a single part whenever an inventory transaction is recorded for the part. As a default, this option is blocked for all types of inventory transactions, to prevent user errors. You can disable the block for any desired transaction type. Example. 
 
## To disable the block:

 

 1 .  Enter the Inv. Transaction Documents form. 
 

 2 .  On the lines for the desired transaction types, flag the Open Serial Numbers column.
