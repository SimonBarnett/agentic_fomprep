# Setting Up Service Calls

 
## Types of Service Calls

 

You can define categories ( types ) for your service calls based on any criteria that serve your purposes (e.g., part families; the department providing the service). When you record a service call, you can indicate the type of call and then later, retrieve service calls by type and create reports sorted by call type. 
 
## To create a list of service call types:

 

 ·        Enter the Types of Service Calls form. In the Call Type column, enter a description for each service call type.
