# Types of Malfunctions 

 

You can record a list of possible malfunctions which might occur in the parts you service. A malfunction is a brief description of the problem with the part, as defined by the call taker or the technician (as opposed to the problem as the customer sees it). Example. 
 
## To record types of malfunctions:

 

 1 .  Enter the Malfunction Codes form. 
 

 2 .  Record a code and description for each malfunction.
 Tip for dual-currency users: If you are working in a language other than English and want to print service calls in English, fill in the Description (Lang 2) column as well. 
 

 3 .  Remain in the Malfunction Codes form.
 Tip: You can add more malfunctions later, as you need them.
