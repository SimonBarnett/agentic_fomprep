# Assigning Families to Malfunctions

 

Each type of malfunction generally affects a limited number of parts belonging to the same part family. You can create a list of families for each type of malfunction. As a result, once a part from this family is specified when a call is recorded, the Choose list of possible malfunctions is limited to those codes applying to the part. 
 
## To assign families to malfunctions:

 

 1 .  Enter the Families With This Malfunct Type form (a sub-level of the Malfunction Codes form). 
 

 2 .  List the family (or families) subject to this malfunction.
