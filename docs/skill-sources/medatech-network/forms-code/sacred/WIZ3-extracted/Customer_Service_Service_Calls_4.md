# Problem Codes

 

You can record a list of possible “problems” which might occur in the parts you service. A problem in Priority is defined or described from the point of view of your customers. Example. Problems are different from malfunctions in that malfunctions are defined by trained technicians, not by customers. 
 
## To record a list of problem codes:

 

 1 .  Enter the Problem Codes form. Record a code and description for each type of problem.
 Tip for dual-currency users: If you are working in a language other than English and want to print service calls in English, fill in the Problem Desc (Lang 2) column as well. 
 

 2 .  If desired, in the Call Type column, select the type of service call to which this problem applies. As a result, once a call type is specified when recording a service call, the Choose list in the Problem Code column is limited to these codes. 
 
## Notes: 

 

 ·        You can add more problems later, as you need them. 
 

 ·        To add a new call type, use the Types of Service Calls form.
