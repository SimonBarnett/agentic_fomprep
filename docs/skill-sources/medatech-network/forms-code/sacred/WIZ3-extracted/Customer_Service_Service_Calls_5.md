# Resolution Codes

 

Resolution codes are possible actions taken by the call taker or the technician to solve the malfunction. 
 
## To record a list of resolution codes:

 

 1 .  Enter the Resolution Codes form. 
 

 2 .  Record a code and a brief description of the action.
 Tip for dual-currency users: If you are working in a language other than English and want to print service calls in English, fill in the Resolution (Lang 2) column as well. 
 
## Tip:

 

You can add more resolution codes later, as you need them.
