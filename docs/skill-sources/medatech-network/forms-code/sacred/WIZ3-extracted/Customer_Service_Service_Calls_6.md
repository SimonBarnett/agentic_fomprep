# Business Processes

 

You set up business processes by defining statuses in a BPM flow chart. The status assigned to a service call indicates the stage it is in and whether or not you can open an invoice for it. 
 

There are several predefined statuses, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules, assign colors to call statuses and set status properties . 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Service Calls program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Service Calls form. 
 

 ·        To set the maximum period of time that service calls can retain certain statuses (before being flagged as exceptions in the Active Service Calls form), enter the Exception Definition sub-level of the Statuses for Service Calls form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
