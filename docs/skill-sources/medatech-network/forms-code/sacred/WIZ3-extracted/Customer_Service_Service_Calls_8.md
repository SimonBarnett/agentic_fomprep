# Calendar Colors

 

The calendars display, among other things, technicians' appointments for service calls. You can distinguish between service calls by color-coding their call status, call type or malfunction type. Any service call that does not have a color receives the default service call color. 
 
## Before You Begin

 

 ·        Enter the Colors for Calendar form. Note the default colors for each type of calendar entry, in order to make sure not to assign these same colors. 
 
## To assign colors per call status:

 

 ·        Run the BPM Flow Chart-Service Calls program. Right-click on each status and select Set Color . 
 
## To assign colors per call type or malfunction type:

 

 ·        Enter the Types of Service Calls form or the Malfunction Codes form. For each call type or malfunction, select a color in the Color in Calendar column. 
 
## Tip: 

 

Use a bright color (e.g., red) for the type/status requiring the most urgent attention, leaving the other types/statuses without color so that they receive the default service call color.
