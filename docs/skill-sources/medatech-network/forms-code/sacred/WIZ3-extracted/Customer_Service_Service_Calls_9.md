# Repeat Service Calls

 

You can set up Priority so that a newly opened service call for the same serialized part is considered a repeat call . You do so by indicating the number of days that can pass between the original call and the repeat call. 
 
## To define repeat calls:

 

 1 .  Enter the Logistic Constants form. The CRepCallDays constant is pre-set to 0 days. 
 

 2 .  Change the value of the CRepCallDays constant. Example .
