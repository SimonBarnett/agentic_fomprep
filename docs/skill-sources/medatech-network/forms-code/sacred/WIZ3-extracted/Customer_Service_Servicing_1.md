# Setting Up Servicing Packages

 
## Defining Servicing Packages

 

If you offer customers a variety of servicing packages, each including different services and prices, you should define each one. Example . Then, when you choose a servicing package while recording a service call, the information on serviced parts, labor and prices is filled in automatically. 
 
## Note: 

 

In Priority , a service package is defined as a part. This enables you to price the package (e.g., using Priority ' s price lists), just as you do any other part.
