# Parts Generally Used in This Servicing Package

 

You can define the parts that are usually used when this servicing package is carried out. As a result, when you choose a servicing package while recording a service call, these parts are listed automatically. 
 
## To define parts used in a servicing package:

 

 1 .  Enter the Part Catalogue form. 
 

 2 .  On a new line, record a part to represent this servicing package (e.g., “Semi-annual for stove model 900”).
 Tip: Use a special numbering system for such parts (e.g., they all begin with 9 ). 
 

 3 .  Click the Additional Details tab. In the Type column, select P (a “make” item). 
 

 4 .  Click the Prices & Costs tab. In the List Price column, record the price of this part. 
 Note : You can also use any other pricing mechanism offered by Priority (e.g., price lists) to set prices for the package. 
 

 5 .  Enter the Child Parts sub-level form. 
 

 6 .  The part you just created is the “parent part”, and the parts generally used in this servicing package (including work hour parts) are the “child parts”. List all the child parts. 
 

 7 .  For each "child part", indicate the quantity of children required to produce one unit of the parent in the Qty (Child) column. For example, if a certain package usually requires two work hours, specify 2 in the Qty (Child) column of the work hour part.
 Note: When the child part is a sub-assembly, also treat it as a parent and define child parts for it in the same way.
