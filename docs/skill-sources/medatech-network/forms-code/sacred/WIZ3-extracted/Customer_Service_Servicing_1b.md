# To define servicing packages:

 

 1 .  Enter the Servicing Packages form. Record a descriptive name for the servicing package. 
 

 2 .  In the Part Number column, record the part you created to represent the servicing package (the “parent part”). 
 

 3 .  If desired, record any remarks in the Servicing Packages - Remarks sub-level form. These remarks are included in any service call recorded for this servicing package.
