# Servicing Reminders

 

When a service call is opened for a customer, the system checks to see if any parts at that customer are due for servicing within the next 30 days. If there are, Priority issues a warning message. 
 
## To change the number of days forward that the system makes this check:

 

 1 .  Enter the Logistic Constants form. The CMaintenance constant is pre-set to 30 days. 
 

 2 .  Change the value of the CMaintenance constant.
