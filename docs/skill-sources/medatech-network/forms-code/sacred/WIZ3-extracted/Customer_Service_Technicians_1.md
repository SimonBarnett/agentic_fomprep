# Setting Up Technicians

 

A technician is a type of service provider. Anyone who is a trained technician should be flagged as a service provider and assigned the predefined Technician skill. If other users also answer service calls, flag them as service providers and create additional skills for them (e.g., Telephone Support, In-Field Support). These skills can also be categorized by type, based on any criteria that serve your purposes. 
 
## To create a list of skill types:

 

 1 .  Enter the Skill Types form. 
 

 2 .  Record a code and description for each type of skill. 
 
## To define additional skills:

 

 1 .  Enter the Skills form. 
 

 2 .  Record a code and description for each skill. 
 

 3 .  If desired, assign each skill a skill type.
