# Technicians' Schedules

 

When recording a service call, the call taker can view appointments already scheduled for technicians in one of the sub-level forms. This helps the call taker determine the availability of each technician for additional appointments. As a default, the appointments are displayed for seven days forward from the current date. 
 
## To change the number of days forward that appointments are displayed:

 

 1 .  Enter the Logistic Constants form. The CForwardSchd constant is pre-set to 7 days. 
 

 2 .  Change the value of the CForwardSchd constant to the desired number of days.
