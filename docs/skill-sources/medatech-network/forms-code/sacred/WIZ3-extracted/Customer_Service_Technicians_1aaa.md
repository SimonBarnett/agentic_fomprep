# Zones for Service Calls

 

When scheduling service calls, it helps to know which zone each of your customers belongs to. For example, you can assign a default technician to each zone (see next screen). 
 
## To set up zones and assign them to customers:

 

 1 .  Enter the Shipping Zones form. 
 

 2 .  For each zone, record a code and description. 
 

 3 .  Enter the Customers form and retrieve the desired customers. 
 

 4 .  For each customer, click the Shipments tab and choose a zone code.
