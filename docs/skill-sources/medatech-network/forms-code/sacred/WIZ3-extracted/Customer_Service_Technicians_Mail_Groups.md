# Groups of Technicians

 

For ease in scheduling service calls for those technicians that handle the same type of malfunction, it is recommended to set up groups. For example, all electricians can be assigned to a particular group, and e-mail and service call scheduling can be done in bulk to all electricians belonging to that group. 
 
## To prepare the group:

 

 1 .  Enter the Groups form. 
 

 2 .  Record a name and description for the new group. 
 

 3 .  Enter the Users in Group sub-level form and list all technicians in the group. 
 

 4 .  If desired, enter the Authorized Access to Group sub-level form to record the users who are authorized to send e-mail to this group and to schedule them for service calls.
