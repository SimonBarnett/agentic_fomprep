# Enabling Access to Secure Data

 

Once secured accounts, customers and/or vendors have been defined, only authorized users will be able to view related data. 
 
## To define an authorized user:

 

 1 .   Enter the Personnel File form and retrieve the user in question.
 Tip: Retrieve by User (in the General tab). 
 

 2 .   Enter the Company-Specific Information sub-level form and click the Data Privileges tab. 
 

 3 .   Flag any of the following columns: 
 

 ·      Secured Accounts Authorization 
 

 ·      Secured Customers Authorization 
 

 ·      Secured Vendors Authorization 
 
## Notes:

 

 ·        Click to view a list of user authorizations per data type. 
 

 ·        Click to return to the main screen.
