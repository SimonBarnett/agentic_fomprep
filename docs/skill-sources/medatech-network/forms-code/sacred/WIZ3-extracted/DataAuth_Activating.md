# Activating the Data Authorization Mechanism

 

To have the system check whether each user is entitled to view one or more specific types of data, activate the Data Authorization mechanism for data of that type. Users will only have access to data that they are authorized to view. 
 
## To activate authorization checks:

 

 ·        For s ecured a ccounts , customers and vendors – flag a single record (in any of the five forms) as secured. Click for details. 
 

 ·        For a ll other data types – run the Activate/Disable Data Authoriz'n program; select the type of data authorization you wish to activate and choose the Activate Data Authorization option. 
 
## Note:

 

Click to begin authorizing users for various types of data.
