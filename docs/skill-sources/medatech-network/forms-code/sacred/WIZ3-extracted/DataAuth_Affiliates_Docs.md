# Enabling Access to Subsidiary Documents

 

If you choose to restrict access to subsidiary documents, you can define, for each user, which subsidiaries he or she is authorized to view. You can also flag specific users (e.g., the CEO) as authorized to see documents recorded in all subsidiaries. 
 
## To define the subsidiaries a user can view:

 

 1 .  Enter the Personnel File form and retrieve the user in question.
 Tip: Retrieve by User (in the General tab). 
 

 2 .  Enter the Company-Specific Information sub-level form. 
 

 3 .  Do one of the following: 
 

 ·      To allow access to all subsidiaries, click the Data Privileges tab and flag the Authorized to View All Subsidiaries column. 
 

 ·      Otherwise, enter the Authorization for Subsidiaries sub-level form and flag any subsidiaries the user is authorized to see. 
 
## Notes:

 

 ·        To activate Data Authorizations for subsidiary documents, run the Activate/Disable Data Authoriz'n program for this data type and select the Activate Data Authorization option. Thereafter, users will only be able to access documents recorded in subsidiaries that they are authorized to view. 
 

 ·        Documents that are not recorded for any subsidiary will be accessible to all users. 
 

 ·        Click to view a list of user authorizations per data type. 
 

 ·        Click to return to the main screen.
