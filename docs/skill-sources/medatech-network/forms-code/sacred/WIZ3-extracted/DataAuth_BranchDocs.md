# Enabling Access to Branch Documents

 

If you choose to restrict access to branch documents, you can define, for each user, which branches he or she is authorized to view. You can also flag specific users (e.g., the CEO) as authorized to see documents recorded in all branches. 
 
## To define the branches a user can view:

 

 1 .   Enter the Personnel File form and retrieve the user in question.
 Tip: Retrieve by User (in the General tab). 
 

 2 .   Enter the Company-Specific Information sub-level form. 
 

 3 .   Do one of the following: 
 

 ·      To allow access to all branches, click the Data Privileges tab and flag the Authorized to View All Branches column. 
 

 ·      Otherwise, enter the Authorization for Branches sub-level form and flag any branches the user is authorized to see. 
 
## Notes:

 

 ·        To activate Data Authorizations for branch documents, run the Activate/Disable Data Authoriz'n program for this data type and select the Activate Data Authorization option. Thereafter, users will only be able to access documents recorded in branches that they are authorized to view. 
 

 ·        Restricting access to branches does not automatically restrict access to the records of customers and vendors that are linked to those branches. To widen the restriction to include customer and vendor records, run the Define Data Auth by Branch/Rep program. 
 

 ·        Documents that are not recorded for any branch will be accessible to all users. 
 

 ·        Click to view a list of user authorizations per data type. 
 

 ·        Click to return to the main screen.
