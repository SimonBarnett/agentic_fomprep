# Enabling Access to Documents Defined with a Budget Item

 

If you choose to restrict access to documents for which a particular budget item has been defined, you can define, for each user, which budget items he or she is authorized for. You can also flag specific users (e.g., the CFO) as authorized to see documents involving all budgets. 
 
## To define the budget items a user is authorized for:

 

 1 .  Enter the Personnel File form and retrieve the user in question.
 Tip: Retrieve by User (in the General tab). 
 

 2 .  Enter the Company-Specific Information sub-level form. 
 

 3 .   Do one of the following: 
 

 ·      To allow access to documents involving all budgets, click the Data Privileges tab and flag the Authorized to View All Budgets column. 
 

 ·      To allow access to documents involving specific parts of the budget, select Assign Data Authoriz for Budgets from the list of Direct Activations . 
 

 ·      Otherwise, enter the Authorization for Budget Items sub-level form and flag any budget items the user is authorized for. 
 
## Notes:

 

 ·        To activate Data Authorizations for documents with budget items, run the Activate/Disable Data Authoriz'n program for this data type and select the Activate Data Authorization option. Thereafter, users will only be able to access data involving budget items that they are authorized for. 
 

 ·        Documents recorded without a budget item will be accessible to all users. 
 

 ·        Click to view a list of user authorizations per data type. 
 

 ·        Click to return to the main screen.
