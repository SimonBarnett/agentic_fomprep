# Authorizing Users for Various Types of Data

 

Once the Data Authorization mechanism has been activated for each of the various types of data, you must also define which users are authorized to access each type of data: 
 

 ·        Click to flag users as authorized to view secured data. 
 

 ·        Click to enable access to branch documents. 
 

 ·        Click to enable access to sales opportunity types. 
 

 ·        Click to enable access to sales reps' documents. 
 

 ·        Click to enable access to subsidiary documents. 
 

 ·        Click to enable access to documents for which a budget item has been defined. 
 

 ·        Click to enable access to payroll data based on payroll groups. 
 

 ·        Click to enable access to documents linked to projects.
