# Disabling the Mechanism

 

For each type of data authorization, the system manager can disable the mechanism so that it no longer checks whether each user is entitled to view data. Definitions will remain in the system, but they will be disregarded. 
 
## Before You Begin

 

If you intend to disable the mechanism for secured accounts, customers or vendors, you must first remove the flag that defines them as secured. 
 

 ·        For accounts, use the following forms ( General tab):
 Chart of Accounts 
 Chart of Accounts Receivable 
 Chart of Accounts Payable 
 

 ·        For customers, use the Customers form ( Details tab). 
 

 ·        For vendors, use the Vendors form ( Details tab). 
 
## To disable the authorization checks:

 

 ·        Run the Activate/Disable Data Authoriz'n program. Select the type of data authorization you wish to disable and choose the Disable Data Authorization option.
