# What Data is Hidden?

 
## Secured Accounts

 

Users who are unauthorized to view secured accounts will not be able to access any data involving those accounts. For instance, in the Entry Journal, users will not be able to see entries involving those accounts; if only some of the entry items include secured accounts, users will be able to view the other items. Unauthorized users who run financial statements will receive incomplete information (it will not include data from secured accounts), and a remark to that effect will appear at the bottom of the report. 
 
## Secured Customers and Vendors

 

Users who are unauthorized to view secured customers will not be able to access any data involving those customers. For example, they will not be able to run reports for those customers or to view any documents (e.g., quotes, orders, shipments, invoices) opened for those customers. The same restrictions apply to secured vendors. 
 
## Branches, Subsidiaries, Sales Reps, Sales Opportunity Types, Budgets and Projects

 

Users will only be able to view documents (e.g., quotes, orders, shipments, invoices) recorded in the branches or subsidiaries for which they are authorized. Documents without a branch or subsidiary are accessible to all users. The same restrictions apply to documents involving sales reps, sales opportunity types, budget items or projects for which users are authorized. 
 

Unauthorized users who run budget reports will receive incomplete information (reports will not include data associated with restricted budget items). 
 
## Payroll Groups

 

Users will only be able to view payroll data associated with the payroll groups for which they are authorized. Payroll data for employees that have not been assigned to a group will be accessible to all users. 
 
## Note:

 

Secured data is nonetheless available to all users in BI reports and in the forms displaying monthly data in the Executive Reports menu. You should therefore ensure that privileges are carefully assigned to these reports and forms in all their respective menu trees.
