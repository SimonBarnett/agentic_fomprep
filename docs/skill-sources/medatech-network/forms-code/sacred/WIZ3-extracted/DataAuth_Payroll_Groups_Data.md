# Enabling Access to Payroll Data per Payroll Group

 

If you choose to restrict access to employee payroll data, you can define, for each user, which payroll groups' data he or she is authorized to access. You can also flag specific users (e.g., the CFO) as authorized to access all payroll groups. 
 
## To define the payroll groups whose data a user is authorized to view:

 

 1 .  Enter the Personnel File form and retrieve the user in question.
 Tip: Retrieve by User (in the General tab). 
 

 2 .  Enter the Company-Specific Information sub-level form. 
 

 3 .   Do one of the following: 
 

 ·      To allow access to all payroll groups, click the Data Privileges tab and flag the Authorized to View All Payroll Groups column. 
 

 ·      Otherwise, enter the Authorization for Payroll Groups sub-level form and flag any payroll group(s) the user is authorized to access. 
 
## Notes:

 

 ·        To activate Data Authorizations for payroll groups, run the Activate/Disable Data Authoriz'n program for this data type and select the Activate Data Authorization option. Thereafter, users will only be able to access data involving payroll groups for which they are authorized. 
 

 ·        Payroll data for employees that have not been assigned to a group will be accessible to all users. 
 

 ·        Click to view a list of user authorizations per data type. 
 

 ·        Click to return to the main screen.
