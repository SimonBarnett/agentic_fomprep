# Enabling Access to Documents Linked to a Project

 

If you choose to restrict access to documents linked to specific projects, you can define, for each user, which projects he or she is authorized to access. You can also flag specific users (e.g., the CFO) as authorized to access documents for all projects. 
 
## To define the projects whose documents a user is authorized to view:

 

 1 .  Enter the Personnel File form and retrieve the user in question.
 Tip: Retrieve by User (in the General tab). 
 

 2 .  Enter the Company-Specific Information sub-level form. 
 

 3 .   Do one of the following: 
 

 ·      To allow access to all projects and their linked documents, click the Data Privileges tab and flag the Authorized to View All Projects column. 
 

 ·      Otherwise, enter the Authorization for Projects sub-level form and flag any projects for which the user is authorized to view linked documents. 
 
## Notes:

 

 ·        To activate Data Authorizations for projects, run the Activate/Disable Data Authoriz'n program for this data type and select the Activate Data Authorization option. Thereafter, users will only be able to access data involving projects for which they are authorized. 
 

 ·        Documents not linked to any project will be accessible to all users. 
 

 ·        Click to view a list of user authorizations per data type. 
 

 ·        Click to return to the main screen.
