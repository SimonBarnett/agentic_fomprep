# Reactivating the Mechanism

 

When the Data Authorization mechanism is disabled for any of the various types of authorizations, the system no longer checks whether each user is entitled to view that type of data. Nonetheless, definitions remain in the system and are easily reactivated. 
 
## To reactivate:

 

 ·        Secured a ccounts , customers and vendors – flag a single record (in any of the five forms) as secured. Click for details. 
 

 ·        All other data types – run the Activate/Disable Data Authoriz'n program. Select the type of data authorization you wish to activate and choose the Activate Data Authorization option.
