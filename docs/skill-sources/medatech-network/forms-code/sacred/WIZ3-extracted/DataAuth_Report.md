# Viewing User Authorizations per Data Type

 

 Priority makes it easy for you to see which users are authorized to access specific records among the various types of data that are subject to restriction: e.g., sales reps and branches. Run the following report to view the complete list of authorized users, alongside the records each user is authorized to access. 
 
## To view user authorizations:

 

 ·        Run the Data Authorization report, and select the desired data type.
 Note: This report can only be run for one data type at a time.
