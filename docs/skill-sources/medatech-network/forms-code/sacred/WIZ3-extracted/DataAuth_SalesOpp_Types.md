# Enabling Access to Sales Opportunity Types

 

If you choose to restrict access to particular types of sales opportunities, you can define, for each user, which sales opportunity types he or she is authorized for. You can also flag specific users (e.g., the sales manager) as authorized to see sales opportunities of all types. 
 
## To define the sales opportunity types a user is authorized for:

 

 1 .  Enter the Personnel File form and retrieve the user in question.
 Tip: Retrieve by User (in the General tab). 
 

 2 .  Enter the Company-Specific Information sub-level form. 
 

 3 .   Do one of the following: 
 

 ·      To allow access to all sales opportunities, click the Data Privileges tab and flag the Auth ' d to View All Sales Opp Type s column. 
 

 ·      Otherwise, enter the Authorizat'n for Sales Opp Types sub-level form and flag any sales opportunity types the user is authorized for. 
 
## Notes:

 

 ·        Restrictions also apply to any sales reps assigned this opportunity type. 
 

 ·        To activate Data Authorizations for sales opportunity types, run the Activate/Disable Data Authoriz'n program for this data type and select the Activate Data Authorization option. Thereafter, users will only be able to access sales opportunities of the types that they are authorized for.
