# Enabling Access to Sales Reps' Documents

 

If you choose to restrict access to documents involving particular sales representatives, you can define, for each user, which sales reps he or she is authorized for. You can also flag specific users (e.g., the sales manager) as authorized to see documents involving all sales reps. 
 
## To define the sales reps a user is authorized for:

 

 1 .  Enter the Personnel File form and retrieve the user in question.
 Tip: Retrieve by User (in the General tab). 
 

 2 .  Enter the Company-Specific Information sub-level form. 
 

 3 .   Do one of the following: 
 

 ·      To allow access to documents involving all sales reps, click the Data Privileges tab and flag the Authorized to View All Sales Reps column. 
 

 ·      Otherwise, enter the Authorization for Sales Reps sub-level form and flag any sales reps the user is authorized for. 
 
## Notes:

 

 ·        To activate Data Authorizations for sales reps, run the Activate/Disable Data Authoriz'n program for this data type and select the Activate Data Authorization option. Thereafter, users will only be able to access documents involving sales reps that they are authorized for. 
 

 ·        Restricting access to sales reps does not automatically restrict access to the records of customers and vendors that are linked to those sales reps. To widen the restriction to include customer and vendor records, run the Define Data Auth by Branch/Rep program. 
 

 ·        Documents recorded without a sales rep will be accessible to all users. 
 

 ·        Click to view a list of user authorizations per data type. 
 

 ·        Click to return to the main screen.
