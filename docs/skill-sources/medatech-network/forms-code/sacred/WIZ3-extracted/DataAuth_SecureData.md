# Defining Data as Secured

 

The following types of records can be defined as secured: accounts (GL, A/R and A/P), customers and vendors. Users who are unauthorized to view secured data of a given type will not be able to view any related data (e.g., journal entries, orders and invoices). 
 
## Note:

 

Click for more details on what data is hidden. 
 
# To define an account as secured:

 

 ·        Retrieve the account in one of the following forms, and flag the Secured Account column (in the General tab):
 Chart of Accounts 
 Chart of Accounts Receivable 
 Chart of Accounts Payable 
 
## To define a customer as secured:

 

 ·        Retrieve the customer in the Customers form and flag the Secured Customer column ( Details tab). 
 
## To define a vendor as secured:

 

 ·        Retrieve the vendor in the Vendors form and flag the Secured Vendor column ( Details tab). 
 
## Notes:

 

 ·        In the various charts of accounts, move to Full-Record Display Mode to access the form's tabs. 
 

 ·        Once even one account, customer or vendor is defined as secured, the Data Authorization mechanism is activated for secured data of that type. From then on, only authorized users have access to any related data. Click to define those user s authorized to access secured data .
