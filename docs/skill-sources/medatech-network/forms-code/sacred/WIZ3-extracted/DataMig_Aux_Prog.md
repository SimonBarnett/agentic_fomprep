# Auxiliary Programs

 

The auxiliary programs enable you to make sweeping adjustments to the data in an interim table, before they are transferred to the system. Some of these programs are common to all data types (e.g., for removing quote marks, removing data from the interim table that already exists in the system and clearing the table entirely), while others are specific to the type of data in question (e.g., for changing part units, changing a price list currency). 
 
## To run the auxiliary programs:

 

 ·        Enter the Auxiliary Programs sub-menu of the appropriate data migration sub-menu (e.g., Part Data Migration ), and run the desired programs.
