# To correct discrepancies between data in the interim table and existing data in the system:

 

 1 .  Revise or add to your system data using the forms in the Forms for Recording Data menu. 
 

 2 . Do either or both of the following: 
 

 ·      Click to revise certain data automatically in batch. 
 

 ·      Revise the data in the interim table manually. 
 

 3 . Check again for errors. 
 

 4 . Repeat the above process until there are no errors. 
 
## Notes:

 

 ·        Click to populate the system with part specs, part families and customer categories from data in the interim table. 
 

 ·        Click to load data from the interim table to the system database. 
 

 ·        Click to return to the main screen.
