# Defining the Load File

 

You can import data into Priority using ASCII files generated by your previous system, or using an intermediary format, such as MS-Excel. The columns in the input file must match the corresponding columns in Priority . Each column can be assigned a fixed width, or separated from the next column by a tab. 
 
## To define the structure of the load file:

 

 1 .  Enter the relevant file definitions form (e.g., for part data, enter the Load File Definitions-Parts form). 
 

 2 .  Flag the Inactive column for any field that you do not want to load into the interim table. 
 

 3 .  Fill in the First Character and Last Character columns in one of the following ways: 
 

 ·      If you are loading a text file with columns of a fixed width, use these values to define the width of each column. 
 

 ·      If you are loading a text file with tab separations, fill in the same number in both columns. This number will determine the position of the column within the record, relative to the other columns. 
 

 4 . Select the appropriate Loaded Date Format for each date column. 
 
## Note:

 

If you are loading journal entries and accounts, use the Definition of Load Parameters form to define load parameters for your data sources.
