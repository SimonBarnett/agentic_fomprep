# Creating Choose Lists from Interim Data

 

When migrating part and customer data, you can use the data in the interim table to populate Priority tables with permitted values for customer categories and part specs, as well as with new part families. 
 
## To build a list of permitted values for customer categories (from the Interim Table-Parts):

 

 ·        Run the Set Permitted Values-Cust Categ. program. 
 
## To build a list of permitted values for part specs (from the Interim Table-Parts):

 

 ·        Run the Set Permitted Values-Part Spec program. 
 
## To add part families (from the Interim Table-Parts):

 

 ·        Run the Create Part Families from IntTbl program. 
 
## Notes:

 

 ·        Click to load data from the interim table to the system database. 
 

 ·        Click to return to the main screen.
