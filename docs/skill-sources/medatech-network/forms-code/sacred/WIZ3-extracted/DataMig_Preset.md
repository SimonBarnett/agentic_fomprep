# Defining Basic Data

 

Before importing records into the database, you need to set up the necessary basic data in a number of Priority forms (e.g., part units, currencies, warehouses). Records for which the required data have not been defined in the system will not be loaded into the system. 
 
## To define basic data:

 

 ·        Fill in the forms listed under the Forms for Recording Data menu.
