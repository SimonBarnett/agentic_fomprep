# To load a file into the interim table:

 

 1 . Run the Load File into Interim Table program in the relevant data migration sub-menu. 
 

 2 . Specify the path to the data file. 
 
## Notes:

 

 ·        Click to check and correct errors in the interim table. 
 

 ·        Click to populate the system with part specs, part families and customer categories from data in the interim table.
