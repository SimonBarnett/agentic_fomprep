# Loading Data from the Interim Table to the System Database

 
# Before you begin

 

 1 .  Run the report provided in each sub-menu to check whether any records in the interim table already exist in the system (e.g., Parts Already in Database , Customer Contacts Already in DB ). 
 

 2 . Do one of the following: 
 

 ·      If records exist in the database and you want to overwrite them with the records in the interim table, proceed to the data load. 
 

 ·      If records exist in the database and you do not want to overwrite them, run the program provided in each sub-menu to remove such records from the interim table (e.g., Delete Existing Parts from Table , Del Existing Contacts from Table ). 
 
# To load data into the system database:

 

 ·        Run the Load from InterimTbl to Database program. 
 
## Notes:
