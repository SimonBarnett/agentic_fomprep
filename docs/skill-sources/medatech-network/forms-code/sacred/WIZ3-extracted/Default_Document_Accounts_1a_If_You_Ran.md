# Default_Document_Accounts_1a_If_You_Ran

- **Source:** `Default_Document_Accounts_1a_If_You_Ran.htm`

Set Up Default Accounts - Introduction.2 
 
 
- 
 
 
 

If you ran the Account Initialization or Account Initialization-Intl program (for the U.S. and dual-currency packages, respectively), Priority has predefined the default GL account for each transaction type. You can view these accounts – and change them, if necessary – in the Default Accounts form. 
 

If you did not run the program, fill in the GL accounts manually. 
 
## Note: 

 

The Default Accounts form lists additional transaction types (an explanation of each appears in the sub-level form). These transaction types fall into two categories: 
 

 ·              Inventory transactions recorded in the entry journal when the Post Cost of Goods Sold program is run. These can be set up when you are ready to run COGS. For information, run the Cost of Goods Sold (COGS) Wizard . 
 

 ·              Other transactions (e.g., Prior Retained Earnings). If you did not run the Account Initialization or Account Initialization-Intl program, fill in the GL accounts manually.
