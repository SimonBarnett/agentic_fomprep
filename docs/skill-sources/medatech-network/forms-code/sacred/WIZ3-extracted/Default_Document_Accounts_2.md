# Changing the Default GL Account Setup

 

If Priority 's default account setup does not fully meet your company's needs, you can change it based on how income and expenses are distributed in your company (e.g., per warehouse in which the inventory transaction takes place). 
 

You make the changes per type of transaction. In other words, you can change the predefined setup for one or more transaction types and leave the predefined setup for others. 
 
## Note:

 

If Priority 's default account setup meets your company's needs, you are finished with this wizard.
