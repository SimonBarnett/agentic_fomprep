- 
 
 
 
# To set up default accounts for a family within a warehouse:

 

 1 .  Enter the Accounts for Warehouses form. 
 

 2 .  Retrieve the desired warehouse(s). 
 

 3 .  Enter the Acc'ts for Families in Warehouse sub-level form. 
 

 4 .  In the Family column, choose the desired accounting family. 
 

 5 .  In the column(s) for the type(s) of default account you want to set up (e.g., Income ), choose an account.
