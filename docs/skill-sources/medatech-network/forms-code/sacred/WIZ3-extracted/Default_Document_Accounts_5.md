# To set up default accounts for a warehouse:

 

 1 .  Enter the Accounts for Warehouses form. 
 

 2 .  Retrieve the desired warehouse(s). 
 

 3 .  In the column(s) for the type(s) of default account you want to set up (e.g., Income ), choose an account.
