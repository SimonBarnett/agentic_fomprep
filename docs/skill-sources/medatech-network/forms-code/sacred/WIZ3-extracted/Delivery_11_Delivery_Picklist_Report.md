# Running Delivery Reports

 

 Priority allows you to produce a picklist report either according to orders or according to shipping documents/sales invoices. These reports display a list of all the orders or documents that have been recorded for delivery to customers, sorted by distribution route, round and delivery date. Each of these reports is useful for the driver who makes the deliveries. 
 

You can also print a batch of orders or individual order confirmations with picklists. The customer bar code is displayed for each order item (where relevant), and there are empty spaces in which to fill in information on the stages of picking parts from inventory, loading goods on the truck and supplying them to the customer. 
 

Finally, you can print out a delivery list for each driver, providing such information as the location of the shipped goods ( Shipping Pallet ), their weight and volume, and the customers on the route. You can also prioritize your customers, so that they appear in a specific order in the report.
