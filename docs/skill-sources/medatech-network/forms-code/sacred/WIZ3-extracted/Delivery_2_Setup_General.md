# Setting Up the Delivery Module

 

Before you begin working with the module, you should define: 
 

 Vehicle types, vehicles and distribution routes 
 

 Part families for which deliveries will be scheduled , including the weight and volume of parts in those families 
 

 Customer info, such as distribution routes, delivery days, and the type of document to accompany the delivery 
 

 The default warehouse from which goods are delivered, per user 
 

 An order status that allows for delivery
