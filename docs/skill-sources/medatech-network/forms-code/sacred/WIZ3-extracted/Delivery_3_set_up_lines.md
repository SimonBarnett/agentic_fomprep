# Recording Details of Vehicles and Distribution Routes

 

Before you can schedule orders for delivery, you need to define the types of vehicle in which deliveries will be made, and record the specific vehicles used by your company. You also need to define shipping zones, and the distribution routes within those zones. Defining the weight and volume capacities of the various vehicle types allows you to ensure that the weight and volume of the delivered parts does not exceed the maximum capacities defined for the vehicle assigned to a particular route. 
 
## To define vehicle types:

 

 1 .  Enter the Vehicle Types form. 
 

 2 .  For each type, record a Vehicle Type Code and a corresponding Vehicle Type Description . 
 

 3 .  Specify the Maximum Weight that this type of vehicle can carry, and the Unit by which the weight is measured. 
 

 4 .  Specify the Maximum Volume that this type of vehicle can carry, and the Unit by which the weight is measured. 
 
## To record delivery vehicles:

 

 1 .  Enter the Transports form. 
 

 2 .  For each vehicle, record a License Number and Transport Description . 
 

 3 .  Specify the Shipper/Driver Number . The name of the shipper/driver will appear automatically.
 Tip: To define additional shippers/drivers, use the Drivers/Shippers form. 
 

 4 .  Specify the Vehicle Type Code .
