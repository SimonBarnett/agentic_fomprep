# Assigning Default Warehouses

 

For each employee who will be preparing deliveries, you can designate the default warehouse from which goods are to be delivered. This will facilitate automatic scheduling, as well as the preparation of shipping documents and sales invoices. 
 
## To assign a default warehouse:

 

 1 .  Enter the Personnel File form and retrieve the employee in question (e.g., by username). 
 

 2 .  Enter the Company-Specific Information sub-level form and designate the warehouse in question.
