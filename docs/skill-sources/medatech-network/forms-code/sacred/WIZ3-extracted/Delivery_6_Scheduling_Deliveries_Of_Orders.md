# Preparing a Delivery Schedule

 

The delivery schedule is used to assign each sales order a delivery date, distribution route and round number for that route. To be scheduled, the following conditions must be met: 
 

 ·        The order status must allow for shipment. (Click to define such an order status. ) 
 

 ·        At least one order item must belong to a part family flagged for delivery. (Click to flag the part family. ) 
 

 ·        The order must be open. 
 

 Priority provides a program that schedules deliveries automatically. After the schedule has been created, you can add an order manually (e.g., a new rush order). 
 

You can also choose to schedule deliveries manually without utilizing the automatic mechanism.
