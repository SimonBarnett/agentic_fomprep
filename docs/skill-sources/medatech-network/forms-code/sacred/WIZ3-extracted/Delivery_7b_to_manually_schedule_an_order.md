# To manually schedule delivery of a single order:

 

 1 .  Enter the Deliveries by Order form. 
 

 2 .  Retrieve the desired order (e.g., by its date or customer number).
 Note: Only orders that meet the criteria for delivery scheduling can be retrieved. 
 

 3 .  Choose a distribution route in the Distrib. Route Code column. The value 1 will appear automatically in the Round Number column. If the order is intended for delivery in a later round of the designated route, change the round number accordingly.
 Tip : To view the customer's default distribution route, enter the Customers form and click the Shipments tab. 
 

 4 .  The Delivery Date is derived automatically from the due date of the order. Revise it if necessary. 
 Note: If the delivery date falls on a day of the week that is not defined as a delivery day for the customer, the Exception column is automatically flagged. 
 

 5 .  If you want the order to be accompanied by a different document than the customer default, select the desired value in the Delivery Doc. Type column.
 Note: The default delivery document is a function of the Delivery with Sales Inv. column in the Invoices tab of the Financ. Parameters for Customers form. If the column is flagged, deliveries are made with a sales invoice. Otherwise, they are delivered with a shipping document.
