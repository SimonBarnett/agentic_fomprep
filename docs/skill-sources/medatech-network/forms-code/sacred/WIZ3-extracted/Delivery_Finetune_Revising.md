# Reviewing and Revising Deliveries Via the Scheduling Forms

 

Use the delivery scheduling forms to obtain more comprehensive and detailed information about specific orders; to change the distribution route, round and/or document type (from a shipping document to a sales invoice or vice versa); and to cancel or reschedule a delivery. 
 
## What do you want to do?

 

 Review and revise scheduling data 
 

 Cancel scheduled deliveries 
 

 Reschedule an order
