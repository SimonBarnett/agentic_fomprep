## Notes: 

 

 ·        The customer's default distribution route is defined in the Customers form. 
 

 ·        The default delivery document is a function of the Delivery with Sales Inv. column in the Invoices tab of the Financ. Parameters for Customers form. If the column is flagged, deliveries are made with a sales invoice. Otherwise, they are delivered with a shipping document.
