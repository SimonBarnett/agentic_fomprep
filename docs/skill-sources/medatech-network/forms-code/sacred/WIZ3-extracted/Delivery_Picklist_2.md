Delivery Scheduling - Running Delivery Reports.3 
 
 
- 
 
 
 

 To produce a picklist per order: 
 

 ·        Run the Delivery Picklist by Order report. 
 
## To produce a picklist per shipping document:

 

 ·        Run the Picklist by Shipping Doc/Invoice report. 
 Note: This report can be sorted by document or by part family. 
 
## To print a batch of orders with picklists:

 

 ·        Run the Print Orders With Picklist report. 
 
## To print an order confirmation with a picklist:

 

 ·        Select the Picklist print format when preparing the confirmation. 
 
## To print a delivery list for each driver:

 

 ·        Run the Delivery List for Driver report.
