# Preparing Documents to Accompany the Delivery

 

You can automatically open shipping documents or sales invoices that will accompany the parts shipped to customers, based on either sales orders or packing slips. After checking the documents prepared for the delivery, they can be finalized, printed and attached to the delivered goods.
