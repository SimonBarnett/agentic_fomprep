# To prepare invoices or shipping documents for the delivery:

 

 1 .  Run the Prepare Sales Invs+Shipping Docs program. Once the program is completed, you are notified as to how many documents were opened of each type. 
 Notes: 
 

 ·      The program opens documents only for open sales orders with a status that allows shipment, and whose delivery date and distribution route (and delivery round, if specified) match those specified. 
 

 ·      If the SUpdOrdDet constant is set to 1, the details of the ordered goods (e.g., quantity, weight and volume) will be updated accordingly in the Deliveries by Order form. 
 

 2 .  Depending upon the type of document that was opened, do the following: 
 

 ·      If the program created invoices, enter the Sales Invoices form. 
 

 ·      If the program created shipping documents, enter the Customer Shipments form. 
 

 3 .  Retrieve the desired documents that were created (e.g., by date).
