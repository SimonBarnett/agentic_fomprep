## Notes:

 

 ·        Once the invoice or shipping document is final, you cannot make changes to it directly. Rather, you must use the Invoice Revisions or Revision of Final Shipping Doc. form, respectively. To revise the Truck No. and Shipper/Driver , run the Revise Truck No./Driver in Docs program. 
 

 ·        For more details on revising these documents, run the Customer Shipment/Return Wizard or the Customer Invoices Wizard .
