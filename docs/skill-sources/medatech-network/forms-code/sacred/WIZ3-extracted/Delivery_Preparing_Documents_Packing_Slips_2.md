# To prepare invoices or shipping documents for the delivery:

 

 1 .  Run the Prepare Docs from Packing Slips program. Once the program is completed, you are notified as to how many documents were opened of each type. 
 Note: The program opens documents only for those crates that are recorded in final packing slips which are earmarked for orders whose delivery date and distribution route (and delivery round, if specified) match those specified. 
 

 2 .  Depending upon the type of document that was opened, do the following: 
 

 ·      If the program created invoices, enter the Sales Invoices form. 
 

 ·      If the program created shipping documents, enter the Customer Shipments form. 
 

 3 .  Retrieve the desired documents that were created (e.g., by date).
