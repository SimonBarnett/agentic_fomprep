# Using the Scheduling Work Area

 

The Scheduling Work Area allows you to simultaneously view all orders scheduled for up to 10 routes, as well as selected details of the orders (e.g., total part quantity, weight or volume). Then, with the click of the mouse, you can move an ordered quantity from one of the displayed routes to another. 
 

To open the work area, run the Scheduling Work Area program.
