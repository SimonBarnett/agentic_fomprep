# Defining an Order Status for Deliveries 

 

To schedule the delivery of ordered goods, the order in question must have a status that allows for shipment and for delivery scheduling. 
 
## To check that an order status has been so defined:

 

 ·        Enter the Statuses for Orders form. Check that at least one status is flagged in both the Allow Shipmt/ProjRep and Schedule Deliveries columns. 
 
## Notes:

 

 ·        To add a new status or revise the attributes of existing ones, run the BPM Flow Chart-Sales Orders program. 
 

 ·        If you also maintain statuses for individual order items, check the same column in the Statuses for Order Items form.
