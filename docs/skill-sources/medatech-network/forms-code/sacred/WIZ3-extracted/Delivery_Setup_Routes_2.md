## To define shipping zones:

 

 1 .  Enter the Shipping Zones form. 
 

 2 .  Record a code and description for each shipping zone.
 Tip: Use the States & Countries in Zone sub-level form to list the states (and countries) that are included in the shipping zone. 
 
## To define distribution routes:

 

 1 .  Enter the Distribution Routes form. 
 

 2 .  In the Code- Distrib. Route column, record a code for each route. Also record a description and select the warehouse from which the route starts. If you maintain bins, specify the bin as well. 
 

 3 .  In the Truck No. column, choose the truck that will deliver the goods. The Shipper/Driver column will be filled in automatically, but may be revised. 
 

 4 .  Specify the shipping zone to which the route belongs in the Zone Code column.
