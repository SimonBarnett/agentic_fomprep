# Canceling a Final Deposit Slip

 

If errors are discovered in a final deposit slip, you can create a new document with negative values, which cancels the original one and creates a reversing journal entry. 
 
## To cancel a final deposit slip:

 

 1 .  Enter the Deposit Slips form and retrieve the desired deposit slip. 
 

 2 .  Do one of the following: 
 

 ·              Select Cancel Document (Original Date) from the list of Direct Activations to create a cancellation document and reversing journal entry dated to the original document date. 
 

 ·              Select Cancel Document For Date from the list of Direct Activations to create a cancellation document and reversing journal entry for a designated date. 
 
## Notes:

 

 ·        In order to cancel a final deposit slip whose journal entry is still pending, you must post the entry before running the cancellation program. 
 

 ·        You must be authorized to change the status of deposit slips to Canceled . 
 
## To view cancellation results:

 

Every canceled document and the document that canceled it are flagged in the Canceled column of the Sums tab. Both documents will be for the same amount, with different signs (positive amounts in the original document and negative amounts in the cancellation document).
