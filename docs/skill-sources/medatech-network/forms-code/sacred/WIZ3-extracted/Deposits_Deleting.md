# Deleting a Pending Deposit Slip

 

Pending deposit slips are deposits that have not yet been finalized and can be deleted from the system. 
 
## To delete a pending document:

 

 1 .  Enter the Deposit Slips form and retrieve the desired deposit slip. 
 

 2 .  Select Delete Pending Deposit Slip from the list of Direct Activations . 
 
## Note:

 

Click to return to the main screen.
