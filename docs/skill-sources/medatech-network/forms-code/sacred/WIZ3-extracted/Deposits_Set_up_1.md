# To set document attributes for deposits:

 

 1 .  Enter the Financial Documents form. 
 

 2 . Move to the Deposit line. 
 

 3 . Check the attributes that have been defined and revise as necessary.

For more information, run the Set Up Financial Docs Wizard .
