# To set a maximum number of lines for bank deposits to a given account:

 

 1 .  Enter the Bank Accounts form. 
 

 2 .   Move to the line for the bank account in question. 
 

 3 .   In the Max Itms per Deposit column, specify the maximum number of items which may be included in a single deposit slip for this account.
