# Defining Banknotes and Coins for Deposit

 

You can define banknotes and coins for any currency used for deposits. This enables you to indicate quantities of banknotes (e.g., 10 X 100-dollar note) and coins when depositing cash, rather than just a total cash sum (1,000 dollars). 
 
## To define banknotes and coins:

 

 1 .  Enter the Banknotes and Coins form. 
 

 2 .  Specify the currency in question. 
 

 3 .  Define the Note/Coin Code and Note/Coin Descr. (e.g., "100-dollar note"). 
 

 4 .  Indicate the Denomination of the banknote or coin.
