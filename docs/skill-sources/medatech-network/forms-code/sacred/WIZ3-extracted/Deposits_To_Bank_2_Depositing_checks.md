# Depositing Checks to a Bank Account

 

There are two ways you can prepare the deposit slip: 
 

 ·        Manually OR 
 

 ·        Automatically, for checks whose payment dates fall within a designated time period. 
 

As a general rule, if you are depositing most or all of the checks at the cashier with payment dates falling within a reasonable time period, prepare the deposit automatically. Otherwise, prepare it manually. 
 
## Note for dual-currency users:

 

Deposits of postdated checks can only be prepared manually.
