 9 .  Enter the Deposited Items form (another sub-level of the Deposit Slips form). The flagged checks appear. 
 

 10 .  Check that all the deposit information is correct. Make any corrections (e.g., check number, payment date) in the Revision of Checks form. To view the corrections in the deposit slip, refresh the screen (press Ctrl+F11 ) while in the Deposited Items form. 
 

 11 .    If the deposit slip needs to be checked before it is deposited, assign it the Checking status (in the References tab). In the Assigned to column, specify the username of the person who is responsible for checking the document. The deposit slip cannot be finalized until this status is changed. 
 Tip: You can define work flow rules so that the assigned user changes automatically when the status is assigned. 
 
## Notes:

 

 ·        D ual-currency users: Before reconciling bank accounts, it is recommended to run the Cash Postdated Checks program, which causes each postdated check to be recorded in a separate journal entry. Consequently, entries for incoming postdated checks will debit the bank account and credit the Postdated Chk Acc In account, while entries for outgoing postdated checks will debit the Postdated Chk Acc Out account and credit the back account. To view the results of running this program, run the Postdated Checks Cashed in Bank report. 
 

 ·        To view all deposits made to a bank account over a designated time period, run the Bank Deposits report. 
 

 ·        Depending on how deposits are set up, you may be required to finalize the deposit slip before you can leave the form. Explanation . 
 

 ·        Until you finalize the deposit slip, the checks it contains continue to appear in the cashier. However, you cannot include these checks in another deposit slip.
