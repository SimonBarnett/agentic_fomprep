# To prepare the deposit slip automatically:

 

 1 .  Run the Prepare Deposit Slip program. If you are depositing both checks and credit card slips, leave the Payment Type Code column blank. A message will appear informing you of the (temporary) number of the deposit slip. 
 

 2 .  Enter the Deposit Slips form and retrieve the deposit slip by its number.
 Note: To assign handling of the deposit slip to another employee, specify his/her username in the Assigned to column (in the References tab). You can then exit the form and ignore the following instructions. 
 

 3 .  Enter the Items at Cashier sub-level form. To exclude any items from the deposit slip, delete each line you want to exclude (press Ctrl+Delete ). 
Tip: To check whether the cashier balance is sufficient to cover the deposit, return to the upper-level form and select Check Cashier Balance from the list of Direct Activations .
