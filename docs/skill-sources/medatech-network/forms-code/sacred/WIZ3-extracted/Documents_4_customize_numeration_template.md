# Customizing the Numeration Templates

 

The Open Numeration Templates program creates numeration templates for the specified year, based on the system defaults. If you maintain branches, a different set of templates will be assigned to each branch. You can customize the template for any given type of document (and branch), so long as you have not yet opened a document of that type. 
 
## To customize the numeration template:

 

 1 .  Enter the Document Numeration Templates form. 
 

 2 .  For each document type, you can change: 
 

 ·      The prefix, including the year and branch identifier. 
 

 ·      The initial number. 
 
## Notes: 

 

 ·        The number of documents of each type that may be opened during a given year is limited by their column width less the width taken up by the prefix. Example. Make sure that the maximum document number allowed by the template is high enough to open the quantity of documents of this type anticipated in one year. 
 

 ·        If you expect to open relatively few documents of a given type over a period of one year, you can reduce the column width for that document type in order to assign numbers of shorter length. 
 

 ·        The option to delete the branch identifier from the prefix is useful when you want the branch identifier to appear in some documents (e.g., sales orders), but not in others (e.g., invoices). 
 

 ·        Click to return to the main screen.
