# To record company-specific job details:

 

 1 .  From the Personnel File form, enter the Company-Specific Information sub-level form. 
 

 2 .  Specify the Department to which the employee belongs and any other relevant information. 
 
## Note:

 

In a multi-company enterprise, you can only record/view details relevant to the current company.
