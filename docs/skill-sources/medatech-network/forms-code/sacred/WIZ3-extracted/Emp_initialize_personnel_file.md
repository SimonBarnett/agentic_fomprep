# Recording Personnel Files

 
## Before You Begin

 

A personnel file is usually opened automatically when a user name is assigned to the employee. If Priority has been synchronized with the Windows Active Directory, a user name is assigned and a personnel file opened when the employee logs in for the first time. Otherwise, this occurs when the Add New User program is run. 
 
## Note:

 

For more information, run the Opening a User Wizard . 
 
## The Personnel File

 

A personnel file contains the following categories of data: 
 

 ·        Personal Details: Name, social security number. 
 

 ·        General Details: Work team to which the employee belongs, address and telephone 
 

 ·        System Parameters: Employee ID, user name 
 

 ·        Company-specific job details: Department 
 

 ·        Position details: Position title, start date, percentage of full-time, employment type 
 

Some of this information is filled in automatically when the above program is run. The rest of the data, however, needs to be completed now. 
 
## Note:

 

If the employee is not a system user, the personnel file must be opened manually.
