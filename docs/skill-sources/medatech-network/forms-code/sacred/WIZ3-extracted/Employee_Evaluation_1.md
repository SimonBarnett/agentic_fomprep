# To record an evaluation:

 

 1 .  Enter the Evaluation Recording form. 
 

 2 .  Do one of the following: 
 

 ·              If the evaluation was scheduled in advance, retrieve the questionnaire opened for the employee. 
 

 ·              Otherwise, record the date of the evaluation, the questionnaire's format code, and the employee ID of the evaluator. 
 

 3 .  Enter the Responses to Questions sub-level form. All of the questions appear automatically. 
 

 4 .  For each question, select an answer from the predefined list, in the No. Response column. 
 Tip: Use the parallel Respondent's Remarks sub-level form to record remarks regarding any of the questions.
