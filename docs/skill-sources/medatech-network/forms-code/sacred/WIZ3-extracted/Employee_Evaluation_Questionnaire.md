# To create an evaluation questionnaire:

 

 1 .  Enter the Evaluation Formats form. 
 

 2 .  Record a Format Code and Questionnaire Title . 
 

 3 .  Enter the Questions in Questionnaire sub-level form and record the contents of the questionnaire, one question per line.
 Note: If the question overflows the available space, you can continue it in the Question (cont.) sub-level form. 
 

 4 .  For each question, enter the Possible Responses sub-level form and record a range of appropriate answers (e.g., absolutely not, probably not, perhaps, probably, absolutely). 
 

 5 .  To print the list of questions and their possible answers, run the Print Evaluation Formats report.
 Tip: Use this report as the form on which the evaluator records answers.
