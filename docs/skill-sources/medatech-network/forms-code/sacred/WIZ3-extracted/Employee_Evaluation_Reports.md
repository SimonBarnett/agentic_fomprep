# Analyzing Evaluations

 

The system provides several reports to assist you in analyzing the results: 
 

 ·        Print Evaluations – Details the contents of specific evaluation questionnaires. 
 

 ·        Evaluation Analysis – Summarizes the pattern of responses to each question in a questionnaire. 
 

 ·        Evaluator's Remarks – Details additional comments on the questionnaires.
