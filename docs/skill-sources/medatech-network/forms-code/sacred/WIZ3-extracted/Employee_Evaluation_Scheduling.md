# To schedule an evaluation:

 

 1 .  Enter the Evaluation Recording form. 
 

 2 .  Specify the future Date on which the evaluation is to be performed. The Questionnaire Number is filled in automatically. 
 

 3 .  Select the Format Code of the questionnaire to be administered. 
 

 4 .  Specify the applicant's social security number in the Employ/Cand SocSec# column. 
 

 5 .  Record the name of the person that is to perform the evaluation.
