# Recording a New Employee

 

Click if the new employee was never recorded as a job candidate. 
 
## To convert a job candidate to an employee:

 

 1 .  In the Job Candidates form, retrieve the desired job candidate. 
 

 2 .  Run the Convert Candidate to Employee program. The candidate's data is copied to the Personnel File form and its sub-levels.
