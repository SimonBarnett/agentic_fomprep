# Recording Information about the Employee's Job

 

 1 .  Enter the Personnel File form and retrieve the desired employee. 
 

 2 .  If the employee will be able to log in to Priority and he/she has already been assigned a user name , make sure that it is recorded in the User column (if a user name has not yet been assigned, it can be added to the personnel file by the system manager). 
 

 3 .  Record the First Name and Last Name . The employee's Full Name appears automatically, but can be revised. 
 

 4 .  If needed, click the Position & Team tab and change the information in the Job Title column. 
 

 5 .  If you want to change the employee's main Company , select Change Employee's Company from the list of Direct Activations . 
 

 6 .  If the employee is on a team, choose his/her team leader in the Leader's EmpID column. If the employee is a team leader, flag the Team Leader column. 
 

 7 .  Click the Address & Phone tab and make sure that the employee's address, phone numbers and e-mail address are correct. 
 

 8 .  Click the Assigned to tab and, if necessary, change the employee status and/or person responsible for this employee. 
 

 9 .  If desired, attach a file containing a photograph of the employee. 
 
## Note:

 

The data in this form is shared by all companies in a multi-company enterprise.
