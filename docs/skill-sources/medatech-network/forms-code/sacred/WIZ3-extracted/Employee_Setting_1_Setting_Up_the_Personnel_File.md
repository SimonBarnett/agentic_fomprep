# Setting Up Human Resources

 

Before you begin recording a personnel file, make sure that the company's departments and job positions have been defined. These settings should have been defined when you set up the Human Resources module. If they have not, run the Personnel Setup Wizard . 
 
## To check the company's departments:

 

 ·        Enter the Departments form, and make sure departments have been defined. 
 
## To check the company's job positions:

 

 ·        Enter the Job Positions form, and make sure positions have been defined.
