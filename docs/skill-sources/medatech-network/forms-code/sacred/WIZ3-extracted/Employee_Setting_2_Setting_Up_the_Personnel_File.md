# To record an employee in the personnel file:

 

 1 .  Enter the Personnel File form and record the employee's Social Security Number . An Employee ID appears automatically.
 Note: If Priority has been synchronized with the Windows Active Directory and the employee has logged in, or if the Add New User program was run, a personnel file was opened automatically and linked to the employee's user name. In such a case, retrieve the file and complete the missing data. 
 

 2 .  If desired, attach a file containing a photograph of the employee. 
 

 3 .  In the General tab, select the employee's user name and record the First Name , Last Name , Title and Gender . The employee's Full Name appears automatically, but can be revised. 
 

 4 .  Click the Position & Team tab and record the employee's Job Title . The current company is assigned automatically as the employee's main company.
 Tip: Select Change Employee's Company from the list of Direct Activations to change the company. 
 

 5 .  If the employee is on a team, choose his/her team leader in the Leader's EmpID column. If the employee is a team leader, flag the Team Leader column. 
 

 6 .  Click the Address & Phone tab. Record the employee's address, phone numbers and e-mail address. 
 

 7 .   Click the Definitions tab and fill in any relevant information. 
 

 8 .  Click the Assigned to tab. The default employee status and person responsible for this employee appear automatically, but can be revised. 
 
## Note:

 

The data in this form is shared by all companies in a multi-company enterprise.
