Employees - Recording Company-Specific Details 
 
 
- 
 
 
 
# To record information specific to the company in which the employee works: 

 

 1 .  Enter the Company-Specific Information sub-level of the Personnel File form. 
 

 2 .  Fill in any applicable columns (e.g., for a sales rep, fill in the Type of Sale column). 
 
## Note:

 

In a multi-company enterprise, you can only record/view details relevant to the current company.
