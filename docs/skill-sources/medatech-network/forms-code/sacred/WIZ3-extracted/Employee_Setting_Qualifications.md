# To record the employee's qualifications:

 

 Note: If the employee was initially recorded as a job candidate, qualifications may already be recorded. 
 

 1 .  Enter the parallel Qualifications sub-level form. 
 

 2 .  For each qualification, select a relevant Qualification Code . The description appears automatically. 
 

 3 .  Select the Value that best describes the employee in regards to the qualification. 
 

 4 .  The current company appears automatically as the company for which the qualification is defined. Revise as necessary. 
 
## Tip: 

 

To define qualifications and their possible values, run the Personnel Setup Wizard .
