# Defining an Employee as Inactive

 

When an employee stops working in the company (e.g., has been fired), you need to define this person as an inactive employee. The employee will not appear on any Choose lists of employees and the employee's username will automatically become inactive. 
 
## To define an employee as an inactive employee and user:

 

 1 .  Enter the Personnel File form and retrieve the desired employee. 
 

 2 .  Click the Assigned to tab. 
 

 3 .  Assign the employee a Status defined as Inactive (see the Statuses for Employees form). The Inactive Employee column (in the General tab) is flagged automatically and the employee's user record is flagged in the Inactive User column of the User Permissions form. 
 
## Notes:

 

 ·        If rules have been defined for changes in employee status, you may need authorization to make the status revision. 
 

 ·        To leave the employee active but make the user record inactive (e.g., when the employee stops working in the system), manually flag the Inactive User column in the User Permissions form.
