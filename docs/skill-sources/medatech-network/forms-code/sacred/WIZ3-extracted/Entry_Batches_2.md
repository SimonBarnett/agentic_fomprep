# Creating Entry Batches

 

 To create an entry batch: 
 

 ·        Run the Create New Entry Batch program, specifying a fiscal year and user. As a result, each time this user manually records a journal entry during that year, this batch number is assigned automatically to the entry as a default. 
 
## Note:

 

Batch numbers are not assigned to journal entries that were created automatically from financial transactions (e.g., when you finalize an invoice).
