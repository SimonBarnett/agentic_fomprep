# Viewing Entry Batches 

 

To view existing entry batches and the journal entries belonging to them, do one of the following: 
 

 ·        Enter the Journal Entry Batches form. Retrieve the desired batches. Enter the Entries in the Batch sub-level form to view the entries in each batch. OR 
 

 ·        Run the Journal Entries by Batch report.
