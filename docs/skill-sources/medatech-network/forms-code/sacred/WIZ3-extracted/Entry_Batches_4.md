# Closing Entry Batches

 

When you are finished recording all the journal entries belonging to a batch, close the batch. Do one of the following: 
 
## If you posted the journal entries as you recorded them:

 

 ·        Run the Close Entry Batch program. 
 
## If you have not yet posted the journal entries, post them and close the batch simultaneously:

 

 ·        Run the Post Journal Entries program. 
 
## Note:

 

You cannot close an entry batch assigned to another user.
