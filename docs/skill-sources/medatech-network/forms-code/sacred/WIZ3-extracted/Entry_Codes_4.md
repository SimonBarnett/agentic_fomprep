 4 .  For the % of Credit/Debit column, do one of the following: 
 

 ·              If you recorded a 4 in the Debit Code or Credit Code column, record the percentage of the total sum of the transaction you want to be credited/debited to this account. After recording all the lines, make sure that the total sum of the percentages is 100. 
 

 ·              If the percentage varies (i.e., you recorded a 4 in the Debit Code or Credit Code column), leave the column blank. You will specify the amount manually when you record each journal entry. 
 

 ·              If you recorded a different field code, designate 100 . 
 

 5 .  If the journal entry amount for this account is to be split and displayed on separate lines, flag the Divide column. Explanation. 
 

 6 .  If necessary, fill in the Source of Details and Details columns. Explanation . 
 

 7 .  If desired, specify any of the following: Budget Item, Contra Account, Profit/Cost Center, Cash Flow Code . These will serve as defaults for the account in this line.
