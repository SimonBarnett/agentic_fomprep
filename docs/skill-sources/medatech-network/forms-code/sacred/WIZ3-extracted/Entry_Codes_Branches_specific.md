# Assigning Separate Entry Codes to Branches

 

You can create special entry codes that apply to a particular branch (e.g., ROS = Receipt Out-of-State ), and which will replace the predefined entry codes for any users assigned to that branch. Whenever a user in a given branch records a financial document for which an alternate entry code has been defined, the special entry code for this branch is assigned automatically, rather than the general entry code defined for this type of document. For example, a receipt which was opened by a user in an out-of-state branch is assigned the ROS entry code, instead of the REC entry code for receipts. 
 
# To assign an entry code to a branch:

 

 1 .  Enter the Branches form and retrieve the desired branch. 
 

 2 .  Enter the Journal Entry Codes for Branch sub-level form. 
 

 3 .  Record the type of financial document you want to link to the branch. 
 

 4 .  Select the Entry Code to be applied to the current document for this branch. When you open a document of this type for a vendor or customer linked to this branch, it will be assigned this entry code automatically.
