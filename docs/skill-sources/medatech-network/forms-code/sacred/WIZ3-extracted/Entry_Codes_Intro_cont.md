Set Up Entry Codes - Intro.2 
 
 
- 
 
 
 

You can also use entry codes to facilitate manual recording of journal entries, particularly for transactions that you record on a regular basis (e.g., payroll entries). Once you specify the entry code, the journal entry is itemized automatically. 
 

Each entry code determines how accounts are credited/debited on the basis of a defined entry pattern . Most of the entry patterns of entry codes linked to financial documents include some type of account pattern . 
 

 Sample entry pattern. 
 
## Notes:

 

 ·        Each line in an entry pattern can be linked to a subsidiary. This is particularly useful when you need to record journal entries involving accounts in different subsidiaries. 
 

 ·        To view additional examples of entry patterns, enter the Entry Patterns , sub-level of the Journal Entry Codes form. 
 

 ·        We do not recommend changing the entry pattern of a predefined entry code.
