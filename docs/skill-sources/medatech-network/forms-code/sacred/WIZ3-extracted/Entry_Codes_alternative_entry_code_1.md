# Creating an Alternate Entry Code for a Financial Document

 

Since many things are shared by an existing entry code and the code you wish to define, use the former as a basis for comparison. 
 
## To copy the entry pattern from a predefined code:

 

 1 .  Enter the Journal Entry Codes form and retrieve the predefined entry code. 
 

 2 .  Enter the Entry Patterns sub-level form. The predefined entry pattern is itemized in this form. Open the Edit menu on the Menu Bar, select the Store Records option and return to the upper-level form. 
 

 3 .  In the Entry column, record a new code to represent the type of transaction in question. 
 

 4 .  In the Transaction column, record a brief description of the type of transaction (e.g., Purchasing 60-40 ). 
 

 5 .  Fill in the Source of Details column, and, if necessary, the Details column. Explanation . 
 

 6 .  Open the Edit menu on the Menu Bar, select the Retrieve Records option and approve this operation. The predefined entry pattern is copied to the Entry Patterns sub-level form, in which you can make the necessary changes.
