# To modify the entry pattern:

 

 Example of an alternate entry code , 
 

 1 .  Enter the Entry Patterns sub-level form. 
 

 2 .  If you wish to make changes in the accounts that are involved in the transaction, move to the Account/Pattern column and record one of the following: 
 

 ·              If the account is the same for each journal entry , record the actual account number. OR 
 

 ·              If all the journal entries involve accounts of the same type, record the appropriate account pattern. 
 

 Note: If you want to restrict the account pattern to accounts from a particular subsidiary (e.g., customer accounts at a specific branch), designate the Subsidiary . 
 

 3 .  Make sure that the Debit/Credit codes suit your needs. In order to change them, do one of the following: 
 

 ·              To debit or credit the total amount to this account, designate 1 in the Debit Code or the Credit Code column, respectively. OR 
 

 ·              If the percentage of the transaction to be credited/debited to this account varies from one journal entry to another, designate 4 in either the Debit Code or the Credit Code column, whichever is appropriate. You will specify the amount manually when you record each journal entry. OR 
 

 ·              In other cases, use one of the other codes. Explanation .
