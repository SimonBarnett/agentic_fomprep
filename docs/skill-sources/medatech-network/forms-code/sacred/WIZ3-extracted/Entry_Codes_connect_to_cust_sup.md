Set Up Entry Codes - Assigning to a Customer or Vendor 
 
 
- 
 
 
 
## To assign an entry code to a customer:

 

 1 .  Enter the Financ. Parameters for Customers form. 
 

 2 .  Click on the Invoices tab, and do one of the following: 
 

 ·              If the entry code is for debit transactions, record the appropriate entry code in the Debit Entry Code column. 
 

 ·              If it is for credit transactions, record it in the Credit Entry Code column. 
 
## To assign an entry code to a vendor:

 

 1 .  Enter the Financial Parameters for Vendors form. 
 

 2 .  Click on the Invoice Data tab, and do one of the following: 
 

 ·              If the entry code is for transactions crediting the vendor, record the appropriate entry code in the Entry Code-Invoice column. 
 

 ·              If it is for transactions debiting the vendor, record it in the Entry Code-Credit/Debit Memo column.
