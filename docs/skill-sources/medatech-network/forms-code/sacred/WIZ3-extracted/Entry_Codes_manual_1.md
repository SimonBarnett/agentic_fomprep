# To create an entry code for manual entries:

 

 1 .  Enter the Journal Entry Codes form. 
 

 2 .  In the Entry column, record a code that represents the type of transaction. 
 

 3 .  In the Transaction column, record a brief description of the type of transaction (e.g., Salaries ). 
 

 4 .  Fill in the Source of Details column, and, if necessary, the Details column. Explanation .
