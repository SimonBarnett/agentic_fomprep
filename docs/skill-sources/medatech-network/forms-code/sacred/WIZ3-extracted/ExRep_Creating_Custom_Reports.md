# Creating Custom Reports

 

Each area of analysis in the Executive Reports Module has its own report generator. Report generators allow you to create and save custom reports you can use to obtain data and details tailored to your individual needs. You can then generate an SQL query on the basis of a custom report; this is useful for retrieving data in BI tools and external programs such as MS-Excel. 
 

For detailed instructions on how to use the report generators and create SQL queries, run the Report Generators Wizard .
