# Creating a BI Cube

 

 Priority enables you to build BI cubes from BI reports that are defined in the system, and to save these files to disk. 
 
## To build a BI cube:

 

 ·        Run the Create Cube in SQL Server program. 
 
## To save a BI cube to disk:

 

 ·        Run the Save Cube program. 
 

 Note : 
 

Full BI cube functionality requires SQL Analysis Service. This service is not available when working in the Rich interface or in installations on SQL Server Express.
