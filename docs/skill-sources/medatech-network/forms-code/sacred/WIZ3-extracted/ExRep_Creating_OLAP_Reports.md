# Creating BI Reports and BI Cubes

 

BI reports are an important management tool used to view sales data (orders, invoices, commission sales), purchasing data (orders, invoices), financial data (journal entries), service call data and project report information in a variety of cross-sections. 
 

You can also create BI cubes from an existing BI report, and save these cubes for use with Priority 's BI tools, as well as external applications such as MS-Excel. 
 

There are three stages to working with a BI report: 
 

 ·        Preparing the data (updating recent data) 
 

 ·        Running the report 
 

 ·        Fine tuning the report 
 

Data can be prepared automatically on a daily basis or manually at the user's discretion. Once a report is run, the data can be viewed in various cross-sections and different levels of detail. Once you have achieved the desired display of data, you can export the final report to Word, Excel or Outlook (as an e-mail attachment), print it or save it as an HTML page. 
 
## What do you want to do?

 

 Prepare data for a BI report 
 

 Run and fine tune a BI report 
 

 Create a BI cube from an existing report 
 

 Export a BI report to an external application 
 
## Notes:

 

 ·        Full BI cube functionality requires SQL Analysis Service. This service is not available when working in the Rich interface or in installations on SQL Server Express. 
 

 ·        The data authorization mechanism does not apply to BI reports. This means that all users who are authorized to create BI reports can view any data displayed in these reports, even if they have not been assigned the corresponding data privileges.
