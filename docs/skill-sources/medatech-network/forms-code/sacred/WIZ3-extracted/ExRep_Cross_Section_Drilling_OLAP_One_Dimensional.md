# Cross-section Drilling in One-dimensional Format

 

The report initially displays data for the entire population. You can drill down to see various cross-sections of this data. 
 
## To drill down one level:

 

Click All . The pop up menu displays available dimensions by which to break down the data. Choose one. Example . 
 
## To drill down to the next level:

 

Click on one of the values in the left column and select a sub-category in the pop-up menu. Example . 
 

You can continue to drill down within the data until you reach the cross-section that you want. 
 
## To return to the previous level:

 

Click on the back arrow, or in the Go menu, select Back. 
 
## To return to the entire population:

 

Click the Return to Start icon at the top of the report. 
 
## Notes: 

 

 ·        Click on any column title to sort data within the current cross-section by the values in that column. 
 

 ·        If you click on a monetary value in the data, at any stage, you will get a detailed report of what makes up the sum. 
 

 ·        If you click on a linked value in the displayed data (other than the values in the left column), you will be taken to the form where the data originated. Example . 
 

 ·        In certain reports (e.g., Invoice Analysis (BI) and Order Analysis (BI) ), a Control Lamp is displayed, indicating target compliance for key performance areas. The color of the control lamp is determined by values in the current report, based on the value ranges defined in the Definition of Gauge Scales form. 
 

 ·        The input screen that appears when you want to drill down to a more detailed report contains a column called Use Pattern , which allows you to limit the displayed data according to a given criterion. For example, you can specify "5*" to limit a part report to parts beginning with the number 5. 
 

 ·        Click the icon located next to the period or date range defined for the report to view a column chart of all records in the current population. 
 

 ·        Click the icon located next to any of the values in the left column to view a column chart of that record. 
 

 ·        You can also view charts which provide graphic display of the data (e.g., three-dimensional charts and Flash-based charts) by clicking the icon located next to various column titles. 
 

 ·        Have your system manager check the CHARTTYPE system constant to make sure graphic display parameters are set correctly for your system.
