# To choose the Dimensions format:

 

 1 .  Click the icon. 
 

 2 .  Under Dimensions , choose between Multi-dimensional and One-dimensional formats. 
 
## Notes:

 

 ·        The format that you choose here becomes the default the next time the report is run. 
 

 ·        The same dialog box is also used to define the display format. Click for details.
