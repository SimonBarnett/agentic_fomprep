# Defining the Display Format

 

 1 .  Click the icon. 
 

 2 .  Select the appropriate display options for the table values: 
 

 ·              Rounding 
 

 ·              Total 
 

 ·              Percentages 
 
## Notes:

 

 ·        The format that you choose here becomes the default the next time the report is run. 
 

 ·        The same dialog box is also used to define the Dimensions format. Click for details.
