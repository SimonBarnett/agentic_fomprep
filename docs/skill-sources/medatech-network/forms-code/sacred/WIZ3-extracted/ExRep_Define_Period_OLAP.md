# Defining Periods and Companies

 

Once you have run one of the BI reports, specify the period and company for which to display data. You can specify either an absolute period (e.g., the first quarter of 2011) or the range of dates when the period begins and ends (e.g., from the start of this quarter to the end of this month). You can also specify multiple periods and/or companies to compare data from each. 
 
## To define the periods and companies for which to display data:

 

 1 .  Do one of the following: 
 

 ·      To specify an absolute period, click the icon ( Define Period ). In the appropriate columns, select the Year (e.g., 2010) and the Period in Year (e.g., November) for which to display data. 
 

 ·      To specify a range of dates, click the ( Define Date Ranges ) icon. You can then choose from a list of relative Start and End Date s (e.g., start of last month, end of this quarter) or click the calendar to open a pop-up calendar from which to choose the exact Start and/or End Date . 
 

 2 .  If you are working in a multi-company environment, select the C ompany for which to display data. 
 

 3 .  Select a Level of Detail for the report. For example, you can run a report for a whole year displaying data for each quarter; in this case, the Level of Detail would be Quarterly. 
 

 4 .  If you wish to compare data from more than one company (when working in a multi-company environment) and/or period, select the additional companies and/or periods whose data you wish to compare. Example. 
 

 5 .  Once you have set up a template of periods and/or companies, you can save it if desired (by clicking on one of the numbered buttons in the Save Template section). 
 
## Note:

 

Whatever values are currently chosen become the default the next time the report is run. To change them, click the appropriate icon and either redefine manually or reuse a saved definition by clicking on the appropriate number in the Get Template section.
