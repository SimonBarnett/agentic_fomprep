# Defining Parameters in English for BI Reports

 

If you are using the dual-currency package in a language other than English, and want to produce BI reports in English, you must define English values for the columns that appear in your reports. You should check each of the forms in which the relevant data are defined, and make sure that English values have been recorded for the columns in question. 
 
## Tip:

 

Click to hide columns that you want to exclude from BI reports. 
 
## Columns that appear in most BI reports:

 

 ·        Vendor N ame , in the Vendors form. 
 

 ·        [Customer] N ame , in the Customers form. 
 

 ·        [Customer] Group Description , in the Customer Groups form. 
 

 ·        Part Description , in the Part Catalogue form. 
 

 ·        [Part] Family Description , in the Part Families form. 
 

 ·        Branch Name , in the Branches form. 
 

 ·        [Accounting] Family , in the Accounting Families form.
