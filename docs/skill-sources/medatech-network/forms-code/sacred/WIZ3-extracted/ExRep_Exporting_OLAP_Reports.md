# Exporting a BI Report

 

 Priority enables you to export a BI report to external applications such as Word, Excel or Outlook (as an e-mail attachment), by clicking the appropriate icon at the top of the report. In each case, the export is a .htm file that opens in the selected application, which can then be saved to any of the file formats available in that application.
