# Preparing and Viewing Monthly Summaries

 

 Priority allows you to view monthly summaries of customer invoices , shipped goods , sales orders, purchase orders and purchasing invoices. 
 

Before you view the monthly summaries, you will need the system to calculate data over a designated period in the following cases: 
 

 ·        to view summaries for the first time 
 

 ·        to update existing data in keeping with changes made since the last calculation of data 
 

 ·        to expand or limit the period covered 
 

 Note : 
 

Calculations for each type of monthly summary are made separately.
