# Calculating Monthly Data

 

You determine the period within which to make monthly calculations by designating start and end dates. Any item whose document date falls within this period will be taken into account. 
 
## Note:

 

Each time you rerun the program the data appearing in the summaries will be recalculated and updated. 
 
## To calculate monthly summaries:

 

 ·        For shipped goods, run the Calculate Monthly Sales program. 
 

 ·        For customer invoices, run the Calculate Monthly Invoices program. 
 

 ·        For sales orders and commission orders, run the Calculate Monthly Sales Orders program. 
 

 ·        For purchase orders, run the Calc. Monthly Purchases (Orders) program. 
 

 ·        For purchase invoices, run the Calc. Monthly Purchases (Invs.) program.
