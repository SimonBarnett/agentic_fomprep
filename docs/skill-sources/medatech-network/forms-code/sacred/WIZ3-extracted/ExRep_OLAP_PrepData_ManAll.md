# To manually prepare data for some or all BI reports together:

 

 1 .  Make sure the EDays BI constant has been set to meet your needs.
 Tip: Click to set the constant . 
 

 2 . Run the Prepare All for Analysis (BI) program, and make sure the categories of data you want to prepare are flagged. 
 
## Notes:

 

 ·        To obtain up-to-date data on a daily basis, run the program at the end of every work day. 
 

 ·        Click to run a BI report.
