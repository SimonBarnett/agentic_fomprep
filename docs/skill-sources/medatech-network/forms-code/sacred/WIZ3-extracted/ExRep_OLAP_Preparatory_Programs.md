# Preparing BI Data

 

Preparations for BI reports involve the update of a selected portion of the data. This entails the addition of new data (recorded since the last preparation), as well as any recent revisions (e.g., changes in open invoices). 
 

The data update can be run automatically on a daily basis, or manually at your discretion. When run manually, you can update data for some or all reports together or each one separately (the latter choice is faster). 
 

If the data displayed in BI reports have accumulated over the years and are no longer relevant, you can run a program that clears all data from the BI report mechanism. 
 
## Note:

 

Once data is prepared, it remains available for future BI reports. Rerunning a preparatory program will update existing data as of a designated date, and append new data to that already in the system. Existing data outside of the date range will not be affected. 
 
## What do you want to do?

 

 Set up automatic preparation of BI data 
 

 Manually prepare data for some or all reports together 
 

 Manually prepare data for a single BI report 
 

 Clear all data from BI reports
