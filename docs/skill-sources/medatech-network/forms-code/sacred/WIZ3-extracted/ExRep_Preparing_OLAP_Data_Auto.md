# To set up automatic preparation of BI data:

 

 1 .  Make sure the EDays BI constant has been set to meet your needs.
 Tip: Click to set the constant . 
 

 2 . Enter the Flag BI Reps for "Prepare All" form. 
 

 3 . Flag the reports that you wish to update when running the Prepare All for Analysis (BI) program. 
 

 4 . Have your system manager add the Prepare All for Analysis (BI) program to the Tabula Task Scheduler. 
 
## Notes:

 

 ·        Once automatic preparation has been set up, you can run BI reports whenever you like, without the need to prepare data. Data will always be up-to-date as of the previous evening. 
 

 ·        Until automatic preparation is set up, you can prepare data manually by running the Prepare All for Analysis (BI) program. Flagging reports in the Flag BI Reps for "Prepare All" form will not affect your report choice options when running this program. 
 

 ·        Click to run a BI report.
