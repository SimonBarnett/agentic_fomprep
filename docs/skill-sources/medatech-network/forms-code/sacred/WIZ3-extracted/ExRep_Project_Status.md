# Excluding Projects of a Given Status

 

Projects of a given status can be excluded from BI data. 
 
## To flag project statuses for exclusion:

 

 1 .  Run the BPM Flow Chart-Projects program. 
 

 2 .  For each status that you want to exclude, flag the Omit from Analysis column when defining status properties.
