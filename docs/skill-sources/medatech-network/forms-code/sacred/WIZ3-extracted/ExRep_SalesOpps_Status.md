# Excluding Sales Opportunities of a Given Status

 

Sales opportunities of a given status can be excluded from BI reports and custom reports designed in the Sales Opportunity Rep. Generator . 
 
## To flag sales opportunity statuses for exclusion:

 

 1 .  Run the BPM Flow Chart-Sales Opps program: 
 

 2 .  For each status that you want to exclude, flag the Omit from Reports column when defining status properties.
