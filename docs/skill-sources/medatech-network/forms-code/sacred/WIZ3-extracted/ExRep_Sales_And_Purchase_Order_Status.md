# Excluding Orders of a Given Status

 

Sales orders, purchase orders and commission orders of a given status can be excluded from monthly summaries, customized reports and BI data. 
 
## To flag order statuses for exclusion:

 

 1 .  Run the appropriate program: 
 

 ·      For sales orders: BPM Flow Chart-Sales Orders . 
 

 ·      For purchase orders: BPM Flow Chart-Purchase Orders . 
 

 ·      For commission orders: BPM Flow Chart-Commiss'n Orders . 
 

 2 .  For each status that you want to exclude, flag the Omit from Reports column when defining status properties.
