# Setting Up Executive Reports

 

There are three optional settings that globally affect the data displayed in executive reports. 
 

 ·        You can exclude certain documents (sales opportunities, sales orders, purchase orders and commission sales orders) from executive reports on the basis of their status. Example . 
 

 ·        You can limit the project data you view in BI reports on the basis of the project status. 
 

 ·        You can ensure the automatic display of up-to-date information in the BI reports by setting a constant that determines the date as of which to update all BI data in preparation for running the reports. This update can then be run automatically, on a daily basis, by the Tabula Task Scheduler.
