# Viewing Dashboards

 

 Priority Dashboards display relevant data in a variety of cross-sections, such as reports, graphs and tables. In addition, they provide access to relevant BI reports. 
 

Each Dashboard is comprised of a number of web parts, which can be arranged as desired using a built-in design tool. These web parts can also display any external websites that have been defined in Priority . 
 

For detailed instructions on working with Dashboards, see the User Interface Guide .
