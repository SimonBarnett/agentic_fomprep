# To load the Part Spec Work Area:

 

 1 .  Run the Load Work Area by Base Product program.
 Tip: If you are in the Part Catalogue form, retrieve the desired base product (style) and select Load Work Area by Base Product from the list of Direct Activations . 
 

 2 .  Select the desired Load Mode : 
 

 ·              Choose Entire Size Chart to load all of the possible combinations of colors and sizes for the designated style, as recorded in the Part Colors (Fashion) sub-level of the Part Catalogue and the style's selected size chart, respectively. 
 

 ·              Choose Defined Assortment to load a specific assortment of the designated style, as defined in the Assortment sub-level of the Part Catalogue . 
 

 3 .  Specify the desired style in the Base Product input column. After loading the work area, the program will display a message informing you of the number of draft parts that were opened.
 Note: The program will load all of the possible parts based on the designated style, including parts that have already been defined. You can take this opportunity to revise their attributes, if necessary.
