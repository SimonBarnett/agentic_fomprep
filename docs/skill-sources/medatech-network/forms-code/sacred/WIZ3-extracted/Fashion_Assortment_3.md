# To create new parts from the Part Spec Work Area:

 

 1 .  Enter the Part Specs Work Area form and retrieve all records.
 Tip: If you are in the Part Catalogue form, retrieve the desired base product (style) and select Part Specs Work Area from the list of Direct Activations . 
 

 2 .  If you chose the Entire Size Chart option, press Ctrl + Del to remove any undesired draft parts from the work area. 
 

 3 .  For each remaining draft part, check the defined part attributes (e.g., Type , Family , Accounting Family , Standard Cost, Base List Price ) and revise them if necessary.
 Note: If you revise the attributes of previously existing parts, these attributes will be updated automatically in the forms in which they appear (e.g., Part Catalogue , Parts , Financial Parameters for Parts ).
