Fashion - Creating New Parts from the Work Area.2 
 
 
- 
 
 
 

 4 .  Exit the form and run the Create Parts from Work Area program.
 Notes: 
 

 ·              If you are in the Part Catalogue form, retrieve the desired base product (style) and select Create Parts from Work Area from the list of Direct Activations . 
 

 ·              After creating the new parts, the program will display a message informing you of the number of parts that were opened. If the program encounters difficulties opening any of the draft parts (e.g., size chart values were not copied into the Definition of Part Specs form for Spec 3), it will display an error report informing you of the problems. 
 

 ·              The original style will now be flagged in the Base Product column of the Part Catalogue form for each new part. 
 
## Notes:

 

 ·        You can run the Check Compliance w/Base Product report to check that part specs are identical to those of the fashion style to which they are linked, and use the Fix Compliance with Base Product program to fix any discrepancies you discover. 
 

 ·        You can run the Non-Permitted Spec Values report to display all specs that were defined manually, rather than from a list of permitted values. 
 

 ·        Click to assign international bar codes (GTIN) to the new parts. 
 

 ·        Click to use the new style and catalogue numbers to convert existing inventory. 
 

 ·        Click to maintain price lists for fashion items . 
 

 ·        Click to return to the Fashion Style s menu.
