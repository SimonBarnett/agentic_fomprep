# Supplying Fashion Goods to a Chain of Stores

 

Sales in the fashion industry involve the distribution of large quantities and varieties of goods to chains of stores, which may be your own factory outlets or external franchises. Each store is represented in the system by a warehouse linked to a customer. Priority provides an efficient automated system that allows your warehouse staff to distribute the right assortments of goods to each store when they are needed. 
 

Once you have defined default assortments for each combination of distribution and product types, you can open a unified sales order for all stores in the chain. This “order” will act as a distribution planner from which you can generate a unified purchase order (that displays separate assortment matrices for each store), and a set of packing slips (one for each store, displaying its particular assortment matrix). 
 
## Note:

 

Individual customers (e.g., wholesalers) can also be included in automatic distribution planning, alongside one or more chains of stores, provided they have been assigned distribution types.
