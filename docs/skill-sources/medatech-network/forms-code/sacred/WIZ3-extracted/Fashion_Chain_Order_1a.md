# To create a unified sales order:

 

 1 .  Enter the Sales Orders form, and open a sales order for your dummy customer.
Click if you have not yet defined a dummy customer .
 Note: Make sure the order is assigned a sales type that has been flagged for distribution (in the Types of Sales form). 
 

 2 .  Enter the List of Styles sub-level form. Your first task is to record a separate line for each combination of fashion style and distribution type (i.e., one line for the large stores, one line for the small stores, etc.). 
 Note: The following instructions describe how you can use the automatic customer distribution list as an aid when filling in this form. Make sure all customers have been assigned distribution types before you begin; click if they have not . 
 

 3 .  Specify the first fashion style that you are supplying in the Base Product No. column. The current date appears automatically in the Due Date column (at the end of the row), but may be revised. 
 

 4 .  Select Prepare Customer Distrib. List from the list of Direct Activations and specify the customers you wish to supply. 
 

 5 .  Enter the parallel Customer Distribution List sub-level form, and change the Distribution Type of any of the customers, if necessary.
 Note: If necessary, delete the lines for any customers that are not relevant to this order, leaving only those stores you are currently supplying. 
 

 6 .  Make a note of how many customers belong to each distribution type (i.e., 2 customers of Type AA , 3 customers of Type BB ).
