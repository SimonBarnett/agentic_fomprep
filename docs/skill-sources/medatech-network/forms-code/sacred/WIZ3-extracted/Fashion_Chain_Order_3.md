# Itemizing the Assortments

 

Now that you have recorded the fashion styles you are supplying, you need to determine the contents of the assortment that will be sent to each type of store and to your reserve stock. The Assortment sub-level form consists of a matrix that displays the colors and sizes defined for the current style in all possible combinations. 
 

Each line represents a set , which consists of all items of different sizes that share the same color. 
 

The itemization process is made easier by the default assortments you defined for each product type/distribution type combination (provided that you assigned a product type to each fashion style). In practice, these default quantities appear set by set, after you specify a quantity of sets. 
 

Remember that each assortment that you itemize will be shipped to every store that has the same distribution type. 
 
## To itemize an assortment:

 

 1 .  Return to the first line in the List of Styles sub-level form and enter the Assortment form in the next sub-level. If you specified a color in the List of Styles form, only that set appears in the chart. 
 

 2 .  Specify the Number of Sets you want to supply of each color: 
 

 ·              If you defined a default assortment for this style and distribution type, the quantities defined for this set will appear automatically. Revise them if necessary. 
 

 ·              If there is no default assortment, specify the desired quantities for each size. 
 

 Note s : 
 

 ·              You can select Copy Distribution from the list of Direct Activations to copy the distribution values from one color to all other colors in the assortment. 
 

 ·              If you enter a quantity for a color/size combination for which no catalogue number has been created, you will receive an error message. 
 

 3 .  Use the parallel Remarks sub-level form to record any remarks pertaining to this assortment.
 Note: These remarks can appear on the order printout, depending on the selected print format. 
 

 4 .  Return to the List of Styles form and move to the second line. Repeat the above process for every line in the form. 
 
## Note:

 

When the order is assigned a status that is flagged for Matrix Thinning, all rows in the Assortment form with quantities of 0 are automatically removed from the matrix assortment (for all sizes).
