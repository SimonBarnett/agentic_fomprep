# Monitoring Order Progress

 

A series of reports allows you to monitor inventory levels of the items you are supplying, as well as up-to-date balances of both your distribution plan (i.e., the unified sales order) and any purchase orders you generated. 
 
## To view total quantities of the parts you are supplying, compared to available inventory:

 

 ·        Select Status of Inventory for Distrib. from the list of Direct Activations of the Sales Orders form. 
 Notes: 
 

 ·              If you leave the Stores Only option blank, the report also takes into account the items that were ordered for your reserve stock, which can now be used to make up any shortfalls. 
 

 ·              If you select the Show Shortages Only option, the report only displays items with an inventory shortfall. 
 
## To view up-to-date order balances for the items you are supplying:

 

 ·        Select Order Balance per Style or Order Balance per Style/Customer from the list of Direct Activations of the Sales Orders form.
 Note: The same reports can be run from the Order Reports (Fashion) menu. 
 
## To view up-to-date order balances for the items you are purchasing:

 

 ·        Select Purchase Order Balance per Style from the list of Direct Activations of the Purchase Orders form.
 Note: The same report can be run from the Purchase Order Reports menu.
