# Converting Inventory from One Style to Another

 

You may find it necessary at times to reclassify a line of fashion items under a different style; for example, if you want to extend the run of a popular item into the next year's catalogue (and the year appears in the style number), or downgrade an unpopular item to the discount category. Priority 's inventory conversion feature allows you to assign new styles and catalogue numbers to existing fashion items, while preserving their inventory data. 
 

Furthermore, you can even convert an entire class of items, each with its own catalogue number, into a single catalogue item. This is particularly useful when you are downgrading a line of items to the discount rack, where everything costs the same, regardless of style or size. 
 
## Before you begin

 

 ·        Define a new style in the Part Catalogue , assign it a size chart and colors and use it to create new catalogue numbers for all the items that you want to convert.
 Notes: 
 

 ·              If you try to convert items to a style for which no catalogue numbers have been defined, you will receive an error report when the conversion program is finished running. 
 

 ·              Click to define new styles and their catalogue parts.
