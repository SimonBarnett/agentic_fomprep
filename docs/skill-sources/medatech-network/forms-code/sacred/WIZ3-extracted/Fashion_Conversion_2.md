# To convert from one style to another:

 

 ·        Run the Convert Inventory for Style program, providing the following input data: 
 

 ·              The Warehouse (and Bin , if any) in which the inventory to be converted is stored. 
 

 ·              The Original Style from which you are converting. 
 

 ·              The Color and Size of the items to be converted, in the event that you want to limit the conversion to a specific sub-category of the style. 
 

 ·              The Converted Style that you want to assign to the inventory. 
 

 ·              If you want to convert all the catalogue parts linked to a given style to a single catalogue number (i.e., the Converted Style itself), flag the Remove Size/Color column. 
 
## Notes:

 

 ·        The status of the inventory remains the same after conversion; however, links to work orders or operations are not preserved. 
 

 ·        Click to return to the Fashion Styles menu.
