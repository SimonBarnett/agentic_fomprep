# Maintaining Fashion Styles

 

Fashion styles are essentially base products and behave as such. Consequently, you can use the Part Spec Work Area to generate individual catalogue parts from their respective styles, and use base product features to maintain fashion price lists. 
 
## What do you want to do?

 

 Set up colors and sizes 
 

 Define a new style 
 

 Create catalogue parts in a given style 
 

 Assign international bar codes (based on a GTIN series) to parts 
 

 Convert fashion inventory from one style to another 
 

 Maintain prices for fashion merchandise
