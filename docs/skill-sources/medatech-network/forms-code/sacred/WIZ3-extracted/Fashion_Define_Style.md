# Defining a New Style

 

Fashion assortments work in the same manner as base products and their linked parts. You begin by defining a fashion style, whose attributes will all be copied to each fashion item derived from it. 
 
## To define a new style:

 

 1 .  Enter the Part Catalogue form. 
 

 2 .  Specify a Part Number and Description (e.g., Summer Skirts). Take into account that the part number will become an element of the part numbers of the new items. 
 

 3 .  In the Details tab, assign the Size Chart that you defined for this style. 
 

 4 .  Assign a Part Family and Preferred Vendor , if desired.
 Tip: You can change these values later, and the changes will take effect on all parts linked to the style. 
 

 5 .  Click the Additional Details tab. Revise the style's Type , Unit , and Factory Unit , if necessary. If you are creating new parts for future rather than current use, flag the Not in Use column.
 Note: If the style is not an actual part that can be included in inventory transactions, make sure the IStyleTrans constant (in the Logistic Constants form) is set to 1 . This will prevent you from defining the part for inventory control.
