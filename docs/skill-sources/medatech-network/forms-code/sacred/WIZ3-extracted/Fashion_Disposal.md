# Disposing of Fashion Items

 

 Priority provides a special program that automatically itemizes an inventory disposal document with the entire balance of a given fashion style with a given status in a designated warehouse. 
 
## To record a disposal document automatically:

 

 1 .  Run the Open Disposal Document for Style program, specifying the style and status that you want to dispose of, as well as the warehouse from which to dispose of it. 
 

 2 .  Enter the Inventory Disposal form and retrieve the new inventory disposal document. 
 Tip: Use today's date. 
 

 3 .  Enter the List of Styles sub-level form and its own sub-level Assortment to view and revise the quantities of disposed items. 
 Note: A separate line is opened in the List of Styles form for each operation in which the current style is stored in inventory. 
 

 4 .  Continue processing the document in the usual manner. 
 
## Notes:

 

 ·        You can also open an inventory disposal document manually and itemize it using the assortment matrix. 
 

 ·        When the disposal document is assigned a status that is flagged for Matrix Thinning, all rows in the Assortment sub-level of the List of Styles form with quantities of 0 are automatically removed from the matrix assortment (for all sizes).
