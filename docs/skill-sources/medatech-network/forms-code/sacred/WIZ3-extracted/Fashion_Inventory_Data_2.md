# To view general inventory data in retail warehouses:

 

 ·        Run the Available Assortments per Style report to view inventory levels of designated styles, in an assortment matrix.
 Tip: This report can also be run by Direct Activation from the Part Catalogue form. 
 

 ·        Run the Avail Assortmts per Style/Warehs report to view inventory levels of designated styles, sorted by warehouse (i.e., using a separate assortment matrix per warehouse).
 Tip: This report can also be run by Direct Activation from the Part Catalogue form. 
 

 ·        Run the Available Assortments as of Date report to view inventory levels of designated styles as of a given date, in an assortment matrix. 
 

 ·        Run the Current Inv. by Part/Warehouse report to view inventory levels of designated styles and/or items in designated warehouses. 
 

 ·        Run the Transactions w/Sales Warehouses report to view total quantities (per style or per part) of goods that were either shipped to, returned from or sold from selected sales warehouses (i.e., factory outlets and franchises). 
 

 ·        Run the Trans w/Sales Warehs-Daily Total report to view daily totals (per style, per part or overall) of goods that were either shipped to, returned from or sold from selected sales warehouses (i.e., factory outlets and franchises) within a designated period. 
 
## To view inventory transactions per style in selected warehouses:

 

 ·        Run the Inv Journal by Warhs & Base Prod report.
 Note: This report displays data from all warehouse types, during a given time period. 
 
## To view summaries of inventory transactions per style or part:

 

 ·        Run the Transaction Summ. per Warehouse report.
 Note: This report displays both daily and monthly summaries of all transactions in selected warehouses of Type D and W , during a given time period.
