# To view inventory data for past dates:

 

 1 .  Run the Load Inventory Data as of Date program and specify the date for which you are loading inventory data. 
 Tip: Run this program more than once for different dates to compare data over time. 
 

 2 .  Enter the Inventory Data as of Date form or run the Inventory as of Date per Style report to view inventory data for selected warehouses.
 Note: Run the Inventory as of Date - Detailed report to see additional data. 
 
## To find parts and styles in the work area for which standard and/or actual costs are not defined:

 

 ·        Run the Parts in Work Area With No Cost report. 
 
## Notes:

 

 ·        Run the Clear Inventory Data for Date program to remove inventory data for a given date. 
 

 ·        Click to return to the Fashion Inventory menu.
