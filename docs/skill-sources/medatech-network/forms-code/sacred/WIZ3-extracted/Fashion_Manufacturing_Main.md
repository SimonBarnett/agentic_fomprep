Fashion - Manufacturing Fashion Goods

 Manufacturing Fashion Goods
 

The production process works somewhat differently in the fashion industry, as both the work order assortment matrix and the work order kit list are finalized retroactively, on the basis of production reports. Priority also provides certain features that automate the process of subcontracting. 
 
## What do you want to do?

 

 Open a work order for an assortment of goods 
 

 Report production for fashion goods 
 

 Update the work order assortment and kit list on the basis of production reports 
 

 Send work in progress to a subcontractor
