# Creating Catalogue Parts in a Given Style

 

The Part Specs Work Area helps you to create specific catalogue parts on the basis of each style. When you load a style (base product) into the work area, the load program creates draft parts from all of the possible combinations of colors and sizes that have been defined for that style. You can then choose which combinations to actually record in the system as parts. 
 

In fact, the work area does not take the color and size values directly from the Part Catalogue form where they were defined for that style, but from an intermediate form called Definition of Part Specs . This form organizes your style attributes into specs , each with its own list of possible values. It allows you to assign a special code to each spec value that will appear as an element of the new part numbers , define separators to connect these elements, and determine the order of elements in the part number.
