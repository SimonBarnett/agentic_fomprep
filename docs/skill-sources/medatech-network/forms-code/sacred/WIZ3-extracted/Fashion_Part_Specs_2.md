Fashion - Creating Catalogue Parts for a Style.2 
 
 
- 
 
 
 

When working with the Fashion module, the specs appearing in the Definition of Part Specs form behave in a particular way: 
 

 ·        Spec 1: This spec represents the base style of the fashion item. It is taken automatically from the Description defined for that style in the Part Catalogue form, though it may be changed in the Permitted Spec Values sub-level form, in the Specification Value column. The part number element of Spec 1 is taken automatically from the style's Part Number , but may be changed in the Code in New Part No. column. 
 

 ·        Spec 2: This spec represents the color of the fashion item. The values of this spec are taken automatically from the Colors (Fashion) form where they are defined. The part number element of Spec 2 is taken automatically from the Color Code defined for each color in that form. 
 Note: You may add a color to the Permitted Spec Values sub-level form under Spec 2 for a temporary purpose; however, this color will not remain permanently in the list unless it is recorded in the Colors (Fashion) form as well. 
 

 ·        Spec 3: This spec represents the size of the fashion item. These values must be recorded manually in the Permitted Spec Values sub-level form under Spec 3, even though you have already listed them in the Size Charts form. You also need to define the part number element for each size value in the Code in New Part No. column. 
 

 ·        Spe c s 4-20 : Each of these specs may be flagged in the Update by Base Prod column (in the Definition of Part Specs form), such that any change to that spec for the style in question automatically takes effect for all parts linked to that style.
