# Checking and Revising Part Specification Definitions

 
## Note: 

 

Once you have been working with the Fashion module for a while, have settled on a part numbering system that suits your needs (i.e., spec codes or separators) and have already defined a number of size codes, you can begin loading the work area directly. Click to do so . 
 
## To fine-tune the part specs:

 

 1 .  Enter the Definition of Part Specs form, and enter the Permitted Spec Values sub-level form under Spec 1. 
 

 2 .  Move to the desired base style in the Specification Value column; the style's part number appears in the Code in New Part No. column. Revise either value if you want the new product number and/or description to differ from that of their base product.
