# To view current prices per fashion style: 

 

 1 .  Enter the Price Lists form and move to the desired price list. 
 

 2 .  Flag the Base Product Only column. 
 

 3 .  Enter the Part Prices sub-level form. All parts that are linked to a fashion style (or other base product) and share the same price are represented by a single line. 
 

 Notes: 
 

 ·        For more information about creating and maintaining price lists, run the Prices and Discounts Wizard or the Vendor Parts and Prices Wizard . 
 

 ·        Click to return to the Fashion Styles menu.
