# Reporting Production for Assortments

 

The Reporting Production form is equipped with its own List of Styles sub-level form, to enable you to itemize production details per assortment, and save you the trouble of specifying the work orders for each particular fashion item individually. In this setting, the List of Styles form also contains columns for work order number and operation. 
 
## To report production per assortment:

 

 1 .  Enter the Reporting Production form and open a new production report.
 Tip: For details, run the Production Report Wizard . 
 

 2 .  Instead of itemizing the report in the Production Details sub-level form, enter the List of Styles sub-level form. 
 

 3 .  In the Base Product No. column, specify the first fashion style being produced.
 Note: Unless it is otherwise filled in, the Details column in the upper-level form will display the first style recorded in this form. 
 

 4 .  Specify the Work Order opened for the current style, and the Operation you are reporting. 
 

 5 .  If you only want to report production of this style in one color, specify its Color Code .
