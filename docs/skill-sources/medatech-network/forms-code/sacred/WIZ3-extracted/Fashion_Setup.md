# Setting Up Fashion Inventory

 

In order to take full advantage of Priority 's automated fashion features, you need to define dummy customers for factory outlets and link them to warehouses, define default assortments for inventory transactions and set up a number of parameters and constants that affect order itemization and sales reports. 
 
## What do you want to do?

 

 Set up dummy customers 
 

 Set up warehouses 
 

 Set up default assortments 
 

 Set up numbers and bar codes for sets 
 

 Set up how order items are matched to shipped/received items 
 

 Set up sales reports for franchises
