# Setting Up Colors and Sizes

 

Use the Colors (Fashion) form to compile a list of all of the colors you will use to create fashion styles. These values will appear in the Choose list of the Part Colors (Fashion) sub-level of the Part Catalogue form, where you assign the appropriate colors to each style. 
 

The Size Charts form allows you to create size charts appropriate to a particular fashion style or category of styles (i.e., one chart of shoe sizes can be used for any number of shoe styles). 
 
## To define the general color chart:

 

 1 .  Enter the Colors (Fashion) form. 
 

 2 .  For each color, specify a Color Code and Color Name . The codes you record will become elements of the part numbers of the final items, so be concise (e.g., BR or 01 rather than Brown). 
 
## To define size charts:

 

 1 .  Enter the Size Charts form. 
 

 2 .  Specify a Size Chart Code and Size Chart Name . Be as general as possible, so you can use the chart again for styles in the same category that may be defined in the future. 
 

 3 .  Fill in all possible sizes in the available columns, using whatever designations are needed. Later, you will have the opportunity to define the codes that will represent each size in the new part numbers. 
 
## Tip:

 

Click to define a fixed display size for size charts.
