# Defining a Fixed Display for Size Charts

 

The SMinSIzesNum constant determines the minimum width of size charts in all printed assortments, regardless of the actual number of sizes in that assortment. For example, if you set the value of the constant to 12, a printout for a part that comes in the sizes "S", "M", "L" and "XL" will display a size chart that is 12 columns wide; one column for each of the defined sizes, and 8 empty columns. 
 
## To set the constant:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SMinSIzesNum constant and change the constant's value to reflect the number of columns you wish to display in printed assortments.
