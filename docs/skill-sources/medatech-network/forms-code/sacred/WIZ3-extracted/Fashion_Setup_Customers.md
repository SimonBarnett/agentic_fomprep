# Setting Up Dummy Customers for Unified Orders

 

In order to create a unified sales order for a chain of stores, you need to open a record for a virtual customer for whom the order will be made out. If you are supplying your own factory outlets you need to create dummy customers for each separate outlet. 
 
## To record a dummy customer:

 

 1 .  Enter the Customers form, and open a new customer record.
 Tip: Choose a customer name that identifies the store to which it is linked (e.g., North Mall, South Mall). 
 

 2 .  Select Convert Potential Cust to Cust from the list of Direct Activations .
