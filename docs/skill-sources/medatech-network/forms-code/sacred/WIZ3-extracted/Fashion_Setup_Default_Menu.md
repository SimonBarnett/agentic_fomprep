# Setting Up Default Assortments

 

Different types of stores are generally consistent in the distribution of items that they sell. For example, large department stores tend to display a wide range of sizes and colors in a predictable curve (i.e., larger quantities for the middle sizes, smaller at the extremes), whereas small upscale boutiques will focus on a narrow selection of sizes and colors, each according to their clientele. By assigning a distribution type to each store that you supply, and a product type to each style, you can create default assortment templates that closely approximate what the matrix will look like for any given transaction. This limits your work to minor revisions, instead of filling in each matrix manually.
