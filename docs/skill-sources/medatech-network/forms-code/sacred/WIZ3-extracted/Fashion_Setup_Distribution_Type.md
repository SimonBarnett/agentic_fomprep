# Assigning Distribution Types

 

Each distribution type represents a category of stores (e.g., “department store”, “sportswear store”, “boutique”) that usually stock the same types of items in the same proportions. For example, a sportswear store is likely to carry sweatpants in a wider range of colors than a department store. 
 

Each customer that represents a retail store (i.e., franchise or factory outlet) should be assigned a distribution type. If you supply individual customers (e.g., wholesalers) and wish to include them in automatic distribution planning, you should assign them a distribution type as well. You also need to define a special distribution type for your own reserve stock. 
 
## Note: 

 

If you are distributing goods to your own factory outlets, make sure you have created a dummy customer for each store, and linked it to a store warehouse. 
 
## To define a distribution type:

 

 1 .  Enter the Distribution Types form. 
 

 2 .  Record a Distribution Type Code and Distribution Type Description for each desired type. 
 

 3 .  Define a special distribution type called “RESERVE” that won't be assigned to any store. 
 

 4 .  Flag the Store column for every distribution type except “RESERVE”. 
 
## To assign a distribution type to a customer:

 

 1 .  Enter the Customers form and retrieve the desired customers. 
 

 2 .  For each customer, specify the appropriate Distribution Type in the Shipments tab.
