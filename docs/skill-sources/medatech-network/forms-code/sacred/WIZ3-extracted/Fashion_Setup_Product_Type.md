# Assigning Product Types

 

Each product type represents a category of garments (e.g., “shoes”, “sweaters”, ”swimsuits”) that are usually stocked in the same proportions. If the size distribution of high-heeled shoes tends to differ from that of tennis shoes, then “shoes” is probably too wide a category, and you need to create different product types for each sub-category. 
 

Each individual fashion style should be assigned a product type. 
 
## To define a product type:

 

 1 .  Enter the Product Types form. 
 

 2 .  Record a Product Type Code and Product Type Description for each desired type. 
 

 3 .  Specify the Size Chart associated with the product type. 
 
## To assign a product type to a fashion style:

 

 1 .  Enter the Part Catalogue form and retrieve the desired style.
 Tip: Use the Base Product flag in the Additional Details tab to retrieve all styles (as well as any other base products). 
 

 2 .  In the Details tab, specify the desired Product Type .
 Note : If a size chart has been defined for this style, make sure it does not differ from that defined for the product type.
