# Setting Up Set Numbers and Bar Codes

 

Each horizontal row, or set , in a style assortment represents the defined range of sizes for a single color in that style. You can define separate part numbers or bar codes for specific sets within an assortment, which can be used to itemize your transaction documents more efficiently. 
 
## To define a set number or bar code:

 

 1 .  Enter the Part Catalogue form and retrieve the desired style. 
 

 2 .  Enter the Part Colors (Fashion) sub-level form. 
 

 3 . For each desired set, specify the Color Code . The Color Name appears automatically, and a Set Number and Set Bar Code are assigned by the system.
