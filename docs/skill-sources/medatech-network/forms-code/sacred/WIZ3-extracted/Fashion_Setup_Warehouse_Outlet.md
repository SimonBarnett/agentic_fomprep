# To open an outlet warehouse:

 

 1 .  Enter the Warehouses form, and open a new type D warehouse in the usual way.
 Tip: For details, run the Open a Warehouse Wizard . 
 

 2 .  Leave the check marks in the Inventory Valued and Transaction Costing columns, and flag the For Consignment and Sales Warehouse columns (the former is used to define an external warehouse; the latter is used to indicate that goods in the warehouse are available for sale). 
 

 3 .  To set the position of the new warehouse in tabular reports (e.g., pick lists), specify a value in the Rep. Display Order column. The warehouse with the lowest number appears first in the X-axis of the report. 
 

 4 .  Click the Consignment tab and link the warehouse to the Customer Number of the dummy customer you created for this store.
