# Supplying a Single Customer

 

Supplying fashion goods to a single large customer, such as a wholesaler, is similar to supplying any other goods, except that the inventory transaction documents are itemized via assortment matrices. These matrices will be created automatically if you have defined default assortments (i.e., assigned product types to your styles and a distribution type to this customer). You can list the styles in the order manually, or copy all styles (and their assortment matrices) from an existing sales order. 
 

For each style in the order, you can choose to display the entire default assortment, a particular set (i.e., the range of sizes for a single color) within that assortment, or a single part (a single size in a single color). 
 

Alternately, you can include single customers in a unified sales order, together with chain stores. Click to do so. 
 
## To open a sales order for a single customer of fashion goods:

 

 1 .  Enter the Sales Orders form, and record a sales order in the usual way. 
 

 2 .  Enter the List of Styles sub-level form to list styles in the order.
 Tip: Alternatively, you can select Copy Assortmt from Another Order from the list of Direct Activations to copy the list of styles and assortment matrices from an existing sales order. When the program finishes running, enter the List of Styles sub-level form and its sub-level, Assortment , to check the styles and assortments copied into the order and make any necessary revisions. It is recommended that you check all definitions outlined in the following steps. 
 

 3 .  If the customer has been assigned a distribution type, specify it in the Distribution Type column. 
 

 4 .  In the Manual Quantity column, specify the number of sets to assign to each color in the assortment. This value appears in the Number of Sets column for each color in the Assortment sub-level form. If you leave this column blank, the value 1 is assigned automatically.
 Note: If you are defining an assortment for an individual part, this value does not appear in the Number of Sets column, but within the assortment matrix, for that part's size and color. 
 

 5 .  In the BarCode/Manual column, do one of the following: 
 

 ·              To use the full default assortment for the designated style, specify the part number or bar code of the style. 
 

 ·              To use the default assortment for a single set, specify the set number or bar code (as defined in the Part Colors (Fashion) form). 
 

 ·              To use the default value for a specific part in the assortment, specify its part number or bar code. In this case, the assortment will display the set to which that part belongs.
