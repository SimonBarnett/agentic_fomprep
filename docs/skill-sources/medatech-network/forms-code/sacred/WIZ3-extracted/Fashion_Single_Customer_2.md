## Notes:

 

 ·        Select Open Purchase Ord from Sales Ord from the list of Direct Activations to generate a purchase order that displays the assortment matrix defined in the sales order. 
 

 ·        Use the Sales Orders for Order sub-level of the Purchase Orders form to open a single purchase order from multiple sales orders, which automatically displays a single assortment matrix composed of all the ordered goods. For details, run the Purchase Order Wizard . 
 

 ·        When recording a sales invoice for this order, select Copy Assortment from Order from the list of Direct Activations of the Sales Invoices form to copy the assortment from the order to the invoice. 
 

 ·        If the IMatrixOnly constant is set to 1 (in the Logistic Constants form), order items generated by the assortment may not be revised in the order lines themselves. Rather, any change must be made in the List of Styles form and its sub-level, Assortment .
