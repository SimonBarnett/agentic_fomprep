# Sending Work In Progress to a Subcontractor

 

If you want to subcontract operations within a work order, Priority allows you to automatically generate a shipment document and purchase order that display the assortment matrix defined in the work order. 
 
## To create a shipping document and purchase order for the subcontractor:

 

 1 .  Enter the Work Orders form and retrieve the work order in question. 
 

 2 .  Enter the Routing for the Work Order sub-level form and move to the last operation reported for the goods before being sent to the subcontractor. 
 

 3 .  Select Open Shipment to Subcontractor from the list of Direct Activations and specify the subcontractor number. 
 

 4 .  Select Shipmt to Subcontr/Issue of Kit from the list of Direct Activations and retrieve the new shipping document (e.g., by today's date). Finish filling it in.
 Note: The List of Styles sub-level contains Operation and Work Order columns, the former to record which operation each style is in when sent to the subcontractor, and the latter to record which work order is to be charged for the subcontracting costs. For more information about recording subcontractor shipping documents, run the Working w/Subcontractors Wizard . 
 

 5 .  Select Open PO Based on Assortment from the list of Direct Activations of the Shipmt to Subcontr/Issue of Kit form and specify the last operation in the work order routing to be performed by the subcontractor. 
 

 6 .  Select Purchase Orders from the list of Direct Activations and retrieve the new purchase order (e.g., by today's date). Finish filling it in.
 Note: For more information about recording purchase orders, run the Purchase Order Wizard . 
 

 7 .  When you open a Goods Receiving Voucher for the finished goods, specify the number of the original shipping document in the Shipmt to Subcontr column, in the References tab of the GRV. 
 
## Notes:

 

 ·        When a shipping document, purchase order or GRV are assigned a status that is flagged for Matrix Thinning, all rows in the matrix assortment with quantities of 0 are automatically removed (for all sizes). 
 

 ·        Click to return to the Manufacturing menu .
