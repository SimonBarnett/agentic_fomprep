# Updating the Work Order Assortment Matrix and Kit List

 

The production routings of fashion parts usually contain a key operation (e.g., cutting material) that may result in widely variable quantities of completed parts. Example. In anticipation of this actuality, fashion manufacturers usually refrain from officially issuing parts to the kit list until the production process is over and the actual number of completed parts is fully known. Priority takes advantage of this methodology by allowing you to update both the work order assortment and the kit list according to the actual number of reported parts. 
 
## To update the assortment and kit list:

 

 ·        Select Replace Work Order Assortment from the list of Direct Activations and specify the reported operation that resulted in new assortment quantities.
 Note: If any materials have already been issued to the kit, the work order assortment will be updated but the kit list will not. 
 
## Notes:

 

 ·        Click to send work in progress to a subcontractor using the work order assortment matrix. 
 

 ·        The regular work order printout displays the assortment matrix – simply select Print Work Order from the list of Direct Activations . 
 

 ·        Click to return to the Manufacturing menu.
