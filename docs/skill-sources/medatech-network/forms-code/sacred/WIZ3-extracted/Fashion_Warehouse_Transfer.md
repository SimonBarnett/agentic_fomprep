# Transferring Fashion Inventory Between Warehouses

 

 Priority provides a special program that automatically itemizes a warehouse transfer document, moving the entire balance of a fashion style with a given status from one warehouse to another warehouse and/or status. 
 
## To record a warehouse transfer automatically:

 

 ·        Run the Transfer Inventory for Style program, specifying the style you want to transfer, as well as the warehouses and statuses between which to transfer it.  
 
## Notes:

 

 ·        Enter the Warehouse Transfer form to retrieve the new warehouse transfer document. 
 

 ·        Run the Warehouse Transfers per Style report to view data regarding warehouse transfers, displayed per style. 
 

 ·        You can also open a warehouse document manually and itemize it using the assortment matrix. Select Cpy Assortmt from Another Transf from the list of Direct Activations to copy the assortment matrix defined in an existing warehouse document into the new document. 
 

 ·        When the transfer document is assigned a status that is flagged for Matrix Thinning, all rows in the Assortment sub-level of the List of Styles form with quantities of 0 are automatically removed from the matrix assortment (for all sizes).
