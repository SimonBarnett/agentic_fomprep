# Working With Fashion Inventory

 

The List of Styles form and its Assortment sub-level appear in every inventory-related document as an alternative to the standard itemization form. This allows you to perform the full range of inventory transactions using assortment matrices, from orders to invoices. A number of Direct Activations allow you to copy assortments from one document to another, or delete all styles and assortments in a given document (when the final sums are found to be inaccurate). Certain document statuses also enable you to automatically adjust the document's matrix assortment, removing all rows with quantities of 0 throughout the assortment. Priority also provides a variety of forms and reports that use matrices to display sales and inventory data in matrix format.
