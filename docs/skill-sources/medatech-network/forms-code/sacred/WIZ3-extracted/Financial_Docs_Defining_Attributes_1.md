# Defining Financial Document Attributes

 

 1 .  Enter the Financial Documents form. All the financial documents in the system are displayed, along with their initial status .
 Tip : It is recommended that you move to Full-Record Display Mode . 
 

 2 .   D ual-currency users: If you are working in a language other than English and want your document codes and descriptions to appear in English, record them in the Document Code-Lang 2 and Document Type-Lang 2 columns, respectively. 
 

 3 .  For each financial document, you can define the following attributes: 
 
 
 
 

 Column 
 
 

 Attribute 
 
 
 

Post Journ. Entries? 
 
 

Whether to post journal entries automatically to the ledger when the document is finalized. 
 
 
 

Round Price? 
 
 

Whether to round the total price in the document. 
 
 
 

Text from Order/Shp? 
 
 

Whether to copy text from the shipping/receiving document to the invoice.
