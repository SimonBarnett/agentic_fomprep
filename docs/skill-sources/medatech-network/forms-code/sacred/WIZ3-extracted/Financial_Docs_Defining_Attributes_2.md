 4 .  For each financial document, you can define the following checks and limits: 
 
 
 
 

 Column 
 
 

 Attribute 
 
 

 Column 
 
 

 Attribute 
 
 
 

Chk if Total Price = 0 
 
 

Whether to allow users to finalize a document with a total amount of 0. 
 
 

Postdate Limit &
Pre-date Limit 
 
 

How many days back and forward to allow documents to be post- and pre-dated. 
 
 
 

Chk if Item Price = 0 
 
 

Whether to allow users to finalize a document with a line item amount of 0. 
 
 

Check Order of Dates 
 
 

Whether to allow invoices to be prepared out of date order. 
 
 
 

Check for Neg. Sums? 
 
 

Whether to allow users to finalize a document whose total amount is negative. 
 
 

Check Order of Dates 
 
 

Whether to allow invoices to be prepared out of date order. 
 
 
 

Finalize Immediately 
 
 

Whether to allow documents to remain pending. 
 
 

Canc. on Orig. Date 
 
 

How to date the cancellation invoice and reversing journal entry when canceling a purchase invoice with the Today's Date option. 
 
 
 

Negative Sum Counter 
 
 

Whether documents whose total amount is negative will have a separate numeration sequence. 
 
 

Disallow Single User 
 
 

Whether to allow users to finalize a document that they opened (and whose status has never been updated by another user). 
 
 
 

Auth. Can't Finalize 
 
 

Whether to allow users to finalize a document if they were the last one to update its status or assigned user. 
 
 

Entry for Zero Invs? 
 
 

Whether to create a journal entry for invoices/credit memos that have a zero total.
