# Creating a Numeration Template

 

At the beginning of every year (and when you first start to work with Priority ), you need to create new numeration templates. Numeration templates consist of a prefix and sequential number. 
 

You can format the numeration template for each type of document individually, including determining the prefix (with or without a branch identifier), the starting number and the total number of characters. Example. 
 
## To create new numeration templates:

 

 ·        Run the Open Numeration Templates program. 
 
## Notes:

 

 ·        If you work with branches, you can define a different template per branch. For more information, see the Branches Wizard . 
 

 ·        You can run the Open Numeration Templates program in the middle of the year, if needed. It will only affect document types that have not yet been set up for this year (or branch).
