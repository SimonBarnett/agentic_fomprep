# Recording Set Text

 

All types of financial documents have a sub-level form for recording remarks and other text regarding the transaction. This text appears on the printout of the document. 
 

For each type of financial document, you can record set text, which will be automatically copied to the Remarks sub-level form (and may then be revised or added to for individual documents). 
 

For each type of financial document, you can record set text to be used with a particular branch and entry code. Set text recorded this way will appear on all financial documents assigned to that branch and entry code and will override the default set text for that document type. 
 
## To record set text for a document type:

 

 ·        From the Financial Documents form, enter the Set Text for Document sub-level form and type the desired text. 
 
## To record set text for a document type in English when working in another language (dual-currency users only):

 

 ·        From the Financial Documents form, enter the Set Text for Document - Lang2 sub-level form and type the desired text. This text will appear in documents created for those customers and vendors that have been flagged to receive English printouts (in the Printouts in Lang 2 column of the Customers and Vendors forms, respectively). 
 
## To record set text for a document type per branch and entry code:

 

 ·          From the Financial Documents form, enter the Journal Entry Codes per Branch sub-level form and move to the line for the branch and entry code in question. In the Set Text for Branch sub-level form, record the desired text. 
 
## To record set text in English for a document type per branch and entry code, when working in another language (dual-currency users only):

 

 ·        From the Financial Documents form, enter the Journal Entry Codes per Branch sub-level form and move to the line for the branch and entry code in question. In the Set Text for Branch - Lang2 sub-level form, type the desired text. This text will appear in documents created for those customers and vendors that have been flagged to receive English printouts (in the Printouts in Lang 2 column of the Customers and Vendors forms, respectively). 
 
## Note:

 

When opening an invoice on the basis of another document (e.g., a sales order), the Remarks form will include the set text for that document, as well as the set text recorded for the invoice in this form.
