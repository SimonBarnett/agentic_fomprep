# Consolidated Financial Statements

 

If you plan to prepare consolidated financial statements, you need to flag which companies to include. 
 
## To flag participating companies:

 

 1 .  From the main File menu, select Define Multiple Companies . 
 

 2 .  Flag each participating company. 
 
## Notes:

 

 ·        This selection, which applies to each user individually, remains in effect for every multi-company form or report in the system, until the user changes it. 
 

 ·        If you do not select any companies in the Define Multiple Companies dialog box, consolidated financial statements will include only those companies flagged as Multi-company in the Companies form.
