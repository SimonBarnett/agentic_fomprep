# Balance Sheets and P&L Reports

 

The balance sheet and P&L report are hierarchical in structure: 
 

 ·        Each statement is divided into sections . 
 

 ·        Each section contains one or more headings . 
 

 ·        Under each heading appear several items . 
 

 Example. 
 
## Structure of Financial Statements

 

The standard structure of financial statement sections is predefined by Priority : 
 

 ·        Balance Sheet: Assets, Liabilities, Equity 
 

 ·        P&L Report: Income, Cost of Goods Sold, Expenses. 
 
## You use the same form to define or view headings for both types of statements. 

 

A second form is used to define or view items for both types of statements for GL accounts. 
 

Most A/R and A/P accounts use the predefined “Accounts Receivable” and “Accounts Payable” balance sheet items. Customers who are vendors use the “Receivables/Payables” balance sheet item. You can also define additional balance sheet items for A/R and A/P accounts.
