# Headings

 

Each statement heading refers to one of its sections. You can modify existing headings and add new ones to the balance sheet and P&L report, if desired. Make sure that the new headings are properly assigned to their respective reports (for instance, you would assign the new heading Other Expenses to the P&L report, under the main heading of Expenses ). 
 
## To add or modify report headings:

 

 1 .  Enter the Bal. Sheet/P&L Report Headings form. This form displays all the headings recorded for balance sheets and P&L reports. 
 

 2 .  In the Heading column, add a new heading, or change the name of a heading. This name will appear in all financial statements that you produce. 
 

 3 .  In the Section column, choose the section to which you are assigning this heading, or check that the heading is assigned correctly. 
 

 4 .  In the Order column, set the sequence in which the headings will appear in each section of the statement. The heading with the smallest number appears first. 
 

 5 .  Enter the Items per Heading sub-level form to view the items and their order, per heading. 
 

 6 .  You can use the Order column to change the order of items in each section, but you cannot define new ones.
