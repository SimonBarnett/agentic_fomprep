# Report Items

 

If the predefined items do not meet your needs, you can do any of the following: 
 

 ·        Add new items 
 

 ·        Change the properties of existing items 
 

 ·        Change the order of items 
 
## To add new items or modify existing ones:

 

 1 .  Enter the appropriate form (according to the type of account involved): 
 

 ·      Bal. Sheet/P&L Items-GL Accounts 
 

 ·      Bal. Sheet Items - A/R Account 
 

 ·      Bal. Sheet Items - A/P Account 
 

 2 .  In the Item column, add a new item or change the name of an existing one. This item will appear in all financial statements of this type that you produce. 
 

 3 .  In the Order column, set the sequence in which the items will appear in each section of the statement. The heading with the smallest number appears first.
 Tip: You can also define the order of items in the Items per Heading form, sub-level of Bal. Sheet/P&L Report Headings . 
 

 4 .  In the Heading column, choose the heading to which you are assigning this item, or check that the item is assigned correctly. 
 

 5 .  For any balance sheet item, you can designate a contra item . 
 

 6 . Dual-currency users: If you are working in a language other than English, you can record an English heading for a report item in the Item (Lang. 2) column, which will appear when financial statements are run in English.
 Note: Financial statements that are run or created in the Financial Statement Generator when English is the system interface only appear in English when English headings have been defined for each item. 
 
## Notes: 

 

 ·        Accounts are attached to report items when the accounts are opened, in the Chart of Accounts form. 
 

 ·        Click to check the results of your changes.
