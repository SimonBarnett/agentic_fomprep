# Trial Balance

 

The trial balance has a three-level hierarchy. Each element in the hierarchy has a code, as follows: 
 

 ·        Sections are determined by a single digit followed by two asterisks (e.g., 1** for Assets). 
 

 ·        The headings are identified by two digits followed by an asterisk, the first digit being the same as that for the corresponding section (e.g., 10* for Current Assets). 
 

 ·        The items in a given heading have a three-digit code, the first two digits corresponding to those in the heading (e.g., 101 for Cash on Hand, 102 for Petty Cash). Example.
