Set Up Financial Statements - Setting Up a Trial Balance 
 
 
- 
 
 
 
## To set up the trial balance:

 

 1 .  Enter the Trial Balance Items form. 
 

 2 .  Designate the sections, headings and items. 
 

 3 .  Enter the Accounts Incl in Trial Bal Item sub-level form to view the accounts attached to each item in the upper-level form. 
 
## Notes:

 

 ·        If you have run the Account Initialization or Account Initialization-Intl program (in the U.S. package or dual-currency package, respectively), the trial balance structure is created automatically. 
 

 ·        The items appear in the report in numerical order. 
 

 ·        Accounts are attached to report items when the accounts are opened, in the Chart of Accounts form.
