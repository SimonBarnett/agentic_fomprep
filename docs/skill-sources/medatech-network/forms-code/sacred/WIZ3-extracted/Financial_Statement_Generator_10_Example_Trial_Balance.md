# Example of Column Bar: Quarterly Trial Balance

 

This bar contains three columns: 
 

 ·              opening balances 
 

 ·              sums for the quarter 
 

 ·              closing balances 
 

In the Definition of Column Bars form, assign the bar the title: "Quarterly Trial Balance". In the Original Date column, specify the first day of the year (e.g., 01/01/12). 
 

Fill in the columns of the Columns in Bar sub-level form as follows: 
 

 ·              Column Number: 1 
 Title: Opening Balance
 Column Type: 1 
 

 Description: Period Start
 From Date: 01/01/12
 
 

 ·              Column Number: 2
 Title: 2 nd Qtr 2004
 Column Type: 2
 Description: Period Total 
 

 From Date : 01/01/12
 To Date : 31/03/12
 
 

 ·              Column Number: 3 
 Title: Closing Balance
 Column Type: 3
 Description: Period End 
 

 To Date : 31/03/12 
 
## Notes:

 

 ·        You can also indicate the relevant Full Company Name , Division , Subsidiary and/or account Group , if necessary. 
 

 ·        When running the Run Financial Statement program, leave the Report Date column blank to run the statement for the original column dates or specify a different Report Date to roll the column dates forward or backward, relative to the column bar’s Original Date (e.g., specify 30/06/12 to run this statement for the second quarter of 2012).
