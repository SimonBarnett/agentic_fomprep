# Example of Column Bar: Consolidated Statement

 
## Note:

 

This bar can be used for consolidated balance for the second quarter of 2012 as well as for P&L report for the first two quarters of 2012. 
 

This bar contains the following columns: 
 

 ·              2 nd quarter data for company A 
 

 ·              2 nd quarter data for company B 
 

 ·              Totals (A+B) 
 

In the Definition of Column Bars form, assign the bar the title: "Consolidated - 2 nd Qtr 2004". 
 

Fill in the columns of the Columns in Bar sub-level form as follows: 
 

 ·              Column Number: 1
 Title: Company A
 Column Type: 3
 Description: Period End 
 

 To Date : 30/06/12
 Full Company Name : Company A
 
 

 ·              Column Number: 2
 Title: Company B
 Column Type: 3
 Description : Period End
 To Date : 30/06/12
 Full Company Name: Company B 
 

  
 

 ·              Column Number: 3 
 Title: Total
 Column Type: 4 
 

 Description: Calculated
 Expression: #1 + #2 
 
## Notes:

 

 ·        All companies in a consolidated statement must share the same Priority application. When designating the full company name, use the exact name that appears in the list when you Select Company.
