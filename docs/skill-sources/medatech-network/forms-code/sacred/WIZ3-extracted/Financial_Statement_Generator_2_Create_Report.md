# Creating a Report

 

A financial statement is made up of two parts: report items and a column bar . 
 

Report items are generally created once for each type of statement, by running a designated program. You can customize both the line items themselves (their titles and order) and the accounts attached to them. 
 

In contrast, multiple column bars are defined to display data for a particular range of dates (e.g., the second quarter of 2013) or to display a comparison between two or more periods (e.g., between the first two quarters of the year). Each column in a given column bar can be defined to display sums for a designated period, subsidiary, company and/or division. You can also define columns that display data as a percentage or as a function of any of the other columns in the same column bar (e.g., Column B – Column A). 
 

To design your own financial statement, you need to: 
 

 ·        Create report items or use an existing customized report. 
 

 ·        Create the column bar or use an existing one. 
 

 ·        Run the statement to test it. 
 

You can also revise the graphic design of your customized financial statements.
