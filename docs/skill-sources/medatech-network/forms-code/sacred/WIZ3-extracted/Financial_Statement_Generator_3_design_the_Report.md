# Graphic Design

 

When designing your own financial statements, you can determine the style, size and color of fonts, as well as other design attributes. These definitions are global; that is, they affect all customized statements created by all users. 
 
## To view the default design settings and make any desired revisions:

 

 1 .  Enter the Financial Statement Design form. 
 

 2 .  For each level of the report (e.g., heading, sub-heading, total), check the assigned settings and revise as necessary.
 Tip: Press F6 twice from the Font for Description or the Font for Sums columns to access a form in which to define new fonts. 
 

 3 .  To quickly check the results of your changes, select Sample Statement from the list of Direct Activations , which displays a demo report reflecting most design definitions.
