# Setting Up Report Items in English

 

If you are working in the dual-currency package in a language other than English and want to produce financial statements in English, values must be defined in English for all balance sheet and P&L section headings and items. 
 
## Before you begin

 

 ·        Make sure English values have been defined for each record in the following forms: 
 

 ·              Bal. Sheet/P&L Report Headings 
 

 ·              Bal. Sheet/P&L Items-GL Accounts 
 

 ·              Bal. Sheet Items - A/P Account 
 

 ·              Bal. Sheet Items - A/R Account 
 

 ·              Trial Balance Items
