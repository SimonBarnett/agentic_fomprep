# Creating Report Items

 

Once you are satisfied with the setup of your financial statements, you are ready to create the report items. 
 
## To create report items:

 

 ·        Run the Create Customized Statement program. 
 
## Note for dual-currency users working in a language other than English:

 

To create report items in English, change the system language to British English (you will need to exit and re-enter Priority), and run the Create Customized Statement program.
