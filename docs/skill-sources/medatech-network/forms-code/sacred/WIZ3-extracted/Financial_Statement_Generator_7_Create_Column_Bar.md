# Creating a Column Bar

 

 1 .  Enter the Definition of Column Bars form and open the column bar. 
 

 2 .  Assign the bar an informative title. Important : If the column bar is suitable only for a particular type of statement, this should be clear from the title - e.g., "2 nd Qtr (P&L)." 
 

 3 .  If you want to define columns in this column bar using a rolling date, indicate the bar’s Original Date (e.g., 01/01/11). Subsequently, when running a financial statement based on this column bar, you will be able to indicate a Report Date that will be compared to this Original Date , and all dates defined in the column bar (in the Columns in Bar sub-level form) will be rolled forward or backward accordingly. For example, if the designated Report Date falls exactly 6 months after the Original Date , all dates defined in the column bar will be rolled forward by 6 months as well. 
 Note: If the difference between these two dates is in whole months (e.g., both fall at the end of a month), then all column dates will be offset in whole months. If the difference in dates is not in whole months (e.g., one falls at the beginning of the month, while the other falls in the middle of the month), then the offset will be calculated in months and days.
