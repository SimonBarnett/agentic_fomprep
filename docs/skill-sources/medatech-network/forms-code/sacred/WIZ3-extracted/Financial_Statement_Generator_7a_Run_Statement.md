# Running the Financial Statement

 

To check the report items and/or column bar you have created for errors, you can simply run the report. 
 
## To run the financial statement:

 

 1 .  Click Run Financial Statement , make sure that New is selected and then click OK . 
 

 2 .  Choose the desired type of report and then choose the desired column bar. 
 

 3 .  Fill in the remaining parameters in the next input screen.
 Note: If an Original Date has been defined for the selected column bar, indicate a Report Date at this stage in order to roll all column dates forward or backward, as needed. For example, if the designated Report Date falls exactly 6 months after the Original Date , all dates defined in the column bar will be rolled forward by 6 months as well. 
 

 4 . You can also run a financial statement that has your company’s logo on it, meant for external distribution, by clicking Run Financial Statemt (Document) . 
 

  
 
## Notes:

 

 ·        If there are problems with the statement, you may need to modify the column bar or the report items. 
 

 ·        Click to revise the graphic design of statements. 
 

 ·        Click to return to the main screen.
