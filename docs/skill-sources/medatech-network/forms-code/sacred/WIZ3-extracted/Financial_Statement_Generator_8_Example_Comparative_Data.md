# Example of Column Bar: Comparative Data

 

This bar is made up of two columns, comparing the closing balance at the end of the second quarters of two consecutive years. 
 

In the Definition of Column Bars form, assign the bar the title: "2 nd Qtr-This Year vs. Last Year". In the Original Date column, specify the first day of the year (e.g., 01/01/12). 
 

Fill in the columns of the Columns in Bar sub-level form as follows: 
 

 ·              Column Number: 1 
 Title: <P2.MM/YYYY>
 Column Type: 3
 Description: Period End
 To Date: 30/06/2011 
 

 ·              Column Number: 2 
 Title: <P2.MM/YYYY>
 Column Type: 3
 Description : Period End
 To Date : 30/06/2012 
 
## Notes:

 

 ·        You can also indicate the relevant Full Company Name , Division , Subsidiary and/or account Group , if necessary. 
 

 ·        When running the Run Financial Statement program, leave the Report Date column blank to run the statement for the original column dates or specify a different Report Date to roll the column dates forward or backward, relative to the column bar’s Original Date (e.g., specify 01/01/13 to run this statement the following year).
