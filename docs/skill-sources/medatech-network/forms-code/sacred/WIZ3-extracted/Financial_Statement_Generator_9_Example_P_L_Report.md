# Example of Column Bar: 2 nd Qtr 2012-P&L Report

 

This bar contains four columns: 
 

 ·              totals for the second quarter 
 

 ·              percentages for these quarterly totals 
 

 ·              YTD totals 
 

 ·              percentages for the YTD totals 
 

In the Definition of Column Bars form, assign the bar the title: "2 nd Qtr 2012 (P&L)". 
 

Fill in the columns of the Columns in Bar sub-level form as follows: 
 

 ·              Column Number: 1 
 Title: 2 nd Qtr 2012
 Column Type: 2
 Description: Period Total
 From Date: 01/04/12
 To Date: 30/06/12
 
 

 ·              Column Number: 2 
 Title: %
 Column Type: 5 
 

 Description: Percentage 
 

  
 

 ·              Column Number: 3
 Title: YTD
 Column Type: 3 
 

 Description: Period End
 To Date: 30/06/12
 
 

 ·              Column Number: 4 
 Title: % 
 

 Column Type: 5 
 

 Description: Percentage
