## Notes:

 

 ·        Any other changes to the report should be made with caution. If at any time you are unhappy with the changes you have made: 
 

 1 .  Take the report in question out of use (remove the check in the In Use column of the upper-level form). 
 

 2 .  Change its title (so you can reuse the title you want). 
 

 3 .  Rerun the Create Customized Statement program. 
 

 4 .  Use the relevant sub-level(s) of the Makeup of Financial Statements form to make the desired changes to the template you created. 
 

The report template is now available for your private use. If you want all users to have access to it, flag the General Use column in the Makeup of Financial Statements form. (Make sure the In Use column is flagged as well.) 
 

 ·        Click to create a column bar. 
 

 ·        Click to test the report (using an existing column bar). 
 

 ·        Click to return to the main screen.
