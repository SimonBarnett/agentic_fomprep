# Opening a Fiscal Period

 

When you are ready to work with a given fiscal period (i.e., to post journal entries that fall within it), you must open it. 
 
## To open a fiscal period:

 

 ·        Run the Open Fiscal Period program. The program opens the latest fiscal period that has not yet been opened.
