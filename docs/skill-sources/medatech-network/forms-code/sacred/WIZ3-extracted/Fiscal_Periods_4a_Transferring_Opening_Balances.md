# Transferring Account Balances

 

At the start of each fiscal year, you transfer account balances to the new year. This updates opening balances in all accounts based on the last balance calculated for each account in the previous year. 
 
## To transfer account balances:

 

 1 .  Run the Transfer Opening Balances program. 
 

 2 .  To check the results of the program, run the Opening Balances of Accounts report. 
 
## Notes:

 

 ·        You can run the program again whenever new journal entries are posted for the previous year. 
 

 ·        Balances of income and expense accounts are not transferred to the following year. Instead, they are posted to the default Prior Retained Earnings Account and their opening balance for the new year is reset to 0 .
