# Reopening a Fiscal Period

 

If you need to record a journal entry in a closed fiscal period, reopen the period. You can reopen the period either for transaction dates or reference dates : 
 

 ·        Run the Reopen Fiscal Period program, selecting either transaction date or reference date. The program cancels the closing of the latest closed period. 
 
## Note:

 

To reopen a fiscal period that is not the latest to have been closed, you must first reopen all the later periods.
