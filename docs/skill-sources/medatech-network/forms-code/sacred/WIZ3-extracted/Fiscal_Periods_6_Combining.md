# Combining the Last Two Fiscal Periods

 

To combine two periods, they must be in the same month (i.e., the start date of the first period and the end date of the second period must fall in the same month). 
 
## To combine the last two periods that were defined:

 

 ·        Run the Combine 12th & 13th Periods program (even if the periods are not the 12th and 13th). The program changes the two periods to one period whose end date is the end date of the later period.
