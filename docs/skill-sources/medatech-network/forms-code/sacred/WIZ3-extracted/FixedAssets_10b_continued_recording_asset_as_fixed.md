 7 .   Dual-currency users: Exchange rates and index information are updated automatically (in the Purchase tab) according to the purchase date of the asset, but may be revised. If the recorded indexes use a different index base than the one applied to Price Index values (in the Currencies form), specify the Index Base (Code) .
 Notes: 
 

 ·              It is likely that values for the base index and the previous month's index are not yet known. These can be filled in later by a special program before recording depreciation entries in the ledger. 
 

 ·              If the asset was purchased before you began working with Priority , you will need to record exchange rates and indexes for the asset's purchase date manually. 
 

 ·              To record index bases in the system, use the Index Bases form.
