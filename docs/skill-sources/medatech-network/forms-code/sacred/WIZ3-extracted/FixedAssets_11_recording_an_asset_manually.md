# To record a fixed asset manually:

 

 1 .  Enter the Fixed Assets form. 
 

 2 .  Record the date the asset was purchased in the Purchase Date column. The Effect Date and Payment Date columns will be filled in automatically, and a code identifying the asset will appear in the Asset Number column (by consecutive numeration). This code can be changed, if necessary.
 Note: The date of purchase will be considered the effect date for calculating depreciation. To begin calculating depreciation from a different date, revise the effect date. 
 

 3 .  Specify the Asset Group to which this asset belongs. The asset will inherit the group's GL accounts and depreciation definitions, which can be changed, if necessary. 
 Note: Check the asset's depreciation parameters twice : in the accounting definitions and in the tax definitions. 
 

 4 .  Specify the asset's Purchase Price . 
 

 5 .  In the Details tab, specify the Branch to which the asset belongs. If you work with subsidiaries, the accounts defined for the corresponding subsidiary will automatically appear in the Accts tab. 
 

 6 .  If you are recording one fixed asset for several items, indicate their quantity in the Quantity column.
