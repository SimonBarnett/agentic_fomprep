# Recording Prior Nominal Depreciation

 

On occasion, a fixed asset may have already depreciated before you recorded it into the system. Specifically, this occurs when records from another system are transferred to the Fixed Assets module in Priority . In this case, instead of recalculating the accumulated depreciation, you can simply record the value of any prior depreciation. 
 
## To record prior nominal depreciation for accounting purposes:

 

 1 .  Enter the Depreciation%-Accounting Records form, a sub-level of Fixed Assets . 
 

 2 .  Specify the prior nominal depreciation and the date until which it was calculated. 
 
## To record prior nominal depreciation for tax purposes:

 

 ·        Do the same in the Depreciation % - Tax Records form, another sub-level of Fixed Assets .
