# Recording Residual Values

 

In some cases, you may wish to cease depreciation of the asset when it reaches a given residual value. 
 
## To record a residual value for accounting purposes:

 

 ·        Enter the Depreciation%-Accounting Records form, a sub-level of Fixed Assets . 
 
## To record a residual value for tax purposes:

 

 ·        Enter the Depreciation % - Tax Records form, another sub-level of Fixed Assets .
