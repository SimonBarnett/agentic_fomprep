# Calculating Depreciation

 

Depreciation is calculated, for both tax and accounting purposes, on a daily basis. For this reason, depreciation for the month of January will be higher than that for February, as there are more days in January. 
 
## To calculate depreciation of assets:

 

 1 .  Run the Calculate Depreciation program. This program calculates the monthly depreciation of any number of designated assets – for both accounting and tax purposes – for the designated fiscal year. 
 

 2 .  To view results, run the Cost and Depreciation report. 
 
## Notes:

 

 ·        You can also calculate depreciation for a single asset by Direct Activation from the Fixed Assets form. Results are displayed in the Calculated Deprec.-Acc'ting Recs and Calculated Deprec. - Tax Records sub-level forms. 
 

 ·        New assets will not appear in the fixed assets reports until the Calculate Depreciation program is run.
