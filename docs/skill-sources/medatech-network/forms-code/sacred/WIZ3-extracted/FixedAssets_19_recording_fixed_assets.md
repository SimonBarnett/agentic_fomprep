# Recording Depreciation in the Ledger

 

Before recording depreciation in the ledger, make sure it was recently calculated. Depreciation is recorded, in a pending journal entry, as a debit against the asset's depreciation account and a credit against its accumulated depreciation account. 
 

You can choose to record depreciation alone, scrapping/sales alone or both depreciation and scrapping/sales. 
 
## Notes:

 

 ·        The dates of entries that will be recorded in the ledger depend upon the value you designated for the AssetDates constant. 
 

 ·        Dual-currency users: If asset values are adjusted for inflation, you may need to fill in missing index values (that were unavailable at the time of the asset's purchase or sale) before you record depreciation or the sale/scrapping of assets in the ledger. To do so, run the Update Index for Fixed Assets program. 
 
## To record depreciation entries:

 

 ·        Run the Record Asset Trans. in Journal program.
