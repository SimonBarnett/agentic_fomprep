# Appreciating the Value of a Fixed Asset

 

 Priority appreciates the value of a fixed asset when you define it as the principal asset of a new asset. The new (component) asset is assigned the same attributes as those of the principal asset, thus increasing the value of the latter. Example. 
 

The appreciation in the value of the fixed asset can be seen in reports. 
 
## To define the new (component) asset:

 

 1 .  Enter the Fixed Assets form. 
 

 2 .   Specify the attributes of the new asset (e.g., purchase date, asset description, asset group, purchase invoice details).
 Note: The asset group of the new asset must be the same as that of the principal asset. 
 

 3 .   Specify the principal asset's number in the Principal Asset column.
