# Setting Up Fixed Assets Accounts

 

Each fixed asset must be assigned to four GL accounts in the Chart of Accounts form, as follows: 
 

 ·        an asset account 
 

 ·        an accumulated depreciation account 
 

 ·        a depreciation expense account 
 

 ·        a capital gains account 
 

For assistance in setting up these accounts, run the Open GL Accounts Wizard . 
 
## Notes:

 

 ·        In the U.S. system, the Account Initialization program automatically sets up one asset account ( Equipment ) and one accumulated depreciation account ( Acc Dep - Equipment ). In the dual-currency system, it sets up three main asset accounts ( Equipment , Property-Land and Property-Bldgs ) and two accumulated depreciation accounts ( Equipment-Accumulated Deprec. and Buildings-Accumulated Deprec .). 
 

 ·        For each account, make sure that the Trial Bal Item and Bal Sheet/P&L Item columns are filled in. 
 

 ·        If you work with subsidiaries, you need to open fixed asset accounts for each subsidiary. For details about copying GL accounts automatically from the main company to a subsidiary, run the Subsidiaries Wizard .
