# To distribute depreciation expenses among several GL accounts:

 

 1 .  Enter the Depreciation Expense Accounts sub-level form. 
 

 2 .  Specify the accounts against which you want to debit each part of the depreciation expense.
 Note: If you work with subsidiaries, assign accounts in the main subsidiary. Individual assets will be linked to the correct subsidiary according to their designated branch. 
 

 3 .  Attach each account to the appropriate profit or cost centers, one per profit/cost group .
 Note: For more information about profit/cost groups, run the Cost Allocation Wizard . 
 

 4 .  Indicate the Percent of total depreciation expenses to be charged to each GL account. 
 
## Note:

 

To charge depreciation expenses to different profit groups within the same account, open a new line with the same account number for each profit group.
