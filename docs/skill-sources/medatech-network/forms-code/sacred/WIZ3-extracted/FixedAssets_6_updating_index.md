# Recording Monthly Index Values

 

If asset values are linked to the index, indexes must be recorded in the system, index bases must be recorded for old assets whose bases differ from that of the regular Price Index, and you must decide whether to allow a drop in the index to adjust values downward. 
 

Index values must be recorded for the first and the last day of each month. For instance, when the index value for August is published (in September), this value must be recorded for both August 1 and August 31. 
 

 To record monthly index values: 
 

 1 .  Enter the Exchange Rates form. 
 

 2 .  Specify the Date of the first day of the month in question. 
 

 3 .  Enter the Itemized Rates sub-level form and move to the line for Price Index . In the Exchange Rate column, record the index value. 
 

 4 .  Return to the upper-level form and, in a new line, specify the Date of the last day of the month. 
 

 5 .  Repeat Step 3.
