# To record index bases:

 

 1 .  Enter the Index Bases form. 
 

 2 .  Record the Index Code and Description of Index . 
 Tip: For reference, it is recommended that you include the last two digits of the year of the index in the code and/or description. For example, for the base index rate for 1993, record 93. 
 

 3 .  In the Ratio to Main Index column, record the ratio between the base rate for the year in question and the base rate applied to the Price Index (in the Currencies form). 
 
## To prevent adjustments due to a drop in the Price Index:

 

 1 .  Enter the Financial Constants form and move to the AssetNegInd constant. 
 

 2 .  Set the value to 0 .
