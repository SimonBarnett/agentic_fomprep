# Additional Definitions

 

You can define additional parameters to assist in locating the fixed asset and recording its scrapping: 
 

 ·        The asset's category 
 

 ·        The asset's location 
 

 ·        The investment plan to which the asset is linked. By linking assets to an investment plan, you can produce reports to be utilized in investment planning strategy. 
 

 ·        The asset's sale/scrapping category 
 
## To define fixed asset categories:

 

 ·        In the Fixed Asset Categories form, specify a code and brief description for each category. Example. 
 
## To define fixed asset locations:

 

 ·        In the Fixed Asset Locations form, specify a code and brief description of each location. 
 
## To define investment plans:

 

 ·        In the Investment Plans form, list your investment plans, indicating the item in each plan to which assets are attached. 
 
## To define sale/scrapping categories:

 

 ·        In the Sale/Scrapping Categories form, specify a code and brief description for each category. Example.
