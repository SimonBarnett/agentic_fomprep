# Setting the Intervals for Asset Replacement 

 

Two constants determine the period between the sale of an asset and the purchase of its replacement, within which it is permitted to deduct the capital gains acquired for the old asset from the value of the new one. The first constant covers the scenario in which the sale precedes the purchase. The second covers the scenario in which the purchase precedes the sale. These intervals are usually determined by law. 
 
## To set the permitted interval between sale and purchase:

 

 1 .  Enter the Financial Constants form, and move to the AssetReplacementFrom constant. 
 

 2 .  By default, the constant is set to 12 months. Revise, if necessary. 
 
## To set the permitted interval between purchase and sale:

 

 1 .  In the Financial Constants form, move to the AssetReplacementTo constant. 
 

 2 .  By default, the constant is set to 4 months. Revise, if necessary.
