# To record the disposal of a sold asset:

 

 1 .  In the Fixed Assets form ( Sale tab), choose the asset's Sale/Scrap Code . 
 

 2 .  Make sure the Sale /Scrap Date is specified, and that a check mark appears in the Sale/Scrap Journal Entry column.
 Notes: 
 

 ·              If transactions were recorded for the asset after the sale/scrap date, adjustments must be made before proceeding; consult with the Eshbel support staff. 
 

 ·              Leave the Fixed Assets form open. 
 

 3 .  If the asset is a component of a principal asset, or has been split from an asset, click the Details tab and delete the number from the Principal Asset column.
 Note: The number will remain in the Original Asset column, in order to preserve the asset's history. 
 

 4 .  After any necessary adjustments have been made, calculate depreciation (select Calculate Depreciation from the list of Direct Activation s ) and then run the Record Asset Trans. in Journal program.
