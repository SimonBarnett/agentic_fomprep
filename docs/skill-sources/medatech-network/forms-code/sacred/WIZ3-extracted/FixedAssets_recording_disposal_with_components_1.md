# To record the disposal of a principal asset together with its component assets:

 

 1 .  In the Fixed Assets form, retrieve the principal asset. 
 

 2 .  Click the Sale tab and record the asset's Sale/Scrap Code . The following occur automatically: 
 

 ·              The Sale/Scrap Date is filled in from the invoice. 
 

 ·              A check mark appears in the Sale/Scrap Journal Entry column. 
 

 ·              The sale data is copied from the principal asset to all its component assets. 
 

 Notes: 
 

 ·              If transactions were recorded for the asset after the sale/scrap date, adjustments must be made before proceeding; consult with the Eshbel support staff. 
 

 ·              Leave the Fixed Assets form open. 
 

 3 .  After any necessary adjustments have been made, calculate depreciation (select Calculate Depreciation from the list of Direct Activation s ) and then run the Record Asset Trans. in Journal program.
