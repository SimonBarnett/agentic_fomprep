# To check and post the resulting journal entry:

 

 1 .  In the Fixed Assets form ( Sale tab), make sure you are in the scrapped asset's record. 
 

 2 .  Refresh the screen (press Ctrl + F11 ). The number of the pending journal entry appears in the Entry No. – Sale/Scrap column. 
 

 3 .  Move to that column and press F6 to access and check the entry. 
 

 4 .  Select Post Journal Entry from the list of Direct Activation s to post the journal entry to the ledger. 
 
## Notes:

 

 ·        Click to revise the data in a sale/scrap ping transaction for which a journal entry has been posted . 
 

 ·        Click to return to the main screen.
