# To record the scrapping of a principal asset together with its component assets:

 

 1 .  In the Fixed Assets form, retrieve the principal asset. 
 

 2 .  Click the Sale tab and record the asset's Sale/Scrap Code and Sale/Scrap Date . The following occur automatically: 
 

 ·              A check mark appears in the Sale/Scrap Journal Entry column. 
 

 ·              The scrap data is copied from the principal asset to all its component assets. 
 

 3 .   Dual-currency users: Exchange rates and index information are updated automatically (in the Sale tab) according to the scrap date of the asset, but may be revised. If the recorded indexes use a different index base than the one applied to Price Index values (in the Currencies form), specify the Index Base (Code) .
 Notes: 
 

 ·              It is likely that values for the base index and the previous month's index are not yet known. These can be filled in later by a special program before recording scrap entries in the ledger. 
 

 ·              To record index bases in the system, use the Index Bases form. 
 

 ·              If transactions were recorded for the asset after the sale/scrap date, adjustments must be made before proceeding; consult with the Eshbel support staff. 
 

 5 .  After any necessary adjustments have been made, calculate depreciation (select Calculate Depreciation from the list of Direct Activation s ) and then run the Record Asset Trans. in Journal program.
