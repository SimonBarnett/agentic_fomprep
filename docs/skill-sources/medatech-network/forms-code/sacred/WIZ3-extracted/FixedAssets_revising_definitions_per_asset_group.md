# Updating Account Definitions and Depreciation Rates of Asset Groups

 

In some cases, it is necessary to update the account definitions and depreciation rates of an active asset group. 
 

This is particularly useful when an asset group has been opened and assets have already been assigned to it, but no accounts or depreciation rates were recorded for it. 
 

 Priority enables you to record the desired accounts and depreciation rates for the asset group, and then copy them to all assets that belong to the group. 
 
## Warning: 

 

This will override any account definitions and/or depreciation rates that have been recorded for individual assets in the group.
