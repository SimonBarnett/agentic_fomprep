# Setting up Fixed Asset Groups

 

Fixed asset groups include assets that share the same depreciation attributes and GL accounts. You can either define GL accounts for the entire asset group, or define separate GL accounts per state in which the asset is located. 
 
## Notes:

 

 ·        An asset is assigned to a group when it is recorded. The asset inherits its group definitions, but these may be revised. 
 

 ·        If you define separate GL accounts per state, the state must be specified when each fixed asset is recorded. 
 
## To record a fixed asset group:

 

 1 .  Enter the Fixed Asset Groups form. 
 

 2 .  Specify a code identifying the group, and a brief description of the group. 
 

 3 .  Specify the depreciation of assets in the group, calculated according to either federal depreciation rate tables OR the Straight-Line method. The depreciation method will be inherited by all assets in this group, but may be revised for individual assets. 
 

 If using federal tables: 
 

 ·              For the ledger, use the Depreciation Table column in the Depreciation-Acc ' ting tab. 
 

 ·              For tax purposes, use the Depreciation Table column in the Depreciation-Tax tab. 
 

 If using the Straight-Line method: 
 

 ·              For the ledger, use the % Depreciation column in the Depreciation-Acc ' ting tab. 
 

 ·              For tax purposes, use the % Depreciation column in the Depreciation-Tax tab.
