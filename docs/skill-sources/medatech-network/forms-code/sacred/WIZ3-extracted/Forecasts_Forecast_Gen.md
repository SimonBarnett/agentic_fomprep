# Preparing an Automatic Demand Forecast

 

The Generate Demand Forecast program allows you to create an automatic forecast based on one of the following sources: 
 

 ·        the monthly average of sales orders whose due dates fall during the designated period (i.e., the order pipeline) 
 

 ·        sales forecasts based on sales orders 
 

 ·        sales forecasts based on customer invoices 
 

While the order pipeline is a good source for short-term planning, sales forecasts (of either type) are the preferred source for long-term planning. 
 
## To create a forecast automatically:

 

 1 .  Run the Generate Demand Forecast program, specifying the source on which you want to base this forecast. 
 

 2 .  Enter the Demand Forecasts form, retrieve the forecasts that were created, and revise them if necessary.
