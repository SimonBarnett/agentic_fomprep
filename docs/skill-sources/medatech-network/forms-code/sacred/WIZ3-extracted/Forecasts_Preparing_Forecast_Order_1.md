# Preparing Forecast Orders

 

Forecast orders can be opened from within a given demand forecast or via the menu. Opening the order from within a forecast generates a single forecast order for the entire year. Opening the order via the menu enables you to prepare forecast orders for several demand forecasts simultaneously, and allows you to choose which months these orders will be opened for. 
 

All forecast orders are assigned the program run date as their order date. A separate order item is opened for each part and month, provided a forecasted quantity has been specified. The due date of the order items is determined by the Order Due Date appearing in the demand forecast (although it can be revised in the forecast order itself). 
 
## Notes:

 

 ·        If the demand forecast was opened for a specific customer, the forecast order will be opened for that customer as well. Otherwise, the forecast order will be opened for the predefined "Forecast" customer. 
 

 ·        The forecast order looks just like a regular sales order, except that its number is identical to the forecast code (i.e., has the prefix F ) and an F appears in the Forecast/Stock column in the Follow-up tab of the Sales Orders form. 
 

 ·        The forecast order will not include past months (even if these are selected as input). 
 

 ·        If a forecast order has already been opened for these months, running the program a second time will replace the existing order with a new one.
