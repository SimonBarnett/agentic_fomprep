## To open a forecast order from within a demand forecast:

 

 1 .  Enter the Demand Forecasts form and retrieve the demand forecast in question. 
 

 2 .  Select Prepare Forecast Order from the list of Direct Activations . 
 
## To open forecast orders in a batch:

 

 ·        Run the Prepare Forecast Order program.
 Note: If you run the program for a portion of the year and later rerun it for additional months, the new order items will be added to the existing forecast order. 
 
## To view a forecast order:

 

 ·        Do one of the following: 
 

 ·      Return to the Demand Forecasts form and retrieve the demand forecast in question. Move to the Code column and press F6 . OR 
 

 ·      Enter the Sales Orders form and use the program run date to retrieve the forecast order(s).
