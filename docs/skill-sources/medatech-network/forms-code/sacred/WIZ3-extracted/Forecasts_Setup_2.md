# The SFcastOrdDay Constant

 

The SFcastOrdDay constant determines the day of the month which will serve as the default due date of all order items in forecast orders. For example, if you assign it a value of 10, forecast order items will be due on January 10, February 10, March 10, and so on. This will determine the Order Due Date in any new forecast (affecting the due date of the forecast order opened for it), but it can be revised both in the demand forecast itself and in the forecast order that is created for it. 
 
## To set the value of the constant:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the line for the SFcastOrdDay constant and specify the desired value.
