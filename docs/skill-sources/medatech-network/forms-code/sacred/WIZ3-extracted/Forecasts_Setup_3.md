# The MnthForecast Constant

 

The MnthForecast constant determines which forecast orders will be used to reduce the demand generated by sales orders. 
 

When the constant is set to its default value 0 , only those forecast orders whose due date falls before or on the actual order's due date will be used to reduce the demand generated by sales orders. MRP will generate a work order (or demand) for the larger of the two types of orders, and another work order (or demand) for the difference between the two. 
 

When the constant is set to 1 , all those forecast orders that are due in the same month as the corresponding sales order will be used to reduce the demand generated by sales orders for the entire month, regardless of due dates. 
 

If it is imperative to fill your sales orders on time, leave the preset value of the constant at 0 (consider exact due date). If, in contrast, it is more important to prevent the accumulation of surplus inventory in the warehouse, set the constant value to 1 (consider entire month). Example. 
 
## To set the value of the constant:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the line for the MnthForecast constant and select the desired value.
