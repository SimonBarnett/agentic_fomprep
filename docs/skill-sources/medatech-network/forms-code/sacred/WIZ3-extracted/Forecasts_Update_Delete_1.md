# Revising or Deleting a Demand Forecast

 

You can revise a demand forecast (e.g., update quantities, add parts, delete parts) even after a forecast order has been opened for it (provided the original due date has not already passed). However, you must run a program to replace the existing forecast order with an updated version that reflects the changes made. The new forecast order will retain the same order number as the old one. The quantities recorded for each order item will be updated in keeping with the revised forecast. Line items from the original forecast order will not, however, be deleted, so that you can retain a history of forecasted quantities. 
 

If an entire demand forecast ceases to be relevant, you can delete it and replace it with a new one. Before performing the deletion, you must close its forecast order. The new demand forecast (and its forecast order) will receive a new number.
