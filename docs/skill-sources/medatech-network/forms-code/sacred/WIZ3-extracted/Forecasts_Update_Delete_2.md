Demand Forecasts - Revising/Deleting a Forecast.2 
 
 
- 
 
 
 

 To revise a forecast: 
 

 1 .  Enter the Demand Forecasts form and retrieve the demand forecast in question. 
 

 2 .  Make the necessary revisions to the forecast.
 Tip: To delete entire lines from a forecast, run the Delete Demand Forecasts program and select the parts in question. 
 

 3 .  Select Prepare Forecast Order from the list of Direct Activations to replace the existing forecast order with an updated version that reflects the changes made. 
 
## To delete an entire forecast:

 

 1 .  Make sure its forecast order has been closed (if not, run the Close Forecast Order program). 
 

 2 .  Run the Delete Demand Forecasts program.
