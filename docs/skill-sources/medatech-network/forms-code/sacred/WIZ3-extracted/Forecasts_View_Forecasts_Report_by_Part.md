# Viewing Demand Forecasts per Part

 

You can view forecasted quantities of a sold part over the course of the year by producing a report of the monthly forecasts recorded for the part each year. The report in question displays total forecasted quantities for the part per demand forecast; yearly totals for the part; and a grand total of all years in which forecasts were recorded for the part. 
 
## To view forecasts per part:

 

 ·        Run the Demand Forecasts per Part report.
