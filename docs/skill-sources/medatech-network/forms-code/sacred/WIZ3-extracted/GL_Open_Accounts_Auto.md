# Opening GL Accounts Automatically

 

If your company does not have a working list of GL accounts, you can run a program that: 
 

 ·        Opens a set of GL accounts 
 

 ·        Creates a hierarchy of trial balance items 
 

 ·        Assigns each GL account to its proper place in financial statements and 
 

 ·        Assigns default GL accounts to various transactions (e.g., inventory, income). 
 
## To open GL accounts automatically:

 

 ·        U.S. package: Run the Account Initialization program. 
 

 ·        Dual-currency package: Run the Account Initialization-Intl program. 
 
## Note:

 

Click to assign the new accounts to account groups .
