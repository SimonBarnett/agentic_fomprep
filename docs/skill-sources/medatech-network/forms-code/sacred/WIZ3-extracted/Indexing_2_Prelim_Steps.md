# Setting Up for Indexing

 

Before adjusting data to the price index, you must: 
 

 ·        Flag those balance sheet/P&L items to be indexed. 
 

 ·        Define an adjustment account for indexing. 
 Note: If the Account Initialization-Intl program has been run, this account is already set up. 
 
## To flag items to be adjusted to the index:

 

 1 .  Enter the Bal. Sheet/P&L Items-GL Accounts form. 
 

 2 .  Flag the Adjust Prices column for the appropriate balance sheet or P&L item. All accounts included in that sub-section of the statement will be adjusted to the index. 
 
## To define an adjustment account for indexing:

 

 1 .  Open an account in the Chart of Accounts form.
 Tip: Run the Open GL Accounts Wizard . 
 

 2 .  Enter the Default Accounts form. 
 

 3 .  On the line for Financing Expenses , record the number of the newly opened account. When indexing is calculated, any needed adjustments will be recorded against this account.
