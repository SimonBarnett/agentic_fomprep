# To adjust transactions based on the price index:

 

 ·        Run the Calculate Adjustment by Index program for the desired fiscal year. 
 
## Notes:

 

 ·        Click to view results in the indexed financial statements. 
 

 ·        Click to check results by viewing indexed balances of selected accounts. 
 

 ·        If the program has been run for the previous fiscal year, once you are satisfied that results are correct, run the Transfer Opening Balances program to transfer indexed opening balances to the current fiscal year. 
 

 ·        If you are adjusting values several years in the past, do the following: 
 

 ·      run the indexing program for the first year 
 

 ·      transfer opening balances to the second year 
 

 ·      run the indexing program for the second year 
 

 ·      transfer opening balances to the third year 
 

 ·      etc.
