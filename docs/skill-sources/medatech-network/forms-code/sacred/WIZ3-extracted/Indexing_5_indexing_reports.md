# Running Indexed Financial Statements

 

Before running the reports, ensure that adjustments to the index were made recently. 
 
## To view the last date that the calculation program was run:

 

 ·        Run the Indexing Date program. 
 
## You can run the following indexed statements:

 

 ·        Balance Sheet w/Linkage to Index 
 

 ·        Profit & Loss w/Linkage to Index 
 

 ·        Trial Balance w/Linkage to Index 
 

 ·        Account Ledger w/Indexing . 
 
## Notes:

 

 ·        While adjustments are usually made to the price index in effect when the calculation program was run, you can run the reports for a different index date. The rate on that date will be taken into account instead. 
 

 ·        The first three reports only display indexed values for those accounts whose balance sheet/P&L item were flagged for indexing. The last report displays indexed values for all accounts, regardless of the flag. 
 

 ·        If results seem inaccurate, click to check indexed balances of selected accounts. 
 

 ·        If the statements have been run for the previous fiscal year, once you are satisfied that results are correct, run the Transfer Opening Balances program to transfer indexed opening balances to the current fiscal year.
