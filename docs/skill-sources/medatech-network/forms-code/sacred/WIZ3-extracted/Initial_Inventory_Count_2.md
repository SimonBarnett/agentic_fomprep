# To itemize the count:

 

 1 .  Enter the Itemized Inventory Count sub-level form. 
 

 2 .  Record each part number on a separate line. 
 

 3 .  If you maintain lot or work order numbers, record the number in the Work Order/Lot column.
 Tips: 
 

 ·      Click if the lot is not yet defined in the system. 
 

 ·      Click if the work order is not yet defined in the system. 
 

 4 .  If necessary, change the part’s status. 
 

 5 .  To record the existing quantity of the part in this warehouse (and bin), fill in one of the following columns: 
 

 ·      Counted Qty (Fact.) OR 
 

 ·      Counted Qty-Buy/Sell OR 
 

 ·      Click to record the counted quantity in packing crate units.
