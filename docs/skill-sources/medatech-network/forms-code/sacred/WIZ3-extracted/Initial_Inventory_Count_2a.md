# Checking the Inventory

 

You need to check that the startup inventory levels in Priority are the same as those in your enterprise. 
 

 1 .  Run the Inv. per Warehouse as of Date report for all warehouses, for the date when you recorded the inventory count. 
 

 2 .  Spot-check that the report is correct (e.g., by recounting the inventory in some warehouses). Make any necessary corrections to the inventory count documents.
