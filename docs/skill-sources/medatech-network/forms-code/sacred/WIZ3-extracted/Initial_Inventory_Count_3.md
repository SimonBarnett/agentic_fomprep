# Calculating Past Balances

 

Your first set of past balances should be identical to your initial inventory levels. 
 
## To create past balances:

 

 ·        Run the Calculate Balance for Date program for the date you recorded the initial inventory count. 
 
## Notes:

 

 ·        To make a change to the inventory count after you calculate past balances, first delete the last past balance by running the Delete Last Past Balance program. 
 

 ·        Click to return to the main screen .
