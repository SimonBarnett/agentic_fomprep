# Finalizing the Count Document

 

Once you are sure that the inventory counts are correct, you need to finalize the count document so that no changes may be made. 
 
## To finalize a document:

 

 1 .  Enter the Inventory Count form and retrieve the document in question. 
 

 2 .  Change the status to Final . 
 
## Note:

 

To reopen a final document, so as to make corrections, select Reopen Document from the list of Direct Activations .
