# Record Default Packing Crates

 

If any parts are stored in packing crates, you can record the count in terms of packing crates. 
 
## To record default packing crates for these parts:

 

 1 .  If you have not yet done so, set up crate types in the Packing Crate Types form. 
 

 2 .  In the Inventory Parameters for Parts form, retrieve the desired parts. 
 

 3 .  For each part, click the Sales tab and record a C rate T ype C ode .
