# Recording Default Warehouses

 

You should record default warehouses for parts that are generally stored in a particular warehouse (and bin). 
 
## To record default warehouses:

 

 1 .  Enter the Inventory Parameters for Parts form. Retrieve the desired parts. 
 

 2 .  For each part, click the Inventory tab and record a warehouse.
