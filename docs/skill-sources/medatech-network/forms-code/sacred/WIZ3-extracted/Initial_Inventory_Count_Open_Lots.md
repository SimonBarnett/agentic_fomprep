# Opening Lots for Initial Inventory

 

 Priority maintains inventory balances of purchased goods per lot number. You therefore need to create a list of all lot numbers of existing purchased inventory. You will assign these lot numbers to part balances when you record the initial inventory count. 
 
## To open a list of lots:

 

 1 .  Enter the Raw Material Lots form. 
 

 2 .  For each part: Choose the part number. 
 

 3 .  Record the lot number and lot quantity. If desired, also record the expiration date and the vendor’s lot number.
