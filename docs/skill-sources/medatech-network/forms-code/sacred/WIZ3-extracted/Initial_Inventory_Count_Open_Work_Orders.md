# Opening Work Orders for Initial Inventory

 

 Priority maintains inventory balances of processed goods per work order number. If you maintain work order numbers for manufactured parts, you need to create a list of the work order numbers of existing inventory. You will assign these work order numbers to part balances when you record the initial inventory count. 
 
## To open a list of work orders:

 

 1 .  Enter the Work Orders form. 
 

 2 .  For each part: Choose the part number. 
 

 3 .  If a work order number is not filled in automatically, record a number for the work order. 
 

 4 .  Record the quantity. 
 

 5 .  If the work order is already closed, flag the Closed column. 
 

 6 .  Flag the Release column. 
 

 7 .  Click the Production Data tab and record the date production began. (If you do not know, record today’s date.)
