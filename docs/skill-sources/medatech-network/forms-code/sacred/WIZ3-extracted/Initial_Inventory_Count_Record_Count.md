- 
 
 
 
# To record the initial count:

 

 1 .  Enter the Inventory Count form. 
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column. 
 

 2 .  In the Date column, record the date of the day before you started working with Priority (e.g., if you started working with Priority on Jan. 1, record Dec. 31 of the previous year). 
 

 3 .  In the Warehouse column, choose a warehouse. If the inventory count involves more than one warehouse, record a separate line for each warehouse. 
 

 4 .  If you maintain bins, do one of the following: 
 

 ·      To obtain one document per warehouse. Record the main bin in the Bin column in the upper-level form. Later, change this for line items where necessary. OR 
 

 ·      To obtain one document per bin. Record a separate line for each bin. 
 

 5 .  The document’s Status will automatically be set to Draft .
