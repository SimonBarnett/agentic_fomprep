# Setting Up Finance Charges

 

To set up the finance charge mechanism, you need to: 
 

 ·        Define one or more types of finance charges 
 

 ·        Check the default Finance Charges account (the account credited for the amounts charged), revising it if necessary 
 

 ·        Assign a type of finance charge to each relevant customer. 
 
## What do you want to do?

 

 Define types of finance charges 
 

 Check the default Finance Charges account 
 

 Assign finance charge rates to customers
