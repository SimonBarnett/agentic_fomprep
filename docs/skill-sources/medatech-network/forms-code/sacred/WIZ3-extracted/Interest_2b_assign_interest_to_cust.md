# Assigning Finance Charge Rates to Customers

 

To assign finance charge rates to customers, link a given finance charge code to a given customer. Whenever a new customer is recorded in the system, that customer is automatically assigned the predefined 001 code (Default Finance Charge), but this may be revised. 
 
## To assign a finance charge code to a customer:

 

 1 .  Enter the Financ. Parameters for Customers form and retrieve the customer in question. 
 

 2 .  Click the Charges tab. The default 001 code appears automatically in the Finance Charge column. Change it as necessary. 
 

 3 .  Flag the Calculate Finance Charge column, so that finance charges will be calculated for this customer.
