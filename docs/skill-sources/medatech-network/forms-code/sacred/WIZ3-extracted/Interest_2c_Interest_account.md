# Checking the Default Finance Charges Account

 

The default Finance Charges account is credited whenever an invoice billing a customer for finance charges is finalized. 
 
## To check the account:

 

 1 .  Enter the Default Accounts form. 
 

 2 .  Move to the line for Finance Charges and make sure the account listed is the one you wish to credit. Change it as necessary.
