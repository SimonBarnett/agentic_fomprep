# Viewing Finance Charge Calculations

 

You can view calculations of the finance charges owed by given customers, as well as any invoices for previous finance charges. If you are working in the dual-currency system, you can also view the calculations by which amounts due when the invoice was issued are adjusted for exchange rate fluctuations on the day payment is received. 
 
## To view finance charge calculations for selected customers:

 

 ·        Run the Finance Charges report. 
 
## To view invoices already recorded for finance charges: 

 

 ·        Run the Charges Billed to Customers report. 
 
## To view finance charge calculations per receipt (dual-currency only):

 

 ·        Run the Fin. Charges per Receipt (ç"ù) report.
