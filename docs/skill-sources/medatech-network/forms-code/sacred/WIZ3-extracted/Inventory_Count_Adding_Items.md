# Adding Items to the Count Manually

 

There are two cases in which you need to add lines to the prepared forms: 
 

 ·        If you are counting a part for the first time in a given warehouse, and the calculated quantity of the part is zero, the part automatically has a work order/lot number of 0 and the status Goods . To record a work order/lot number or another status, manually add a line containing the correct information. (Record the counted quantity in the added line.)
 Important: Only add a line manually when the part has no recorded warehouse balance or a balance of zero. 
 

 ·        If you do not maintain bins, you can record separate counts of the same part for each location in the warehouse. Manually enter additional lines for each location. (In determining variance, the system compares the calculated quantity to the total counted quantity of the part in all locations.) 
 
## To add a line manually:

 

 1 .  In the Itemized Inventory Count sub-level form, choose the desired part. 
 

 2 .  If necessary, record the Work Order/Lot number and/or Status .
