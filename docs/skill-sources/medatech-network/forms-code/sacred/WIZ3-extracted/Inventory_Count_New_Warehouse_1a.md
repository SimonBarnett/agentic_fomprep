# Preparing an Initial Inventory Count for the New Warehouse

 

Prepare an inventory count for a new warehouse only if that warehouse was acquired with inventory. If it was acquired without inventory, simply record transactions for this warehouse and then perform a routine inventory count as in all other warehouses. 
 
## Before You Begin

 

You can define the new warehouse as the default warehouse for any given part. Once you perform a routine count for the new warehouse, the program that prepares the count can be set to include all parts defined as stored in this warehouse, even if their current inventory level is zero. 
 
## To define the default warehouse for a part:

 

 1 .  Enter the Inventory Parameters for Parts form. 
 

 2 .  Retrieve the desired parts. 
 

 3 .  For each part, record the default Warehouse (and Bin ).
