# To open the count:

 

 1 .  Enter the Inventory Count form. 
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column. 
 

 2 .  In the Date column, record today's date. 
 

 3 .  In the Warehouse column, choose the new warehouse. 
 

 4 .  If you maintain bins, do one of the following: 
 

 ·      To obtain one document per warehouse. Record the main bin in the Bin column. Later, change this for line items where necessary. OR 
 

 ·      To obtain one document per bin. Record a separate line for each bin. 
 

 5 .  The document will automatically be set to the initial status (usually, Draft) .
