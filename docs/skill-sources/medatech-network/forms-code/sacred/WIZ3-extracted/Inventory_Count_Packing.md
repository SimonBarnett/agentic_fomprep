# Recording the Counted Quantity in Packing Crate Units

 
## Before You Begin

 

 ·        If you have not already done so, click to set up a crate type code for the part. 
 
## To record the counted quantity:

 

 ·        In the Itemized Inventory Count form, fill in the Packing Crates (No.) and Crate Type Code columns. The counted quantity appears in the Counted Qty (Fact.) and Counted Qty-Buy/Sell columns.
