# Preparing the Inventory Count

 

When preparing an inventory count, the system calculates warehouse balances for a particular date. This can be either today's date or some date in the past . These calculated quantities are then compared to physically counted quantities recorded by the user and amounts of variance are displayed. 
 

Do not prepare the inventory count until you are sure that no further inventory transactions are likely to take place before the physical count is performed and recorded in the system. 
 
## To prepare the count for today's date:

 

 ·        Run the Prepare for Inventory Count program. 
 
## To prepare the count for a date in the past:

 

 ·        Run the Prepare for Inventory Count program. 
 
## To view calculated quantities:

 

 1 .  Enter the Inventory Count form. 
 

 2 .  Retrieve the desired count documents (retrieval tips). 
 Note: To assign handling of a document to another employee, specify his/her username in the Assigned to column. If you have done so for all prepared documents, you can exit the form and ignore the following instructions. 
 

 3 .  Enter the Itemized Inventory Count sub-level form to view results. 
 
## Notes:

 

 ·        The following are not included in inventory counts: 
 

 ·      Warehouses flagged in the External Control column (in the Warehouses form) 
 

 ·      Parts that are not flagged in the Inv. Control column (in the Part Catalogue form) 
 

 ·      Parts with the status Not In Use . 
 

 ·        Click to record the physical count. 
 

 ·        Click to return to the main screen.
