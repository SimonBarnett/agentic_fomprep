# Correcting Errors in Inventory Transaction Documents

 
## Before You Begin

 

 1 .  Run the Inventory Journal for Warehouse report to view inventory transactions per warehouse and part over a given period. 
 

 2 .  Run the Pending Docs Before PastBal-OLD report to view any transaction documents that were opened before the last calculation of past balances but were never finalized. 
 

 3 .  If any problematic document was recorded before the date that past balances were last calculated, you have to delete those balances before you can fix the document. To do so, run the Delete Last Past Balance program. 
 
## Correcting Errors in a Pending Document

 

 ·        If the problematic document is still pending (has not been finalized), simply make corrections in the document (e.g., increase the quantity of goods in a customer shipment).
