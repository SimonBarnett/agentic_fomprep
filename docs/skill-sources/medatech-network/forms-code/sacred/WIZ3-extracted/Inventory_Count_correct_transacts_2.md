# Correcting Errors in a Final Document

 

In most cases, you can correct a final document by reopening it, making the necessary revisions, and finalizing it again. 
 

Sometimes, however, this is not possible (e.g., because the transaction in question has already been invoiced). In that case, you need to create a reversing document. If the original document added to inventory balances, the reversing document subtracts from them, and vice versa. An entry is opened automatically for the reversing document in the Audit Trail form. 
 
## To reopen a final document:

 

 ·        Retrieve the document in question and select Reopen Document from the list of Direct Activations . 
 
## To create a reversing document:

 

 1 .  Open a new document of the same type as the original document (e.g., a shipping document). 
 

 2 .  Manually record the incorrect items in the sub-level form exactly as they appear in the original document, with one exception: Record quantities as negative values.
