Inventory Count - Introduction 
 
 
- 
 
 
 

There are a few different scenarios in which inventory counts are run: 
 

 ·        Upon installation of Priority , you need to record initial inventory counts for all warehouses. 
 

 ·        Upon acquiring a new warehouse that includes inventory, you must perform an initial inventory count before any transactions are recorded involving that warehouse. More . 
 

 ·        Routine inventory counts are performed on a regularly scheduled basis. 
 
## What do you want to do?

 

 Record initial inventory counts (run the Initial Inventory Count Wizard ) 
 

 Record an inventory count for a new warehouse acquired with inventory 
 

 Run a routine inventory count
