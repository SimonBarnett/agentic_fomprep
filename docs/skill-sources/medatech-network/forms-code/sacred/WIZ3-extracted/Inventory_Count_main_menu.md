# Routine Inventory Counts

 

Routine inventory counts involve: 
 

 ·        automatic preparation of calculated quantities 
 

 ·        recording the physical count 
 

 ·        approving counted quantities when identical to or close to calculated quantities 
 

 ·        investigating variance between calculated and counted quantities 
 

 ·        performing a recount when necessary. 
 
## Note:

 

Business processes (statuses) for count documents and default warehouses for parts are usually set up when you run the initial inventory count. Click if they have not been set up .
