# Performing the Physical Count

 

You can print out forms in which to record the results of physical counts. 
 
## To record results during the physical count:

 

 1 .  Run the Print Inventory Count Form report to print forms for the count. 
 

 2 .  Perform the physical count, recording it by hand in the printed forms. 
 
## Notes:

 

 ·        Click to record counted quantities in the system. 
 

 ·        Click to return to the main screen.
