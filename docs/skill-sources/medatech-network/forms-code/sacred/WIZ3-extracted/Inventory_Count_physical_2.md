# Recording Counted Quantities in Inventory Count Documents

 

Counted quantities must be recorded in inventory count documents prepared automatically by the system. 
 

 Important! No inventory transactions should have been recorded in the system since the count was prepared. If, for any reason, this is not the case, you must prepare a recount, inputting the original count documents, before proceeding further: 
 

 ·      If the original inventory count was prepared for today's date, run the Prepare for Recount program (from the Prepare Count for Today (Quick) menu) OR 
 

 ·      If the original inventory count was prepared for a previous date, run the Prepare for Recount program (from the Prepare Count for Past Date menu). 
 
# To record counted quantities in the system:

 

 1 .  Enter the Inventory Count form and retrieve the documents for each warehouse (retrieval tips). . 
 

 2 .  For each document, enter the Itemized Inventory Count sub-level form. 
 

 3 .  To record the existing quantity of a part, copy it into one of the following columns: 
 

 ·      Counted Qty (Fact.) OR 
 

 ·      Counted Qty-Buy/Sell OR 
 

 ·      Click to record the counted quantity in packing crate units. 
 
## Notes:

 

 ·        Any variances between calculated and counted quantities appear in the Variance (Factory) column. 
 

 ·        If you maintain bins, check the Bin column to make sure you are recording the quantity for the correct bin.
