# Recording a Recount

 

If you have corrected transaction documents retroactively and/or created new transaction documents, you need to record a recount. 
 

 1 .  Do one of the following: 
 

 ·      If the original inventory count was prepared for today's date, run the Prepare for Recount program (from the Prepare Count for Today (Quick) menu) OR 
 

 ·      If the original inventory count was prepared for a previous date, run the Prepare for Recount program (from the Prepare Count for Past Date menu). 
 

 2 .  To obtain a new list of remaining variances, run the Count Discrepancies report. 
 

 3 .  To approve quantities having no variance or only minor variance, enter the Inventory Count form and its sub-level, Itemized Inventory Count , and flag the Approve Counted Qty column. 
 

 4 .  For each remaining quantity having variance, select one of the following options: 
 

 ·      Approve the counted quantity by flagging the Approve Counted Qty column. OR 
 

 ·      Click to check inventory transactions further. 
 

 5 .  When all counted quantities are approved, return to the Inventory Count upper-level form. Change the status to Final .
