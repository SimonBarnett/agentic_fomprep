# To check the physical count: 

 

 1 .  Using the results of the Count Discrepancies report as a guide, physically recount the quantities with major variance. 
 

 2 .  If any results are different than in the first count, revise the counted quantity in the Itemized Inventory Count sub-level form. If possible, approve the new quantity by flagging the Approve Counted Qty column.
 Note: If additional transactions have been recorded since the original count, these must be considered when comparing counted and recounted quantities. 
 

 3 .  Do one of the following: 
 

 ·      If no variances remain, return to the Inventory Count upper-level form and change the status to Final . OR 
 

 ·      If major variances still remain, click to check inventory transactions .
