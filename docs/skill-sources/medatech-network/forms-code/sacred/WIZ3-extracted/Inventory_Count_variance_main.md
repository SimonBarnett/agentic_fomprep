# Investigating Variances

 

Inventory count variances occur when there are discrepancies between the quantities calculated by the system and counted quantities. Discrepancies are either the result of mistakes in the count or inaccurate recording of inventory transactions. If the system detects variances, you should investigate their source before approving them; once a variance is approved, the system creates an inventory transaction to adjust the inventory balance accordingly. Explanation. 
 
## Before You Begin

 

 ·        Run the Count Discrepancies report to obtain a list of all variances and detect the major ones. 
 Note: Users of the Fashion module should use the Count Discrepancies per Style report instead to view variances per style.
