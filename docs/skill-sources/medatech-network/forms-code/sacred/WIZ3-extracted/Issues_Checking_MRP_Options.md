# Checking MRP Options

 

If you are issuing in bulk on the basis of the MRP Issues Plan, it is important to check when MRP was last activated and whether it was run as a simulation. If the program has not been run for a while or was run as a simulation, results may not be up-to-date or final. In that case, you should consult with the person who runs MRP before preparing issues to the floor. 
 
## To check when and how MRP was last run:

 

 ·        Run the View Dates & Chosen Options program.
