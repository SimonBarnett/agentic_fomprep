# Issue of Supplies

 

Inventory issued as supplies consists of parts that are required in the production process, yet are not considered components of the processed part, such as machine oil. This inventory does not belong to the plant floor; that is, it is reduced from the inventory in the warehouse from which it is issued, but does not appear as floor inventory. 
 
## To issue supplies:

 

 1 .  Enter the Issue of Supplies form. 
Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the General tab). 
 

 2 .  Record the Date of the issue. The Document Number appears automatically. 
 

 3 .  In the General tab, choose the Issuing Warehouse and Bin from which the issued parts are to be transferred.
 Note: If parts are issued from more than one warehouse (or bin), designate the main one here. When itemizing the document, indicate the issuing warehouse for each part. 
 

 4 .  Click if the part is issued for use in a project. 
 

 5 .  Enter the Issued Items sub-level form. 
 

 6 .  Specify the Part Number of the issued part.
