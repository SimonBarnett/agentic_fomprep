# Before You Begin

 

Note that any negative inventory balances and missing issues on the plant floor will be added to the calculated demand. You should identify the source of the problem and correct inventory balances before running the Prepare Issues to Floor Stock program. 
 
## To identify the source of negative inventory and missing issues:

 

 ·        Run the Current Inventory by Warehouse or Inv. per Warehouse as of Date report for all floor warehouses, specifying <0 in the Balance (Fact. Unit) input column. 
 

 ·        Enter the Missing Issues form and retrieve missing issues for all floor warehouses.
 Tip : Missing issues also appear in the Inv. per Warehouse as of Date report as negative inventory. 
 
## Note: 

 

Run the Backflush Wizard for instructions regarding the handling of negative inventory and missing issues.
