# To issue in bulk:

 

 1 .  Run the Prepare Issues to Floor Stock program. 
 

 2 .  Enter the Issues to Floor Stock form and retrieve the issue document prepared by the program (for example, by date).
 Note: Click if no issue document was prepared. 
 

 3 .  Enter the Issued Items sub-level form, which displays the issues prepared by the program on the basis of available inventory balances.
 Notes: 
 

 ·      If existing inventory belongs to different part versions, lots or work orders, or is stored in several warehouses, the system displays the inventory to be issued on separate lines. The choice of which inventory to issue first is determined by a set order of precedence. Explanation. 
 

 ·      Click if you think that certain issued parts are missing . 
 

 4 .  For each line, check the part's details (e.g., part revision, work order/lot, status, warehouse); revise them if necessary.
 Note: The status of each part needs to be one that is flagged as Available for Issue (in the Inventory Statuses form).
