# Issuing in Bulk

 

Bulk issues are determined by the Prepare Issues to Floor Stock program, which calculates the quantities of child parts required for production, subtracts the quantities of parts already available in the relevant plant-floor warehouse (type F ), and prepares the issues according to the existing inventory balances in regular warehouses (type D ). Explanation. 
 

How the program calculates issue quantities depends upon the value assigned to the IFloorInv constant: 
 

 ·        According to the Issues Plan (generated by MRP) 
 

 ·        According to minimum floor stock (as defined for each issued part) 
 

 ·        According to the sum of bulk quantities required for the kit lists of all released, open work orders. Explanation. 
 

After the program prepares the issues, quantities must be approved manually.
