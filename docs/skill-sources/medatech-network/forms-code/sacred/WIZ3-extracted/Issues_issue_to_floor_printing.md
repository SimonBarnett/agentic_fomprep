# Printing an Issue Document for Bulk Quantities

 
## To print a single issue document:

 

 1 .  Enter the Issues to Floor Stock form and retrieve the desired document. 
 

 2 .  Select Print Issues to Floor Stock from the list of Direct Activations . 
 
## To print multiple issue documents:

 

 ·        Run the Print Floor Issues report. 
 
## Note:

 

Click to return to the main screen .
