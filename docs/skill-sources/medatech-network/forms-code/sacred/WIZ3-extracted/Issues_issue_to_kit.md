# Issuing to a Kit

 

When issuing to a kit, the entire issued quantity is intended for a specific work order, and other work orders cannot use this inventory. Issues to kits are recorded in a special sub-level of the Work Orders form. This sub-level form automatically displays all child parts required for production of the work order that have been flagged as issued to kits. 
 

Because issues to kits are done while handling work orders, run the Work Orders Wizard for detailed instructions.
