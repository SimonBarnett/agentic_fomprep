Issues - Linking an Issued Part to a Project or Activity 
 
 
- 
 
 
 
# To link the issued part to a project or an activity:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  In the Project Number column, choose/check the project. 
 

 3 .  If you have linked the document to a project activity, the WBS code of the activity appears in the WBS column. Revise it if necessary. 
 

 4 .  Change the Percent Completed , if necessary.
 Note: To revise the Activity Status , move to the Activity ID column and press F6 , then make the revision in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 5 .   Return to the upper-level form.
