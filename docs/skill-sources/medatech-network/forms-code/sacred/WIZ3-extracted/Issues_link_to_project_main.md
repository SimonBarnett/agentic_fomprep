# Linking Issued Supplies to Projects

 

You can link an issue of supplies to a project or to a specific project activity (when all issued parts are for the same activity). The cost of the transaction is added to the cost of the project or activity to which it is linked (unless the issuing warehouse is a project warehouse, in which case the cost was added when the supplies entered the warehouse). 
 

Project information will appear automatically when the issuing warehouse is a project warehouse. 
 
## Note:

 

When itemizing the issue transaction, you can link individual lines to a project activity. 
 
## What do you want to do?

 

 Link the document to the entire project or check the linked project 
 

 Link the document to a project activity or check the linked activity
