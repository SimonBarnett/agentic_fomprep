# Manual Issues

 

Manual issues are recorded during production reporting, and are intended for parts that are issued for immediate use (e.g., particularly expensive parts). 
 

Parts flagged for manual issue (in the Parts form) appear in the kit list but are not flagged as issued to kits; the Prepare Issues to Floor Stock program ignores these parts when it prepares issues to the floor. When reporting production for the relevant operation in the work order, these parts appear in the Choose list of parts for manual issue (in the Manual Issues to Work Order form, two levels down from the Reporting Production form). 
 

You can also issue parts in the Manual Issues to Work Order form that were not flagged for manual issue, though you will receive a warning when you do so. 
 

Furthermore, parts returned for rework need to be issued manually. 
 
## Note:

 

Because manual issues are recorded during production reporting, run the Production Report Wizard for detailed instructions.
