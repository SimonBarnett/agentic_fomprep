# Setting Up Alternate Parts 

 

For every child part used in production, you can define alternate parts that can replace it in the production of a particular parent part. More specifically, you can define when and how alternate parts are used when there is insufficient inventory of the original child part. 
 
## To define the use of alternate parts:

 

 1 .  Enter the Planning Constants form. 
 

 2 .  Move to the UsePartAlt constant. 
 

 3 .  Choose between the following options: 
 

 1 – The system will use the existing inventory of alternate parts when issuing to kits, issuing bulk quantities to the plant floor and calculating floor inventory ( Backflush ), as well as during Production Planning and MRP . 
 

 2 – The system will use the existing inventory of alternate parts when issuing to kits, issuing bulk quantities to the plant floor and calculating floor inventory ( Backflush ), but not during Production Planning and MRP . 
 

 0 – The system will not use alternate parts. 
 
## Notes:

 

 ·        Even if you allow for the general use of alternative parts, you can still prevent the use of alternates for specific parts in a specific work order. 
 

 ·        Click to define alternates for a child part.
