# Setting Up the Method of Calculating Bulk Quantities

 

When issuing bulk parts to the plant floor, the issued quantity must be sufficient to fulfill the needs of production (until the next issue). Priority supports three methods of calculating issue quantities: 
 

 ·        According to the Issues Plan (generated by MRP) 
 

 ·        According to the sum of quantities required for all released work orders that are still open 
 

 ·        According to minimum floor stock (as defined for each bulk part) 
 

Choose the method that is appropriate to your factory's production methods. Explanation. 
 
## To set the method of calculating issue quantities:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the IFloorInv constant, and choose the appropriate value. 
 
## Note:

 

The value 1 requires the definition of minimum stock values for each issued part. Click to define minimum floor stock of a bulk part .
