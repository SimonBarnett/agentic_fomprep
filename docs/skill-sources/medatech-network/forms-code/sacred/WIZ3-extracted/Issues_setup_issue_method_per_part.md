# Setting Up Types of Issues

 

Before you can begin using a part for production, you must decide upon the method by which it will be issued. By default, all new parts are flagged for issue to a kit. 
 

A part that is usually issued in bulk can be flagged for issue to a kit for a specific work order. However, you cannot change the issue type of a part that is defined as issued to kits. 
 
## To set the issue type for a part:

 

 1 .  Enter the Parts form and retrieve all parts that are to be issued. 
 

 2 .  Do one of the following: 
 

 ·      If the part is to be issued to a kit, make sure a check mark appears in the Issued to Kits column. 
 

 ·      To issue in bulk, or for an issue of supplies, remove the check mark. 
 

 ·      If the part is to be issued manually, remove the check mark, and flag the Manual Issue column.
