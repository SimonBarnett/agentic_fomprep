# Setting Up Issues

 

Before issuing parts, you need to define: 
 

 Business processes for issues of supplies (statuses) 
 

 The type of issue for each part 
 

 The method of calculating required quantities of bulk parts 
 

 The minimum floor stock of each bulk part (when calculation of bulk quantities is based on minimum floor stock) 
 

 The way the system handles alternate parts Explanation. 
 

 Alternate parts for each issued part
