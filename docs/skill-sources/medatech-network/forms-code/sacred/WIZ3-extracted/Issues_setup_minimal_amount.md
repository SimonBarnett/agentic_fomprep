# Setting Up Minimum Floor Stock

 

Minimum stock of bulk parts affects the Prepare Issues to Floor Stock program when the value of the production constant IFloorInv is 1 . In this case, the program will calculate the required quantity of parts by subtracting existing inventory of the part (in the warehouse in which it is needed) from its defined minimum stock. 
 
## To define minimum stock for a bulk part:

 

 1 .  Enter the Purchase/MRP Parameters for Part form and retrieve the desired part. 
 

 2 .  Enter the Minimum Floor Stock sub-level form. 
 

 3 .  Open a new line for each plant-floor warehouse in which the part is needed, and specify the minimum inventory of the current part required in each warehouse.
