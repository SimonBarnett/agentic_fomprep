# Troubleshooting Issues in Bulk

 

If the Prepare Issues to Floor Stock program did not prepare the issues you expected, check the following: 
 

 ·        If bulk issues are based on the MRP issues plan, run the Issues Plan report. If the issues in question do not appear there, make sure MRP was properly run. Click for further details. 
 

 ·        If a part intended for issue is not listed in the Issues to Floor Stock form, make sure the part in question is not defined as a kit component in the Parts form. Kit components are issued directly to a kit and not issued in bulk to the plant floor.
 Note: Each issue line opened by the program displays the balance of available inventory, i.e., inventory that has a status flagged in the Available for Issue column (in the Inventory Statuses form) and has not been packed for a specific customer.
