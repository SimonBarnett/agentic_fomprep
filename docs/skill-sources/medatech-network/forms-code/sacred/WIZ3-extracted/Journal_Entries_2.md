# Before You Begin: Entry Codes

 

The entry code for a journal entry determines how accounts are debited and credited. You need to decide what entry code to use: 
 

 ·        For a simple entry, use the predefined M code. 
 

 ·        For a complex entry, use the predefined C code. 
 

 ·        For a specific financial transaction (e.g., an office purchase), you can create your own code. This can be either simple or complex. 
 

For more information on existing entry codes, and to create your own, click to run the Set Up Entry Codes Wizard .
