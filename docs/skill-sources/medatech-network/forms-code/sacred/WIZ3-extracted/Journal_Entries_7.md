Manual Journal Entries - Copying a Journal Entry 
 
 
- 
 
 
 
# To copy an existing journal entry:

 

 1 .  Enter the Entry Journal form and retrieve the entry that you want to copy. 
 

 2 .  Select Copy Journal Entry from the list of Direct Activation s . 
 

 3 .  In the input screen, record the relevant Transaction Date , Due Date and Reference Date for the new entry, as well as a brief remark that will appear in the entry's Details column. When the program is completed, a message appears with the number of the new entry. 
 

 4 .  Retrieve the new entry in the Entry Journal form. 
 

 5 .  Make any necessary revisions. 
 

 6 .  Select Post Journal Entry from the list of Direct Activation s . A permanent number is assigned to the entry and it is posted to the ledger.
