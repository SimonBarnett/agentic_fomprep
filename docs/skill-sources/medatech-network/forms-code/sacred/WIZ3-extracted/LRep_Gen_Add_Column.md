# To add a column to a customized ledger report:

 

 1 .  Enter the Ledger Rep Generator(Trans Date) form and move to the desired report. 
 

 2 .  Enter the Report Columns sub-level form and move to the column directly above the desired position of the new column.
 Note: Column position in the report generator determines both the order in which the columns will appear in the report, as well as the default sorting order of the report's results. 
 

 3 .  Create a new line (Ctrl+Enter) and select the desired column from the Choose list. 
 

 4 .  Revise the columns Title or Width , as needed.
