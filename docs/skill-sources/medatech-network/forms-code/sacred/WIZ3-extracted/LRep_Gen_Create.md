# To create a customized ledger report:

 

 1 .  Enter the Ledger Rep Generator(Trans Date) form. 
 

 2 .  Designate a report title.
 Note: This title will appear at the head of each report that you run, as well as in the report print-out menu. 
 

 3 .  Enter the Report Columns sub-level form. 
 

 4 .  Select columns in the following order: 
 

 ·     Opening Balance 
 

 ·     Transaction Date 
 

 ·     Entry No. 
 

 ·     Reference 
 

 ·     Refer. 2 
 

 ·     Details 
 

 ·     Cumulative Balance 
 

 5 .  To change the width or title of a column, leave the line, then return and make the desired changes in the Title or Width column of the Report Columns form. 
 

 6 .  The order in which you selected the report columns determines both the order in which the columns will appear in the report and the default sorting order of the report's results. To move a column, delete it and open a new line for it ( Ctrl+Enter ) from the column immediately above the desired position.
