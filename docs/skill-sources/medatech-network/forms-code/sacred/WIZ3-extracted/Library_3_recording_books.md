Library - Recording Publications 
 
 
- 
 
 
 
## To record publications:

 

 1 .  Enter the Library Catalogue form. 
 

 2 .  Record the Title of the publication. Priority assigns a catalog number, which appears in the I nternal N umber column when you leave the line.
 Note to dual-currency users in a non-English system: If you are working in a language other than English and want this publication to be recorded in English, move to the Misc. tab and record an English title in the Title in Lang 2 column. 
 

 3 .  To attach a file to the current library record, use the folder icon to browse to the desired document and import it.
 Tip: Right-click the folder icon and select Import ; Priority will create a copy of the target file in a directory accessible to all network users. A link to this file appears in the File Name column. The icon now indicates the file extension of the linked publication (e.g., PDF). 
 

 4 .  Fill in any other available information. 
 

 5 .  In the Catalogue Data tab, the initial Status appears automatically; revise as necessary. In the Assigned to column, make sure the correct username is specified.
 Tip: You can define work flow rules so that the assigned user changes automatically when a given status is assigned. 
 

 6 .  In the In Charge column, specify the user who is in charge of the publication's content. 
 

 7 .  You can record remarks about the publication in the Remarks form (a sub-level of the Library Catalogue ).
