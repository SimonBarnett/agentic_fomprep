# Maintaining Versions of a Library Publication

 

Each library record in your company is linked to a single file, which is stored on the server. If the file becomes out-of-date, you may wish to attach a newer version of the file, while continuing to maintain a history of previous versions. Priority allows you to maintain multiple versions of any library publication with different dates of publication, thus maintaining a history of all files that have been attached to the library record. 
 
## To save a version of a library publication:

 

 1 .  Enter the Library Catalogue form and retrieve the publication in question. 
 

 2 .  Select Save Revision for Current Doc. from the list of Direct Activations. The Date of Publication is updated to today's date and details of the previous version (i.e., the saved version) are copied into the Document Revisions sub-level form. 
 
## Tip:

 

You can view previous versions of the publication by entering the Document Revisions sub-level form and clicking the icon on the right.
