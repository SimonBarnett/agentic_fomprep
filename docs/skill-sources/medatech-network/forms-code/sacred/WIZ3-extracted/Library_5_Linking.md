# Linking Publications to a Form or Document

 

You can link publications in your library to specific records in various forms and documents (e.g., a project activity, service call, or part). This publication can then be accessed from the form or document itself. 
 
## To link the library publication:

 

 1 .  Enter the appropriate form or document and retrieve the record in question. 
 

 2 .  Enter the Library sub-level form. 
 

 3 .  In the Internal Number column, specify the number of the desired publication. 
 
## Tip:

 

You can view the linked publication by clicking the icon on the right.
