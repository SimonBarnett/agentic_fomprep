# Deleting an Attached File

 

Each library record in your company is attached to a single file, which is stored on the server. If the file becomes out-of-date or you need to change the filename, you may want to delete it. 
 
## To delete a file:

 

 1 .  Enter the Library Catalogue form and retrieve the publication in question. 
 

 2 .  Select Delete Publication Attachment from the list of Direct Activations. The file is removed from the server and the filename is no longer listed in the File Name (Cover) column.
