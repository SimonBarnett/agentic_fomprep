# Creating the Amortization Schedule

 

Once you have opened a new loan, you need to define how loan payments will be made. The method you use depends on the type of amortization schedule you want the system to prepare automatically. You can also create a schedule manually. 
 
## What do you want to do?

 

 Prepare an Equal Payments, Equal Principal or On Call schedule 
 

 Prepare a Custom schedule 
 

 Create the amortization schedule manually
