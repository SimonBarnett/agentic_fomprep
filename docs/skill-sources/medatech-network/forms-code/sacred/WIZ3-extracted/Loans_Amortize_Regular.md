# To record payment information:

 

 1 .  In the Bank Loans form, click the Payment tab and record the number of payments. 
 

 2 .  Record the amount of each payment. 
 Note: For equal-principal payments, this is the amount of principal in each payment. 
 

 3 .  If necessary, change the frequency of principal and/or interest payments.
