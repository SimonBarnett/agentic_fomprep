# Trying Out Loan Scenarios – Overview

 

Before actually taking out the loan, you can create hypothetical scenarios, “playing” with various parameters to see how changing their values affects your payments. In this way, you can decide on loan conditions that are acceptable to you. 
 

 Priority offers two options for trying out loan scenarios: 
 

 ·        the Loan Calculator 
 

 ·        the various loan forms. 
 

Use the Calculator when working with loans involving monthly payments when there is a fixed interest rate and the type of amortization schedule is either equal payments (the sum of principal and interest is the same in each payment) or equal-principal payments (the amount of principal is the same in each payment). 
 

In all other cases (e.g., when payments are more frequent, there is variable interest, you want a custom amortization schedule), use the loan forms instead. 
 
## Note:

 

The Calculator is much easier and faster to use.
