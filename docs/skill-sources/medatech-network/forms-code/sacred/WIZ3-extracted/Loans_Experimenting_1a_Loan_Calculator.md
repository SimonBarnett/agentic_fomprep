# Planning a Loan Using the Loan Calculator

 

 1 .  Run the Loan Calculator report. 
 

 2 .  Choose the desired type of amortization schedule (equal payments or equal-principal payments). 
 

 3 .  Record the Loan Amount and the No. of Payments . 
 

 4 .  Record the interest rate OR the monthly payment. Priority calculates the missing parameter and prepares an amortization schedule. 
 

 5 .  Run the report again to try out different loan parameters.
