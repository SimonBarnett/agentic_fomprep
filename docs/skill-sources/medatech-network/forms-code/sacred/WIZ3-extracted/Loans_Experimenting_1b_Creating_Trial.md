# Recording a Trial Loan

 

The three basic parameters that may vary in a trial loan are: 
 

 ·        Interest rate 
 

 ·        Number of payments 
 

 ·        Amount of each payment 
 

You record the amount of the loan, the frequency of payments and any two of these parameters. Priority calculates the third and prepares an amortization schedule.
