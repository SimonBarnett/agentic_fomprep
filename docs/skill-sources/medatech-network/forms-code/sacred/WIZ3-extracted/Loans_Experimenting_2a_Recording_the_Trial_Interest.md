# To record the trial interest rate:

 

 ·        Click the Interest Data tab and record a fixed interest rate OR choose a variable interest rate. For a variable interest rate, you can also record a margin. 
 
## Note:

 

If, rather than setting the interest rate, you prefer to calculate it after setting all other parameters (i.e., the amount of each payment, the number of payments and the payment frequency), continue to the next screen. You will calculate the interest rate later.
