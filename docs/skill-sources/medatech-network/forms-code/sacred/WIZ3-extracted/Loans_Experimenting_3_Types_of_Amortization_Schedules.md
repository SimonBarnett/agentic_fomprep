# Types of Amortization Schedules – Overview

 

You need to choose one of four amortization schedule types. The two major types are: 
 

 ·        Equal Payments. The sum of principal and interest is the same in each payment. 
Use this option only if you are using a fixed interest rate. 
 

 ·        Equal Principal. The amount of principal is the same in each payment. 
 
## In addition, two special types of amortization schedules are available:

 

 ·        On Call. A special type of equal-principal amortization schedule. Use it if you make payments more often than once a month. 
 

 ·        Custom. You decide on a number of payments and define each payment (or group of payments) separately. Example.
