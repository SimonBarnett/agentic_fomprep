# Creating a Custom Schedule

 

You create a custom schedule in the Custom Amortization Schedule sub-level form, using as many lines as required to define all the payment installments. Example. 
 

 1 .  Enter the Custom Amortization Schedule sub-level form. 
 

 2 .  For each line, fill in the From Payment and To Payment columns. 
 Note: If the line defines only one payment, record this payment number in both columns. 
 

 3 .  On each line, record the amount due per payment. 
 

 4 .  On each line, record the frequency of payment. This frequency applies to both principal and interest payments. 
 

 5 .  On each line, record the type of amortization schedule (Equal Payments or Equal Principal).
 Note: If you are using a variable interest rate, you must choose Equal Principal.
