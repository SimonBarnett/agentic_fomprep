# Changing Default Information

 

You can prepare an amortization schedule using the information you have recorded so far and using Priority 's default values for all other loan information. If this meets your needs, go on to the next screen. If not, you can change default values in the Bank Loans form. 
 
## To change default values: 

 

 1 .  If you specified a fixed interest rate and equal payments, and you want interest to be calculated based on the exact number of days between payments, click the Interest Data tab and flag the Int by Month Length column. 
 

 2 .  For a variable interest loan only, you can flag the Incl All Rate Chngs column (under the same tab), to take into account all changes in the interest rate between payments. 
 

 3 .  If the bank will be calculating the first payment differently than all the others, click the Payment Data tab and change the Adjustment Code to 1 . 
 

 4 .  If desired, click the Payment Data tab and change any of the following dates: first payment of principal, first payment of interest and date to begin calculating interest. 
 

 5 .  If payments are always due on the very last day of the month, flag the Paymt at Month End column.
