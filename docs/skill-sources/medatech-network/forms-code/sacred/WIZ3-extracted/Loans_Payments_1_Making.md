# Making Loan Payments 

 

Before each due date (e.g., once a month), you may need to update the loan's amortization schedule. 
 

After actually making the payment, you can record the journal entries for the payment in Priority 's general ledger. 
 
## Before You Begin (Variable Interest Loans Only)

 

 1 .  Click if you still need to record any changes in the interest rate that occurred since the last payment. 
 

 2 .  If you recorded any changes in Step 1 , run the Update Interest Amounts program.
