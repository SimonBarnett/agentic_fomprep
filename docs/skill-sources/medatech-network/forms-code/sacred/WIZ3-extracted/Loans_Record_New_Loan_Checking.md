# Calculating and Checking the Loan

 

 1 .  Select Prepare Amortization Schedule from the list of Direct Activations to generate an amortization schedule. 
 

 2 .  Enter the Amortization Schedule sub-level form and review the schedule. Make any necessary corrections. 
 

 3 .  To print the schedule, return to the upper-level form and select Amortization Schedule from the list of Direct Activations .
 Tip: Click to print amortization schedules for more than one loan. 
 

 4 .  Change the loan status to Active . 
 
## Note:

 

Click to return to the main screen.
