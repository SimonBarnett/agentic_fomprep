Bank Loans - Linking Payments to a Currency or Index 
 
 
- 
 
 
 
# To link payments to the Last Known Index or a foreign currency:

 

 1 .  Click the Linkage Data tab and select the index or currency in the Linked Currency column. 
 

 2 .  Specify the Linked Rate Date and Base Rate of the index or currency.
 Note: To allow for reduced payment when the rate drops, flag the Negative Price Adj column. 
 

 3 .  If either the principal or the interest is only partially linked, specify the appropriate percentage in the Principal Linkage or Interest Linkage column. If they are fully linked, specify 100.00 .
