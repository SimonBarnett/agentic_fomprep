# Additional Payment Information

 

 1 .  If the bank is calculating the first payment differently than the others, change the Adjustment Code to 1 . 
 

 2 .  If necessary, revise the first payment date for principal ( 1st Princ. Pay Date ), the first payment date for interest ( 1st Interest Pay Date ) and the date on which to begin calculating interest ( Calc. Interest as of ). 
 

 3 .  If payments are always due on the very last day of the month, flag the Paymt at Month End column. 
 
## For a fixed interest loan with equal payments:

 

 ·        To calculate interest according to the exact number of days between payments, click the Interest Data tab and flag the Int by Month Length column. 
 
## For a variable interest loan:

 

 ·        To take into account all changes in the interest rate between payments, click the Interest Data tab and flag the Incl All Rate Chngs column.
