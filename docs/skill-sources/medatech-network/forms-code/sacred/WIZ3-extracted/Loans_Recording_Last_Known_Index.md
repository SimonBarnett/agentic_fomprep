# To update the value of the Last Known Index:

 

 1 .  Enter the Exchange Rates form. 
 

 2 .  Record the date on which the index value was last released. 
 

 3 .  Enter the Itemized Rates sub-level form and move to the line for the Last Known Index. 
 

 4 .  Record the index value in the Exchange Rate column.
