# Setting Up The Bank Account

 

You need to make sure the bank account from which you will pay back the loan is set up in the system. Also record banking holidays so that the system does not schedule loan payments or calculate interest on those days. 
 

 1 .  Enter the Bank Accounts form. 
 

 2 .  Do one of the following: 
 

 ·      Move to the line for the desired bank account OR 
 

 ·      If the bank account does not appear, see the Set Up Bank Accounts Wizard . 
 

 3 .  Enter the Banking Holidays sub-level form. 
 

 4 .  If the holidays have not yet been recorded, record them.
