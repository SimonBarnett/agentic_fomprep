# Setting Up Types of Variable Interest

 

Interest rates for variable interest loans are set according to different types of base rates (e.g., the prime rate). You need to define each type of base rate in the system. 
 
## To define a type of base rate:

 

 1 .  Enter the Currencies form. 
 

 2 .  In the Curr column, record a code for the type of base rate (e.g., P for Prime). In the Currency Description column, record a description. 
 

 3 .  Flag the Interest column.
