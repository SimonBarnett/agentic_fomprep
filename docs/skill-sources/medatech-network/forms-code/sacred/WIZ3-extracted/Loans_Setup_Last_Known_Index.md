# Recording the Last Known Index

 

If loan payments are linked to the latest price index that is in effect on the date of payment, you need to define a Last Known Index and maintain it separately from the regular Price Index. Explanation. 
 
## To define the Last Known Index:

 

 1 .  Enter the Currencies form. 
 

 2 .  In the Curr column, record a code for the Last Known Index. 
 

 3 .  In the Currency Description column, record a description. 
 
## To assign an initial index value to the Last Known Index:

 

 1 .  Enter the Exchange Rates form. 
 

 2 .  Record the most recent date on which index values were published. 
 

 3 .  Enter the Itemized Rates sub-level form and move to the line for the Last Known Index. 
 

 4 .  Record the published index value in the Exchange Rate column.
