# Purpose of Loan

 

Loan purposes are categories into which you will place all loans that serve the same need (e.g., ongoing financing; financing new factory). For each loan purpose, you record two GL accounts: one for interest expenses and one that is credited each time you make a loan payment. These will appear as defaults when you record a loan with this purpose. 
 
## Note: 

 

You record the expense account for payment of principal separately for each loan. 
 
## To set up loan purposes:

 

 1 .  Enter the Purposes of Loans form. 
 

 2 .  Record the purpose. 
 

 3 .  Record the GL accounts. 
 Note: If you work with subsidiaries, specify accounts in the main subsidiary. Individual loans will be linked to the correct subsidiary according to their designated company branch.
