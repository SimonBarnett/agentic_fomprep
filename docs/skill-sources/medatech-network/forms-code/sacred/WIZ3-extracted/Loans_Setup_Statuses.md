# Setting Up Business Processes for Loans

 

You can use a BPM flow chart to customize statuses that help you control the processing of loans. There are four predefined statuses : Draft, Active, Frozen and Closed . These may be sufficient for your needs. 
 

While the predefined statuses cannot be deleted, you can change their names and properties. If needed, you can define additional statuses. You can define paths between these statuses, create work flow rules and set status properties. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Bank Loans program. 
 
## Tips:

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Loans form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
