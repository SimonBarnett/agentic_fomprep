# Defining Review Boards 

 

Before you begin handling malfunctions, you have to define the various review boards that are responsible for different types of malfunctions. These boards are made up of company employees recorded in the Personnel File form. 
 
## To record a review board:

 

 1 .  Enter the Material Review Boards form. 
 

 2 .  Record a code and a short description of the board. 
 

 3 .  To list the members of the board, enter the Board Members sub-level form and record each member's employee ID. 
 Note: You can also assign an alternate for each board member. 
 

 4 .  In the Send E-mail column, check the column if the member is to receive mail about the malfunctions for which this review board is responsible. 
 

 5 .  In the Authoriz. Required column, check the column if the member's authorization is required when a decision has to be approved.
