# Setting Up Business Processes for Malfunctions

 

You set up business processes by defining statuses in a BPM flow chart. 
 

The status of a malfunction determines the stage it is in (e.g., closed). Status changes reflect the flow of malfunction servicing through the various stages in the system, and the decisions made by the quality appointee or the review board. For instance, the status may indicate whether the malfunction has been assigned to a review board and whether it is the vendor's fault. 
 

There are several predefined statuses, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Malfunctions program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Malfunctions form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
