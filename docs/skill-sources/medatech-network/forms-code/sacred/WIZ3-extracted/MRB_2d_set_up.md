# Defining Malfunctions

 

When recording a malfunction document, you can indicate the severity of the malfunction and where it was detected. You therefore need to create a list of severity levels and detection places. 
 
## To define levels of malfunction severity:

 

 ·        In the Levels of Malfunction Severity form, record each severity level and a brief description of that level. 
 
## To define detection places:

 

 ·        In the Places of Malfunction Detection form, record a code and description for each location at which malfunctions tend to be detected (e.g., warehouse, plant floor).
