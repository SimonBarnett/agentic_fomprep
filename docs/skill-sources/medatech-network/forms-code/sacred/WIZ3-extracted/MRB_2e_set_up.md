MRB - Setup: Malfunctions and Resolutions.2 
 
 
- 
 
 
 

The quality appointee is required to pinpoint the reason for the malfunction and may also categorize it by type (e.g., engineering, machinery). The review board can record engineering recommendations, as well as specific malfunctions (e.g., mechanical, electrical, communications failure) and their resolutions. For these purposes, you need to create lists of reasons for malfunctions, types of malfunctions, engineering recommendation codes, malfunction codes and resolution codes. 
 
## Note:

 

Malfunction codes and resolution codes are also used in service calls. 
 
## To define reasons for malfunction:

 

 ·        In the Reasons for Malfunctions form, record a code and description for each cause of malfunction. 
 
## To define types of malfunction:

 

 ·        In the Types of Malfunctions form, record a code and description for each type of malfunction (e.g., engineering, machinery). 
 

 To define engineering recommendation codes: 
 

 ·        In the Engineering Recommendation Codes form, record a code and description for each type of engineering recommendation. 
 
## To define malfunction codes:

 

 ·        In the Malfunction Codes form, record a code and description for each specific malfunction.
 Note: The sub-level form is only relevant for service calls. 
 
## To define resolution codes:

 

 ·        In the Resolution Codes form, record a code and description for each solution.
