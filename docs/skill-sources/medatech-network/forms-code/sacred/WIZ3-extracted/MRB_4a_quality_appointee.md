# Further Handling of the Malfunction

 

The quality appointee's decision determines further handling of the malfunction: 
 

 ·        If the quality appointee decides to send the malfunction to MRB, the malfunction is assigned to the review board in charge. 
 

 ·        If the quality appointee determines that the malfunction is the vendor's fault, the next step is to link the malfunction document to appropriate inventory transactions. 
 

 ·        If the malfunction document has been assigned the “Canceled” status, the process of handling the malfunction ends.
