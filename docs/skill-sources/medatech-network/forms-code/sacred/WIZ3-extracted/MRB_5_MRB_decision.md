# Handling of the Malfunction by the Review Board

 

If a malfunction is sent to MRB for further handling, members of the review board need to record details about how they are dealing with the malfunction, as well as the decision reached regarding a solution. That decision then needs to be authorized by all board members flagged as authorizers (or their alternates). 
 

Mail about the malfunction can be sent to any member of the board, as well as to people outside the company (such as vendor contacts). The mail message informs recipients of the date on which the review board is convening and the number of the malfunction document. An attachment contains additional information recorded about the malfunction and how the review board is handling it. Thus, mail can be sent at any stage of the process.
