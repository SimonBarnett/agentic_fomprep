# Further Handling of the Malfunction

 

The board's decision determines the further handling of the malfunction: 
 

 ·        If the review board determines that the malfunction is the vendor's fault, the next step is to link the malfunction document to appropriate inventory transactions. 
 

 ·        If the malfunction document has been assigned the “Canceled” status, the process of handling the malfunction ends. 
 

 ·        Otherwise, the malfunction is dealt with in the factory, in accordance with the board's decision. 
 
## Notes:

 

 ·        Once the malfunction is resolved, the quality appointee is responsible for closing the malfunction document.
