# Linking the Malfunction Document to Inventory Transactions

 

Following the quality appointee/review board's decision, or in order to save the information regarding the malfunctioning part, you can link the malfunction document to an inventory transaction related to the malfunctioning part, such as a goods receiving voucher or a return to vendor. You can also link the document to the original purchase order or to a work order. Example. This information can then be accessed from the malfunction document itself. 
 
## To link the malfunction document:

 

 1 .  Enter the Malfunction Linked to Document form and indicate the number of the malfunction document and today's date. This form is a sub-level of the transaction item, which is itself recorded in the sub-level of the following upper-level forms: 
 

 ·        Warehouse Transfer 
 

 ·        Inventory Count 
 

 ·        Goods Receiving Vouchers 
 

 ·        Returns to Vendor 
 

 ·        Purchase Orders 
 

 2 .  To link the malfunction document to the Work Orders form, enter its Malfunction Linked to Document sub-level form and record the same information. 
 
## Notes: 

 

 ·        To view the inventory transactions to which the malfunction document is linked, enter the Transactions Linked to Malfunctn form (sub-level of the Malfunction Document form). 
 

 ·        Click to return to the main screen.
