# Closing the Malfunction

 

If the quality appointee or the MRB decides to close the malfunction, the employee responsible (usually the quality appointee) must assign the “Closed” status to the malfunction document, making it final. 
 
## To close the malfunction document:

 

 1 .  Enter the Malfunction Document form and retrieve the document in question. 
 

 2 .  In the Details tab, change the malfunction S tatus to “Closed”. 
 

 3 .  In the Review Board tab, flag the MRB Decision Implemented column if the board's recommendation was implemented. 
 

 4 .  Flag the Preventives Implemented column if decisions about preventive action were implemented.
 Note: Any preventive action that needs to be taken to keep the malfunction from happening again can be recorded in the Preventive Action sub-level form. 
 
## Notes: 

 

 ·        To reopen a malfunction document and record changes, select Reopen Malfunction Document from the list of Direct Activations . 
 

 ·        Click to return to the main screen.
