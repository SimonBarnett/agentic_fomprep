# Preparing Sales and Forecast/Stock Orders for Consideration by MRP

 

When running MRP, you will need to choose the type of orders from which to calculate required quantities: open sales orders, forecast/stock orders or both. In any case, MRP will only take into account those order items that have been flagged for participation in MRP, and whose due dates fall within the planning period. Before running MRP, therefore, you should check that all of the necessary lines (in all types of orders) are so flagged. You can flag an order item for participation in MRP when recording the order, or afterwards (e.g., if the employee recording the order is not authorized to flag for MRP). You can either flag individual line items manually, or run a program that flags all lines in an order automatically.
