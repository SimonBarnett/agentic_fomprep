# Setting Up MRP for Distributors

 

You must first define MRP for Distributors as the system`s basis for purchase planning. 
 

When calculating the balances of available inventory, MRP for Distributors only takes into account parts stored in Type D warehouses, and only those parts with a status flagged as Basis for Planning . 
 

You may want to review your warehouses and inventory statuses to make sure they are correctly defined. 
 

Finally, you can assign each purchased part a replenishment type , which determines how the required quantity of the part is calculated by purchase planning. 
 
## Note:

 

 MRP for Distributors does not take into account a part`s safety stock ; this is dealt with during purchase planning.
