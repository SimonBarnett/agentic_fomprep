# MRPBus_setup_warehouse

- **Source:** `MRPBus_setup_warehouse.htm`

MRP for Distributors - Setup: Warehouse Types and Inventory Statuses 
 
 
- 
 
 
 
## To check warehouse types:

 

 1 .  Enter the Warehouses form and retrieve all warehouses. 
 

 2 .  For each warehouse, check the Type column (in the General tab): 
 

 ·      The value D signifies that the warehouse inventory is taken into account by MRP 
 

 ·      The value W signifies that the warehouse inventory is not taken into account by MRP. 
 
## To check inventory status definitions:

 

 1 .  Enter the Inventory Statuses form 
 

 2 .  For each status that is to be taken into account by MRP, flag the Available Inventory column. Only inventory with a status that is flagged in that column is considered available inventory for planning purposes. 
 Note: MRP takes into account parts packed for a customer (i.e., with the customer number as their status) in every Type D warehouse.
