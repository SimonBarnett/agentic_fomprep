# Calculating Demand for Purchased Parts

 

The method of calculating demand for purchased parts differs according to its replenishment type: 
 

 ·        If the part's replenishment type is R ( dynamic demand ), the quantity required for sales is calculated according to actual sales and forecast orders. 
 

 ·        If the part's replenishment type is B ( static demand ), MRP does not open issues for routine consumption. Rather, purchase planning handles these parts directly, according to the planning parameters defined for each part.
