MRP for Manufacturers - Info: The Issues Plan 
 
 
- 
 
 
 

 The Issues Plan 
 

The issues plan displays the demand for raw materials as calculated by MRP for both production and resale, including the required quantities and the dates on which they need to be issued. 
 

This data is used as input to purchase planning, and to prepare bulk issues of parts to the plant floor. MRP also plans issues for assembled parts, although it does not plan work orders for them. 
 

You can decide whether issues will be planned separately for each parent work order, planned monthly per parent part or planned monthly as one issue to all work orders of all parent parts.
