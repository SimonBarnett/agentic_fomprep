# Purchase Planning

 

When running the MRP program, you can choose to run purchase planning as well. The Purchase Planning program calculates projected part balances on the basis of the issues plan generated by MRP. It then opens purchase requisitions to cover any shortfalls in inventory that are anticipated up to the designated end date (after taking into account any open purchase orders as well as any existing inventory of purchased parts). The program generates a purchase demand document containing all of the new purchase requisitions.
