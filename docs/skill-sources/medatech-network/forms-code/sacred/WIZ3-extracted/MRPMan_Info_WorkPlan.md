# The Work Plan

 

When you open work orders in MRP, you can choose to prepare a work plan for the opened work orders. The program then schedules all work order operations on a time axis, according to the defined production times and the permitted percentage of operational overlap. 
 

You can view the work plan in a Gantt chart, which can then be modified manually, provided that this functionality has not been disabled via the MRP Gantt Chart Display Settings form; you can also produce related work and workload reports. 
 

Alternatively, you can open an individual work plan for a single work order by Direct Activation from the Work Orders form.
