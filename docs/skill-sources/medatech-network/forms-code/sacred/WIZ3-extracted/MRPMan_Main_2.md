# MRP performs the following operations:

 

 ·        Calculates the demand for final products.

 ·        Plans or opens work orders for final products and their sub-assemblies, according to the calculated demand.

 ·        Calculates demand for purchased parts according to the parent work orders (open or planned). 
Click for more information. 
 

 ·        Plans issues of purchased parts according to the calculated demand.

 ·        Prepares a work plan (optional).

 ·        Runs purchase planning (optional).
