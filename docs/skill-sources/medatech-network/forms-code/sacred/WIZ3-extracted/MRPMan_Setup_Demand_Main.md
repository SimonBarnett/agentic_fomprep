 Setting Up Demand Parameters 
 

There are a number of parameters that affect how MRP works for any given part: 
 

 ·        Replenishment Type determines the method used to calculate the required quantity of each part. 
 

 ·        Demand Range allows you to designate a fixed time period within which the program combines all demands for a given part into a single quantity. 
 

 ·        Safety Stock determines the minimum quantity of parts that must always remain in inventory. MRP takes this value into account when calculating required quantities, so that the inventory level of any given part does not fall below its defined safety stock. 
 

 ·        Scrap allows you to establish the average percentage of a part that is lost during the preparation of a sales order for the part itself, or during production when the part is added to its parent. 
 

 ·        Forecast orders (which represent future demand) are also taken into account during MRP planning. You can determine how MRP handles forecast orders when they coexist with actual sales orders in the same month.
