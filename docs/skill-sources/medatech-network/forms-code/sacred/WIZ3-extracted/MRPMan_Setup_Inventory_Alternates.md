# To define whether MRP will use alternate parts:

 

 1 .  Enter the Planning Constants form. 
 

 2 .  Move to the UsePartAlt constant and set the desired value. 
 
## Notes:

 

 ·        Alternate parts on the plant floor will only be used if the run-time option allowing floor inventory to be taken into account is selected. 
 

 ·        To define alternates for a specific part, use the Alternate Parts form, sub-level of the Parts form.
