# To define how MRP relates to floor inventory:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the MRPSepFloors constant and set the desired value. 
 
## Notes:

 

 ·        This constant is only relevant when MRP is run with the option of taking floor inventory into account. 
 

 ·        You cannot choose the value 1 (i.e., each floor warehouse is considered as separate inventory) if the PUseFlrStock constant (defined in the Logistic Constants form) is set to use floor stock in purchase planning (i.e., has a value of 1 ).
