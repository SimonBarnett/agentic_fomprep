# Setting Up MRP

 

You can run the program in a variety of ways. Results are affected by parameters that are defined on different levels – for parts, operations, work cells and warehouses – as well as by the relevant production, planning and logistic constants. 
 

These factors work together in a wide range of combinations, which you can test in the simulation mode until you discover the most desirable method for your company.
