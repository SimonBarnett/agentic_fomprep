# Restricting Use of the Gantt Chart

 

You may want to restrict access to the MRP Gantt Chart for certain employees. You can make the chart read-only and/or prevent work orders of a given status from appearing at all. 
 
## To restrict usage of the work plan using the Gantt chart:

 

 1 .  Enter the MRP Gantt Chart Display Settings form and move to the line(s) of any employees you wish to restrict. 
 

 2 .  Flag the Read Only column, if desired. 
 

 3 .  Enter the Work Order Statuses sub-level form and flag the Hide from Chart column for the statuses of any work orders that should not be included in the work plan for that employee. 
 
## Note: 

 

To prevent any access to the Gantt chart, use the Privilege Explorer .
