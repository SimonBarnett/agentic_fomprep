# To define the order in which work cells are displayed in the Gantt chart:

 

 1 .  Enter the Work Cells form, and retrieve all relevant work cells. 
 

 2 .  In the Display Order-Gantt column, specify for each work cell the order in which it will appear in the work plan Gantt chart (the smaller the number, the higher its place in the chart; work cells assigned a value of 0 appear last). If you do not want a certain work cell to appear in the chart, specify -1 .
 Note: All work cells in which work orders are produced appear in production control reports, whether or not they appear in the Gantt chart.
