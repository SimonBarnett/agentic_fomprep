# To define part parameters affecting work order size:

 

 1 .  Enter the Purchase/MRP Parameters for Part form and select the desired part. 
 

 2 .  Click the Planning Quantities tab. 
 

 3 .  To restrict work orders for this part to a certain minimum quantity, record the quantity (in buy/sell units) in the Min for Order/W. Ord column. 
 

 4 .  To restrict work orders for this part to a certain maximum quantity, record the quantity (in buy/sell units) in the Max for Work Order column. 
 Note: If a balance remains for a given part demand, an additional work order is opened to cover it. 
 

 5 .  If necessary, specify a work order increment in the Increment for Ord/WO column.
