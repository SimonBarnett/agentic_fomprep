MRP for Manufacturers - Work Order Setup: Restoring Automatic Timing Updates 
 
 
- 
 
 
 
# To restore automatic updates of timing parameters:

 

 1 .  In the Purchase/MRP Parameters for Part form, remove the timing parameter values that were recorded manually. 
 

 2 .  Click the MRP Definitions tab and flag the Automatic Prod Time column. 
 

 3 .  Enter the Parts form and retrieve the part in question. 
 

 4 .  Temporarily change the part's Routing to any other routing. 
 

 5 .  Leave the current record (e.g., press PgDn ). 
 

 6 .  Return to the record and restore the correct Routing . The timing parameters will once again reflect changes made to operation parameters.
