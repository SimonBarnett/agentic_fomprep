# Production Timing

 

Parameters affecting production time can be defined both per operation and per part. If you choose the run-time option to create a work plan, MRP uses the operation parameters; otherwise it uses the parameters defined for the part. 
 

By default, the production time defined for a part is continuously updated by operation timing parameters (after the new operation data has been recorded in a part routing). You can disable this option via a flag in the Purchase/MRP Parameters for Part form. 
 
## Note:

 

Whereas production time for operations is defined in hours, total production time for a part is rounded to complete days.
