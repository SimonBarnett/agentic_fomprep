# To set up a part for automatic work orders:

 

 1 .  Enter the Assign WO/Lot Templates to Parts form and select the desired part. 
 

 2 .  Flag the Open Automatically column. 
 

 3 .  Select the desired numeration template in the Wk Ord/Lot Template column. 
 
## To set MRP to open work orders automatically:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the WorkOrdNum constant and set the value to 1 . 
 
## Notes:

 

 ·        If you choose not to open work orders automatically, the Release operation will not appear automatically as the first operation in the routings you define. 
 

 ·        Click to perform additional work order setups.
