# Defining Timing Parameters per Operation

 

You can define operation parameters on three different levels, which function as a hierarchy: 
 

 ·        Operation parameters are first defined in the basic record of each operation. 
 

 ·        When you open a new part routing, the values already recorded appear by default in each operation in the routing. These values may then be revised for that specific routing. 
 

 ·        When you open a work order for a given part, the values recorded for the part routing appear by default in the routing for that work order. These values may then be revised for that specific work order. 
 

You can have MRP create a detailed work plan based on the parameters defined for each production operation and part. Then, if necessary, you can revise the operation parameters for each of the opened work orders.
