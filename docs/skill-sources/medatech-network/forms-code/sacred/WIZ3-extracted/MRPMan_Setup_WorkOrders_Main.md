# Setting Up Work Order Parameters

 

After calculating required part quantities, MRP plans the work orders needed to fill the demand. You can run MRP to open work orders according to an optimized work plan, provided that you define the relevant part parameters and assign work order templates. 
 

If you plan to have MRP open work orders, you can define a variety of parameters that affect work order size (e.g., minimum and maximum quantities, fixed increments). 
 

Parameters affecting production time can be defined either per part or per production operation. If you want MRP to schedule production automatically in a work plan, you need to define time parameters per operation. You also need to define the way work cells are displayed in the work plan Gantt chart. 
 

There may be a need to move up the due date of a sales order, such that it then precedes the end date of the work order opened (in a previous MRP run) to produce the ordered parts. A production constant determines whether the current run of MRP will still use the original work order to offset the demand generated by the sales order, or will ignore the work order and open a new one. 
 

You can also define a time range within which a new work order will not be opened if a work order is already open for that part, even if the completion date of the existing work order is later than the due date of the sales order it is supposed to fill. 
 

To automatically open work orders for parts produced by subcontractors, you need to define each subcontractor's priority and projected production capacity.
