# How Manual Issues Are Considered

 

By default, in kit lists, MRP takes into account the issue balance of parts that are defined as Kit Components (in the Parts form) or issued in bulk, but not of parts issued manually. If you change the value of the constant to 1 , MRP treats manually issued parts in the same manner as kit components and bulk parts. 
 
## To set the TakeIsKit constant:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the TakeIsKit constant and make sure the desired setting has been selected.
