MRP for Manufacturers - Analyzing MRP Results.3 
 
 
- 
 
 
 

 Demand from Work Orders: The quantity of child parts required by work orders for their parent parts (planned, opened or released), to which the child parts have not yet been issued. 
 

 Planned Work Orders: Work orders that were planned by MRP, in order to supply the calculated demand (when it is not possible to supply that demand using available and/or future inventory). 
 
## Notes:

 

 ·        Demand from safety stock does not appear as a separate line in the report, but is taken into account (for Type P parts only) when the first work order is planned (the defined quantity of safety stock is specified in each part's header in the report). 
 

 ·        Work orders that have already been released for parent parts for which MRP found no demand are not taken into account and do not generate part issues.
