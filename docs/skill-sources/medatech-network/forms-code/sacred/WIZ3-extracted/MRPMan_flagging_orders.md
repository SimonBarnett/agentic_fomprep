# Preparing Sales Orders and Forecast/Stock Orders for Consideration by MRP

 

When calculating demand dynamically on the basis of orders, MRP takes into account all open sales and forecast/stock orders that have been flagged for participation in MRP (and whose due dates fall within the planning period). Order items can be flagged for participation in MRP as the order is recorded, or afterwards (e.g., if the employee recording the order is not authorized to flag for MRP). Before you run MRP you must therefore ensure that all of the necessary line items (in all types of orders) have been flagged. 
 

You can either flag individual line items manually, or run a program that flags all lines in an order automatically.
