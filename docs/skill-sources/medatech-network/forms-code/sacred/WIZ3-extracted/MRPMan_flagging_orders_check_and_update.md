# To check and revise individual order items:

 

 1 .  Enter the Release Orders for Planning form. 
 

 2 .  Retrieve the order items that you want to check. Tips. 
 

 3 .  For each line, check the value in the MRP column. Revise if necessary. 
 
## Notes:

 

 ·        You cannot flag order items that are defined for routine consumption (i.e., assigned Required/Sold Qty and Freq. Of Need/Sale values in the Purchase/MRP Parameters for Part form). 
 

 ·        Click to return to the main screen.
