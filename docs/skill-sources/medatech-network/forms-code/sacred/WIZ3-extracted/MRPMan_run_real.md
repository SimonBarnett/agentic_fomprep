# Before you begin:

 

 ·        If you have run MRP simulations in order to arrive at the optimum configuration of settings and run-time options, you can run the View Dates & Chosen Options program to view the options chosen during the last run of MRP. 
 

 ·        Click if you are planning to choose the run-time option that allows MRP to take account of floor inventory. 
 
## To run MRP in real mode:

 

 ·        Run the Material Requirements Planning program and choose Open Work Orders .
