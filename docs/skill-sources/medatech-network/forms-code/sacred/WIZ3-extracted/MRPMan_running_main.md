# Running MRP for Manufacturers

 

The MRP for Manufacturers program can be run in two modes: Simulation and Real . 
 

 Simulation mode allows you to experiment with different combinations of settings and run-time options without committing your system to the results you receive. Each simulation you run results in planned work orders and raw material issues (viewable in special forms) that you can analyze and discard until you arrive at the configuration best suited to your company's needs. 
 

Once you have determined the optimum configuration for MRP, run the program in Real mode. In this mode, the program creates an actual raw material issues plan for the planned work orders, which is available for use by purchase planning. If the system has been set up to allow the automatic opening of work orders, MRP opens the work orders as well, adding the Release operation to the beginning of each routing. Finally, a run-time option allows you to create a work plan based on operation parameters and displayed in a Gantt chart.
