MRP for Manufacturers - Running MRP: Overview.3 
 
 
- 
 
 
 

Open purchase orders to vendors that are not defined as subcontractors represent the future entry of parts into inventory, and thus reduce demand. 
 

In addition, several run-time options allow you to reduce demand by: 
 

 ·        using parts already packaged for a customer to reduce demand generated by the same customer. 
 

 ·        reducing the demand generated by forecast/stock orders against existing inventory . 
 

 ·        taking into account final parts that have yet to be produced for open and released work orders. Explanation.
