# Planning Work Orders

 

Work order planning is dependent on the designated method of aggregating part demand, as well as on additional parameters defined per part, such as maximum and minimum work order quantity. 
 

When running MRP, you can choose one of two options for aggregating part demand: 
 

 ·        If you choose the On Monthly Basis option, the program will create a monthly demand for each part, which unifies all required quantities of that part in a given month. 
 

 ·        If you choose the By Demand Range option, the program will combine all required quantities of each part within the period defined for that part. If no range has been defined for a part, a separate work order is planned for each demand source (e.g., sales order, safety stock); in this case, the end date of each planned work order is taken from the corresponding due date for the part.
