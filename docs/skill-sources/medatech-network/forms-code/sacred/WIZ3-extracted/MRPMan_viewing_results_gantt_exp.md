# MRP for Manufacturers: The Gantt Chart

 

The Gantt chart displays the projected production time of each operation planned for a given work order. The operations are organized according to the work cells in which they are performed. The end of each operation is connected by an arrow to the beginning of the next operation in the work order's routing, enabling you to track the order of operations. Similarly, the last operation of the work order for a child part is connected to the parent part for which it was opened. 
 

You can view the Gantt program in various levels of detail (months, weeks, days). 
 

You can also manually alter the start and end times of operations, provided that this functionality has not been disabled via the MRP Gantt Chart Display Settings form; these changes will automatically affect the timing of the work orders and/or issues linked to those operations. Details. You can use the program's MRP Options menu to define parameters for these automatic effects, and to set a warning in cases where the manual modification of production times would cause a part to miss its due date.
