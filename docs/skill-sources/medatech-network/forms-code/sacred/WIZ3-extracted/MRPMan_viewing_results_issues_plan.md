# Viewing the Issues Plan

 

The issues plan displays raw material demands as calculated by MRP for production and resale, including the quantities required and the dates on which they need to be issued. This data is used by the Purchase Planning program to create purchase requisitions for the required parts, and by the Prepare Issues to Floor Stock program to prepare bulk issues to the plant floor (when issues are prepared on the basis of MRP). 
 
## To view the issues plan:

 

 ·        Run the Issues Plan report. 
 
## To view the planned issues of a particular part:

 

 ·        Enter the Purchase/MRP Parameters for Part form, retrieve the desired part, then enter the MRP Analysis - Raw Materials sub-level form. 
 
## Notes:

 

 ·        An issues plan is only created when you run MRP in real mode. If you run the Issues Plan report after running an MRP simulation, it will display the results of the last real MRP run. 
 

 ·        The MRP Analysis - Raw Materials form contains details that do not appear in the report. You can use this form if you want to understand how planned issues were calculated for a particular part. Example .
