# Viewing and Revising Opened Work Orders

 

If you used MRP to open work orders automatically, you should review the new work orders for errors and make any necessary revisions. These revisions will automatically update the work plan, if you chose to create one. 
 

If you set a tolerance value for work orders that were opened prior to the running of MRP, you may want to advance the production dates of those work orders that currently lag behind the due dates of their corresponding sales orders. 
 
## To view and revise work orders:

 

 1 .  Enter the Work Orders form. 
 

 2 .  Retrieve the opened work orders.
 Tip: Use the Opened Auto column (should be flagged in the Details tab) and the Date Opened column (using the MRP run date). 
 

 3 .  Check the details of each opened work order (e.g., production end date, subcontractor, project number) and revise them, if necessary. 
 
## To view and revise surplus work orders (that are lagging behind required due dates):

 

 1 .  Run the Work Orders to Expedite report. This report displays all work orders whose end dates fall after the due dates of the sales orders for which they were opened. 
 

 2 .  Click each work order number to open the work order and revise its production dates.
 
 
## Notes:

 

 ·        Click to view the work plan, if you chose to create one. 
 

 ·        For information about processing the work order, run the Work Orders Wizard .
