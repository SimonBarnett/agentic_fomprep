# To view the planned work orders:

 

 ·        Run the Analysis of MRP Results (ATP) report. 
 
## To view the planned work orders for a particular part:

 

 ·        Enter the Purchase/MRP Parameters for Part form, retrieve the desired part, then enter the MRP Analysis - Processed Parts sub-level form.
