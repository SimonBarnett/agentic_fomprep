# Viewing the Work Plan

 

MRP only creates a work plan when you run the program choosing the Create Work Plan runtime option. However, you may also create a work plan for a single work order by Direct Activation from the work order. Regardless of how the work plan is created, it may be viewed in a number of ways. 
 
## To view the work plan using the Gantt program:

 

 ·        Run the MRP Gantt Chart program. 
 
## Notes:

 

 ·        Depending on Gantt chart settings, you may also be able to update the work plan. See Restricting Use of the Gantt Chart . 
 

 ·        In order to appear in the Gantt chart, each work cell (or its department) must be assigned a work pattern. For more information, run the Factory Modelling Wizard . 
 

 ·        If you want to ensure that changes to the work plan remain within the bounds of the defined work pattern (e.g., when dragging the work order to a new time slot), click the upper MRP Options menu and flag the Enforce Work Pattern option. 
 

 ·        Click for an explanation of the Gantt program and its uses. 
 
## You can also run the following work plan and workload reports:

 

 ·        Work Plan 
 

 ·        Work Plan - Labor 
 

 Note: Before running this report, make sure that skills have been properly defined and assigned to the relevant operations. For more information, run the Factory Modelling Wizard . 
 

 ·        Work Cell Loads per Period 
 

 ·        Period Loads per Work Cell 
 
## To view the work plan for a specific work order:

 

 1 .  Enter the Work Orders form and retrieve the work order in question. 
 

 2 .  Enter the sub-level form, Work Plan for Work Order , to view the work plan.
