# Clearing the Customer Work Area

 

If the work area contains data from a previous session, you may want to clear it before loading a new set of records. Otherwise, the new records will be added to those already there. 
 
## To view existing data in the work area:

 

 ·        Enter the Customer Work Area form. 
 
## To clear the work area:

 

 ·        Run the Clear Customer Work Area program.
