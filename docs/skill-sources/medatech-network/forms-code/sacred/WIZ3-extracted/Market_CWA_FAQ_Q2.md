# Saving the Cross-section of Customers

 

You can easily save the set of customers currently appearing in the work area by assigning them a unique business classification (run the Assign Business Classif to Custs program). 
 
## Note:

 

While running the program, the Customer Work Area form opens so that records can be retrieved. To choose all the records, exit this form without changing its contents.
