# Fine-tuning the Work Area

 

After you have loaded the customer work area, you may find you need to fine-tune the results. Sometimes, the number of customers retrieved is simply too large. Other times, the criteria specified are too narrow, resulting in only a few customers loaded. 
 
## If too many records were retrieved:

 

 ·              Run the Clear Customer Work Area program and rerun the load program, specifying more criteria (such as an additional business classification). OR 
 

 ·              Delete any unwanted records. With the cursor on each record to be removed, click Delete Record From Work Area . 
 
## If too few records were retrieved:

 

 ·              Clean the work area and rerun the load program, specifying fewer criteria (such as fewer marketing events). OR 
 

 ·              Rerun the load program, specifying different criteria, without cleaning the work area first. The new records loaded are added to the existing ones. 
 
## Note:

 

Click to return to the Customer Work Area menu.
