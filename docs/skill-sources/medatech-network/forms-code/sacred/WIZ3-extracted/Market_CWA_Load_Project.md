# Load by Project

 

You can load into the work area those customers for which specific projects have been opened, together with one or more types of contacts for each customer. Customers are loaded per contact. In other words, if a customer has two contacts that meet the specified criteria, that customer will be loaded twice, once for each contact. 
 
## To load customers:

 

 1 .  Run the Load by Project program. In the input screen that opens, flag the desired contact types. 
 

 2 .  The Projects form opens. Retrieve the desired projects and exit the form. 
 

 3 .   Priority loads the Customer Work Area with records of any customers with the specified type(s) of contacts for which projects were selected, and reports how many records were loaded. 
 

 4 .  Enter the Customer Work Area form to see the customer records.
 Note: The E-mail in New Group column displays the e-mail or fax number as defined in the system .
