# Loading the Work Area

 

 Priority includes several programs to help make loading the work area quick and easy. There is also a program for loading customer records by more than one criterion at a time. 
 
## Note:

 

If the work area contains data from a previous session, the new records will be added to those already there. To start from scratch, click to clear the work area. 
 
## How do you want to load the work area?

 

 By business classification 
 

 By contacts 
 

 By marketing event or activity 
 

 By task 
 

 By project 
 

 By multiple criteria 
 
## Note:

 

Click to return to the Customer Work Area menu.
