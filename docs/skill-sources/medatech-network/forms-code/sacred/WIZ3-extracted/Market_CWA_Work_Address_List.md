# To print customer addresses:

 

 1 .  Run the Print Addresses from Work Area report. 
 

 2 .  When the work area opens, press F7 to remove any customers whose address you do not wish to include. 
 

 3 .  Exit the work area. The addresses of all customers displayed in the form will appear in the printed list.
