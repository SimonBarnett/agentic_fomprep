# To print a customer list:

 

 1 .  Run the Print Cust List from Work Area report. 
 

 2 .  When the work area opens, press F7 to remove any customers that you do not wish to include. 
 

 3 .  Exit the work area. All customers displayed in the form will appear in the printed list.
