# Preparing Mailing Labels

 

Before you begin, check with your system manager that the EXCELTITLE constant (in the System Constants form) is set to 1 . 
 

 1 .  Enter the Customer Work Area form. 
 

 2 .  Retrieve the records for which you want to prepare mailing labels. How? 
 

 3 .  From the File menu, select Send Data to Microsoft Excel . 
 

 4 .  From within Excel, copy and paste the desired columns (e.g., Customer Name , Street Address ) into an MS-Word file. 
 

 5 .  Use Word's Mail Merge feature to prepare the mailing labels.
