# Using the Work Area

 

Once you have loaded a sample of customers in the work area, you can perform any of the following operations on the chosen sample in a batch. 
 
## What do you want to do?

 

 Prepare mailing labels 
 

 Prepare a group 
 

 Assign business classifications 
 

 Record marketing events 
 

 Open tasks 
 

 Synchronize contacts with MS-Outlook 
 

 Print a list of customers from the work area 
 

 Print customer addresses from the work area 
 
## Note:

 

Click to return to the Customer Work Area menu.
