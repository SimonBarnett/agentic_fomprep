# Opening Tasks

 

You can use the work area to open the same task for all customers appearing in it. If you work with marketing campaigns, and you are opening a task related to a specific campaign, the system will automatically add all customers in the work area to the campaign. 
 
## To open tasks:

 

 1 .  Make sure the task has been defined in the Task Codes form. 
 

 2 .  Run the Open Tasks for Custs in W. Area program. The Customer Work Area opens. 
 

 3 .  Retrieve the customers for which you want to open tasks and exit the form. How? 
 

 4 .  In the input screen that appears, specify the details of the shared task: its date, the assigned user, its task code and its subject. 
 

 5 .  You also have the option of designating a marketing campaign; as a result, the system will open the defined task for all customers participating in this campaign. If any customers in the work area are not yet defined as sales opportunities for the selected campaign, they will be automatically added to it. 
 

 6 .  Click OK . Priority reports how many tasks were opened. 
 

 7 .  To view the tasks, enter the Tasks form.
