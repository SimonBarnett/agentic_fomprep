# To open a task for a sales opportunity:

 

 1 .  Enter the Tasks form and open a task in the regular manner.
 Tip: Click for more information about opening tasks . 
 

 2 .  Click the Campaign tab and specify the Campaign Code . A Sales Opportunity No. is filled in automatically, based on the pattern defined in the Document Numeration Templates form.
 Note : If you have been assigned to the campaign (in the Employees Involved in Campaign form), the Campaign Code is usually filled in automatically. 
 

 3 .  Record additional details in the task, such as customer contact information, a timed reminder or the other employees participating in the campaign. 
 
## Note:

 

If the current task code has been properly defined, completion of the task will advance the status of the sales opportunity.
