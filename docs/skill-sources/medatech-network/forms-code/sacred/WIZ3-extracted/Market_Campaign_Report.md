# To view the progress of sales opportunities in a campaign:

 

 ·        Enter the Marketing Campaigns form and retrieve the marketing campaign in question, then enter the Campaign Progress sub-level form. 
 

 OR 
 

 ·        Run the Campaign Progress Analysis report, or the Analyze Progress (Work Area) program, indicating the code of the campaign whose progress you want to check. 
 Note: The report adds the option of viewing inactive customers as well as active ones, and can be printed out.
