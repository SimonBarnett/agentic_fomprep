# Printing Sales Opportunity Documents

 
## To print a single document:

 

 1 .  Enter the Sales Opportunities form and retrieve the document in question. 
 

 2 .  Select Print Sales Opportunity Info from the list of Direct Activations . 
 
## To print several documents:

 

 ·        Run the Print Sales Opportunity Info report.
