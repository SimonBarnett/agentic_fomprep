# Setting Up Marketing Campaigns

 

Marketing campaigns are carried out via activities (tasks, quotes and orders) completed for individual customers, as documented in individual sales opportunity documents (one per customer and campaign). The progress of the campaign is reflected in the current status of each sales opportunity, which determines the probability of its successful closure. You can also define the degree of urgency with which each sales opportunity should be handled. 
 
## What do you want to do?

 

 Create a list of sources for sales opportunities 
 

 Set up sales opportunity types 
 

 Create a list of reasons for a failed sales opportunity 
 

 Set up BPM for sales opportunities 
 

 Define odds of closure 
 

 Define urgency rankings
