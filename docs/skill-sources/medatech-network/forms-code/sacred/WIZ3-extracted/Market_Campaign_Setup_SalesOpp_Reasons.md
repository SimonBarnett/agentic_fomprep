# Creating a List of Reasons for Failed Sales Opportunities

 

You need to list possible reasons for sales opportunities that fall through (e.g., purchased from competitors, insufficient budget). 
 
## To define reasons for failed sales opportunities:

 

 ·        Enter the Reasons for Sales Opp Failure form and list each possible reason for a failed sales opportunity. 
 
## Note: 

 

You can add more reasons later, as needed.
