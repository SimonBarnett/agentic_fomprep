# Setting Up Sources for Sales Opportunities

 

The source of a potential sale may be anything, ranging from a specific person to a newspaper ad your company has run. 
 

As these values can also be used to generate new leads, they are recorded in the same form as lead sources. 
 
## To create a list of sources:

 

 ·        Enter the Sources of Leads/Sales Opps form and record each source on a separate line. 
 
## Tip: 

 

You can add more sources later, as new campaigns are opened.
