# Working with Outlook Categories

 

 Priority enables you to import categories from Outlook, copy Outlook categories from a different Priority user, or create new ones. The Outlook categories you have defined in Priority can also be exported to Outlook. 
 

In this way, you can routinely back up your Outlook categories to Priority and restore them if necessary (e.g., after replacing your computer or reinstalling the operating system). 
 
## To import Outlook categories into Priority :

 

 ·        Run the Import Categories from Outlook program. 
 
## To copy Outlook categories from a different Priority user:

 

 ·        Run the Copy User Categories program. Then load the new categories into Outlook (see below). 
 
## To view or update Outlook categories saved in Priority :

 

 ·        Enter the List of Outlook Categories form. 
 
## To export Outlook categories from Priority and load them into Outlook:

 

 ·        Run the Export Categories to Outlook program.
