# Setting Up Business Processes for Sales Opportunities

 

Business processes for sales opportunities are set up by defining statuses – and the paths that connect them – in a BPM flow chart. The rules that govern these paths determine the status an opportunity acquires when a specific activity is performed (e.g., task, price quote, sales order). The progress of a marketing campaign can be ascertained by tracking the statuses of the sales opportunities of which it is composed. 
 

There are several predefined statuses for sales opportunities, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 

In addition, if you work with BI reports for sales opportunities, you must assign each status a unique status code. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Sales Opps program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Sales Opportunities form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide . 
 
## To assign status codes to sales opportunity statuses:

 

 1 .  Enter the Statuses for Sales Opportunities form. 
 

 2 .  Move to the More Definitions sub-level form and assign each status a unique Status Code .
