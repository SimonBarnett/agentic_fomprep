# Setting Up Business Parameters and Classifications

 

You can assign an unlimited number of business classifications to customers, vendors and their contacts using the relevant sub-levels of the Customers and Vendors forms. Example. They can also be assigned to customers automatically during the initial survey, or via the Customer Work Area. 
 
## To define parameters and classifications:

 

 1 .  Enter the Business Classific. Parameters form and record a code and description for each parameter. 
 

 2 .  Enter the Possible Classific per Parameter sub-level form and record a description for each corresponding classification. You can either define the classification code manually, or allow Priority to assign the code automatically when you leave the line. 
 
## Notes:

 

 ·        To record business classifications without parameters (e.g., for contacts), use the Business Classification Codes form instead. 
 

 ·        Click to perform additional setups .
