# Setting Up Customer Groups

 

You can classify your customers into groups, for easy retrieval and focused reporting. Groups allow you to open tasks and activities for multiple customers without designating them individually. 
 

Alternatively, you can create a multi-level hierarchy of business classifications , which can be used to load customers into the Customer Work Area. 
 
## To define customer groups:

 

 1 .  Enter the Customer Groups form and record a code and description for each group.
 Note for dual-currency users working in languages other than English: You can record a group description in English in the Group De s c. (Lang 2) column. 
 

 2 .  Specify the relevant Sales Rep Number for the current group. 
 

 3 .  Enter the Customers in Group sub-level form and list the customers you want to include in the group.
