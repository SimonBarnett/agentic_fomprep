# Setting Up Leads

 

Leads are usually imported from e-mail messages received in MS-Outlook, but may also be recorded manually. They can then be used to open potential customers, which can be included in marketing campaigns. To set up for work with leads, you need to define lists of possible values for lead sources, lead types and urgency rankings (used to prioritize marketing tasks). 
 
## To create a list of lead sources:

 

 ·        Enter the Sources of Leads/Sales Opps form and record each source on a separate line. 
 
## To create a list of lead types:

 

 ·        Enter the Types of Leads form and record each type on a separate line. 
 
## To create a list of urgency rankings:

 

 ·        Enter the Urgency Ranking form and record each ranking on a separate line.
 Note: These rankings are also used to prioritize sales opportunities. 
 
## Tip: 

 

You can add more definitions to these forms later, as new leads are recorded.
