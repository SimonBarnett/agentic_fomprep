# Setting Up Tasks

 

 Priority enables you to plan tasks and schedule employees to perform them. You can also use tasks to track marketing events and other business activities. 
 

Before recording tasks, you need to create a list of task codes. Example. In addition, you can create a check list for each task code, i.e., a list of sub-tasks to be opened automatically when any task is assigned that task code. Example. 
 

You can also record a list of task types in order to classify your tasks into groups. Example. Finally, you can define different set text for each task type. This text will appear automatically in the remarks form of any tasks assigned that type, where it may be revised. You can then assign each employee a default task code, type and start time, which will appear automatically in any task that employee is assigned. You can also assign personal office hours to each employee, which further aids in scheduling tasks. 
 

To maintain tasks, you can also set up business processes (statuses), as well as the colors used to display tasks in the calendar.
