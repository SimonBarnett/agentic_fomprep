# Creating a Check List for a Task Code

 

You can predefine a list of tasks that must be performed as part of a standard process such as employment termination. This check list is linked to a relevant task code, such that tasks are opened automatically based on the check list whenever that task code is assigned to a task. 
 

Each task that is opened in this manner receives the designated status and appears in the Tasks for Document sub-level form under the "main task" for which it was opened. Each of these sub-tasks must be completed before the main task can be flagged as Done . 
 
## To create a check list for a task code:

 

 1 .  Enter the Task Codes form and retrieve the desired task code. 
 

 2 .  Enter the Check List for Task Code sub-level form and select the employee to whom the task will initially be assigned. 
 

 3 .  Record a Subject for the task, and select a Task Code and Task Type , if desired. 
 

 4 .  Select the Status to be assigned to the task, when opened. 
 

 5 .  Do one of the following: 
 

 ·              To open the task for the date on which it is created, leave the Day of Month and Next Month columns blank. 
 

 ·              To open the task for a specific day of the current month, indicate the desired day of the month and leave the Next Month column blank. 
 

 ·              To open the task for the first day of the following month, leave the Day of Month column blank and flag the Next Month column. 
 

 ·              To open the task for a specific day of the following month, indicate the desired day of the month and flag the Next Month column.
