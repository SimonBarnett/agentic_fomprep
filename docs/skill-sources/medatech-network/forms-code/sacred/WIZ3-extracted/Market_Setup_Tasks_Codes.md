# To record a list of task codes:

 

 1 .  Enter the Task Codes form and record a task code and its description. 
 Note s : 
 

 ·              There are several predefined task codes (e.g., for incoming and outgoing mail). 
 

 ·              Tasks can be defined from within most system documents. Define your codes accordingly, for tasks opened from within sales orders, service calls, etc. 
 

 2 .  A check mark initially appears next to each task code in the Interface w/Outlook column, indicating that tasks with this code will be exported automatically to MS-Outlook. Remove the check mark next to any task codes you do not want to export. 
 Note: You can also flag tasks to synchronize with Outlook by task type (in the Task Types form); use that form when you want to flag tasks using a broader criterion than task code. 
 

 3 .  Flag the Appointment column for task codes representing appointments and meetings (whose start time differs from their end time). These task codes are used to define employee shifts and default settings for new tasks.
 Note: Tasks with a task code that is flagged as an Appointment will appear in the Calendar and the Appointment Calendar .
