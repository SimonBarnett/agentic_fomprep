# Setting Calendar Colors

 

The calendar displays appointments for each designated user. All appointments are created from tasks with distinct start and end times. You can distinguish between tasks (appointments) in the calendar based on their task status or their task code. Any task that does not have a color receives the default task color. 
 
## Before You Begin

 

 ·        Enter the Colors for Calendar form. Note the default colors for each type of calendar entry, in order to make sure not to assign these same colors. 
 
## To assign colors per task status:

 

 ·        Run the BPM Flow Chart-Tasks program. Right-click on each status and select Set Color . 
 
## To assign colors per task code:

 

 ·        Enter the Task Codes form. For each code, select a color in the Color in Calendar column. 
 
## Tip: 

 

Use a bright color (e.g., red) for the status/code requiring the most urgent attention.
