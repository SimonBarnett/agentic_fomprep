# Default Definitions per Employee

 

Assign a default task code and task type to any employee who is usually scheduled for the same type of task. Assign a default task time for any employee who usually begins to perform tasks at a set time of day. You can also assign personal office hours (e.g., for a part-time employee). 
 

These defaults will appear automatically whenever this employee is assigned a task, but may be revised. The system will issue a warning whenever you try to assign a task that falls beyond the employee's personal office hours. 
 
## To assign default definitions:

 

 1 .  Enter the Personnel File form and retrieve the desired employee. 
 

 2 .  Click the Definitions tab and record the desired start time in the Default Task Time column. 
 

 3 .  Enter the Company-Specific Information sub-level form and select the Task Code and Task Type for this employee. 
 

 4 .  Enter the parallel Office Hours per Employee sub-level form and record the employee's work days and hours.
 Tip: To view and/or change office hours for the entire company, use the Office Hours form.
