# Defining Durations for Appointments

 

You can predefine possible durations for tasks that are defined as appointments. You can then select the relevant duration manually for a given appointment, or assign a default duration to appointments opened for employees in a particular branch. 
 
## To define appointment durations:

 

 ·        Open the Appointment Durations form and record possible durations in hours and minutes (e.g., 000:30).
