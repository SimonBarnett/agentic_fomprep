# Setting Up Task Retrieval

 

The Tasks for Customer sub-level form displays opened tasks. To ensure that the amount of records retrieved in this form suits your needs, set the constant which determines the number of days back to begin automatic retrieval of tasks. 
 
## To determine how far back to retrieve tasks:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the STaskDays constant and, in the Value column, specify the number of days back to retrieve tasks (the default is 90 days). 
 
## Note: 

 

E-mails to and from customer and vendor contacts automatically open a task for the user who received or sent the message. To disable this automatic mechanism, select Options from the Mail menu in the Top Bar and remove the check from the "Record e-mail as customer/vendor tasks" option.
