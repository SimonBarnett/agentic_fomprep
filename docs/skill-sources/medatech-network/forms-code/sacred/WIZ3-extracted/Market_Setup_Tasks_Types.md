# To record a list of task types:

 

 1 .  Enter the Task Types form and record the desired task types. 
 

 2 .  A check mark initially appears next to each task type in the Interface w/Outlook column, indicating that tasks of this type will be exported automatically to MS-Outlook. Remove the check mark next to any task types you do not want to export. 
 Note: You can also flag tasks to synchronize with Outlook by task code (in the Task Codes form); use that form when you want to flag tasks using a narrower criterion than task type. 
 

 3 .  A check mark initially appears next to each task type in the Display for You column. Remove the check mark next to any task types that do not interest you (e.g., types recorded by other users). Tasks of these types will no longer appear for you during task retrieval or when viewing a task summary (but other users will continue to see them). 
 Note: To hide task types with respect to a given customer's tasks, enter the Customers form, retrieve the customer in question, enter the Task Types to Display sub-level form and remove the check mark from the same column ( Display for You ). 
 

 4 .  Flag the Marketing column if you want tasks with the current task type to be linked automatically to a sales opportunity. When a task with this task type is opened for a given customer, and there is currently an open sales opportunity for the customer in question, it will be linked to the new task automatically. 
 

 5 .  Enter the Set Text for Task Type sub-level form and record set text for tasks of this type.
 Tip for dual-currency users: If you are working in a language other than English, and wish to print out tasks in English, record set text in English in the Set Text for Task Type - Lang 2 sub-level form. Set text in English will appear in any task opened for a customer or vendor defined to receive Printouts in Lang 2 .
