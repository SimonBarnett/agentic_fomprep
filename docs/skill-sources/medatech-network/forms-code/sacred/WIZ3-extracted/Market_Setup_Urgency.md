# Defining Urgency Rankings

 

Urgency rankings enable sales reps to prioritize the sales opportunities assigned to them. Each urgency ranking is assigned a contact frequency, indicating how often the customer should be contacted in sales opportunities with that ranking. 
 
## To create a list of urgency rankings:

 

 ·        Enter the Urgency Ranking form and record each ranking on a separate line. 
 
## Note:

 

These rankings can also be assigned to leads.
