# To record the completion of a task:

 

 1 .  Enter the Tasks form and retrieve the task. 
 

 2 .  Flag the Done column or change the task status to Completed . The end date is filled in automatically. 
 
## Notes:

 

 ·        If sub-tasks are defined for this task (in the Tasks for Document sub-level form), you will not be able to record completion of this task unless all of its sub-tasks are flagged as Done . 
 

 ·        If the user who originally recorded the task is not the user who closed it, the former will receive e-mail notification along with an attachment of a print version of the task. 
 

 ·        You can also change the task status by accessing the parallel appointment in the calendar. 
 

 ·        To close a batch of tasks that have been assigned to a given user, run the Close Tasks program.
