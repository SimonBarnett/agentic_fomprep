# Duplicating Tasks

 

If there is a task that recurs frequently (for example, a staff meeting), you can copy it, automatically creating identical tasks for the same day and time on subsequent weeks. All task details are duplicated including text, customer, participants and resource allotment. 
 
## To duplicate a task:

 

 1 .  Enter the Tasks form and retrieve the task in question. 
 

 2 .  Select Duplicate a Task from the list of Direct Activations .
 Note: This program can also be run from the Customer Relations Management menu.
