# Recording an Appointment in the Calendar

 

The calendar displays all existing appointments, taking into account defined office hours, holidays and employee absences. It can also be used to create new appointments (and revise existing ones). The program can be run from the menu or from within a specific task. 
 
## To run the program from the menu:

 

 ·        Run the Calendar . 
 
## To run the program from within a task:

 

 1 .  Enter the Tasks form and retrieve the task in question. 
 

 2 .  Select Calendar from the list of Direct Activations . 
 
## To add an appointment:

 

 1 .  Make sure the appropriate employee and date appear in the calendar. 
 

 2 .  Double click in the appropriate time slot or press Insert . 
 

 3 .  The Tasks form opens with certain data already filled in. Complete the necessary information and exit the form. The new appointment will automatically appear in the calendar.
