# Tips (continued)

 

 ·        To view the details of an appointment, press F11 . To change those details, double click on it or press F6 . 
 

 ·        To print an appointment, right-click its time slot and select Print Task . 
 

 ·        Additional function keys: 
 

 ·              Shift+ F4 – change view (toggles between horizontal display of hours, vertical display of hours and Gantt chart).
 Windows users: Press F4 instead of Shift+F4 . 
 

 ·              Ctrl+F11 – refresh screen. 
 

 ·              Tab/Shift+Tab – move to the next/previous appointment. 
 

 ·              Ctrl+ Del – delete the current appointment. 
 
## Notes:

 

 ·        Any change to an appointment updates the Tasks form. 
 

 ·        When adding an appointment in a multi-company environment (where the Tasks form has been designated a multi-company form), use the File menu to select a default company in which to always open appointments. Or select “No Company”, and manually designate the appropriate company for each opened appointment. 
 

 ·        Click to return to the Tasks and Appointments menu.
