# Handling an Open Task or Appointment

 

Once a task or appointment is opened, you can view its details and make any desired revisions. 
 
## To revise an appointment:

 

 ·        Run the Calendar and access the appointment. 
 Note: Click for tips on using the calendar. 
 
## To handle an open task:

 

 1 .  Enter the Tasks form, and retrieve the desired task(s). Retrieval tips. 
 Notes: 
 

 ·              If you have limited the types of tasks you will be viewing (during the setup), you will not be able to retrieve tasks of the excluded types. To revise those definitions, enter the Task Types form and flag the task type you wish to have displayed (in the Display for You column). If it is already flagged, enter the Customers form and retrieve the customer whose tasks you wish to view. Then enter the Task Types to Display sub-level and flag the task type you wish to have displayed (in the Display for You column). Then repeat the retrieval procedure. 
 

 ·              To view a summary of all tasks ever recorded for the current customer (regardless of assigned user), select Task Notes for Customer from the list of Direct Activations or enter the Tasks for Customer sub-level form. Any limitations on the task types you can view apply here as well. 
 

 ·              Another way to access your own tasks is to enter the To Do List and retrieve all items you are responsible for. Where the Document Type is “Task”, move to the Document Number column and press F6 .
