# Tasks and Appointments

 

Tasks are assigned to one or more users and linked to customers/vendors and their contacts. Appointments are maintained in a graphic interface calendar, and include such information as the customer and contact involved. 
 

Any task whose start time precedes its end time automatically opens an appointment for each assigned user, and updates of the task revise appointment details in the calendar. Conversely, any appointment opened or updated in the calendar opens or updates a parallel task. 
 
## Note:

 

If a task is linked to a project, you can report labor hours and other expenses for the project directly under the task. For more information see the topic, “Reporting Work Hours and Travel Expenses” in the Project Management Wizard .
