# Opening a Task or Appointment

 

Tasks can be recorded manually, thereby opening a parallel appointment, and appointments can be opened in the calendar, thereby opening a parallel task. Appointments and tasks can also be imported from MS-Outlook (from the Outlook calendar and Outlook e-mail messages, respectively). In addition, they are opened automatically within Priority under certain circumstances: 
 

 ·        when employees are scheduled for a service call, warehouse assembly, project activity or sales order, or when a check list is defined for orders of a given sales type. 
 

 ·        when the Open Tasks for Custs in W. Area program is run, using the Customer Work Area 
 

 ·        whenever an e-mail message is sent to or received from a customer/vendor via the internal mail system. You can easily disable this mechanism if you wish. Explanation. 
 

 ·        when the Open Task for Message program is run from within an incoming or outgoing internal mail message. 
 

 ·        when a task is assigned a task code for which a check list has been defined (in the Check List for Task Code sub-level of the Task Codes form). 
 

 ·        when a sales opportunity reaches a designated status, provided that a check list of tasks has been linked to the progress of sales opportunities in the relevant marketing campaign (in the Check List for Sales Opps sub-level of the Marketing Campaigns form).
