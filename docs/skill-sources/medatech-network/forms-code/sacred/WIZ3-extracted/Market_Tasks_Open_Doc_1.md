# To open a task manually for a specific document:

 

 1 .  Enter the relevant form and retrieve the desired document. 
 

 2 .  Enter the Tasks for Document sub-level form. 
 

 3 .  Specify a Start Date for the task. The Task Number will appear automatically. 
 

 4 .  Revise any task details that were filled in automatically with default values (e.g., Assigned To , Subject , Task Code ), as needed. 
 

 5 .  If the task is for the customer or vendor for which the document was opened, select the appropriate contact (in either the Contact or Vendor Contact column, respectively). The corresponding contact information will appear automatically. 
 

 6 .  If the task is an appointment, in which additional employees from your company will participate, select the relevant individuals or groups in the Participant or Group columns.
 Note s : 
 

 ·              The system will automatically update the calendar of each employee assigned to the appointment, and alert them with an e-mail message. 
 

 ·              To select a group, you need to be authorized to access it. Contact your system manager if you do not have the necessary permissions. 
 

 7 .  If certain resources are required for the appointment (e.g., a projector), you can select up to three items in the Resource columns that will be reserved for the appointment.
 Tip: To view the projected usage of a given resource and/or to add resources to the Choose list, use the Resources form and its sub-level, Planned Resource Utilization . 
 

 8 .  Record a brief Remark regarding the current task. 
 

 9 .  To fill in additional details for this task (e.g., a reminder), press F6 from the Task Number column.
