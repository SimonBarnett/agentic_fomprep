# Additional Setups

 

A number of setups must be performed periodically, both in Priority and in Outlook. 
 
## To prepare for synchronizing calendars:

 

 1 .  In Priority : If you are exporting tasks from Priority to Outlook, make sure that task codes and task types are properly defined. Only those tasks whose type or code is flagged to Interface w/Outlook in the Task Types or Task Codes form, respectively, will be updated in Outlook when the program is run. 
 

 2 .  In Outlook: If you are importing appointments from Outlook to Priority , be sure to flag any appointment you want to be excluded as Private in Outlook. 
 
## To prepare for importing Outlook contacts:

 

 1 .  In Outlook: Choose a color and assign it to any Outlook contact you wish to import. This will be changed (or cleared) when the synchronization program ends.
 Note s : 
 

 ·              Depending on the method used to create Priority tasks from Outlook messages, the same color may be used to select e-mail messages that are imported as Priority tasks. 
 

 ·              In Office 2007 and higher, contacts are linked to category colors. In older versions, colored flags are assigned. 
 

 2 .  When updating data on an existing contact in Priority , if any Outlook contact is linked to more than one customer in Priority , use Outlook categories to distinguish between the customers. That is, create a category in Outlook for each one (use either the Priority customer number or a unique string from the Priority customer name). Do the same for any contact linked to more than one vendor. Then assign the appropriate category to each Outlook contact.
 Note: Depending on the method used to create Priority tasks from Outlook messages, the same categories may be used when importing e-mail messages. 
 
## Creating Tasks or Service Calls from Outlook Messages

 

There are two ways with which to define those Outlook messages that will be used to create tasks or service calls in Priority : 
 

 ·        In Office 2007 and higher, you can use the Synchronize with Priority command. This allows you to prepare Outlook messages for synchronization even when working in Offline mode and even when Priority is not open. It also enables you to choose the customer for which the task or call is opened, as well as the assigned user. 
 

 ·        You can use colors and categories.
