# To set up synchronization options in Priority :

 

 1 .  Open the Mail menu on the Priority Top Bar, and select Synchronize with Outlook . 
 

 2 .  To synchronize calendars, indicate what to update (only Priority , only Outlook, or both). If you do not want to synchronize calendars, flag the No Update box.
 Note: Your permissions (as defined in the User Permissions form) may limit you to synchronization in only one direction. 
 

 3 .  To import contacts from Outlook, flag the appropriate box. Designate the color that you have assigned to contacts (under Task definitions), as well as the color to assign after the program is completed. 
 

 4 .  When using colors and categories to create tasks and service calls from Outlook messages, flag the appropriate boxes and choose whether messages will be imported as open or closed tasks. If you have not already defined colors for contacts, designate the color that you have assigned to your Outlook messages for tasks, as well as the color to assign after the program is completed. Also designate the color you have assigned to your Outlook messages for service calls, as well as the color to assign after the program is completed.
 Note: This is not necessary if you use the Synchronize with Priority command (available in Office 2007 and higher). 
 

 5 .  To update Outlook tasks based on your to-do list, flag the appropriate box. 
 

 6 .  If you have multiple mail folders defined in Outlook, specify the Outlook Folder to which e-mail is to be sent during synchronization. 
 

 7 .  Specify the Priority company with which to synchronize Outlook. Regardless of the Priority company you are working in when a scheduled synchronization is performed, Outlook will be synchronized with the specified company. 
 Note: The company you are working in when you set this option is the default. 
 

 8 .  Indicate the interval at which you want automatic synchronization to occur.
 Note: You can also run the synchronization program manually.
