You can add columns to Outlook based on any of the parameters used for synchronization with Priority . Such columns can be used to update synchronization parameters and flag messages for synchronization directly from the Messages pane. You can also use the standard grouping and sorting tools in Outlook to arrange your messages according to any of these columns. For instance, you can use these tools to easily locate all messages that have been successfully synchronized for a particular customer. 
 

Use Outlook's Field Chooser tool to add any of the synch parameters to Outlook as a user-defined field that displays the relevant Priority data. For instance, use it to add the Synch ronize with Priority field, which when flagged indicates that the current message is to be (or has been) synchronized with Priority , or the Completed Sync with Priority field, which will be flagged once the message has been successfully synchronized (indicating that a corresponding task or service call has been opened in Priority ). 
 
## To add user-defined fields to Outlook:

 

 1 .  From the Inbox, right click on any column heading and select Field Chooser from the drop-down menu. 
 Note: Click if you do not see any column headings in the Messages pane. 
 

 2 .  Click the arrow at the top of the Field Chooser dialog box, scroll through the items in the drop-down menu and select User-defined fields in Inbox . 
 

 3 .  Use the mouse to drag the desired field to any location in the header bar. 
 

 Notes: 
 

 ·        The same procedure can be used in other folders besides the Inbox (e.g., Sent Items). In this case, select User-defined fields in folder from the drop-down menu at the top of the Field Chooser dialogues box. 
 

 ·        The above instructions apply to Outlook 2007. Later versions of Outlook may work slightly differently. 
 

You can also enable in-cell editing in Outlook, allowing you to edit or flag any relevant columns (or remove the check mark) within the Messages pane. This enables you to define synchronization parameters and flag messages for synchronization directly from the Messages pane, rather than selecting the Synchronize with Priority option. 
 
## To enable in-cell editing in Outlook:

 

 1 .  Right click on any column heading and select Customize Current View from the drop-down menu. 
 

 2 .  In the dialog box that opens, click Other Settings . 
 

 3 .  Flag the A llow in-cell editing check box and click OK . 
 

 Note: 
 

The above instructions apply to Outlook 2007. Later versions of Outlook may work slightly differently.
