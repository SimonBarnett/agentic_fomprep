# Synchronizing Appointments, Contacts and To-Do Items With Microsoft Outlook

 

A bilateral interface with MS-Outlook facilitates appointment, contact and task maintenance in and out of the office. Specifically, it can be used to: 
 

 ·        synchronize calendars 
 

 ·        import customer and vendor contact information from Outlook to Priority 
 

 ·        create new tasks and/or service calls based on Outlook e-mail messages 
 

 ·        update Outlook tasks with to-do items 
 

You can set up the synchronization mechanism to operate automatically at regular intervals, or you can run it manually. 
 

Additional programs allow you to export customer and vendor contact information and tasks from Priority to Outlook, and to import Outlook categories into Priority and vice versa, for backup and recovery purposes. 
 

You can also run a program that sends an e-mail message with attached appointment information to all task participants (users, customer/vendor contacts), which can then be uploaded into their Outlook calendars. 
 
## Note: 

 

When synchronizing tasks between Priority and Outlook, Priority tasks that have been assigned the "Canceled" status will be deleted from the Outlook task log. Similarly, the deletion of an Outlook task will cause the parallel Priority task to receive the "Canceled" status.
