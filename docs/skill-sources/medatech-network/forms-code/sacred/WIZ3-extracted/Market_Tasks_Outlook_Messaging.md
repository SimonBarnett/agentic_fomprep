# Sending Appointment Information (for Outlook) to Participants

 

You can send appointment details to participants who may not have access to Priority (e.g., users working remotely, customer/vendor contacts). The scheduling information can then be uploaded directly into the recipient's Outlook calendar. 
 

An e-mail is sent to each participant with a file attachment. When the recipient opens the attachment, an appointment containing all details of the meeting, as they were recorded in Priority (e.g., participants, start time, end time), is opened in the Outlook calendar. 
 

Before you begin, you therefore have to insure that all participants have e-mail addresses defined in Priority . 
 
## To define an e-mail address for a user:

 

 1 .  Enter the Personnel File form and retrieve the desired user. 
 

 2 .  Click the Address and Phone tab and check that an e-mail address has been defined for this user. If not, record it now.
