# To send reminders of an appointment:

 

 1 .  Enter the Tasks form, and retrieve the desired task(s). Retrieval tips. 
 

 2 .   Move to the References tab and flag the Remind column. 
 

 3 .   In the Hrs/Mins in Advance column, specify the desired number of hours and/or minutes in advance of the appointment to make the reminder (e.g., 00:30). The system will send the scheduled user an e-mail reminder prior to the upcoming appointment, based on this value.
