CRM - Tasks and Appointments: Viewing.1 
 
 
- 
 
 
 
## To view appointments:

 

 ·        Run the Calendar program. 
 Note: Click for instructions. 
 
## To view tasks assigned to a specific employee:

 

 ·        Run the Tasks per Assigned User or the Tasks per User - Detailed report. 
 
## To view tasks that have been/are being taken care of:

 

 ·        Run the Reported Tasks in This Co. report. 
 
## To view tasks recorded for a specific customer:

 

 ·        Run the Tasks per Customer report. 
 
## To view tasks with the same task code:

 

 ·        Run the Tasks per Task Code report. 
 
## To view tasks opened for a specific project or project activity:

 

 ·        Run the Tasks per Project or the Tasks per Project Activity report. 
 
## To view tasks per customer, project or project activity:

 

 1 .  Enter the Tasks form and retrieve any task for the customer or project in question. 
 

 2 .  Select Tasks per Customer and Project from the list of Direct Activations .
