CRM - Tasks and Appointments: Viewing.2 
 
 
- 
 
 
 
## To view a customized summary of the tasks opened for a specific customer or for customers with the same sales rep:

 

 ·        Run the Task Notes for Customer report, OR 
 

 ·        Run the Task Summary per Sales Rep report. 
 
## To view a summary of customers that were not contacted on schedule, per sales rep:

 

 ·        Run the Infrequent Customer Contact report. 
 
## To view a detailed list of customers that were not contacted on schedule, per sales rep:

 

 ·        Run the Details of Infreq. Cust. Contact report. 
 
## To view a customized summary of the tasks opened for a specific vendor:

 

 1 .  Retrieve the vendor in the Vendors form. 
 

 2 .  Select Task Summary for Vendor from the list of Direct Activations . 
 
## To view a customized summary of vendor tasks that are still open:

 

 1 .  Retrieve the vendor in the Vendors form. 
 

 2 .  Enter the Tasks for Vendor sub-level form. 
 

 3 .  Select Open Tasks for Vendor from the list of Direct Activations . 
 
## Notes:

 

 ·        To customize the reports that display task summaries, enter the Task Types form and delete the check mark next to any task types you are not interested in viewing. This will affect all subsequent runs of the reports, as well as retrievals of tasks. It will not affect other users. 
 

 ·        Click to return to the Tasks and Appointments menu.
