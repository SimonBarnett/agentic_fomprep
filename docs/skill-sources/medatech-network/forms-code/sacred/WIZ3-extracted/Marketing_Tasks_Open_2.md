# To open a task manually for a specific customer or vendor:

 

 1 .  Enter the Tasks form. 
 

 2 .  Record a Subject for the new task. A Task No. appears automatically. 
 

 3 .  If you are assigning the task to another user, click the Definitions tab and change the username in the Assigned to column.
 Tip: For help in scheduling one or more employees for a task, use one of the calendars in the sub-level forms, or select Calendar from the list of Direct Activations . Explanation. 
 

 4 .  The assigned user's default Task Code and Task Type appear automatically. Revise them if necessary.
 Note: If a check list has been defined for the designated task code (in the Check List for Task Code sub-level of the Task Codes form), any tasks in this check list are opened automatically and appear in the Tasks for Document sub-level form. These sub-tasks can be revised as necessary. 
 

 5 .  Return to the Definitions tab. The current date and time appear automatically in the Start Date/Time and End Date/Time columns. Fill in the correct values.
 Note: For a task that does not have a set time (e.g., a phone call), leave the default time. 
 

 6 .  If you are setting a reminder for the task, move to the References tab and flag the Remind column. In the Hrs/Mins in Advance column, specify the desired number of hours and/or minutes in advance of the appointment to make the reminder (e.g., 00:30). The system will send the scheduled user an e-mail reminder prior to the upcoming appointment, based on this value.
