# To reassign an employee to a production department:

 

 1 .  Enter the Personnel File form and retrieve the desired employee.
 Tip: You can use the employee's username in the User column of the General tab. 
 

 2 .  Enter the Company-Specific Information sub-level form and specify the new Department to which to assign this employee.
