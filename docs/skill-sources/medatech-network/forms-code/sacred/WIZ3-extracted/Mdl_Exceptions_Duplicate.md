# To define a work exception: 

 

 1 .  Enter the Work Exceptions form. 
 

 2 .  For each new exception, specify a code and description. 
 

 3 .  In the Type column, specify A if the exception adds hours to the usual work pattern (e.g., an extra shift during a busy season), or B if the exception represents a break in the usual work pattern (e.g., a holiday). 
 

 4 .  In the Start and End columns, specify the dates at which the exception takes effect and expires (if the exception is for a single day, use the same date in both columns). The respective days of the week appear automatically. 
 

 5 .  If the exception does not cover the entire day, enter the Exception Timetable sub-level form and specify the Start and End times of the exception period on each day. The resulting Span appears automatically.
