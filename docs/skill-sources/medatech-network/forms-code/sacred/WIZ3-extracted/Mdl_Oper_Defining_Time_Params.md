# Defining Standard Machine and Employee Time 

 

For each operation performed in a work cell, you need to define the standard work time for unskilled employees ( E ) and machines ( T ). Employee/machine time is recorded in minutes and can either be constant for all such operations, or vary according to the part undergoing the operation. 
 

When skilled employees are working the machines, you need to record the number of employees and their skills; if skilled employees are only required part of the time the machine is running, employee time is defined as a percentage of the machine time. 
 

 E and T times are carefully measured on the plant floor. In the case of a temporary or permanent change in these values, Priority provides a time factoring mechanism that allows you to apply different time values without changing the recorded standard values.
