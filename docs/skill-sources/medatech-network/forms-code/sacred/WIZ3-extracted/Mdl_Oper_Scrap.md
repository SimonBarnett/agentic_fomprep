# Defining Scrap

 

Scrap is the percentage of a part that is lost during a given operation. You define scrap as an operation processing parameter that affects all parts on which it is performed. 
 

 Note: You can also define scrap as a child part parameter (i.e., the percentage lost whenever the part is joined to any parent), as a parent part parameter (i.e., the percentage lost of any child joined to the parent), or as parts lost or damaged during shipment. For instructions, see the "Define Parts for Production" section. 
 
## To define scrap as an operation parameter:

 

 1 .   Enter the Operations form and retrieve the desired operation. 
 

 2 .   Enter the Operation Processing Parameters sub-level form and select S in the Parameter column 
 

 3 .   Select C in the Operand column (for Constant) and specify the percentage of scrap as a real number in the Coefficient column (e.g., 0.20 , 0.05 ).
