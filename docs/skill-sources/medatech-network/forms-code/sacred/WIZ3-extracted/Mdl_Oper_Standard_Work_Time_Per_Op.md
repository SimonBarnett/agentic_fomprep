# To define constant labor and machine time:

 

 1 .  Enter the Operations form and retrieve the desired operation. 
 

 2 .  Enter the Operation Processing Parameters sub-level form. 
 

 3 .  In the Parameter column, specify E for employee time or T for machine/skilled employee time. The operation code will appear automatically in the Variable column. 
 

 4 .  In the Operand(C/M/D) column, specify C (for Constant ). 
 

 5 .  In the Coefficient column, record the standard employee or machine time. 
 

 6 .  Click to define skilled employees for this operation. 
 

 7 .  Click to set up time factoring. 
 
## Notes:

 

 ·        Click to define variable labor and machine time for an operation. 
 

 ·        Click to return to the Processing Parameters menu.
