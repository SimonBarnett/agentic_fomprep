# Setting Up Time Factoring

 

Time factoring allows you to revise employee time and machine time (as well as skilled employee time, which is based on machine time) for an operation without permanently changing its standard work time parameters. Example. 
 

When a time factor is specified, employee/machine time is calculated by multiplying the factor by the standard time defined for the operation or part. 
 
## To define a time factor for a given operation:

 

 ·        In the Time Factor column of the Operations form, specify the desired value.
