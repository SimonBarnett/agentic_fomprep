# To attach a document to a part:

 

 1 .   Enter the Parts form and retrieve the desired part. 
 

 2 .   Enter the Documents for Part sub-level form. 
 

 3 .   For each document, record a description and the date it was composed. 
 

 4 .   Use the File Name column (or the folder icon on the right) to browse to the document and attach it to the part in the upper-level form.
 Tip: If you right-click the folder icon and select Import , Priority will create a copy of the target file in a directory accessible to all network users. 
 

 5 .   If applicable, specify the Document Number , Code-Document Type and Version of Doc .
 Tip: To define new document type codes, use the Document Types form. 
 

 6 .   A check mark appears automatically in the In Use column, indicating that the document is currently relevant to the part. If the document becomes out-of-date, you can remove the checkmark rather than delete the line, thus maintaining a history of all documents that have been attached to the part. 
 

 7 .   If the document refers to a specific revision of the current part, specify the respective ECO Number . 
 

 8 .  Record any comments pertinent to the document in the Remark s column. 
 Tip: If the document exists only in hard copy, use this column to record its location (e.g., room, file cabinet, file).
