# To assign a routing to a processed part:

 

 1 .  Enter the Parts form and retrieve the desired processed part. 
 

 2 .  In the General tab, the Assemb routing appears automatically in the Routing column. Use the Choose list to select the appropriate routing.
 Tip: Click to define a new routing.
