# Attaching Engineering Data to a Routing Operation

 

You can assign blueprints, specs, tools or remarks to any operation in a part's routing. 
 
## To attach engineering data:

 

 1 .   Enter the Parts form and retrieve the desired part. 
 

 2 .  Enter the Part Routing sub-level form and move to the desired operation. 
 

 3 .  Enter the Engineering Data sub-level form and specify a Blueprint Number , Spec Number , Tool , and/or predefined Remark , as needed.
 Note: All engineering data must first be defined in the system. Click F6 twice on any of the above columns to enter the respective form and define new values. 
 
## Note:

 

Run the Part Routing report to view a chart of the part routing together with the attached engineering data.
