Modeling - Byproducts Overview.2 
 
 
- 
 
 
 

Sometimes a minor modification to the source part allows it to produce a different set of byproducts; for example, the wood board could be cut to create one large tabletop and its accessories, or two small tabletops and their accessories. In such a case, you can define one byproduct from each set (e.g., the tabletop) as the main byproduct of that set, and link it to the other byproducts in the set. Main byproducts enable MRP to open work orders for the correct set of parts. 
 

If MRP identifies demand for byproducts (and is run with the option to open work orders), work orders are opened for both the source parts and their byproducts. If you are opening work orders manually, you can open a work order for one byproduct of a given source part and run a Direct Activation that opens work orders for both the source part and the rest of its byproducts. 
 

For detailed instructions in opening work orders for byproducts, run the Work Orders Wizard .
