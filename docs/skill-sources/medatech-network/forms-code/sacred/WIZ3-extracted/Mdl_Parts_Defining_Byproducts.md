# To define a source part and its byproducts:

 

 1 .  Enter the Parts form and retrieve the processed (type P ) part that will serve as the source part. 
 

 2 .  In the General tab, select “Byprod” in the Routing column. 
 

 3 .  Define a new type P part for each byproduct, and select its appropriate Routing (e.g., the “Sawing” routing, in the case of wooden table parts). 
 

 4 .  For each byproduct, enter the Child Parts sub-level form and specify the previously defined source part as its child part. 
 

 5 .  In the Parent Operation column, specify the operation in the byproduct's routing in which the source part (as child part) “joins” its parent (e.g., the “Sawing” operation, in the case of wooden table parts). 
 
## Notes:

 

 ·        Click to define a main byproduct.
