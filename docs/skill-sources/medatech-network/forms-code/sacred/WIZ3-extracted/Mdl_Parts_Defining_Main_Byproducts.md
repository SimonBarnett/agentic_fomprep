# To define a main byproduct:

 

 1 .  In the Parts form, retrieve the part you have selected to be the main byproduct of the current source part. 
 

 2 .  Click the Additional Details tab and specify the part's number in the Main Byproduct Part# column. 
 

 3 .  Retrieve each remaining byproduct in that set and specify the same Main Byproduct Part# . 
 

 4 .  Repeat this process for all possible sets of byproducts that can be produced from the current source part.
