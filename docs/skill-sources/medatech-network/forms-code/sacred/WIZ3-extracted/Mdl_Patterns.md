# Defining Work Patterns and Exceptions 

 

A work pattern is a schedule of hours per day according to which a production department or work cell operates. Work patterns are qualified by exceptions , which are specific periods during which the work pattern is not in effect. 
 

 Priority provides a number of predefined work patterns, which may be revised as needed. You may also define additional work patterns. When you assign a work calendar to a production department, it is inherited by each of the department's assigned work cells. You may also assign a different calendar to individual work cells, which overrides that of the department. 
 
## To define or revise a work pattern:

 

 1 .   Enter the Work Patterns form. 
 

 2 .  For each new pattern, specify a code and description. 
 

 3 .  Enter the Pattern Timetable sub-level form, and specify the Start and End times between which operations can be scheduled each day.
