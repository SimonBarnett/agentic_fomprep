# Routings

 

A production routing is a series of operations performed in a particular order in their respective work cells on the plant floor. When assigned to a part, the routing represents the process by which that part is manufactured. 
 

Each buy item is assigned the raw material issue ( Issue ) routing when it is defined in the system. Each make item is assigned the warehouse assembly ( Assemb ) routing, though this may be revised. 
 

You can define a routing and later customize it on two separate levels: 
 

 ·        For a specific part, after the routing has been assigned to the part 
 

 ·        For a specific work order, after it has been opened for the part.
