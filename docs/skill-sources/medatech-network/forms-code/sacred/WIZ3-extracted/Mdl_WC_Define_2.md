Modeling - Defining a Work Cell.2 
 
 
- 
 
 
 

 6 .  Move to the Inv./Costing Control column and select the appropriate value: 
 

 ·      Select R if production is always reported, inventory is maintained and actual costing is calculated for this work cell. 
 

 ·      Select T if the operation is the last of a series of operations performed by a subcontractor (in which case it affects inventory and costing). 
 

 ·      Select L if the operation performed at this work cell is sometimes (or always) sent out to a subcontractor and if it is in the middle of such a series. 
 

 ·      Select C for actual costing only (inventory balances are not maintained). 
 

 ·      Leave the column blank to deactivate both inventory and actual costing (operations in the work cell are still taken into account for standard costing). 
 

 Notes: 
 

 ·      Do not use setting C if you intend to run COGS. 
 

 ·      These settings serve as defaults for the work cell, which may be overridden for specific operations, and even for specific work orders. 
 

 ·      For more information about inventory and costing control, run the Costing for Manufacturers Wizard .
