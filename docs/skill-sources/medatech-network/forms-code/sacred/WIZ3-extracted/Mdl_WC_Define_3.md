 7 .  Specify the Warehouse to which the work cell belongs: 
 

 ·      If the operations in question are performed in your factory (even if they are sometimes performed by a subcontractor), specify the appropriate floor (type F ) warehouse. 
 

 ·      If the operations are always performed by a subcontractor (i.e., this is the subcontractor's work cell), specify the subcontractor's warehouse. 
 

 8 .  If there are other work cells that perform the same operations, enter the Alternate Work Cells sub-level form and specify each one on a separate line. If you do not want the planning programs to take an alternate work cell into account, flag the Ignore When Planning column.
