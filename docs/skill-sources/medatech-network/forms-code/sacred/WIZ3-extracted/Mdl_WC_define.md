# Defining Work Cells

 

Work cells are stations on the plant floor where operations are performed. Each work cell may host a number of operations performed by various machines. An important aspect of factory modeling is breaking down a job into distinct operations and assigning them to work cells. Example. 
 

If you work with subcontractors, you should define them and their warehouses before you begin modeling work cells. For assistance, run the Working w/Subcontractors Wizard . 
 
## To define a work cell:

 

 1 .  Enter the Work Cells form. 
 

 2 .  For each new work cell, specify an identifying code and description. 
 

 3 .  Specify the Department to which this work cell belongs. 
 

 4 .  By default, the work cell uses the work pattern in effect for its department. To assign a different work pattern, select a value in the Work Pattern column. 
 Tip: Click to define a new work pattern. 
 

 5 .  By default, the work cell uses the work exceptions in effect for its department. To assign additional work exceptions to this work cell, enter the Work Cell Exceptions sub-level form and select a value in the Work Exception column.
 Tip: Click to define a new work exception.
