# Processing Parameters

 

Processing parameters are settings that define specific attributes of an operation (e.g., required machine time, percentage of scrap). You can define a parameter as constant, in which case it always affects the operation in the same way. Example. Alternatively, you can modify the parameter with a variable that receives different values from different parts; consequently, the affect of the parameter depends on the part on which the operation is performed. Example. 
 

The T , E and S parameters represent an operation's standard machine time, standard employee time and percentage of scrap, respectively. These parameters are relevant to systems that run MRP and cost analysis, and must be defined for most operations. In fact, the T parameter appears automatically in the Operation Processing Parameters sub-level form whenever a new operation is defined.
