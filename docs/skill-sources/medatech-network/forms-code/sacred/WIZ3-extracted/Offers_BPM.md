# Setting Up Business Processes for Special Offers

 

You can use a BPM flow chart to customize statuses that help you control the processing of special offers. 
 

There are several predefined statuses for special offers, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart - Special Offers program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Special Offers form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
