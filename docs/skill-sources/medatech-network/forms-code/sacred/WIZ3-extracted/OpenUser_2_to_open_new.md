# Opening a User Record and Personnel File

 
## Before you begin

 

 ·        Click to set up a password policy for your company. 
 
## To open a user record with its corresponding personnel file:

 

 1 .   Run the Add New User program. Specify the user's Full Name and Social Security No. , and designate the desired User Name and Privilege Group Leader . A new record will be opened for the user in the Users form, linked to a new record in the Personnel File form.
 Note: This program can only be run by users with system manager privileges and users who are flagged to Manage All Users (in the Permissions tab of the User Permissions form). 
 

 2 .  To view the new user, enter the Users form and retrieve by user name. 
 

 3 .  Enter the Groups sub-level form, and assign the user to the desired group(s). 
 

 4 .  Run the Assign Password program to assign the user a password. 
 Note: Only users with system manager privileges and users who are flagged to Manage All Users (in the Permissions tab of the User Permissions form) can run this program for all users. Users who are flagged to Manage User Group can run the program only for their own privilege group. 
 

 5 .  To view the new personnel file, enter the Personnel File form and retrieve by the User (in the General tab). 
 Tip: Have the HR manager fill in any missing information. For more details, run the Employee Wizard .
