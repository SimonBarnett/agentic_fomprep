# To open a user record manually:

 

 1 .  Enter the Users form. 
 

 2 .  Fill in the employee's User Name and Employee ID . The Employee Name is filled in automatically from the personnel file, and an Operating System Code is assigned. 
 

 3 .  To assign the user to a privilege group, select the group leader in the Privilege Group Leader column. 
 

 4 .  Enter the User Permissions sub-level form. 
 

 5 .  To have the user receive internal Priority mail at his/her external e-mail address, choose one of the following options in the Redirect E-mail column: 
 

 ·      B , for the user to receive the mail at both addresses OR 
 

 ·      E , for the user to receive the mail only at the external address. 
 

 6 .  If needed, flag the type of user license assigned to this user. 
 

 7 .  Click the Permissions tab to define permissions allowing this user to interface with external applications and/or customize Priority entities. 
 

 8 .  Enter the parallel sub-level form, Groups , and assign the user to the desired group(s). 
 

 9 .  To assign the user a login password, run the Assign Password program. 
 Note: Only users with system manager privileges and users who are flagged to Manage All Users (in the Permissions tab of the User Permissions form) can run this program for all users. Users who are flagged to Manage User Group can run the program only for their own privilege group.
