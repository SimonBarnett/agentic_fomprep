- 
 
 
 
# To define a Priority privilege group leader:

 

 1 .  Enter the Users form. 
 

 2 .  In the User Name column, record a name that represents the privilege group to be led by this user (e.g., Sales, Service). 
 

 3 .  Record a description in the Full Name column. An operating system code is assigned automatically. 
 

 4 .  Leave the line. Ignore the warning message (as this is a fictitious user, no personnel file is required).
