# Setting the Password Policy

 

To increase internal security in your company, you can decide on a password policy. 
 

You can determine how many days a password can be in effect, set a minimal length for all passwords, and decide whether a password should be simple or complex. 
 

You can also have the system run a history check each time a password is changed, to make sure the user does not use the same password within a designated number of days. 
 
## To determine the password policy:

 

 ·        Run the Set Password Policy program.
