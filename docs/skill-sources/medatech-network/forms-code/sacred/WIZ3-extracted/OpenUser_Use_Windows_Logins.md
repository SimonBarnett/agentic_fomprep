# Identifying Users by Their Windows Active Directory Logins

 

When working in Priority on SQL Server , you can choose to use the same user names and passwords defined for your employees in Windows to access Priority as well. If you choose this option, it will not be necessary for users to log in to the system separately. 
 

Even if you have already begun using user names and passwords unique to Priority , you can synchronize the system with the Windows Active Directory at any time. 
 

Once the systems have been synchronized, Priority user records are updated automatically whenever data is revised for users of the Active Directory. 
 
## Note:

 

This process is irreversible – once you begin using the Active Directory to log users into Priority , you can no longer use separate Priority user names and passwords. 
 
## To apply Windows logins to Priority:

 

 ·        Click if you have not yet opened user records in Priority . 
 

 ·        Click to synchronize existing users with the Windows Active Directory. 
 

 ·        Click to define the conditions under which users will be linked to their Windows definitions.
