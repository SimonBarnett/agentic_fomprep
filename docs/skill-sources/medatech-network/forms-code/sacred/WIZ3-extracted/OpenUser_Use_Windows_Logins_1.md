# Identifying Users by Their Windows Logins During System Initialization

 

If you have not yet opened user records in Priority , you can set up the system to interface directly with the Windows Active Directory. Consequently, when a user enters the system for the first time, a user record and personnel file are opened automatically, based on that user's Windows login information. Details. 
 
## Before you begin

 

 1 .  Click to define Priority privilege group leaders . 
 

 2 .  Enter the Groups in Active Directory form and assign each Priority group leader to the appropriate Active Directory privilege group. In particular, assign the superuser to the highest Active Directory group (e.g., “Administrator”).
 Note: Additional group leaders can be defined and linked to the Active Directory at any time, provided that they are fictitious users. 
 
## To set up Priority to use Windows logins:

 

 ·        Run the Activate Use of Active Directory program. 
 
## Notes:

 

 ·        Click to change the conditions under which personnel files and user names are opened automatically. 
 

 ·        Click to return to the main screen.
