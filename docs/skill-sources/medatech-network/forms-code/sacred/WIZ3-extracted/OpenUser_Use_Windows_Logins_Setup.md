# Defining the Conditions Under Which User Names and Personnel Files Are Opened Automatically

 

After running the Activate Use of Active Directory program, user names and personnel files are opened by default for every new user, according to the user's Windows login. 
 

You can set up the system so that only existing users (for which a personnel file has already been opened) will receive a user name, and will henceforth enter the system using their Windows login. New users will need to be assigned a user name and personnel file manually before they can enter the system. 
 

An additional possibility is to set up the system so that when an employee who is not yet a user activates Priority , the system looks for a match between the employee's Windows login and an employee name in the Personnel File form. If an identical employee name is found, it appears in the Windows Login column in that form, and a corresponding Priority user name is created. This is useful when you want to expand the number of Priority users in your company. 
 
# To define when user names and personnel files are opened automatically.

 

 1 .  Enter the System Constants form and move to the A D A UTOOPEN constant. 
 

 2 .  Set the value as desired.
