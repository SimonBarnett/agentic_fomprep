# Defining a User as Inactive

 

An inactive user will not be able to log in and record data in Priority . The user name will not appear on any Choose lists of users. 
 
## To define a user as inactive:

 

 1 .  Enter the User Permissions form and retrieve the desired user. 
 

 2 .  Click the Permissions tab. 
 

 3 .  Flag the Inactive User column.
