# Branch Warehouse

 

The branch warehouse serves as the default in any inventory transaction document (e.g., customer shipment) recorded by a user in this branch. 
 
## To assign a warehouse to a branch:

 

 1 .  Enter the Branches form and retrieve the desired branch. 
 

 2 .  In the Warehouse column (in the Branch Details tab), choose the warehouse you wish to link to the branch. 
 
## Tip:

 

To set up branches, run the Branches Wizard .
