# To open the fiscal periods:

 

 1 .  Return to the line for the previous fiscal year and enter the Fiscal Periods sub-level form. Twelve fiscal periods appear automatically, one for each full month. 
 

 2 .  You can leave each period as it is, or alter it by changing its end date. The next period's start date is updated automatically.
 Note: The first period must begin on the start date of the fiscal year, and the last period must end on the end date of the fiscal year. 
 

 3 .  Return to the upper-level form and do the same for the current fiscal year. 
 

 4 .  Run the Open Fiscal Period program for all twelve periods of the previous year and for the first period of the current year.
 Note: Each time you run this program, the next consecutive period is opened.
