## Defining New Warehouses

 

 Priority allows you to define new warehouses, including warehouses for special purposes, such as: 
 

 ·        a sales warehouse 
 

 ·        a holding warehouse 
 

 ·        a kit warehouse 
 

 ·        an issuing warehouse 
 

 ·        a consignment/loan warehouse 
 

 ·        a transit warehouse 
 

 ·        a vendor consignment warehouse 
 

 ·        a fashion outlet or franchise warehouse 
 

 ·        a repairs warehouse 
 

 ·        a project warehouse 
 

 ·        a warehouse for each subcontractor 
 

 ·        a bonded warehouse (for dual-currency users) 
 

For each type of special warehouse, you need to define specific parameters .
