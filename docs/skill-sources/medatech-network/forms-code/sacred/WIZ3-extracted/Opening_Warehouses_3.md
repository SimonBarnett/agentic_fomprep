# Defining Default Warehouses

 

Inventory transactions are recorded against a given warehouse. For most types of transactions, you can define a default warehouse that will be recorded automatically in each new transaction document. Example. This default can always be overridden in the actual document. 
 

 Notes: 
 

 ·        The predefined Main warehouse is filled in automatically for some types of transactions. Usually, it may be revised. 
 

 ·        When a consignment warehouse is assigned to a vendor, it becomes the default warehouse for GRVs from that vendor. For more information, run the Receipt/Return of Goods Wizard . 
 
## To define a warehouse as a default for a given type of transaction:

 

 1 .  Enter the Inv. Transaction Documents form. 
 

 2 .  Move to the line for the type of transaction in question. 
 

 3 .  In the Default Warehouse column, record the warehouse name. (Also record the bin, if you maintain bins). 
 
## Notes:

 

 ·        Click to define additional warehouses. 
 

 ·        Click to return to the main screen.
