# Maintaining Bins

 

You should only maintain bins if you intend to fully document the transfer of parts from one bin to another. 
 
## To record bins for a warehouse:

 

 1 .  Retrieve the warehouse in the Warehouses form and move to Multi -Record Display Mode .
 Note: Bins cannot be defined for type F warehouses (on the plant floor). 
 

 2 .  Move to a new line (directly below that one) and copy all columns (press F10 ) from the previous line, except the bin.
 Notes: 
 

 ·      Do not change the default 0 bin, which is recorded automatically whenever a new warehouse is opened. It is used to represent the entire warehouse. 
 

 ·      Do not copy the flag in the Main Project Warehs column. 
 

 3 .  In the Bin column, record the code you want to assign to the bin. 
 

 4 .  Repeat for all other bins in that warehouse.
