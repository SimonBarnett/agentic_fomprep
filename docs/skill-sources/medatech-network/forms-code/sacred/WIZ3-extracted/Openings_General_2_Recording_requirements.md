# Recording Job Requirements

 

In various sub-levels of the Jobs form, you can record the qualifications, types of interviews, tests and other information required of applicants for the job. 
 
## To record general job requirements:

 

 ·        Enter the Job Requirements sub-level form. Any basic responsibilities and requirements recorded for the position appear automatically. Revise or add to them, as desired. 
 
## To record required certifications for this job:

 

 ·        Enter the Certification Required for Job sub-level form and specify any certifications required to apply for the job. 
 
## To record acceptable qualifications:

 

 1 .  Enter the parallel Qualifications Required for Job sub-level form. 
 

 2 .  For each required qualification, specify the Qualification Code . The description will appear automatically.
 Tip: If you have not yet defined job qualifications and values, run the Personnel Setup Wizard . 
 

 3 .  Use the Value and To Value columns to delineate a range of values that is considered acceptable for the job. 
 

 4 .  Flag the Mandatory column if an acceptable showing in this qualification is absolutely required for every applicant. 
 

 5 .  Flag the Include in Appl Search column if you want this characteristic to be taken into account when retrieving qualified job applicants. Explanation.
