## To record required interviews:

 

 1 .  Enter the Interviews Required for Job sub-level form. Select the code of any interview required for this job. 
 

 2 .  If the interview must be conducted by a particular employee, choose him/her in the Interviewer-Empl ID column. 
 

 3 .  In the Documentation (File) column, you can attach any documentation associated with the interview (e.g., a job application form). 
 
## To record required tests:

 

 ·        Enter the Tests Required for Job sub-level form. Select the code of any test required for this job.
