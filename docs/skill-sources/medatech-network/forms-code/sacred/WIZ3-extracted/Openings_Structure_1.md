# Defining Organizational Structure

 

 Priority allows you to define your company's organizational structure. By linking each position to its immediate superior (i.e., Boss ' s Job ), you can create a hierarchy of jobs within the company. This hierarchy can then be viewed via the Jobs Explorer . 
 
## To define a job hierarchy:

 

 1 .  Enter the Jobs form and retrieve the desired job. 
 

 2 .  In the Boss ' s Job column, select the desired superior's job. 
 
## To view the job hierarchy for one or more positions:

 

 ·        Run the Jobs Explorer program.
