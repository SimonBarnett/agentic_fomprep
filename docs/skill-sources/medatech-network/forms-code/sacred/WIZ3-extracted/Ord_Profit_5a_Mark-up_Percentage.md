# Recording a Markup Percentage

 

 1 .  Prepare the price quote (in the Price Quotations for Customers form), including parts, quantities and discounts (in the Itemized Quotation sub-level form). 
 Notes : 
 

 ·              Make sure the Unit Price column is blank. If it has a price, delete it. 
 

 ·              Click to create a customized bill of materials for a quoted item. 
 

 2 .  Check the accuracy of the sales rep and any discounts awarded, as these affect the final price. 
 

 3 .  In the Markup (%) column (of the upper-level form), record the desired markup. 
 

 4 .  Select Estimate/Recommend Prices from the list of Direct Activation s to have Priority calculate recommended prices based on the markup specified.
