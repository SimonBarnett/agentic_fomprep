# Setting the Method of Calculating the Percentage of Profit

 

The SOrdProfit constant determines whether the percentage of profit in a price quote or order is determined by dividing the amount of profit by the cost of the parts or by the price after discount. Example. 
 
## To set the calculation method:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the line for the SOrdProfit constant, and do one of the following: 
 

 ·              Leave the preset value of 0 to calculate the percentage based on part costs. 
 

 ·              Change the value to 1 to calculate the percentage based on the price after discount.
