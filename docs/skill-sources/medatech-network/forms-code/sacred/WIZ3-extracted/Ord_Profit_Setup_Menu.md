# Setting Up Profitability Calculations

 

Before profitability can be calculated, you need to determine the source of the part's cost and the method for calculating the percentage of profit. If you use a customized bill of materials in quotes or orders, you also need to determine whether prices will be based on the child parts in the customized BOM, or derived from the usual sources (e.g., price list, order price). 
 

All three setups are determined by constants in the Logistic Constants form. 
 
## What do you want to do?

 

 Determine the source of the part ' s cost 
 

 Set the method of calculating the percentage of profit 
 

 Determine how prices are calculated in a customized BOM
