Outgoing Shipping Vouchers - Linking Order Items to a Voucher 
 
 
- 
 
 
 
# To link sales order items to an outgoing shipping voucher:

 

 1 .  Enter the Outgoing Shipping Vouchers form and retrieve the desired outgoing shipping voucher. 
 

 2 .  Enter the Choose Order Items sub-level form. This form displays open order items. If a customer or order is defined for the outgoing shipping voucher, only those order items that are relevant for the defined voucher are displayed. 
 

 3 .  In the Choose Item column, flag each order item that you wish to link to the outgoing shipping voucher.
 Note: Alternatively, you can manually record order items for the shipping voucher in the parallel Order Items form. 
 

 4 .  Enter the parallel Order Items sub-level form and choose one of the following options to indicate the quantity of each item to be shipped: 
 

 ·              To ship the entire balance of the order item, flag the Approve column. The Qty to Ship will be filled in automatically with the whole Balance . 
 

 ·              Manually specify the Qty to Ship .
