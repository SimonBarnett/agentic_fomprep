# Manually Distributing an Expense Item 

 

You can override an expense item's assigned burden type by manually defining the ratio by which is to be distributed among the sold parts in the shipping voucher. You can also target expenses to one or more specific invoices. 
 
## To manually distribute an expense item:

 

 1 .  Move to the desired item in the Additional Expenses form. 
 

 2 .  Enter the Manual Distrib of Added Expenses sub-level form. Each sold part in the voucher appears on a separate line. 
 

 3 .  For each item, if you want a certain portion of the expense to be added to a specific invoice, record the number of the Invoice in question. Examples. 
 

 4 .  For each part, fill in the Proportion of Burden column with a value representing the relative portion of the expense to be added to that sold item. Example. 
 
## Notes:

 

 ·        You can record multiple lines for a single part, specifying a different invoice in each line. 
 

 ·        When the shipping voucher is closed, the expenses added to each purchased part include both the specified portion of each expense that is assigned to that part throughout the voucher and the specified portion of each expense that is assigned directly to a particular invoice. 
 
## To view the results of manual distribution:

 

 1 .  Return to the Outgoing Shipping Vouchers form and select Calculate Expense Burdening from the list of Direct Activations . 
 

 2 .  Return to the Manual Distrib of Added Expenses form. The exact amount of the expense assigned to each part appears in the Expenses column.
