# Defining a Checklist for Outgoing Shipping Vouchers

 

 Priority enables you to define a checklist of outgoing shipment tasks for each customer. 
 
## To define the checklist:

 

 1 .  Enter the Customers form. 
 

 2 .  Enter the Outgoing Ship Voucher Checklist sub-level form. 
 

 3 .  Record a Subject , Task Code , and Task Type for any tasks you wish to include in the checklist. 
 

 4 .  Record additional details in the Remarks sub-level form, as desired.
