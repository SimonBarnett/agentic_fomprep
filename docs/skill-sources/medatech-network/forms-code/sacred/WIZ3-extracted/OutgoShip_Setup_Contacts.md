# To Define Contacts for Outgoing Shipping Vouchers:

 

 1 .  Enter the Customers form. 
 

 2 .  Retrieve the desired customer. 
 

 3 .  Enter the Customer Contacts sub-level form. 
 

 4 .  Add the desired contacts, and flag the Outgo Vouch Contact or Outgo Vouch Contact2 option for them. These contacts will appear by default in outgoing shipping vouchers for this customer.
