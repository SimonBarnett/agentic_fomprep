# Viewing the Burden Distribution in Outgoing Shipping Vouchers

 

In order to allow you to preview the distribution of expenses in outgoing shipping vouchers before they are closed, Priority provides a program that calculates the distribution according to the proportions that were either preset or defined manually for each sold part in the voucher, taking pending invoices into account as well. After running this program, you can make any necessary corrections and run the program again, until you achieve satisfactory results. 
 
## To preview the distribution of shipping expenses:

 

 1 .  Enter the Outgoing Shipping Vouchers form and select Calculate Expense Burdening from the list of Direct Activations of each voucher in question, if you have not already done so. 
 

 2 .  Do one of the following: 
 

 ·     Run the Outgo Shipping Voucher Summary report to view the total burden per part in each shipping voucher.
 Tip for dual-currency users: Run the Outgo Ship Summary-Foreign Curr. report to view this data in a foreign currency. 
 

 ·     Run the Outgoing Shipping Burden report to view the breakdown of expenses distributed to each part in each shipping voucher.
