# Working With An Authorizer List

 

Just as with BPM statuses, the first user on the authorizer list is automatically notified by e-mail when the relevant status is assigned to a blanket purchase order. When the first authorizer signs, the second user is notified and so on; however, it is not mandatory to sign in sequence. Once a senior authorizer signs the order, users appearing earlier in the list need not sign. 
 
## To authorize a blanket purchase order:

 

 1 .  In the Blanket Purchase Orders form, retrieve the order you are supposed to authorize.
 Tip: The username of the next person to sign appears in the Next Signature column. Consequently, you can click the Authorization & Follow-up tab and retrieve all orders for which your username appears in that column. 
 

 2 .  Enter the Blanket Order Authorization sub-level form. The names of all users whose signatures are needed for authorization will appear. 
 

 3 .  Authorize next to your own name by flagging the Approve column. 
 

 4 .  Return to the Purchase Demands upper-level form and click the Authorization & Follow-up tab: 
 

 ·      If the document is now fully authorized, the Status changes automatically to Authorized . 
 

 ·      If the document is not yet fully authorized, the name of the next user who is supposed to authorize it appears in the Next Signature column. This user will receive an e-mail message regarding this authorization. 
 

 5 .  In the Assigned to column, designate the next user who is to handle the document (e.g., the next authorizer, the purchase manager).
