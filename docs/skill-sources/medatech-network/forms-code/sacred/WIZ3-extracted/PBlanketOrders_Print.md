# Printing a Blanket Purchase Order

 
## Before you begin:

 

 1 .  In the Blanket Purchase Orders form, retrieve the desired blanket purchase order. 
 

 2 .  Enter the Blanket Purchase Orders-Remarks sub-level form. The text appearing in this form will appear as a remark on the printout. Make sure that it is correct. 
 
# To print one order:

 

 ·        Select Print Blanket Purchase Order from the list of Direct Activation s .
 D ual-currency users: If you wish to print the order in English and are working in another language, select Print BlanketPurchOrd-ForeignLng instead. 
 
## To print more than one order:

 

 ·        Run the Print Blanket Purchase Order report.
 D ual-currency users: To print in English when working in another language, run the Print BlanketPurchOrd-ForeignLng report.
