# Setting Up Blanket Purchase Order Authorization

 

There are two methods you can use to authorize blanket purchase orders – an authorizer list and BPM rules. 
 

The authorizer list is defined in a separate form and assigned to individual blanket orders. It contains the names of those users who must sign off on a blanket purchase order, without reference to the amount of the order. Once an order receives a status that allows it to be authorized, the first authorizer is notified automatically by e-mail. Once the first authorizer signs, the next authorizer on the list is notified, and so on. 
 

BPM status and path rules can used to obtain the same results as authorizer lists, made even more powerful by the limitless combinations of conditions and behaviors provided by BPM. For a full explanation of BPM and its uses, see the User Interface Guide .
