# Creating Authorizer Lists

 

 Priority offers the option of working with authorizers whose signatures are required before blanket purchase orders can be sent to the vendor. 
 
## To create an authorizer list:

 

 1 .  Enter the Blanket Order Authorizers form. 
 

 2 .  In the Name column, record each authorizer' s username. 
 

 3 .  In the Signature Order column, specify the position of the current user in the authorizer list. The user with the smallest number signs first. 
 
## Notes:

 

 ·        Any change in the authorizer list will only affect blanket purchase orders that were opened after the change.
