# PP_AccRec_example_retro_receipt

- **Source:** `PP_AccRec_example_retro_receipt.htm`

PP_AccRec_example_retro_receipt 
 
 
- 
 
 
 

Let's say you received a check from a customer, with no clear indication of the invoices it was meant to cover, and you issued a receipt against it. A month later, the customer informs you that the check is payment for two invoices that had been issued to the customer. Since the receipt is already final, you can no longer flag it with the appropriate invoices. Priority allows you to flag these invoices and specify the payment amount for each of them retroactively, in the receipt's journal entry.
