- 
 
 
 

To set up reconciliations, you must first designate the method of matching invoices to receipts. You can designate a certain reconciliation method to be the general default, as well as different reconciliation methods that override the default for specific customers (e.g., walk-in customers). In addition, you can designate a default adjustment account for reconciliation variances, in which small differences in reconciled items are recorded.
