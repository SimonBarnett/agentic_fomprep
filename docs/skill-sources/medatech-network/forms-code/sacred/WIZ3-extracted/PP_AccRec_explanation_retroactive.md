# PP_AccRec_explanation_retroactive

- **Source:** `PP_AccRec_explanation_retroactive.htm`

PP_AccRec_explanation_retroactive 
 
 
- 
 
 
 

When recording a receipt, you can link it to the appropriate invoice(s). When this is not possible (e.g., if the invoice was issued after receipt of payment), you can link the receipt to one or more invoices retroactively in the entry journal (if you are working with the “By Invoice” reconciliation method). You can also split the invoice amount into installments directly in the entry journal, prior to reconciliation with the receipt. 
 
## Note:

 

If you use the “First Invoice First” reconciliation method, you can reconcile retroactively using the Reconciliation Worksheet.
