# PP_Add_Expenses_Bonded_Warehouse

- **Source:** `PP_Add_Expenses_Bonded_Warehouse.htm`

PP_Add_Expenses_Bonded_Warehouse 
 
 
- 
 
 
 

Imported goods can be stored in a bonded warehouse prior to paying customs duties. Only when goods are released from the bonded warehouse are you required to pay customs. 
 

Goods stored in the bonded warehouse are usually those for which the customs duties are exceptionally high, and therefore are only released when actually purchased by a customer (e.g., purchase of an automobile).
