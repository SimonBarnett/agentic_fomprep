# PP_Add_Expenses_Burden_Proportion

- **Source:** `PP_Add_Expenses_Burden_Proportion.htm`

PP_Add_Expenses_Burden_Proportion 
 
 
- 
 
 
 

A particular expense is linked to three shipped items, to which the following burden proportions are assigned: 
 

 ·        Item A: 2 
 

 ·        Item B: 3 
 

 ·        Item C: 5 
 

The sum of the three values is 10; consequently, when the costing program distributes this expense among the three parts, Item A will be burdened with 20% of the expense (2/10), Item B with 30% (3/10) and Item C with 50% (5/10).
