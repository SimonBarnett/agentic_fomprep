# PP_Add_Expenses_Manual_Distribution

- **Source:** `PP_Add_Expenses_Manual_Distribution.htm`

PP_Add_Expenses_Manual_Distribution 
 
 
- 
 
 
 

Your shipping service makes a delivery containing three types of parts from different vendors, each of which is listed in a separate shipping voucher, and bills you for the entire delivery in a single invoice. Since it is not possible to add the same invoice line to all three vouchers, you need to disregard the invoice and enter the appropriate portion of the shipping expense manually in each voucher. Thus, out of the $100 delivery bill, an expense item is created in Voucher A for $25, another is created in Voucher B for $40, and a third is created in Voucher C for $35.
