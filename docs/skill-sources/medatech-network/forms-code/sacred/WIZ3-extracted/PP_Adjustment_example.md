PP_Adjustment_example

In the U.S.: For an account in Euros, the adjustment will be to the balance in Dollars. 
 

For dual-currency users: For an account in the local currency (e.g., Euro), the adjustment will affect the balance in the second currency (e.g., US Dollars).
