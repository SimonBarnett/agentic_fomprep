# PP_Analysis_Extending_Lots

- **Source:** `PP_Analysis_Extending_Lots.htm`

PP_Analysis_Extending_Lots 
 
 
- 
 
 
 

The maximum number of times it is permissible to extend the shelf life of lots or work orders for a given part is defined in the Inventory Parameters for Parts form. Note that changing the value of this parameter will allow all lots or work orders of this part to be extended the specified number of times.
