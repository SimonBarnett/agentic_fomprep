# PP_AuthorizerLists

- **Source:** `PP_AuthorizerLists.htm`

PP_AuthorizerLists 
 
 
- 
 
 
 

In each list, you indicate the users who can sign, as well as the total order amount above which their signature is mandatory. The sequence of authorizations is determined by that starting amount. One user must be required to sign as of a 0 (zero) amount. Not everyone has to authorize the order; once a senior user (appearing later in the list) signs the order, users appearing earlier in the list need not sign.
