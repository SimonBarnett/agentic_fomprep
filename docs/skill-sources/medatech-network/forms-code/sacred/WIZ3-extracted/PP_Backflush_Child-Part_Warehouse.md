# PP_Backflush_Child-Part_Warehouse

- **Source:** `PP_Backflush_Child-Part_Warehouse.htm`

PP_Backflush_Child-Part_Warehouse 
 
 
- 
 
 
 

When a plant floor warehouse is assigned to a manufactured part (in the Backflush From Other Floors sub-level of the Warehouses form), the Backflush program reduces its child parts from the specified warehouse.
