 Automatic Inventory Transactions 
 

The Backflush automatically transfers processed parts from one operation to the next, on the basis of the production reports recorded since the last run of the program. In addition, it reduces from inventory the child parts used in the reported operations. 
 

When the last operation for a part has been reported, the Backflush automatically transfers the finished parts off the plant floor into the designated factory warehouse.
