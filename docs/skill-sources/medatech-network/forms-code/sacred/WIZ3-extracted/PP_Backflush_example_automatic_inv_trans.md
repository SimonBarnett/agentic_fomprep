PP_Backflush_example_automatic_inv_trans 
 
 
- 
 
 
 

As a result of a production report for the operation "Door Assembly," carried out on 10 kitchen cabinets, the Backflush program will record the following inventory transactions: 
 

 ·        Entry into inventory of 10 kitchen cabinets in the "Door Assembly" operation 
 

 ·        Removal from inventory of 20 kitchen cabinet doors (each cabinet has two doors).
