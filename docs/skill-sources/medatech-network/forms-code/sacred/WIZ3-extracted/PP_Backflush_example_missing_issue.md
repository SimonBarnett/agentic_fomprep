PP_Backflush_example_missing_issue 
 
 
- 
 
 
 

 Example: 
 

As production was reported for 10 kitchen cabinets, and 2 doors are needed per cabinet, the Backflush program tries to reduce 20 cabinet doors from child part inventory. Since only 15 doors have been recorded as issued, the Backflush records missing issues for 5 cabinet doors (unless the TakeNonKit production constant is set to 1 ).
