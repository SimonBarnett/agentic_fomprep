# PP_Backflush_example_missing_issue_3

- **Source:** `PP_Backflush_example_missing_issue_3.htm`

PP_Backflush_example_missing_issue_3 
 
 
- 
 
 
 

A part is issued to the plant floor in sufficient quantity for its parent, but a subsequent warehouse transfer has reduced this inventory. When the Backflush program tries to reduce child parts as a result of a production report for the parent, the remaining child part inventory is not sufficient, and the missing quantity is recorded as missing issues.
