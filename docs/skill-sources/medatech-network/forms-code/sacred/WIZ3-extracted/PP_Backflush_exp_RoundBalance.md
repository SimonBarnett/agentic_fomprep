# PP_Backflush_exp_RoundBalance

- **Source:** `PP_Backflush_exp_RoundBalance.htm`

PP_Backflush_exp_RoundBalance 
 
 
- 
 
 
 

A fractional quantity usually results from an irregular parent-child ratio. One of the possible causes of this is the definition of standard scrap. For example, 19 table legs (rather than 16) are usually needed to produce 4 tables, leading to a parent-child ratio of 1:4.75. In a work order for one table, five legs are issued to the kit (as table legs are issued in complete units, the required quantity is automatically rounded from 4.75 to 5). However, 4.75 table legs will be reduced from inventory after production is reported, according to the ratio defined in the BOM, as child part reduction is not subject to automatic rounding. Consequently, 0.25 table legs will remain recorded in plant-floor inventory.
