# PP_Backflush_exp_clean_inventory

- **Source:** `PP_Backflush_exp_clean_inventory.htm`

PP_Backflush_exp_clean_inventory 
 
 
- 
 
 
 

It is sometimes necessary to issue a larger quantity to the kit than that planned (often because parts were lost in the production process). On other occasions, the issue to the kit is smaller than that planned, yet the inventory issued is sufficient for the needs of production. 
 

In such cases, because the Backflush program reduces child inventory according to the quantities in the kit list, actual floor inventory does not match the reduced inventory, and surpluses or deficits are created on the plant floor (even though the issued quantity met actual production needs).
