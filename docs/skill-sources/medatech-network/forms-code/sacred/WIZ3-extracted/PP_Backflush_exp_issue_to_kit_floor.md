 Types of Issues 
 

 ·        Issues to Kits: The issue of a child part to a kit earmarks the entire quantity for a specific work order. That is, other work orders cannot use this inventory. This method is useful when working with relatively expensive parts that you want to keep track of. 
 

 ·        Issue in Bulk: Bulk parts are not intended for a specific work order, but are issued to general floor inventory for use in all work orders that require the part. 
 

 ·        Manual Issues: Parts that require special storage conditions or close tracking (e.g., precious metals) are not issued to the floor, but rather are drawn from inventory during production, and issued manually in production reports.
