 Missing Issues 
 

For every production report or receipt from a subcontractor GRV, the Backflush program reduces the inventory of the child parts used in the operation in question, in proportion to the reported amount of parent parts produced. If the relevant plant floor warehouse (i.e., the warehouse in which the operation was performed, or the warehouse that was defined for automatic reduction of child parts used in the floor warehouse, if the parts are issued in bulk) does not contain sufficient inventory of the child part, the program records the discrepancy as missing issues.
