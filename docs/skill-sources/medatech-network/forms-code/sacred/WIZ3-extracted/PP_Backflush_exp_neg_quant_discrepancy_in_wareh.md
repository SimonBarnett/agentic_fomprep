# PP_Backflush_exp_neg_quant_discrepancy_in_wareh

- **Source:** `PP_Backflush_exp_neg_quant_discrepancy_in_wareh.htm`

PP_Backflush_exp_neg_quant_discrepancy_in_wareh 
 
 
- 
 
 
 

For a production report on operation B , the Backflush program reduces the inventory in the previous operation (operation A ) from the floor warehouse in which operation B was performed. If, in fact, the inventory from operation A is in a different warehouse, a negative balance will occur, even if operation A was reported correctly. 
 
## Possible causes of warehouse discrepancies:

 

 ·        In the work order routing, an automatic transfer was defined for operation A , to a warehouse other than that in which operation B is executed. 
 

 ·        Operations A and B belong to different work cells, which are themselves linked to different floor warehouses.
