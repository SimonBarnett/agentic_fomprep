# PP_Backflush_exp_scrap

- **Source:** `PP_Backflush_exp_scrap.htm`

PP_Backflush_exp_scrap 
 
 
- 
 
 
 

Scrap is the percentage of child part quantity that is lost during production of the parent part. Scrap is taken into account when the work order is released, and calculated according to the work order quantity, parent/child ratio and the defined percentage. 
 

The defined scrap only affects kit list quantities for parts issued in bulk, and does so automatically. If scrap is defined for a part issued to the kit, you need to adjust the required issue quantity manually. In both cases, MRP takes scrap into account when calculating quantities to be purchased.
