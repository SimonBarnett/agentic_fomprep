# PP_Backflush_final_parts

- **Source:** `PP_Backflush_final_parts.htm`

PP_Backflush_final_parts 
 
 
- 
 
 
 

When a factory warehouse has been designated in the final reported operation of a work order, the Backflush program automatically transfers the finished parts off the plant floor into the designated warehouse. You can determine whether all processed parts enter the warehouse (including rejected parts and parts that need to be checked) or only completed parts. For more details, run the Production Report Wizard .
