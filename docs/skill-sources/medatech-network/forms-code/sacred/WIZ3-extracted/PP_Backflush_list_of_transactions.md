# PP_Backflush_list_of_transactions

- **Source:** `PP_Backflush_list_of_transactions.htm`

PP_Backflush_list_of_transactions 
 
 
- 
 
 
 

The Backflush takes into account the following inventory transactions: 
 

 ·        Automatic transactions recorded by the program as a result of production reports 
 

 ·        Automatic transactions recorded by the program as a result of receipts from subcontractors
 Note: These two transaction types are labeled "Backflush" in the Audit Trail form. 
 

 ·        Automatic warehouse entries resulting from final production reports
 Note: This type of transaction is labeled "Prod. Completed" in the Audit Trail form. 
 

 ·        Bulk issues to the plant floor 
 

 ·        Issues to kits 
 

 ·        Manual issues 
 

 ·        Shipments of parts to subcontractors 
 

 ·        Inventory counts in floor warehouses 
 

In addition, any transaction that moves inventory into or out of a floor warehouse is taken into account (e.g., warehouse transfers, laboratory releases).
