PP_Backflush_plant_floor_warehouse 
 
 
- 
 
 
 

A plant-floor warehouse consists of all the work cells and any storage areas on a given plant floor. If production takes place in several locations, which are distant from each other, there may be multiple plant-floor warehouses.
