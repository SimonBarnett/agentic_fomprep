# PP_Budgets_Estimated_cost

- **Source:** `PP_Budgets_Estimated_cost.htm`

PP_Budgets_Estimated_cost 
 
 
- 
 
 
 

If the PR is for a specific vendor, the part’s estimated cost is taken from that vendor’s price list. Otherwise, it is taken from the part’s standard cost. Once a vendor has responded to an RFQ created for the current PR, the estimated cost is updated by the vendor’s quoted price.
