# PP_Budgets_Links_Example_of_chain

PP_Budgets_Links_Example_of_chain 
 
 
- 
 
 
 

If you link a budget item to a purchase or sales document, this linkage is preserved in subsequent financial documents. For example, if you link a budget item to a particular purchase order item, this budget item appears in any goods receiving voucher or vendor invoice based on the order, and you can use it to determine the account to be debited for the purchased goods. 
 

Note, however, that specifying a budget item in the early stages of a transaction chain does not necessarily determine which account will be debited, as one budget item may be linked to several GL accounts.
