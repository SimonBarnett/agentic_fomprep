# PP_Budgets_Suffix

- **Source:** `PP_Budgets_Suffix.htm`

PP_Budgets_Suffix 
 
 
- 
 
 
 

A suffix typically represents a common area in which funds are appropriated (e.g., - 001 = salaries, -002 = office supplies, -003 = network maintenance). Thus, the same suffix is often shared by a number of budget items (e.g., the TRV suffix would be attached to the travel budgets of both the northern and the southern branches of the personnel division).
