# PP_CMNF_Addl_costs_per_costing_unit

- **Source:** `PP_CMNF_Addl_costs_per_costing_unit.htm`

PP_CMNF_Addl_costs_per_costing_unit 
 
 
- 
 
 
 

Nails are issued as supplies to a work order, each nail costing $0.001. For the sake of convenience (and to avoid rounding the cost to zero), you can specify a costing unit of 1000, and record a Supply Cost of $1 per unit.
