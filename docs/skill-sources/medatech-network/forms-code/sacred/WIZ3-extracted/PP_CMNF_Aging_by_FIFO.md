PP_CMNF_Aging_by_FIFO 
 
 
- 
 
 
 

The inventory balance of a given part is 100 units, and the last incoming transactions were recorded in the system as follows: 
 

 ·        July: 35 units at $100 per unit 
 

 ·        June: 40 units at $90 per unit 
 

 ·        May: 50 units at $80 per unit 
 

The aging report starts from the latest incoming transaction and moves backwards in time, until it accounts for the current inventory balance. Consequently, the aging calculation is: 
 

 ·        (35 * 100) + (40*90) + (25*80) = 9100 
 

 ·        9100 \ 100 = 91 
 

The total inventory value is $9100, and the value per unit is $91.
