# PP_CMNF_Constant_E_T

- **Source:** `PP_CMNF_Constant_E_T.htm`

PP_CMNF_Constant_E/T 
 
 
- 
 
 
 

In the Gluing operation, glue-machine time ( T ) and employee time to work the gluing machine ( E ) are fixed, regardless of the type of part. 
 

However, in the Sawing operation, bandsaw time ( T ) and employee time to work the bandsaw ( E ) are different for a 10 cm.-thick board than for a 20 cm.-thick board.
