# PP_CMNF_Machine_time

- **Source:** `PP_CMNF_Machine_time.htm`

PP_CMNF_Machine_time 
 
 
- 
 
 
 

 Machine work hour cost is the average cost of running a certain machine for one hour. Together with the standard machine time, this value determines a manufactured part's machine cost. 
 

 Indirect machine cost is the sum of indirect costs related to the operation of a machine for one hour. The time used to calculate indirect costs is the sum of the standard machine and setup times, multiplied by the indirect hourly machine cost. 
 
## Note:

 

Standard setup time is calculated by adding the standard mount and dismount times to the percentage of standard machine time defined for setting up the work cell.
