# PP_CMNF_time

- **Source:** `PP_CMNF_time.htm`

PP_CMNF_time 
 
 
- 
 
 
 

The drying machine's operation time is influenced by the room temperature: an operation that takes an hour during the winter takes only 45 minutes during the summer. Priority allows you to define the machine's standard operation time as one hour, and use a Time Factor of 0.75 during the summer.
