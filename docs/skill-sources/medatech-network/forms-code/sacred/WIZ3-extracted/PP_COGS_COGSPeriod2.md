# PP_COGS_COGSPeriod2

- **Source:** `PP_COGS_COGSPeriod2.htm`

PP_COGS_COGSPeriod2 
 
 
- 
 
 
 

When online COGS is used, the entry is recorded when the document or invoice is finalized, for a sum equal to the transaction cost that was calculated by costing (see the Audit Trail ) form). 
 

As this transaction cost is only an estimate (the entry is recorded in the middle of the period and is not based on updated costing results), when the Post Cost of Goods Sold program is run, additional entries are recorded for the date of the original transaction (if several entries for the same transaction type fall on the same day, they are combined in one entry). These entries credit/debit the original accounts and use the original entry code. The entry sum is equal to the difference between the initial cost (calculated when the document/invoice was finalized) and the transaction cost calculated by costing.
