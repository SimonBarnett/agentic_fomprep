# PP_COGS_Standard_Costs

- **Source:** `PP_COGS_Standard_Costs.htm`

PP_COGS_Standard_Costs 
 
 
- 
 
 
 

When perpetual COGS is run, COGS entries are determined by the standard cost of transactions. For purchased parts, the standard shipping cost is added to the standard part cost. For manufactured parts, the standard cost includes standard materials, labor and burden. 
 

The cost of inventory transactions is calculated per cost component (materials, labor, burden), updating the appropriate inventory accounts. Variance entries are created to cover the difference between inventory account balances and standard inventory values.
