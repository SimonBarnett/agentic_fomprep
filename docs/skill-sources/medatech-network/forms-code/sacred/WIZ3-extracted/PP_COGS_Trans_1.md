# PP_COGS_Trans_1

- **Source:** `PP_COGS_Trans_1.htm`

PP_COGS_Trans_1 
 
 
- 
 
 
 

When the invoice is finalized, a journal entry is recorded that debits the Purchases/Inventory account with the standard cost (in order to adjust the inventory account balance to match standard inventory valuations calculated by costing). In addition, a variance entry is created that debits the Price Variance account and credits the inventory account with the difference between the part's standard cost and its invoice price.
