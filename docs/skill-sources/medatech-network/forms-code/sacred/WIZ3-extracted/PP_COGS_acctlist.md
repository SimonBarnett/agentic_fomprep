 ·        COGS-Materials

 ·        Inventory Disposal 
 

 ·        Part Sampling 
 

 ·        Production Costs 
 

 ·        Purchases/Inventory 
 

 ·        Standard Shipping Costs 
 

 ·        Inventory Count Variance 
 

 ·        Assembly Variance 
 

 ·        Conversion Variance 
 

 ·        Price Variance

 ·        COGS-Labor

 ·        Burden Offset 
 

 ·        Material Efficiency Variance 
 

 ·        Labor Efficiency Variance 
 

 ·        Burden Efficiency Variance
