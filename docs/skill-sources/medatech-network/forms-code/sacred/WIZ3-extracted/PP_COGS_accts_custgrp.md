PP_COGS_accts_custgrp

Only a single COGS account can be defined per customer group. This account will hold the combined costs of materials, labor and burden, even if three separate accounts ( COGS – Material , COGS – Labor and COGS – Burden ) have been defined in the Default Accounts form or per warehouse.
