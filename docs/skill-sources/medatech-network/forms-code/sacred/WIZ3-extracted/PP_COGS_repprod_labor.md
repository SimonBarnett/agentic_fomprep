# PP_COGS_repprod_labor

- 
 
 
 

Labor costs are calculated by the production time of employees, multiplied by the percentage defined for the shift, as recorded in production reports during the COGS period. Production time for a skilled worker is multiplied by the direct cost of skilled labor; production time for an unskilled worker is multiplied by the direct cost of unskilled labor. 
 
## Notes: 

 

 ·        If employee time is reported for a break (i.e., an operation marked "B" in the production report), the time is taken into account when calculating labor cost. 
 

 ·        Journal entries (entry code = LH ) debit the Inventory – Labor account and credit the Labor Offset account. When the Post Cost of Goods Sold program is run, they are recorded in a single entry dated for the end of the COGS period.
