# PP_Candidate_Inactive

- **Source:** `PP_Candidate_Inactive.htm`

PP_Candidate_Inactive 
 
 
- 
 
 
 

Inactive candidates cannot be recorded as applicants for any job opening. They also do not appear in Choose lists of candidates. By flagging candidates as inactive, you can maintain records for former job applicants, without interfering with the routine processing of current job applications.
