# Column Title

 

To update the column title dynamically each time the report is run, use the P1 and P2 parameters to represent the From Date and To Date columns, respectively, and then indicate the desired date format (e.g., MMM YYY). Finally, enclose the entire expression in angled brackets. For example, if the date from which sums are taken into account for this column in the statement is January 1, 2012, recording “Profit for <P1.MMM YYYY> ” will generate the column title “Profit for Jan 2012”.
