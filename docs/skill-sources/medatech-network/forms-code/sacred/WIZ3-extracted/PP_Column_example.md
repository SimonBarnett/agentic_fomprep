You can use basic arithmetical symbols, as well as the functions: MAX, MIN, AVG and SUM. To refer to the value of other columns in the bar, use the # symbol, together with the column number - e.g., (#3 - #10). When using one of the functions, place all column numbers within a set of parentheses, using commas as separators - e.g., MAX(#1, #5, #7).
