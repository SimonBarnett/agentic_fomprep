PP_CommissionSales_4_example 
 
 
- 
 
 
 

A given price quote includes two lines for the item "leather sofa". The quoted price per unit is $500 for a quantity of 10, and $300 for a quantity of 100 sofas. Both lines will appear in the commission order based on this price quote. If the customer chooses the second option (more quantity for less price), the first line should be deleted from the order.
