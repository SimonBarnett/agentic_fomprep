A product bundle is defined as any sold part that actually comprises an assortment of products (such as a gift basket). If you base a price quote on a product bundle, the quote is itemized automatically with all the components in the bundle. 
 

Each component part can have defined substitutes. For instance, if a gift basket includes a bottle of wine, you can create a list of wines out of which to choose the proper one for any specific basket. 
 

 Tip : To define a product bundle, run the Product Bundles Wizard .
