# PP_CommissionSales_quantity_of_optional_part

- **Source:** `PP_CommissionSales_quantity_of_optional_part.htm`

PP_CommissionSales_quantity_of_optional_part 
 
 
- 
 
 
 

When defining the product bundle, you indicate the quantity of each component part and its substitutes required in a single bundle. In the quote, the part quantity is calculated by multiplying this required quantity by the number of product bundles quoted.
