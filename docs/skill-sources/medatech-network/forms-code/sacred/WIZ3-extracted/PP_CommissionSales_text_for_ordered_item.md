# PP_CommissionSales_text_for_ordered_item

- **Source:** `PP_CommissionSales_text_for_ordered_item.htm`

PP_CommissionSales_text_for_ordered_item 
 
 
- 
 
 
 

If the order is based on a price quotation, any remarks recorded for this item in the quote are automatically copied to the order item. Otherwise, if the Copy Part Remarks column is flagged for commission orders in the Copy Part Remarks to Document form, remarks are taken from the Parts - Remarks form, a sub-level of the Part Catalogue .
