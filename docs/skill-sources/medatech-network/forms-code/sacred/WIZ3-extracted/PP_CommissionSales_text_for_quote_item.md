# PP_CommissionSales_text_for_quote_item

- **Source:** `PP_CommissionSales_text_for_quote_item.htm`

PP_CommissionSales_text_for_quote_item 
 
 
- 
 
 
 

If the quote is based on an RFQ, any remarks recorded for this item in the RFQ are automatically copied to the quoted item. Otherwise, if the Copy Part Remarks column is flagged for commission sale quotes in the Copy Part Remarks to Document form, remarks are taken from the Parts - Remarks form, a sub-level of the Part Catalogue .
