# PP_Consignment_transit

- **Source:** `PP_Consignment_transit.htm`

PP_Consignment_transit 
 
 
- 
 
 
 

A transit warehouse is a virtual warehouse defined by the user in which inventory is recorded that is actually in transit to the consignment warehouse. This warehouse is useful when it is expected to take a long time for the goods to arrive at their destination. It allows the system to take such goods into account when calculating inventory levels in consignment warehouses for purposes of replenishment.
