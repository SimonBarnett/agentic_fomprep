# Contra Items 

 

An account is included under the contra item if it is an asset account with a credit balance, or a liability or equity account with a debit balance. If no contra item is defined, the account always appears under its original item. 
 

 Note : The contra item must already be recorded in the form, either predefined or as an item added manually.
