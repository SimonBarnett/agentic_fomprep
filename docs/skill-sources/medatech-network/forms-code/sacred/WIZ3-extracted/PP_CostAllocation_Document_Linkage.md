# PP_CostAllocation_Document_Linkage

- **Source:** `PP_CostAllocation_Document_Linkage.htm`

PP_CostAllocation_Document_Linkage 
 
 
- 
 
 
 

When you record a profit or cost center for an item in a sales order, it will appear in any customer shipment based on the order, then in any invoice based on the shipment. Finally, when the invoice is finalized, it will appear in the journal entry.
