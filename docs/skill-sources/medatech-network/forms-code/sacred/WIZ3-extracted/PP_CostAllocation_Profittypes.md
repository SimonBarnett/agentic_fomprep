# PP_CostAllocation_Profittypes

- **Source:** `PP_CostAllocation_Profittypes.htm`

PP_CostAllocation_Profittypes 
 
 
- 
 
 
 

You could assign profit centers from Group 1 to accounting families, profit centers from Group 2 to customer groups and profit centers from Group 3 to branches. Three profit centers would then be recorded for each invoice item, depending on the accounting family to which the item belongs, the customer group assigned to the customer for which the invoice was opened and the branch in which the document was recorded.
