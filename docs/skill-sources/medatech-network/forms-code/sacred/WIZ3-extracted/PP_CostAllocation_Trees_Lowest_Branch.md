# PP_CostAllocation_Trees_Lowest_Branch

- **Source:** `PP_CostAllocation_Trees_Lowest_Branch.htm`

PP_CostAllocation_Trees_Lowest_Branch 
 
 
- 
 
 
 

In a one-level tree, assign profit/cost centers to the top-level code with two asterisks (e.g., 1**). 
 

In a two-level tree, assign profit/cost centers to branch codes with one asterisk (e.g., 11*, 12*). 
 

In a three-level tree, assign profit/cost centers to sub-branch codes with no asterisk (e.g., 111, 121).
