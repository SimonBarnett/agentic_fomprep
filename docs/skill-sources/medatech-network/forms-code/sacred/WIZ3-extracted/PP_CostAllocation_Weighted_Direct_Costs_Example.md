PP_CostAllocation_Weighted_Direct_Costs_Example 
 
 
- 
 
 
 

A hotel has two types of rooms (Suite and Standard), each of which is defined as a profit center. There are 200 standard rooms, whereas there are only 50 suites; accordingly, the profit centers are assigned weights of 4 and 1, out of a total 5. The laundry bill is an indirect cost that must be divided between these profit centers. 
 

The direct cost of suites last month was $10,000, and the direct cost of standard rooms was $15,000. Their weighted average is calculated as follows: 10,000 x 1/5 + 15,000 x 4/5 = $14,000. The laundry bill of $3000 is distributed among the profit centers in the following manner: 
 

Suite: 3000 x 1/5 x 10,000 / 14000 = $428.57 
 

Standard: 3000 x 4/5 x 15,000 / 14000 = $2571.43
