# PP_Costing_Bonded_Warehouse

- **Source:** `PP_Costing_Bonded_Warehouse.htm`

PP_Costing_Bonded_Warehouse 
 
 
- 
 
 
 

When imported goods enter a bonded warehouse, shipping/importing expenses are documented in the shipping voucher. The subsequent release of these goods is documented in Release from Bonded Warehouse documents. 
 

In such a case, costing ignores the expenses documented in the shipping voucher, instead taking the total import costs recorded for each released item (including a portion of the expenses taken from the shipping voucher, customs duties and extra costs related to the release process).
