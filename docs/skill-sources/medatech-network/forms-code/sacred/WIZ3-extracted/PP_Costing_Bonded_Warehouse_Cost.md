# PP_Costing_Bonded_Warehouse_Cost

- **Source:** `PP_Costing_Bonded_Warehouse_Cost.htm`

PP_Costing_Bonded_Warehouse_Cost 
 
 
- 
 
 
 

Bonded warehouses are not included in costing calculations; consequently, the receipt of goods into a bonded warehouse is not considered an incoming inventory transaction. If no further shipping expenses are calculated or recorded in the Release from Bonded Warehouse form when such goods enter inventory, part cost is calculated according to the unit price recorded in the invoice, without the shipping expenses, and the cost source that appears is "Shipping Voucher". 
 

If, however, the cost of a line in a Release from Bonded Warehouse document is recalculated or recorded manually, the part cost will include shipping expenses, and the cost source will be "Transact" (in order to prevent the costing program from recalculating costs).
