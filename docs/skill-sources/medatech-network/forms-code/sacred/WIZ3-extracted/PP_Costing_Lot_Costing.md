# PP_Costing_Lot_Costing

- **Source:** `PP_Costing_Lot_Costing.htm`

PP_Costing_Lot_Costing 
 
 
- 
 
 
 

The costing program can calculate inventory valuations of purchased items by the lots in which they were received. If you chose to run costing without taking lot costs into account, the system records order lot data (e.g., expiration dates) for that inventory, but does not maintain separate costs for each lot.
