PP_Costing_Misc_Factors 
 
 
- 
 
 
 

The report does not take into account: 
 

 ·        Incoming transactions that were recorded prior to the costing initialization date. 
 

 ·        Transactions regarded by costing as inventory returns (e.g., a negative issue of supplies, intended to reduce a previous issue that was found to be excessive).
