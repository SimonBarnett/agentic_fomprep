# PP_Costing_Recent_Receipts

- **Source:** `PP_Costing_Recent_Receipts.htm`

PP_Costing_Recent_Receipts 
 
 
- 
 
 
 

The report displays the latest inventory receipts needed to account for the current part balance. For example, if there are 1000 units of the part in inventory and the most recent inventory receipts are as follows: 
 

 ·      Dec. 2: 200 units 
 

 ·      Nov. 2: 500 units 
 

 ·      Oct. 2: 300 units 
 

 ·      Sept. 2: 400 units, 
 

the report will display the receipts for December, November and October, which together equal the current inventory balance.
