# PP_Costing_Shipping_Cost_Type

- **Source:** `PP_Costing_Shipping_Cost_Type.htm`

PP_Costing_Shipping_Cost_Type 
 
 
- 
 
 
 

The shipping cost type refers to the method by which a part is shipped: by air (A), sea (S) or land (L). The costing program uses this definition to determine whether to take into account standard air cost, sea cost or land cost.
