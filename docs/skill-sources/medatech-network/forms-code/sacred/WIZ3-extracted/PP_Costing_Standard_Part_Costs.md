# PP_Costing_Standard_Part_Costs

- **Source:** `PP_Costing_Standard_Part_Costs.htm`

PP_Costing_Standard_Part_Costs 
 
 
- 
 
 
 

If the Std. Material Cost option is chosen, standard costs are determined by the standard costs of the assembled part's components. 
 

If the Actual Material Cost option is chosen, standard costs are determined by the actual cost of the assembled part's raw materials (Type R child parts), and the standard cost of all sub-assemblies (Type P child parts).
