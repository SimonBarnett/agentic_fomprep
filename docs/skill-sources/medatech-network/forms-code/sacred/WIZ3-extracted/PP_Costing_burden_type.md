# PP_Costing_burden_type

- **Source:** `PP_Costing_burden_type.htm`

PP_Costing_burden_type 
 
 
- 
 
 
 

The burden type determines how an expense is distributed among the purchased items (by weight, volume, price or quantity purchased). For example, if you define weight as the burden type for the part "Air Shipment", that expense will be divided among the shipped items according to their weight.
