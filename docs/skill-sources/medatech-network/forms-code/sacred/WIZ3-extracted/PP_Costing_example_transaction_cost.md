# PP_Costing_example_transaction_cost

- **Source:** `PP_Costing_example_transaction_cost.htm`

PP_Costing_example_transaction_cost 
 
 
- 
 
 
 

During a certain period, you placed several large orders with the same vendor, consequently receiving a larger discount than usual. The initial orders, however, were for the list prices and did not include the discount. When the first shipments arrived, their costs were determined online by the purchase order price. However, when you received the monthly invoice it displayed prices reduced by significant discounts. The costing that you run after receiving the invoice will update the cost of the receipt of goods in keeping with the invoice price. This is because the invoice price is stronger (higher in the cost source hierarchy) and more accurate than the purchase order price.
