PP_Costing_importing_file

Shipping vouchers are used to link parts representing expenses to the purchased parts that incurred those expenses. This enables the costing program to distribute the expenses among the purchased parts, according to defined parameters. It also enables you to preview the distribution results before costing is run. 
 

Shipping vouchers are particularly useful when a single expense invoice applies to parts recorded in several different purchase invoices, or when several different expense invoices apply to the same purchase invoice.
