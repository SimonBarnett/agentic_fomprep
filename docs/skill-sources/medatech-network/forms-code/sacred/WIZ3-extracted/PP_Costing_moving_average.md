# PP_Costing_moving_average

- **Source:** `PP_Costing_moving_average.htm`

PP_Costing_moving_average 
 
 
- 
 
 
 

The Moving Average method views each warehouse like a vat – inventory that enters it mixes with the existing inventory, and whatever comes out is composed of this mixture. When new items enter inventory, a new weighted average cost is calculated for that part. Because all parts are considered to share the same cost, parts leaving inventory do not affect the cost average. 
 

For example, assume that there are 100 units of a certain part in inventory, costing $30 per unit. When 50 additional units enter inventory, at a cost of $20 per unit, the new average cost of the part is $26.67, according to the formula: (100 ´ 30 + 50 ´ 20) / 150. 
 

If 30 units of the part then leave, the cost of the part will NOT be updated, rather: 
 

(100 ´ 30 + 50 ´ 20 - 30 ´ 26.67) / 120 = 26.67.
