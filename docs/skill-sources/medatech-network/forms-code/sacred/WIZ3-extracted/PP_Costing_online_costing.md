# PP_Costing_online_costing

- **Source:** `PP_Costing_online_costing.htm`

PP_Costing_online_costing 
 
 
- 
 
 
 

Online costing provides a running cost estimate that takes into account inventory that has been received since the previous costing run. Whenever a GRV or vendor invoice is finalized, the system recalculates the cost of each part on the basis of the cost of the receipt, and updates the Cost column (for dual-currency users, this may be the second currency Cost column) in the Part Catalogue form.
