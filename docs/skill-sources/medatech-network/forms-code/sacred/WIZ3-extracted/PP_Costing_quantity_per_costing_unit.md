# PP_Costing_quantity_per_costing_unit

- **Source:** `PP_Costing_quantity_per_costing_unit.htm`

PP_Costing_quantity_per_costing_unit 
 
 
- 
 
 
 

The cost of one nail is $0.001. For the sake of convenience (and to avoid rounding the cost to zero), you can record a standard cost of $1 per 1000 nails, which you then define as the part's costing unit . Standard cost and other costs will be defined in units of 1000.
