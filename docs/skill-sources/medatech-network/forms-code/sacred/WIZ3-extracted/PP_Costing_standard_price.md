# PP_Costing_standard_price

- **Source:** `PP_Costing_standard_price.htm`

PP_Costing_standard_price 
 
 
- 
 
 
 

Standard part costs provide both input to standard costing and a default cost source for actual costing, when no other data is available. When recorded prior to the initial inventory count, they can also be used to initialize inventory values.
