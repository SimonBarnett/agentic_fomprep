# Why Do We Need a Past Balance?

 

The purpose of costing for past balance dates is to compare part costs and inventory values at different points in time. To maintain the integrity of this data, inventory values must not be changed retroactively in the period preceding the costing date. The past balance program calculates inventory balances for a given date and "locks" the inventory system, such that you cannot record, revise or delete any inventory transactions recorded prior to that date. 
 

The breakdown into past balance periods facilitates the analysis of results, and reduces the run time of the programs that calculate inventory balances and inventory valuations.
