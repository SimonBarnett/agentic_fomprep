# PP_Costing_work_hour_cost

- **Source:** `PP_Costing_work_hour_cost.htm`

PP_Costing_work_hour_cost 
 
 
- 
 
 
 

When a warehouse assembly is reported, the number of work hours performed by each employee for that assembly is recorded. The cost of these work hours is determined by the standard cost defined for the work hour part assigned to each user.
