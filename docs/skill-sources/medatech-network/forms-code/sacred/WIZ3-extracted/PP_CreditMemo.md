# PP_CreditMemo

- **Source:** `PP_CreditMemo.htm`

PP_CreditMemo 
 
 
- 
 
 
 

Use a credit memo to credit customers for overcharges (regardless of the type of invoice in which the customer was billed). 
 

Also use it to record credit for returns . Depending on how the customer was originally charged, you can record a credit memo via a multi-shipment invoice (in which case a separate return document must also be recorded) or via a sales invoice (as negative quantities, provided the Negative Sum Counter column is flagged for sales invoices in the Financial Documents form).
