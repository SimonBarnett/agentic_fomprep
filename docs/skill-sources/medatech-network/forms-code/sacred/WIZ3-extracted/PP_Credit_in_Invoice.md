# PP_Credit_in_Invoice

- **Source:** `PP_Credit_in_Invoice.htm`

PP_Credit_in_Invoice 
 
 
- 
 
 
 

You can include credit for returns (as a negative quantity), together with charges for shipments, within a multi-shipment invoice , provided that the original shipment was billed in a multi-shipment invoice and a separate return document was recorded.
