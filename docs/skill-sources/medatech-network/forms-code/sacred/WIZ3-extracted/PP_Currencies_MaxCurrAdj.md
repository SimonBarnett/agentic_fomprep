# PP_Currencies_MaxCurrAdj

- **Source:** `PP_Currencies_MaxCurrAdj.htm`

PP_Currencies_MaxCurrAdj 
 
 
- 
 
 
 

If the exchange rate between the U.S. dollar and the Euro is currently 1.217 and the MaxCurrAdj constant is set to 10%, the rate may increase to 1.337 (1.217 + 0.12) or decrease to 1.097 (1.217 - 0.12) without generating a warning.
