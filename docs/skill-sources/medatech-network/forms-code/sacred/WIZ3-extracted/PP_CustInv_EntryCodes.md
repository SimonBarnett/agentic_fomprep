# PP_CustInv_EntryCodes

- **Source:** `PP_CustInv_EntryCodes.htm`

PP_CustInv_EntryCodes 
 
 
- 
 
 
 

The entry code determines the accounts included in the journal entry for this invoice and the amounts debited/credited against each. It is taken from the debit entry code assigned to this customer or, if there is none, by the predefined entry code for this type of invoice. For more details, see the Set Up Entry Codes Wizard .
