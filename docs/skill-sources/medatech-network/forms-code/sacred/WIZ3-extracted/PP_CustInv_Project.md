# PP_CustInv_Project

- **Source:** `PP_CustInv_Project.htm`

PP_CustInv_Project 
 
 
- 
 
 
 

By linking a customer invoice or credit memo to a project, you can keep track of the charges and credits against each project. Moreover, the default income account assigned to the project (defined in the Accounts for Projects form) serves as the income account for the invoice/memo. 
 

A project appears automatically in the following cases: 
 

 ·        When a single project is recorded for the customer, and the SLinkProject constant is set to 1 . 
 

 ·        When the invoice/memo is based on a document linked to a project.
