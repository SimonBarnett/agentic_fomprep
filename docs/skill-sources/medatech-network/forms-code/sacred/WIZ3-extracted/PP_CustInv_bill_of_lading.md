# PP_CustInv_bill_of_lading

PP_CustInv_bill_of_lading 
 
 
- 
 
 
 

When packed crates are included in a sales invoice, this is called a bill of lading. Sales invoices that are used as a bill of lading can include any crates that are recorded in final packing slips, earmarked for the invoiced customer (or packed for stock), and located in the sending warehouse and bin recorded for the invoice.
