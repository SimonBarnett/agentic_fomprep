# PP_CustInv_export_invoice

- **Source:** `PP_CustInv_export_invoice.htm`

PP_CustInv_export_invoice 
 
 
- 
 
 
 

An export invoice is used to bill foreign customers for shipped goods. Like a multi-shipment invoice, it does not create an inventory transaction. This type of invoice is also used to bill foreign customers for service contracts, service calls and projects.
