# PP_CustInv_multiship_invoice

- **Source:** `PP_CustInv_multiship_invoice.htm`

PP_CustInv_multiship_invoice 
 
 
- 
 
 
 

A multi-shipment invoice bills the customer for shipped goods but, unlike other Priority invoices (except for export invoices in the dual-currency package), does not create an inventory transaction. 
 

Use this type of invoice when you want to bill the customer independently of shipping documents, such as when you are invoicing multiple shipments together. Also use this type of invoice to bill for service contracts, service calls and projects.
