# PP_CustInv_order_tolerance

- **Source:** `PP_CustInv_order_tolerance.htm`

PP_CustInv_order_tolerance 
 
 
- 
 
 
 

The total shipment of a given part (which can include several different shipments) cannot exceed the order balance by a percentage greater than the order tolerance. For example, if the order tolerance for widgets is 10% and the order is for 200 units, you cannot record an invoice for more than 220 widgets.
