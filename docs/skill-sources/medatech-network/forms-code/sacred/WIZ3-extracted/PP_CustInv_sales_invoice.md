# PP_CustInv_sales_invoice

- **Source:** `PP_CustInv_sales_invoice.htm`

PP_CustInv_sales_invoice 
 
 
- 
 
 
 

A sales invoice both bills the customer for shipped goods and serves as a shipping document. 
 

As an invoice, it generates a journal entry for the sale. As a shipping document, it deducts the delivered goods from inventory.
