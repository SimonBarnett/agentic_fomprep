# PP_CustShip_return_quantity

- **Source:** `PP_CustShip_return_quantity.htm`

PP_CustShip_return_quantity 
 
 
- 
 
 
 

You may have shipped a large selection of goods, of which only one or two parts are being returned. While all items are copied from the shipping document, you record quantities only for the returned items. All items with quantities of zero (those that are not returned) will be deleted once the document is finalized.
