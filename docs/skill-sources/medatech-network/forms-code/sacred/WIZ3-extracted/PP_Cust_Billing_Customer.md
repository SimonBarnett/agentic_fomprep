# PP_Cust_Billing_Customer

- **Source:** `PP_Cust_Billing_Customer.htm`

PP_Cust_Billing_Customer 
 
 
- 
 
 
 

You can link several customers to a billing customer, and all of their invoices will debit the billing customer's account. You can also instruct the system to send their invoices to the billing customer's address.
