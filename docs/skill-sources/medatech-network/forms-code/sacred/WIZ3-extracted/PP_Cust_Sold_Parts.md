# PP_Cust_Sold_Parts

- **Source:** `PP_Cust_Sold_Parts.htm`

PP_Cust_Sold_Parts 
 
 
- 
 
 
 

A list of parts can be defined for a particular customer, which appears in the Choose list when recording a sales order. If a list has been made both for an individual customer and the representative customer, the parts on both lists are available to that customer. 
 

If you flag a customer in the Ship Cust Parts Only column of the Customers form, the customer is only permitted to order parts on the defined customer or representative part list.
