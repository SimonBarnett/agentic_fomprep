# PP_Customer_Credit_Definition

- **Source:** `PP_Customer_Credit_Definition.htm`

PP_Customer_Credit_Definition 
 
 
- 
 
 
 

Customer credit is defined as: 
 

 ·        open orders (provided the CreditOrders constant is set at 0 or 1 ) 
 

 ·        unbilled documents (unbilled shipments/uncredited returns, unbilled service calls, and contract and project payment installments that have not been invoiced) 
 

 ·        unbilled reported project hours 
 

 ·        pending sales invoices 
 

 ·        unpaid bills.
