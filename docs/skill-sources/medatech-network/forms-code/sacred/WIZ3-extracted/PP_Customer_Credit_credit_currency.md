# PP_Customer_Credit_credit_currency

- **Source:** `PP_Customer_Credit_credit_currency.htm`

PP_Customer_Credit_credit_currency 
 
 
- 
 
 
 

You might use a different currency in an international multi-company setting. Suppose your company has a subsidiary in another country, and both companies work with the same customer. The customer has a different billing currency in each of your companies, and you want to define a multi-company credit limit. In this case, you would have to select one of these currencies as the Credit Currency .
