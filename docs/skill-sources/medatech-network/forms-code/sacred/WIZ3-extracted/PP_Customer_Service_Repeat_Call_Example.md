PP_Customer_Service_Repeat_Call_Example 
 
 
- 
 
 
 

If the CRepCallDays constant is set to 3, a call opened today is considered a repeat call of a call opened two days ago. If it is set to 1, only new calls opened on the same day are considered repeat calls.
