# PP_Customer_Service_Service_Calls_Repeat_Call_Definition

- **Source:** `PP_Customer_Service_Service_Calls_Repeat_Call_Definition.htm`

PP_Customer_Service_Service_Calls_Repeat_Call_Definition 
 
 
- 
 
 
 

For the same serialized part, a second service call that is opened within a certain number of days of the original call (e.g., within seven days).
