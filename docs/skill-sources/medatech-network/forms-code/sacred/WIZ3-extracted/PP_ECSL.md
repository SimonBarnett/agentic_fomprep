# PP_ECSL

- **Source:** `PP_ECSL.htm`

PP_ECSL 
 
 
- 
 
 
 

If you are registered for VAT and you supply goods to businesses registered for VAT in other European Community (EC) member states, you must declare these sales on an EC Sales List (ECSL). The information provided is used by EC member states to ensure that VAT has been correctly accounted for.
