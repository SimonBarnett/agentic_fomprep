# PP_EntryCodes_other_field_codes

PP_EntryCodes_other_field_codes 
 
 
- 
 
 
 

 Other codes: 
 

2 – used to debit/credit only the net amount (without tax). This is relevant only in entry codes for financial documents. 
 

3 – used to debit/credit only the tax amount. This is relevant only in entry codes for financial documents. 
 

5 – used to debit/credit only taxable items. 
 

6 – used to debit/credit only non-taxable items. 
 

7 – used to debit/credit taxes withheld from a payment to a vendor (dual-currency package). 
 

8 – used to debit/credit payment to a vendor after taxes have been withheld (dual-currency package). 
 

9 – used when a customer payment was returned, to debit/credit the penalty amount. 
 

10 – used when a discounted rate has been received for payment within a certain number of days, to debit/credit the amount discounted.
