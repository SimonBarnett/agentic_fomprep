# PP_EntryCodes_source_of_details

- **Source:** `PP_EntryCodes_source_of_details.htm`

PP_EntryCodes_source_of_details 
 
 
- 
 
 
 

The value in the Source of Details column determines the default type of details that are to be attached to journal entries of this type. For instance, if you choose "Invoice Details," details will be taken from the original invoice. 
 

If you wish to manually designate default details for this entry code, choose "Code Details" (or "Month+Code Details"), and record the details in the Details column.
