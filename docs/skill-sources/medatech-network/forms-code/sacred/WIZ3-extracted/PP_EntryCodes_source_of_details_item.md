# PP_EntryCodes_source_of_details_item

- **Source:** `PP_EntryCodes_source_of_details_item.htm`

PP_EntryCodes_source_of_details_item 
 
 
- 
 
 
 

The value in the Source of Details column determines the default type of details that are to be attached to items of journal entries of this type. For instance, if you choose "Invoice Details," details for this account will be taken from the original invoice. 
 

If you wish to manually designate default details for this account, choose "Code Details" (or "Month+Code Details"), and record the details in the Details column.
