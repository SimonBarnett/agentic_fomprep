# PP_EntryCodes_split

PP_EntryCodes_split 
 
 
- 
 
 
 

There are a number of cases in which you may want to split the sum that was recorded in the account: 
 

 ·        Split by payment terms: when the payment terms of an invoice allow for a number of installments. 
 

 ·        Split by LineItems account pattern: when you want each item to appear on a separate line in the journal entry. 
 

 ·        Split by receipts: when a number of checks (or other forms of payments) are covered by the same receipt, and you wish to record them separately in the customer account.
