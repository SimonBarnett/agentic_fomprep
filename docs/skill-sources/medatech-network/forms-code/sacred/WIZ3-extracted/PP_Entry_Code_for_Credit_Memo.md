# PP_Entry_Code_for_Credit_Memo

- **Source:** `PP_Entry_Code_for_Credit_Memo.htm`

PP_Entry_Code_for_Credit_Memo 
 
 
- 
 
 
 

The entry code determines the accounts included in the journal entry for this credit memo and the amounts debited/credited against each. It is taken from the credit entry code assigned to this customer or, if there is none, by the predefined entry code for credit memos. For more details, see the Set Up Entry Codes Wizard .
