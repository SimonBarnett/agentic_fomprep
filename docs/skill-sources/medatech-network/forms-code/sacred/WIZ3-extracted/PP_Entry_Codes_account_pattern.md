# PP_Entry_Codes_account_pattern

- **Source:** `PP_Entry_Codes_account_pattern.htm`

PP_Entry_Codes_account_pattern 
 
 
- 
 
 
 

 Priority provides predefined account patterns which represent different types of accounts. When a journal entry is created automatically from the financial document, the actual account is taken from the document. For example, the A/P pattern represents vendor accounts and is included in the entry pattern VND which is predefined for vendor invoice. When recording a vendor invoice, in the journal entry which is automatically created, the vendor account itself is used instead of the A/P pattern.
