# PP_FAQ_special_pricelist

- **Source:** `PP_FAQ_special_pricelist.htm`

PP_FAQ_special_pricelist 
 
 
- 
 
 
 

A special price list (with relatively low prices) is usually used for a specific price quote, order or invoice. Item discounts are not applied to prices taken from this price list, but overall discounts are applied to the total transaction.
