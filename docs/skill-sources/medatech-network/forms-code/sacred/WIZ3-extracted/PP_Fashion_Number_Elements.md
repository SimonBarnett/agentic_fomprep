# PP_Fashion_Number_Elements

- **Source:** `PP_Fashion_Number_Elements.htm`

PP_Fashion_Number_Elements 
 
 
- 
 
 
 

The number of each fashion item is a composite of its spec codes. For example, the following codes were assigned to these Color values: 
 

Black: 01 
 

Brown: 02 
 

White: 03 
 

If the part number of the Running Shoe style is 102 (and the defined size values are 28 , 30 and 32 ), the part numbers for its derived items will look like this: 
 

102-01-28, 102-01-30, 102-01-32, 102-02-28, etc.
