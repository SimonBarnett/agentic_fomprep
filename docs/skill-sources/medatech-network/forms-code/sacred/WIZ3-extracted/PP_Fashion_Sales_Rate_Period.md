# PP_Fashion_Sales_Rate_Period

- **Source:** `PP_Fashion_Sales_Rate_Period.htm`

PP_Fashion_Sales_Rate_Period 
 
 
- 
 
 
 

If the base period is set at 365 days (one year) and you define a 90-day period for Style X that corresponds to the usual sales season, the system calculates the sum total of all items in that style that were sold during the last year, and divides it either by 90 days, or by the equivalent number of weeks, to determine daily and weekly sales rates.
