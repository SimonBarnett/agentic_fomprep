# PP_Fashion_Separators

- **Source:** `PP_Fashion_Separators.htm`

PP_Fashion_Separators 
 
 
- 
 
 
 

Separators connect the various spec codes into a single part number for a fashion item. For example, you may choose to use hyphens ( 102-01-28 ), slashes ( 102/01/28 ), commas ( 102,01,28 ) or no separator at all ( 1020128 ).
