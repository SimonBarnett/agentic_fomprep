# PP_Fashion_Update_Kit

- **Source:** `PP_Fashion_Update_Kit.htm`

PP_Fashion_Update_Kit 
 
 
- 
 
 
 

The original work order quantity for a run of blue jeans was 100. In practice, 110 pairs were cut from the available cloth. Consequently, the number of zippers and buttons required for this work order is now 110. In this case, you need to update both the work order kit list (for the cut cloth as well as the zippers and buttons) and the assortment matrix.
