Press F6 from the Initial Status column to access the status form for each document type and view the attributes of its initial status. To revise those attributes, add new statuses and update existing ones, run the BPM flow chart by Direct Activation from the status form. 
 

For detailed instructions on using BPM flow charts, see the User Interface Guide .
