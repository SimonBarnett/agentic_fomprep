# PP_Financial_Docs_entry_code_example

- **Source:** `PP_Financial_Docs_entry_code_example.htm`

PP_Financial_Docs_entry_code_example 
 
 
- 
 
 
 

You can define an entry code INN as the default for documents of type INV (i.e., sales invoices) for the northern branch, and INS for the southern branch. Whenever an employee of the northern branch opens a sales invoice, the entry code INN is assigned to the invoice; whenever an employee of the southern branch opens a sales invoice, the entry code INS is assigned to the invoice.
