# PP_Fiscal_Periods_transaction_dates

PP_Fiscal_Periods_transaction_dates 
 
 
- 
 
 
 

The transaction date determines the month in which the entry is recorded in the ledger. It is usually the date the transaction is recorded in Priority . 
 

The reference date is the original date of the transaction. It is often the same as the transaction date. 
 

 Example of two different dates: On July 3, you receive a vendor invoice dated June 28. You have already produced a balance sheet for June. Record a reference date of June 28 and a transaction date of July 3.
