# PP_FixedAssets_Base_Indexes

- **Source:** `PP_FixedAssets_Base_Indexes.htm`

PP_FixedAssets_Base_Indexes 
 
 
- 
 
 
 

When an asset is sold, tax is withheld from the revenue based on the adjusted value of the asset (i.e., its value after inflation). When an asset is bought and sold according to different index bases, its value cannot be calculated without comparing the two base rates and making the necessary adjustment. 
 

Your local authorities may periodically release a new index base according to which the cost of living is calculated. The ratio between one index base and another is also usually published by the same authorities. 
 

For example, if the Price Index (recorded in the Currencies form) uses the index base from 1998, and assets were recorded in the system in 1993, record the conversion rate between the index of 1998 and that of 1993, as provided by your local government authority.
