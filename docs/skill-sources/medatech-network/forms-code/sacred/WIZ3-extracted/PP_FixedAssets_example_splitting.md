The asset "computer" (whose value was $1000) has been split into two assets after two years, the principal asset "computer" ($800) and the new asset "modem" ($200). 
 

The modem inherited all of the definitions of the original computer in which it was installed (e.g., accounts, depreciation definitions for accounting and taxes). 
 

The computer, whose annual depreciation before the split amounted to $100, will now depreciate annually by $80.
