# PP_GL_Bal_Sheet

- **Source:** `PP_GL_Bal_Sheet.htm`

PP_GL_Bal_Sheet 
 
 
- 
 
 
 

The item in the balance sheet OR profit & loss report (depending on the type of account) in which to include the account. For example, include an account for salaries in the Salary Expenses item, which is part of the P&L report.
