PP_GL_VAT_Report_Item 
 
 
- 
 
 
 

 Dual-currency users: Link the account to the appropriate VAT Report Item if it is one of the following: 
 

 ·        An income account 
 

 ·        Any kind of VAT account 
 

 ·        A vendor's withholding tax account 
 

 ·        A customer's withholding tax account.
