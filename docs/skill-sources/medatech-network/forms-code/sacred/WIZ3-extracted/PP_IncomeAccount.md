# PP_IncomeAccount

- **Source:** `PP_IncomeAccount.htm`

PP_IncomeAccount 
 
 
- 
 
 
 

The income account that appears automatically may come from a variety of sources, such as: 
 

 ·        the account linked to the project for which the invoice/memo has been recorded 
 

 ·        the account linked to the budget item assigned to this line item 
 

 ·        the default income account, as defined for the entire system, per warehouse, per accounting family, per customer group, etc.
