# PP_Inventory_Count_Past_Date

- **Source:** `PP_Inventory_Count_Past_Date.htm`

PP_Inventory_Count_Past_Date 
 
 
- 
 
 
 

When the inventory count is performed for a date in the past, inventory levels from the latest past balance form the basis for calculated quantities. Then, quantities are added or subtracted in accordance with any transactions recorded after that past balance was generated.
