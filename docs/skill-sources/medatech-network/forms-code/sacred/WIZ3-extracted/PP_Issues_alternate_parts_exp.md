# PP_Issues_alternate_parts_exp

- **Source:** `PP_Issues_alternate_parts_exp.htm`

PP_Issues_alternate_parts_exp 
 
 
- 
 
 
 

An alternate part is a part that can replace a child part in the routing of a given parent part. 
 

When the system is instructed to issue a child part in quantities larger than the inventory balance available in the warehouse, it automatically tries to complete the issue with inventory of the alternate part (unless the relevant system constant has been set not to allow alternate parts, or no such part has been defined).
