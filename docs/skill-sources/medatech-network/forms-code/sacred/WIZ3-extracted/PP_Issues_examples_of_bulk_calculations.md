PP_Issues_examples_of_bulk_calculations 
 
 
- 
 
 
 

Preparing issues on the basis of MRP calculations allows you to control the parameters by which the Issues Plan is created (by changing the MRP runtime options). This method also allows you to take into account future production (i.e., planned work orders that have not been released). 
 

By contrast, preparing issues on the basis of open, released work orders allows you to focus on what is required in specific warehouses at the current moment. Use this method when there is a relatively constant flow of raw materials to the plant floor. 
 

Preparing issues on the basis of minimum inventory balances is appropriate when the consumption of raw materials is relatively constant in plant floor warehouses, and you want to maintain a fixed minimum balance accordingly.
