# Issue of Supplies

 

This type of issue is used for parts that are required in the production process, yet are not considered components of the processed part. Inventory issued as supplies is reduced from the inventory in the warehouse from which it is issued, but does not appear as floor inventory. 
 

Example of this type of part: machine oil, cleaning supplies, drafting pencils.
