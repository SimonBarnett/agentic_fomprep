# Bulk Issue

 

When issuing in bulk to the plant floor, the quantity of parts issued is unrelated to any work order. This quantity is calculated for all production needs; that is, it is intended for all work orders that require the part. If you are working with MRP, issue quantities are calculated by the Issues Plan; otherwise, they are calculated according to the total quantities required for all released and open work orders, or according to the minimum floor stock defined for the child parts. 
 

Examples of this type of part: screws, paint, and electrical wire.
