# Issue to Kit

 

When issuing to a kit, the entire issued quantity is intended for a specific work order, and is not available for other work orders. This method is useful for relatively expensive parts whose use requires tracking. 
 

Examples of this type of part: electronic components (e.g., processors, memory chips).
