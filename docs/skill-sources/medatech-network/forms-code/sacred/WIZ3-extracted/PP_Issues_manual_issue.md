# Manual Issue

 

Manual issues are recorded when production is reported. In this case, the required parts are not issued in advance, in preparation for production, but rather are drawn from inventory during the production process. This method is generally used to issue particularly expensive parts or parts that require special storage conditions that are not available on the plant floor. 
 

Examples of this type of part: diamonds, gold.
