# PP_Issuing_Warehouse

- **Source:** `PP_Issuing_Warehouse.htm`

PP_Issuing_Warehouse 
 
 
- 
 
 
 

An issuing warehouse issues parts to kits on a specific plant floor. It is usually needed when you have multiple plant floors located some distance apart (e.g., in different cities). For more information, see the Work Orders Wizard .
