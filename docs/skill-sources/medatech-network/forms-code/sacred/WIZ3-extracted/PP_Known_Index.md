# PP_Known_Index

- **Source:** `PP_Known_Index.htm`

PP_Known_Index 
 
 
- 
 
 
 

The regular Price Index is updated retroactively, whenever a new index value is published by local authorities (usually, once a month). For example, if index values are published on the 15 th of every month, then the index value for April is not available until May 15. This value is then assigned (in the Currencies form) to the Price Index for the first and last dates in April. 
 

Loan payments, however, are often linked to the index that is currently in effect. This is last month's index if it has already been published. But it could also be the value in effect two months ago, if last month's index value is not yet available (e.g., if the loan is taken out on May 10, April's index value is not yet known; the last known index in this case would be the one for March). 
 

You therefore need to maintain a separate Last Known Index (also in the Currencies form) for loan payments.
