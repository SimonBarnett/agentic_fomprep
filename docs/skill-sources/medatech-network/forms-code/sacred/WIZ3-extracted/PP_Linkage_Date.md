# PP_Linkage_Date

- **Source:** `PP_Linkage_Date.htm`

PP_Linkage_Date 
 
 
- 
 
 
 

The linkage date determines the exchange rate, price index or price list that is used when adjusting prices. That is, prices can be adjusted to the date of the sales order (when adjusting prices from a blanket order), the date of the shipment or the date of the customer invoice. This is originally determined by the linkage date assigned to this customer or, if there is no customer definition, by the value of the LinkDate constant.
