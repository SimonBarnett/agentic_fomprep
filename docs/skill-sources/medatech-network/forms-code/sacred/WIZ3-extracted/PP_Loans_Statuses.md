# PP_Loans_Statuses

- **Source:** `PP_Loans_Statuses.htm`

PP_Loans_Statuses 
 
 
- 
 
 
 
 
 
 

 Status 
 
 

 Properties 
 
 
 

 Draft 
 
 

Assign when the loan is first opened. 
 
 
 

 Active 
 
 

Transactions can be recorded in the entry journal.
The system checks that amounts entered for various loan parameters (e.g., amount of loan, amount of each payment, number of payments) are compatible. 
 
 
 

 Frozen 
 
 

Assign when you postpone a payment installment. 
 
 
 

 Closed 
 
 

Assign when the loan is fully paid.
