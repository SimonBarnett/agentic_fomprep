# PP_MRPBus_Forecast_Stock

- **Source:** `PP_MRPBus_Forecast_Stock.htm`

PP_MRPBus_Forecast/Stock 
 
 
- 
 
 
 

Orders to stock are used to generate inventory that is not reserved for a particular customer, but rather will be used to fill future sales orders. 
 

Forecast orders are a specific type of stock order, opened automatically on the basis of monthly demand forecasts. 
 

Both types of orders can be opened manually, by recording a sales order and assigning it an S or F in the Forecast/Stock column. 
 

The planning programs relate to both types in the same manner.
