# PP_MRPBus_Static_Demand

- **Source:** `PP_MRPBus_Static_Demand.htm`

PP_MRPBus_Static_Demand 
 
 
- 
 
 
 

Parts with replenishment type B are required in fixed amounts at regular intervals. This is called static demand , as it is not influenced by fluctuating sources of demand, such as sales orders for the part (or its parent).
