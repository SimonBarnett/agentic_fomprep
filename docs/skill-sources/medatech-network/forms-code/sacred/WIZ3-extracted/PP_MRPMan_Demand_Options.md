# PP_MRPMan_Demand_Options

- **Source:** `PP_MRPMan_Demand_Options.htm`

PP_MRPMan_Demand_Options 
 
 
- 
 
 
 

When the demand for a given part is calculated according to sales orders, MRP takes into account all orders whose due dates fall within the designated planning period. You can choose whether the program aggregates all orders per calendar month, planning a single monthly work order for each part, or aggregates demand according to the demand range defined separately for each part.
