# PP_MRPMan_MRPTolerance

- **Source:** `PP_MRPMan_MRPTolerance.htm`

PP_MRPMan_MRPTolerance 
 
 
- 
 
 
 

If the due date of a sales order is moved up by 10 days, and the assigned tolerance is only 7 days, the corresponding work order is not taken into account during MRP calculations, and appears in MRP results under the heading "Surplus Work Order". Similarly, if the due date of a purchase order (for a manufactured part, purchased from a vendor that is not a subcontractor) is delayed by 10 days, it is no longer considered available inventory for the current order, and a new work order is planned.
