# PP_MRPMan_Static_Demand

- **Source:** `PP_MRPMan_Static_Demand.htm`

PP_MRPMan_Static_Demand 
 
 
- 
 
 
 

Parts with Replenishment Type B are required in fixed amounts at regular intervals. This is called static demand , as it is not influenced by fluctuating sources of demand. If the part is purchased, MRP does not prepare issues for routine consumption; purchase planning opens requisitions directly for such parts, according to their defined consumption parameters. The replenishment type affects the calculation of direct part demand, which is added to the demand derived from open or planned work orders for parent parts, and from safety stock.
