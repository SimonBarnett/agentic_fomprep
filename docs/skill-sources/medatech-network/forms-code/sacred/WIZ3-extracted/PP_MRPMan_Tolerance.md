# PP_MRPMan_Tolerance

- **Source:** `PP_MRPMan_Tolerance.htm`

PP_MRPMan_Tolerance 
 
 
- 
 
 
 

Work order tolerance (defined by the MRPTolerance constant in the Production Constants form) is the maximum number of days that the end date of an open work order may lag behind the due date of the sales order for which it was originally opened, as well as the maximum number of days that the due date of a purchase order (for a manufactured part, purchased from a vendor that is not a subcontractor) may lag behind the start date of a work order and still be considered available inventory for that work order.
