# PP_MRPMan_WO_Params

- **Source:** `PP_MRPMan_WO_Params.htm`

PP_MRPMan_WO_Params 
 
 
- 
 
 
 

If 25 units of a given part have been ordered, and the minimum work order quantity of that part is 100 units, MRP will open a work order for 100 units. If 125 units of the part were ordered, and the work order increment for that part is 50, MRP will open a work order for 150 units.
