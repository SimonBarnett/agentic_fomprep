 Case: 
 

The planned issue of a child part to a certain work order is smaller than the amount required to produce the quantity of parent parts specified in the work order. When viewing the planned issue in the MRP Analysis - Raw Materials sub-level form, a value greater than 0 appears in the Use of Floor Stock column. In other words, MRP took into account existing inventory of the child part on the plant floor and reduced the quantity required for the work order accordingly.
