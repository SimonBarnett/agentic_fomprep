# PP_MRPMan_example_demand_range

- **Source:** `PP_MRPMan_example_demand_range.htm`

PP_MRPMan_example_demand_range 
 
 
- 
 
 
 

When running MRP, you can choose to combine several demands into one work order, either per monthly demand range, or according to the demand range defined for each part. 
 

That is, one work order will be opened for all part demands within the chosen time period (regardless of their source), on the first date of that period. 
 

 Note: If you choose the demand range option, and define a demand range of 0, a separate work order is opened for each demand for that part.
