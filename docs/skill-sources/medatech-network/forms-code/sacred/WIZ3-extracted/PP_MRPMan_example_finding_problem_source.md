 Case: 
 

According to the quantity of orders recorded for a certain part, 10 work orders should have been opened for that part, yet the program only opened 9. When viewing the Analysis of MRP Results (ATP) report, a line recording an open work order is displayed. This indicates that the program identified an existing released work order for that part, and reduced the quantity of the original demand by the work order's balance. Consequently, it was only necessary to plan 9 new work orders instead of 10.
