If the time required to perform the current operation on the specified quantity of parts is 4 days, and a 25% overlap has been defined for that operation, the start date of this operation will fall one day before the end date of the previous operation, according to the following formula: X - 25% ´ 4 = X - 1 (where X is the end date of the previous operation).
