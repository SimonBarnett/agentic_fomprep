# PP_MRPMan_example_overlap_part

- **Source:** `PP_MRPMan_example_overlap_part.htm`

PP_MRPMan_example_overlap_part 
 
 
- 
 
 
 

If the production time of a parent work order for plastic containers is 10 days, and a 20% overlap has been defined for that part, the start date of a work order for containers will fall 2 days before the end date of the child work order for plastic lids, according to the following formula: X - 20% ´ 10 = X - 2 (where X is the end date of the work order for the lids). 
 

You can define a percentage of overlap between the production of a parent part and that of its child (as in the above example), or between sequential operations in the production routing of a single part. In both cases, the overlap is defined for the part or operation that is produced or executed last.
