# PP_MRPMan_exp_gantt_mrp_options

PP_MRPMan_exp_gantt_mrp_options 
 
 
- 
 
 
 

If you advance the Begin Production date of a parent work order, the program automatically changes the dates of its child work orders. Or, if issues have been planned for the work order, the issue dates are changed accordingly. Similarly, if you delay the end date of a child work order, the program automatically changes the dates of the parent work order.
