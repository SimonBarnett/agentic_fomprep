# PP_MRPMan_exp_inv_reduces_forecast

- **Source:** `PP_MRPMan_exp_inv_reduces_forecast.htm`

PP_MRPMan_exp_inv_reduces_forecast 
 
 
- 
 
 
 

If you choose the run-time option Revise Forecst Ords , the program will reduce existing inventory from the demand resulting from forecast/stock orders, and the difference will appear in the Analysis of MRP Results (ATP) report under Demand-Forecast Ords . 
 

If the demand is meant to represent the estimated quantity of sales, you should choose this option (because you can supply part of the demand from existing inventory). However, if the demand is meant to represent the quantity that the factory is planning to produce in a given period, unrelated to existing inventory, you should not choose this option.
