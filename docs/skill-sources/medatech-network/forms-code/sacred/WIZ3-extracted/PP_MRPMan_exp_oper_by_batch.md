# PP_MRPMan_exp_oper_by_batch

PP_MRPMan_exp_oper_by_batch 
 
 
- 
 
 
 

That is, the amount of time required to perform an operation on a certain quantity (batch) of parts is equal to the amount of time it takes to perform the operation on a smaller quantity. 
 

 Example: The production of ceramic plates requires firing them in an oven. This operation takes the same amount of time whether the oven is partially filled or filled to capacity.
