# PP_MRPMan_exp_parallel_processing

- **Source:** `PP_MRPMan_exp_parallel_processing.htm`

PP_MRPMan_exp_parallel_processing 
 
 
- 
 
 
 

This column is useful when the production time and quantity are basic production values that can be multiplied as needed. 
 

 Example: A certain factory generally uses one assembly line to produce a certain part. The production rate (i.e., production time and quantity) represents the rate of the assembly line. Sometimes it is necessary (e.g., due to seasonal increases in part demand), to open additional assembly lines for that part. In such a case, it is more convenient to maintain the time/quantity values (that are identical for each assembly line) and record the number of active assembly lines in this column.
