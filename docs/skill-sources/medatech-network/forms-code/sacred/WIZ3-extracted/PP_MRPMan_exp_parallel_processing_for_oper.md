# PP_MRPMan_exp_parallel_processing_for_oper

- **Source:** `PP_MRPMan_exp_parallel_processing_for_oper.htm`

PP_MRPMan_exp_parallel_processing_for_oper 
 
 
- 
 
 
 

This column is useful when the time span and quantity of an operation are basic production values that can be multiplied as needed. 
 

 Example: A certain operation is generally performed by one team of employees. The operation's production rate (i.e., the time and quantity values) reflects the rate of the team. Sometimes, however, due to seasonal increases in demand for the part, additional teams are assigned to that operation. In this case, it is more convenient to maintain the time/quantity values (that are identical for each team) and record the number of teams assigned to the operation in the MRP–Workers/Machines column.
