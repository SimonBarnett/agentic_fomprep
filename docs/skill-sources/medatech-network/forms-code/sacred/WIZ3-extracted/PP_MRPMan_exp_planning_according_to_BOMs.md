# PP_MRPMan_exp_planning_according_to_BOMs

PP_MRPMan_exp_planning_according_to_BOMs 
 
 
- 
 
 
 

If different BOMs have been defined for the same part for different subcontractors (for example, when you need to supply one subcontractor with the required components, while another subcontractor purchases the components himself), MRP will plan work orders and issues according to the subcontractor executing the relevant operations. 
 

If work orders are planned for a part defined as maintaining BOM revisions, MRP uses the BOM of the revision in effect on the date production begins, provided that the revision has been authorized. If not, the program plans work orders according to the last authorized BOM revision.
