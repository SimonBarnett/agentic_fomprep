# PP_MRPMan_exp_range_of_issues

- **Source:** `PP_MRPMan_exp_range_of_issues.htm`

PP_MRPMan_exp_range_of_issues 
 
 
- 
 
 
 

You can choose one of the following methods of planning issues of purchased parts: 
 

 To each work order separately: One issue line is opened for each work order that requires a certain purchased part as a child part. This is the recommended method, unless your scope of production renders it unfeasible. 
 

 Monthly per parent part: One issue line is opened for the monthly total of work orders planned for each parent part that requires the purchased part. 
 

 Monthly: One issue line is opened for the monthly total of all work orders that require the purchased part. 
 

 Notes: 
 

 ·        In the first case, the issue date corresponds to the work order's planned start date. Otherwise, the issue date is the first of the month. 
 

 ·        Issues to subcontractors are always made for each work order separately, regardless of the chosen method.
