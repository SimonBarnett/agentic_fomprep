# PP_MRPMan_exp_w_o_increment

PP_MRPMan_exp_w/o_increment 
 
 
- 
 
 
 

The increment is the value to which work order quantities are rounded; when the quantity of a work order exceeds the minimum quantity defined for that part, it is rounded to the next multiple of the increment. For example, if the minimum quantity is 30, the increment is 5 and part demand is 43, the work order is opened with a quantity of 45.
