# Retrieval tips:

 

 ·        To retrieve all order items whose due dates fall within a certain period, use the Due Date column. 
 

 ·        To retrieve all order items recorded within a certain period, use the Date column. 
 

 ·        To retrieve all order items for a certain part, use the Part Number column.
