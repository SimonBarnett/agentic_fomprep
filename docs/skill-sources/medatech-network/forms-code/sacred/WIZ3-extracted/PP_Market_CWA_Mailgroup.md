# PP_Market_CWA_Mailgroup

- **Source:** `PP_Market_CWA_Mailgroup.htm`

PP_Market_CWA_Mailgroup 
 
 
- 
 
 
 

The column displays the e-mail address of the customer contact (as recorded in the Customer Contacts form). If there is no such address, the customer's e-mail address appears. If there is no customer address, the column displays the contact's fax number. If there is no such number, it displays the customer's fax number.
