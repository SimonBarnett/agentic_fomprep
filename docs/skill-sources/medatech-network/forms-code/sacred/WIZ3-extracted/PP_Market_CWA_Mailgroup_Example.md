PP_Market_CWA_Mailgroup_Example 
 
 
- 
 
 
 

The data displayed in the E-mail in New Group column is as follows: 
 

 ·        If a contact appears for the customer, the column displays that contact's e-mail address, if there is one, or fax number, if there is not (as recorded in the Customer Contacts form). 
 

 ·        If there is no contact, or if the contact has no e-mail address or fax number recorded, the column displays the customer's fax number (as recorded in the Customers form).
