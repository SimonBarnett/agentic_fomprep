 To narrow down customer records: 
 

 ·              Press F7 to clear individual records. OR 
 

 ·              Retrieve a portion of the records in the Customer Work Area (e.g., by area code in the Phone Number column). 
 

 Note : Only the records that appear in the form will be taken into account.
