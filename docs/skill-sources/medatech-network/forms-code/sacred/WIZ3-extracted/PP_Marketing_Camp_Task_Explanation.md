PP_Marketing_Camp_Task_Explanation 
 
 
- 
 
 
 

A task code represents a grouping of tasks of the same category assigned to different customers. For instance, you can open 500 tasks for a marketing presentation for 500 different customers, where all tasks are assigned the Presentation task code. Once the presentations are made, the sales opportunities for these customer can be automatically moved to the Presentation status.
