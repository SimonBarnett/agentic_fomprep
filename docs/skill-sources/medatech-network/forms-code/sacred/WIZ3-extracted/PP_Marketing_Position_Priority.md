# Position Priority

 

Say you assigned the position “VP for Purchasing” priority 1 and “CEO” priority 2. 
 

 ·              If a particular customer has both the Purchasing VP and the CEO listed as contacts, the Purchasing VP is the priority contact. 
 

 ·              If the customer does not have a Purchasing VP contact, the CEO is the priority contact.
