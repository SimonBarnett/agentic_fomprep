# PP_Marketing_Tasks_retrieval_tips

- **Source:** `PP_Marketing_Tasks_retrieval_tips.htm`

PP_Marketing_Tasks_retrieval_tips 
 
 
- 
 
 
 

To handle your own assigned tasks, retrieve them by your user name in the Assigned to column of the Definitions tab. Or retrieve by Customer No. 
 

To handle tasks opened by the system, retrieve them by one of the predefined task codes: 
 

001 – Incoming Mail 
 

002 – Outgoing Mail 
 

003 – Service Call 
 

004 – Assembly 
 

005 – Project Activity 
 

006 – Order.
