# PP_Marketing_Tasks_sub_levels

- **Source:** `PP_Marketing_Tasks_sub_levels.htm`

PP_Marketing_Tasks_sub_levels 
 
 
- 
 
 
 

The My Calendar form displays your own calendar. Use it when you want to schedule a task for yourself. It opens automatically when you enter the Tasks form. 
 

The Calendar (All Users) form displays the upcoming appointments of all company employees. Use it to decide which employee(s) to schedule for the current task. 
 

The Assigned User's Calendar form is accessible after recording an employee in the Assigned to column. Use it to help assign start and end times to the task. 
 

The Calendar displays appointments for selected users. It can also be used to revise appointments and add new ones.
