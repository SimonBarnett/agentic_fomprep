# PP_Marketing_tasks_mail_opens_task

- **Source:** `PP_Marketing_tasks_mail_opens_task.htm`

PP_Marketing_tasks_mail_opens_task 
 
 
- 
 
 
 

E-mails to and from customer contacts or vendor contacts automatically open a task for the user who received or sent the message. To disable this automatic mechanism, enter the Options screen from the Mail Top Bar and remove the check mark from the "Record e-mail as customer/vendor tasks" dialog box.
