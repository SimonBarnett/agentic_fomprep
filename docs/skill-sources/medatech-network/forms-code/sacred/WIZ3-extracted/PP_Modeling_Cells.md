PP_Modeling_Cells 
 
 
- 
 
 
 

Once your product is assembled it is painted in a spray machine, dried in an oven, then sprayed with lacquer. The different constraints for these processes indicate that they should be defined as three separate operations. At the same time, these operations are usually performed in close proximity to each other. In this case, you can define a work cell called Finishing, and assign it the three operations Painting, Drying and Lacquering.
