# PP_Modeling_Constant_Param

- **Source:** `PP_Modeling_Constant_Param.htm`

PP_Modeling_Constant_Param 
 
 
- 
 
 
 

The S parameter (percentage of scrap) assigned to the Holepunch operation is defined as constant, because the operation always creates the same percentage of scrap, regardless of the material used or its thickness.
