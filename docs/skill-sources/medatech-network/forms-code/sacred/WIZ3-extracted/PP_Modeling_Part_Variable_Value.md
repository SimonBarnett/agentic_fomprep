# PP_Modeling_Part_Variable_Value

- **Source:** `PP_Modeling_Part_Variable_Value.htm`

PP_Modeling_Part_Variable_Value 
 
 
- 
 
 
 

The standard machine time ( T ) parameter of the Sawing operation is multiplied (using the M operand) by a variable called Width with a coefficient of 1 (i.e., each increment of width causes a matching increment of machine time). Thus: 
 

 ·        If a given wooden part is twice the standard width, it should be assigned a Width value of 2 . Therefore, 2 ´ 1 ´ T = 2T or, twice the width takes twice as long. 
 

 ·        If a given wooden part is half the standard width, it should be assigned a Width value of 0.5 . Therefore, 0.5 ´ 1 ´ T = 0.5T or, half the width takes half as long.
