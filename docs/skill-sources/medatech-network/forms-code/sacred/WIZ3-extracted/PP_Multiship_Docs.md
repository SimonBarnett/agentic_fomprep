Multi-shipment invoices (and export invoices, for dual-currency users) usually bill any of a number of document types: 
 

shipping documents, together with returns 
 

service calls (reported parts and labor) 
 

service contracts (recorded payment installments). 
 
## When prepared for a project, they not only bill the above documents that are linked to the project, but also charge for transactions related specifically to the project:

 

reported hours and/or expenses 
 

payments for finished products.
