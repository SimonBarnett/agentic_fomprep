PP_Numeration_Template_example3 
 
 
- 
 
 
 

Assume that, for a given type of document, the column width is 9, the width of the prefix is 5 and the initial number is 1000. In that case, the width left over for actual numbering would be 4, and the highest number that could be assigned would be 9999. Moreover, as document numbers will begin with the initial number, the maximum number of documents of this type that could be opened would be 9000 (9999-999).
