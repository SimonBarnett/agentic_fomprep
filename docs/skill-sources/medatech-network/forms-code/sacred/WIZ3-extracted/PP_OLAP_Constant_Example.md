# PP_OLAP_Constant_Example

- **Source:** `PP_OLAP_Constant_Example.htm`

PP_OLAP_Constant_Example 
 
 
- 
 
 
 

If the Prepare All for Analysis (BI) program is run on September 15 and the constant value is 30, data will be collected from August 1 until September 15, updating 45 days of data. In other words, the program finds the date 30 days ago and then goes back to the first of that month. 
 

If you change the constant to 14, then when the program is run on September 15, only the BI data as of September 1 will be updated.
