PP_OLAP_Definition 
 
 
- 
 
 
 

 BI (business intelligence) tools allow you to easily analyze data from multiple perspectives. In Priority ' s BI reports, you determine the exact cross-section of data to be displayed in the data cube by drilling down within categories and accessing only the specific data that you want to see. For example, you can see how a particular part is selling, cross referenced by the type of sale and broken down by the country in which it was sold.
