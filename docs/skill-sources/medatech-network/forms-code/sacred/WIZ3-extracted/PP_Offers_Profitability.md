# PP_Offers_Profitability

- **Source:** `PP_Offers_Profitability.htm`

PP_Offers_Profitability 
 
 
- 
 
 
 

Ten eligible customers each order the awarded quantity of two special offer parts. These parts cost the company five dollars each, and are sold to the customers at a discount, for seven dollars each. The profitability of the special offer is calculated by: 
 

 ·        Subtracting the cost of each order from its price [(7 x 2) - (5 x 2) = 4]. 
 

 ·        Combining the resulting profits from all special offer orders (10 x 4) = 40. 
 

The profitability of this special offer is 40 dollars.
