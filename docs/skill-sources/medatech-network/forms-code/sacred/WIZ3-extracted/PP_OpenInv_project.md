# PP_OpenInv_project

- **Source:** `PP_OpenInv_project.htm`

PP_OpenInv_project 
 
 
- 
 
 
 

The program prepares invoices for all transactions linked to each selected project: 
 

customer shipments and returns 
 

service calls (reported parts and labor) 
 

payments for service contracts 
 

reports of project hours/expenses 
 

payments for finished products in the project.
