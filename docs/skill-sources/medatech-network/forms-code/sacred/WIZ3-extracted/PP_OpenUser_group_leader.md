# PP_OpenUser_group_leader

- **Source:** `PP_OpenUser_group_leader.htm`

PP_OpenUser_group_leader 
 
 
- 
 
 
 

In Priority , privileges are assigned to a group leader, and inherited by all users in the group. Using fictitious users as group leaders ensures continuity when actual employees join or leave the company. Furthermore, group leaders must be fictitious when synchronizing with the Windows Active Directory.
