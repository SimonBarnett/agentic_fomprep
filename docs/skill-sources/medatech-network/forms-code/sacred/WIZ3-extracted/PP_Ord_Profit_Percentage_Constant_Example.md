# PP_Ord_Profit_Percentage_Constant_Example

- **Source:** `PP_Ord_Profit_Percentage_Constant_Example.htm`

PP_Ord_Profit_Percentage_Constant_Example 
 
 
- 
 
 
 

The total price of a given order (including all discounts) is $50. The total cost of the ordered parts is $40. Profit is thus $10. If the percentage of profit is calculated in relation to part costs, it would be 25% (10/40 x 100). If it is calculated in relation to the price after discount, it would be 20% (10/50 x 100).
