# PP_Outlook_Import_Contacts

- **Source:** `PP_Outlook_Import_Contacts.htm`

PP_Outlook_Import_Contacts 
 
 
- 
 
 
 

When contacts are imported from Outlook to Priority , changes to existing contact data are made in the Contacts form (the contact is identified by name and e-mail address). If the contact does not appear in that form, that person is added to the Leads form as well.
