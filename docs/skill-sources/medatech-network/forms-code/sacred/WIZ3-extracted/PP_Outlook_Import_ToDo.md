# PP_Outlook_Import_ToDo

- **Source:** `PP_Outlook_Import_ToDo.htm`

PP_Outlook_Import_ToDo 
 
 
- 
 
 
 

Any item appearing on your to-do list and assigned to you (e.g., a sales order you are responsible for) will be transferred to Outlook tasks. If you then open the Detailed List in Outlook, you can view information about the task (e.g., details of the order), as well as access the Priority form in question.
