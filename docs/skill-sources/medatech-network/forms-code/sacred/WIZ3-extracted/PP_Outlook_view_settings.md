# PP_Outlook_view_settings

- **Source:** `PP_Outlook_view_settings.htm`

PP_Outlook_view_settings 
 
 
- 
 
 
 

If you do not see column headings in Outlook, modify the view settings as follows: 
 

 1 .  From the View menu, click Current View and then select Customize Current View . 
 

 2 .  In the dialog box that opens, click Group By . 
 

 3 .  Clear the Automatically group according to arrangement check box and click OK . 
 

 Note: 
 

The above instructions apply to Outlook 2007. Later versions of Outlook may work slightly differently.
