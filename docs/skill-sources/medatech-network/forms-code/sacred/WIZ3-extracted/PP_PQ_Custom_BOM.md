# PP_PQ_Custom_BOM

- **Source:** `PP_PQ_Custom_BOM.htm`

PP_PQ_Custom_BOM 
 
 
- 
 
 
 

A “Luxury” dinner table is usually assembled from four mahogany legs, but a certain customer wishes it to have six legs. When customizing the table's BOM, change the quantity of the “mahogany leg” item from 4 to 6.
