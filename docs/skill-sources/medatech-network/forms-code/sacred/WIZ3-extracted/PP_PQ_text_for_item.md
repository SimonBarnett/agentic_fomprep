# PP_PQ_text_for_item

- **Source:** `PP_PQ_text_for_item.htm`

PP_PQ_text_for_item 
 
 
- 
 
 
 

If the quote is based on another document, any remarks recorded for this item in the original document are automatically copied to the quoted item. Otherwise, if the Copy Part Remarks column is flagged for price quotations in the Copy Part Remarks to Document form, remarks are taken from the Parts - Remarks form, a sub-level of the Part Catalogue .
