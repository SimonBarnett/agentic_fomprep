# PP_Parts_Base_Product

- **Source:** `PP_Parts_Base_Product.htm`

PP_Parts_Base_Product 
 
 
- 
 
 
 

A base product is a part in the catalogue that is selected to serve as the hub of a group of similar parts, for both analytical and logistical purposes. For example, you can analyze sales data according to base product, and automatically update the prices and discounts of linked parts according to their base product.
