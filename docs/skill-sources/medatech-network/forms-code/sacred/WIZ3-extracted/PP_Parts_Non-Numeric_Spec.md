PP_Parts_Non-Numeric_Spec 
 
 
- 
 
 
 

The following codes were assigned to the Color spec for a line of shoes: 
 

Brown: 01 
 

Black: 02 
 

The part's catalogue number will be SH2002 01 for the brown shoe, and SH2002 02 for the black shoe.
