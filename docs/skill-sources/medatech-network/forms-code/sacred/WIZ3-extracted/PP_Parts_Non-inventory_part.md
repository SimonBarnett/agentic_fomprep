# PP_Parts_Non-inventory_part

- **Source:** `PP_Parts_Non-inventory_part.htm`

PP_Parts_Non-inventory_part 
 
 
- 
 
 
 

A part, generally of type O , for which you do not maintain inventory data. This includes services (e.g., consulting), products consumed on a regular basis (e.g. coffee, soap) and general parts used for a variety of items (e.g., travel expenses).
