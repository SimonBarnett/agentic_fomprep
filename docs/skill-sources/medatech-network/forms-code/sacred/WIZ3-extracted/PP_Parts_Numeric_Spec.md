One of the specs for a drill bit is Diameter : 
 

 ·        The Type is INT (i.e., integer.) 
 

 ·        The Minimum Value is 8 (mm). 
 

 ·        The Maximum Value is 12 . 
 

 ·        The Interva l is 2 . 
 

 ·        When assigning specs to a part in the Part Catalogue form, only the following diameters will be permitted: 6, 8, 10 and 12.
