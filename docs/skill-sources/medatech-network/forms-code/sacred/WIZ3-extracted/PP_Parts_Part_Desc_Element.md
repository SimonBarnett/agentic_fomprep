# PP_Parts_Part_Desc_Element

- **Source:** `PP_Parts_Part_Desc_Element.htm`

PP_Parts_Part_Desc_Element 
 
 
- 
 
 
 

Just as the part number can be a composite of several specification codes, the part description can be a composite of several specification values, separated by a punctuation mark (e.g., Loafer,2002,Brown,Lg or Loafer_2002_Brown_Lg) .
