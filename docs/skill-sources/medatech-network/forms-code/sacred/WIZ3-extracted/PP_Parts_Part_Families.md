# PP_Parts_Part_Families

- **Source:** `PP_Parts_Part_Families.htm`

PP_Parts_Part_Families 
 
 
- 
 
 
 

 A part family is a group of parts that share the same sales, purchasing, inventory and service data. For example, all items belonging to a particular part family can be awarded the same discount, or be flagged as work hours.
