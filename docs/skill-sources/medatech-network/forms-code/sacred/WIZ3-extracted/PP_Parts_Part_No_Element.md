# PP_Parts_Part_No_Element

- **Source:** `PP_Parts_Part_No_Element.htm`

PP_Parts_Part_No_Element 
 
 
- 
 
 
 

If the spec is numeric, the value itself becomes part of the catalogue number. For example, if the spec is Year , a possible number is SH 2002 01. 
 

If the spec is non-numeric, the spec's value code becomes part of the catalogue number. For example, if the spec is Color , and the code for black is 02 , a possible number is SH2002 02 .
