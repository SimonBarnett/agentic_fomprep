# PP_Past_Balance_corrections

- **Source:** `PP_Past_Balance_corrections.htm`

PP_Past_Balance_corrections 
 
 
- 
 
 
 

Current inventory balances may need adjustment when: 
 

 ·        Transactions recorded in inventory documents did not affect current inventory (e.g., due to a power failure) 
 

 ·        A part previously defined as not subject to inventory control has been redefined as subject to inventory control
