# PP_Percentages_Format

- **Source:** `PP_Percentages_Format.htm`

PP_Percentages_Format 
 
 
- 
 
 
 

Beside each table value, you can display its proportional share in the column total (in percentages) or its cumulative percentage (i.e., including the values that precede it). 
 

In addition, if the table values record activities over several months, you can also display the monthly average of each value.
