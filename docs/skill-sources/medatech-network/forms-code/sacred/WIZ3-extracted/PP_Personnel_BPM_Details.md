# PP_Personnel_BPM_Details

- **Source:** `PP_Personnel_BPM_Details.htm`

PP_Personnel_BPM_Details 
 
 
- 
 
 
 

Job statuses describe the various stages of recruitment for an open position (e.g., "Recruiting", "Filled"). 
 

Candidate statuses describe the current relationship of the person in question with the company (e.g., "Active", "Inactive"). 
 

Applicant statuses describe the relationship of a given employee or candidate with a particular job opening (e.g., "Applying", "Hired"). 
 

Employee statuses describe the current relationship of a given employee with the company (e.g., " Contracted" , "Active Employee", "Former Employee").
