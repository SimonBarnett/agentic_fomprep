PP_Prepaid_payment_range 
 
 
- 
 
 
 

Assume that you have made an annual subscription to Accounting Monthly magazine, which costs $2400. In the invoice, you specify Jan.1 to Dec. 31 as the start and end dates for the distribution of expenses. The system will record a journal entry with twelve items for equal amounts: $200 for 1/31, $200 for 2/28, and so on until the last journal entry: $200 for 12/31.
