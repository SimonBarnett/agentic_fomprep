PP_PriceAdj_Basket 
 
 
- 
 
 
 

You can define a currency called "Curr. Basket 1", which links the transaction in the following manner: 
 

 ·        50% of the transaction sum is linked to the euro. 
 

 ·        15% is linked to the dollar. 
 

 ·        35% is linked to the pound sterling.
