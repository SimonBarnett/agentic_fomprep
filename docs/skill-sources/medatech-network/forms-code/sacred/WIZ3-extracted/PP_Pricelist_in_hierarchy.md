# PP_Pricelist_in_hierarchy

- **Source:** `PP_Pricelist_in_hierarchy.htm`

PP_Pricelist_in_hierarchy 
 
 
- 
 
 
 

If the document in question is not based on another document and is manually linked to a price list when the document is recorded, the prices of the parts in this document are taken from the designated price list. 
 

This is useful if you want to use a different price list than the customer's regular one (e.g., a special price list for an end-of-season sale).
