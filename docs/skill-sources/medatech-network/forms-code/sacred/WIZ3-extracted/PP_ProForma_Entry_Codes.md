# PP_ProForma_Entry_Codes

- **Source:** `PP_ProForma_Entry_Codes.htm`

PP_ProForma_Entry_Codes 
 
 
- 
 
 
 

The entry code determines the accounts included in the pro forma journal entry and the amounts debited/credited against each in the entry journal. The predefined code for pro forma invoices appears automatically, but may be revised. For more details, see the Set Up Entry Codes Wizard .
