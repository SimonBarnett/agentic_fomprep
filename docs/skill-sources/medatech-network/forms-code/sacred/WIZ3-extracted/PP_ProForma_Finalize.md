# PP_ProForma_Finalize

- **Source:** `PP_ProForma_Finalize.htm`

PP_ProForma_Finalize 
 
 
- 
 
 
 

 Finalize Immediately is a document attribute in the Financial Documents form. If pro forma invoices are flagged for this attribute, you must finalize any newly opened invoice before closing the form. In other words, you cannot create a pending pro forma invoice.
