PP_ProForma_Project_Link 
 
 
- 
 
 
 

The project number is assigned automatically to the invoice: 
 

 ·      When a single project is recorded for the customer, and the SLinkProject constant is set to 1 . 
 

 ·      When the invoice is based on a document linked to a project.
