# PP_ProForma_text_for_item

- **Source:** `PP_ProForma_text_for_item.htm`

PP_ProForma_text_for_item 
 
 
- 
 
 
 

If the invoice is based on another document, any remarks recorded for this item in the original document are automatically copied to the invoice item. Otherwise, if the Copy Part Remarks column is flagged for pro forma invoices in the Copy Part Remarks to Document form, remarks are taken from the Parts - Remarks form, a sub-level of the Part Catalogue .
