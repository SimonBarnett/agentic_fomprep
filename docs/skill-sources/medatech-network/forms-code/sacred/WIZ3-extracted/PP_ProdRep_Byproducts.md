# PP_ProdRep_Byproducts

- **Source:** `PP_ProdRep_Byproducts.htm`

PP_ProdRep_Byproducts 
 
 
- 
 
 
 

Reporting an operation usually results in the addition of a single part into inventory. However, the system also provides a special predefined operation called Byprod , which occurs uniquely in a predefined routing of the same name and results in the creation of a set of different parts, called byproducts , from a single raw material, called the source part .
