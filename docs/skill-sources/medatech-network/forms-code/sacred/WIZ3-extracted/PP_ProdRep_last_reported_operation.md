# PP_ProdRep_last_reported_operation

- **Source:** `PP_ProdRep_last_reported_operation.htm`

PP_ProdRep_last_reported_operation 
 
 
- 
 
 
 

There may be cases when the last operations in a routing are meant to be performed but not reported. Since the Backflush program only responds to reported operations, the parameters affecting automatic warehouse entry must be defined in the last reported operation in the routing.
