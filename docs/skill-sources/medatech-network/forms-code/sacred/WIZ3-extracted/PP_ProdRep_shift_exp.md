Defining shifts is important if salaries are adjusted according to shift. In this case, you define for each shift the percentage by which salaries are adjusted (relative to the standard salary), and record in each production report the shift in which the reported operation was performed. When you run the costing program, the system automatically adjusts labor costs according to the percentage recorded for each shift.
