PP_Project_Management_exp_automatic_sub-activities 
 
 
- 
 
 
 

Once a project activity has been linked to a SOW item, you can open sub-activities automatically according to the sub-levels of the item. The program will copy to each new sub-activity the description of its corresponding sub-item. Data in sub-level forms (e.g., remarks, attachments) are not copied.
