PP_Project_Management_exp_planning_versions 
 
 
- 
 
 
 

Planning versions serve as drafts of the project plan. After a new planning version has been authorized, you can put it into effect as the new project plan. Maintaining versions allows you to experiment with variations of the planning data until you are satisfied with the resulting plan.
