# PP_Project_Management_milestones

- **Source:** `PP_Project_Management_milestones.htm`

PP_Project_Management_milestones 
 
 
- 
 
 
 

A milestone is an activity to which you can link project payment installments (in the Projects/Accounts sub-level of the Payments for Project form). When a milestone activity is completed (i.e., 100% is recorded in the Percent Completed column), the payment is automatically freed for billing.
