# PP_Project_Management_periodic_invoice_exp

- **Source:** `PP_Project_Management_periodic_invoice_exp.htm`

PP_Project_Management_periodic_invoice_exp 
 
 
- 
 
 
 

If the Periodic Invoice column is flagged, the program will issue one invoice per transaction type. If it is not flagged, the program will issue one invoice per individual shipment (and return) and one invoice per transaction type for every other type of transaction.
