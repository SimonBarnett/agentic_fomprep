PP_Project_Management_product_part

For example, in a housing project, the product for the Electricity Installation activity would be the Electrical System. The Electrical System part would have as child parts the various switches, wires, sockets, etc. needed for the installation. It will also have as child parts a certain number of electrician work hours.
