# PP_Project_Management_team_percentage

- **Source:** `PP_Project_Management_team_percentage.htm`

PP_Project_Management_team_percentage 
 
 
- 
 
 
 

The percentage of full time allocated to the team leader is automatically split evenly between the assigned team members. For instance, if the team leader is allocated 120%, and the team consists of three members, each member will be allocated 40% of full time.
