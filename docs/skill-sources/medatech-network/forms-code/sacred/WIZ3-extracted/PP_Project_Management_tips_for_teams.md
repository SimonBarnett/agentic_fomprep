PP_Project_Management_tips_for_teams 
 
 
- 
 
 
 

 Tips: 
 

 ·        When assigning individual employees to an activity, either the full name or username (as defined in the Personnel File ) is acceptable. 
 

 ·        To assign a company team to an activity, ensure that the SAllTeam constant is set at 1 or 2 and then designate the team leader (if the constant is set at 2 , the leader will not be assigned to the activity). 
 

 ·        To assign a team created specifically for this project, ensure that all team members have been listed and that the All Team Members column in the Project Teams form is flagged. Then designate the name of the team.
