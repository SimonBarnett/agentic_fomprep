# PP_Project_Management_warehouse_project

- **Source:** `PP_Project_Management_warehouse_project.htm`

PP_Project_Management_warehouse_project 
 
 
- 
 
 
 

All inventory that is sent to the project (e.g., by GRV, transfer to project warehouse) is charged to the project, as are issues of supplies to the project. 
 

In order to avoid double charges (e.g., for receipt and issue of the same goods), inventory should be received into one of the project warehouses (issues from a project warehouse are not charged against the project).
