# PP_Project_Management_work_hour_part

- **Source:** `PP_Project_Management_work_hour_part.htm`

PP_Project_Management_work_hour_part 
 
 
- 
 
 
 

In Priority , work hours are "parts" that are attached to a part family flagged as a work hour family. You can define a default work hour part for each employee in the Personnel File form. This part appears automatically when the employee reports work hours (e.g., for projects, service calls). 
 

There is also a predefined work hour part that serves as the general default. In work hour reports, if no default work hour part is defined for the employee, the general work hour part appears instead.
