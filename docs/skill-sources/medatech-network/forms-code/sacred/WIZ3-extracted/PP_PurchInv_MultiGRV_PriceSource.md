# PP_PurchInv_MultiGRV_PriceSource

- **Source:** `PP_PurchInv_MultiGRV_PriceSource.htm`

PP_PurchInv_MultiGRV_PriceSource 
 
 
- 
 
 
 

The PurchDocPrice constant determines whether multi-GRV invoice prices are: 
 

 ·        always taken from the original GRV 
 

 ·        always taken from the original purchase order (or vendor price list, when there is no order), or 
 

 ·        taken from the GRV only when there is no purchase order or price list.
