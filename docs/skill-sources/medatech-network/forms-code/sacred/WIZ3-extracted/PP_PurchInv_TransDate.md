# PP_PurchInv_TransDate

- **Source:** `PP_PurchInv_TransDate.htm`

PP_PurchInv_TransDate 
 
 
- 
 
 
 

By default, the transaction date of the journal entry opened for this invoice is the invoice date (i.e., the transaction date is identical to the reference date). To use a different transaction date, record it in the Transaction Date column.
