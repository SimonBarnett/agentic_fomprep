# PP_PurchasePlanning_Increments

- **Source:** `PP_PurchasePlanning_Increments.htm`

PP_PurchasePlanning_Increments 
 
 
- 
 
 
 

The increment is the value to which purchase requisition quantities are rounded; when the planned quantity of a purchase requisition exceeds the minimum quantity defined for that part, it is rounded to the next multiple of the increment. For example, if the minimum quantity is 30, the increment is 5 and the required quantity is 43, the purchase requisition is opened with a quantity of 45.
