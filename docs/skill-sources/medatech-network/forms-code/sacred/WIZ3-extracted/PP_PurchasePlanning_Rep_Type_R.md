# PP_PurchasePlanning_Rep_Type_R

PP_PurchasePlanning_Rep_Type_R 
 
 
- 
 
 
 

Parts with Replenishment Type R are required in different amounts at different times. This is called dynamic demand , as it fluctuates dynamically according to the volume of sales orders or open work orders (for the part itself, or its parent part) received during the period in question. 
 

Demand for these parts is calculated by MRP or production planning and detailed in the issues plan.
