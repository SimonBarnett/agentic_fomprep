In the coming month there will be three issues of a particular material to the plant floor, whose minimum order quantity is 200 units: one for 60 units, one issue for 70 and one for 80. If the demand range for this part is thirty days, the total requisition for that period will be for 210 parts, which satisfies the minimum requirement. 
 

If, however, no demand range was defined, a separate requisition will be opened for each issue, each of which is subject to the 200-unit minimum. The total requisition for the same period will thus be for 600 parts, almost three times as many parts as are needed.
