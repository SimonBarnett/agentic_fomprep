 Problem : Jonathan discovered that two items, which had the same reference numbers and the same amounts, were not reconciled. 
 

 Solution : The items were recorded within 14 days of each other, but the maximum date range defined for this reconciliation code was 7. Jonathan can broaden the date range of the code's reconciliation methods, or add new methods with a broader date range (e.g., 21).
