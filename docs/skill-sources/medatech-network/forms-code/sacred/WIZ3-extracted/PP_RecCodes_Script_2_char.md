 Problem : Sharon performed a bank reconciliation, and was surprised when an entry item and a statement item with identical dates and amounts were not reconciled. 
 

 Solution : Sharon's problem is due to this particular bank's statement format. She can create a reconciliation code specific to this bank, in which the number of characters used to compare reference numbers is smaller.
