 Problem : Ben discovered that two entries with the same due date and reference number were not reconciled. 
 

 Solution : The entries were not reconciled due to a minute difference in their amounts: one entry was for $600.00, while the other was for $600.01. To reconcile these entries, Ben must allow for a variance of at least 0.01 in the By amount only method.
