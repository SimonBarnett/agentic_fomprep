# PP_Rep_Gen_Expression

- **Source:** `PP_Rep_Gen_Expression.htm`

PP_Rep_Gen_Expression 
 
 
- 
 
 
 

 Expression columns display the results of mathematical operations performed on the values of sum and quantity columns. They are defined by combining column ID numbers (displayed in the following screen) with standard mathematical symbols and predefined operation codes. (e.g., SUM, MAX, MIN or AVG). 
 

For example, the expression 100.0 * SUM(#120)/SUM(#33) displays the results of: 
 

 ·        dividing the sum of values in Column No. 120 by the sum of values in Column No. 33, and 
 

 ·        multiplying the quotient by 100.
