# PP_Rep_Gen_Field_In_Title

- **Source:** `PP_Rep_Gen_Field_In_Title.htm`

PP_Rep_Gen_Field_In_Title 
 
 
- 
 
 
 

If you flag the Field in Title attribute for the Customer Number column in a sales order report, the data for each customer will be grouped under a sub-heading displaying that customer's number. Otherwise, Customer Number will appear as a regular column, in which the number will be displayed separately for each line of data.
