# PP_Rep_Gen_Multiple_Desc

- **Source:** `PP_Rep_Gen_Multiple_Desc.htm`

PP_Rep_Gen_Multiple_Desc 
 
 
- 
 
 
 

Parts that are flagged in the Change Desc. column (in the Part Catalogue ) can be recorded in documents as different items by changing the part description as needed. For example, you can define a general part for office supplies, then revise the description according to the specific part you are recording.
