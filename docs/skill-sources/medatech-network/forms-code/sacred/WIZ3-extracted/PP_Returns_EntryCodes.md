# PP_Returns_EntryCodes

- **Source:** `PP_Returns_EntryCodes.htm`

PP_Returns_EntryCodes 
 
 
- 
 
 
 

The entry code determines the accounts included in the journal entry for this return document and the amounts debited/credited against each. It is taken from the predefined entry code for payment returns, unless you are depositing a returned payment directly in the customer's account, in which case it uses the predefined entry code for payment returns to customers. For more details, run the Set Up Entry Codes Wizard .
