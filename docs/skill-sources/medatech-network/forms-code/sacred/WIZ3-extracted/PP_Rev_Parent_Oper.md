# PP_Rev_Parent_Oper

- **Source:** `PP_Rev_Parent_Oper.htm`

PP_Rev_Parent_Oper 
 
 
- 
 
 
 

The parent operation recorded for each child part in a BOM is the operation in the parent part’s routing in which the child part is joined to the parent. 
 

The child operation is the operation in the child part’s routing that is performed when (or immediately before) it is joined to the parent.
