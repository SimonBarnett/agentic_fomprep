# PP_SalesOrd_Checklist_Example

- **Source:** `PP_SalesOrd_Checklist_Example.htm`

PP_SalesOrd_Checklist_Example 
 
 
- 
 
 
 

You can define the following set of tasks to be opened automatically and assigned to relevant employees whenever an order is assigned the sales type for the sale of a software license: 
 

 ·              Check whether the customer usually purchases a service contract for software. 
 

 ·              Assign the customer a new license number and/or registration key. 
 

 ·              Prepare an installation CD for the software, if needed.
