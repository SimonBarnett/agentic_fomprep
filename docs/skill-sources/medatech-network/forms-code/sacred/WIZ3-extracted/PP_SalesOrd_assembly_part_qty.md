# PP_SalesOrd_assembly_part_qty

- **Source:** `PP_SalesOrd_assembly_part_qty.htm`

PP_SalesOrd_assembly_part_qty 
 
 
- 
 
 
 

When defining the product bundle, you indicate the quantity of each component part and its substitutes required in a single bundle. In the order, the part quantity is calculated by multiplying this required quantity by the number of ordered product as bundles.
