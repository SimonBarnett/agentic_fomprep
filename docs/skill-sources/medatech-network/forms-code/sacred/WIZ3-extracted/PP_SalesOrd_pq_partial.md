PP_SalesOrd_pq_partial 
 
 
- 
 
 
 

A price quotation includes two prices for a package of pens: 
 

 ·        $100 per unit for a minimum order of 10 packages 
 

 ·        $85 per unit for a minimum order of 100 packages 
 
## In an order for 105 packages, a unit price of $85 will appear automatically. In an order for 15 packages, the unit price will be $100.
