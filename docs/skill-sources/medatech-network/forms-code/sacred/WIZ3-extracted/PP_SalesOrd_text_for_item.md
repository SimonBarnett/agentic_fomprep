# PP_SalesOrd_text_for_item

- **Source:** `PP_SalesOrd_text_for_item.htm`

PP_SalesOrd_text_for_item 
 
 
- 
 
 
 

If the order is based on a price quotation, the remarks recorded for this item in the price quotation appear automatically as remarks for the ordered item. Otherwise, if the Copy Part Remarks column is flagged for sales orders in the Copy Part Remarks to Document form, remarks are taken from the Parts - Remarks form, a sub-level of the Part Catalogue .
