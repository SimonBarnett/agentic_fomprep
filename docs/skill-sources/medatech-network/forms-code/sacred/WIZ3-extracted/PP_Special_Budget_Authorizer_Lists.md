# PP_Special_Budget_Authorizer_Lists

- **Source:** `PP_Special_Budget_Authorizer_Lists.htm`

PP_Special_Budget_Authorizer_Lists 
 
 
- 
 
 
 

In each list, you indicate the users who can sign, as well as the total amount above which their signature is mandatory. The sequence of authorizations is determined by that starting amount. One user must be required to sign as of a 0 (zero) amount. Not everyone has to authorize the appropriation; once a senior user (appearing later in the list) signs the appropriation, users appearing earlier in the list need not sign.
