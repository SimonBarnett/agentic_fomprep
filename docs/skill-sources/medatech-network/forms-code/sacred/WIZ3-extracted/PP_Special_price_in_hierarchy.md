# PP_Special_price_in_hierarchy

- **Source:** `PP_Special_price_in_hierarchy.htm`

PP_Special_price_in_hierarchy 
 
 
- 
 
 
 

If the document is not manually linked to a price list, and the customer has been assigned a special price for the part (which is valid on the date on which the document was recorded), the part price will be the special price. Item discounts will not apply, but the customer's overall discount will remain in effect.
