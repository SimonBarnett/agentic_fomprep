# PP_Specs_Pattern_Width

- **Source:** `PP_Specs_Pattern_Width.htm`

PP_Specs_Pattern_Width 
 
 
- 
 
 
 

If you specify 3, the first sequential numbers will be 001, 002, 003…. Note that this number determines the maximum number of parts that you can create using this template. For example, with a value of 3 you can create no more than 999 new parts. If you leave the default value of 0, the number of parts that you can open will be infinite (and the numbers will appear without leading zeroes: 1, 2, 3 … 10 …100).
