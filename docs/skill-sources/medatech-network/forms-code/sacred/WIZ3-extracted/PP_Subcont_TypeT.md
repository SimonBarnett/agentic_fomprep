# PP_Subcont_TypeT

- **Source:** `PP_Subcont_TypeT.htm`

PP_Subcont_TypeT 
 
 
- 
 
 
 

Inventory/costing control setting T is always assigned to the last in a series of operations performed by the subcontractor (the one at which the part is returned). Since, in this case, a subcontractor always performs whatever production is necessary and then returns the part, the number of operations actually executed is irrelevant and you define a single operation, assigning it the T setting.
