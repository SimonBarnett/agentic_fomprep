# PP_Subcont_exp_L_and_T

- **Source:** `PP_Subcont_exp_L_and_T.htm`

PP_Subcont_exp_L_and_T 
 
 
- 
 
 
 

If the subcontractor performs a series of operations, the last of these operations should be flagged as requiring a production report (type T ) and the others as not requiring reports (type L ). The operations flagged with an L will be considered intermediate operations in which the part does not need to reenter inventory. When you record a GRV for the processed part (after receiving parts at the completion of the final T operation), the system reduces all child parts, including those required for the intermediate operations.
