# PP_Subcont_exp_P

- **Source:** `PP_Subcont_exp_P.htm`

PP_Subcont_exp_P 
 
 
- 
 
 
 

This setting is useful when you need to track production of a child part when produced in your factory, but not when produced by the subcontractor. 
 

When the child part is flagged with a P for production by a certain subcontractor, the Backflush program will reduce, against receipt of the parent part, the quantities of parts from which the child part is produced, rather than quantities of the child part itself. (By contrast, when the part is produced in the factory, the Backflush program reduces the appropriate quantity of the child part.)
