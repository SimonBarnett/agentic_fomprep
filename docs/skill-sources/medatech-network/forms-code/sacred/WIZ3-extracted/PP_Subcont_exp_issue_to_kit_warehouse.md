# PP_Subcont_exp_issue_to_kit_warehouse

- **Source:** `PP_Subcont_exp_issue_to_kit_warehouse.htm`

PP_Subcont_exp_issue_to_kit_warehouse 
 
 
- 
 
 
 

Both the issue and the shipment are inventory transactions. Thus, if you record both an issue to the subcontractor warehouse and a shipping document to the subcontractor of the same inventory, you will cause a miscalculation of inventory balances both in your warehouse and the subcontractor's.
