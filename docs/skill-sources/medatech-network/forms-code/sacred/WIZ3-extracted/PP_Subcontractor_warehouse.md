# PP_Subcontractor_warehouse

- **Source:** `PP_Subcontractor_warehouse.htm`

PP_Subcontractor_warehouse 
 
 
- 
 
 
 

Each subcontractor is assigned a plant-floor warehouse in which any components shipped to the subcontractor are “stored” and from which components are removed when a receipt of goods is recorded for the subcontracted part. In this way, the system can track production that takes place at a subcontractor. For more information, see the Working w/Subcontractors Wizard .
