PP_TSBackflush_work_order_hierarchy 
 
 
- 
 
 
 

When choosing inventory to consider, the Backflush program uses the following hierarchy: 
 

 ·        by work order expiration date 
 

 ·        closed work orders before open work orders 
 

 ·        by work order close date
