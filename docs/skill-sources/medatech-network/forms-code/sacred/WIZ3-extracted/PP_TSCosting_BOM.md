# PP_TSCosting_BOM

- **Source:** `PP_TSCosting_BOM.htm`

PP_TSCosting_BOM 
 
 
- 
 
 
 

BOMs should be built hierarchically: composite (Type P ) parts are on the highest level; sub-assemblies (also Type P ), if any, are at the intermediate levels as child parts; and raw materials (purchased Type R parts) occupy the bottom level. If raw materials have not been defined at the lowest level, the BOM must be revised. If there are no child parts to define for a given Type P part, its type must be changed to R – Type P is used exclusively for "make" parts that are assembled or manufactured from other parts defined in the system.
