# PP_TSCosting_Standard_Cost

- **Source:** `PP_TSCosting_Standard_Cost.htm`

PP_TSCosting_Standard_Cost 
 
 
- 
 
 
 

The standard cost appearing in the Product Costing form is not necessarily the standard cost that appears in the Part Catalogue form. The former is calculated by the costing program, and appears in costing, sales and inventory valuation reports, whereas the latter is only updated by the costing program when the UpdStdCost constant is set to 1 . Otherwise, it is maintained independently, either manually or via the Calculate/Update Standard Cost program.
