# PP_TSCosting_Time_Factor

- **Source:** `PP_TSCosting_Time_Factor.htm`

PP_TSCosting_Time_Factor 
 
 
- 
 
 
 

The execution time of the Drying operation is dependent on the ambient temperature during the day. During the summer, the value 0.75 is specified for this column, to reduce the required time by one quarter. Once the summer is over, the value specified for this column is 1.
