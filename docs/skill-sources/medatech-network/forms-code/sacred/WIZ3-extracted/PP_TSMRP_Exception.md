# PP_TSMRP_Exception

- **Source:** `PP_TSMRP_Exception.htm`

PP_TSMRP_Exception 
 
 
- 
 
 
 

If the part was once defined as replenishment type R and orders for the part or its parent parts were flagged for MRP , issues will be generated for them even if they are now defined as replenishment type B.
