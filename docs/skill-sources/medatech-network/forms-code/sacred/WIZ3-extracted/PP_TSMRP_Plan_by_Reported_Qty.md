PP_TSMRP_Plan_by_Reported_Qty 
 
 
- 
 
 
 

As long as production of the work order has begun, the system will take it into account during planning. In the case of partial production (i.e., less than the full work order quantity was reported), the remaining quantity will not be considered future inventory. Consequently, MRP will treat the remaining quantity as a surplus work order.
