# PP_TSMRP_Scrap

- **Source:** `PP_TSMRP_Scrap.htm`

PP_TSMRP_Scrap 
 
 
- 
 
 
 

There is an order for 100 units. The defined scrap is 50 percent. 
 

 Calculation: You need to issue a quantity of X, so that after scrap you are left with the ordered quantity – 
 

X * 50% = 100 
 

X = 100/.50 
 

X = 200
