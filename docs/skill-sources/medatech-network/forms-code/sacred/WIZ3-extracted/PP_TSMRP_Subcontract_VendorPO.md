# PP_TSMRP_Subcontract_VendorPO

- **Source:** `PP_TSMRP_Subcontract_VendorPO.htm`

PP_TSMRP_Subcontract_VendorPO 
 
 
- 
 
 
 

If there are purchase orders to a vendor that is not a subcontractor, MRP takes these ordered quantities into account. Consequently, when Purchase Planning is run, the ordered quantity appears, but does not affect planning. Rather, in one line the order is recorded as increasing projected inventory levels, and the next line deducts the projected inventory increase, which has been Adjusted by MRP . This is because the order has already been taken into account by MRP. 
 

 Note : Purchase Planning does take into account any purchase orders to a subcontractor.
