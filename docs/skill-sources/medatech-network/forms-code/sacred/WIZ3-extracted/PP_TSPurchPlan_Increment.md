# PP_TSPurchPlan_Increment

- **Source:** `PP_TSPurchPlan_Increment.htm`

PP_TSPurchPlan_Increment 
 
 
- 
 
 
 

If an Increment for Ord/WO has been defined, the requisitioned quantities calculated will be rounded up, according to the designated increment. For example, if the increment is defined as 50 and the required quantity is 35, the purchase requisition is opened for a quantity of 50. If the required quantity is 62, the requisition is rounded to 100.
