# PP_TSPurchPlan_MRP

- **Source:** `PP_TSPurchPlan_MRP.htm`

PP_TSPurchPlan_MRP 
 
 
- 
 
 
 

MRP takes into account only those purchase orders that are not from subcontractors, and that are for Type P parts, which are usually processed. Since parts that are produced by subcontractors are also included in purchase planning, this process identifies such orders and deducts them, thereby ensuring that they are only used once in planning calculations.
