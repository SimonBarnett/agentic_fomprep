For instance, you can assign a bright color (e.g., red) to tasks with the Urgent status. 
 
## Notes: 

 

 ·              Alternatively, you can color-code tasks by their task code. 
 

 ·              Color-coding affects how tasks are displayed (as appointments) in the calendar.
