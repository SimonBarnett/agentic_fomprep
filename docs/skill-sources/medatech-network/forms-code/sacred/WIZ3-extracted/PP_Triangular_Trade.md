# PP_Triangular_Trade

- **Source:** `PP_Triangular_Trade.htm`

PP_Triangular_Trade 
 
 
- 
 
 
 

A triangular transaction is a transaction in which a company in one EU country (e.g., UK) is an intermediary between a supplier in a second EU country (e.g., Sweden) and the final customer in a third EU country (e.g., France).
