# PP_VAT_GLAccount

- **Source:** `PP_VAT_GLAccount.htm`

PP_VAT_GLAccount 
 
 
- 
 
 
 

When VAT is charged in a financial document, the tax item in the journal entry is recorded against the assigned GL account. A single GL account (for sales and/or purchases) can be assigned to the VAT code, or different accounts can be assigned to each tax group.
