# PP_VAT_import_vat

- **Source:** `PP_VAT_import_vat.htm`

PP_VAT_import_vat 
 
 
- 
 
 
 

As the VAT for the imported goods themselves is recorded in another purchase invoice, it cannot be calculated as a percentage of the current invoice total. Hence, it must be recorded as a separate “part” in the invoice.
