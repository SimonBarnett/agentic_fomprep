PP_VPQ_Purchase_Demands 
 
 
- 
 
 
 

A purchase demand document is a list of individual purchase requisitions. It may contain related items (e.g., that were manually requisitioned by a given department), or non-related items (e.g., in a document generated automatically during purchase planning).
