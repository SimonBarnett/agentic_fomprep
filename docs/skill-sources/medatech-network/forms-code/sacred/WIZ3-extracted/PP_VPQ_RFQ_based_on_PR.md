Two separate PRs are opened for a “computer keyboard,” one by the Development Dept. and one by the Marketing Dept. When the Prepare RFQs from PRs program is run, an RFQ will be opened that includes two lines; each line will contain the part description “computer keyboard” and its respective PR number.
