# PP_VPQ_minimum_quantity

- **Source:** `PP_VPQ_minimum_quantity.htm`

PP_VPQ_minimum_quantity 
 
 
- 
 
 
 

A price quotation includes two prices for chairs: 
 

 ·        $150 per unit for a minimum order of 10 chairs 
 

 ·        $100 per unit for a minimum order of 50 chairs 
 

When preparing a purchase order for 60 chairs based on this quote, a unit price of $100 will appear automatically. When preparing a purchase order for 15 chairs, the unit price will be $150.
