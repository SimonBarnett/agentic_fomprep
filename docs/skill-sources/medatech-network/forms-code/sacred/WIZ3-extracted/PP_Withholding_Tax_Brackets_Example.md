Given the above tax brackets, the following calculation explains how to calculate withholding tax for a payment of €4,500: 
 

The first €2,000 is taxed at 10%: €2,000 x .10 = € 200
The next €2,000 is taxed at 14%: €2,000 x .14 = € 280
The remaining €500 is taxed at 18%: €500 x .18 = € 90 
 

Thus, the total tax withheld is €200 + €280 + €90 = €570.
