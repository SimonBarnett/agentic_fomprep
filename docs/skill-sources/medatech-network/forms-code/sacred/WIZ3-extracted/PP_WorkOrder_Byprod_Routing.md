# PP_WorkOrder_Byprod_Routing

- **Source:** `PP_WorkOrder_Byprod_Routing.htm`

PP_WorkOrder_Byprod_Routing 
 
 
- 
 
 
 

A normal operation usually results in the addition of a single part into inventory. However, the system also provides a special predefined operation (and routing) called Byprod , which results in the creation of a set of different parts, called byproducts , from a single raw material, called the source part . The source part appears as the child of each of its byproducts, which should themselves be defined as child parts of the final product and appear in its kit list.
