Issuing warehouses are useful, for instance, when there are two plant floors located a considerable distance apart (e.g., one in Manhattan and one in Brooklyn). By linking the Brooklyn warehouse to the Brooklyn plant floor, you ensure that the system ignores materials stored in the Manhattan warehouse when preparing issues to kits for work orders to be carried out on the plant floor in Brooklyn.
