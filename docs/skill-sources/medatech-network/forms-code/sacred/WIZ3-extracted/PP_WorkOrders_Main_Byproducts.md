PP_WorkOrders_Main_Byproducts 
 
 
- 
 
 
 

Sometimes one source part can be used to create several different sets of byproducts; for example, a wood board could be cut to create one large tabletop and its accessories, or two small tabletops and their accessories. In such a case, one byproduct from each set is chosen to be the main byproduct of that set, and is linked to the other byproducts in that set.
