# PP_WorkOrders_number_pattern_width_of_field

- **Source:** `PP_WorkOrders_number_pattern_width_of_field.htm`

PP_WorkOrders_number_pattern_width_of_field 
 
 
- 
 
 
 

If you specify 4, the first sequential numbers will be 0001, 0002, 0003 …. 
 

Note that this number determines the maximum number of work orders that you can open using this template. For example, with a value of 4 you can open no more than 9999 work orders. If you leave the default value of 0, the number of work orders that you can open will be infinite (and the numbers will appear without leading zeroes: 1, 2, 3 … 10 …100).
