# PP_WorkOrders_rework_exp

- **Source:** `PP_WorkOrders_rework_exp.htm`

PP_WorkOrders_rework_exp 
 
 
- 
 
 
 

When you open a work order for rework, all operations in its routing are automatically flagged as rework when they are reported. You can also flag a production report as rework manually, without opening a special work order, and it will be ignored by the Backflush program.
