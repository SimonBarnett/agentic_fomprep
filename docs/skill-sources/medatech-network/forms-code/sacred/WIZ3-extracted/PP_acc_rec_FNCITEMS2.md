# PP_acc_rec_FNCITEMS2

- **Source:** `PP_acc_rec_FNCITEMS2.htm`

PP_acc_rec_FNCITEMS2 
 
 
- 
 
 
 

This form parallels the sub-level form of Receipts that lists the invoices that are linked to a receipt (the Invoice Amounts Being Paid form). That is, if several invoices are flagged for payment, each one of them appears on a separate line, even though they usually appear in the ledger as one amount. 
 

If the receipt is already partially reconciled with one or more invoice installments, these will appear as well, and a reconciliation number will be displayed.
