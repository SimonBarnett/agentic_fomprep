# Adding Shipping Prices in a Multi-Shipment Invoice

 

As each shipper's rates are defined per shipping zone and vehicle type, and each individual vehicle is assigned a shipper and a vehicle type (in the Transports form), the designation of a vehicle number in a shipping document automatically adds a line charging for shipping in the invoice for that document.
