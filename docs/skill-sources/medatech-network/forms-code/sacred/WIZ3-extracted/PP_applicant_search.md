# PP_applicant_search

- **Source:** `PP_applicant_search.htm`

PP_applicant_search 
 
 
- 
 
 
 

The parallel Qualified Applicants for Job sub-level form is a tool for finding qualified applicants for a given job, as it displays all eligible candidates and employees that are not yet linked to the job. Eligibility is determined by their status (which must be defined as part of the applicant pool) and their qualifications (they must have all qualifications flagged in the Include in Appl Search column of the Qualifications Required for Job form). You simply flag all applicants that you want to consider; when you exit the form, these applicants are moved to the parallel List of Applicants and Current Job Applicants sub-level forms.
