# PP_approve_difference

- **Source:** `PP_approve_difference.htm`

PP_approve_difference 
 
 
- 
 
 
 

If the detected variance is positive, the adjusting inventory transaction adds the missing quantity to the current inventory balance. Conversely, if the detected variance is negative, the adjusting transaction subtracts the difference from the current balance. For example, if the calculated quantity is 5 and the counted quantity is 8, once you approve the variance, 3 items will be added to the current inventory balance.
