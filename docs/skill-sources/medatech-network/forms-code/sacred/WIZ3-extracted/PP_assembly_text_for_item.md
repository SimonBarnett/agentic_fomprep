# PP_assembly_text_for_item

- **Source:** `PP_assembly_text_for_item.htm`

PP_assembly_text_for_item 
 
 
- 
 
 
 

If the assembly is based on a sales order, the remarks recorded for this item in the order appear automatically as remarks for the assembled item. Otherwise, if the Copy Part Remarks column is flagged for this document type in the Copy Part Remarks to Document form, remarks are taken from the Parts - Remarks form, a sub-level of the Part Catalogue form.
