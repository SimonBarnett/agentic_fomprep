# PP_bonded_warehouse

- **Source:** `PP_bonded_warehouse.htm`

PP_bonded_warehouse 
 
 
- 
 
 
 

A bonded warehouse is where imported goods are stored prior to payment of customs duties and release by a customs agent. Customs only become due when the goods are released from the bonded warehouse. 
 

Goods stored in the bonded warehouse are usually those for which the customs duties are exceptionally high (e.g., an automobile), and are therefore only released when actually purchased by a customer. 
 

Imported goods are not subject to costing or inventory valuation until they are released from the bonded warehouse. For more information, run the Shipping Expenses Wizard .
