# PP_commission_main_part_pricing

- **Source:** `PP_commission_main_part_pricing.htm`

PP_commission_main_part_pricing 
 
 
- 
 
 
 

You may want to record the price for a single main component and leave all other components without prices. For instance, if the product bundle is for a digital camera and accessories, you would manually record the price for the main component “camera” and leave the price blank for all other components (camera case, memory card, batteries and so on).
