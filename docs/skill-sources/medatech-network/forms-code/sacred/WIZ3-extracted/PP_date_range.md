# PP_date_range

- **Source:** `PP_date_range.htm`

PP_date_range 
 
 
- 
 
 
 

  
 

 ·        Account reconciliation: the maximum range (in days) within which the system will compare the due dates of two journal entries. 
 

 ·        Bank reconciliation: the range (in days) within which the system will compare an entry's due date with the date of the statement item.
