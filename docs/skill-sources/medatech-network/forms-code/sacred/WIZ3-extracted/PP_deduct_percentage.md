# PP_deduct_percentage

- **Source:** `PP_deduct_percentage.htm`

PP_deduct_percentage 
 
 
- 
 
 
 

The percentage of each invoice total that will be deducted from the amount owing. Usually, you indicate the same percentage as was paid in advance. For instance, if 20% of the order is being paid in advance, you would probably indicate a deduction percentage of 20.
