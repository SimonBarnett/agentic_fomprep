# PP_document_in_hierarchy

- **Source:** `PP_document_in_hierarchy.htm`

PP_document_in_hierarchy 
 
 
- 
 
 
 

If the document in question is based on another document (e.g., a customer shipment based on an order), all prices and discounts are usually taken from the original document. However, if the DocPrice constant (in the Financial Constants form) is set at 3 or 4 , prices will be taken from the price list even if the document is based on an order. 
 
## Note: 

 

In an invoice, the price source (customer shipment, order or price list) is always determined by the DocPrice constant.
