# PP_final_reconciliation

- **Source:** `PP_final_reconciliation.htm`

PP_final_reconciliation 
 
 
- 
 
 
 

Finalizing a pending reconciliation assigns an identical final reconciliation number to all relevant journal entries. The finalized items are deleted from the Reconciliation Worksheet . 
 
## Note:

 

The reconciliation number assigned to a final reconciliation is different from the pending reconciliation number assigned in the Reconciliation Worksheet, which is only temporary and is deleted when the reconciliation is finalized.
