# PP_final_reconciliation_acct

- **Source:** `PP_final_reconciliation_acct.htm`

PP_final_reconciliation_acct 
 
 
- 
 
 
 

The Finalize Reconciliation program assigns an identical reconciliation number to each of the reconciled journal entries. All finalized items are then deleted from the Reconciliation Worksheet . 
 
## Note:

 

The reconciliation number assigned to a final reconciliation is different from the reconciliation number assigned in the Reconciliation Worksheet, which is only temporary and is deleted when the reconciliation is finalized.
