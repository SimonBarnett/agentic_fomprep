# PP_holding_warehouse

- **Source:** `PP_holding_warehouse.htm`

PP_holding_warehouse 
 
 
- 
 
 
 

In the event that goods are not immediately shipped to the customer, but remain on your premises even after the invoice is issued, they are stored in a holding warehouse. Inventory in holding warehouses is not taken into account during costing. For more information, see the Customer Invoices Wizard .
