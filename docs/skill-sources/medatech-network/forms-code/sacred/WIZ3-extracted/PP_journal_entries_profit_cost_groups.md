# PP_journal_entries_profit_cost_groups

- **Source:** `PP_journal_entries_profit_cost_groups.htm`

PP_journal_entries_profit/cost_groups 
 
 
- 
 
 
 

Each profit/cost group contains a different set of profit/cost centers, representing a different cross-section of cost and revenue data. 
 

In the Profit/Cost Center 1 column, you can select a profit/cost center belonging to the first profit/cost group, in the Profit/Cost Center 2 column a profit/cost center belonging to the second group, and so on.
