# PP_loan_warehouse

- **Source:** `PP_loan_warehouse.htm`

PP_loan_warehouse 
 
 
- 
 
 
 

A consignment/loan warehouse is used to record the “holding” of goods shipped on consignment or on loan to a customer. Though the merchandise is physically stored at the customer, it is recorded as inventory in the warehouse, where it remains subject to inventory valuation and costing control. If the warehouse is flagged for multiple customers (in the Inv. by Customer column), the parts that are shipped to it receive the ID number of the receiving customer as their status. For more information, see the Consignments Wizard .
