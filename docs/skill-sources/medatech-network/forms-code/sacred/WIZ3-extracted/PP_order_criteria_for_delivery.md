# PP_order_criteria_for_delivery

- **Source:** `PP_order_criteria_for_delivery.htm`

PP_order_criteria_for_delivery 
 
 
- 
 
 
 

To be scheduled, the order must meet the following conditions: 
 

 ·        The order status must allow for shipment and for delivery scheduling. 
 

 ·        If statuses are also assigned to order items, the item status must also allow for shipment. 
 

 ·        At least one order item must belong to a part family flagged for delivery. 
 

 ·        The order must be open.
