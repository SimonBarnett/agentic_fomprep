# PP_pending_reconciliation

- **Source:** `PP_pending_reconciliation.htm`

PP_pending_reconciliation 
 
 
- 
 
 
 

A pending reconciliation is one that has been started but not completed. It appears in the Reconciliation Worksheet (as two or more records sharing the same reconciliation number), but not in the ledgers. 
 

When you finalize (i.e., accept) a pending reconciliation, it is recorded in the ledgers and the records are deleted from the worksheet.
