# PP_predefined_warehouse

- **Source:** `PP_predefined_warehouse.htm`

PP_predefined_warehouse 
 
 
- 
 
 
 

  
 
 
 
 

Warehouses are categorized into three warehouse types . One predefined warehouse is provided for each type. In a manufacturing setting, all three types of warehouses are used. In a non-manufacturing setting, only types D and W are used. 
 

  
 
 
 

 Type 
 
 

 Description 
 
 

 Predefined Warehouse 
 
 
 

 F 
 
 

Work cells; storage areas on the plant floor. 
 

Used only in a manufacturing setting. 
 
 

 Plant Floor (Flr) . This warehouse is automatically attached to all work cells. 
 
 
 

 D 
 
 

Materials and finished goods that are considered during production planning, MRP and purchase planning. 
 

In a non-manufacturing setting, used for most warehouses. 
 
 

 Factory Warehouse ( Main ) 
 
 
 

 W 
 
 

Goods not available for current sales purposes (e.g., a remote warehouse whose inventory is available for sale only near there). These goods are not considered during various types of inventory calculations (e.g., projected balances, purchase planning, MRP).
