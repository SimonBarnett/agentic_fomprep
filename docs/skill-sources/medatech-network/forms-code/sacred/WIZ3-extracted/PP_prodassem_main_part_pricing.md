# PP_prodassem_main_part_pricing

PP_prodassem_main_part_pricing 
 
 
- 
 
 
 

You may want to assign the price to a single main component and leave all other components without a price. For instance, if the product bundle is for a digital camera and accessories, you would manually record the price (in the quote or order) for the main component “camera” and leave the price blank for all other components (camera case, memory card, batteries and so on).
