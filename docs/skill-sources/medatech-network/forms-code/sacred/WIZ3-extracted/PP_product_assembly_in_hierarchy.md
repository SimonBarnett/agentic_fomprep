# PP_product_assembly_in_hierarchy

- **Source:** `PP_product_assembly_in_hierarchy.htm`

PP_product_assembly_in_hierarchy 
 
 
- 
 
 
 

If a special unit price has been assigned to the component part in a product bundle, this price will appear in the sales document. If the part is flagged for price calculation in the document, its price is determined by the regular price hierarchy. A price of 0 indicates that the product bundle is priced according to its main component rather than the parts that comprise it. 
 

 Tip: To define a product bundle, run the Product Bundles Wizard .
