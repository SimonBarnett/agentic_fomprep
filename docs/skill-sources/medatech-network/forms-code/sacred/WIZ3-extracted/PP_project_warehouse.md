# PP_project_warehouse

- **Source:** `PP_project_warehouse.htm`

PP_project_warehouse 
 
 
- 
 
 
 

When working with projects you need to assign a warehouse to each project. This will ensure accurate calculation of the project's inventory charges. That is, all inventory transferred to the project (e.g., via GRV or warehouse transfer) is billed to the project, as are all issues of supplies. In order to avoid double billing (e.g., for receipt and issuance of the same part), the inventory needs to be received in one of the project's warehouses. For more information, see the Project Management Wizard .
