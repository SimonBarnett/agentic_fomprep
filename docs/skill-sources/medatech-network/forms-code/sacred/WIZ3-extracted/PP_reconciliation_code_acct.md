PP_reconciliation_code_acct 
 
 
- 
 
 
 

A reconciliation code is a procedure used by the automatic reconciliation program to match journal entries. It consists of one or more predefined reconciliation methods (e.g., match by reference number, match by amount) in a set order. You can create as many reconciliation codes as you need (e.g., different ones for different accounts). Or you can use Priority 's predefined code.
