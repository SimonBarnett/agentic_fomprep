# PP_representative_cust

- **Source:** `PP_representative_cust.htm`

PP_representative_cust 
 
 
- 
 
 
 

A representative customer is one whose assigned prices, discounts and parts are inherited by other customers. 
 

For example, you might sell goods to various branches of a fast-food restaurant chain. Rather than setting prices, discounts and parts for each branch separately, you can set them for one branch and then define that branch as the representative customer for the other branches. 
 

 Note : The representative customer is not necessarily the billing customer.
