# Creating Reversing Documents

 

If the original document added to inventory balances, the reversing document subtracts from them, and vice versa. An entry is opened automatically for the reversing document in the Audit Trail form. 
 
## To create a reversing document:

 

 1 .  Open a new document of the same type as the original document (e.g., a shipping document). 
 

 2 .  Manually record the incorrect items in the sub-level form exactly as they appear in the original document, with one exception: Record quantities as negative values.
