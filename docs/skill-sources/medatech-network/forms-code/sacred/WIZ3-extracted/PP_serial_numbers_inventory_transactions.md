# Inventory Transactions

 

 ·        Receipts from vendors (as recorded in goods receiving vouchers or vendor invoices) 
 

 ·        Laboratory testing 
 

 ·        Returns to vendors 
 

 ·        Issues of materials (issues to floor stock, issues to kits, manual issues) 
 

 ·        Reports of production 
 

 ·        Warehouse transfers 
 

 ·        Packing of goods 
 

 ·        Shipments to customers (as recording in shipping documents, sales invoices or over-the-counter invoices) 
 

 ·        Returns from customers 
 

 ·        Part sampling 
 

 ·        Inventory disposal
