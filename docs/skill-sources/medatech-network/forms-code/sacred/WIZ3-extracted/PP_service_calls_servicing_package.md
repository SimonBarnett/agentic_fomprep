# PP_service_calls_servicing_package

- **Source:** `PP_service_calls_servicing_package.htm`

PP_service_calls_servicing_package 
 
 
- 
 
 
 

You can define a variety of servicing packages that you offer customers, each including different services (for example, installation costs; semi-annual servicing). When you choose a servicing package while recording a service call, the information on serviced parts, labor and prices is filled in automatically.
