- 
 
 
 

If payments are quarterly, they are always calculated for all contracts for January 1, April 1, July 1 and October 1. 
 

 Exception: The first period is likely to be slightly longer, since a service contract does not necessarily begin at the start of a quarter. Consequently, if a service contract begins on November 15, the first payment will cover the period between November 15 and March 31. The second payment will cover the period between April 1 and June 30, and so on.
