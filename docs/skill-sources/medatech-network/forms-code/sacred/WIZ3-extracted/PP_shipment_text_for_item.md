# PP_shipment_text_for_item

- **Source:** `PP_shipment_text_for_item.htm`

PP_shipment_text_for_item 
 
 
- 
 
 
 

If the current document is based on another document, any remarks recorded for this item in the original document are automatically copied to the line item here. Otherwise, if the Copy Part Remarks column is flagged for this document type in the Copy Part Remarks to Document form, remarks are taken from the Parts - Remarks form, a sub-level of the Part Catalogue .
