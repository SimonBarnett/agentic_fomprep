# PP_transit_warehouse

- **Source:** `PP_transit_warehouse.htm`

PP_transit_warehouse 
 
 
- 
 
 
 

A transit warehouse is a virtual warehouse that “stores” ordered goods as they are being shipped to a consignment warehouse. This allows the Replenish Consignment Warehouses program to keep track of this inventory when calculating the amounts required to replenish the inventory in the consignment warehouse. You should open a transit warehouse for a given consignment warehouse when the shipping time between the company warehouse and the consignment warehouse is expected to be long. For more information, see the Consignments Wizard .
