# PP_unknown_index_values

- **Source:** `PP_unknown_index_values.htm`

PP_unknown_index_values 
 
 
- 
 
 
 

Since index values for a given month are published sometime in the following month, an asset's base index is generally not available at the time of the purchase or sale. Moreover, if the purchase or sale is early in the month, before the index value is released, it is also possible that the previous month's index is not yet known. For example, if the index is published on the 15th of every month, and an asset is purchased on March 14, then its base index will be unknown until April 15 and its previous month's (February's) index will be unknown until March 15.
