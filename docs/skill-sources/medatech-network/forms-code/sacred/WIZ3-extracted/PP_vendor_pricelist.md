# PP_vendor_pricelist

- **Source:** `PP_vendor_pricelist.htm`

PP_vendor_pricelist 
 
 
- 
 
 
 

A given vendor is defined as the preferred vendor for a certain part. The part price in the vendor price list is $10. The price list is flagged as a price source for customers using list prices (without the vendor discount), and its price factor is 1.2 (representing a 20% markup). 
 

In a sales document recorded for the customer in which no other part price is available, a price of $12 will appear.
