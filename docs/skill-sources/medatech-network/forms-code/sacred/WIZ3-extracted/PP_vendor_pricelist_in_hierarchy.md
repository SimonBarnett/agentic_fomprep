PP_vendor_pricelist_in_hierarchy

If the part does not appear in the Base price list, the price may be taken from the price list of its preferred vendor, if that price list has been defined as a price source for customers. In this case, a specified markup is added to either the vendor's listed or discounted price. All customer discounts remain in effect.
