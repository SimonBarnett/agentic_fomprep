# Setting Up Price Quotations 

 

Before you begin working with price quotations, you need to perform several setups. 
 
## What do you want to do?

 

 Round the total price 
 

 Set the expiration period 
 

 Determine how quoted prices are calculated in a customized BOM 
 

 Set up business processes (BPM) for price quotations (statuses) 
 

 Record set text for price quotations 
 

 Set up part remarks for price quotations 
 

 Define types of sales 
 
## Notes:

 

 ·        To define product bundles on which to base a quote, run the Product Bundles Wizard .
