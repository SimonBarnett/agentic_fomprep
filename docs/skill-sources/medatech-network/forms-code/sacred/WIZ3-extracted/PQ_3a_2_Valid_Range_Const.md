# Setting the Expiration Period

 

You can set a default time period (in days) in which price quotations will remain in effect. 
 
## To set the default expiration period:

 

 ·        Enter the Logistic Constants form, move to the SQuoteDays constant, and specify the number of days in the Value column. 
 
## Note: 

 

 SQuoteDays is preset at 30.
