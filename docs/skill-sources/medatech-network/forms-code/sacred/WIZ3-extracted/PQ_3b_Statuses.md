# Setting Up Business Processes for Price Quotations

 

You set up business processes by defining statuses in a BPM flow chart. 
 

There are several predefined statuses for price quotes, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Customer Quotes program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To add a status description that will appear on printouts of any price quotes with a given status, retrieve the status in the Statuses for Price Quotations form and specify the description in the Additional Status Definitions sub-level form. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Price Quotations form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
