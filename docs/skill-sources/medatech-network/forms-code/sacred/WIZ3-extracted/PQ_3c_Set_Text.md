# Assigning Set Text to Price Quotations

 

Create set text so that certain remarks appear on all (or most) of the printouts of price quotations. You can later change or delete these remarks for each specific price quotation. 
 
## To assign set text:

 

 1 .  Enter the Set Text for Price Quotes form. 
 

 2 .  Record the desired remarks in the Set Text for Price Quotations sub-level form. 
 D ual-currency users: If you are working in a language other than English, and wish to print out price quotations in English, record set text in the Set Text for Price Quotes-Lang 2 sub-level form. Any quotes opened for customers defined as receiving Printouts in Lang 2 will contain set text in English. 
 

These remarks will automatically appear in the Price Quotations - Remarks sub-level form of each new price quotation, and may be revised there. Any remarks appearing in this sub-level form are automatically included in the printout of the quote. 
 
## Note: 

 

Set text is overwritten by remarks assigned to specific types of sales.
