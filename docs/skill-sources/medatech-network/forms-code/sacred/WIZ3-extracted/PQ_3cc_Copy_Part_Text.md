# Copying Part Remarks to Price Quotations

 

You can set up price quotations so that part remarks are recorded automatically for individual items when a part number is recorded or revised in an itemized quote. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks to quoted items:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "Price Quotation", flag the Copy Part Remarks column.
