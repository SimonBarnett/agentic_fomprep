# Defining Types of Sales

 

Each price quote can be assigned a specific type of sale, each with its own designated set text. This text will automatically appear in the Price Quotations - Remarks sub-level form of any quote of this type, overwriting the general set text defined for price quotations, and consequently appear on the printout. 
 

Individual users can be assigned default sales types, which will appear automatically on any price quote they record. 
 
## To define sale types:

 

 1 .  Enter the Types of Sales form. 
 

 2 .  Record the code number and description of the desired sale type. 
 D ual-currency users: If you are working in a language other than English, and wish to produce reports that include a description of the sales type in English, fill in the Type of Sale (Lang2) column. 
 

 3 .  Enter the Set Text for Quotes/Orders sub-level form and record set text for this type of sale.
 Dual-currency users: If you are working in a language other than English, and wish to print out quotes in English, record set text in the Set Text for Quotes/Orders-Lang2 sub-level form. Any quotes of this type opened for customers defined as receiving Printouts in Lang 2 will contain set text in English. 
 
## To assign a default sale type:

 

 1 .  Enter the Personnel File form and retrieve the desired user. 
 

 2 .  Enter the Company-Specific Information sub-level form, and choose the appropriate Type of Sale . The set text for that sale type will appear automatically in every price quote recorded by that user. 
 
## Note: 

 

The default sales type will also be assigned to any sales order opened by this user.
