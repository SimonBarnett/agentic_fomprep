# To check the quoted items:

 

 1 .  Enter the Itemized Quotation sub-level form. The price quote is itemized automatically on the basis of the original quote. 
 

 2 .  Make sure that the part descriptions are suitable.
 Tip: You can change the description of any part that is flagged in the Change Desc. column of the Part Catalogue form. 
 

 3 .  In the Qty column, make sure that the minimum quantities for each item are correct.
 Tip: To check part availability, use the Inventory for Part and the Part Availability sub-level forms. 
 

 4 .  Make sure that the unit price and discount are correct for each item.
 Notes: 
 

 ·      Select Discounts Applying to Item from the list of Direct Activations to view a breakdown of the discounts awarded for the part. 
 

 ·      You can view the profitability of the item in the Actual Profit column. See the Profitability Wizard for more details. 
 

 ·      For more information on prices and their sources, see the Prices and Discounts Wizard . 
 

 5 .  Click if an item requires a customized bill of materials. Example. 
 Notes: 
 

 ·      If you make any changes in the BOM, these will affect the quoted item's price and cost, with two exceptions:
1) If they were recorded manually, the only way to change them is by selecting Calculate Price/Cost by BOM from the list of Direct Activations .
2) If the SBOMPrice constant is set to 0 , the item's price will not be affected, even by running Calculate Price/Cost by BOM . 
 

 ·      Before printing the quote, select the With Custom BOM print format.
