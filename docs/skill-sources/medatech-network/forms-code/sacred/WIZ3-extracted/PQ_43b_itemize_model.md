# To check quoted items for product bundles:

 

 1 .  Enter the Itemized Quotation sub-level form. It is itemized automatically according to the recorded product bundles and their quantities. 
 

 2 .  The Part Number of each default component for this bundle is filled in automatically. To change a quoted item, press F6 and select the part in question from the Choose list.
 Note: The Choose list includes all parts defined as substitutes for the default component in this product bundle. 
 

 3 .  Make sure the part quantity is correct. 
 

 4 .  If a unit price and/or discount appear automatically, ensure that they are correct and revise when necessary. . 
 Notes: 
 

 ·      Click for a review of resources to consult when pricing manually . 
 

 ·      Click if you want to record a desired markup and have Priority calculate the price for you. 
 

 ·      If an item is not to be billed, remove the check from the Billable column, and the price will revert to 0.00. Example.   
 

 ·      The Price Source column displays the source of the quoted price (e.g., special part price, customer price list, manual entry). 
 

 ·      Only discounts and special prices that are valid for the full period in which the price quotation is in effect are used to calculate item prices.
