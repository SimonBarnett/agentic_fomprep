# Recording a Price Quotation

 

There are several methods of itemizing a new price quotation. You can specify items, their quantities and prices manually, or you can copy them from an existing price quotation and then modify them. 
 

Another method is to create a price quotation for product bundles, that is, sold parts that actually comprise an assortment of items. Each component part in a given bundle can have defined substitutes. 
 

Finally, you can open a price quotation from within a sales opportunity. 
 
## Tips:

 

 ·        To define product bundles, run the Product Bundles Wizard . 
 

 ·        To open a quote from a sales opportunity, run the CRM Wizard .
