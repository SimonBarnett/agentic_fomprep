# Printing the Price Quotation

 
## To print one quote:

 

 1 .  Retrieve the quote in the Price Quotations for Customers form. 
 

 2 .  Select Print Price Quotation from the list of Direct Activations .
 D ual-currency users: If you wish to print the quote in English and are working in another language, click Print Quote in Foreign Language instead. 
 
## To print more than one quote:

 

 ·        Run the Print Price Quotation report.
 D ual-currency users: To print in English when working in another language, run the Print Quote in Foreign Language report. 
 
## Notes: 

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen.
