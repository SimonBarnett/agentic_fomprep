# Linking a Quoted Item to a Project

 

You can link individual quoted items to a project or activity. This link will then be copied to any order item opened on the basis of this quoted item. 
 
## To link the quoted item to a project and/or activity:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  In the Project Number column, choose the project number.
 Note : If you have specified a project for the entire quote, it will appear automatically and may not be changed. 
 

 3 .  The project's default income account appears automatically in the Account Number column. Revise it if necessary. 
 

 4 .  In the WBS column, choose the WBS code of the activity. 
 

 3 .  Change the Percent Completed , if necessary.
 Note: To revise the Activity Status , move to the Activity ID column and press F6 , then make the revision in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 4 .  Return to the Itemized Quotation upper-level form.
