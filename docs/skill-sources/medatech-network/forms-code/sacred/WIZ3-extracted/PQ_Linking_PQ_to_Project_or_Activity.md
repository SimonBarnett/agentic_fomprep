# Linking a Quote to a Project or Activity

 

You can link a price quote to an entire project or a specific project activity. This link will then be copied to any sales order that is opened on the basis of the quote. 
 
## To link the quote to a project:

 

 1 .  Click the Project tab. 
 

 2 .  In the Project Number column, choose the project.
 Note : Project information will appear automatically if a single project has been recorded for the customer, and the SLinkProject constant is set to 1 . 
 
## To link the quote to a project activity:

 

 1 . Enter the Projects/Accounts sub-level form. 
 

 2 . In the Project Number column, choose the project. 
 

 3 . The project's default income account appears automatically in the Account Number column. Revise it if necessary. 
 

 4 . In the WBS column, choose the WBS code of the activity.
 Note: You cannot revise the Percent Completed column in this form. Instead, move to the Activity ID column and press F6 , then make any revisions desired to the project activity in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 5 . Return to the Price Quotations for Customers upper-level form.
