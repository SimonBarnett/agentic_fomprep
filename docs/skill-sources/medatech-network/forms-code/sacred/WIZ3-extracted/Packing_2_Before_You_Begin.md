# Setting Up Packing Slips

 

To record the packing of goods, you must create a list of packing crates, together with their capacity, weight (prior to packing) and volume. Furthermore, you can define a default warehouse which will be filled in automatically in all packing slips. Finally, you can set up business processes (BPM) for packing slips – i.e., define statuses, as well as record set text. 
 
## What do you want to do?

 

 Record crate types 
 

 Define a default warehouse 
 

 Set up the method of linking packing slip s to sales orde rs 
 

 Set up BPM for packing slips 
 

 Record set text for packing slips
