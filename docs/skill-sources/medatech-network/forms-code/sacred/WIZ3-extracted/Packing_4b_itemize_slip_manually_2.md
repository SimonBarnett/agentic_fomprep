# To itemize the packing slip:

 

 1 .  Click if the packed goods are for a project. 
 

 2 .  Enter the Packed Items sub-level form. 
 

 3 .  Specify the Part Number of the packed item. 
 

 4 .  If you work with projects, click to link an item to a project or project activity. 
 

 5 .  Specify the Work Order (or lot, if you are packing raw materials) to which the part belongs.
 Note: You cannot pack a part from a work order that has expired. 
 

 6 .  The Warehouse and Bin from which the goods are taken are copied from the upper-level form. Change them, if necessary. 
 

 7 .  Do one of the following: 
 

 ·      Select the Crate Type Code and specify the number of packed crates in the Packing Crates (No.) column. The Quantity column will be filled in automatically. 
 

 ·      Specify the quantity of the part being packed in the Quantity column. 
 

 Note : If you are allowed to record partially packed crates (i.e., the IPartialPack constant is set to 1 in the Logistic Constants form), you can designate the number and type of packing crates and then revise the packed quantity accordingly. Once you do, however, any revision to the number or type of packing crates will have no effect on the packed quantity. 
 

 8 .  To record serial numbers for the packed part, use the Serial Numbers in Transaction or the Auto Recording of Serial Nos. sub-level forms. 
 

 9 .  Return to the upper-level form. 
 
## Notes:

 ·        Click to return to the main screen.
