# Finalizing the Packing Slip

 

Once all details in a packing slip are complete, the document must be finalized. Only then can a packing crate be included in a bill of lading or transferred to another warehouse. 
 
## To finalize the packing slip:

 

 ·        In the Packing Slip form, retrieve the packing slip in question and change its status to Final . 
 
## Notes:

 

 ·        Click to print the packing slip. 
 

 ·        Click to return to the main screen.
