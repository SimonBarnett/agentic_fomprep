# To define a default warehouse:

 

 1 .  Enter the Inv. Transaction Documents form and move to the Packing Slip line. 
 

 2 .  In the Default Warehouse column, choose the default warehouse (i.e., the warehouse from which goods are usually shipped). You may also specify a warehouse bin.
