# Set Text for Packing Slips

 

If you want certain remarks to appear on all printouts of packing slips, you can designate set text for this purpose. 
 
## To designate set text:

 

 1 .  Enter the Set Text for Packing Slips form. 
 

 2 .  Record the desired remarks in the Set Text for Packing Slips sub-level form.
 Dual-currency users: If you are working in a language other than English, and wish to print packing slips in English, record set text in the Set Text for Pack Slips-Lang 2 sub-level form. Any documents opened for customers defined as receiving Printouts in Lang 2 will contain set text in English. 
 

These remarks will automatically appear in the Remarks sub-level form of each new packing slip, but may be revised there. Any remarks appearing in that sub-level form appear automatically in the printout of the packing slip.
