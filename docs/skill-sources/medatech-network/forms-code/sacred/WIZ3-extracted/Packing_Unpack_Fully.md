# To fully unpack a crate:

 

 1 .  Enter the Packing Slip form, and retrieve the packing slip in question. 
 

 2 .  Select Unpack Crate from the list of Direct Activations . The program opens another packing slip for the fictional “Goods” customer and assigns both the original and the new slip a status of “Unpacked”, which does not allow the crate to be used anymore (e.g., linked to a shipping document). The items in the new packing slip are moved into inventory in the warehouse in which the crate is unpacked.
