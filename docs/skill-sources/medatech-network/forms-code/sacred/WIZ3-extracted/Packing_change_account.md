Packing Slip - Changing the Account for a Project Transaction 
 
 
- 
 
 
 
# To change the account affected by the transaction:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  Choose/check the project number. The default account of the project appears in the Account Number column. 
 

 3 .  Choose the account to be affected by the current transaction.
