Packing Slip - Recording Crate Types 
 
 
- 
 
 
 
# To record crate types:

 

 1 .  Enter the Packing Crate Types form. 
 

 2 .  Specify the code and type (e.g., Box) of the packing crate. 
 

 3 .  Specify the Crate Weight and its unit of measure. 
 

 4 .  Specify the Crate Volume . The default unit of volume is cubic foot (cft), but this may be revised. 
 

 5 .  Specify the crate's Capacity , i.e., the number of parts it usually holds, in buy/sell units. If capacity varies according to the part being packed, use the Crate Capacity per Part sub-level form instead.
