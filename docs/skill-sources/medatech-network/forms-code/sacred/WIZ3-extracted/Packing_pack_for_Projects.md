# Packing for Projects

 

You can link a packing slip to a project or to a specific project activity (when the packed goods are for a single activity). The cost of the transaction is added to the cost of the activity or project to which it is linked. 
 

Once the transaction is linked to a project or activity, you can change the account credited by the packing slip if it differs from the project's default account. 
 

Project information will appear automatically in the following cases: 
 

 ·        When a single project has been recorded for the customer, and the SLinkProject constant is set to 1 . 
 

 ·        When the packing slip is based on a single sales order linked to a project. 
 
## Note:

 

When itemizing the slip, you will also be able to link individual items to a project activity. 
 
## What do you want to do?

 

 Link the packing slip to the entire project or check the linked project 
 

 Link the packing slip to a project activity or check the linked activity 
 

 Change the account being credited
