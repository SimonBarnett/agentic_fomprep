# To assign one part to a part family:

 

 1 .  Enter the Part Catalogue form. 
 

 2 .  Specify the desired Family in the Details tab. 
 
## To assign a group of parts to a part family:

 

 ·        Run the Add Parts to Family program. 
 
## To remove a group of parts from a part family (and re-assign them to the Default family):

 

 ·        Run the Remove Parts from Family program.
