# Working With Base Products

 

You can select any part in your catalogue to serve as the base product for a group of related parts. Base products are useful both as an analytical and a logistical tool: 
 

 ·        Reports according to base product provide a higher level of data analysis. For example, if you link all colors and sizes of running shoe to a given shoe (e.g., Nike, white, size 8), you can analyze your sales data for all running shoes as a unit. 
 

 ·        Most inventory transaction documents feature a print format that unites all parts sharing the same base product (as well as the same unit price and discount) into a single line. 
 

 ·        Base products facilitate the itemization of inventory and financial documents. By specifying a base product, you can use a Choose list to select part numbers from the list of parts linked to that product. 
 

 ·        You can use base products to automatically adjust the prices and discounts of linked parts. For example, if all the running shoes are priced the same, you can raise the price of the base product in order to automatically raise the price of all the shoes linked to it. Furthermore, if a linked part consists of several units of the base product (e.g., a three-pack or ten-pack), the program automatically multiplies the new base price by the number of units. 
 

 ·        You can load parts into the Part Specs Work Area on the basis of their base product; furthermore, you can use the work area to assign a common base product to a new batch of parts. 
 

You link a part to a base product in the Part Catalogue form.
