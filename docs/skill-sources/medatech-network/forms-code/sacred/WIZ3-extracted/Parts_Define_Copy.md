# Copying an Existing Part

 

If the new part you wish to define is very similar to an existing part, you can save time by copying records from one part to the other. You can number the new parts manually or have the system number them automatically, on the basis of a designated part template. 
 
## Tip: 

 

Click to define part templates. 
 
## To copy a part:

 

 ·        Run the Copy Parts program.
 Note: If the CopyPartRev constant is set at 1 (default), the part's revisions and BOM revisions are copied as well. 
 
## To revise the new part:

 

 1 .  Enter the Part Catalogue form and retrieve the new part. Make any necessary revisions.
 Note: At any point in the following process, you can transfer handling of the part to another employee, by specifying his/her username in the Assigned to column (in the Additional Details tab). 
 

 2 .  Click the Specs tab and make any necessary changes to the part specifications. 
 Tips: 
 

 ·      Click to define new part specifications or add new spec values. 
 

 ·      You can also use the Part Specifications form to assign (and view) specifications that define parts. 
 
## Note:

 

Links to parent parts are not copied. Record them manually in the Single-level Bill of Materials form.
