 6 .  Record the Factory Unit in which the part is generally processed. 
 Notes: 
 

 ·      If the part is manufactured in the factory, use the unit in which it is produced. 
 

 ·      If the part is a package containing multiple units of a base product, select ea . 
 

 ·      Otherwise, use the same unit recorded in the Unit column. 
 

 7 .  In the Conversion Ratio column, record the number of factory units that equal one buy/sell unit. If the ratio between these units is predefined in the Unit Conversions form, it appears automatically.
 Note: If the part is a package containing multiple units of a base product, indicate the quantity of units. 
 

 8 .  If you want to be able to record inventory transactions for this part (e.g., shipping documents and GRVs) in which the quantity in buy/sell units does not correspond to the quantity in factory units (for pricing purposes), flag the Variable Conversion column.
 Note: When a part is flagged in this column, quantities recorded in the buy/sell unit in inventory documents do not affect its inventory balance.
