Part Definition - Defining Inventory Parameters 
 
 
- 
 
 
 
# To define inventory parameters:

 

 1 .  Enter the Inventory Parameters for Parts form, and record the Part Number . The Part Description and Type appear automatically. 
 

 2 .  In the Inventory tab, specify the Warehouse and Bin in which the part is generally stored. Default values appear, but may be revised. 
 

 3 .  Specify the default Entry Status received by the part when recorded in a Goods Receiving Voucher . The status Goods appears automatically, but may be revised. 
 

 4 .  Click the Sales tab and define the part's Order Tolerance ; this is the percentage by which a receipt or shipment is permitted to exceed the ordered quantity. 
 

 5 .  Define the part's Close Order Tolerance ; this is the order balance at which a purchase or sales order automatically closes. It can be defined in part units, or as a percentage of the order. For the latter, use the Close Order Toler (%) column. 
 

 6 .  If the part is shipped in crates, designate a Crate Type Code . This will appear as the default value in a number of inventory documents (e.g. shipping documents).
