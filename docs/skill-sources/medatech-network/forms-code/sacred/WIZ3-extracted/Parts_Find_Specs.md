# The Part Specs Explorer

 

Run the Part Spec Explorer to locate the number and prices of parts according to their specifications. The Explorer can also be accessed from the Part Number column in any form. 
 
## To enter the Explorer directly:

 

 1 .  Run the Part Specs Explorer program. 
 

 2 .  Click Search in the Open Part Spec Explorer dialogue box. A list of all first-level assigned values appears (that is, those values of Spec 1 that have been assigned to parts). 
 

 3 .  Do one of the following: 
 

 ·      Select one of the first-level specification values (e.g., “Volvo”) and click View . The Explorer will display all parts that were assigned that value, in hierarchical order (based on additional specifications assigned to each part). 
 

 ·      Click View All . The Explorer will display all parts that have been assigned specification values, in hierarchical order. 
 

 4 .  Open and close items as in any Windows explorer. When you reach a part's lowest level (i.e., its last assigned specification), you will be able to view its part number, list price and purchase price. 
 

 5 .  Use Copy and Paste to copy the part number into a form (e.g., a sales order).
