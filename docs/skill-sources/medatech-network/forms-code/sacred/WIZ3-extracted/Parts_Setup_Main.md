# Setting Up Parts

 

Before you begin working with parts, you need to define part units, families and specifications. You can also set a constant that determines whether part revisions and BOM revisions are copied automatically when a part is copied, as well as a constant that causes item remarks (extended part descriptions) to be read only. Finally, you need to set up the BPM flow chart for part statuses. 
 
## What do you want to do?

 

 Define part units and unit conversions 
 

 Define part numeration templates 
 

 Define part families 
 

 Define part specifications 
 

 Set whether revisions are copied together with parts 
 

 Block revision of item remarks in documents 
 

 Set up business processes (BPM) for parts (statuses)
