# Defining Part Specifications

 

Part specifications classify the various attributes of a part into a hierarchy of categories, which can be used to retrieve specific cross-sections of parts. 
 

Specifications should be defined in order of the most distinguishing characteristics, so that each new specification creates sub-categories of the previous one. For example, Spec 1 should be the part Model , Spec 2 the Year of its manufacture, and Spec 3 the Color . Example. 
 

Specifications can also be combined to create new parts, using the Part Specs Work Area. If you intend to use part specifications in this manner, skip this setup and follow the more extensive setup instructions when defining a new part. 
 
## Note:

 

By default, part specifications do not appear in document printouts. To change the default so that part specifications are displayed, the system manager can run the Show/Hide Part Specs in Printout program. 
 
## To define part specifications:

 

 1 .  Enter the Definition of Part Specs form. 
 

 2 .  For each specification, define a Type and Spec Description . 
 

 3 .  If the specification is numeric, designate its permitted Minimum Value , Maximum Value and Increment . Example. 
 

 4 .  If the specification is non-numeric, enter the Permitted Spec Values sub-level form and record all its possible values in the Specification column. If a given value is only relevant for parts in a particular part family, indicate that Family .
 Note: Only those spec values that are defined for the part's family (as well as any spec values that are not defined for any family) will appear in Choose lists in the Part Catalogue and Parts forms.
