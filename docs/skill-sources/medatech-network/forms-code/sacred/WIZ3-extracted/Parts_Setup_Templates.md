# Defining Part Numeration Templates

 

Numeration templates define the method by which the system automatically numbers new parts. You can record as many templates as you want, each representing a different family or category of parts. 
 
## To define a numeration template:

 

 1 .  Enter the Part Number Templates form. 
 

 2 .  In the Template column, record the code that will identify the template. 
 

 3 .  Record a brief Description of the template (e.g., "Summer Chairs"). 
 

 4 .  If you want all numbers assigned to this template to begin or end with a set string, record a Prefix or Suffix . 
 

 5 .  If you want all numbers assigned to this template to have the same width, record in the Place Holders column the number of digits to be used (leading zeros are inserted when necessary). Explanation. 
 

 6 .  If you want to start with a specific number (other than 1 ), record the number preceding it in the Last Value column of the template. The next part created with this template will receive the next number in sequence.
 Note: If parts have already been created on the basis of this template, the column displays the last number assigned.
