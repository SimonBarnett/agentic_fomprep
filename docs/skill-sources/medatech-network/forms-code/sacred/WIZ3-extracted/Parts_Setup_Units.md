# Defining Units and Conversions

 
## To define part units:

 

 1 .  Enter the Part Units form. 
 

 2 .  Some units are predefined. Record any additional units and a description for each. 
 
## To set up unit conversions:

 

 1 .  Enter the Unit Conversions form. 
 

 2 .  Some unit conversions are predefined. For each additional unit conversion, fill in all the columns.
