# Setting Whether Revisions Are Copied

 

When you copy a part (using the Copy Parts program), the system is initially set so that part revisions and BOM revisions are copied as well. However, you can change this default. 
 
## To prevent the copying of part and BOM revisions:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the CopyPartRev constant and change its value to 0 .
