# The Part Specs Work Area

 

You can use the Part Specs Work Area to create groups of related parts on the basis of part specifications. 
 

The first step in this process is to define the part specifications, and determine which spec values to use as elements in the number or description of the new parts. Example. 
 

The second step is to load the work area, which creates draft parts from all possible combinations of the designated part specifications. You can then fine-tune the combinations from which you want to create parts and eliminate unwanted combinations. 
 

Finally, you run the program that creates new parts from the work area records. 
 
## What do you want to do?

 

 Define part specifications 
 

 Load the work area 
 

 Create parts from work area records
