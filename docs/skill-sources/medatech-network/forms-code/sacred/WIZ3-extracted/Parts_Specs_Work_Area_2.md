# Defining Part Specifications

 

Specifications should be defined in order of the most distinguishing characteristics, so that each new specification creates sub-categories of the previous one. For example, Spec 1 should be the part Model , Spec 2 the Year of its manufacture, and Spec 3 the Color . Example. 
 
## To define part specifications:

 

 1 .  Enter the Definition of Part Specs form. 
 

 2 .  For each specification, define a Type and Spec Description . 
 

 3 .  Enter the Permitted Spec Values sub-level form. Record all possible values in the Specification column, and designate a part numeration code for each one in the Code in New Part No. column. Return to the upper-level form. 
 

 4 .  To include the spec as a part numeration element , flag the Part Number Element column. 
 

 5 .  To include the spec as a part description element , flag the Part Desc. Element column, and indicate the desired Separator between this element and the next one (e.g., comma, hyphen, underline). 
 

 6 .  To change the order in which specs combine to create a new part number (for example, if you want the year to precede the model code, even though the model is Spec 1), assign each spec the desired position in the Part Number Sequence column. 
 

 7 .  To change the order in which specs combine to create a new part description, assign each spec the desired position in the Part Desc. Sequence column.
