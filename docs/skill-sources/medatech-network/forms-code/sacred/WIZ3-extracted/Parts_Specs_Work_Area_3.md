# To load part specifications into the work area:

 

 1 .  Run the Load Work Area by Part Specs program. 
 

 2 .  Select the specifications you want to include in the part's catalogue number and/or description.
 Note: Some specifications may have been defined for classification purposes only, and do not need to be included in the part number or description. 
 

 3 .  By default, all existing values are loaded into the work area. To restrict a specification to certain values, do one of the following: 
 

 ·      To select some of the permitted values, press F6 twice to open the form listing all permitted values. Move to each unwanted value and clear it by pressing F7 . When all the unwanted values are cleared, close the form to load the remaining values. 
 

 ·      To select a range of numerical values, use an operator and specify the operand. 
 

 ·      To select a single spec value, click the button to the right of the value column. Select the desired value from the Choose list. 
 

 4 .  Do one of the following: 
 

 ·      Specify the Type , Family , Unit to be assigned to the new part. These will all appear in the work area, but may be revised there. 
 

 ·      Specify a Base Product to assign to the new part. The base product's Type , Family , Unit and Routing will appear automatically in the work area, though they all may be revised. 
 

 5 .  Click OK . When the program finishes running, it will display a message telling you the number of draft parts that were loaded into the Part Specs Work Area .
