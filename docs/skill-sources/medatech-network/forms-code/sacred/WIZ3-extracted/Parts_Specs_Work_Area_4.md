# To create parts:

 

 1 .  Enter the Part Specs Work Area form and view the draft parts. Each possible combination of the selected specifications appears on a separate line. Revise them if necessary, and delete any unwanted lines (press Ctrl+ Del ). 
 

 2 .  If none of the specifications were designated as catalogue number or description elements, fill in the Part Number and Part Description of each draft part manually. 
 

 3 .  Record additional attributes (e.g., Accounting Family , Standard Cost, Base List Price ) for the draft parts, as desired. 
 

 4 .  Run the Create Parts from Work Area program. Any attributes added to the new parts will appear automatically in the relevant form (e.g., Part Catalogue , Parts , Financial Parameters for Parts ).
 Note: If any problems are encountered, an error report will appear. 
 
## To clear the work area:

 

 ·        Run the Clear Specs Work Area program.
