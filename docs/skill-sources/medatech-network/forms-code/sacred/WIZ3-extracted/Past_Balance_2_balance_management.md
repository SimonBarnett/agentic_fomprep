# How Priority Manages Inventory Balances

 

In Priority , inventory balances are maintained by: 
 

 ·      Part catalogue number 
 

 ·      Warehouse and bin 
 

 ·      Lot or work order number 
 

 ·      The status of the part 
 

 ·      The operation performed on the part. 
 

Thus, a given part can have several inventory balances. For example, if a part is stored in two warehouses, two inventory balances will be maintained. If the part is assigned different statuses, inventory balances will be maintained for each status. Example.
