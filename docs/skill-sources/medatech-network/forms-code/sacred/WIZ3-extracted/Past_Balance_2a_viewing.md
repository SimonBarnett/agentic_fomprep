# To view inventory balances:

 

 ·        Enter the Current Warehouse Inventory form or the Warehouse Balances form (a sub-level of Warehouses ), OR 
 

 ·        Enter the Inventory for Part form, a sub-level of Part Catalogue , OR 
 

 ·        Run the reports in the Current Inventory menu, OR 
 

 ·        Run reports of inventory as of a given date, in the Inventory Reports menu. 
 
## To view inventory balances in all companies (in a multi-company environment):

 

 ·        Enter the Multi-Company Inventory for Part form, a sub-level form of the Part Catalogue form, OR 
 

 ·        Run the reports from the Multi-Company Reports menu.
