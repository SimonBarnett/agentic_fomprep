# Current Inventory vs. Inventory as of Date

 

 Priority provides two sources of information about inventory balances: 
 

 ·        Current inventory: calculated online. Each inventory transaction recorded in the system immediately affects current inventory balances. Reports of current inventory display these online balances. 
 

Floor inventory balances are only updated online when the production constant OnlineBF is set to 1 , and even then are not considered definitive until the full Backflush program is run. 
 

 ·        Inventory as of date: Several reports display inventory balances for a specific date in the past. Unlike current inventory reports, these reports recalculate inventory balances and take into account the plant floor inventory for the given date as well.
