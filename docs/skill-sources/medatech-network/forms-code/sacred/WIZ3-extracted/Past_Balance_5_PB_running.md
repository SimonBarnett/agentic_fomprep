# Calculating Past Balances

 

Past balances are calculated by adding to or subtracting from the previous past balance of each part, based on the inventory transactions that have been recorded since that date. 
 

Once past balances have been calculated, you cannot revise inventory transactions recorded prior to that date, unless you delete the past balances. You should therefore check the existing inventory balances and resolve any inaccuracies (e.g., negative inventory, missing issues) before you calculate new past balances. 
 

Similarly, you cannot calculate past balances for a given date if past balances already exist for a later date. Make sure that there are no past balances that conflict with the one you are calculating.
