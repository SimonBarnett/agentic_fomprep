# Checking Inventory Before Calculating Past Balances

 

Before calculating past balances, you need to pay special attention to negative inventory, pending inventory documents and missing issues (in calculations of floor inventory). 
 
## Negative Inventory Balances

 

Before calculating past balances, you should check for and correct any negative quantities of inventory. These usually result from incorrect documentation of inventory transactions. 
 
## To find negative inventory balances:

 

 ·        Run the Inv. per Warehouse as of Date report for the date on which you intend to calculate past balances. 
 
## To handle negative balances:

 

 1 .  Run the Inventory Journal for Warehouse report to view inventory transactions per warehouse and part over a given period. Try to track down the transaction that was improperly documented. 
 

 2 .  Do one of the following: 
 

 ·      If the document in question is not final, simply make any needed corrections (e.g., to quantities). 
 

 ·      If the document has been finalized, you can usually reopen it by selecting Reopen Document from the list of Direct Activation s ; then correct and finalize it again. If you cannot reopen it (e.g., an invoice has already been recorded for it), create a reversing document to correct the error. 
 
## Tip:

 

For assistance with correcting negative balances in floor inventory, run the Backflush Wizard .
