# Deleting Past Balances (and Costing Results)

 

When cost analysis is run for a given past balance date, costing results must be deleted before past balances can be deleted for that date. 
 

 Warning: Deleting past balances and costing results can affect inventory valuations! Consult with implementation or support personnel before making any such deletions. 
 
## To delete costing results:

 

 1 .  Run the Delete Costing Results program. 
 

 2 .  Specify as input the date of the earliest past balance you want to delete. All costing results calculated on or after that date will be deleted. 
 
## To delete past balances:

 

 ·        Run the Delete Last Past Balance program once for each past balance you want to delete (each time you run the program it deletes the latest existing past balance).
