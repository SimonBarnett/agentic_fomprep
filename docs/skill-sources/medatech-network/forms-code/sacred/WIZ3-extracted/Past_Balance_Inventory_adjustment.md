# Past_Balance_Inventory_adjustment

- **Source:** `Past_Balance_Inventory_adjustment.htm`

Past Balances - Inventory Balances.3 
 
 
- 
 
 
 

 To adjust the inventory balance of a part in a specific warehouse and bin: 
 

 1 .  Enter the Part Catalogue form and retrieve the desired part. 
 

 2 .  Select Adjust Inventory in Warehouse from the list of Direct Activation s , specifying the warehouse (and bin) in which to update the balance, and the quantity with which to replace the current balance. The program automatically opens and approves an inventory count document with the updated balance. 
 
## Note:

 

The program only adjusts the quantity of parts of "Goods" status that have no work order or operation number.
