# Pending Inventory Documents

 

 ·        Check all pending documents, i.e., all inventory documents that have not been finalized, including invoices that double as inventory documents (i.e., sales invoices and over-the-counter invoices), and finalize them if possible. 
 
## Tip: 

 

To find pending documents, run the Pending Documents report for the period between the last past balance date and the date on which you wish to calculate new past balances. 
 
## Plant Floor Inventory (Missing Issues)

 

 ·        When calculating past balances, the system treats missing issues as negative inventory on the plant floor. It is therefore recommended that you make the necessary corrections beforehand. 
 
## To deal with missing issues:

 

 1 .  Run the Backflush program to trace missing issues. 
 

 2 .  Enter the Missing Issues form to view the missing issues. 
 

 3 .  Identify the source of the problem (e.g., inaccurate issues of floor stock), and correct the relevant documents.
 Note: If the source of the problem cannot be found or cannot be resolved in the original document, you can update the floor inventory by counting inventory in the floor warehouse. 
 

 4 .  Rerun the Backflush program to ensure that there are no more missing issues.
