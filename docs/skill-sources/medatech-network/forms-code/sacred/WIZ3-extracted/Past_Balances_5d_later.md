# Checking for Later Past Balances

 

You can only calculate past balances for a given date if there are no existing past balances for later dates. If later past balances have already been calculated, you must first delete them. 
 
## To check for later past balances (and costing runs):

 

 1 .  Enter the Dates of Calculated Balances form. 
 

 2 .  Check the Date column for past balances calculated after the desired date. 
 

 3 .  For each later past balance calculation, check the Costing Performed column. A check mark indicates that costing was run for that past balance date. If it appears, the costing results will have to be deleted as well. 
 
## Notes:

 

 ·        Click to delete later past balances and costing results. 
 

 ·        Click to calculate new past balances .
