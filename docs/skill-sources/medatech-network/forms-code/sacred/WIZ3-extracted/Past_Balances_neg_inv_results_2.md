## To correct inventory transaction documents:

 

 1 .  Run the Inventory Journal for Warehouse report to view inventory transactions per warehouse and part over a given period. Try to identify the transaction that was improperly documented. 
 

 2 .  Do one of the following: 
 

 ·      If the document in question is not final, simply make any needed corrections (e.g., to quantities). 
 

 ·      If the document has been finalized, you can usually reopen it by selecting Reopen Document from the list of Direct Activation s ; then correct and finalize again. If you cannot reopen it (e.g., an invoice has already been recorded for it), create a reversing document to correct the error. 
 
## To deal with missing issues:

 

 1 .  Run the Backflush program to trace missing issues. 
 

 2 .  Enter the Missing Issues form to view the missing issues. 
 

 3 .  Identify the source of the problem (e.g., inaccurate issues of floor stock), and correct the relevant documents.
 Note: If the source of the problem cannot be found or cannot be resolved in the original document, you can update the floor inventory by counting inventory in the floor warehouse. 
 

 4 .  Rerun the Backflush program to ensure that there are no more missing issues. 
 
## Notes:

 

 ·        For assistance with correcting missing issues and negative balances in floor inventory, run the Backflush Wizard . 
 

 ·        Click to recalculate past balances once inventory transactions have been adjusted.
