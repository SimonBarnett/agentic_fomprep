# Setting Up Business Processes (BPM) for Human Resources

 

You set up business processes by defining statuses in a BPM flow chart. 
 

There are separate flow charts for jobs, for candidates, for job applicants, and for employees. Details. 
 

In each flow chart, there are several statuses predefined in the system, to which you can add as many statuses as you like. You can define paths between these statuses , create workflow rules and set status properties . 
 
## To use the flow charts:

 

 ·        For jobs, run the BPM Flow Chart-Jobs program. 
 

 ·        For job candidates, run the BPM Flow Chart-Candidates program. 
 

 ·        For applicants to a specific job, run the BPM Flow Chart-Job Applicants program. 
 

 ·        For employees, run the BPM Flow Chart-Employees program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Jobs Statuses for Candidates Statuses for Job Applicants , and Statuses for Employees forms. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
