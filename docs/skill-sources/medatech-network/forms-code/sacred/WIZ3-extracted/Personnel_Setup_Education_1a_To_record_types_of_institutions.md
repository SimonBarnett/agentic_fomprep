# Before you Begin

 

Define a list of institution types and department codes that you will use to define specific institutions. 
 
## To record types of institutions:

 

 ·        Enter the Types of Learning Institutions form. Record a code and description for each type of institution (e.g., university, training college). 
 
## To record departments or faculties:

 

 ·        Enter the Departments and Faculties form. Record a code and description for each department or faculty.
