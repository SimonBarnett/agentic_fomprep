# To record institutions:

 

 1 .  Enter the Learning Institutions form and record a code and description for each educational institution. 
 

 2 .  Choose the relevant Type (Code) for each one. 
 

 3 .  Record any other desired information. 
 
## To list departments at each institution:

 

 ·        Enter the Departments and Faculties sub-level form. Choose the department(s) and record any other desired information. 
 
## To list possible degrees or certificates held by employees or job candidates:

 

 ·        Enter the Degrees/Certificates form. Record a code and description for each degree or certificate (e.g., B.A., M.Sc., Teaching Certificate).
