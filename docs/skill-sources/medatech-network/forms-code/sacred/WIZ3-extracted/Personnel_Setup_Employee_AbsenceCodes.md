# Setting Up Reasons for Absence

 

Possible reasons for employee absence are used in reporting absences, either by employees themselves or by the human resources manager. Several reasons are predefined in the system: Illness, Vacation and Other . You can define any additional ones you need. 
 
## To define reasons for absence:

 

 ·        Enter the Reasons for Absence form. Record a code and description for each possible reason for employee absence.
