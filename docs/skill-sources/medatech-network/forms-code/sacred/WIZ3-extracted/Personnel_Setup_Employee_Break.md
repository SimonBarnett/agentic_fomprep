# Setting Up Reasons for Leaves of Absence

 

Possible reasons for employee leave are used in reporting extended leaves of absence (e.g., maternity leave). 
 
## To define reasons for a leave of absence:

 

 ·        Enter the Reasons for Leave of Absence form. Record a code and description for each possible reason for an employee leave of absence.
