# Setting Up Reasons for Terminating Contracts

 

You need to define possible reasons for ending work contracts with employees (e.g., unsatisfactory work, downsizing, personal problems). 
 
## To record a list of reasons for ending contracts:

 

 ·        Enter the Reasons for Ending Contract form, and list the possible reasons.
