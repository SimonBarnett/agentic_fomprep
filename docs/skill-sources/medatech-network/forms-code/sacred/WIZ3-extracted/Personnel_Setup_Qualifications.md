# Defining Qualifications

 

You can create a list of qualifications and define the possible values that each qualification can receive. Afterwards you can assign to each job the qualifications it requires. In a later stage, you can specify each employee's or candidate's qualifications, so that the system can propose applicants for a job opening by matching their qualifications with those required for the job. 
 
## To define qualifications:

 

 1 .  Enter the Possible Values for Qualificatns form and record all of the possible values that could be assigned to qualifications. 
 

 2 .  Enter the Qualifications form and record a code and description for each qualification. 
 

 3 .  For each qualification, enter the Possible Values for Qualificat'n sub-level form and select the relevant values.
