# Setting Up Job Interviews

 

Define possible types of interviews intended for candidates and employees. Afterwards, you can assign the required interviews to the appropriate positions and jobs, and monitor the interviews conducted with applicants for specific jobs. Furthermore, you can define a list of statuses for interviews. 
 
## To set up job interview types:

 

 ·        Enter the Types of Job Interviews form, and record a code and description for each type of job interview. 
 
## To set up interview statuses:

 

 ·        Enter the Statuses for Interviews form, and record a description of each interview status.
 Tip: When conducting an interview with a job applicant, you can flag a column indicating that the interview was successful. It is therefore not necessary to define a status to that effect; instead, define statuses such as “scheduled”, “completed”, and so forth.
