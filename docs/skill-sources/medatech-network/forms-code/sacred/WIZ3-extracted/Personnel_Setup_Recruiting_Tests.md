# Setting Up Test Types

 

Record a list of various types of tests required of job candidates and employees. Afterwards, you can assign the required tests to the appropriate positions and jobs, and monitor the tests administered to employees and candidates for specific jobs. 
 
## To set up test types:

 

 1 .  Enter the Types of Tests form, and record the name or a description of each type of test. 
 

 2 .  Attach any documents related to the test (e.g., the examination form).
