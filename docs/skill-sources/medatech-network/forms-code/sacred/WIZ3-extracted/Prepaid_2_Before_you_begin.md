# Setting Up Prepaid Expenses and Deferred Income 

 

Before you begin working with prepaid expenses or deferred income, you must define accounts against which the journal entries for the distribution of expenses/income will be recorded. Every GL account for prepaid expenses or deferred income should be assigned a target P&L account, to which amounts will be transferred once their due date arrives. 
 

Furthermore, if you maintain a budget, you can determine whether prepaid expenses/deferred income are to be budgeted in advance or in the fiscal period in which each amount is transferred to its target P&L account.
