# To set up accounts for prepaid expenses and deferred income:

 

 1 .  Enter the Chart of Accounts form and move to Full-Record Display Mode . 
 

 2 .  Open GL accounts for prepaid expenses and deferred income, assigning each an appropriate description (e.g., prepaid rent).
 Note: For further information about setting up accounts, run the Open GL Accounts Wizard . 
 

 3 .  For each new account, click the Add ' l Definitions tab. Flag the Prepaid Exp/Inc Acct column. 
 

 4 .  If the prepaid expenses or deferred income in question are usually transferred to a certain P&L account, specify this account in the Default Target Account column. Whenever you record an invoice (or journal entry) involving this prepaid expense/deferred income account, this target account will be filled in automatically, although it may be revised. 
 
## To determine when prepaid expenses/deferred income are to be budgeted:

 

 1 .  Enter the Financial Constants form, and move to the BudExpensesOnly constant. 
 

 2 .  Revise the value of the constant, if necessary.
