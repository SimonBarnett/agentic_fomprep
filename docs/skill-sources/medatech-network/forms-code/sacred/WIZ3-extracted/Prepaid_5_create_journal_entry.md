# Creating a Journal Entry for Prepaid Expenses or Deferred Income

 

When there is no invoice, you can record prepaid expenses or deferred income directly in the entry journal, using a user-defined entry code. In the entry code, you determine how the due date of the first prepaid item is to be calculated and the number of items in the entry. Use a different entry code for each type of prepaid expense or deferred income. The entry is then itemized accordingly, with a difference of one month between the due dates of successive lines.
