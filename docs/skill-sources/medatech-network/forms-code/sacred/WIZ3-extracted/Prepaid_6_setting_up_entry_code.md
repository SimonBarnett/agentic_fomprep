# To define an entry code for prepaid expenses or deferred income:

 

 1 .  Use the Journal Entry Codes form and its sub-level, Entry Patterns , to define a new entry code.
 Tip: For details on creating new entry codes, run the Set Up Entry Codes Wizard . 
 

 2 .  On the line for the prepaid expense/deferred income account, move to the No. of Prepayments column. Fill in the number of entry items to be recorded for the prepaid expense or deferred income. Example . 
 

 3 .  To set the due date of the first entry item, which ultimately determines when each amount is transferred to the P&L account, do one of the following: 
 

 ·              If the transfer is to begin immediately, at the end of the month in which the entry's transaction date falls, flag the End of Month-DueDate column. 
 

 ·              To postpone the first due date for one or more months ( Example ), designate the number of months in the "+Months (DueDate)" column AND check the End of Month-DueDate column. 
 
## Notes: 

 

 ·        If you wish due dates to fall on a day other than the end of the month, leave the End of Month-DueDate column blank. The first due date will then be identical to the reference date of the journal entry. You can also use the "+Days (DueDate)" column to postpone the first due date for a given number of days.
