# Revising the Target P&L Account

 

 Priority allows you to revise the target P&L account even after you have posted the initial entry for prepaid expenses/deferred income. 
 
## To revise the P&L account:

 

 1 .  Enter the Entry Item Revisions form. 
 

 2 .  Retrieve by the prepaid expenses/deferred income account and/or any other relevant column (e.g., Transact Date , Entry Number ). 
 

 3 .  In the Target Acct-Prepaid column, specify the correct P&L account.
