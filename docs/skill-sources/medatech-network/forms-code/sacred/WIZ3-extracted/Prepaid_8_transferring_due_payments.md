# Transferring the Prepaid/Deferred Amounts to Target P&L Accounts

 

When a prepaid or deferred amount reaches its due date, a journal entry has to be recorded for its transfer from the prepaid expense or deferred income account to its target P&L account. Example. Priority offers a program that automatically records journal entries for all prepaid/deferred amounts that have come due. 
 
## To check which deferred amounts have not yet been transferred to their target P&L accounts:

 

 ·        Run the PrepdExp/DeferredInc to Transfer report. 
 
## To transfer amounts that have come due:

 

 ·        Run the Transfer PrepaidExp/DeferredInc program. You can run it for all prepaid expense and deferred income accounts, or for selected accounts only. 
 

 Tip: It is recommended to have the system manager run this program for all accounts every night, using the Tabula Task Scheduler .
