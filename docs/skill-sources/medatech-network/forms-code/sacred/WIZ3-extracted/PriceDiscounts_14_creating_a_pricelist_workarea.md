# Using a Work Area to Create a Price List 

 

Using Priority ' s price list work area, you can create a new list based on an existing one, making certain adjustments, such as recording prices in a different currency or for different minimum quantities. After creating the new list, you can raise or lower the prices of individual parts. One of the advantages of using the work area is that you can view old prices while modifying them to arrive at new prices. 
 
## To create a new price list in the work area, you need to:

 

 1 .  Load the old price list into the work area 
 

 2 .  Make any necessary adjustments in the work area (i.e., updating each part's price, quantity and/or currency, adding new parts) 
 

 3 .  Open a new price list (without prices) 
 

 4 .  Download the updated prices into the new price list.
