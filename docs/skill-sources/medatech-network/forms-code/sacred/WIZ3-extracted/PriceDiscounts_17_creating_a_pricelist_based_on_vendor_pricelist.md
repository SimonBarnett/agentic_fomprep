# Creating a Price List From a Vendor Price List

 

In a buy-resell setting, you can create a customer price list from a vendor price list. Prices taken from the vendor price list can be marked up by a specified percentage or absolute value. The new customer price list can then be assigned to one or more customers, like any other price list. 
 
## Note:

 

Another option is to define a given vendor price list as a price source for customers. When no other part price is available for a given sales document, the system takes the vendor's price and adds a specified markup (provided that the vendor in question is the preferred vendor for that part). Click for more details . 
 
## To create a customer price list based on a vendor price list:

 

 1 .  Enter the Price Lists form. Assign a code, description and currency to the price list. 
 

 2 .  Run the Revise Cust PList by Vend PList program. 
 
## To view the new price list:

 

 1 .  Return to the line for the new price list in the Price Lists form. 
 

 2 .  To view the parts and their prices, enter the Part Prices sub-level form.
