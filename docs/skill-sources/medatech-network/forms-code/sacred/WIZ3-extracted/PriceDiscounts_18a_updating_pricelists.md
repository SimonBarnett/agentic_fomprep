# Updating an Existing Price List

 

You can update a price list by adding parts or raising/lowering prices. If you buy goods from the vendor and resell them to customers, you can update the relevant customer price list in keeping with changes in the vendor price list. If you work with base products , you can automatically update all its linked parts in a given price list. 
 
## What do you want to do?

 

 Add parts to an existing price list 
 

 Raise/lower prices in a price list 
 

 Update a customer price list on the basis of a vendor price list 
 

 Update prices according to a base product
