# Opening a New Version of a Price List

 

Different versions of the same price list are distinguished by their list dates. The valid version is flagged as such, and its prices appear in the price list. The other versions can be accessed through a sub-level form. 
 

An easy way to create a new version of a price list is to copy an older version and update part prices. 
 
## To prepare a copy of a price list:

 

 ·        Run the Copy Price List program. Choose the same price list in both the Source Price List and the To Price List columns. 
 

 To raise (or lower) prices automatically: 
 

 ·        Run the Raise/Lower Prices program. Choose the list date of the new version of the price list.
 Note: Click to update prices according to a base product. 
 

 To change prices manually: 
 

 1 .  Enter the Price Lists form and move to the price list in question. 
 

 2 .  Enter the Price List Dates sub-level form and move to the new version you have created. 
 

 3 .  Enter the Part Prices sub-level form. Change prices as necessary.
