# Updating a Customer Price List Based on Changed Vendor Prices

 

If you purchase goods from a vendor and resell them to customers, and the vendor raises or lowers the prices of several items, you can easily update the customer price list that includes these items. 
 
## To update the customer price list based on the vendor's price list:

 

 ·        Run the Revise Cust PList by Vend PList program.
