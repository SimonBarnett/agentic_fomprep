# Deleting a Price List

 
## To delete the contents of a price list for a particular list date:

 

 1 .  Enter the Price Lists form and retrieve the desired price list. 
 

 2 .  Enter the Price List Dates sub-level form and move to the date of the desired version. 
 

 3 .  Select Delete Price List For Date from the list of Direct Activations. 
 
## Notes: 

 

 ·      Alternatively, run the Delete Price List For Date program. 
 

 ·      To delete a valid price list, you must first put a different version into effect. Click to do so . 
 
## To delete all versions (list dates) of a price list:

 

 ·        Run the Delete Price List program.
