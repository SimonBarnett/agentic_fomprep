# Defining Discount Codes

 

Each discount, regardless of type (part/family/overall), is defined by a unique code that represents the discount percentage and the period in which the discount is valid. 
 

There are two ways to define discount codes: 
 

 ·        Define them manually, and then assign them to a variety of customers. 
 

 ·        Define a discount specifically for a given customer, and the discount code will be created automatically. 
 
## To define a discount code manually:

 

 1 .  Enter the Discount Codes form. 
 

 2 .  Record a code and a description. 
 

 3 .  Specify the period in which the discount is valid. 
 

 4 .  Specify the percentage of the discount. 
 
## To create discount codes automatically:

 

 ·        Record the discount directly for the customer.
