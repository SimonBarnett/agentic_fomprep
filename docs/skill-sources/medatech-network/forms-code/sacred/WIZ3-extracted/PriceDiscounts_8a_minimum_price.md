# Defining a Minimum Part Price 

 

Defining a minimum part price allows you to control the sale price that can be recorded for that part in sales documents (e.g., price quotes, orders). Users will receive a warning message if they record a part price that deviates from the defined minimum. 
 
## Tip:

 

Use the Privilege Explorer to change the warning to an error message. 
 
## To define a minimum part price:

 

 1 .  Enter the Part Catalogue and retrieve the desired part. 
 

 2 .  Click the Prices & Costs tab and record the Minimum Price .
