# Working with Price Lists

 

Price lists are the main tool for determining customer prices in Priority . When part prices are automatically recorded by the system (e.g., in sales orders), they are usually taken from the valid price list in which they appear. 
 

The source of each automatically recorded price appears in the relevant form (e.g., Part Price Options ). If you want to distinguish between prices that are taken from different price lists, you can assign price sources to individual price lists, either manually or automatically. The designated price source will then appear automatically when prices are taken from the price list in question. If a given price list is not assigned a price source, the price source will simply appear as "Price List". 
 

There are two predefined price lists: 
 

 ·        The Base price list, applied automatically when no other price source is available; 
 

 ·        The Cost price list, which automatically includes every part with a recorded cost; this can be used to prepare internal billing documents for the shipment of goods between departments or branches. 
 

In addition to price lists predefined in the system, you can create individual price lists for a single customer (including the general representative ) or group of customers. You can also create unlimited versions of a given price list, each with a different list date; however, only one version can be valid at a time. The same part can appear in more than one valid price list, when priced using different units of measure or in different currencies. Example. 
 

You can also flag a customer price list as a special price list (e.g., for end-of-season sales). 
 
## Note: 

 

You can assign several different price lists to the same customer. If a given part appears in more than one price list, the system will take the price from the one with the highest priority. If priorities have not been assigned to customer price lists, the price will be taken from the most recent one.
