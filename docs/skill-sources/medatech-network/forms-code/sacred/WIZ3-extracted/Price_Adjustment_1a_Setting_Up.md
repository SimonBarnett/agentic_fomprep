# Setting Up for Price Adjustments

 

Before price adjustments can be made, several setups must be defined to suit your company's standard practices. These setups determine the default date for which adjustments will be made (the linkage date), the exchange rate date to be used when the payment currency differs from the invoice currency, whether linked amounts are included in part prices or appear on a separate line (linkage options), and whether to lower part prices in invoices when there is a drop in the exchange rate or index (negative adjustment). 
 

In addition, if you often link prices to the same currency basket, you can define a currency to represent that basket. You can then revise the basket details in specific order documents. 
 
## Note:

 

These setups have no effect on price adjustments to service contract payments.
