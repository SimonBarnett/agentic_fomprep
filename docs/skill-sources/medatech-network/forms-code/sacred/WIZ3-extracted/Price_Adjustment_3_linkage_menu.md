Price Adjustment Wizard - Linkage Menu 
 
 
- 
 
 
 
# What Do You Want To Do?

 

 Record a dual-currency order 
 

 Link an order to a foreign currency or index 
 

 Link an order to a currency basket 
 

 Link a sales order (or blanket sales order) to a price list 
 

 Link a sales order to prices in effect on the invoice date 
 

 View the results of price adjustment 
 
## Notes:

 

 ·        For help in recording orders, run the Sales Order Wizard or the Purchase Order Wizard . 
 

 ·        To view open sales orders with prices adjusted to the current date, run the Adjust Prices in Orders program and then the Adjusted Order Prices report. The adjusted balance in the report displays the total price that would be charged for the balance of the order if the invoice/shipment were recorded today. 
 

 ·        To view the same information for open purchase orders, run the Adjust Prices in Purchase Orders program and then the Adjusted Purchase Orders report. 
 

 ·        Click to return to the main screen .
