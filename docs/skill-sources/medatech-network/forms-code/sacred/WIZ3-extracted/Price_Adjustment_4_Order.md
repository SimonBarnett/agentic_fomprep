# Linking an Order to a Single Foreign Currency or Index

 

You can link the following to a single foreign currency or price index: 
 

 ·      an entire sales order, purchase order, blanket sales order or blanket purchase order 
 

 ·      individual sales order items. 
 

The order (or order items) in question must be recorded in the local currency. 
 
## What do you want to do?

 

 Link an entire order to a currency/index 
 

 Link individual sales order items to a currency/index 
 
## Note:

 

 Click to return to the linkage menu.
