# To link a specific sales order item to a single currency or price index:

 

 1 .  Enter the Sales Orders form to record the order. 
 

 2 .  To change the default linkage date , click the Payment Info tab and revise the value in the Price Linkage column. 
 

 3 .  To change the default linkage option , record the desired value in the Link Option column. 
 

 4 .  Enter the Order Items sub-level form to record the ordered parts. 
 

 5 .  In any line for which you want to link the part price, move to the Linked Currency column and select the currency or the price index in question. 
 

 6 .  The current exchange rate for that currency/index appears in the Base Rate column. Revise as necessary.
