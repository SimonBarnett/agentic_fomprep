# Linking an Order to a Currency Basket

 

You can link the following to a currency basket: 
 

 ·        an entire sales order, purchase order or blanket sales order 
 

 ·        individual sales order items. 
 

The order (or order items) in question must be recorded in the local currency. 
 
## Tip:

 

Click to create a new currency representing this basket (if you plan to use it often). 
 
## What do you want to do?

 

 Link an entire order to a currency basket 
 

 Link individual sales order items to a currency basket 
 
## Note:

 

 Click to return to the linkage menu.
