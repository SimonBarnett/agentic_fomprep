# To link a specific sales order item to a currency basket:

 

 1 .  Enter the Sales Orders form to record the order. 
 

 2 .  To change the default linkage date , click the Payment Info tab and revise the value in the Price Linkage column. 
 

 3 .  To change the default linkage option , record the desired value in the Link Option column. 
 

 4 .  Enter the Order Items sub-level form to record the ordered parts. 
 

 5 .  In any line for which you want to link the part price, move to the Linked Currency column and select the currency you've defined for the basket.
 Note : If no such currency has been defined, you can manually define the make up of the basket in the Linkage Details sub-level form. 
 

 6 .  Enter the next sub-level form, Linkage Details , to view the make up of the basket for this order item. The Base Rate displays the exchange rate in effect for each currency on the order date. Revise this, or any other columns, as necessary.
 Tip: To automatically revise the Base Rate to the exchange rate in effect on a desired date, change the Base Date to that date. 
 

 7 .  Do one of the following: 
 

 ·      If there is an agreement to stop linkage of this currency a certain number of months prior to an order item's delivery or due date, indicate the number of months in the Latest Linkage-mnths column. Explanation. 
 

 ·      To use the Exchange Rate Date defined for this currency in the upper-level form, flag the Linkage from Header column. The Latest Linkage-mnths column will be set automatically to 0 and will not affect linkage.
