# Linking a Service Contract

 

Service contracts are often paid in installments. Priority allows you to link contracts to a price index, foreign currency or currency basket, so that each payment amount is adjusted to the exchange rate or index in effect on the payment date. 
 
## What do you want to do?

 

 Link a contract to the price index 
 

 Link a contract to a foreign currency 
 

 Link a contract to a currency basket 
 

 View adjustments to contract payments
