# Viewing Adjustments to Contract Payments

 

When payment installments are calculated automatically for the contract, you can view the results of price adjustment in the Payment Installments form, sub-level of the Service Contracts form. The payment amount will be adjusted to the specified index, currency or currency basket, using the rate in effect on the payment date. 
 
## Note:

 

Use the Linkage Calculations sub-level form to view how linkage was calculated for a particular contract payment.
