# Allowing Negative Price Adjustment in Invoices

 

The LinkNegative constant determines whether the system will by default lower local-currency prices in both customer invoices and purchase invoices when there is a drop in the exchange rate of the foreign currency or index to which the original order is linked. 
 
## Note:

 

You can change the default for any given sales order or blanket sales order. 
 
## To allow for negative price adjustment:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the LinkNegative constant and change its value to 1 .
