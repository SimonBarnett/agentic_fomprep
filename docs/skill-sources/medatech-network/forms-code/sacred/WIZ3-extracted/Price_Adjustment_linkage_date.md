# Setting Linkage Dates

 

Part prices can be adjusted to the exchange rate/index that is in effect on: 
 

 ·      the order date (relevant only when linking blanket orders) 
 

 ·      the date of shipment/receipt or 
 

 ·      the invoice date. 
 

 Purchasing : The linkage date for purchase invoices is set by a constant, which affects all invoices. 
 

 Sales : The linkage date for customer invoices can be set to affect all invoices or can be defined per customer. In addition, these defaults can be revised later, when recording individual sales orders (or blanket sales orders). 
 
## To set the default linkage date for all purchase invoices:

 

 1 .  Enter the Financial Constants form and go to the PurchLinkDate constant. 
 

 2 .  Set the value of the constant as required. 
 
## To set the default linkage date for all customer invoices:

 

 ·        In the same form, go to the LinkDate constant and set the value of the constant as required. 
 
## To set a different linkage date for a particular customer:

 

 1 .  Enter the Financ. Parameters for Customers form and retrieve the desired customer. 
 

 2 .  Click on the Invoices tab and select the appropriate option in the Linkage Date column.
