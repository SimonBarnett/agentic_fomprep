# Defining Linkage Options

 

You need to determine whether adjustments are made directly to each part price or appear as a lump sum on a separate line. 
 

 Purchasing : The linkage option for purchase invoices is set by a constant, which affects all invoices. 
 

 Sales : The linkage option for customer invoices can be set to affect all invoices or can be defined per customer. In addition, these defaults can be revised later, when recording individual sales orders. 
 
## To set the default linkage option for all purchase invoices and customer invoices:

 

 1 .  Enter the Financial Constants form and go to the LinkOptions constant. 
 

 2 .  Set the value of the constant as required. 
 
## To set a different linkage option for a particular customer:

 

 1 .  Enter the Financ. Parameters for Customers form and retrieve the desired customer. 
 

 2 .  Click on the Invoices tab and select the appropriate value in the Linkage Options column.
