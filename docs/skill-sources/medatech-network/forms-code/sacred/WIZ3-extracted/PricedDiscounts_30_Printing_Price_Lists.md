# Viewing and Printing Price Lists

 

 Priority offers three formats for viewing and printing price lists: sorted by part number, sorted by part description or including pictures. 
 
## To print a price list:

 

 ·        Run the Print Price List report. Select the desired format in the Print/Send Options dialog box.
Dual-currency users: To print in English when working in another language, run the Print Price List (Lang 2) report. 
 
## Note:

 

To print a partial price list (e.g., for all parts in a given family), use the following reports: 
 

 ·        Price List-Sorted by Part Number 
 

 ·        Price List-Sorted by Part Desc. 
 

 ·        Price List With Pictures
