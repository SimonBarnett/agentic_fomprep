# To view current prices per base product:

 

 1 .  Enter the Price Lists form and move to the desired price list. 
 

 2 .  Flag the Base Product Only column. 
 

 3 .  Enter the Part Prices sub-level form. All parts that are linked to a base product (and share the same price) are represented by a single line.
