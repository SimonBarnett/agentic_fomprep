# Tools for Working with Price Lists

 

 Priority provides you with various tools for creating new price lists and maintaining existing ones. Each price list can be assigned to one or more customers. 
 
## What do you want to do?

 

 Set up price sources for individual price lists 
 

 Set up pricing for parts that are linked to a base product 
 

 Create a base price list 
 

 Create a new price list 
 

 Update an existing price list 
 

 Assign a price list to a customer 
 

 Maintain versions of a price list 
 

 Create a special price list 
 

 Delete a price list
