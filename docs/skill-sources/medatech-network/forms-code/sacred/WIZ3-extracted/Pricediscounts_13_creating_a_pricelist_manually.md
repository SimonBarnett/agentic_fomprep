# Creating a Price List Manually

 

 1 .  Enter the Price Lists form and assign a code, description and currency to the price list. 
 

 2 .  If this is a special price list , flag the Special Part Prices column. 
 

 3 .  Choose the Price Source that will appear throughout the system when prices are taken from this price list. If no price source is assigned, the price source will appear in the relevant forms as "Price List".
 Note: If the SPLAutoPrSrc constant is set as 1 , this column is filled in automatically. 
 

 4 .  Enter the Part Prices sub-level form. 
 

 5 .  Designate the Part Number and the minimum Quantity for which the price is valid. 
 

 6 .  The part's buy/sell unit appears automatically in the Unit column. If the part is purchased in a different unit, change the unit.
 Note: Make sure a conversion ratio between the buy/sell unit and the unit you have recorded has been defined in the Unit Conversions form. 
 

 7 .  Specify the Price of the part and the Currency to which this price refers. 
 

 8 .  Attach a Picture of the part if desired. 
 
## Tips:

 

 ·        If most parts in the list share a common string in their part numbers, run the Prepare Price Lists program to add a batch of parts to the list simultaneously. Then revise the quantity and/or unit, as necessary, and record part prices. 
 

 ·        To record different prices for different quantities of the same part, record each quantity on a separate line, indicating the correct minimum quantity and price. Example.
