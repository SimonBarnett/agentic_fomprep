# To create a price list in the work area:

 

 1 .  Run the Prepare Work Area program, specifying the old price list.
 Note: If the work area is not empty, run the Clear Work Area program. 
 

 2 .  Enter the Work Area form. The parts in the old price list appear. Where necessary, change quantities, prices and currencies, or add new parts to the list. 
 Note: If you load a price list for base products, the new price list will nevertheless assign prices to all individual parts linked to each base product, even if they are hidden in the existing price list. 
 

 3 .  Enter the Price Lists form. Create a new price list by specifying a code, description and currency. When you are done, leave the line. 
 

 4 .  Run the Create New Price List program to download the revised data into the new price list. 
 
## To view the new price list:

 

 1 .  Return to the line for the new price list in the Price Lists form. 
 

 2 .  To view parts and prices, enter the Part Prices sub-level form.
