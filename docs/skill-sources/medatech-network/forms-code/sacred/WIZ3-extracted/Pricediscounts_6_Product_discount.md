# Assigning a Part Discount to Customers

 

You can manually assign a defined discount code to a single customer for a given part, or you can run a program that assigns the same code to several customers and parts in batch. You can also assign a unique discount to a specific customer, for which the system will create a new code automatically. 
 
## To assign a part discount to a single customer and part:

 

 1 .  Enter the Customers form and retrieve the desired customer. 
 

 2 .  Enter the Part Discount sub-level form and specify the desired Part Number . 
 

 3 .  Do one of the following: 
 

 ·      Choose the appropriate discount code. 
 

 ·      Specify the percentage of the offered discount in the Discount% column and indicate the period in which the discount is valid ( Start Date and Expir. Date ). A discount code will be assigned automatically, and the Type of Discount will reflect the percentage offered and the period covered. 
 
## Note:

 

If you record the discount manually, you can reuse the same record to specify a later discount, simply by changing the details of the awarded discount. The Type of Discount will automatically be revised accordingly. 
 
## To assign the same discount to several customers and/or parts:

 

 ·        Run the Assign Discounts to Parts program.
 Tip: To reverse this process (i.e., to remove the same discount from several customers and/or parts), run the Delete Part Discounts program.
