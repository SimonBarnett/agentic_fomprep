# Using a Vendor Price List as a Sales Price Source

 

You can define a given vendor price list as a price source for customers, indicating whether to use the vendor's list prices or discounted prices. When no other part price is available for a given sales document, the system takes the vendor's price and adds a specified markup (provided that the vendor in question is the preferred vendor for that part). In this case, all customer discounts remain in effect. Example. 
 
## Note:

 

Another option is to create a new customer price list from a vendor price list and assign it to a customer. Click for more details . 
 
## To define a vendor price list as a sales price source:

 

 1 .  Enter the Vendor Price Lists form. 
 

 2 .  In the PriceSource Cust column, specify L to use the vendor's list price or D to use the vendor's discounted price. 
 

 3 .  Record the markup amount in the Price Factor column.
