# Defining a Printer in Priority 

 
## Before You Begin

 

 ·        Make sure the printer is properly installed in Windows. 
 
## To define the printer in Priority:

 

 1 .  Enter the Define Printers - Windows form. 
 

 2 .  Record a code for the printer (e.g., the model name). 
 

 3 .  Record a description of the printer. 
 

 4 .  Select Attach Printer from the list of Direct Activations . 
 

 5 .  To double check the results of the program, select Display Printer Attachment from the list of Direct Activations . 
 
## Note:

 

Click to link a report to the printer.
