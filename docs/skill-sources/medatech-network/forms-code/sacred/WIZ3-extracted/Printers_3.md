# Linking a Report to a Printer

 
## Before You Begin

 

 ·        The printer in question must be defined in Priority and linked to its respective Windows printer. Click to define it. 
 
## To link the report to the printer:

 

 1 .  Enter the Define Printers - Windows form and retrieve the printer in question. 
 

 2 .  Enter the Entities for Printer sub-level form. 
 

 3 .  In the Entity Name column, press F6 to open the Entities form. 
 

 4 .  Press F11 to enter Query mode and move to the Title column. 
 

 5 .  Type the title of the report and press Enter . 
 

 Note: If more than one line is retrieved, move to the correct line. You can tell which line is correct by the contents of the Type column, as follows: 
 

 ·              If types P and R appear, move to the line with P . 
 

 ·              If types R and D appear, move to the line with D . 
 

 ·              If all three types appear, move to the line with P . 
 

 6 .  Note the value in the Type column. 
 

 7 .  Press F8 to copy the report back to the Entities for Printer form. 
 

 8 .  In the Type column, record the value you noted in Step 6 . 
 
## Notes:

 

 ·        Click to enable printing without user intervention. 
 

 ·        Click to return to the main screen.
