# To install a logo file:

 

 1 .  Prepare an image file (e.g., jpg ) containing the company logo. Since the company's name and address always appear on printouts, the logo should not include these details.
 Note: The logo size in the document will be identical to its size in the file. 
 

 2 .  Enter the Company Data form. 
 

 3 .  Specify the above path in the HTML Logo column. It is important that you record the path to the logo file via the network. There are several possible methods: 
 

 ·              Record the network path to the file containing the company logo. 
 

 ·              Right-click on the icon, Browse to the desktop, open the Network Neighborhood and select the file from its real location. 
 

 ·              Right-click on the icon, select Import and then select the file from your local drive. A copy of your file will be inserted in the ..\priority\system\mail directory, and its filename will be recorded automatically in this form column.
