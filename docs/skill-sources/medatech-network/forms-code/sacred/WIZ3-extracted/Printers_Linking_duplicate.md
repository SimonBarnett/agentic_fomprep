# To link a report to this printer:

 

 1 .  In the Entity Name column, press F6 to open the Entities form. 
 

 2 .  Press F11 to enter Query mode and move to the Title column. 
 

 3 .  Type the title of the report and press Enter . 
 

 Note: If more than one line is retrieved, move to the correct line. You can tell which line is correct by the contents of the Type column, as follows: 
 

 ·              If types P and R appear, move to the line with P . 
 

 ·              If types R and D appear, move to the line with D . 
 

 ·              If all three types appear, move to the line with P . 
 

 4 .  Note the value in the Type column. 
 

 5 .  Press F8 to copy the report back to the Entities for Printer form. 
 

 6 .  In the Type column, record the value you noted in Step 4 .
