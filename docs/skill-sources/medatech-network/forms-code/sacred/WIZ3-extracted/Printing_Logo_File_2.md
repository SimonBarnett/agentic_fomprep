# Notes:

 

 ·        This logo will appear on all documents printed in HTML format in Priority , as well as those issued through the Internet. 
 

 ·        If you use the Import method and later revise the content of the original logo file (the one on your local drive), be sure to reimport the file to ensure that the copy on the network is up-to-date. 
 

 ·        If you record the company web site address in this form, the company logo will also serve as a link to the company web site when documents are sent by e-mail. 
 

 ·        In a multi-company setting, prepare one logo for each company, saving all files in the same directory. For each, make sure you are in the correct company and then specify the needed information in the Company Data form. 
 

 ·        Dual-currency users who work in a language other than English can also prepare a separate logo for printouts in English. Save it in the same way as the regular logo, and record its path and filename in the HTML Logo (Export) column. 
 

 ·        Click to set document header styles to use the company logo. 
 

 ·        Click to return to the main screen.
