# Printing Without User Intervention

 

 Priority offers the option of printing a report or document without any user intervention (skipping printer selection, page selection, copies, etc.), provided that the report/document is linked to a specific printer. This is particularly useful when the printout is executed automatically, via a batch program. 
 
## To enable printing without user intervention:

 

 1 .  Enter the Define Printers - Windows form and retrieve the printer in question (click if the printer has not yet been defined in Priority ). 
 

 2 .  Enter the Entities for Printer sub-level form. 
 

 3 .  Move to the report in question (click if it does not appear ). 
 

 4 .  Flag the Immediate Printout column. 
 
## Note:

 

Click to return to the main screen.
