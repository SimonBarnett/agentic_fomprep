# Assigning Privileges

 
## Before You Begin

 

Before you assign privileges, you may want to prepare the following informative report: 
 

 ·        The User Privs: Entities Not Treated report lists, for a group leader you designate, any new entities added to the system (e.g., after a new version of Priority was installed) for which the group leader has not yet been assigned privileges.
