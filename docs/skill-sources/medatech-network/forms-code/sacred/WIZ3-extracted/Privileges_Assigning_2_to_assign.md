# Assigning Privileges

 

In most cases, the initial privileges defined for a menu or entity are automatically applied to any sub-menus and/or entities at lower levels in the Explorer. You can then modify the privileges for any of these entities directly, as necessary. However, if the privileges for a menu or entity are later modified, these modifications will not automatically override any privileges that were assigned directly to sub-menus and/or entities at a lower level in the Explorer. If you want modified privileges for a given menu or entity to be applied automatically to all sub-menus and/or entities at all lower levels, click the upper Edit menu and select the Override option. 
 
## To assign privileges:

 

 1 .  Make sure that all users in the group to which you are assigning privileges have exited Priority . 
 

 2 .  Make sure you are in the desired company. 
 

 3 .  Run the Privilege Explorer . Choose the desired group leader. The system performs some work that may take a few minutes. When it finishes, the Main menu of the Explorer is displayed.
 Note: You can also choose an individual user who is not assigned any group leader. 
 

 4 .  If the group leader has never been assigned privileges, an X appears next to the title of the Main Menu. Right-click the menu title and assign Write privileges, which will apply to all menus and entities throughout the system.
 Note: If you fail to do so, users belonging to this group will not be able to enter Priority . 
 

 5 .  Go through each module and modify the privileges for any sub-menus or entities to which users in this group should not have Write access. To do so, right-click the menu or entity title and make the desired change (e.g., revoke, hide, read only).
 Note: Click to view types of privileges .
