Privilege Explorer - Assigning Privileges.3 
 
 
- 
 
 
 

 6 . If you chose Form Columns or Form Warning Messages , a window appears displaying all the columns or messages. Right-click the mouse on the desired column or message. A menu appears containing the different types of privileges you can assign. Choose the desired type of privilege.
 Notes: 
 

 ·              To enable users to update data in a form, but not to open new records, give them Full Access only to those columns they can update. Tip for advanced users . 
 

 ·              To prevent users from deleting records from a form, check the No record deletion box at the bottom of the window. 
 

 7 .  To confirm the assignment, choose Apply Changes from the File menu. The system performs an authorization, which takes a short while.
 Note: Changes to form columns and warning messages are made immediately (on-line) once you close the window, and there is no need to apply changes in this instance. 
 

 8 .  The new privileges will go into effect as soon as the users in question re-enter Priority .
