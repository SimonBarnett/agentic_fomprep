# Viewing Reports on Privilege Assignment

 

The following reports are available: 
 

 ·        The Discreps in User Privilege Tree report lists any inconsistencies in the privileges held by this group leader. Example. 
 

 ·        The Column Privilege Restrictions report displays form columns for which given user groups have special restrictions (read-only, hidden or mandatory). 
 

 ·        The Privileges per Group Leader report displays the privileges held by a given group leader for system entities. Entities are displayed by menu location. 
 
## Notes: 

 

 ·        Click to view a history of changes to user privileges .
