# Copying Privileges from One Company to Another, for a Specific User Group

 

The system assigns privileges only for the company in which you are running the Privilege Explorer . When you copy an entire company in Priority , all privileges are also copied. Therefore, the usual reason that you need to specifically copy privileges from one company to another is to make small adjustments (e.g., to copy privileges for a particular menu). 
 
## Before You Begin:

 

 ·        Make sure that, in the company from which you are copying the privileges, all group leaders in question have the desired set of privileges.
