# To copy privileges from one company to another:

 

 1 .  Make sure that no users in the groups to which you are assigning privileges are working in Priority . 
 

 2 .  Make sure you are in the company from which you want to copy the privileges. 
 

 3 .  Run the Privilege Explorer program. Choose the desired group leader. The system performs some work that may take a few minutes. When it finishes, the Main menu of the Explorer is displayed. 
 

 4 .  Move to the desired entity and right-click it.
 Tip: To copy the entire set of privileges from one company to another, right-click the Main menu. 
 

 5 .  From the menu that appears, choose Copy To Other Companies . A window appears displaying all other companies and the current privileges held by this group leader for this entity in each company. 
 

 6 .  Choose the desired company and click OK .
 Tip: To choose more than one company, use Ctrl or Shift while clicking, as in the Windows Explorer. 
 

 7 .  To confirm the privileges, choose Apply Changes from the File menu. The system performs an authorization; this takes a short while. The new privileges will go into effect as soon as the users in question re-enter Priority in the target company.
