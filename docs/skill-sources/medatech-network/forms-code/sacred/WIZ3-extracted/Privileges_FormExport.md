# Assigning Privileges to Export Data

 

 Priority allows you to authorize users to export data from a form to Excel or print it to a file. 
 
## To authorize a user to export data:

 

 1 .  Enter the User Permissions form and retrieve the desired user. 
 

 2 .  Click on the Permissions tab and flag the Download Form Data option.
