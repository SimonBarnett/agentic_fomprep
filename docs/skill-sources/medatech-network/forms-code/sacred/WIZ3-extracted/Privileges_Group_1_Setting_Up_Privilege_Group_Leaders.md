# Setting Up Privilege Groups 

 

In Priority , you generally assign privileges to the group leader, which are then “inherited” by all users in the group. You must therefore: 
 

 ·        Set up group leaders. 
 

 ·        Assign users to the group. 
 
## To set up group leaders:

 

 1 .  Open a user record, as explained in the Opening a User Wizard , to serve as the group leader. 
 

 2 .  In the User Name column, record a name that represents the privilege group to be led by this user (e.g., Sales, Service), rather than the user name of an actual employee. This ensures that the name of the group leader remains relevant regardless of changes in personnel. 
 

 3 .  Once you have opened a user record representing the privilege group leader, make sure this record appears in the Users form and that the Group Leader (Privs) column is blank. 
 
## Notes: 

 

 ·        To ensure that user records that serve only as privilege group leaders are not taken into consideration for license counting purposes , flag them as Inactive Users (in the User Permissions sub-level of the Users form) . 
 

 ·        To define an actual employee as a group leader, simply make sure that he or she appears in the Users form and that the Group Leader (Privs) column is blank.
