# To view a history of changes to user privileges:

 

 1 .  Enter the History of Privileges form. This form displays a separate record for each change made to any of the privileges assigned to a given user, including entity privileges copied from another group leader or company, warning/error messages and change of group leader. 
 

 2 .  Retrieve the desired data. You can use any of the form's columns (or combinations thereof) to retrieve different cross-sections of data. For example: 
 

 ·              Retrieve a User to view all of the changes made to all the user's privileges. 
 

 ·              Retrieve a Type of Change to view all users for whom similar changes were made. 
 

 ·              Retrieve an Entity Name to view all changes made to all users for that entity. 
 

 ·              Retrieve a New Group Leader to view all users who were assigned that group leader.
