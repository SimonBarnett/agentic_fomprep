# Copying Privileges from One Group Leader to Another

 

Use of the Privilege Explorer to copy privileges from one group leader to another is usually limited to making small adjustments (e.g., copying privileges for a particular menu). 
 
## Notes:

 

 ·        Copying privileges from one group leader to another overrides any privileges previously defined for the target group leader. 
 

 ·        To copy privileges from one group leader to another in a number of companies, copy the privileges separately in each company.
