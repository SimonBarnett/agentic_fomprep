# To copy privileges from one group leader to another:

 

 1 .  Make sure that no users in the groups to which you are allocating privileges are working in Priority . 
 

 2 .  Make sure you are in the desired company. 
 

 3 .  Run the Privilege Explorer program. Choose the source group leader. The system performs some work that may take a few minutes. When it finishes, the Main menu of the Explorer is displayed. 
 

 4 .  Move to the desired entity and right-click it. 
 Tip: To copy the source group leader's entire set of privileges, right-click the Main menu. 
 

 5 .  From the menu that appears, choose Copy To Other Users . A window appears displaying all the other group leaders and the privileges of each group leader for this entity. 
 

 6 .  Choose the desired group leader and click OK .
 Tip: To choose more than one group leader, use Ctrl or Shift as in the Windows Explorer. 
 

 7 .  To confirm the privileges, choose Apply Changes from the File menu. The system performs an authorization that takes a short while. The new privileges will go into effect as soon as the users in question re-enter Priority .
