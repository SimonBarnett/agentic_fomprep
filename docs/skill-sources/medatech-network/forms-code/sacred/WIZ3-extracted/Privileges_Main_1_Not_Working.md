# Working Without Privileges

 

In Priority , you generally assign privileges to the group leader, which are then “inherited” by all users in the group. In a similar way, if you decide not to maintain privileges, you can link all users to the “tabula” group leader, who is assigned full privileges. In this case, all users will have full privileges, i.e., free access to all components of the system. 
 
## To assign the tabula user as group leader to all users:

 

 1 .  In the Users form, retrieve all users. 
 

 2 .  For each user, move to the Group Leader (Privs) column, and choose the “tabula” group leader from the Choose list. 
 
## Note:

 

In a Tabula database, use the "Manager" group leader.
