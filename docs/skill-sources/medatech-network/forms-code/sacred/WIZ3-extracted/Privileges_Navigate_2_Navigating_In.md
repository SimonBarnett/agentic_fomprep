# Navigating in the Explorer 

 

The following steps demonstrate navigating in the Privilege Explorer . 
 
## To navigate in the Explorer:

 

 1 .  Run the Privilege Explorer program, choosing any desired group leader. The system performs some work that may take a few minutes. When it finishes, the Main menu of the Explorer is displayed. 
 

 2 .  Note that there is a colored symbol to the left of the Main menu.
