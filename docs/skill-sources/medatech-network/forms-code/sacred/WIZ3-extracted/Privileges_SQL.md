# Assigning Privileges for System Customizations

 

 Priority allows for the customization of the standard system. Users who are permitted to customize the system are designated as authorized for SQL. 
 
## To authorize a user to perform system customizations:

 

 1 .  Enter the User Permissions form and retrieve the desired user. 
 

 2 .  Click on the Permissions tab and flag the Authorized for SQL column.
