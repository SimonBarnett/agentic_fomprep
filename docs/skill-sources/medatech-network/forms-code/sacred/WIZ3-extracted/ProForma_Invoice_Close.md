# Finalizing Pro Forma Invoices

 

When you finalize a pro forma invoice, the following occurs: 
 

 ·        A unique internal invoice number is generated, which replaces the temporary number that appeared when the invoice was opened. 
 

 ·        If the invoice is based on documents, the Billed column in each document is flagged. 
 

 ·        A pro forma journal entry is recorded for the invoice. 
 

 ·        The status of the invoice is set to Final . 
 
## Note:

 

If the Post Journ. Entries column is not flagged for pro forma invoices (in the Financial Documents form), the pro forma journal entry that is created is only pending. That is, it needs to be checked and posted.
