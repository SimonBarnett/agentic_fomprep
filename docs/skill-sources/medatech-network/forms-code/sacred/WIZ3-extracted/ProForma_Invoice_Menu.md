# Preparing Pro Forma Invoices

 

Pro forma invoices can be prepared, automatically or manually, on the basis of reported project hours and/or project payments, as well as on the basis of service calls and/or a service contract. After recording and checking the invoice, it should be finalized and printed. Finalizing an invoice creates a pro forma journal entry. If necessary, you can perform certain revisions in final pro forma invoices or cancel them. 
 
## What do you want to do?

 

 Record a pro forma invoice 
 

 Finalize a pro forma invoice 
 

 Print a pro forma invoice 
 

 Revise a final pro forma invoice 
 

 Cancel a final pro forma invoice 
 

 Delete a pending pro forma invoice
