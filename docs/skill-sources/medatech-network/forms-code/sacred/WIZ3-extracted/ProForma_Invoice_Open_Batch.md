# Preparing a Batch of Pro Forma Invoices Automatically

 

The Prepare Pro Forma Invoices program automatically opens pro forma invoices: 
 

 ·        for a project 
 

 ·        for selected service documents 
 

 ·        for all service documents within a given period 
 
## Before you begin:

 

 1 .  Make sure you have performed all setups for pro forma invoices. Most of these setups directly affect the outcome of this program.
 Tip: Click to access the setup menu . 
 

 2 .  If possible, finalize or delete all pending pro forma invoices (run the Finalize Pro Forma Invoices or Delete Pending Pro Forma Invs. program, respectively). This will make it easier to retrieve the invoices opened by the program, as only the new ones will have temporary numbers (with the prefix T ).
