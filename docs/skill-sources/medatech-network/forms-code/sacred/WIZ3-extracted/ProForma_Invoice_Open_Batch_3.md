# To check the results of the program:

 

 1 .  Enter the Pro Forma Invoices form and retrieve each invoice opened by the program.
 Tips: 
 

 ·      Retrieve by T* in the Invoice No. column to access all pending invoices. 
 

 ·      To assign handling of an invoice to another employee, specify his/her username in the Assigned to column. If you have done so for all prepared documents, you can exit the form and ignore the following instructions. 
 

 2 .  Check the Contact column to make sure that the relevant invoice contact appears. Change if necessary. 
 Tip: To define new contacts for the customer or to assign a default contact for invoices, use the Customer Contacts form, a sub-level of the Customers form. For more information, see the Open Customers Wizard . 
 

 3 .  Click the References tab and check the Rep No. column to make sure that the correct sales rep appears. Change if necessary.
 Note: If the invoice is for several documents that have been made through more than one sales rep, designate the main one here. When itemizing the invoice, indicate the sales rep for each line item. 
 

 4 .  Click the Financial Terms tab. Make sure that the Tax Code (for dual-currency users: VAT Code ) is correct. 
 

 5 .  The overall discount, applied to the entire invoice, is calculated automatically from the overall discounts assigned to each document. If you want to override that discount, or if no discount was given in any document and you want to award one now, use the Set Overall Discount % column. 
 
## Note:

 

If the invoice was created for a project, the project number appears in the Project tab. More details.
