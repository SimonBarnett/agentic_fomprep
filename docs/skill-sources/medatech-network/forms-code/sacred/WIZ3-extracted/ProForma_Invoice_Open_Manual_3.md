# To itemize the pro forma invoice:

 

 1 .  Enter the Invoice Items sub-level form. 
 

 2 .  Specify the Part Number of the type of work hour being billed and make sure its Part Description is appropriate.
 Note: Click to define a new work hour part. 
 

 3 .  Record the Quantity of work hours to be billed. 
 

 4 .  Make sure that prices and discounts are correct. 
 

 5 .  The sales rep and the commission percentage due for the line item appear automatically. Change as necessary. 
 

 6 .  Click to link this line item to a project or project activity . 
 

 7 .  Enter the Invoice Item - Remarks sub-level form and check the remarks that appear there. Revise or add to them, as desired.
 Notes: 
 

 ·      Any part remarks recorded in the part catalogue appear in this form automatically if Copy Part Remarks has been flagged for pro forma invoices (in the Copy Part Remarks to Document form). 
 

 ·      The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 ·      To include these remarks in the printout of the invoice, select a suitable print format .
