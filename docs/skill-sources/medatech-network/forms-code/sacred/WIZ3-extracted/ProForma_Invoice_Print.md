# Printing Pro Forma Invoices - Before You Begin

 
## To check remarks:

 

 1 .  Enter the Pro Forma Invoices form and retrieve the desired invoice. 
 

 2 .  Enter the Invoice/Memo - Remarks sub-level form. Check the text recorded there, which will appear in the invoice printout. Revise it if necessary. 
 

 3 .  If you are printing invoices with item remarks , move to the parallel Invoice Items sub-level form. For each item, make sure that the remarks recorded in the Invoice Item - Remarks sub-level form are suitable. Explanation. Revise them if necessary.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 4 .  Return to the Pro Forma Invoices form. 
 
## To verify the customer's mailing address:

 

 ·        Move to the Invoice - Add'l Details sub-level form. Check the recorded address. If you want to send the invoice to a different address, change the address details in this form.
 Tip: To permanently change the customer's mailing address, use the Customers form.
