# Printing Pro Forma Invoices

 
## To print a single invoice:

 

 1 .  Enter the Pro Forma Invoices form and retrieve the desired invoice. 
 

 2 .  Select Print Pro Forma Invoice from the list of Direct Activations . 
 

 Notes: 
 

 ·      D ual-currency users: If you wish to print the invoice in English and are working in another language, select Print Pro Forma Inv-Foreign Lang instead. 
 

 ·      To simultaneously finalize and print the invoice, select Finalize & Print Invoice from the list of Direct Activations . 
 
## To print a batch of invoices:

 

 ·        Run the Print Pro Forma Invoice report.
 D ual-currency users: To print in English when working in another language, run the Print Pro Forma Inv-Foreign Lang report. 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the Pro Forma Invoices main screen .
