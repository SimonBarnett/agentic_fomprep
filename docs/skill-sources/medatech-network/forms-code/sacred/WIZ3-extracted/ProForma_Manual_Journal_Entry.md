# To record a manual pro forma entry:

 

 1 .   Enter the Entry Journal form. 
 

 2 .  Record details of the entry as usual. 
 

 3 .  After checking that all information is correct, post the entry by selecting Convert to Pro Forma Entry from the list of Direct Activations . The pro forma entry is assigned a permanent number with the prefix P . 
 
## Note:

 

For more information on recording manual journal entries, run the Manual Journal Entries Wizard .
