# Linking an Invoice Item to a Project or Activity

 

By linking a given line item in a pro forma invoice to a project, you can keep track of the charges against each project. 
 

A project appears automatically in the following cases: 
 

 ·        When a single project is recorded for the customer, and the SLinkProject constant is set to 1 . 
 

 ·        When the invoice is based on a document linked to a project. 
 
## To link a line item to a project or activity:

 

 1 . Enter the Projects/Accounts sub-level form. 
 

 2 . In the Project Number column, choose/check the project number. 
 

 3 . The project's default account appears automatically in the Account Number column. Revise it if necessary. 
 

 4 . In the WBS column, choose/check the WBS code of the activity. 
 

 3 .  Change the Percent Completed , if necessary.
 Note: To revise the Activity Status , move to the Activity ID column and press F6 , then make the revision in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 4 .  Return to the upper-level form.
