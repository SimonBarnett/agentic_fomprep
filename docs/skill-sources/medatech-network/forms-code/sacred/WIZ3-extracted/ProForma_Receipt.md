# Recording a Receipt Based on Pro Forma Invoices

 

In cash-based accounting, the customer payments you receive can be taken into account in aging calculations based on pro forma entries. This is usually done by linking the receipt to one or more pro forma invoices. However, this option is available even when the customer does not remit payment for specific pro forma invoices (e.g., in the case of an advance payment). 
 
## Notes:

 

 ·        When you finalize the receipt, a regular journal entry will be created for the payment transaction. The entry item that credits the customer will double as both a pro forma entry (reconciled with the debit entry of the pro forma invoice) and as a regular entry (which will be reconciled with the multi-shipment invoice, once it is recorded). When the receipt is linked to one or more pro forma invoices, the reconciliation is performed automatically. 
 

 ·        The following instructions focus on those steps unique to cash-based accounting, and disregard steps common to recording receipts in general. If you are unfamiliar with how to work with customer receipts, run the Customer Receipts Wizard .
