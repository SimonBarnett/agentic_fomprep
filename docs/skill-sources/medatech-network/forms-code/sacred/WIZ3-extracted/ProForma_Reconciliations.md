# Reconciling Pro Forma Entries

 

The system automatically reconciles the pro forma entry created when a pro forma invoice is finalized with the credit entry created upon finalization of the customer receipt linked to that invoice. However, if there are unreconciled pro forma entries (e.g., those created manually), you need to reconcile them manually. 
 
## Note:

 

The following instructions focus on those steps unique to cash-based accounting, and disregard steps common to account reconciliations in general. If you are unfamiliar with how to handle reconciliations, run the Account Reconciliation Wizard .
