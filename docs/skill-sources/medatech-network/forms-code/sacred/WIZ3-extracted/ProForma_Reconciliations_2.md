# To manually reconcile pro forma entries:

 

 1 .  Run the Prepare for Reconciliation program. In the second input screen, make sure that the Pro Forma Entries column is flagged . 
 

 2 .  Continue as usual. 
 
## Notes:

 

 ·        The reconciliation worksheet will include both pro forma entries (with the prefix P ) – that were recorded automatically when pro forma invoices were finalized, or recorded manually in the Entry Journal – and regular journal entries. The latter are entry items crediting the customer, created against final receipts based on pro forma invoices. These receipt entries need to be reconciled with the appropriate pro forma entries. The receipt entries will later be reconciled with the (regular) debit entries for the multi-shipment invoices recorded against them. 
 

 ·        Click to return to the main screen.
