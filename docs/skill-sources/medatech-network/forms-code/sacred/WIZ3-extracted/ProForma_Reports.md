# Running Reports Based on Pro Forma Entries

 

Pro forma entries can be taken into account in two types of reports: customer credit and aged receivables. 
 
## To run customer credit reports based on pro forma entries:

 

 ·        Once the ProFormaBasis constant is set for work on a cash basis, customer credit calculations automatically take pro forma entries into account. All you have to do is run customer credit reports in the usual way. 
 
## To run aged receivable reports based on pro forma entries:

 

 ·        Run the reports as usual. In the appropriate input screen, flag the option to base the report on Pro Forma Entries .
