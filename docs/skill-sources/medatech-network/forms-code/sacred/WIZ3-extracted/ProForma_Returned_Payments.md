# Recording a Returned Payment Against a Pro Forma Invoice

 

There are a number of ways to record a returned payment, when the original customer receipt was recorded against a pro forma invoice: 
 

 ·        If you receive a replacement payment immediately , record the return document directly against the customer's account, effectively cancelling the original payment. Also record a customer receipt for the new payment, reconciling it with the returned payment. In this case, no new multi-shipment invoice should be prepared and no new pro forma entry is recorded for the customer. 
 

 ·        If you debit the customer ' s account in the return document , but do not receive additional payment right away, flag the Pro Forma Entry Too column in the Returned Payments form. Then cancel the multi-shipment invoice (for the original customer receipt) or record a credit memo, and reconcile the returned payment with the cancelled invoice or credit memo. The returned amount will then appear in the customer's aging reports, when run for pro forma entries. When a new payment is received, flag the pro forma entry for the returned payment in the customer receipt, and prepare a new multi-shipment invoice.
