# Copying Part Remarks to Pro Forma Invoices

 

You can set up pro forma invoices so that part remarks are recorded automatically for individual items when a part number is recorded or revised in an itemized invoice. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks to invoice items:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "Pro Forma Invoice", flag the Copy Part Remarks column.
