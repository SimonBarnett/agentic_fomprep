# Setting up Cash-Based Accounting

 

Before you can work on a cash basis, you must perform a number of setups. 
 
## Note:

 

Of the setups recorded here, only the first four options are specific to pro forma invoices. The rest affect all types of customer invoices (multi-shipment invoices, sales invoices, over-the-counter invoices and, for dual-currency users, export invoices). In other words, make sure you set definitions that are suitable for all types of invoices that you will be opening. 
 
## What do you want to do?

 

 Enable cash-based accounting in Priority 
 

 Assign document properties to pro forma invoices 
 

 Set up business processes (BPM) for pro forma invoices (statuses) 
 

 Set up part remarks for pro forma invoices 
 

 Define billing customers 
 

 Determine how branches are assigned to invoices 
 

 Set up automatic preparation of invoices (general) 
 

 Set up automatic preparation of invoices when billing per project 
 

 Set up automatic preparation of invoices based on service calls/contracts
