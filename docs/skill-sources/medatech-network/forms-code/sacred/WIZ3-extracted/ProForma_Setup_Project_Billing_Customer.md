# Addressing Invoices to the Billing Customer

 

Pro forma invoices that are prepared automatically for a project can be opened either for the customer recorded in the original sales document or for that customer's billing customer. 
 
## Note: 

 

This definition affects multi-shipment invoices as well. 
 
## To open invoices for the billing customer:

 

 1 .  Enter the Financ. Parameters for Customers form and retrieve the regular customer (the one that appears in the original document). 
 

 2 .  Make sure that a Billing Customer has been defined in the Customer tab. 
 

 3 .  Click the Invoices tab and flag the Inv. to Billing Cust column. 
 
## Notes:

 

 ·        If a third-party billing customer has been recorded for a particular order or order item, that will override the customer's default billing customer. If several different billing customers need to be charged, a separate invoice will be opened for each one. 
 

 ·        Click to return to the main screen.
