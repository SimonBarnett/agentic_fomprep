# Setting How Service Documents are Invoiced

 

When you use the Prepare Pro Forma Invoices program to open invoices based on service calls and/or contracts, you you have the option, per customer, of: 
 

 ·        Preparing a single pro forma invoice for each individual service document (the system default). 
 

 ·        Preparing two periodic invoices – one billing service calls and the other for contract payments. 
 
## Notes:

 

 ·        If you choose to create one pro forma invoice for each service document, you will also have to open individual multi-shipment invoices later on. 
 

 ·        Click for a detailed explanation of how billable documents are grouped together into periodic invoices. 
 
## To set up periodic invoices:

 

 1 .  Enter the Financ. Parameters for Customers form and retrieve the desired customer.
 Note: Retrieve the customer for which invoices will be recorded, whether it be the regular customer or the billing customer. 
 

 2 .  Click the Invoices tab and flag the Periodic Invoice column. 
 
## Notes:

 

 ·        If periodic invoices are recorded for the billing customer, all documents (of each type), and/or any line items in a document, recorded for any customer using this billing customer are charged together in the same invoice. 
 

 ·        Do not flag customers for periodic invoices if invoice dates are taken from the original document. 
 

 ·        Click to return to the main screen.
