Cash-Based Accounting - Returned Payments.2 
 
 
- 
 
 
 

  
 

 ·        If you record the return document for the Returned Payments Cashier and only later debit the customer ' s account via a deposit slip , flag the Pro Forma Entry Too column in the Deposit Slips form. Again, you need to cancel the multi-shipment invoice (or record a credit memo) and reconcile it with the deposit. The deposited amount will then appear in the customer's aging reports, when run for pro forma entries. When a new payment is received, reconcile the pro forma entry for the deposit with the receipt, and prepare a new multi-shipment invoice.

 ·        For more information on returned payments, run the Returned Payments Wizard . 
 

 ·        For more information on deposits, run the Deposits Wizard .
