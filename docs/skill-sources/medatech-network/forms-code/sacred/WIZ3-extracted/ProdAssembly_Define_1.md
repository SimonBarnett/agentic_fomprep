# To define a product bundle:

 

 1 .  Enter the Product Bundles (Quotes/Orders) form. 
 

 2 .  In the Product Bundle column, record the name or number identifying the new bundle. 
 

 3 .  In the Bundle Description , record a short description of the product bundle. 
 

 4 .  If the product bundle is currently available for sale, make sure the In Use column is flagged. 
 

 5 .  Set the order in which the bundle will appear in Choose lists in price quotes and sales orders by assigning it a Display Order (the lower the number, the higher the product bundle will appear in the list).
