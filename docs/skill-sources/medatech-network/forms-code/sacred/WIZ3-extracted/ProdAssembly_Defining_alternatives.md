Product Bundles - Defining Substitute Components 
 
 
- 
 
 
 
# To define substitute components:

 

 1 .  For any component part that has possible substitutes, enter the Substitutes for Component sub-level form. 
 

 2 .  Specify the Part Number and Quantity of each substitute component. 
 

 3 .  Do one of the following: 
 

 ·      To use the part's default unit price, determined by the system's price hierarchy (e.g., special part price, list price and so on), flag the Calc. Price in Doc column and leave the Special Part Price column blank. 
 

 ·      To use a different price, record it in the Special Part Price column and leave the Calc. Price in Doc column blank. 
 

 ·      To have the part appear without a price , leave both columns blank.
