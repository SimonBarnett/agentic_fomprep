Production Report Wizard - Introduction (Cont.) 
 
 
- 
 
 
 

If you have performed an operation that creates a set of byproducts from a source part , report production only for the source part. Backflush will create inventory of the byproducts, and reduce any additional child parts required in the operation. For more information about byproducts, run the Factory Modelling Wizard .
