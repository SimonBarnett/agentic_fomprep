# Reporting Production

 

You can report a regular production operation, an operation setup and/or a break. 
 

 ·        If labor and machine times are reported in a setup operation, labor cost (direct and indirect) and setup cost (machine time * the cost of one setup hour) are added to the work order's setup cost. 
 

 ·        If labor and machine times are reported for a break, labor cost and machine cost (direct and indirect) are added to the general work order cost. 
 

 ·        If work in your factory is divided into shifts, you can report production per shift, thus affecting the calculation of production costs. Explanation. . 
 
## Note:

 

If you do not report an operation that requires reporting, a negative inventory balance will be created on the plant floor. Click for an explanation of negative inventory balances.
