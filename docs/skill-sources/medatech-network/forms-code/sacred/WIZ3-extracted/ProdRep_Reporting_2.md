# To record a production report: 

 

 1 .  Enter the Reporting Production Details form.
 Note: Production reports recorded in this form are included in a daily general form generated automatically by the system. Alternatively, you can create a departmental report form in the Reporting Production form, and use the Production Details sub-level form to report a batch of operations (each in a separate line). 
 

 2 .  Record the Date of production. The Report No. appears automatically after you leave the current line. 
 

 3 .  Record the Work Order number. The Part Number and Work Order Quantity appear automatically.
 Note: If you do not use work orders, record a 0 , then record the number of the part on which the operation is performed in the Part Number column. Production reports with no work order number are ignored by costing. 
 

 4 .  Do one of the following: 
 

 ·              Click to report a regular operation. 
 

 ·              Click to report a break or setup.
