# To report a break or setup:

 

 1 .  Specify the Operation being set up, or during which the break was taken.
 Note: Production reports are included in a daily general form generated automatically by the system. You can also create a departmental report form in the Reporting Production form, and use the Production Details sub-level form to report a batch of operations (each in a separate line). 
 

 2 .  Click the Quantities tab and specify the Employee ID of the employee performing the setup or taking the break.
 Note: If more than one employee performed the setup or took the break, use the Reporting Workers sub-level form to list them all. 
 

 3 .  Click the Details tab and fill in the Set-up/Break (S/B) column: 
 

 ·              Choose S if you are reporting a setup. 
 

 ·              Choose B if you are reporting a break. 
 

 4 .  If you are reporting a break or setup operation in which a machine is involved, click the Times tab and record the machine and labor time spent performing the operation, using either the Start Time and End Time columns, or the Span column.
 Note s : 
 

 ·              If labor and machine times are reported in a setup operation, labor cost (direct and indirect) and setup cost (machine time * the cost of one setup hour) are added to the work order's setup cost. 
 

 ·              If labor and machine times are reported for a break, labor cost and machine cost (direct and indirect) are added to the general work order cost. 
 

 5 .  Click the Form tab and flag the Final column.
 Notes: 
 

 ·              You can only flag this column for reports that were recorded in this form. 
 

 ·              You can reopen the report for revision by removing the check mark from this column.
