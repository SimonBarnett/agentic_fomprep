# Viewing Production Reports

 

The system provides reports as well as a special form for viewing reported production data. 
 
## To view production reports by form:

 

 ·        Run the Reported Production by Form report or 
 

 ·        Enter the View Reported Production form and use the Form Number column to retrieve the desired records. 
 
## To view production reports by work order:

 

 ·        Run the Reported Production by Work Ord. report or 
 

 ·        Enter the View Reported Production form and use the Work Order column to retrieve the desired records. 
 
## To view production reports for serialized parts:

 

 ·        Run the Production per Serial Number report. 
 
## To view production reports for rejected items:

 

 ·        Run the Summary of Defective Parts report or 
 

 ·        Enter the View Reported Production form and use the Defect Codes column to retrieve the desired records.
