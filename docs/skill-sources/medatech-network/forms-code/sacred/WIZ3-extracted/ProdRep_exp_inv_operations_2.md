# Notes: 

 

 ·        Operations may be flagged for inventory/costing control in one of three ways, according to the following hierarchy: 
 

 ·              The flag is assigned to a work cell and affects all operations performed in that work cell. 
 

 ·              The flag is assigned to a specific operation (overriding the work cell flag). 
 

 ·              The flag is assigned to a specific operation in a given work order routing (overriding the other two flags). 
 

 ·        For more information regarding floor inventory calculation, run the Backflush Wizard . 
 

 ·        For more information about working with subcontractors, run the Working w/Subcontractors Wizard .
