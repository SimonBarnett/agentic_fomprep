# Setting Up Production Reports

 

Before you begin working with production reports, you need to define various standard costs related to production (e.g., labor costs, machine costs, indirect costs). For detailed instructions, run the Costing for Manufacturers Wizard . 
 

If your factory runs in shifts, you need to define these shifts and their parameters in the system. Explanation. 
 

You can determine which parts are included in the automatic entry of finished parts into the factory warehouse, and whether or not to retain the work order and operation number for these parts.
