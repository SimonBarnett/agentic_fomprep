# Setting Up Shifts

 

 1 .  Enter the Shifts form. 
 

 2 .  Open a new line for each shift; record its name in the Shift column. 
 

 3 .  If necessary, record a Shift Description . 
 

 4 .  If salaries are adjusted according to shift, specify in the Rate (%) column the percentage by which salaries are increased in the current shift, relative to the standard salary (for example, if the salary for night work is 1.5 times the standard day salary, record a rate of 150% for the "Night" shift).
 Note: This affects costing of reported labor, which is determined by the employees who performed the reported operation and the amount of labor time reported for it.
