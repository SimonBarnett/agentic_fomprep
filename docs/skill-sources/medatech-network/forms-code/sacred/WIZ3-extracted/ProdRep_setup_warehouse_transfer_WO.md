# ProdRep_setup_warehouse_transfer_WO

- **Source:** `ProdRep_setup_warehouse_transfer_WO.htm`

Production Report - Setup: Automatic Warehouse Entry.4 
 
 
- 
 
 
 

 To set up automatic warehouse entry in the work order routing: 
 

 1 .  Enter the Work Orders form and retrieve the desired work order. 
 

 2 .  Enter the Routing for the Work Order sub-level form and move to the last reported operation in the routing. 
 

 3 .  If you defined a target warehouse in the part's routing, it appears automatically in the To Warehouse column, but may be revised. Otherwise, specify a warehouse. 
 

 4 .  I f necessary, update the Remove Wk Order No. and Remove Oper. Number columns. 
 
## Notes:

 

 ·        You can only remove the work order number if you have also removed the operation number and defined a warehouse to which to transfer the manufactured inventory. 
 

 ·        Removing the number of an operation in the middle of the production routing is likely to result in negative inventory when the following operation is reported.
