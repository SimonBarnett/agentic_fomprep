# To set up automatic warehouse entry in the part routing:

 

 1 .  Enter the Routings form and retrieve the part's production routing. 
 

 2 .  Enter the Operations in Routing sub-level form and move to the last reported operation in the routing. 
 

 3 .  In the To Warehouse column, choose the warehouse to which you want the finished parts to be transferred. 
 

 4 .  If you want to remove the operation number from the finished inventory, flag the Remove Oper. Number column. 
 

 5 .  If you want to remove the work order number from the finished inventory, flag the Remove Wk Order No. column. 
 
## Notes:

 

 ·        You can only remove the work order number if you have also removed the operation number and defined a warehouse to which to transfer the manufactured inventory. 
 

 ·        Removing the number of an operation in the middle of the production routing is likely to result in negative inventory when the following operation is reported.
