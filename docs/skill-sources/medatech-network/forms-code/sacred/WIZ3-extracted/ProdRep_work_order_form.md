# Printing a Work Order

 

The work order document is used to manually fill in production details, including production reports. It contains the details of the work order (e.g., part number, start date), routing, kit list, any recorded remarks, production reports, and more. Note that the work order printout does not include the documents attached to the work order; these must be printed separately. 
 
## To print one work order:

 

 1 .  Enter the Work Orders form and retrieve the desired work order. 
 

 2 .  Select Print Work Order from the list of Direct Activations . 
 
## To print multiple work orders:

 

 ·        Run the Print Work Order report.
