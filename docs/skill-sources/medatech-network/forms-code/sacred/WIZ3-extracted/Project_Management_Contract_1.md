# Opening a Service Contract for a Project

 

 Priority allows you to automatically open a service contract for all of the project's finished products for which service parameters have been defined. 
 
## To open a service contract:

 

 1 .  Enter the Projects form and retrieve the desired project. 
 

 2 .  Enter the Finished Products sub-level form and make sure that the service parameters are correctly defined for each part to be covered by the service contract. 
 

 3 .  Return to the upper-level form and select Open Service Contract for Proj. from the list of Direct Activations . Priority opens a service contract for the customer in question for any relevant finished products in the project.
