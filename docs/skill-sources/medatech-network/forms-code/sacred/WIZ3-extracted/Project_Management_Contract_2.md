# To view the service contract:

 

 1 .  Enter the Service Contracts form and retrieve the contract by project number. 
 

 2 .  Make any desired changes to the contract (e.g., change the status).
 Tip : Run the Service Contract Wizard for more information. 
 
## Notes:

 

 ·        You can also view the service contract in the Service Contracts for Projects sub-level of the Projects form. 
 

 ·        Billing for service contracts is handled through the Customer Service module. 
 

 ·        Click to return to the main screen.
