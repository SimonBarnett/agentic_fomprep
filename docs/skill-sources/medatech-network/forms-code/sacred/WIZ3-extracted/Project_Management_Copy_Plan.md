# Copying a Project Plan

 

You can copy the project plan from one project to another, provided that no planning has yet been done for the second project. 
 
## To copy a project plan:

 

 1 .  Enter the Projects form and open a new project (if it hasn't yet been opened). 
 

 2 .  Retrieve the (old) project that contains the project plan you want to copy. 
 

 3 .  Select Copy Plan to Another Project from the list of Direct Activations . 
 

 4 .  In the input screen, specify the number of the project to which you want to copy the plan. 
 

 5 .  If you want to include the allocation of human resources to project activities as recorded in the original project, flag the Copy Resources column.
