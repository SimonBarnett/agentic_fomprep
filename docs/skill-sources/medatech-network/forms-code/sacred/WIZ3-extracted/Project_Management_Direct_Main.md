# Working Directly in the Project Plan

 

When you work directly in Priority 's project plan, all revisions take effect immediately. If you want to create a backup of the project plan at a particular stage, you can save the project plan as a planning version. You can also export the project plan into an MS-Project file. 
 

If working directly in the project plan becomes impractical, you can easily switch over to working with planning versions. 
 
## Before You Begin

 

 ·        To automatically update cumulative planned costs and work hours for a project any time the project plan is updated, click the Planning tab and flag the Automatic Cost Calc column. 
 
## What do you want to do?

 

 Plan the project 
 

 Save the current project plan in a planning version 
 

 Export the project plan into an MS-Project file 
 

 Print the project plan or project activities 
 

 Switch to working with planning versions
