# Planning the Project

 

The project can be planned in one of two forms: 
 

 ·              Project Planning , a sub-level of Projects 
 

 ·              Project Activities , accessed directly from the menu. 
 

Which form to use is a matter of personal preference: use the former to work with all activities in a single project; use the latter to access activities from multiple projects. 
 

To simplify matters, the following refers only to the Project Planning sub-level form. The same basic steps, with minor differences, are used to work with the Project Activities form. 
 
# To plan the project:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Enter the Project Planning sub-level form and move to Full-Record Display Mode.
 Note: At any point in the following process, you can transfer responsibility for the activity to another employee, by specifying his/her username in the Owner column. 
 

 3 .  For each activity, record a WBS Code . 
 

 4 .  Record the activity's name in the Name of Activity column. 
 

 5 .  Record the activity's Start Date and End Date .
 Note: Make sure that the time range of a sub-activity does not deviate from the time range of its summary activity. 
 

 6 .  Record a Priority for this activity.
 Note s : 
 

 ·              This value is automatically updated in the activity's record in the To Do Item , and this update is recorded in the History of Statuses sub-level form. 
 

 ·              When importing an MS-Project file, this column displays the priority given to this activity, as specified in the MS-Project file. 
 

 7 .  If the activity is a milestone , click the Details tab and flag the Milestone column. 
 

 8 .  To link an existing project to the activity as a sub-project, click the Subproject tab and specify the Subproject number. The cost and profit data of the sub-project will be included in calculations for this activity. 
 Note: The sub-project must already be recorded in the Projects form. 
 

 9 .  To link the activity to a SOW item, click the SOW tab and specify the Document Number and SOW Item . 
 

 10 .  If you have an external file that pertains to a specific project activity, you can attach it to the activity using the Attachments form, sub-level of the Project Planning form.
