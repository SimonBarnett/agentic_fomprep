# Printing the Project Plan or Project Activities

 

You can print an entire project plan, together with each activity's remarks, as well as specific activities and their remarks. 
 
## To print the project plan:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Select Print Planning Document or Project Planning With Remarks from the list of Direct Activations . 
 
## To print selected activities from the project plan:

 

 ·        Run the Project Planning With Remarks report for the desired project and activity.
 Tips: 
 

 ·              Leave the Version input column empty to print the version in effect. 
 

 ·              Use a wildcard in the WBS Code or Name of Activity input column to print multiple activities (e.g., write 3* to print all activities with a WBS code beginning with "3.", writ`e Init* to print all activities with names beginning with the string "Init").
