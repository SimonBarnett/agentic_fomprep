- 
 
 
 
# To save the project plan in a planning version:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Select Save Version from the list of Direct Activations . The program creates a new record for the current project plan in the Planning Versions form, where it is assigned the next available version number. 
 
## Notes: 

 

 ·        If the Planning Versions sub-level form is open, you need to exit and reenter in order to view the new version. 
 

 ·        The original project plan continues to be displayed in the Project Planning sub-level form (i.e., the Version in Effect column continues to display 1 ).
