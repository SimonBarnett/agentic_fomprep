# Working with Planning Versions

 

Switching over to working with versions is as easy as saving the project plan, which creates a new planning version. From that point on, you can simply update the project plan by putting new versions into effect. You can prevent the project plan from being revised manually by flagging the project accordingly. 
 
## To save the project plan in a planning version:

 

 ·        From the Projects form, select Save Version from the list of Direct Activations . 
 
## To prevent manual revision directly in the project plan:

 

 ·        Click the Planning tab and flag the Update Versions Only column. 
 
## Note:

 

Click to go to the Planning Versions menu.
