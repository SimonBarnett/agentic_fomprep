# Exporting a Planning Version to a Data File

 

 Priority provides a program that automatically exports the planning version currently in effect to an external data file, which can then be imported into another installation of Priority (e.g., for synchronization purposes). 
 
## To export a planning version:

 

 1 .  Enter the Projects form and retrieve the desired project. 
 

 2 .  Make sure that the full path and name of the target data file appear in the MS Project File column (in the Planning tab). If not, enter the Planning Versions sub-level form and specify the file in the MS Project File column of the version currently in effect. 
 

 3 .  In the upper-level form, select Upload Project Plan from the list of Direct Activations .
