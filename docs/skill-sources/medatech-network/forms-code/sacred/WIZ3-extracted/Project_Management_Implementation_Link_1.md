# Linking a Document to a Project/Activity

 

You can link either an entire document or individual items within it to a project/activity. If you link individual line items to an activity, you can also change the activity's status and/or the percentage completed. 
 
## Note:

 

If a single project has been opened for a customer (and the SLinkProject constant is set to 1 ), every document opened for that customer is automatically linked to the project. 
 
## What do you want to do?

 

 Link an entire document to a project 
 

 Link an entire document to a project activity 
 

 Link a line item to a project OR project activity
