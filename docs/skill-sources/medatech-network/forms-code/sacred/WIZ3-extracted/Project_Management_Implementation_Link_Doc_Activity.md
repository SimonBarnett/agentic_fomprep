# To link a document to an activity:

 

 1 .  Enter the appropriate form and retrieve the document you want to link to the project activity. 
 

 2 .  Enter the Projects/Accounts sub-level form. 
 

 3 .  Select the Project Number . The default project accounts appears automatically. 
 

 4 .  If necessary, change the account against which the present transaction is to be debited/credited. 
 

 5 .  Select the WBS Code of the desired project activity.
 Note: You cannot revise the Percent Completed column in this form. Instead, move to the Activity ID column and press F6 , then make any revisions desired to the project activity in the form that opens. Finally, press Esc to return to Projects/Accounts .
