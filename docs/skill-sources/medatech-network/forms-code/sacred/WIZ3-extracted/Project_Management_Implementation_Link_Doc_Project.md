Project Management - Linking a Transaction to a Project 
 
 
- 
 
 
 
## To link a document to a project:

 

 1 .  Enter the appropriate form and retrieve the document you want to link to the project. 
 

 2 .  Select the desired Project Number (in most documents, under the Project tab). 
 
## Note:

 

Unless you specifically define otherwise, the transaction will be debited/credited against the project's default income/expense account. 
 
## To change the expense/income account against which the transaction will be debited/credited:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  Select the Project Number again. The default project accounts appear automatically. 
 

 3 .  Change the account against which the present transaction is to be debited/credited. 
 
## Note:

 

Click to return to the Project Implementation menu .
