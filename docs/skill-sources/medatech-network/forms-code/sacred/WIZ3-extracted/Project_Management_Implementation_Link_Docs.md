# Linking Transaction Documents to a Project

 

The following transactions can be linked to a project: 
 
## Inventory transactions

 

When you link an inventory transaction to a project, the inventory involved is debited from the project or credited to it, depending on the type of transaction. To avoid a situation where two transactions (e.g., receipt of goods, shipment to the customer) charge the project for the same inventory, inventory should always be received directly into a project warehouse. Then, when you issue materials from the project warehouse, they are not charged to the project a second time. 
 
## Purchase transactions:

 

 ·              purchase demands 
 

 ·              RFQs 
 

 ·              price quotations 
 

 ·              purchase orders 
 

 ·              vendor invoices 
 

 Note: Purchase orders and purchase demands can be prepared and linked automatically. 
 
## Sales and customer service transactions:

 

 ·              sales orders 
 

 ·              service contracts 
 

 ·              service calls 
 

 ·              customer invoices 
 

 Note: Service contracts and invoices can be opened and linked automatically.
