# Linking a Journal Entry to a Project

 

You can link a journal entry to a project or activity directly in the journal. This option is particularly useful in the case of manual journal entries that are not based on a financial document (e.g., salary payments). You can even link to an entry that has already been posted to the ledger. 
 
## To link a pending journal entry to a project or activity:

 

 1 .  Enter the Entry Journal form and retrieve the desired entry. 
 

 2 .  Enter the Itemized Entry sub-level form, move to the entry item that you want to link, and move to Full-Record Display Mode. 
 

 3 .  Click the Project tab and specify the desired Project Number . 
 

 4 .  To link to an activity, select the desired WBS Code . 
 
## To link a posted journal entry to a project or activity:

 

 1 .  Do one of the following: 
 

 ·              If you know the entry number, enter the Entry Revisions form and retrieve the desired entry. Then enter the Itemized Revisions sub-level form and move to the entry item that you want to link (usually the line for the income or expense account). 
 

 ·              Otherwise, enter the Entry Item Revisions form and retrieve the desired entry item (e.g., by date, income/expense account, budget item). 
 

 2 .  Select the desired Project Number . 
 

 3 .  To link to an activity, select the desired WBS Code .
