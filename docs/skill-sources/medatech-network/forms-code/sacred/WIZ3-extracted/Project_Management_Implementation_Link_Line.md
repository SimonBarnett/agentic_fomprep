# To link an item to a project or a project activity:

 

 1 .  Enter the appropriate form and retrieve the document whose line item(s) you want to link to a project. 
 

 2 .  Enter the document's itemization sub-level form; move to the line that you want to link to a project/activity. 
 

 3 .  Enter the Projects/Accounts sub-level form. 
 

 4 .  Select the desired Project Number . The default project account appears automatically. 
 

 5 .  If necessary, change the account against which the present transaction will be debited/credited. 
 

 6 .  If you want to link the item to an activity, select the WBS Code of the desired activity. Change the activity's Percent Completed , if desired.
 Note: To revise the Activity Status , move to the Activity ID column and press F6 , then make the revision in the form that opens. Finally, press Esc to return to Projects/Accounts .
