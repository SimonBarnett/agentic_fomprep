# Recording Project Implementation

 

Once work has begun on the project, employees working on the project can report the work hours they have devoted to the project, as well as any travel expenses incurred. 
 

Inventory transactions are reported to a project by linking the transaction documents to the project or one of its activities. You can also link journal entries to a project or activity directly in the entry journal; thus, even expenses recorded directly in the journal can be added to the calculation of project and activity costs. 
 

When a substantial amount of work on the activity has been completed, you can record this by designating the percentage completed. You can also track the status of a project or activity. 
 
## What do you want to do?

 

 Report work hours and travel expenses for a project 
 

 Link inventory transactions and other documents to a project/activity 
 

 Link a journal entry to a project 
 

 Track the progress of work on a project
