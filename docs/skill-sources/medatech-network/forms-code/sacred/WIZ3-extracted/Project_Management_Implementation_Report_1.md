# Reporting Work Hours and Travel Expenses

 

 Priority allows you to report the labor invested in a project/activity, including travel time and mileage, as well as any miscellaneous expenses incurred while working on the project (e.g., meals, hotel accommodations). The costs of the reported labor and expenses are added automatically to the project/activity costs. 
 

The items you report will only be automatically billed if they are flagged as billable. 
 

You can report labor and expenses for a project in the main form Reports of Project Hrs/Expenses , as well as by project activity (using the Reports of Project Hrs/Expenses sub-level of the Project Activities form) or task (using the Reports of Project Hrs/Expenses sub-level of the Tasks form). All reports made to a specific project can be easily viewed and revised in the Reports of Project Hrs/Expenses sub-level of the Projects form. 
 
## Notes:

 

 ·        The instructions provided in this wizard for reporting in the main Reports of Project Hrs/Expenses form are equally valid for either of the sub-level report forms. Enter any of these forms and continue as directed. 
 

 ·        You can also load project reporting data from an external application, and review and/or modify these data in the Reports of Project Hrs/Expenses form. For further information on loading data from external sources, see the Data Migration Wizard . 
 

 ·        When using the sub-level of the Tasks form to report project hours/expenses, move to Full-Record Display Mode (which is more convenient for data entry). 
 

 ·        Reported parts are automatically flagged as billable if the part family they belong to is so defined (in the Part Families form). 
 

 ·        Click to define mileage and travel time defaults for the project , if you have not already done so.
