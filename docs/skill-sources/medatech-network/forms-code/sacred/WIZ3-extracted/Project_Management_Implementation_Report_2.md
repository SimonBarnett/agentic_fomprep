# To report work hours and travel expenses:

 

 1 .  Enter the Reports of Project Hrs/Expenses form. 
 

 2 .  Record the Date the work was performed. Your username and default work hour part will appear automatically, in the Employee and Part No. columns, respectively. 
 Note: If you are filing a report for someone else, you can change the username (and with it the default work hour part) accordingly. 
 

 3 .  If you were assigned a default project, the Project No. appears automatically. Otherwise, specify the project to which you are reporting. 
 

 4 .  If the hours were devoted to a specific project activity, designate its WBS Code . 
 

 5 .  Check In the Part No. column that the work hour part is correct. If you are reporting a miscellaneous expense, specify its number in this column and revise its Description , if necessary. 
 

 6 .  Click the References tab. If the project is managed at different customer sites, choose the Site at which the work was carried out. This is important for calculating travel time and mileage.
 Tip: Click to define a new project site . 
 

 7 .  If you are reporting hours based on a sales order, specify the Order and line number.
 Note: By default, once you report the quantity of project hours specified in the sales order, that order is closed automatically. Click to prevent this from happening.
