# Tracking the Progress of Work on a Project

 

You can use the Status column in the Projects form to indicate the current stage of a project. You can also assign a status to each project activity. To track the progress of a project, you can record the percent completed for each activity. You can also view a history of all the statuses and percentages of completion that have been recorded for a project or a project activity. 
 
## Notes:

 

 ·        When you record 100% completion for a milestone activity, any payment linked to that activity is automatically freed for billing. 
 

 ·        Activity status and percent completed can be changed when linking a document item (e.g., sales order item, vendor invoice item, GRV item) to a project activity.
