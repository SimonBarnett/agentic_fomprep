## Project and Project Activity Tracking

 

You can maintain statuses and assigned users for projects and project activities, and you can record an activity's percentage of completion. 
 
## To revise the project status:

 

 1 .  Enter the Projects form. 
 

 2 .  Retrieve the project in question and update its Status .
 Note: The user assigned to the project is the Project Manager . 
 
## To revise an activity's status, assigned user and/or percentage of completion:

 

 1 .  Enter the Project Activities form. 
 

 2 .  Retrieve the activity in question and update the relevant columns. 
 Notes: 
 

 ·              The user assigned to a project activity is the Owner . 
 

 ·              If you record 100% completion of a given activity, any payment linked to that activity is automatically freed for billing. 
 
## To view a history of statuses and assigned users (for an entire project or specific activities):

 

 ·        Enter the History of Statuses sub-level form.
