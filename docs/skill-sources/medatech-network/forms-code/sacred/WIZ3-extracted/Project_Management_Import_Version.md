# Importing a Planning Version from a Data File

 

You can import items from a planning version recorded in another installation of Priority , via a data file created in that installation. 
 
## To import a planning version:

 

 1 .  Enter the Projects form and retrieve the desired project. 
 

 2 .  Enter the Planning Versions sub-level form and open a new planning version. 
 

 3 .  In the MS Project File column, browse to the source data file. 
 

 4 .  Select Download Project Plan from the list of Direct Activations .
