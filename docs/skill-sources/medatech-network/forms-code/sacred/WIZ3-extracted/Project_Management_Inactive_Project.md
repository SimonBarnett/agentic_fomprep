# Making a Project Inactive

 

To make a project inactive, simply change its status to Final . Such a project will not appear in Choose lists and cannot be recorded in transaction documents. 
 

When the Final status is assigned, the system checks whether the project in question is linked to any open documents or tasks or has any inventory. If it does, a warning message is generated. 
 
## Note:

 

Alternatively, you can assign the project any new status defined for an Inactive Project . Click to define statuses.
