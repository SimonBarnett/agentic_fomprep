# Preparing Invoices for Projects

 

 Priority allows you to prepare multi-shipment and pro forma invoices for the project automatically. The project customer is billed for: 
 

 ·        Project payments that are due and authorized for billing 
 

 ·        Billable project hour reports (reported work hours and expenses) 
 

 ·        Billable service calls for the project 
 

 ·        Payments that are due for service contracts for the project 
 

 ·        In the case of multi-shipment invoices, billable shipments to the project 
 
## Note: 

 

The number of invoices that are prepared for each customer depends on the value of the OneInvPerPrj constant. Click for further information and/or to change the constant value . 
 
## To prepare one or more multi-shipment invoices:

 

 ·        Run the Prepare Invoices program. 
 Note: For detailed instructions, run the Customer Invoices Wizard . 
 
## To prepare one or more pro forma invoices:

 

 ·        Run the Prepare Pro Forma Invoices program. 
 Note: For detailed instructions, run the Cash-Based Accounting Wizard .
