# Working with the Project Management Module

 

If you have just started working with the module, you should begin by defining project management parameters. After the module is set up, you can open a new project, define parameters specific to the project (e.g., ledger accounts, warehouses, travel costs), import the project plan from MS-Project (or do the planning in Priority ), and begin recording project work. 
 
## What do you want to do?

 

 Set up the Project Management module 
 

 Open a new project 
 

 Plan the project 
 

 Prepare project purchases 
 

 Report project implementation 
 

 Record payment installments for a project 
 

 Prepare invoices for one or more projects 
 

 Open a service contract for a project 
 

 View project cost, revenue and profit 
 

 Make a project inactive
