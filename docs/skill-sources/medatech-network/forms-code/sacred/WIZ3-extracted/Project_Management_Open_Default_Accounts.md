# To assign default accounts to a project:

 

 1 .  Enter the Accounts for Projects form. 
 

 2 .  Select the desired Project Number . 
 

 3 .  Choose the project's default Income Account and Expense Account . 
 
## Note:

 

You can use this form to assign the project a Profit Center , as well.
