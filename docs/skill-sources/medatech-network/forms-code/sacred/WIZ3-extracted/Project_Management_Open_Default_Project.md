# Setting Up the Default Project for Users

 

You can assign the new project as the default project for users that will be working on it. This will cause the project number to appear automatically when the users open work hour reports, though it may be revised. 
 
## To assign a default project:

 

 1 .  Enter the Personnel File form and retrieve the desired user. 
 

 2 .  Enter the Company-Specific Information sub-level form. 
 

 3 .  In the Project column, specify the project number.
