# Defining a Default Purchasing Method

 

Purchase demands and purchase orders can be opened automatically for materials required for project activities. You can define a default purchasing method for all materials in the project, which can be revised as needed for individual parts. 
 
## To define the default purchasing method:

 

 1 .  If the project is not already open, enter the Projects form and retrieve the new project. 
 

 2 .  Click the Additional Details tab. In the Purch for Project column, do one of the following: 
 

 ·              Specify D if you are generally required to open purchase demands before you can order materials. 
 

 ·              Specify O if you generally order materials without requisitioning them. 
 

 ·              Leave the column blank if you do not generally purchase materials specially for the project.
