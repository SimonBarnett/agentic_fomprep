# Setting Up Mileage and Travel Time

 

When reporting labor performed for a project, you can also specify the necessary travel time and mileage. 
 

If you specify a project site for the report, the default travel time and mileage defined for that site appear automatically. Otherwise, the general project defaults appear. 
 
## Note: 

 

When you open a project, the travel time and mileage values defined for the customer are filled in automatically, but can be revised. 
 

 To define the customer ' s default mileage and travel time: 
 

 1 .  Enter the Financ. Parameters for Customers form and retrieve the customer in question. 
 

 2 .  Click the Charges tab and specify the Miles to Charge and the Travel Time to Charge . 
 
## Note:

 

These values will serve as defaults for all future projects and service calls you open for this customer.
