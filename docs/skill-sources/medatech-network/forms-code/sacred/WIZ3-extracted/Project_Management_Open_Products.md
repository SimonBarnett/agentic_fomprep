# Recording the Finished Products for the Project

 

In order to determine the final price of a project, you need to list and price its finished products. This can be done automatically, by copying the order items from specific sales orders into the project, or manually. After the products are listed, you need to record project information for them. 
 
## What do you want to do?

 

 Copy sales order items to the project 
 

 Record finished products manually
