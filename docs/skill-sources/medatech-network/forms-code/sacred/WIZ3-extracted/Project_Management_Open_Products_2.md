# To copy sales order items to a project's list of finished products:

 

 1 .  Enter the Sales Orders form and retrieve the order in question.
 Note: This order must already be linked to the project. 
 

 2 .  Select Add Order Items to Project from the list of Direct Activations . 
 

 3 .  Repeat the above for any other order whose items you want to add to the project. 
 

 4 .  To view results, enter the Projects form, retrieve the project in question and enter the Finished Products sub-level form.
 Notes: 
 

 ·              You can also add parts to the form manually, as desired. 
 

 ·              Records in this form do not affect the part's inventory level.
