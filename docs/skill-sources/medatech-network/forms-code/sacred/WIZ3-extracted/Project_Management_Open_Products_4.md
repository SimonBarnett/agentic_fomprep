# To record project information for the products:

 

 1 .  If the Unit Price appears automatically, check that it is correct; otherwise, fill it in. 
 

 2 .  Specify the part's Installation Date , if this information is available. 
 

 3 .  Check that the End of Warranty date is correct. 
 

 4 .  If you want to open a service contract for the project automatically, specify either the Prorate Service Charge or the Flat Service Rate .
