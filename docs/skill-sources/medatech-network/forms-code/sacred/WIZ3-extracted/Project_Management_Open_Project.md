Project Management - Opening a New Project 
 
 
- 
 
 
 
# To open a new project:

 

 1 .  Enter the Projects form. 
 

 2 .  In the Customer Number column, select the customer for which you are opening the project. The Customer Name will then appear automatically. 
 

 3 .  Record a Project Description . When you leave the column, Priority will assign a Project Number automatically. 
 

 4 .  Select the Project Manager . 
 

 5 .  Click the Details tab and select the Project Type . 
 

 6 .  Select the customer Contact for this project. 
 

 7 .  Click the Additional Details tab. In the Months Under Warranty column, record the default number of months the final products of the project are to be under warranty after their installation. 
 

 8 .  If you want a specific price list to be attached to the project, select it in the Price List column. 
 

 9 .  Fill in any other desired information (e.g., Additional Classification , Project Supervisor , Details ). 
 

 10 .  If you have an external file that pertains to the project (e.g., a design spec), you can attach it to the project using the Attachments sub-level form.
