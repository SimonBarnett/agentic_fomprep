# Defining Project Sites

 

 1 .  If the project is not already open, enter the Projects form and retrieve the new project. 
 

 2 .  Move to the Project Sites sub-level form. 
 

 3 .  List the project sites.
 Note: The Choose list includes all sites defined for the project's customer. To define a new customer site, enter the Customers form, retrieve the customer, and record the new site in the Customer Sites sub-level form.
