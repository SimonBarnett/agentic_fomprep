# Defining Technical Specifications

 

It is often necessary to impose certain technical constraints on a SOW item or on the final product of a project activity. For example, you may want to limit the size of an executable file or designate a minimum resistor capacity. Priority allows you to define any number of technical specifications for this purpose (e.g., Megabytes, Volts), and assign a permitted range and interval of values for each spec. 
 
## To define technical specifications:

 

 1 .  Enter the Technical Specifications form. 
 

 2 .  For each specification, record a name and description. 
 

 3 .  In the Minimum Value and Maximum Value columns, specify the lowest and highest values permitted for this spec. 
 

 4 .  If applicable, specify the Increment in which values can be assigned to this spec. 
 

 5 .  Specify the Unit in which the spec is measured.
