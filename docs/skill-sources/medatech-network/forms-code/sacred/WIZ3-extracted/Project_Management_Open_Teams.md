# Defining Project Teams

 

 1 .  If the project is not already open, enter the Projects form and retrieve the new project. 
 

 2 .  Move to the Project Teams sub-level form. 
 

 3 .  For each project team, record a Team Name and select a team leader in the Leader ' s Employee ID column. 
 

 4 .  If the team will always be assigned as a whole, flag the All Team Members column; if team members are individually assigned, leave the column blank. 
 

 5 .  If you know who the team members are, list them in the Project Team Members sub-level form.
 Note: You can update the members of the team as the planning phase progresses. If you are working with MS-Project data, human resources for activities are updated each type you import the MS-Project file, in keeping with the latest definition of the team.
