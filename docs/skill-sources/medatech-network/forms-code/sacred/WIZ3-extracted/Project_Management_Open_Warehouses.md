# Assigning Warehouses to a Project

 

By assigning a warehouse to a project, you ensure that inventory charges against the project are calculated correctly. Explanation . 
 
## To assign a warehouse to a project:

 

 1 .  Enter the Warehouses form. 
 

 2 .  Retrieve any warehouse you wish to assign to the project.
 Tip : To define a new warehouse, run the Open a Warehouse Wizard . 
 

 3 .  Click the Project tab and specify the Project Number . 
 

 4 .  If this is the project's main warehouse, flag the Main Project Warehs column.
