# Planning the Project

 

Project planning includes: 
 

 ·        Recording customer objectives in a SOW document 
 

 ·        Defining project activities 
 

 ·        Scheduling activities and assigning employees 
 

 ·        Planning material requirements (i.e., purchases) for each activity. 
 

Begin by recording your customer's objectives in a Scope of Work (SOW) document . This document, which may be revised as the project progresses, can serve as the basis of your project plan. 
 

The project plan is the central nervous system of your project. It consists of a hierarchical list of activities and sub-activities, representing specific goals to be achieved in order to complete the project. 
 

Each activity and sub-activity is automatically assigned a unique activity ID. You also assign it a WBS code , which indicates its place in the hierarchy. You can designate certain activities as milestones , which are linked to customer payments. 
 

By matching the hierarchy of the project plan to that of the SOW document, you can link activities to SOW items, and even generate sub-activities automatically from sub-items.
