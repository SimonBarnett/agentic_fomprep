Project Management - Project Planning.2 
 
 
- 
 
 
 

Once you have defined an activity, you can plan the materials and human resources required to complete it. The planned cost of the activity is calculated automatically, according to the total costs of its sub-activities. 
 

Direct manual revision of the project plan in Priority is usually only practical in the case of small projects that do not involve working with MS-Project files. In most cases, the project plan is created and maintained via planning versions . 
 

Using versions, you can draft extensive revisions that do not immediately alter the project plan. When a new version is fully authorized, you can run a program that puts it into effect , at which point it replaces the current version in the project plan. To protect the integrity of the project plan, you can restrict all updates of planning data to this method, thus preventing any direct revisions in the project plan itself. 
 

One of the important advantages of working with planning versions is that you can create and update versions with data imported into Priority from MS-Project files (and export a planning version into an MS-Project file). It should also be noted that sub-activities can only be generated by sub-items (recorded in a linked SOW document) in a planning version. 
 

If you are working directly in the Priority project plan, you can save planning versions as backups of the project plan at various stages. Furthermore, you can switch over at any time to working with planning versions.
