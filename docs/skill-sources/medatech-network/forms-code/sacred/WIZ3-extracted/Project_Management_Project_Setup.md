# Setting Up the Project

 

Before you can begin working on the new project, you need to define the relevant project parameters.

 Define the project ' s finished products 
 

 Define project sites 
 

 Define project teams 
 

 Define a default purchasing method for the project 
 

 Define default income and expense accounts for the project 
 

 Define project warehouses 
 

 Define a default project for users 
 

 Define default mileage and travel time for project hour reports 
 

 Define technical specifications required for the project
