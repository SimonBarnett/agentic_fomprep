# Preparing Purchase Demands

 

You can automatically prepare purchase demands for the planned materials (i.e., the parts listed in the BOM for Activity form) of a project. Purchase demands are opened only for parts that are: 
 

 ·        Flagged for purchase demands AND 
 

 ·        Authorized for purchase. 
 
## To automatically prepare purchase demands for a project:

 

 ·        Run the Open Purch Demands for Projects program. The prepared demand documents are automatically linked to the project activity in question.
