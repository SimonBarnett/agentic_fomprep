# Preparing Purchase Orders

 

You can automatically prepare purchase orders for the planned materials (i.e., the parts listed in the BOM for Activity form) of a project. Purchase orders are opened only for parts that are: 
 

 ·              Flagged for purchase orders AND 
 

 ·              Authorized for purchase. 
 

 To automatically prepare purchase orders for a project: 
 

 ·        Run the Open Purch Orders for Projects program. The prepared purchase orders are automatically linked to the project activity in question. 
 
## Note:

 

The program will open one purchase order for all parts supplied by the same vendor. The project manager will receive an automatic e-mail message for every order that the program opens.
