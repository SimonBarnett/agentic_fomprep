# To copy an existing SOW document:

 

 1 .  Enter the Scope of Work (SOW) form, and retrieve the SOW document that you want to copy. 
 

 2 .  Select Copy SOW Document from the list of Direct Activations . Specify the customer for which you are copying the document and record a description for the new copy. 
 

 3 .  A new SOW document will open, containing the same contents as the current version of the original document. The Document Number is filled in automatically. 
 

 4 .  In the Project Number column, specify the project to which the SOW document applies. 
 

 5 .  Click the Details tab, and select a customer Contact for this document.
 Tip: To define a new contact for the customer, use the Customer Contacts form, sub-level of the Customers form. 
 

 6 .  Record additional details, as needed (e.g., Document Type , Additional Classification , Details ). 
 

 7 .  If there is an external file that pertains to this document, use the Attachments sub-level form to attach it to the document. 
 

 8 .  Enter the SOW Items sub-level form and make any desired revisions to the document items. If necessary, enter the Item Remarks sub-level form and revise the remarks for a given item.
