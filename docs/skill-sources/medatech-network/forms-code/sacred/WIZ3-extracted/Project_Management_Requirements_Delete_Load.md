# Canceling the Word File Load

 

If the SOW document was not properly loaded from Word (e.g., there were errors in the format of the file), you can run a program that will delete all loaded items. You can then reload the Word file after making the needed corrections. 
 
## Notes:

 

 ·        You cannot delete loaded SOW items once work has begun on them (e.g., if remarks, a response or planned times have been recorded). In such a case, you must manually delete the added information before running the program. 
 

 ·        The program will not delete saved versions of the SOW document. 
 
## To cancel the load:

 

 ·        From the upper-level form, select Undo MS-Word File Load from the list of Direct Activations .
