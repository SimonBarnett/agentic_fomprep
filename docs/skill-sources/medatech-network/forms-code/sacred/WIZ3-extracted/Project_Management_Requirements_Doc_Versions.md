# Maintaining Versions of SOW Documents

 

 Priority allows you to save versions of a SOW document. You should save a version before making significant changes to the document, to serve as a backup. Once a document has different versions, you can compare the remarks, response and planned hours recorded for each item in the current version with those in a previous one. You can also view all changes made to responses and details for a given item in the current version. 
 
## Note: 

 

Click to save and/or compare versions of a specific remark within a SOW document or one of its versions. 
 
## To save a document version:

 

 1 .  Enter the Scope of Work (SOW) form and retrieve the desired document. 
 

 2 .  Select Save Version from the list of Direct Activations . A new version number will appear in the Version No. column, and a record will open for the new version in the Previous Versions sub-level form . 
 
## To compare versions:

 

 ·        To compare remarks and responses in two designated versions, run the Compare SOW Versions report. 
 

 ·        To compare responses in multiple versions, run the Track Changes in Response report. 
 

 ·        To compare planned hours in two designated versions, open the Scope of Work (SOW) form and retrieve the SOW document in question. Then select Track Changes in Planned Hours from the list of Direct Activations . 
 
## To view changes in responses and details for a given item in the current version:

 

 1 .  Enter the Scope of Work (SOW) form and retrieve the SOW document in question. 
 

 2 .  Enter the SOW Items sub-level form and move to the item in question. 
 

 3 .  Enter the History of Changes sub-level form.
