# Exporting SOW Items to a Data File

 

You can export the items in a SOW document into an external data file, which can then be loaded into a SOW document in another installation of Priority . 
 
## To export a SOW item:

 

 1 .  Enter the Scope of Work (SOW) form and retrieve the desired SOW document. 
 

 2 .  Click the Planning tab. In the SOW File column, record the full path and filename to which the data will be exported.
 Tip: You can define a non-existent file and the system will create it. 
 

 3 .  Select Upload SOW Document from the list of Direct Activations .
