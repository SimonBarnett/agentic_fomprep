# Importing SOW Items from a Data File

 

You can import items from a SOW document recorded in another installation of Priority , via a data file created in that installation. 
 
## To import a SOW item:

 

 1 .  Enter the Scope of Work (SOW) form and retrieve the desired SOW document. 
 

 2 .  Click the Planning tab. In the SOW File column, browse to the relevant data file. 
 

 3 .  Select Download SOW Document from the list of Direct Activations . If items are already recorded in the current SOW document, the items in the data file are added to them.
