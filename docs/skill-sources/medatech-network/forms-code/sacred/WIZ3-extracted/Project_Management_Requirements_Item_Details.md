# Additional Details

 

 Tip: 
 

To facilitate the recording of details, move to Full-Record Display Mode in the SOW Items form. 
 

 1 .  If desired, select an item Status ( Details tab). 
 

 2 .  If an employee has been assigned responsibility for the item, select his/her username in the Owner column. 
 

 3 .  If the item is based on another item recorded in an earlier SOW document (e.g., for a similar project), click the Based on SOW tab and fill in the details of the original document and item. 
 

 4 .  To attach an external file to the SOW item, use the Attachments sub-level. 
 

 5 .  If you want this content to always appear in the Open To-Do Items per Project and Print Detailed Response reports, even when those reports are restricted to Flagged Lines Only , flag the Display in Printout column. 
 

 6 .  To record technical specifications for the item, use the Technical Specs for SOW sub-level form.
