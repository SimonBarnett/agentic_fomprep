# Scope of Work (SOW) Documents

 

Before you begin planning a project, you can list your customer's objectives in a SOW document. This document consists of a numbered hierarchy of items and sub-items, which can include extensive remarks explaining each. Example. 
 

During project planning, you can link each activity to the SOW item it is intended to fulfill. If you are working with planning versions, you can then create sub-activities automatically from the sub-levels of the linked SOW document. 
 

SOW documents can be updated by importing Word files provided by the customer. You can also maintain versions of each SOW document, as well as versions of the remarks recorded for individual SOW items.
