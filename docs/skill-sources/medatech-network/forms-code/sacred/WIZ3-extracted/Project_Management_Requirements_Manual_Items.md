# Itemizing a SOW Document Manually

 

Each SOW item is identified by a number and description. A more detailed remark about each item is recorded in a sub-level form; these remarks can be saved as versions, for future comparison. 
 

Record items in outline format; that is, in a hierarchy of levels and sub-levels. Example. 
 
## To itemize the SOW document manually:

 

 1 .  Enter the Scope of Work (SOW) form and retrieve the desired document. 
 

 2 .  Enter the SOW Items sub-level form. 
 

 3 .  For each SOW item and sub-item, record a SOW Item in outline format (e.g., 1, 1.1, 1.1.1) and a SOW Description . 
 

 4 .  Enter the Item Remarks sub-level form and record a detailed description of the item. Return to the SOW Items form.
