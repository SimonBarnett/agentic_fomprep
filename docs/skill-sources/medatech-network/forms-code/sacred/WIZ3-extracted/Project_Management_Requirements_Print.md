# Printing a SOW Document

 

You can print a SOW document by Direct Activation or from the menu. The program allows you to print an entire document or any portion of it (by indicating the number of the first and last SOW item to be printed). If you flagged SOW lines for printing in the SOW Items sub-level form, you can choose to print only those lines. 
 
## To print a batch of SOW documents:

 

 ·        Run the Print Scope of Work (SOW) program. 
 
## To print a single SOW document:

 

 1 .  Enter the Scope of Work (SOW) form and retrieve the SOW document in question. 
 

 2 .  Select Print Scope of Work (SOW) from the list of Direct Activations .
