# Maintaining Versions of Item Remarks

 

 Priority allows you to save versions of an item's remarks within a SOW document or version. You should save a version before making significant changes to the text, to serve as a backup. Once the remarks for a given item have different versions, you can run a report that compares them. 
 
## Note: 

 

Click to save and/or compare versions of the entire SOW document (i.e., all its remarks) within a SOW document or one of its versions. 
 
## To save a version of an item's remarks:

 

 1 .  Enter the Scope of Work (SOW) form and retrieve the desired document. 
 

 2 .  Enter the SOW Items sub-level form and move to the desired item. 
 

 3 .  Select Save Remarks for Current Date from the list of Direct Activations . A record will open for the new version in the Saved Remarks by Date sub-level form. 
 
## To compare versions of an item's remarks:

 

 ·        Move to the desired item in the SOW Items form and select Track Remark Changes by Date from the list of Direct Activations OR 
 

 ·        Run the Track Remark Changes by SOW Date report.
