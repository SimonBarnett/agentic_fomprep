# Itemizing a SOW Document from a Word File

 

You can import SOW items from a Word file prepared by your customer, containing the numbered hierarchy of item descriptions and remarks. Remarks are usually detailed descriptions of the items, which can be saved as versions, for future comparison. Additional details (e.g., status) can be added after the items are imported. 
 
## Formatting SOW Items in Word

 

In order for Priority to load SOW items from a Word document, your customer must adhere to the following format when creating the document: 
 

 ·        The items must be numbered automatically in outline format. 
 

 ·        The document must not include any unnumbered paragraphs (including blank lines). 
 

 ·        Each item must appear in a separate paragraph. 
 

 ·        The first sentence should consist of a brief description, followed by a period. This sentence will appear in the SOW Description column of the SOW Items sub-level form. All following text will appear in the Item Remarks sub-level of the SOW Items form, for which versions may be maintained. 
 
## Example:

 

9.1 Printed User Guide. The product should be accompanied by a printed user guide in booklet form, sized to fit into the package. The guide should include installation instructions and a troubleshooting section.
