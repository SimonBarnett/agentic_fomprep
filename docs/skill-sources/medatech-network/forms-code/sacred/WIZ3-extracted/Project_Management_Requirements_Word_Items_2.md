# To load the Word file:

 

 1 .  Enter the Scope of Work (SOW) form and retrieve the desired document. 
 

 2 .  Click the Planning tab, and specify the full name and path of the MS Word File .
 Tip: Click the attachment icon to browse to the desired document. Once the path has been loaded, the Word icon appears. If the path is too long, the file will be rejected. 
 

 3 .  Select Load MS-Word File Into Document from the list of Direct Activations . The contents of the file are copied in outline form into the SOW Items sub-level form. 
 Note: The first sentence (up to the first period) is copied into the SOW Description column. All following text is copied into the Item Remarks sub-level form, for which versions can be maintained. 
 

 4 .  Enter the SOW Items and Item Remarks sub-level forms. Make sure that each item's description and remarks were properly loaded. 
 Tip: To save the remarks as they are before making any changes, select Save Remarks for Current Date from the list of Direct Activations . 
 
## Note:

 

Click if the document was not properly loaded (e.g., owing to errors in the format of the Word file).
