# Materials and Human Resource Planning 

 

Once you have imported activities and human resources, you can use Priority to plan the materials required for each activity. The costs of the required materials are added to the activity's planned costs. 
 

You can also fine tune the human resource plan (e.g., check the quantity of planned work hours, check costs, schedule workers).
