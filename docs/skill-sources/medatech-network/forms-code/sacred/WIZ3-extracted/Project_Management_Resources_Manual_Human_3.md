# Scheduling Employees 

 

In order to schedule employees, you need to open a task for them. This task will then generate an appointment in the calendar of each assigned employee. 
 
## To schedule employees:

 

 1 .  Enter the Tasks for Project Activity sub-level of the Project Planning form. 
 

 2 .  Record the main employee responsible for the activity in the Assigned to column.
 Tip: Use the parallel sub-level form, Calendar (All Users) , to view that person's existing schedule. 
 

 3 .  The Subject of the task, the employee's Start Date and End Date (and times) and the Customer Number are filled in automatically; revise as necessary. 
 

 4 .  Indicate the customer's Contact for this task. 
 

 5 .  If there are any additional employees scheduled to work on the activity at the same time , specify them in the Assigned User 2 and Assigned User 3 columns. 
 

 6 .  To schedule entire groups of employees to work together over the same dates, select them in the Group , Group 2 and Group 3 columns.
 Notes: 
 

 ·              You must be authorized to access the designated groups. If you do not have such authorization, consult your system manager. 
 

 ·              To define additional groups, use the Groups form. 
 
## Notes:

 

 ·        To view all tasks that have been opened for the project or one of its activities, select Tasks per Project or Tasks per Project Activity from the list of Direct Activations of the Projects form. 
 

 ·        For information on handling tasks and using the calendar, run the CRM Wizard . 
 

 ·        Click to return to the Planning Versions menu.
