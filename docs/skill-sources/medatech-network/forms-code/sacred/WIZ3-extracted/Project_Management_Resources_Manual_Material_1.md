# Material Planning 

 

Specify each activity's material requirements by designating the product of that activity. The child parts of that product are then automatically listed as requirements. If the product in question is of type R (i.e., a “buy item”), the list will include the part itself as well as any accessory parts defined for it. 
 

If an activity does not result in a final product, you can list its material requirements manually. 
 

The system calculates the cost of the required parts, and adds it to the activity's total planned cost. 
 
## Notes: 

 

 ·        If the product has work hour "parts" as child parts, they will also be listed as requirements. However, their cost is added to the human resources cost, rather than to the materials cost. 
 

 ·        To define a part and its bill of materials, run the Part Definition Wizard .
