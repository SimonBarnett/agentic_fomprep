# Setting Up Part-Time Assignment of Human Resources

 

By default, Priority takes into account part-time assignment of employees or teams to an activity (designated as a percentage of full-time when an employee is assigned, e.g., George[50%]). You can set up the system to ignore any designated percentages (e.g., when imported from MS-Project) and always assign employees or teams to activities on a full-time basis. 
 
## To set up the part-time assignment option:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SHrPercent constant and select the desired value.
