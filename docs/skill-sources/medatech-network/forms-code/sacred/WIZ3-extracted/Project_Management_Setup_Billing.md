# Setting Up Automatic Invoicing

 

The OneInvPerPrj constant determines how the Prepare Invoices program bills for projects. According to its value, the program will issue either: 
 

 ·        One invoice per project, OR 
 

 ·        One invoice per transaction type for each sales order linked to the project, (i.e., one invoice for all the project hour reports linked to an order, one invoice for all the project service calls linked to an order, etc.). OR 
 

 ·        Separate invoices for each transaction type. 
 Note: In this option, the billing of shipments (and returns) is also affected by the customer's Periodic Invoice definition (in the Financ. Parameters for Customers form). Explanation . 
 
## To define how projects will be billed:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Move to the OneInvPerPrj constant and select the desired value. 
 
## Note:

 

For complete details on invoice setups (which also affect invoices prepared for projects), see the Customer Invoices Wizard .
