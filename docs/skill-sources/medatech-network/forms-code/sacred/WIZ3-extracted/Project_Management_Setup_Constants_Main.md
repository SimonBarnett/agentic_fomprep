# Project Constants

 

User-defined constants govern a number of project defaults, which affect aspects of project planning, transaction recording and invoicing. 
 

Set the appropriate constants to determine: 
 

 Whether transaction documents are automatically linked to the customer ' s default project 
 

 Whether project activities are automatically renumbered when one is added or removed 
 

 Whether human resources assignment takes into account percentages of full-time 
 

 Whether company teams assigned to a project include the team leader 
 

 Whether reporting project hours to a sales order automatically closes the order 
 

 How automatic invoicing bills for projects 
 

 How expenses are distributed among sold parts in a project 
 

 How far back to retrieve reported project hours 
 

 Whether to include the cost of open order items in projected costs for the project 
 

 How material costs are calculated during project planning
