# Distributing Expenses Among Sold Parts in a Project

 

The SProjBurden constant determines whether a project's expenses (such as shipping) are distributed among sold parts, incorporating burden distribution, or whether the entire expense will be attached to the project, by means of a linked expense invoice. 
 
## To define how expenses will be distributed:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SProjBurden constant and select the desired value.
