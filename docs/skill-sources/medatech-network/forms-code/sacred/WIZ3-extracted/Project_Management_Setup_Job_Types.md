# Defining Job Types

 

You can facilitate the sorting of project hour reports by classifying the labor performed for a project into job types. Example . 
 
## To define job types:

 

 1 .  Enter the Job Types form. 
 

 2 .  For each job type you wish to define, record a code and a brief description. 
 
## Note:

 

You can add more job types later, as needed.
