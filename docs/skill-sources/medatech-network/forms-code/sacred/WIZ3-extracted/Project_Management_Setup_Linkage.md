# Setting Up Automatic Linkage

 

When a single project has been opened for a given customer, you can determine whether all documents opened for that customer are automatically linked to the default project, or whether the user decides which documents to link. 
 
## To set the constant that determines automatic linkage:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SLinkProject constant and select the desired value.
