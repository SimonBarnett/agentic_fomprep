# Setting Up the Project Management Module

 

If you are working with projects for the first time, you need to set the following parameters, which will apply to all projects opened in the system. 
 
## What do you want to do?

 

 Set up project constants 
 

 Define types of work hours and link them to employees 
 

 Define part families for parts produced in project work orders 
 

 Set up business processes (BPM) and statuses 
 

 Define project and SOW document types 
 

 Define job types
