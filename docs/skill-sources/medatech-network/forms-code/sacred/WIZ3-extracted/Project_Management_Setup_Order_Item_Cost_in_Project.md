# Including Order Item Cost in Projected Project Costs

 

The SProjOrdCost constant determines whether the cost of open order items will be taken into account when calculating projected costs for the project. 
 
## To include the cost of open order items:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SProjOrdCost constant and change its value to 1 . 
 
## Note:

 

This constant determines the system-wide default. You can override it for a particular order item when recording the order.
