# Closing Orders by Reporting Hours

 

You can determine whether or not to allow more project hours to be reported for a sales order than are specified in the order. In other words, you can prevent the system from automatically closing a sales order when the specified number of hours has been reported. 
 
## To determine whether project reports will automatically close a sales order:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SProjRepOrd constant and select the desired value.
