# Calculating Material Costs for Project Planning

 

The SPrjPlanCost constant determines whether the cost of materials used during project planning will be taken from the part's standard cost or its actual cost. Specifically, it determines the value that will be filled in in the Unit Cost column of the BOM for Activity form. 
 
## To determine how material costs are calculated for project planning:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SPrj Plan Cost constant and select the desired value.
