# Defining Part Families for Parts Produced in Project Work Orders

 

If you produce a part in a work order that is linked to a specific project, and the finished product is not stored in a project warehouse, you need to ensure that the product is not charged to the same project twice (e.g., once during production and once during shipping). This is done by assigning the manufactured part to a part family that has been defined for such parts. 
 
## Note:

 

Parts should only be assigned to such families if they are earmarked for the same project for which the work order was produced. Otherwise, they will not be charged to the project to which they are shipped. 
 
## To define a part family for project production:

 

 1 .  Enter the Part Families form and retrieve the desired part family.
 Tip: To define a new part family, run the Part Definition Wizard . 
 

 2 .  Flag the Production for Proj column.
