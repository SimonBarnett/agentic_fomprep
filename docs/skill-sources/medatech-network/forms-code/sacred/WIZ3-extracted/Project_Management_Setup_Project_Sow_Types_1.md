# Defining Project and SOW Document Types

 

You can classify projects by type and use additional classifications to further categorize your projects. Example . 
 

SOW documents can also be assigned types and additional classifications for multi-level classification. 
 

Finally, you can define a separate list of authorizers for the planning versions of each project type. When you assign a project a type, the respective version authorization list is copied automatically to every new planning version of that project. 
 
## To define project types:

 

 1 .  Enter the Project Types form. 
 

 2 .  For each type you wish to define, record a code and a brief description. 
 Tip: If you are working in a language other than English, and wish to run BI reports in English, record an English description as well. 
 

 3 .  Click to prepare a version authorization list for a new project type. 
 
## To define additional classifications for projects:

 

 1 .  Enter the Addit'l Project Classifications form. 
 

 2 .  For each additional classification you wish to define, record a code and a brief description.
