# Setting Up Automatic Renumbering

 

You can determine whether the WBS codes composing the numerical hierarchy of a project plan or planning version are automatically adjusted when an activity is added or removed. 
 
## To set the constant that determines automatic renumbering:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SWBSAutoNum constant and select the desired value.
