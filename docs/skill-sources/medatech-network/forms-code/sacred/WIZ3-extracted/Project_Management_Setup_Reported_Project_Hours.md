# Retrieving Reported Project Hours

 

The SRepDays constant determines how far back to begin retrieving records of reported project hours and expenses when viewing them from within the Projects form. 
 

For example, to automatically retrieve data for the past 45 days, set the constant to 45 (the default is 90). Whenever a user enters the Reports of Project Hrs/Expenses sub-level form, they will see all hours and expenses reported for this project within the last 45 days. 
 
## To determine how far back to begin the retrieval:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SRepDays constant and, in the Value column, specify the number of days back to retrieve reported hours.
