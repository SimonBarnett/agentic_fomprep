# Business Processes for Projects, Activities and SOW Documents

 

You set up business processes by defining statuses in BPM flow charts. 
 

There are several predefined statuses for projects, activities and SOW documents, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 
## To use the flow charts:

 

 ·        Run one of the following programs: 
 

 ·              BPM Flow Chart-Projects 
 

 ·              BPM Flow Chart-Proj. Activities 
 

 ·              BPM Flow Chart-SOW Documents 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter one of the following forms: 
 

 ·              Statuses for Projects 
 

 ·              Statuses for Activities 
 

 ·              Statuses for SOW Documents 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
