# Statuses for Planning Versions

 

There are several predefined statuses for project planning versions. While these statuses cannot be deleted, you can change their names and define additional statuses. Most important, you can define the properties of each status. 
 
## To update existing statuses:

 

 ·        Enter the Statuses for Planning Versions form. A list of statuses appears; revise them as necessary. 
 
## To define a new status:

 

 ·        On a new line, assign a new status name and define its attributes in the relevant columns. 
 
## Notes:

 

 ·        You cannot change the attributes of any version status flagged with Begin Authorization or Fully Authorized once they have been assigned to a planning version. 
 

 ·        You can add or revise statuses later, as needed.
