# To prepare a version authorization list:

 

 1 .  Enter the Version Authorization List sub-level form. 
 

 2 .  Open a line for each principal Authorizer and select the appropriate username. 
 

 3 .  If another user can replace a given authorizer for planning versions of this project type, select the appropriate username in the Alternate column.
 Note: The project manager can sign for any other authorizer. 
 

 4 .  In the Signature Order column, use numerical values to specify the order in which the authorizers will appear in the planning version. 
 Note: These values do not need to be consecutive.
