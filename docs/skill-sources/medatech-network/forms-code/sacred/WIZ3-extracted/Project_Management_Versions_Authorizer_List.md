Project Management - Planning Versions: Preparing an Authorizer List 
 
 
- 
 
 
 
# To prepare or revise a version authorizer list:

 

 1 .  Enter the Planning Version Authorizers sub-level form. 
 

 2 .  Open a line for each new principal authorizer and select the appropriate username in the Authorizer column. 
 

 3 .  If another user can replace the principal authorizer for this version, select the appropriate username in the Alternate column. 
 

 4 .  In the Signature Order column, use numerical values to specify the order in which the authorizers will appear. 
 Note: These values do not need to be consecutive.
