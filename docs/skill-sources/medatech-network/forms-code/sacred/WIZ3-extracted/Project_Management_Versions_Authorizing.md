# Authorizing a Planning Version

 

When a version is ready to be put into effect, initiate the authorization process by changing the version's status to one that allows authorization. 
 
## To authorize a version:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Enter the Planning Versions sub-level form and move to the desired version. 
 

 3 .  In the Version Status column, change the status to one that allows authorization (e.g., Auth. Begun ).
 Tip: Click to define additional statuses. 
 

 4 .  Direct each authorizer (or alternate, if necessary) to enter the Planning Version Authorizers sub-level of the planning version and flag the Authorized column on the appropriate line.
 Note: The project manager can sign for any other authorizer. 
 

 5 .  When all authorizer lines have been flagged, change the version status to Fully Auth. 
 
## Note:

 

Click to put the authorized version into effect.
