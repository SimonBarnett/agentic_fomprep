Project Management - Planning Versions: Deleting a Version 
 
 
- 
 
 
 
# To delete a planning version:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Enter the Planning Versions sub-level form and move to the version you want to delete. 
 

 3 .  Select Delete Version from the list of Direct Activations . 
 
## Note:

 

Any versions following the deleted version will retain their version numbers.
