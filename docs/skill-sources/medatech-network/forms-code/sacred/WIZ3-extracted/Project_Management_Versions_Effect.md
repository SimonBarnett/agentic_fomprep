# Putting a Planning Version into Effect

 

You update the actual project plan by putting the desired planning version into effect. You can only put into effect a planning version with a status flagged as Fully Authorized . 
 

 Note: 
 

Click to authorize the planning version . 
 
## To put a planning version into effect:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Enter the Planning Versions sub-level form and move to the version you want to put into effect. 
 

 3 .  Make sure that the version's status is one that allows it to be put into effect (i.e., flagged as Fully Authorized in the Statuses for Planning Versions form). 
 

 4 .  Select Put Planning Version Into Effect from the list of Direct Activations .
