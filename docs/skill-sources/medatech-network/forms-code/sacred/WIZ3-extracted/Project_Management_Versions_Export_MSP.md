# Exporting Data to MS-Project

 

When you export data to MS-Project, it is saved in a new file. That is, you cannot update an existing MS-Project file from the existing project plan in Priority . 
 
## To export the planning version currently in effect:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Select Send Planning to MS-Project from the list of Direct Activations . 
 
## To export a different planning version:

 

 1 .  Enter the Planning Versions sub-level form and move to the desired version. 
 

 2 .  Select Send Planning to MS-Project from the list of Direct Activations .
