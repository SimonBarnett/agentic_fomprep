# Importing Data from an MS-Project File

 
## Checking Resource Names

 

In order for the MS-Project data to be properly loaded, any resource you assign to an activity in MS-Project has to be the full name of an employee (as recorded in Priority ), his/her Priority username or the name of one of the project teams recorded in Priority . 
 
## Tip: 

 

Click if you have not yet created project teams or listed their members . 
 
## To check that the resource name in MS-Project is valid:

 

 1 .  If the resource is an employee, enter the Personnel File form. Retrieve the employee in question. Check that the resource name is identical to either the employee's full name or username. 
 

 2 .  If the resource is a team, enter the Projects form and retrieve the project in question. Enter the Project Teams sub-level form. Check that the team name is identical to the resource name.
