# To record project activities manually:

 

 1 .  Enter the Project Planning sub-level of the Planning Versions form and move to Full-Record Display Mode.
 Note: At any point in the following process, you can transfer responsibility for the activity to another employee, by specifying his/her username in the Owner column. 
 

 2 .  For each activity, record a WBS Code . 
 

 3 .  Record the activity's name in the Name of Activity column. 
 

 4 .  Record the activity's Start Date and End Date .
 Note: Make sure that the time range of a sub-activity does not deviate from the time range of its summary activity. 
 

 5 .  If the activity is a milestone , click the Details tab and flag the Milestone column. 
 

 6 .  To link an existing project to the activity as a sub-project, click the Subproject tab and specify the Subproject number. The cost and profit data of the sub-project will be included in calculations for this activity.
 Note: The sub-project must already be recorded in the Projects form. 
 

 7 .  To link the activity to a SOW item, click the SOW tab and specify the Document Number and SOW Item . 
 

 8 .  To create sub-activities automatically from a linked SOW item, select Copy Scope of Work from the list of Direct Activations .
 Notes: 
 

 ·              This is only possible when there are no existing sub-activities. 
 

 ·              To view the new sub-activities, retrieve all records in the form again. 
 

 9 .  If you have an external file that pertains to the activity, you can attach it to the activity using the Attachments sub-level form.
