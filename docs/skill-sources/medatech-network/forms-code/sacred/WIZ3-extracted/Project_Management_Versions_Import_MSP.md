# To import MS-Project data:

 

 1 .  In the MS Project File column, record the full name and path of the file. 
 

 2 .  Select Input MS-Project File Data from the list of Direct Activations . Data from the MS-Project file will be loaded into the MS-Project File Data sub-level form. 
 

 3 .  Enter the MS-Project File Data sub-level form and spot check the imported data. Then return to the Planning Versions form and select Check MS-Project Data from the list of Direct Activations for a more in-depth check.
 Note: If there are mistakes, correct them in MS-Project and re-import the file. 
 

 4 .  Once you are sure there are no errors, select Copy MS-Project Data to Plan from the list of Direct Activations . 
 

 5 .   Enter the Project Planning sub-level of the Planning Versions form to view the resulting project planning version. To revise a version activity, move to Full-Record Display Mode and move to the desired activity. 
 

 6 .  To link an existing project to the activity as a sub-project, click the Subproject tab and specify the Subproject number. The cost and profit data of the sub-project will be included in calculations for this activity. 
Note: The sub-project must already be recorded in the Projects form. 
 

 7 .  To link the activity to a SOW item, click the SOW tab and specify the Document Number and SOW Item . 
 

 8 .  To create sub-activities automatically from a linked SOW item, select Copy Scope of Work from the list of Direct Activations . 
 Notes: 
 

 ·              This is only possible when there are no existing sub-activities. 
 

 ·              To view the new sub-activities, retrieve all records in the form again.
