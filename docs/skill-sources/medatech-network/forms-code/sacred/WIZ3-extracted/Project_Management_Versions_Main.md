# Working With Planning Versions

 
## Before You Begin

 

 ·        To restrict all revision of the project plan to the authorization of planning versions (that is, to prevent direct revisions in the plan itself), click the Planning tab and flag the Update Versions Only column. 
 

 ·        To automatically update cumulative planned costs and work hours for a project any time the project plan is updated, click the Planning tab and flag the Automatic Cost Calc column. 
 
## What do you want to do?

 

 Create the first planning version 
 

 Update an existing planning version from an MS-Project file 
 

 Create a new planning version 
 

 Authorize a planning version 
 

 Put a planning version into effect 
 

 Export a planning version to MS-Project 
 

 Export a planning version to an external data file 
 

 Import a planning version f r o m an external data file 
 

 Print a planning version or version activities 
 

 Delete a planning version
