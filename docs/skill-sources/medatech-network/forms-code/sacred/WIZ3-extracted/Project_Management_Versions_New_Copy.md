Project Management - Planning Versions: Copying a Version 
 
 
- 
 
 
 
# To copy a previous version:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Enter the Planning Versions sub-level form. 
 

 3 .  Move to the version you want to copy and select Copy Planning Version from the list of Direct Activations . 
 

 4 .  Leave and reenter the Planning Versions form in order to view the new version. 
 

 5 .  If you have an external file that pertains to this version (e.g., a design spec), you can attach it to the version using the Attachments sub-level form. 
 

 6 .  If you have assigned the project a project type for which authorizers have been defined, the authorizer list appears automatically in the version's Planning Version Authorizers sub-level form, though it may be revised. Otherwise, you can define a list of authorizers for the new version .
