Project Management - Planning Versions: Importing a New Version MSP 
 
 
- 
 
 
 
# To import MS-Project Data into a new version:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Enter the Planning Versions sub-level form and open a new line. 
 

 3 .  Do one of the following: 
 

 ·              Specify a Date for the version. The next available number will appear automatically in the Version column. 
 

 ·              Record a Version number, followed by a Date . 
 

 4 .  Record any brief comments pertaining to the version in the Remark column. For more extensive comments, use the Planning Versions - Remarks sub-level form. 
 

 5 .  If you have assigned the project a project type for which authorizers have been defined, the authorizer list appears automatically in the version's Planning Version Authorizers sub-level form, though it may be revised. Otherwise, you can define a list of authorizers for the new version . 
 

 6 .  If you have an external file that pertains to this version (e.g., a design spec), you can attach it to the version using the Attachments sub-level form.
