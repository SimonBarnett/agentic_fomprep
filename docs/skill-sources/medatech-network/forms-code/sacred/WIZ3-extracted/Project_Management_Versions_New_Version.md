# Creating a New Planning Version

 

You can create a new planning version either by copying and revising a previous version, or by opening a new version in which to import updated data from an MS-Project file. 
 
## What do you want to do?

 

 Copy a previous version 
 

 Import updated MS-Project data into a new version
