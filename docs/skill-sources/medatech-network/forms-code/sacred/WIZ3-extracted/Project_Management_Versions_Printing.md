# Printing a Planning Version or Version Activity

 

You can print an entire planning version together with each activity's remarks, as well as specific activities and their remarks. 
 
## To print a planning version:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Enter the Planning Versions sub-level form and move to the version you want to print. 
 

 3 .  Select Project Version With Remarks from the list of Direct Activations . 
 
## To print the planning version in effect:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Select Print Planning Document or Project Planning With Remarks from the list of Direct Activations . 
 
## To print selected activities from a planning version:

 

 ·        Run the Project Planning With Remarks report for the desired project, version and activity.
 Tips: 
 

 ·              If you leave the Version input column empty, the version in effect is printed. 
 

 ·              Use a wildcard in the WBS Code or Name of Activity input column to print multiple activities (e.g., write 3* to print all activities with a WBS code beginning with "3.", write Init* to print all activities with names beginning with the string "Init").
