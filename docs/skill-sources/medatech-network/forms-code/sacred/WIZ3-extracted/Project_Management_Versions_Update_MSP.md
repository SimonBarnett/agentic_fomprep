# Updating an Existing Version from an MS-Project File

 

If you have made changes to the project plan in MS-Project, you should update the current planning version in Priority to reflect these changes. 
 
## Notes:

 

 ·        Any new activities that you have created in the Priority version will not be erased, but all other changes to the version will be overwritten by the update. Activities that exist only in Priority (i.e., were deleted in the MS-Project file or added in Priority ) will receive a Canceled status. 
 

 ·        Any changes in Priority to the makeup of project-specific teams will be taken into account in the updated plan. Make any necessary changes before re-loading the MS-Project file. 
 
## To update a planning version:

 

 1 .  Enter the Projects form and retrieve the project in question. 
 

 2 .  Enter the Planning Versions sub-level form and move to the desired version. 
 

 3 .  Make sure that the file name and path are correctly recorded in the MS Project File column. 
 

 4 .  Select Input MS-Project File Data from the list of Direct Activations . Data from the MS-Project file will be loaded into the MS-Project File Data sub-level form. 
 

 5 .  Enter the MS-Project File Data sub-level form and check that the data is correct. 
 

 6 .  Return to the Planning Versions form, and select Copy MS-Project Data to Plan from the list of Direct Activations . 
 

 7 .  Enter the Project Planning sub-level form to view the updated planning version. Use this form and its sub-levels to: 
 

 ·              Link any new activities to sub-projects 
 

 ·              Link any new activities to SOW items and create automatic sub-activities 
 

 ·              Record or revise material requirements 
 

 ·              Fine-tune the human resource plan. 
 

 Tip: Move to Full-Record Display Mode before revising a version activity.
