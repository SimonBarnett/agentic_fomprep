# Canceling a Final Vendor Invoice

 

If errors are discovered in a finalized invoice, you can create a new document with negative values, which cancels the original invoice and creates a reversing journal entry. 
 

There are three different options for dating the cancellation invoice and the reversing journal entry ( Transaction Date and Reference Date ). 
 

 ·        Option 1 : Invoice date and entry dates are the same as that of the original invoice. 
 

 ·        Option 2 : Invoice and entry are assigned a designated date. 
 

 ·        Option 3 : The entry's Transaction Date is assigned a designated date, while the invoice and the entry's Reference Date are assigned the original invoice date. 
 
## Before You Begin

 
## If you plan to use Option 2 or Option 3:

 

 1 .   Enter the Financial Documents form and move to the line for Vendor Invoice . 
 

 2 .   Ensure that the Canc. on Orig. Date column is properly defined. That is, make sure it is blank to use Option 2; make sure it is flagged to use Option 3. 
 
## To cancel a final invoice:

 

 1 .   Enter the Vendor Invoices form and retrieve the desired invoice. 
 

 2 .   Do one of the following: 
 

 ·              To use Option 1, select Cancel Document (Original Date) from the list of Direct Activations . 
 

 ·              To use Option 2 or 3, select Cancel Document For Date from the list of Direct Activations . 
 
## Notes:

 

 ·        You must be authorized to change the status of vendor invoices to Canceled . 
 

 ·        Click to return to the main screen .
