# PurchInv_Credit_Final_2

Purchase Invoices/Memos - Finalizing Credit Memos.2 
 
 
- 
 
 
 

The following instructions apply to credit memos recorded separately in the Multi-GRV Invoices form. 
 
## Before you begin:

 

 1 .  Enter the Multi-GRV Invoices form and retrieve the desired credit memo. 
 

 2 .  Click the Payment Info tab and make sure that the Transaction Date is correct. 
 

 3 .  Enter the Invoice - Add'l Details sub-level form. Make sure that the Entry Code is correct, as well as the code and number of the Original Invoice in which you were billed. 
 

 4 .  Return to the upper level form, click the References tab and check the memo's Status . You will only be able to finalize the memo if its current status allows for finalization (e.g., it is assigned the Approved status).
 Note: You must also be authorized to change the status of credit memos (and multi-GRV invoices) to Final . 
 
## To finalize the memo:

 

 ·        Select Finalize Invoice/Memo from the list of Direct Activations . 
 
## To finalize and print the memo:

 

 ·        Select Finalize & Print Invoice/Memo from the list of Direct Activations . 
 
## Note:

 

Click to return to the main screen .
