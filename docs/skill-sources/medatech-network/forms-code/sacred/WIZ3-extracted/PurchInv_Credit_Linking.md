# Linking a Vendor Return to a Credit Memo

 

You can link a vendor return document to a final credit memo (for example, if the memo was recorded and finalized before the goods were returned). 
 
## To link a return document to a memo:

 

 1 .  Enter the Link Invoices/Memos to Documents form and retrieve the desired return document. All returned items that have not yet been credited will appear. 
 

 2 .  For each returned item: 
 

 ·              specify in the Invoice Number column the memo in which the item is credited 
 

 ·              specify C in the Credit/Debit column and 
 

 ·              specify in the Inv. Line column the memo line on which it appears. 
 
## Notes:

 

 ·        Once all items in a return document have been linked to memos, the Credit ed column in the Returns to Vendor form is flagged. 
 

 ·        You can also link the return document in question to an existing multi-GRV invoice, by specifying the invoice number and specifying D in the Credit/Debit column. Returned part quantities will then appear in the invoice as negative values. 
 

 ·        Click to return to the main screen .
