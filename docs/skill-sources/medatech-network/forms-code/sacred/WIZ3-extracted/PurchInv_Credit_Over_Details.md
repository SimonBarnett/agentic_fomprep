# Additional Details

 

 1 .  Move to the Invoice - Add'l Details sub-level form. 
 

 2 .  In the Code – Orig. Inv. column, enter the code of the original invoice in which you were overcharged. 
 

 3 .  In the Original Invoice column, press F6 to open the invoice form and retrieve the invoice in question. Then press F8 to copy its number back into this column. The memo will be reconciled automatically with the original invoice. 
 

 4 .  Return to the upper-level form. Click the References tab and enter a brief remark regarding this memo in the Details column. 
 

 5 .  If you want to record remarks pertaining to this memo that will appear in the printout, move to the Invoice/Memo - Remarks sub-level form and record your remarks. 
 

 6 .  If the memo needs to be checked, return to the Multi-GRV Invoices upper-level form and assign it the Checking status (in the References tab). In the Assigned to column, specify the username of the person who is responsible for checking the document. The memo cannot be finalized until this status is changed. 
 Tip: You can define work flow rules so that the assigned user changes automatically when the status is assigned.
