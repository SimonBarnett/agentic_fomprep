# Recording Credit for Returned Goods

 

There are several methods of recording credit for returned goods, depending on whether you require a separate credit memo, or record credit together with billed items in an invoice. 
 

Credit memos can only be recorded if the goods were originally billed in a multi-GRV invoice. 
 
## What do you want to do?

 

 Record a credit memo 
 

 Record credit in a multi-GRV invoice 
 

 Record credit in a vendor invoice
