# Recording Credit for Returned Goods in a Multi-GRV Invoice

 

You can credit returns in a multi-GRV invoice that also bills for received goods. The cost of the returned goods is deducted from the total price of the invoice. 
 

The following instructions concern the crediting of returns recorded in a Returns to Vendor form. If you are opening a multi-GRV invoice based on GRVs that also record returns (using negative quantities), the returned goods are itemized automatically from the GRV in the same manner as the received goods. Click if the returned goods were recorded in a GRV . 
 
## Before you begin:

 

 ·        Make sure the return has been recorded in Priority in a Returns to Vendor form. 
 
## Note:

 

The return document must be finalized before it can be linked to a credit memo. For more information, run the Receipt/Return of Goods Wizard . 
 
## To record credit in the invoice:

 

 1 .  Enter the Multi-GRV Invoices form and retrieve a pending multi-GRV invoice recorded for the vendor that is crediting you. 
 

 2 .  Enter the Return Documents for Invoice sub-level form and specify the return documents in question (designating either the internal Document number or the vendor's External Doc. Number ). The invoice will be itemized automatically from those documents.
 Note: If the return document is linked to a purchase order, prices are taken from the order. If not, prices are taken from the purchase price or vendor price list. Revise if necessary.
