# Additional Details

 

 1 .  Move to the Invoice - Add'l Details sub-level form. 
 

 2 .  In the Code – Orig. Inv. column, choose the type of the original invoice in which you were billed for the returned goods (GRV). 
 

 3 .  In the Original Invoice column, record the number of that invoice. The memo will be reconciled automatically with the original invoice. 
 

 4 .  Move to the Invoice Items sub-level form and check the items to be credited. Make corrections, as needed. 
 

 5 .  If you want the corresponding line in the entry journal (created when the memo is finalized) to belong to an Entry Item Group , specify the group code. 
 Note: Linking an entry item to a group facilitates data retrieval from the entry journal, as well as data sorting in the general ledger and in transaction reports. 
 

 6 .  Click to link a line item to a project or project activity . 
 

 7 .  Enter the Invoice Item - Remarks sub-level form and check the remarks recorded for the memo item. Revise them if necessary.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable).
