 4 .  In the Invoice Number column, record the number of the vendor's credit memo. 
 

 5 .  In the Debit/Credit column, change the D (debit) to a C (credit). 
 

 6 . Do one of the following: 
 

 ·              To base the memo on a single return document, specify its number in the Document Number column of the References tab. The Details column is filled in automatically from the return document, but may be revised. 
 

 ·              To base the invoice on more than one return document, leave the Document Number column blank and enter the Return Documents for Invoice sub-level form. Record a line for each return document being credited in this invoice, designating either the internal Document or the vendor's External Doc. Number . Return to the upper-level form and record a brief remark in the Details column, if desired. 
 

 Notes: 
 

 ·              If you have already linked the memo to one return document in the upper-level form and wish to link it to additional documents, you can record them in the Return Documents for Invoice sub-level form. 
 

 ·              If the return document is linked to a purchase order, prices are taken from the order. If not, prices are taken from the purchase price or vendor price list. Revise if necessary.
