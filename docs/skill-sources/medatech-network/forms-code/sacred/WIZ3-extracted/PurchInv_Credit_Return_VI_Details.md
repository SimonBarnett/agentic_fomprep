# Additional Details

 

 1 .  Move to the Invoice - Add'l Details sub-level form. 
 

 2 .  In the Code – Orig. Inv. column, enter the code of the original invoice in which you were billed for the returned goods ( VND ). 
 

 3 .  In the Original Invoice column, press F6 to open the invoice form and retrieve the invoice in question. Then press F8 to copy its number back into this column. The current invoice will be reconciled automatically with the original invoice. 
 

 4 .  If the invoice needs to be checked, return to the Vendor Invoices upper-level form and assign it the Checking status (in the References tab). In the Assigned to column, specify the username of the person who is responsible for checking the document. The invoice cannot be finalized until this status is changed. 
 Tip: You can define work flow rules so that the assigned user changes automatically when the status is assigned.
