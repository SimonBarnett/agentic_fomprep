# Canceling a Final Debit Memo

 

If errors are discovered in a finalized memo, you can create a new document with negative values, which cancels the original memo and creates a reversing journal entry. 
 
## To cancel a final debit memo:

 

 1 .  Enter the Debit Memos form and retrieve the desired memo. 
 

 2 .  Do one of the following: 
 

 ·              Select Cancel Document (Original Date) from the list of Direct Activations to create a cancellation memo and reversing journal entry dated to the original memo date. 
 

 ·              Select Cancel Document For Date from the list of Direct Activations to create a cancellation memo and reversing journal entry for a designated date. 
 
## Notes:

 

 ·        You must be authorized to change the status of debit memos to Canceled . 
 

 ·        Click to return to the main screen .
