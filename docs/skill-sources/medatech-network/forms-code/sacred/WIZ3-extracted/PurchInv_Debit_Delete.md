# Deleting a Pending Debit Memo

 

Pending debit memos are documents that have not yet been finalized and can be deleted from the system. 
 
## To delete a pending debit memo:

 

 1 .  Enter the Debit Memos form and retrieve the desired memo. 
 

 2 .  Select Delete Pending Invoice/Memo from the list of Direct Activations . 
 
## To delete a group of debit memos:

 

 ·        Run the Delete Pending Debit Memos program.
