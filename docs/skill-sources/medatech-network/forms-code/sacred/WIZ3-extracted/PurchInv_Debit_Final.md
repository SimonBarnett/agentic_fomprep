# Finalizing Debit Memos

 

Finalization of a debit memo causes the following to occur: 
 

 ·        A unique internal memo number is generated, which replaces the temporary number that appeared when the memo was opened. 
 

 ·        A journal entry is recorded for the memo which includes the contents of the Details column. 
 

 ·        The status of the memo is set to Final .
