# Preparing a Debit Memo

 

A debit memo debits the vendor for returned goods or for overcharging. It is initiated by your company against a vendor, as opposed to a credit memo, which is sent by the vendor. 
 

Click to record a credit memo . 
 
## What do you want to do?

 

 Open a debit memo for the return of goods 
 

 Open a debit memo for overcharging 
 

 Finalize a debit memo 
 

 Revise a final debit memo 
 

 Cancel a final debit memo 
 

 Delete a pending debit memo 
 

 Print a debit memo
