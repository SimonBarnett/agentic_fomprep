# To itemize the debit memo:

 

 1 .  Enter the Memo Items sub-level form. 
 

 2 .  For each overcharged item, specify the Part Number . 
 

 3 .  Record a Quantity of parts. 
 

 4 .  In the Unit Price column, record the full amount you were overcharged for this item. 
 

 5 .  Specify a Budget Item . This value can be used to define the inventory account to be credited for this item. 
 Note: To view information on usage of this budget item, enter the Budgeted vs. Actual sub-level form. 
 

 6 .  Check the Account No . column. Revise it if necessary. 
 

 7 .  Click to link the line item to a project or project activity . 
 

 8 .  Enter the Invoice Item - Remarks sub-level form and check the remarks that appear there. Revise or add to them, as desired.
 Notes : 
 

 ·      Any part remarks recorded in the part catalogue appear in this form automatically if Copy Part Remarks has been flagged for debit memos (in the Copy Part Remarks to Document form). 
 

 ·      To include these remarks in the printout of the debit memo, select a suitable print format .
