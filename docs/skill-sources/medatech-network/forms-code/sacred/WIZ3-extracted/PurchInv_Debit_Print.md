# Printing Debit Memos: Before You Begin

 
## To check the remarks that appear on the printout:

 

 1 .  Enter the Debit Memos form and retrieve the desired memo. 
 

 2 .  Enter the Invoice/Memo - Remarks sub-level form. The text appearing in this form will appear as a remark on the printout. Make sure that it is correct. 
 

 3 .  If you are printing debit memos with item remarks , move to the parallel Memo Items sub-level form. Make sure that the remarks displayed in its sub-level, Invoice Item - Remarks , are correct for each item. Explanation. Revise them if necessary.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 4 .  Return to the Debit Memos form. 
 
## To verify the vendor's mailing address:

 

 ·        Move to the Debit Memo - Add'l Details sub-level form. Make sure that the address recorded is correct.
 Tip: To update the address of a regular vendor (as opposed to a one-time vendor), enter the Vendors form.
