# Printing Debit Memos

 
## To print the debit memo:

 

 ·        Select Print Debit Memo from the list of Direct Activations . 
 

 Notes: 
 

 ·              D ual-currency users: If you wish to print the debit memo in English and are working in another language, click Print Debit Memo in Foreign Lang instead. 
 

 ·              To simultaneously finalize and print the memo, select Finalize & Print Debit Memo from the list of Direct Activations . 
 
## To print a group of debit memos:

 

 ·        Run the Print Debit Memo report.
 D ual-currency users: To print in English when working in another language, run the Print Debit Memo in Foreign Lang report. 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen .
