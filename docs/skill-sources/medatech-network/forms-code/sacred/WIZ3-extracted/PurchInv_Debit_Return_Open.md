# Opening a Debit Memo for Returned Goods

 
## Before you begin:

 

 ·        Record the return in a Returns to Vendor form. 
 
## Note:

 

The return document must be finalized before it can be linked to a debit memo. For more information, run the Receipt/Return of Goods Wizard . 
 
## To open a debit memo:

 

 1 .  Enter the Debit Memos form.
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column. 
 

 2 .  Specify the number of the vendor you wish to debit. The Vendor Name , Date and a temporary Memo Number are filled in automatically.
 Note: In the case of a one-time vendor, specify the one-time vendor number. Then revise the name in the Vendor Name column, and fill in the address and other details in the Debit Memo - Add'l Details sub-level form. 
 

 3 .  If a default Contact appears, make sure that it is the appropriate contact for this memo. Revise if necessary.
 Tip: To define new contacts for the vendor or to assign a default contact for debit memos, use the Vendor Contacts form, a sub-level of the Vendors form. For more information, see the Open Vendors Wizard .
