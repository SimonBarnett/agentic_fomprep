# Revising a Final Debit Memo

 

Only certain columns can be revised in a final debit memo (e.g., Status , Details) . In addition, you can record new remarks and update existing ones. 
 
## To revise a final debit memo:

 

 1 .  Enter the Revision of Invoice Details form and retrieve the desired memo.
 Tip: For best results, retrieve by memo number in the Internal Number column, together with an Invoice Type of DEB. 
 

 2 .  In the References tab, make the necessary revisions in the updateable columns of this form.
 Note: You can only change the memo status to another status defined as final. 
 

 3 .  To record/update remarks for the memo, use the Invoice/Memo - Remarks sub-level form.
