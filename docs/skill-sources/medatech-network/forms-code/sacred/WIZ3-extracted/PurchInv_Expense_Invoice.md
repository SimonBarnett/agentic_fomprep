# Preparing an Expense Invoice

 

Non-inventory expenses, such as technical support and service calls, are recorded in the Multi-GRV Invoices form. You can record expense invoices manually, automatically on the basis of a purchase order or in a batch using the Expense Invoice Work Area. Expense invoices are processed (e.g., finalized, revised, printed) in the same manner as multi-GRV invoices for received goods. 
 
## Note:

 

Invoices created in the work area contain only one expense item, with the part number 000 ; if you require itemized invoices with separate part numbers or descriptions, use a different method. 
 
## What do you want to do?

 

 Record an expense invoice manually 
 

 Record an expense invoice based on a purchase order 
 

 Prepare expense invoices automatically in a batch 
 

 Finalize an expense invoice 
 

 Revise a final expense invoice 
 

 Cancel a final expense invoice 
 

 Delete a pending expense invoice 
 

 Print an expense invoice
