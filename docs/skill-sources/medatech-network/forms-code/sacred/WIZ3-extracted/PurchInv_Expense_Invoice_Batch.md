# Preparing Expense Invoices in a Batch

 

You can use the Expense Invoice Work Area to automatically create a batch of expense invoices, each of which usually corresponds to an original vendor invoice. Note that each invoice contains only one expense item with the part number 000 ; if you require itemized invoices with separate part numbers or descriptions, record them manually (or automatically from purchase orders, if applicable). 
 
## Notes:

 

 ·        Click to record the invoice manually. 
 

 ·        Click to record the invoice on the basis of a purchase order. 
 
## Before you begin

 

 ·        If the Expense Invoice Work Area currently has data in it that you do not need, run the Clear Work Area program to clear the work area. Otherwise, the data you load will be added to the existing data.
