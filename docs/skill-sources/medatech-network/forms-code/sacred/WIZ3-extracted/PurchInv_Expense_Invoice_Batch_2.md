# To prepare the invoices:

 

 1 .  Enter the Expense Invoice Work Area form. 
 

 2 .  For each expense item, open a new line and record the details of the invoice and the expense account to be billed. 
 

 3 .  In the Invoice Amount column, record the total amount of expenses billed in the original vendor invoice (even if the expenses are itemized in the original). 
 

 4 .  In the Details column, record a brief description of the expense. This value will be used as the part description appearing in the invoice (the part number is always 000 ). 
 Note: If the original vendor invoice itemizes a number of expenses, use a description that covers all of them. 
 

 5 .  Select the appropriate Entry Code , as well as the Profit/Cost Center and Budget Item , if any. 
 Note: The GR I entry code appears automatically, but may be revised. 
 

 6 .  The Payment Date appears automatically, according to the payment terms defined for the vendor. Revise if necessary.
 Tip: Use the Financial Parameters for Vendors form to define payment terms for vendors.
