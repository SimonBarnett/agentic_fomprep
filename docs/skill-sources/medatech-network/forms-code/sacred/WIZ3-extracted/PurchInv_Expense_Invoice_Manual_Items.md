# To itemize the invoice: 

 

 1 .  Enter the Invoice Items sub-level form. 
 

 2 .  Record each expense item in one of the following ways: 
 

 ·              Record the same general Part Number for each item (e.g., 000 ) and alter their descriptions
 OR 
 

 ·              Specify a separate number for each expense. 
 

 3 .  If you are using a general part number, change the Part Description for each item; otherwise, make sure that each description is suitable. 
 

 4 .  Record the quantity of parts being billed in the Inv. Quantity column. 
 

 5 .  Record the item's Unit Price and the Item Discount . The item's Extended Price is filled in automatically, as well as the total Amount Owed in the upper-level form.
