# Deleting a Pending Multi-GRV Invoice

 

Pending invoices are documents that have not yet been finalized and can be deleted from the system. 
 
## To delete a pending multi-GRV invoice:

 

 1 .  Enter the Multi-GRV Invoices form and retrieve the desired invoice. 
 

 2 .  Select Delete Pending Invoice/Memo from the list of Direct Activations . 
 
## To delete a group of multi-GRV invoices:

 

 ·        Run the Delete Pending Multi-GRV Inv's. program.
