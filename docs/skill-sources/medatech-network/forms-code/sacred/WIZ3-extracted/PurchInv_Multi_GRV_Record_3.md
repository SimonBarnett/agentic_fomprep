 Notes: 
 

 ·              To revise the payment terms and, in turn, the payment date, use the Invoice - Add'l Details sub-level form. 
 

 ·              To manually define payment installments for this invoice, enter the Payment Installments sub-level form. These installments will override the vendor's default payment terms. 
 

 ·              To change the default payment terms for future transactions with this vendor, enter the Financial Parameters for Vendors form and click the General tab.
