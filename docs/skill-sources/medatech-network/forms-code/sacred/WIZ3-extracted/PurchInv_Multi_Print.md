# Printing Multi-GRV Invoices

 
## Before you begin

 

 1 .  In the Multi-GRV Invoices form, retrieve the desired invoice. 
 

 2 .  Enter the Invoice/Memo - Remarks sub-level form. The text recorded here will appear as a remark on the invoice printout. Make sure it is correct. 
 

 3 .  If you are printing invoices with item remarks , move to the parallel Invoice Items sub-level form. Make sure that the remarks displayed in its sub-level, Invoice Item - Remarks , are correct for each item. Explanation. Revise them if necessary.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 4 .  Return to the Multi-GRV Invoices form. 
 
## To print a copy of the multi-GRV invoice:

 

 ·        Select Print Multi-GRV Inv/Credit Memo from the list of Direct Activations .
 Note: To simultaneously finalize and print the invoice, select Finalize & Print Invoice/Memo from the list of Direct Activations . 
 
## To print a group of multi-GRV invoices:

 

 ·        Run the Print Multi-GRV Inv/Credit Memo report. 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen .
