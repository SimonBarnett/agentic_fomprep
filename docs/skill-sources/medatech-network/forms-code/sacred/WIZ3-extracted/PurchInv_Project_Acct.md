- 
 
 
 
# To change the account debited/credited by the invoice/memo:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  Choose/check the project number. The default account of the project appears automatically in the Account Number column. 
 

 3 .  Choose the account to be credited/debited by the current document.
