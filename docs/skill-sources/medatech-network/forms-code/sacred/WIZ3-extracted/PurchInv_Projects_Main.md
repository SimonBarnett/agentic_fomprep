# Linking Invoices and Memos to Projects

 

You can link a purchase invoice or memo to a project or to a specific project activity (when the entire invoice/memo is for a single activity). When itemizing the invoice/memo, you can also link single line items to different project activities. 
 

Once the invoice/memo is linked to a project or activity, you can change the account debited or credited by the invoice/memo if it differs from the project's default account. 
 

Project linkage appears automatically when the invoice/memo is based on a document linked to a project. 
 
## Note:

 

If a purchase invoice is linked to a project but the receiving warehouse is not, the incoming goods do not add to the cost of the project until they are actually issued to it. If the invoice is based on a purchase order that was linked to the project, consequently adding to the cost of the project, the project is credited for the goods received into the non-project warehouse. 
 
## What do you want to do?

 

 Link the invoice/memo to an entire project or check the linked project 
 

 Link the invoice/memo to a project activity 
 

 Change the account being debited/credited
