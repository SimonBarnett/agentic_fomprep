# Copying Part Remarks to Purchase Invoices and Memos

 

You can set up purchase invoices and memos so that part remarks are recorded automatically for individual items when a part number is recorded or revised in an itemized document. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks:

 

 1 .  Enter the Copy Part Remarks to Document .form. 
 

 2 .  In the line for each desired document type, flag the Copy Part Remarks column.
