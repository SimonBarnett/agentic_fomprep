# Setting Up Document Attributes

 

 Priority allows you to define a variety of default attributes for financial documents. Use these attributes to create custom purchase invoices and memos that meet your specific needs. 
 
## To check or revise vendor document attributes:

 

 1 .  Enter the Financial Documents form. 
 

 2 .  Move to the Credit Memo/Vend line. 
 

 3 .  Check the attributes and revise them as needed. 
 

 4 .  Repeat this process on the Debit Memo , Multi-GRV Inv and Vendor Invoice lines. In the latter two cases, pay particular attention to the Canc. on Orig. Date column, which affects the cancellation of invoices when using the Today ' s Date option. 
 
## Note:

 

For more information on document attributes, run the Set Up Financial Docs Wizard .
