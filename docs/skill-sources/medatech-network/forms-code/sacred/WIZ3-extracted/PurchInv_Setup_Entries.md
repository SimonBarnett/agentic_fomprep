# Assigning Journal Entry Codes to Vendors

 

You can assign custom journal entry codes to each vendor for purchasing invoices and for credit due. The code for invoices will apply to all vendor invoices and multi-GRV invoices recorded for this vendor; the code for credit will apply to all credit memos and debit memos. 
 
## To assign journal entry codes:

 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the desired vendor. 
 

 2 .  Click the Invoice Data tab. 
 

 3 .  Choose the desired codes in the Entry Code–Invoice and Entry Code–Credit/Debit Memo columns.
 Tip: To define new journal entry codes, run the Set Up Entry Codes Wizard .
