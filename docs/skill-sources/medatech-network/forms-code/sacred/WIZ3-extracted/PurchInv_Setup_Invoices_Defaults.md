# Defining a Default Expense Account and Profit/Cost Center

 

For any given vendor, you can define a default expense account, as well as a default profit or cost center (in the first profit/cost group). These will automatically appear in any invoice recorded for that vendor, although they may be revised. 
 
## Note:

 

If the invoice is linked to a project and a separate expense account is designated for that project, that account will override the vendor's default. 
 
## To define a default expense account and profit/cost center:

 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the desired vendor. 
 

 2 .  Click the Invoice Data tab. 
 

 3 .  In the Purchases Account column, specify the vendor's default expense account. 
 

 4 .  In the Profit/Cost Center column, specify the vendor's default profit or cost center.
