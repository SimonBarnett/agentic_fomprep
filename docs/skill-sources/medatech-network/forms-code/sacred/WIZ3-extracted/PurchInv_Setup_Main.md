# Setting Up Purchase Invoices and Memos

 

Before you begin working with purchase invoices and memos, you need to set up the relevant document attributes and system constant. 
 

As vendor invoices also record an inventory transaction, the following list includes default settings pertaining to the receipt of goods. 
 
## What do you want to do?

 

 Set up business processes (define statuses) 
 

 Set up document attributes 
 

 Assign journal entry codes to vendors 
 

 Define a default expense account and profit/cost center for vendor invoices 
 

 Define a default warehouse for vendor invoices 
 

 Set how received goods are linked to their original purchase order 
 

 Define lot numeration templates and shelf life for received parts (vendor invoices) 
 

 Set the price source for multi-GRV invoices 
 

 Determine whether to include closed order items in multi-GRV invoices 
 

 Define packing crate types 
 

 Set up part remarks for purchase invoices and memos 
 

 Determine whether to copy quantities to debit memos
