# Setting Up Business Processes for Invoices and Memos

 

You set up business processes by defining statuses in BPM flow charts. 
 

There are several predefined statuses for purchase invoices and memos, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 
## To use the flow charts:

 

 ·        Run one of the following programs: 
 

 ·              BPM Flow Chart-Vendor Invoices 
 

 ·              BPM Flow Chart-Multi GRV Invs (for multi-GRV invoices and credit memos) 
 

 ·              BPM Flow Chart-Debit Memos 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To automatically block finalization until purchase invoices and/or memos have been checked, flag the predefined Draft status in the Checking column. 
 

 ·        To view the defined properties of all statuses together, enter one of the following forms: 
 

 ·              Statuses for Vendor Invoices 
 

 ·              Statuses for Multi-GRV Invoices (for multi-GRV invoices and credit memos) 
 

 ·              Statuses for Debit Memos . 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
