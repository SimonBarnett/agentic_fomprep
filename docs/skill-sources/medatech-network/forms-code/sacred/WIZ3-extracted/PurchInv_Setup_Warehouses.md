# Defining a Default Warehouse

 

If you work with vendor invoices, both receipts and returns are recorded in the same form. Thus, any default warehouse defined for vendor invoices will be used for both types of inventory transactions. 
 
## To define the default warehouse:

 

 1 .  Enter the Inv. Transaction Documents form. 
 

 2 .  Move to the Vendor Invoice line. 
 

 3 .  In the Default Warehouse column, choose the desired warehouse. 
 

 4 .  If you want to define a default bin, choose the appropriate value in the Bin column. 
 
## Tip:

 

To define additional warehouses, run the Open a Warehouse Wizard .
