# Defining Packing Crate Types

 

If you purchase goods that are shipped in packing crates, it is advisable to create a list of packing crate types, each defined by its capacity, weight (of the crate itself) and volume. 
 
## To record packing crate types:

 

 1 .  Enter the Packing Crate Types . 
 

 2 .  For each type, record a Crate Type Code and Crate Type Desc. (e.g., small box). 
 

 3 .  Designate the weight and volume of this type of crate. 
 

 4 .  In the Capacity column, specify the quantity of parts that can be packed in this type of crate, in buy/sell units. If the capacity is different for different parts, use the Crate Capacity per Part sub-level form instead.
