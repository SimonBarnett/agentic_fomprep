# Finalizing Vendor Invoices

 

Finalization of a vendor invoice causes the following to occur: 
 

 ·        A unique internal invoice number is generated, which replaces the temporary number that appeared when the invoice was opened. 
 

 ·        A journal entry is recorded for the invoice, which includes the contents of the Details column. 
 

 ·        The status of the invoice is set to Final .
