# Itemizing the Order

 

 1 .  Enter the Order Items sub-level form. The order is itemized automatically according to the sales order, but you can add or delete items. 
 

 2 .  Make sure that the part descriptions are suitable.
 Tip: You can change the description of any part that is flagged in the Change Desc. column of the Part Catalogue form. 
 

 3 .  Make sure that the ordered quantities of each item are correct.
 Tip: To check existing and expected inventory levels, use the Inventory for Part and the Part Availability sub-level forms. 
 

 4 .  Make sure that the unit price and discount are correct for each item.
 Note: The unit price is taken from the Cost column of the sales order, provided that it was recorded manually. Otherwise, it is taken from the regular hierarchy of vendor prices. 
 

 5 .  The Due Date column is filled in with the due date of the sales order item. Revise it as necessary
