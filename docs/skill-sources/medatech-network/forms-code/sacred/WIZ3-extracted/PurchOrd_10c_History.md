# View a History of Changes to a Purchase Order

 

You can view the changes made in the quantity, price, discount, currency and/or due date of individual order items. 
 
## To view changes made to items in a particular purchase order:

 

 1 .  Retrieve the desired order in the Purchase Orders form. 
 

 2 .  Enter the History of Changes sub-level form and review changes. 
 
## To view changes made to items in a number of orders:

 

 1 .  Enter the History of Purch. Order Changes form. 
 

 2 .  Retrieve the desired items (e.g., by part number, by order number) and review changes. 
 
## Note:

 

You can maintain purchase order versions by recording a version number in the Current Version column in the Authorization & Follow-up tab of the Purchase Orders form.
