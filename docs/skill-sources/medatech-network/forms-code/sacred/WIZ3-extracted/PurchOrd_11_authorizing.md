# Authorizing Orders

 

When authorization of purchase orders is driven by BPM statuses, you can define rules by which each authorizer is notified when it is his or her turn to sign off on the order. All the authorizer needs to do is to enter the order in question and adjust its status. The next authorizer will automatically be assigned to it and notified. 
 

Alternatively, Priority provides an authorizer list that determines the sequence of authorizations and the persons whose signatures are required.
