# Working With Authorizer Lists

 

Just as with BPM statuses, the first user on the authorizer list is automatically notified by e-mail when the relevant status is assigned to a purchase order. When the first authorizer signs, the second user is notified and so on. Orders for larger amounts usually require the signature of senior authorizers, whereas the signatures of users at the top of the list will suffice for smaller order amounts. Furthermore, it is not mandatory to sign in sequence. Once a senior authorizer signs the order, users appearing earlier in the list need not sign. 
 

The default 00 authorizer list is used automatically. If you work with multiple authorizer lists, you need to revise this value. 
 
## To change the authorizer list:

 

 1 .  Retrieve the order in question in the Purchase Orders form and click the Authorization & Follow-up tab. 
 

 2 .  Choose the appropriate list in the Auth. List Code column.
 Tip: Click to create a new list.
