# To add an authorizer list:

 

 1 .  Enter the Authorizer Lists for Purch Order form. 
 

 2 .  Record a code and a short description for the new list. 
 

 3 .  Enter the Order Authorizers sub-level form and record each authorizer' s username, an alternate authorizer (where applicable) and the amount above which this user's authorization is required.
 Note: The amount specified in the Starting From (Amt) column is checked against the Final Price (after the overall discount is deducted).
