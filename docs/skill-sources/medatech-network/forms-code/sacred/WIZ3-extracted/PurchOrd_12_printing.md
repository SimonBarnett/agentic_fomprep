# Printing an Order

 
## Before you begin:

 

 1 .  In the Purchase Orders form, retrieve the desired order. 
 

 2 .  Enter the Purchase Orders - Remarks sub-level form. The text appearing in this form will appear as a remark on the printout. Make sure that it is correct. 
 

 3 .  If you are printing purchase orders with item remarks , move to the parallel Order Items sub-level form. Make sure that the remarks recorded for each item in the Order Items - Remarks sub-level form are suitable. Revise them if necessary. Explanation. 
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 4 .  Return to the Purchase Orders form. 
 
## To print one order:

 

 ·              Select Print Purchase Order from the list of Direct Activations .
 Note f or d ual-currency users: To print an order in English when working in another language, click Print Purch Order-Foreign Lang. instead. 
 
## To print more than one order:

 

 ·        Run the Print Purchase Order report.
 Dual-currency users: To print in English when working in another language, run the Print Purch Order-Foreign Lang. report. 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen.
