# Orders for Projects

 

You can link an order to a project or to a specific project activity (when the entire order is for a single activity). The cost of the order is added to the cost of the activity or project to which it is linked. 
 

Once the order is linked to a project or activity, you can change the expense account attached to the purchase order if it differs from the project's default expense account. 
 

Project linkage appears automatically in the following cases: 
 

 ·        When the order is opened automatically from within a project. 
 

 ·        If a single project has been recorded for the customer. 
 

 ·        When the order is based on a document linked to a project. 
 
## Notes: 

 

 ·        When itemizing the order, you can also link single line items to specific project activities. 
 

 ·        When you specify a project, the main warehouse defined for the project appears automatically in the Warehouse column (in the References tab). 
 
## What do you want to do?

 

 Link the order to the entire project or check the linked project 
 

 Link the order to a project activity 
 

 Change the attached expense account
