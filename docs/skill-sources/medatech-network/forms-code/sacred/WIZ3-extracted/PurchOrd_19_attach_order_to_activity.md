Purchase Orders - Linking an Order to a Project Activity 
 
 
- 
 
 
 
# To link the order to a project activity:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  In the Project Number column, choose/check the project. 
 

 3 .  The project's default expense account appears automatically in the Account Number column. Revise it if necessary. 
 

 4 .  In the WBS column, choose the WBS code of the activity to which you want to link the order.
 Note: You cannot revise the Percent Completed column in this form. Instead, move to the Activity ID column and press F6 , then make any revisions desired to the project activity in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 5 .  Return to the upper-level form.
