Purchase Orders - Changing the Account for a Project Order 
 
 
- 
 
 
 
# To change the expense account attached to the purchase order:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  Choose/check the project number. The default account of the project appears in the Account Number column. 
 

 3 .  Choose the expense account to attach to the current order. 
 

 4 .  Return to the upper-level form.
