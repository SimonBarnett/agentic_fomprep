# Setting Up Purchase Orders

 

Before you begin recording purchase orders, you need to perform certain setups. 
 
## What do you want to do?

 

 Set up the constant affecting price lists 
 

 Set up the constant determining the range of days in which to search for the last part price 
 

 Set up the constant s affecting order remarks 
 

 Set up delivery terms for purchase orders by vendor 
 

 Record set text for orders 
 

 Set up part remarks for orders 
 

 Define purchase order types 
 

 Define packing crate types 
 

 Set up business processes (BPM) for purchase orders and statuses for order items 
 

 Set up purchase order authorization
