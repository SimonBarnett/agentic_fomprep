# Setting Up Business Processes for Purchase Orders and Statuses for Order Items 

 

You can use a BPM flow chart to customize statuses that help you control the processing of purchase orders, from their inception to their authorization and closure. 
 

There are several predefined statuses for purchase orders, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 

You can also define statuses for individual line items within a purchase order. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Purchase Orders program. 
 
## Tips:

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Purchase Orders form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide . 
 

 ·        Click to use BPM rules to manage purchase order authorization . 
 
## To create statuses for order items:

 

 1 .  Enter the Statuses for PO Items form. 
 

 2 .  In the Status column, record the name of the new status. 
 

 3 .  In the Display Order column, number the statuses according to the desired order of appearance in Choose lists.
