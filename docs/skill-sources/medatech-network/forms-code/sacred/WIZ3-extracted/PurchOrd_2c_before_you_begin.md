# Recording Set Text for Purchase Orders

 

If you want certain remarks to appear on all (or most of) the printouts of purchase orders, you can designate set text for this purpose. 
 
## To designate set text:

 

 1 .  Enter the Set Text for Purchase Orders form. 
 

 2 .  Record the desired text in the Set Text for Purchase Orders sub-level form.
 Dual-currency users: If you are working in a language other than English, and wish to print purchase orders in English, record set text in the Set Text for Purchase Ords-Lang2 sub-level form. Any orders for vendors defined as receiving Printouts in Lang 2 will contain set text in English. 
 

These remarks will automatically appear in the Purchase Orders - Remarks sub-level form of each new order, but may be revised there. Any remarks appearing in this sub-level form are automatically included in the printout of the purchase order. 
 
## Notes: 

 

 ·        Set text is overwritten by remarks assigned to specific types of purchase orders. 
 

 ·        In purchase orders that are copied from vendor quotes, remarks are copied from the quote and the set text is ignored.
