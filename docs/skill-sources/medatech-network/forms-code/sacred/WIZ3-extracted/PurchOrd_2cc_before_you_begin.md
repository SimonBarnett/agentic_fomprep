# Defining Purchase Order Types

 

Each purchase order can be assigned a specific type (e.g., software, furniture, office supplies). Moreover, you can designate set text for each type. This text will be displayed automatically in the Purchase Orders - Remarks sub-level form of any order of this type, in turn affecting what appears on the printout of the purchase order. 
 
## Notes:

 

 ·              Once a type is assigned to a purchase order, the text for that type is used, overriding any set text defined for purchase orders in general. 
 

 ·              Whenever you change the type of a purchase order, the relevant text will only appear in the Purchase Orders - Remarks if no remarks are already recorded for that order. If remarks already exist, you must delete them before changing the order type. 
 
## To define purchase order types:

 

 1 .  Enter the Types of Purchase Orders form. 
 

 2 .  List the order type. 
 

 3 .  Enter the Set Text for Order Type sub-level form and record set text for this type of order.
 Dual-currency users: If you are working in a language other than English, and wish to print purchase orders in English, record set text in the Set Text for Order Type - Lang 2 sub-level form. Any orders of this type for vendors defined as receiving Printouts in Lang 2 will contain set text in English.
