# Viewing Purchase Orders and Other Purchasing Documents

 
## To view purchasing documents: 

 

 ·        Run the Purchasing Overview of Parts report, which displays all open purchase requisitions, fully authorized purchase orders, final price quotations and open blanket orders, sorted by part. 
 
## To view open purchase orders: 

 

 ·        Run the Open Purchase Orders report, which displays the details of all open purchase orders, for specified vendors during a designated period. To view all purchase orders: 
 

 ·        Run the Purchase Orders report, which displays the details of all purchase orders, open or closed, for specified vendors during a designated period.
