# Inventory History of Order Items

 
## To track the inventory history of a given purchase order item:

 

 1 .  Enter the Purchase Orders form and retrieve the order in question. 
 

 2 .  Enter the Order Items sub-level form and move to the desired line item. Check the value of the Balance column. 
 

 3 .  Enter the Order Tracing sub-level form to view the details of all inventory transactions involving the selected order item (e.g., Receipt of Goods, Vendor Invoice). 
 
## To track the inventory history of one or more orders and/or ordered parts:

 

 ·        Run the Purchase Order Supplies report, which displays the inventory transactions and balances of specified parts, sorted by vendor and order number.
