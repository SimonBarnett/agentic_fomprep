# Overdue Purchase Orders

 

You can view, for designated vendors, all purchase order items that have not been delivered by the receipt date specified in the purchase order, including part balances and the number of days by which the parts are late. 
 
## To view overdue orders:

 

 ·        Run the Supply Delays report.
