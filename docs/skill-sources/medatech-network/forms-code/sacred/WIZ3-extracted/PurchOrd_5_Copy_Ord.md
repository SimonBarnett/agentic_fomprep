# Opening a New Order on the Basis of an Existing Order

 

You can open a new purchase order by creating a copy of an existing order. Selected details of the original order (e.g., vendor number, the list of order items and their prices) are copied automatically to the new order, which can then be revised as needed. 
 
## To open a new order on the basis of an existing order:

 

 1 .  Enter the Purchase Orders form and retrieve the order you want to copy. 
 

 2 .  Select Copy Purchase Order from the list of Direct Activations . 
 

 3 .  Retrieve the new order and make the desired revisions.
