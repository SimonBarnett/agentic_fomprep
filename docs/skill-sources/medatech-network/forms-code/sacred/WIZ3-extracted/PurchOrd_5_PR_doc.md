# Recording an Order Based on Purchase Requisitions

 

There are three ways to record an order based on purchase requisitions. You can link a purchase order directly to specific PRs, link the order to an entire purchase demand document (when you intend to purchase all requisitioned items listed in the document from the same vendor), or run a program from within a purchase demand document that automatically creates a separate purchase order for each purchase requisition in the document. 
 
## Note:

 

If you want to copy the estimated unit price of a PR into the order item for that part, make sure the Copy Price to Order column is flagged in the PR. If the PR is linked to a vendor price quote, the column is flagged automatically. 
 
## What do you want to do?

 

 Record a purchase order for individual purchase requisitions. 
 

 Record an order based on an entire purchase demand document. 
 

 Create purchase orders automatically from a purchase demand document .
