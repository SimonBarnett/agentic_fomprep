# To record an order based on purchase requisitions:

 

 1 .  Enter the Purchase Orders form.
 Note: At any point in the following process, you can transfer handling of the order to another employee, by specifying his/her username in the Assigned to column (in the Authorization & Follow-up tab). 
 

 2 .  Record the vendor number. The vendor name, date and order number are filled in automatically.
 Note: In the case of a one-time vendor, record the vendor number defined for one-time vendors and revise the name in the Vendor Name column. Then fill in the address and other details in the Purchase Order - Vendor Details sub-level form. 
 

 3 .  Leave the current order line (e.g., enter any sub-level form) and return to the upper-level form.
 Tip: Leave the Purchase Orders form open. 
 

 4 .  Enter the Purchase Requisitions form and retrieve the desired PR.
 Note: In order to open an order item, the PR must belong to a purchase demand document that is fully authorized (unless no authorization is required) and has a status that allows linkage of PRs to a purchase order. 
 

 5 .  Move to the Order column, and record the number of the purchase order you opened. 
 

 6 .  Return to the Purchase Orders form. An order item is automatically created for the requisitioned part and is linked to the PR in the Order Items sub-level form.
 Note: When a PR is linked to a purchase order, it closes automatically. 
 

 7 .  Link additional PRs to the purchase order, as desired.
