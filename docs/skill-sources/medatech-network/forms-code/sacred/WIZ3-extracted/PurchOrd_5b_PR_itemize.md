# Itemizing the Order

 

 1 .  Enter the Order Items sub-level form. The order has been itemized automatically, but you can add or delete items. 
 

 2 .  Make sure that the part descriptions are suitable.
 Tip: You can change the description of any part that is flagged in the Change Desc. column of the Part Catalogue form. 
 

 3 .  Make sure that the ordered quantities of each item are correct.
 Tip: To check existing and expected inventory, use the Inventory for Part and the Part Availability sub-level forms. 
 

 4 .  Make sure that the unit price and discount are correct for each item. 
 

 5 .  Check the Due Date and revise where necessary. After revising, check the Receipt Date and On-hand Date .
