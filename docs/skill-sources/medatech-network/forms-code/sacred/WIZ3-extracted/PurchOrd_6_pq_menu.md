# Recording an Order Based on a Price Quotation

 

When basing an order on a price quotation, you can choose between two options: 
 

 ·        Copy all line items from the quote to the order (these items can then be revised). 
 

 ·        Record each part number and its quantity manually; prices and other data are filled in automatically from the quote. This option is useful when different prices are quoted for different quantities of the same part. Example.
