# To change the "Copy All to Order" flag:

 

 1 .  Move to the References tab. In the Status column, change the status to a status that allows for revision (e.g., Draft ). 
 

 2 .  Click the Price tab, and flag the Copy All to Order column. 
 

 3 .  Return to the References tab, and in the Status column, restore the original quote status. 
 
## Note:

 

If rules have been defined for changes in quote status, you may need authorization to make the status revisions.
