# If the price quotation is not in the Choose list:

 

A price quote will not appear in the Choose list if its current status does not allow it to open an order. If you still want to base the order on this quote, you must change its status. 
 
## To check the quote status:

 

 1 .  Enter the Vendor Price Quotations form and retrieve the quotation in question. 
 

 2 .  Click the References tab. 
 

 3 .  Check the status. 
 
## To check the definition of a price quote status:

 

 1 .  Enter the Statuses for Vendor Quotes form. 
 

 2 .  Check the value in the Allow Order to Open column. Only quotes with a status flagged in this column can be used to open an order. 
 
## To change the quote status:

 

 1 .  If you have not already done so, enter the Vendor Price Quotations form and retrieve the quotation in question. 
 

 2 .  Click the References tab. 
 

 3 .  Revise the status. 
 
## Note:

 

If rules have been defined for changes in quote status, you may need authorization to make the status revisions.
