# Creating Authorizer Lists

 

 Priority offers the option of working with authorizers whose signatures are required before purchase orders can be sent to the vendor. You can create a single authorizer list, used for all orders, or multiple lists (e.g., one for each department). More details. 
 
## To create a single authorizer list:

 

 1 .  Enter the Authorizer Lists for Purch Order form and move to the predefined 00 code. 
 

 2 .  List the authorizers in the Order Authorizers sub-level form, recording each authorizer's username, an alternate authorizer (where applicable) and the total amount above which this user's signature is mandatory.
 Note: The amount that is taken into account is the Final Price , after the overall discount has been deducted. 
 
## To create multiple authorizer lists:

 

 1 .  Use the 00 code to define your main list of authorizers (see above). 
 

 2 .  In the Authorizer Lists for Purch Order form, record a code and a short description for each additional list. 
 

 3 .  Use the sub-level form to list the authorizers. 
 
## Note:

 

The 00 code will automatically be assigned to each newly opened purchase order. To use a different list, the code must be changed in the order.
