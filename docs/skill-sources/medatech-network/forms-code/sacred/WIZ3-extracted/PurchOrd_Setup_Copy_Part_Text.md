# Copying Part Remarks to Orders

 

You can set up purchase orders so that part remarks are recorded automatically for individual items when a part number is recorded or revised in an itemized order. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks to order items:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "Purchase Order", flag the Copy Part Remarks column.
