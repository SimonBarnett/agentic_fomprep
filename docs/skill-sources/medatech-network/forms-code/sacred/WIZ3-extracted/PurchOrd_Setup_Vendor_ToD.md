# Defining Default Delivery Terms for Vendors

 

You can define default delivery terms for a vendor, which will be recorded automatically in purchase orders to this vendor. These terms can be modified manually within the order. 
 
## To define default delivery terms for a vendor:

 

 1 .  Enter the Vendors form. 
 

 2 .  Move to the Shipments tab. 
 

 3 .  In the Terms of Delivery column, choose the delivery terms for the vendor.
