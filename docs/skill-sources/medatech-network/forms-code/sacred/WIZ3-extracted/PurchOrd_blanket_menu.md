# Recording an Order Based on a Blanket Purchase Order 

 

When opening a purchase order based on a blanket purchase order, part prices and discounts are taken from the blanket order. Moreover, any actual purchase order updates the balance of parts in the blanket order. 
 

When basing an order on a blanket order, you can choose between two options: 
 

 ·        Copy all line items from the blanket order into the order (these items can then be revised). 
 

 ·        Record each part number and its quantity manually; prices and other data are filled in automatically from the blanket order. This option is useful when the purchase order does not contain all of the items listed in the blanket order.
