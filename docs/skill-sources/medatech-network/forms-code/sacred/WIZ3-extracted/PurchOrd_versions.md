# Purchase Order Versions

 

 Priority allows you to save versions of any purchase order. 
 
## To save a version:

 

 1 .  Enter the Purchase Orders form and retrieve the desired order. 
 

 2 .  Select Save Version from the list of Direct Activations. The Current Version ( Authorization & Follow-up tab) is increased by 1 and details of the current order (i.e., the saved version) are copied into the Purchase Order Versions sub-level form and its sub-levels.
