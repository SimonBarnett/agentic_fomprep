# Using BPM Rules to Create Authorization Lists

 

Due to their versatility and potential complexity, BPM tools and their application to authorization cannot be reduced to a simple list of instructions. It is recommended to review the User Interface Guide on the subject, and to consult the Eshbel Implementation Staff to help you create an authorization system that best suits your needs. 
 

The following may be used as a general outline for your work with BPM: 
 

 1 .  Run the BPM Flow Chart-Purchase Demands program. 
 

 2 .  Right-click the Pending Auth status and select Rules . 
 

 3 .  Define one rule by which your first authorizer is assigned the document when it receives the Pending Auth status, and a second rule by which the authorizer is notified when the same condition is met. 
 

 4 .  Define a new status for the first authorization, called First Auth , or something similar.
