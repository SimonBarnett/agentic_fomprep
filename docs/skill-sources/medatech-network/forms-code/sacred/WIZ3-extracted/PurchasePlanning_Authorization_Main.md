# Setting Up Purchase Demand Authorization

 

There are two methods you can use to authorize purchase demands – authorizer lists and BPM rules. 
 

Authorizer lists are defined in a separate form and assigned to individual demand documents. Each list contains the names of those users who must sign off on a purchase demand, with or without reference to the amount of the demand. The demand document always displays the name of the next user whose signature is required, which enables you to run periodic queries to check if any documents require your signature. 
 

BPM status and path rules can used to obtain the same results as authorizer lists, including automatic notification by e-mail or SMS, but made even more powerful by the limitless combinations of conditions and behaviors provided by BPM. For a full explanation of BPM and its uses, see the User Interface Guide .
