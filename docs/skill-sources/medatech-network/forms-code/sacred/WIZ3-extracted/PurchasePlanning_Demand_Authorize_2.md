# Working With Authorizer Lists

 

When authorizing purchase demands via an authorizer list, the process begins when the user preparing the demand document notifies the first user on the list (whose name appears in the Next Signature column of the Authorization & Follow-up tab) that the document is ready. When the first authorizer signs, the second is automatically notified by e-mail and so on. Demands for larger amounts usually require the signature of senior authorizers, while demands for smaller amounts can be signed solely by users who appear earlier in the list. Furthermore, it is not mandatory to sign in sequence. Once a senior authorizer signs the document, users appearing earlier in the list need not sign. 
 

The default 00 authorizer list is used automatically. If you work with multiple authorizer lists, you need to revise this value. 
 
## To change the authorizer list:

 

 1 .  Retrieve the demand document in question in the Purchase Demands form and click the Authorization & Follow-up tab. 
 

 2 .  Choose the appropriate list in the Auth. List Code column.
 Tip: Click to create a new list.
