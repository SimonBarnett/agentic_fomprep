# To add an authorizer list:

 

 1 .  Enter the Authorizer Lists for PRs form. 
 

 2 .  Record a code and a short description for the new list. 
 

 3 .  Enter the Authorizers sub-level form and record each authorizer's username, an alternate authorizer (where applicable) and the amount above which this user's authorization is required.
