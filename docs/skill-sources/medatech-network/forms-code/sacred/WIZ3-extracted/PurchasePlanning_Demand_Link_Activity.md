- 
 
 
 
# To link a purchase demand to a project activity:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  In the Project Number column, choose the desired project. 
 

 3 .  The project's default expense account appears automatically in the Account Number column. If necessary, select a different account for the current demand document. 
 

 4 .  In the WBS column, choose the WBS code of the activity to which you want to link the purchase demand. 
 

 5 .  Change the Percent Completed , if necessary.
 Note: To revise the Activity Status , move to the Activity ID column and press F6 , then make the revision in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 6 .  Return to the upper-level form.
