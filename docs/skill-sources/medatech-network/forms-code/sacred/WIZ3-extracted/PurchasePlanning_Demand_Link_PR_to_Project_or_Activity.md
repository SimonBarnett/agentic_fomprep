Purchase Planning - Linking a Purchase Requisition to a Project or Activity 
 
 
- 
 
 
 
# To link a purchase requisition to a project or activity:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  In the Project Number column, choose the desired project. 
 

 3 .  The project's default expense account appears automatically in the Account Number column. Revise it if necessary. 
 

 4 .  If you have linked the purchase requisition to a project activity, the WBS code of the activity appears in the WBS column. Revise it if necessary. 
 

 3 .  Change the Percent Completed , if necessary.
 Note: To revise the Activity Status , move to the Activity ID column and press F6 , then make the revision in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 4 .  Return to the Itemized Purchase Requisitions form.
