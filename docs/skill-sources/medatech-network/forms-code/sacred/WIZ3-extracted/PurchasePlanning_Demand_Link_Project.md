- 
 
 
 
# To link a purchase demand to a project:

 

 1 .  Click the Project tab. 
 

 2 .  In the Project Number column, choose the desired project. 
 

 3 .  The project's default expense account appears automatically in the Account Number column. If necessary, select a different account for the current demand document.
