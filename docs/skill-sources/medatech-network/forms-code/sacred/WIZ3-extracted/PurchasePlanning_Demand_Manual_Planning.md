# Preparing a Purchase Demand Document Manually

 

If you want to prepare a purchase requisition manually, Priority provides reports that can help you determine needed parts and their required quantities. You can run these reports without having run purchase planning: in fact, they are helpful even if your system does not include MRP or purchase planning. 
 

 ·        The Purchase Recommends (Businesses) report displays the expected shortages of purchased parts, calculated on the basis of open sales and purchase orders, as well as the safety stock defined for each part. 
 

 ·        The Part Availability - Detailed report displays the expected availability of selected parts. The report list the purchase orders and sales orders opened for each part, as well as the part's existing inventory balance. 
 

 ·        The Part Availability report displays a summary of a given part's availability. You can run the report in the format of a work area, which allows you to view both data totals and data details (e.g., inventory balances per warehouse, individual orders). 
 
## Note: 

 

In the part availability reports, you can determine whether open sales orders for parent parts are included in the calculation of a part's availability, using the SParentAvail constant (in the Logistic Constants form).
