# To record purchase requisitions:

 

 1 .  Enter the Itemized Purchase Requisitions sub-level form. 
 

 2 . For each requisition, specify the Part Number of the required part. Make sure that the Part Description is suitable.
 Tip: You can change the description of any part that is flagged in the Change Desc. column of the Part Catalogue form. 
 

 3 .  In the Quantity to Order column, specify the required quantity of the part. 
 

 4 .  In the Demand Date column, specify the date by which the part is required. This value will appear automatically in the Best On-hand Date column, which may be revised. 
 

 5 .  Flag the Notify of Receipt column to receive an e-mail message when the goods are received into inventory. When receipt of the goods is recorded in either the Goods Receiving Vouchers form or the Vendor Invoices form, a message is sent to the user who opened the request and to the user appearing in the For User column in the Purchase Demands form.
