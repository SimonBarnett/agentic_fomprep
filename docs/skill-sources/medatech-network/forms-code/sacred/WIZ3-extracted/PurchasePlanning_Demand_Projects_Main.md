# Purchase Demands for Projects

 

You can link a purchase demand to a project or to a specific project activity (when all of the purchase requisitions it contains are for a single activity). The cost of the demand is added to the cost of the activity or project to which it is linked. 
 

The expense account linked to the project is displayed automatically when the purchase demand is linked to the project, but it may be revised. This account is billed by default when a financial document is recorded on the basis of a purchase order or GRV which is itself based (directly or indirectly) on the purchase demand. 
 
## Notes: 

 

 ·        You cannot link an itemized purchase demand (i.e., in which purchase requisitions have already been recorded) to a project or activity. 
 

 ·        When itemizing the demand, you can also link single purchase requisitions to specific project activities. 
 

 ·        When you specify a project, the main warehouse defined for the project appears automatically in the Warehouse column (in the References & Cost tab).
