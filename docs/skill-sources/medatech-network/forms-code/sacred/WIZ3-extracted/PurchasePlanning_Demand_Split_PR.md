# Splitting a Purchase Requisition

 

In order to change the quantity of an individual purchase requisition, the PR can be split into two separate lines, creating a new PR for the part, whose quantity is subtracted from the original one. The new PR is added to the original demand document and linked to the original PR, whose number appears automatically in the Original PR Number column. 
 
## To split a purchase requisition:

 

 1 .  Enter the Purchase Demands form and retrieve the desired purchase demand. 
 

 2 .  Enter the Itemized Purchase Requisitions sub-level form, move to the line for the PR in question and select Split Purchase Requisitions from the list of Direct Activations, specifying the quantity to be included in the new PR for this part (and subtracted from the original one).
 Tip: To view the new PR, exit and re-enter the sub-level form.
