# Running Purchase Planning

 

The Purchase Planning program calculates projected part balances on the basis of an issues plan generated by one of the resource planning programs (MRP for Manufacturers, MRP for Distributors or Production Planning). 
 

It then opens purchase requisitions to cover any shortfalls in inventory that are anticipated up to the designated end date (after taking into account any open purchase orders as well as any existing inventory of purchased parts). The program generates a purchase demand document containing all of the new purchase requisitions, which is distinguishable from manual purchase demands by an A in the Automatic column (in the Purchase Demands form). 
 

The planning parameters defined for each part determine the size and timing constraints of the purchase requisitions, and each part's preferred vendor appears as the default vendor. 
 

Alternatively, you can run purchase planning to calculate projected balances based on the issues included in the last full run of purchase planning, together with any automatically opened purchase requisitions and open purchase orders, without opening a purchase demand document when the program finishes. 
 

You can run the program in this manner to improve your purchase planning results by calculating expected inventory balances and generating recommendations to handle purchase orders. After implementing these recommendations, you can run the program again to view the new projected balances, and check for any new recommendations. By continuing this cycle you can fine-tune your purchase planning results until you achieve the optimal results. 
 

You can run purchase planning for one or more selected parts.
