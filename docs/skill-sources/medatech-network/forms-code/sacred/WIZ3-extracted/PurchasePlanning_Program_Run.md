# To run purchase planning:

 

 1 .  Run the Purchase Planning program. 
 

 2 .  After reading the initial instructions, do one of the following: 
 

 ·      To update projected balances without opening purchase requisitions, choose the Update Projected Bal option. 
 

 ·      To open purchase requisitions automatically, choose the Create Purch. Demand option. 
 
## Notes:

 

 ·        Click if you chose to open automatic purchase requisitions. 
 

 ·        Click to view planning results. 
 

 ·        Click to return to the main screen.
