# Set Text for Purchase Demands

 

If you want certain remarks to appear on all printouts of purchase demands, you can designate set text for this purpose. These remarks will automatically appear in the Remarks sub-level form of each new purchase demand, but may be revised there. Any remarks appearing in that sub-level form appear automatically in the printout of the purchase demand. 
 
## To designate set text:

 

 1 .  Enter the Set Text for Purchase Demands form. 
 

 2 .  Record the desired remarks in the Set Text for Purchase Demands sub-level form.
 Dual-currency users: If you are working in a language other than English, and wish to print out purchase demands in English, record set text in the Set Text for Purch Demands-Lang2 sub-level form as well. Purchase demands that are recorded for a specific vendor (defined in the upper-level form) will contain set text in English if the designated vendor is defined as receiving Printouts in Lang 2 .
