# Copying Part Remarks to Requisitioned Items

 

You can set up purchase demand documents so that part remarks are recorded automatically for individual requisitioned items when a part number is recorded or revised in an itemized document. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks to requisitioned items:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "Purchase Demand", flag the Copy Part Remarks column.
