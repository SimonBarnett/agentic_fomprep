# Defining Inventory Parameters for Purchased Parts

 

The purchase planning program calculates the demand for purchased (Type R ) parts with replenishment type R , according to the issues plan generated by MRP. When you select the Consider Flr Stock runtime option, MRP reduces this demand against existing inventory that was issued in bulk to the plant floor. 
 

As no issues plan is generated for Type R parts with replenishment type B , purchase planning calculates the demand for such parts according to the consumption parameters defined for them in the Purchase/MRP Parameters for Part form. 
 

Purchase planning takes into account existing inventory of both types in Type D warehouses, provided that its status allows it to participate in planning calculations. You can also set a constant that includes existing plant floor inventory of parts with replenishment type B . 
 
## To check inventory statuses:

 

 1 .  Enter the Inventory Statuses form. 
 

 2 .  For each status that is to be taken into account by purchase planning, flag the Available Inventory column. Only inventory with a status that is flagged in that column will be considered available to reduce demands. 
 
## To set purchase planning to take into account floor inventory of parts with replenishment type B:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the PUseFlrStock constant. 
 

 3 .  Change the value to 1 .
 Notes: 
 

 ·      If the MRPSepFloor production constant is set to 1 (allowing MRP to calculate the inventory in each floor warehouse separately), you cannot set this constant to 1 . 
 

 ·      If you set the PUseFlrStock constant to 1 , expect the purchase planning program to run longer than usual, as the additional calculations are likely to be quite heavy.
