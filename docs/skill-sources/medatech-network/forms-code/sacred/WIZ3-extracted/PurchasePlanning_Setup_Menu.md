# Setting Up Purchase Planning

 

Before you begin working with purchase requisitions and demand documents, you need to: 
 

 Define time and size parameters for purchase requisitions 
 

 Define inventory parameters for purchased parts 
 

 Exclude specific purchase orders from purchase planning calculations 
 

 Set up business processes (BPM) for purchase demands 
 

 Set up purchase demand authorization 
 

 Set up purchase demand types 
 

 Record set text for purchase demands 
 

 Set up part remarks for purchase demands 
 

 Define reasons for purchase demands
