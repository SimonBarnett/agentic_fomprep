# Setting Up Purchase Demand Types

 

Each purchase demand can be assigned a specific type (e.g., software, furniture, office supplies). Moreover, you can designate set text for each type. This text will be displayed automatically in the Set Text for Demand Type sub-level form of any demand of this type and consequently on the printout of such demand documents. 
 

  
 
## Notes:

 

 ·      Once a type has been assigned to a purchase demand, the text for that type is used, overriding any set text defined for purchase demands in general. 
 

 ·      Whenever you change the type of a purchase demand, the relevant text will only appear in the Set Text for Demand Type sub-level form if no remarks are already recorded for that purchase demand. If remarks already exist, you must delete them before changing the purchase demand type. 
 
## To set up purchase demand types:

 

 1 .  Open the Set Text for Demand Type form. 
 

 2 .  Specify the purchase demand type. 
 

 3 .  In the Set Text for Demand Type sub-level form, specify the set text for the current purchase demand type.
 Dual-currency users: If you are working in a language other than English, and wish to print purchase demands in English, record the set text for the current type in the Set Text for Demand Type - Lang2 sub-level form. This text will be used when printing in English.
