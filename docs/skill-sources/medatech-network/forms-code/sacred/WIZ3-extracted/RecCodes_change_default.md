# Tips on Revising the Reconciliation Method

 

 ·        Range in Days
 This is the maximum range (in days) between due dates of entries. The specified range may be too narrow (especially in later reconciliation steps). Scenario .
 Tip: Try designating a greater number of days . 
 

 ·        Num Chars to Compare
 This is the number of characters by which the system will compare two reference numbers (counting from the end). Example . Zero indicates that only items with identical reference numbers will be reconciled. Scenario .
 Tip: Try lowering the designated value. 
 

 ·        Permitted Variance
 When reconciling by amount only, this is the maximum difference allowed between the reconciled amounts. Zero indicates that only identical amounts will be reconciled. Scenario .
 Tip: Try increasing the permitted variance.
