# To assign a consignment warehouse to a vendor:

 

 1 .  Enter the Vendors form and retrieve the desired vendor. 
 

 2 .  Click the Details tab and specify the Consignment Warehouse and bin. This warehouse will now appear as the default warehouse for all GRVs recorded for this vendor.

Click to return to the Vendor Consignment menu .
