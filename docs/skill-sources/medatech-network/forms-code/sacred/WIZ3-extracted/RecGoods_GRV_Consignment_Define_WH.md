# To define a vendor consignment warehouse:

 

 1 .  Open a new warehouse in the regular manner.
 Tip : Run the Open a Warehouse Wizard . 
 

 2 .  In the General tab, remove the check mark from the Inventory Valued column. The check mark next to the Transaction Costing column will disappear automatically. 
 

 3 .  Flag the For Consignment column. 
 
## Note:

 

Click to assign the consignment warehouse to a vendor .
