 7 .  If returns were included, the warehouse recorded in the original GRV appears in the Receiving Warehouse column (in the General tab). Otherwise, the default warehouse appears. Revise if necessary.
 Notes: 
 

 ·      If goods are received into more than one warehouse (or bin), designate the main one here. When itemizing the document, indicate the receiving warehouse for each part. 
 

 ·      The designated bin will be assigned to all received items, with the exception of parts for which a default warehouse bin is defined (in the Inventory Parameters for Parts form) – in that case, the default will appear instead. In any case, the bin (and warehouse) can be revised for specific items. 
 

 ·      Click to change the default warehouse for future GRVs . 
 

 8 .  In the Details column, record a brief remark regarding this GRV. 
 

 9 .  If you are not to be billed for the received goods, click the Price tab and remove the check from the Billable column. 
Note: If only part of the received goods are free of charge, leave the check mark, and change the billing status of those parts during itemization of the GRV. 
 

 10 .  Click the Shipment tab, and check the shipping details. The vendor's default shipping details appear automatically, but may be revised.
 Tip: To define additional shipping codes, use the Shipment Codes form; to define additional shippers, use the Drivers/Shippers form.
