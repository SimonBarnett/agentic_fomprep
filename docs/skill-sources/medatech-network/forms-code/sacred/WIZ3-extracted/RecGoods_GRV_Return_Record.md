# Recording a GRV for Replaced or Returned Goods

 

If you received defective parts that you returned to the vendor for replacement or repair, you can record a GRV for the new or repaired goods on the basis of the vendor return document. 
 
## To record a GRV based on a vendor return document:

 

 1 .  Enter the Goods Receiving Vouchers form. 
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the General tab). 
 

 2 .  Specify the date the goods were received. The document number will be filled in automatically. 
 

 3 .  Specify the number of the vendor that supplied the goods. The vendor's name is filled in automatically.
 Note: In the case of a one-time vendor, specify the one-time vendor number. Then revise the name in the Vendor Name column, and fill in the address and other details in the Vendor Details sub-level form. 
 

 4 .  Specify the contact at the vendor for the current shipment.
 Tip: To define new contacts for this vendor, use the Vendor Contacts form, a sub-level of the Vendors form. For more information, see the Open Vendors Wizard . 
 

 5 .  In the Vendor ' s Doc. column, record the receiving document's reference number (usually the vendor's shipping document number). 
 

 6 .  Make sure the Receiving Warehouse and Bin are correct (that is, that all or most of the received items were received there). Revise as needed.
 Note: The designated bin will be assigned to all received items, with the exception of parts for which a default warehouse bin is defined (in the Inventory Parameters for Parts form) – in that case, the default will appear instead. In any case, the bin (and warehouse) can be revised for specific items.
