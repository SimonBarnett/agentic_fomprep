# To change the attached expense account:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  Choose/check the desired project number. The default expense account of the project appears automatically in the Account Number column. 
 

 3 .  Choose the expense account to attach to the current document. 
 

 4 .  Return to the upper-level form.
