# Linking to Projects

 

You can link a receiving/return document to a project or to a specific project activity. In the case of a GRV, the cost of the goods received is added to the cost of the activity or project to which it is linked. In the case of a return, the cost of the goods is subtracted. 
 

Once the document is linked to a project or activity, you can change the expense account attached to the receipt/return if it differs from the project's default account. 
 

Project linkage appears automatically in the following cases: 
 

 ·        When opening a GRV on the basis of a purchase order that is linked to a project. 
 

 ·        When opening a return document on the basis of a GRV that is linked to a project. 
 
## Notes:

 

 ·        If the GRV is linked to a project but the receiving warehouse is not, the incoming goods do not add to the cost of the project until they are actually issued to it. If the GRV is based on a purchase order that was linked to the project, consequently adding to the cost of the project, the project is credited for the goods received into the non-project warehouse. 
 

 ·        When itemizing the document, you can also link single line items to specific project activities. 
 
## What do you want to do?

 

 Link the document to an entire project or check the linked project 
 

 Link the document to a project activity or check the linked activity
