# Canceling a Pending Return Document

 

A return document that has not yet been finalized can be revised freely as well as canceled. However, a pending return document can only be canceled if all its quantities are zero. Once it has been canceled, it cannot be reopened. 
 
## To cancel a pending return document:

 

 1 .  Enter the Returns to Vendor form and retrieve the desired return document. 
 

 2 .  In the General tab, change the status to Canceled .
