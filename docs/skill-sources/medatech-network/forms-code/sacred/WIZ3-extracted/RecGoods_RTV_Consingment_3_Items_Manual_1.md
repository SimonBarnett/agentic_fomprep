- 
 
 
 
# To itemize the return document manually:

 

 1 .  Specify the vendor's Conta ct for the return of goods, as well as the Project information, if necessary. 
 

 2 .  Enter the Returned Items sub-level form. 
 

 3 .  For each item, choose the most convenient option: 
 

 ·      Specify the system's internal Part Number .
 OR 
 

 ·      If the vendor's part number is recorded in the system, record the appropriate number in the Vend/Manuf Part No. column, and the internal part number will appear automatically. 
 

 Tip: For more information about defining vendor parts, see the Vendor Parts and Prices Wizard . 
 

 4 .  Make sure that the Part Description is suitable.
 Tip: You can change the description of any part that is flagged in the Change Desc. column of the Part Catalogue form. 
 

 5 .  If you maintain lots for this part, specify the lot number. If not, leave the default value of 0 . 
 

 6 .  Do one of the following: 
 

 ·      Specify the Quantity of the returned part manually. 
 

 ·      If you are returning packed goods, designate the Crate Type Code and the number of crates. The Quantity will be calculated automatically, based on crate capacity. 
 

 Note : If you are allowed to record partially packed crates (i.e., the IPartialPack constant is set to 1 in the Logistic Constants form), you can designate the number and type of packing crates and then revise the received quantity accordingly. Once you do, however, any revision to the number or type of packing crates will have no effect on the received quantity.
