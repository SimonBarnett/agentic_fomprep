# To finalize a return document:

 

 1 .  Enter the Returns to Vendor form. 
 

 2 .  Retrieve the desired return document. 
 

 3 .  In the General tab, change the status to Final . 
 
## Notes:

 

 ·        If you have finalized a return document recording the transfer of goods from company inventory to a vendor consignment warehouse, send the vendor a printout of the document; this is how the vendor monitors inventory levels, so as to know when to replenish the consigned stock. 
 

 ·        Click to print the return document . 
 

 ·        Click to return to the main screen .
