# To record a return document based on a GRV:

 

 1 .  Enter the Returns to Vendor form. 
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the General tab). 
 

 2 .  Specify the date the goods were returned. The document number will be filled in automatically. 
 

 3 .  Specify the number of the vendor that supplied the goods. The vendor's name is filled in automatically.
 Note: In the case of a one-time vendor, specify the one-time vendor number. Then revise the name in the Vendor Name column, and fill in the address and other details in the Vendor Details sub-level form. 
 

 4 .  Click the References tab. If the return has already been recorded in an external document, specify the document's number in the External Doc. Number column. Because the information in this return document has already been issued, the Printed column (in the General tab) is flagged. 
 

 5 .  In the GRV column, choose the GRV on which this return document is to be based.
 Note: You can only link to a final GRV. 
 

 6 .  The Warehous e column is filled in automatically from the GRV. If the warehouse from which goods are to be returned to the vendor is not the same as that recorded in the GRV, change its code. The warehouse in all of the line items will be updated accordingly.
 Tip: Different warehouses can be designated for specific lines in the Returned Items sub-level form. 
 

 7 .  The Contact column, Details column (in the References tab), and Project columns (in the Project tab) are filled in automatically from the GRV, but may be revised. Make sure that they are correct.
