# To record a return document manually:

 

 1 .  Enter the Returns to Vendor form. 
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the General tab). 
 

 2 .  Specify the date the goods were returned. The document number will be filled in automatically. 
 

 3 .  Specify the number of the vendor that supplied the goods. The vendor's name is filled in automatically.
 Note: In the case of a one-time vendor, specify the one-time vendor number. Then revise the name in the Vendor Name column, and fill in the address and other details in the Vendor Details sub-level form. 
 

 4 .  Specify the contact at the vendor for the current return.
 Tip: To define new contacts for this vendor, use the Vendor Contacts form, a sub-level of the Vendors form. For more information, see the Open Vendors Wizard . 
 

 5 .  The default warehouse for returning goods appears automatically in the From Warehouse column (in the General tab). Revise as necessary.
 Note: Click to change the default warehouse for future return documents . 
 

 6 .  Click the References tab. If the return has already been recorded in an external document, specify the document's number in the External Doc. Number column. Because the information in this return document has already been issued, the Printed column (in the General tab) is flagged.
