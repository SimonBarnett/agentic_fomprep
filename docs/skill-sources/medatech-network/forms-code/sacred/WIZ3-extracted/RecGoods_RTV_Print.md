# Printing a Return Document

 
## Before you begin:

 

 1 .  Enter the Returns to Vendor form and retrieve the desired document(s). 
 

 2 .  For each document, enter the Vendor Details sub-level form. The details in this form will appear in the printout. Make sure they are correct. 
 

 3 .  Enter the parallel sub-level form, Remarks . The remarks recorded in this form will appear in the printout. Make sure they are correct. 
 

 4 .  If you are printing returns with item remarks , move to the parallel Returned Items sub-level form. Make sure that the remarks displayed in its sub-level, Line Items - Remarks , are correct. Explanation. Revise them as needed.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 5 .  Return to the Returns to Vendor form. 
 
## To print the return document:

 

 ·        Select Print Return to Vendor from the list of Direct Activations .
 Dual-currency users: If you wish to print the return document in English and are working in another language, select Print Return to Vend-ForeignLang instead. 
 
## To print more than one return document:

 

 ·        Run the Print Return to Vendor report (or the Print Return to Vend-ForeignLang report to print in English when working in a different language). 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen .
