# Revising a Final Return Document

 

Once a return document is final, you can still revise certain details – such as its billing status, document status and the user responsible for handling it – in a special form. Moreover, as long as the document has not been billed, you can reopen it and make any needed revisions directly within it. 
 

 Note: 
 

You can change the status of a final return document (to another final status) or the name of the user responsible for handling it, in the Returns to Vendor form. 
 
## To revise a final return document:

 

 1 .  Retrieve the desired document in the Revision of Final Vendor Return form. 
 

 2 .  Make any necessary revisions in that form and in its sub-level, Change Bill Status-Returned Part . 
 
## To reopen a final return document:

 

 1 .  Retrieve the desired document in the Returns to Vendor form. 
 

 2 .  Select Reopen Document from the list of Direct Activations . The document will return to the initial status.
