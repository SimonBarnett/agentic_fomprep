# Returning Goods

 

When you return goods to a vendor, the quantities of parts recorded in the document are subtracted from the inventory balances for those parts in the warehouse from which they are returned. 
 

Return documents can be itemized automatically on the basis of a GRV, or manually. 
 
## What do you want to do?

 

 Record a return document based on a GRV 
 

 Record a return document manually 
 

 Record a return document for goods on consignment from a vendor 
 

 Finalize a return document 
 

 Revise a final return document 
 

 Cancel a pending return document 
 

 Print a return document
