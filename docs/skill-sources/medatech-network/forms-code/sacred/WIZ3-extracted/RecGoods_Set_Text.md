# Set Text for Vendor Returns

 

If you want certain remarks to appear on all printouts of vendor return documents, you can designate set text for this purpose. These remarks will automatically appear in the Remarks sub-level form of each new vendor return document, but may be revised there. Any remarks appearing in that sub-level form appear automatically in the printout of the return document. 
 
## To designate set text:

 

 1 .  Enter the Set Text for Returns to Vendor form. 
 

 2 .  Record the desired remarks in the Set Text for Returns to Vendor sub-level form.
 Dual-currency users: If you are working in a language other than English, and wish to print out vendor returns in English, record set text in the Set Text Vendor Returns-Lang2 sub-level form as well. Any documents opened for vendors defined as receiving Printouts in Lang 2 will contain set text in English.
