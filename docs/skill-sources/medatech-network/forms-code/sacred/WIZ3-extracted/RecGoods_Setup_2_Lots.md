# Lot Number Assignment and Shelf Life

 

 Priority can be set up to automatically open a new lot for received parts when you record the receipt of goods. This number is either taken from the vendor's lot number, or generated internally according to a defined template. 
 

The template can include a prefix and/or suffix, and you can dictate the number of characters in it by designating the number of placeholders. You can also dictate a starting value by recording the number before it ( Last Value ). 
 

You can define as many templates as you want and assign each one to one or more parts. Example . 
 

In addition, most parts for which lots are maintained have a limited shelf life. For such parts, it is important to define the number of months and/or days they can remain in use. When you record the receipt of such parts, the system automatically sets an expiration date for the lot based on the part's defined shelf life (although the expiration date can be revised).
