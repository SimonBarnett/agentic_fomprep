# Defining Packing Crates

 

To record the receipt of packed goods, you must create a list of packing crates, indicating their capacity. 
 
## To record crate types:

 

 1 .  Enter the Packing Crate Types form. 
 

 2 .  For each type, record a Crate Type Code and Crate Type Desc. (e.g., small box). 
 

 3 .  Designate the weight and volume of this type of crate. 
 

 4 .  Specify the crate's Capacity , i.e., the number of parts it usually holds, in buy/sell units. If capacity varies according to the part being packed, use the Crate Capacity per Part sub-level form instead.
