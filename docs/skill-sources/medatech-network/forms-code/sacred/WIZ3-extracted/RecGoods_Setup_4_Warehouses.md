# Defining Default Warehouses

 
## To define a default warehouse for receiving goods:

 

 1 .  Enter the Inv. Transaction Documents form. 
 

 2 .  Move to the Receipt of Goods line. 
 

 3 .  In the Default Warehouse column, choose the desired warehouse. 
 

 4 .  If you want to define a default bin, choose the appropriate value in the Bin column. 
 
## To define a default warehouse for returning goods:

 

 ·        Repeat the above process on the Return to Vendor line. 
 
## Notes:

 

 ·        When a consignment warehouse is assigned to a vendor, it becomes the default warehouse for GRVs from (and returns to) that vendor. Click for more information . 
 

 ·        To define additional warehouses, run the Open a Warehouse Wizard .
