# Copying Part Remarks to GRVs and Vendor Returns

 

You can set up GRVs and/or vendor return documents so that part remarks are recorded automatically for individual items when a part number is recorded or revised in an itemized document. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "GRV" and/or "Vendor Return", flag the Copy Part Remarks column.
