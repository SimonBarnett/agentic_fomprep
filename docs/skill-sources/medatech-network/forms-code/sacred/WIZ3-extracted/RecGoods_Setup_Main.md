# Setting Up Receiving/Return Documents

 

Before you begin recording the receipt/return of goods, you need to set up the following: 
 

 Business processes (BPM) for GRV and return documents (statuses) 
 

 Linking received goods to their original purchase orders 
 

 The method of assigning lot numbers and the definition of shelf life (if you work with lots) 
 

 Packing crates for the receipt and return of goods by crate 
 

 Default warehouses for the receipt and return of goods 
 

 Whether the return of goods to the vendor reopens the original purchase order 
 

 S et text for vendor returns 
 

 P art remarks for GRVs and vendor returns
