# Setting Up the Linkage of Received Goods to Purchase Orders

 

The PAutoFindOrd constant determines whether the system will match each item recorded manually in a GRV (or vendor invoice) with the purchase order and line item it is coming to fill. 
 

If you are used to receiving shipments that completely fill one or more purchase orders, order and line values appear automatically as a result of automatic itemization. System matching is therefore unnecessary, and may even be a hindrance when making manual additions to the document. 
 

If you are used to receiving shipments that only partially fill a single purchase order, or contain discrete items from several different purchase orders, system matching is a useful way to track the closure of purchase orders. 
 
## To set the constant:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the PAutoFindOrd constant and choose the desired value.
