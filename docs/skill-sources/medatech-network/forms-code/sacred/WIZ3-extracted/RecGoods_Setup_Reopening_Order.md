# Reopening the Purchase Order When Goods are Returned

 

You can set a constant so that, when goods are returned to the vendor, the original purchase order is reopened (together with the order item for each returned part). 
 
## To set the constant value:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Choose the appropriate value for the POpenOrder constant.
