# Working With Credit Vouchers

 

Credit vouchers can be given to customers to apply towards future purchases. For instance, you might provide customers with a credit voucher when they return merchandise or as a sales promotion. When goods are returned, you record a (negative) over-the-counter invoice, which doubles as a customer return. When inventory is not affected, you record a (negative) customer receipt instead. 
 

If you wish to work with credit vouchers, you need to define a special Credit Voucher GL account and bank account, as well as a Credit Voucher payment means. 
 
## Note: 

 

Vouchers themselves are not provided by the system, but rather must be printed separately. 
 
## What do you want to do?

 

 Set up credit vouchers 
 

 Issue a credit voucher for returned merchandise (over-the-counter invoice) 
 

 Issue a voucher for credit only (customer receipt) 
 

 Record use of a credit voucher
