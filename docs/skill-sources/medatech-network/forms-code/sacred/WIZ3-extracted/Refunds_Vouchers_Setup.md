# Setting Up Credit Vouchers

 

If you wish to work with credit vouchers, then you must define: 
 

 ·        A GL account and cashier for credit vouchers 
 

 ·        Credit vouchers as a means of payment 
 
## To define an account to be used for credit vouchers:

 

 1 .  Open a GL account for credit vouchers in the Chart of Accounts form, assigning the appropriate balance sheet item (e.g., an item under Current Liabilities). 
 

 2 .  Define a cashier in the Cashiers form, assign a Cashier Code and Cashier Description , and specify the GL Account you just opened. 
 
## Tip:

 

For more details on opening GL accounts and cashiers, run the Open GL Accounts Wizard and Set Up Cashiers Wizard , respectively. 
 
## To define credit vouchers as a means of payment:

 

 1 .  Enter the Payment Means form. 
 

 2 .  Record a Payment Code and a description (e.g., Credit Voucher). 
 

 3 .  Flag the Allow Negative Value column. 
 

 4 .  In the Cash/Bank/Credit Cd column, specify the code of the cashier you just opened for credit vouchers.
