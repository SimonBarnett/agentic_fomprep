 ·     Width – Defined in terms of number of characters. 
 

 ·     Input – Defines the column as input to the report. 
 

 ·     Field in Title – The column does not appear together with the others; rather, each value in that column appears as a horizontal sub-title under which the report data are grouped. Example. 
 

 Note s : 
 

 ·     Some columns are flagged by default as input to certain reports. You can remove these flags as you see fit. 
 

 ·     You can hide an input column from the report by flagging the Hidden column. 
 

 ·     You cannot assign the Field in Title attribute to a column if it is not also assigned to the preceding column. 
 

 9 .  If you have included an expression column in your report, use the relevant column numbers to define the expression. If there are any columns in the expression that you do not want to display separately in the report, go back to the column selection screen and remove them from the Displayed Fields area.

## To add a user-defined report to a Priority menu:

 

 1 .  Navigate to the desired sub-menu and right-click the menu title. 
 

 2 .  Select Add User-Defined Report . 
 

 3 .  Choose the desired report type. 
 

 4 .  Choose the desired report.
 Note: Only the system manager and users in the manager's group are authorized to add such reports to a menu.
