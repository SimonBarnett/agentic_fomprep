Report Generators Wizard – Generating an SQL Query Based on Customized Reports 
 
 
- 
 
 
 
## To generate an SQL query on the basis of a user-designed (customized) report:

 

 1 .  Enter the Customized Rep. Generator-Query form. 
 

 2 .  Retrieve the desired report, then select Create SQL Query from the list of Direct Activations. 
 

 Note s : 
 

 ·        When the program finishes running, the query is displayed in Notepad. This file can be revised as necessary and saved to the location of your choice. 
 

 ·        SQL queries generated in this fashion can be used to retrieve data in BI tools, thereby providing a graphic display of the data.
