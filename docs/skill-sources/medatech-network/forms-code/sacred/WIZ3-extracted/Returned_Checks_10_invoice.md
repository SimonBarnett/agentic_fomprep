# Preparing an Invoice for the Return Fee and Finance Charges

 
## To prepare an invoice:

 

 1 .  Enter the Returned Payments form and retrieve the desired return document. 
 

 2 .  Select Prepare Invoice for Charges from the list of Direct Activations . 
 
## Note:

 

You cannot record an invoice to a restricted customer. If the Restricted constant determines that a customer automatically becomes restricted once a return of payment is recorded, you must wait until the restriction is manually lifted before you can record an invoice billing the return fee and/or finance charges. For more information, see the Restricting Customers Wizard .
