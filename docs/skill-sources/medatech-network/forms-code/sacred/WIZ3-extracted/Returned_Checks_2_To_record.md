# Recording a Returned Check

 

There are a number of ways of working when recording the return of a check from a customer: 
 

 ·        If you want to cancel the original payment, you record the return document directly against the customer's account. When you receive a replacement check (or other form of payment), you record a customer receipt for the new payment, reconciling it with the returned check. More details. 
 

 ·        If you do not know whether or not the returned check will be redeposited, you should record the document for the Returned Payments Cashier , transferring the check to that cashier. If it is eventually redeposited, you record a deposit slip from the Returned Payments Cashier to the bank. If not (e.g., if it is replaced by a new check), you debit the A/R account by recording a deposit slip from the Returned Payments Cashier to the customer (and record a customer receipt for the new payment, reconciling it with the returned check).
