# Printing Notices to Customers

 
## Before you begin:

 

 1 .  Enter the Returned Payments form and retrieve the desired document. 
 

 2 .  Enter the Returned Check - Remarks sub-level form. Check the text recorded there, which will appear as remarks on the printout. Revise it if necessary. 
 

 3 .  Enter the parallel sub-level form, Returned Payment - Add'l Details . Make sure that the mailing address appearing there is correct.
 Tip: To update the address of a regular customer (as opposed to a walk-in customer), use the Customers form. 
 

 4 .  Return to the upper-level form.
