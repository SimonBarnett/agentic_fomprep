# Removing a Returned Payment From the Cashier

 

A returned payment can be handled in one of several ways: 
 

 ·        Deposit to the A/R account. If the customer is expected to provide a replacement payment, the returned payment can be transferred to the A/R account, thereby adding to the customer's debt. When the replacement is received, a new customer receipt is recorded and reconciled with the deposit (as well as the invoice for the return fee/finance charges).
 Tip: Rather than making a deposit, you can directly charge the A/R account while you are recording the return document, by deleting the cashier code that appears automatically. 
 

 ·        Re-deposit in the bank. If the customer has resolved whatever problems caused a given check to be returned, you can re-deposit the check. 
 

 ·        Deposit to a third party. If necessary, you can deposit the returned payment to a third party for collection.
