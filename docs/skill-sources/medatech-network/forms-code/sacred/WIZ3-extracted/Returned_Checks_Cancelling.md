# Canceling a Final Returned Payment Document

 

If errors are discovered in a finalized document, you can create a new document with negative values, which cancels the original one and creates a reversing journal entry. 
 
## To cancel a final document:

 

 1 .  Enter the Returned Payments form and retrieve the desired document. 
 

 2 .  Do one of the following: 
 

 ·              Select Cancel Document (Original Date) from the list of Direct Activations to create a cancellation document and reversing journal entry dated to the original document date. 
 

 ·              Select Cancel Document For Date from the list of Direct Activations to create a cancellation document and reversing journal entry for a designated date. 
 
## Notes:

 

 ·        In order to cancel a final document whose journal entry is still pending, you must post the entry before running the cancellation program. 
 

 ·        You must be authorized to change the status of returned payment documents to Canceled . 
 
## To view cancellation results:

 

Every canceled document and the document that canceled it are flagged in the Canceled column of the Payment Details tab. Both documents will be for the same amount, with different signs (positive amounts in the original document and negative amounts in the cancellation document).
