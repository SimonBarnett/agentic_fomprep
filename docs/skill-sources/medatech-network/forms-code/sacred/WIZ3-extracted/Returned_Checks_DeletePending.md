# Deleting a Pending Returned Payment Document

 

Pending documents are documents that have not yet been finalized and can be deleted from the system. 
 
## To delete a pending document:

 

 1 .  Enter the Returned Payments form and retrieve the desired document. 
 

 2 .  Select Delete Pending Document from the list of Direct Activations . 
 
## Note:

 

Click to return to the main screen.
