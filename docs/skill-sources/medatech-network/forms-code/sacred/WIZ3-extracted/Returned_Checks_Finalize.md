# Finalizing Returned Payments

 

When you finalize a payment return document, the following occurs: 
 

 ·        A unique internal document number is generated, which replaces the temporary number that appeared when the document was opened. 
 

 ·        A journal entry is recorded for the returned payment. 
 

 ·        The status of the document is set to Final . 
 
## Note:

 

If you have not flagged the Post Journ. Entries column for returned payments (in the Financial Documents form), the journal entry created is only pending. That is, it needs to be checked and posted.
