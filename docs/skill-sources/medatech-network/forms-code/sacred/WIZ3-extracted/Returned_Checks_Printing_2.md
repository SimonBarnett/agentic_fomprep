Returned Payments - Printing a Notice.2 
 
 
- 
 
 
 
## To print a single notice:

 

 ·        If the return is of a check, select Print Returned Check Notices from the list of Direct Activations . 
 

 ·        If the return is of a credit card payment or standing order, select Print Returned Payment Notices from the list of Direct Activations . 
 
## To print a batch of notices:

 

 ·        For returned checks, run the Print Returned Check Notices program. 
 

 ·        For other types of returned payments, run the Print Returned Payment Notices program.
