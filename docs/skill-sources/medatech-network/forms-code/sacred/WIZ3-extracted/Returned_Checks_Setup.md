# Setting up Returned Payments

 

Before you begin recording returned payments, you need to: 
 

 ·        Set up business processes (BPM) for returned payments – i.e., define statuses. 
 

 ·        Determine whether a customer whose payment has been returned is automatically defined as restricted. 
 

 ·        Define document attributes, which affect journal entries, as well as remarks on printouts. 
 

 ·        Set up finance charges (if you intend to apply such charges to returned payments). 
 

 ·        Adjust the definition of entry codes affecting returned payments (if you plan to record invoices for return fees). 
 
## What do you want to do?
