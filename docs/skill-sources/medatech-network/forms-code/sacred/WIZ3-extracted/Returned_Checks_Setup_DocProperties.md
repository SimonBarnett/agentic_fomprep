# To define document properties:

 

 1 .  Enter the Financial Documents form. 
 

 2 .  Move to the Returned Payment line and check the default properties, revising them if necessary. In particular: 
 

 ·              Post Journ. Entries : Determines whether a journal entry will be posted to the ledger automatically when the document is finalized. 
 

 ·              Finalize Immediately : Determines whether the document, once opened, must be finalized before the user can leave the form. 
 

 3 .  Use the Set Text for Document sub-level form to record set text that will appear in all returned payment notices (including returned check notices). Alternatively, to record set text that will appear in all returned payment notices for specific branches and entry codes, move to the appropriate branch in the Journal Entry Codes per Branch form, and record the set text in the Set Text for Branch sub-level form. Any text recorded for a specific branch and entry code will override the default text for that document type. You can later change or delete this text for each individual document. 
 
## Notes:

 

 ·        D ual-currency users : If you work in a language other than English, you can record set text in English in the Set Text for Document - Lang2 sub-level form. You may also record set text for specific branches and entry codes by moving to the appropriate line in the Journal Entry Codes per Branch form, and recording the set text in the Set Text for Branch - Lang2 sub-level form. This text will appear in notices printed out for customers that have been defined to receive Printouts in Lang 2 (in the Customers form). 
 

 ·        For more information on document properties, run the Set Up Financial Docs Wizard .
