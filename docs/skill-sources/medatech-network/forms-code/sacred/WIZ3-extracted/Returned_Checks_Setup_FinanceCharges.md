# To set up finance charges:

 

 1 .  Enter the Finance Charge Codes form and create a list of types of finance charges. 
 

 2 .  For each type of finance charge, define charge rates in the Breakdown of Finance Charge sub-level form. 
 

 3 .  In the Financ. Parameters for Customers form, assign a finance charge code to each customer (in the Charges tab). 
 
## Note: 

 

For detailed information, run the Finance Charges Wizard .
