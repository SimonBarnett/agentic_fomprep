# Cancelling Automatic Restriction of a Customer Whose Payment is Returned

 

By default, when a customer's payment is returned by the bank or the credit card company, and a returned payment document is opened, the customer is automatically assigned the Restricted status. You can change this to the Warn ed status or any other status, or you can disable the mechanism altogether. 
 
## To disable automatic restriction of the customer:

 

 1 .  Run the BPM Flow Chart-Customers program. 
 

 2 .  Right-click the Restricted status and select Properties . 
 

 3 .  Remove the check mark from the For Returned Payment column. 
 

 4 .  Move to the status in question and flag it For Returned Payment (or leave the column unflagged for all statuses). 
 
## Tip:

 

To see which status is currently defined in this way, enter the Statuses for Customers form.
