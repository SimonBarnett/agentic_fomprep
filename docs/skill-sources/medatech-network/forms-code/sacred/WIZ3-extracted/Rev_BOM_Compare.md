# Comparing BOM Revisions

 

 Priority provides a report that allows you to compare the composition of different BOM revisions. The report displays child parts, their quantities and their designation data. If you choose to compare more than two revisions at a time (e.g., by using operators to make multiple selections for the compared revisions), the report independently matches each revision in the first group with each revision in the second group. 
 
## To compare BOM revisions:

 

 ·        Run the Comparison of BOM Revisions report.
