# To open a BOM revision based on an ECO: 

 

 1 .  Enter the Parts in the ECO sub-level form.
 Note: You can also retrieve the desired part in the Parts form. 
 

 2 .  For each part, enter the BOM Revisions sub-level form. 
 

 3 .  Record a BOM Revision Number and Description . 
 

 4 .  In the Effect Date column, specify the date on which the new revision is intended to go into effect. The sub-level forms of the new revision are automatically filled in with the data defining the BOM revision currently in effect. 
 

 5 .  Change any or all of the following definitions: 
 

 ·      To make changes to child parts, parent/child ratios, parent operations and/or child operations, use the Child Parts sub-level form. 
 

 ·      To change child part designations, use the Child Part Designations sub-level form. 
 

 ·      To set up a warning that will appear when a user tries to delete a given part from a customized BOM in this revision, use the Custom BOM for Item: Conditions sub-level form. 
 

 Tip: For detailed instructions regarding these definitions, run the Factory Modelling Wizard .
