# Reopening a BOM Revision

 

In order to reopen a BOM revision for changes, all of its authorizers must remove their authorization. 
 
## Authorizer instructions:

 

 ·      Do one of the following: 
 

 ·        If no authorizer list was defined and you are the sole authorizer, remove the check mark from the Authorized column. 
 

 ·        If there is an authorizer list for BOM revisions, enter the Revision Authorization sub-level form in reverse order (i.e., the last authorizer first) and remove the check mark from the Authorize column next to your name. 
 
## Note:

 

When the final check mark has been removed from the Revision Authorization sub-level form, the check mark will no longer appear in the Authorized column of the BOM revision in the BOM Revisions form.
