# To print the current ECO:

 

 ·        Enter the Engineering Change Orders (ECO) form, retrieve the ECO in question and click Print ECO on the Direct Activation bar.
 D ual-currency users : If you wish to print the ECO in English and are working in another language, click Print ECO in Foreign Language instead. 
 
## To print multiple ECOs:

 

 ·        Run the Print ECO report.
 D ual-currency users : To print in English when working in another language, run the Print ECO in Foreign Language report.
