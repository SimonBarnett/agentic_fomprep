# Working With Part Revisions

 

Part revisions are usually due to engineering changes and/or BOM revisions. They can be authorized independently (in which case there is a separate revisions authorizer list), or automatically via authorization of the ECO (provided the revisions authorizer list is empty). In the former case, the part revision must be fully authorized before the authorization process can begin for the ECO to which it is linked. 
 
## What do you want to do?

 

 Open a part revision 
 

 Authorize a part revision 
 

 Put a part revision into effect 
 

 Delete or deactivate a part revision
