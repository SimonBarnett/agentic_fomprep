# Creating Authorizer Lists

 

 Priority provides a unified authorizer list for BOM revisions and part revisions, as well as a separate authorizer list for ECOs. 
 

Part revisions or BOM revisions that are linked to an ECO are authorized automatically upon authorization of the ECO. When part revisions are created automatically on the basis of BOM revisions (i.e., the IdentRevs constant is set at 1 ), and the latter are linked to an ECO, both revisions are authorized together with the ECO. Once a revision is linked to an ECO, it cannot be authorized independently, even when a revisions authorizer list has been defined. 
 
## To define an authorizer list:

 

 1 .  Enter the ECO Authorizers form and/or the Revision Authorizers form. 
 

 2 .  Specify the Name and Signature Order of each authorizer (the lowest number must sign first).
