# Initializing Parts for BOM Revisions

 
## Note:

 

Initializing a part to maintain BOM revisions is an irreversible decision; that is, any changes to the BOM (e.g., child parts, operations, designations) can only be recorded and authorized in a BOM revision. 
 
## To initialize a part to maintain BOM revisions:

 

 1 .  Enter the Parts form and retrieve the desired part. 
 

 2 .  Click the Additional Details tab and flag the BOM Revisions column.
