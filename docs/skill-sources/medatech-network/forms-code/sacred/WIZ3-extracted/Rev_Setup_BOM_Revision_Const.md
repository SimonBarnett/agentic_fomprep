# Creating Automatic Part Revisions

 

By default, part revisions are created independently of BOM revisions, and require separate authorization. Alternatively, you can cause a new part revision to be created automatically upon the authorization of a new BOM revision, and receive the same number. Unless the effect date of the BOM revision is in the future, the new part revision goes into effect immediately, with no need for further authorization. 
 
## To create part revisions automatically on the basis of BOM revisions:

 

 1 .  Enter the Planning Constants form and move to the IdentRevs constant. 
 

 2 .  Change the value to 1.
