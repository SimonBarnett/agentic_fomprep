# Allowing Changes to an Authorized BOM Revision

 

You can set the system to allow you to make changes to an authorized BOM revision (that is, after revoking its authorizations). 
 
## To set up the system to revise authorized BOM revisions:

 

 1 .  Enter the Planning Constants form and move to the ChnConfRev constant. 
 

 2 .  Change the value to 1 .
