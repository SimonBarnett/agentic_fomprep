# Using a Part Revision from an Unauthorized ECO

 

You can set the system to allow you to specify part revisions in inventory documents, even when the ECO to which they are linked has not been authorized. 
 
## To allow the use of part revisions linked to unauthorized ECOs:

 

 1 .  Enter the Planning Constants form and move to the RevECOErr constant. 
 

 2 .  Change the value to 1 . 
 
## Note:

 

Users will continue to receive a warning message when specifying such revisions, even after you’ve changed the value of this constant.
