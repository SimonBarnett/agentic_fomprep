# Setting Up ECOs and Revisions

 

Before you can begin working with ECOs and revisions, there are several crucial setups that must first be performed. In particular, you need to flag those parts for which you intend to maintain BOM revisions. 
 
## What do you want to do?

 

 Set up business processes (BPM) for ECOs (define statuses) 
 

 Define reasons and implications for ECOs 
 

 Create part revisions automatically on the basis of BOM revisions 
 

 Define authorizer lists for ECOs and revisions 
 

 Initialize parts for BOM revisions 
 

 Allow changes to authorized BOM revisions 
 

 Allow the use of a part revision based on an unauthorized ECO 
 
## Notes:

 

 ·        If you wish to copy parts together with their revisions, make sure the CopyPartRev constant is set to 1 . For details, see the Part Definition Wizard .
