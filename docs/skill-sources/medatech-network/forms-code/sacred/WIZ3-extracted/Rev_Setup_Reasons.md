Revisions - Defining Reasons and Implications for ECOs 
 
 
- 
 
 
 
# To define reasons for ECOs:

 

 1 .  Enter the Reasons for ECOs form. 
 

 2 .  Specify a code for each reason and describe it in the Reason for ECO column. 
 
## To define implications of ECOs:

 

 1 .  Enter the List of ECO Implications form. 
 

 2 .  Specify a code for each implication and describe it in the Implication column.
