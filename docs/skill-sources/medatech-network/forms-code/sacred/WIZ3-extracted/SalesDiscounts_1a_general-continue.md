# Price Hierarchy

 

When recording a sales document, an item price appears automatically from one of a variety of sources, in the following order: 
 

 ·        Part prices from the document on which the current document is based 
 

 ·        The price set for the component in a product bundle on which the current document is based 
 

 ·        The price list manually linked to the current document 
 

 ·        The special part price offered 
 

 ·        The valid customer price list 
 

 ·        The base price list 
 

 ·        A vendor price list defined as a price source for customers 
 
## Notes: 

 

 ·        The levels “special part price” and “valid customer price list” each subdivide into three sub-levels: if a value has not been defined for a customer, it is taken from the representative customer; if it has not been defined for the representative customer, it is taken from the general representative. 
 

 ·        A price recorded manually always overrides all other price sources.
