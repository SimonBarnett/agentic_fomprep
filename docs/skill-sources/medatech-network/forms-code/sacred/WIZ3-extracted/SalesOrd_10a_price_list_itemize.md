# To itemize the order:

 

 1 .  Enter the Order Items sub-level form. 
 

 2 .  Record the Part Number of the ordered item. 
 

 3 .  Do one of the following: 
 

 ·              If the customer ordered packed goods, designate the Crate Type Code and the number of crates. The ordered quantity will be calculated automatically, based on crate capacity. 
 OR 
 

 ·              Record the Quantity manually. 
 

The appropriate price and discount from the blanket order will be displayed automatically according to quantity. 
 

 Notes : 
 

 ·              If you are allowed to record partially packed crates (i.e., the IPartialPack constant is set to 1 in the Logistic Constants form), you can designate the number and type of packing crates and then revise the ordered quantity accordingly. Once you do, however, any revision to the number or type of packing crates will have no effect on the ordered quantity. 
 

 ·              If the customer is eligible for a bonus associated with the recorded item, a “bonus line” is automatically added to the order, accompanied by a message. If the customer does not want the bonus, delete the bonus line. For more information on bonuses, see the Bonuses Wizard . 
 

 ·              You can view expected profit on the item in the Profit column. For more details, see the Profitability Wizard . 
 

 ·              For more information on prices and their sources, see the Prices and Discounts Wizard .
