# Viewing a History of Changes to an Order

 

You can view a variety of changes made to order items (e.g., quantity, price). 
 
## To view changes to a single order:

 

 1 .  Enter the Sales Orders form and retrieve the order in question. 
 

 2 .  Enter the sub-level form, History of Changes . 
 
## To view changes to multiple orders:

 

 1 .  Enter the History of Sales Order Changes form. 
 

 2 .  Retrieve the desired records (e.g., by order number) and review changes.
