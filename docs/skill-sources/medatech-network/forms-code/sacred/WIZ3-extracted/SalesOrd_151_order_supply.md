# Order Supply

 

 Priority helps you keep track of order supplies by monitoring the handling and balance of orders and ordered parts. 
 
## What do you want to do?

 

 View open sales orders 
 

 View the handling of ordered items 
 

 Anticipate inventory requirements 
 

 View overdue sales orders
