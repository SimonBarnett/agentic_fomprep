# Open Sales Orders

 
## To view open orders per customer:

 

 ·        Run the Backlog per Customer report to view the backlog of open orders per customer, over a given period. 
 

 ·        Run the Orders to Carry Out (by Cust.) report to view all parts on order and their status, sorted by customer and order number. 
 
## To view open orders assigned to particular employees:

 

 ·        Run the Backlog per Assigned User report to view the backlog of open orders per employee, over a given period. 
 

 ·        Run the Orders to Carry Out (by DueDate) report to view all parts on order and their status, sorted by employee and due date. 
 
## Note: 

 

When more than one employee is assigned to an order, the reports refer to the main employee assigned to that order.
