# Order Item Tracking

 
## To track the handling of a given order item:

 

 1 .  Enter the Sales Orders form and retrieve the order in question. 
 

 2 .  Enter the Order Items sub-level form and move to the desired line item. 
 

 3 .  Enter the Order Tracing sub-level form to view the details of all inventory transactions involving the selected order item (e.g., Packing Slip, Customer Shipment, Sales Invoice). 
 
## To track the handling of one or more orders and/or ordered parts:

 

 ·        Run the Order Tracing report.
