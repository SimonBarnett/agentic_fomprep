# Anticipating Inventory Requirements

 

You can estimate the number of parts that need to be produced in order to meet the due dates of existing order items by comparing ordered quantities to current inventory balances. 
 

You can also determine whether you can supply a given part by a given date by computing future balances of the part, based on current inventory, scheduled customer shipments, and expected production. 
 
## To compare orders to inventory balances:

 

 ·        Run the Demands and Inventory report. 
 
## To view projected balances:

 

 ·        Run the Available to Promise (Proj Bals) report.
