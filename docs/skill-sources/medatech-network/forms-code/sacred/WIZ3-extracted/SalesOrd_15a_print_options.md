# Printing the Order Confirmation

 
## To print a confirmation for one order:

 

 1 .  Retrieve the order in the Sales Orders form. 
 

 2 .  Select Order Confirmation from the list of Direct Activations .
 D ual-currency users: If you wish to print the order confirmation in English and are working in another language, click Order Confirmation-Foreign Lang instead. 
 
## To print a confirmation for more than one order:

 

 ·        Run the Order Confirmation report.
 D ual-currency users: To print in English when working in another language, run the Order Confirmation-Foreign Lang report. 
 
## Notes: 

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to continue processing the order.
