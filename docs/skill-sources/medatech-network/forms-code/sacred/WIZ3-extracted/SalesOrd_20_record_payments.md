# Recording Project Payments for the Order

 
## Reminder: 

 

 ·        Before you can record payment installments, you must link the order to the project or one of its activities. 
 

 ·        Do you record payment installments if the order is for work hours that are billed as they are reported. 
 
## To record project payments for the order:

 

 1 . Enter the Payments for Project Order sub-level form. 
 

 2 . Record the payment date in the Date column. 
 

 3 . The payment description is filled in automatically as “Payment to Project”. Revise it if necessary. 
 

 4 . Record the amount of the payment. 
 

 5 . If you want to postpone preparation of the invoice until certain details are checked, flag the Checking column. 
 

 6 . Return to the upper-level form.
