Sales Orders - Linking an Order Item to a Project or Activity 
 
 
- 
 
 
 
# To link an order item to a project or activity:

 

 1 . Enter the Projects/Accounts sub-level form. 
 

 2 . In the Project Number column, choose/check the project number.
 Note : If you have specified a project for the entire order, it will appear automatically and may not be changed. 
 

 3 . The project's default income account appears automatically in the Account Number column. Revise it if necessary. 
 

 4 . In the WBS column, choose/check the WBS code of the activity. 
 

 3 .  Change the Percent Completed , if necessary.
 Note: To revise the Activity Status , move to the Activity ID column and press F6 , then make the revision in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 4 .  Return to the Order Items upper-level form. 
 
## Note: 

 

Make sure the Incl. in Proj. Cost column is correctly flagged in the Order Items form.
