# Closing Orders or Order Items That Were Not Supplied

 

When the remaining items in a partially filled order (or the remaining balances of partially supplied items) are no longer to be supplied, you can close the order or any of its items manually. If you need to close several orders and/or items from several different orders, Priority provides a program that enables you to close them all simultaneously. 
 
## To close an order manually:

 

 1 .  Enter the Sales Orders form and retrieve the desired order. 
 

 2 .  Click the Follow-up tab and flag the Closed column.
