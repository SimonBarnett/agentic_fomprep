# Setting Up Sales Orders

 

Before you begin working with sales orders, you need to perform certain setups. 
 
## What do you want to do?

 

 Set up the rounding constant 
 

 Determine how order prices are calculated in a customized BOM 
 

 Define whether order items with zero quantity close automatically 
 

 Set up business processes (BPM) for orders and statuses for order items 
 

 Copy price quote remarks to orders 
 

 Record set text for orders 
 

 Set up part remarks for orders 
 

 Define sales types 
 

 Define packing crate types 
 
## Notes:

 

 ·        To define product bundles on which to base an order, run the Product Bundles Wizard . 
 

 ·        When working with projects, you can also set a default determining whether the cost of open order items is taken into account when calculating the project's projected costs. For details, run the Project Management Wizard .
