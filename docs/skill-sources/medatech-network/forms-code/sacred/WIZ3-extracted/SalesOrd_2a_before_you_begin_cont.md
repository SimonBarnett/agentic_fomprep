# Setting Up Business Processes and Item Statuses

 

You set up business processes by defining statuses in a BPM flow chart. 
 

There are several predefined statuses for sales orders, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 

In addition, you can create a set of statuses to assign to individual order items. 
 
## To set up business processes:

 

 ·        Run the BPM Flow Chart-Sales Orders program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Orders form. 
 

 ·        To add a status description that will appear on printouts of any order with a given status, retrieve that status in the Statuses for Orders form and specify the description in the Additional Status Definitions sub-level form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide . 
 
## To create order item statuses:

 

 1 .  Enter the Statuses for Order Items form. 
 

 2 .  In the Status column, record a name for the new status. 
 

 3 .  To allow shipping documents to be opened and project hours/expenses to be reported for order items with this status, flag the Allow Shpmt/ProjRep column. 
 

 4 .  In the Display Order column, number the statuses according to the order in which you want them to appear in the Choose list.
