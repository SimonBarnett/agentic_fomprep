# Defining Types of Sales

 

Each sales order can be assigned a specific type of sale, each with its own designated set text. This text will automatically appear in the Sales Orders - Remarks sub-level form of any order of this type, overwriting the general set text defined for sales orders, and consequently appear on the printout. In addition, you can create a check list for each sales type, i.e., a list of tasks to be opened automatically when any sales order is assigned that sales type. Example. 
 
## To define sales types:

 

 1 .  Enter the Types of Sales form. 
 

 2 .  Record the code number and description of the desired sale type. 
 Dual-currency users: If you are working in a language other than English, and wish to produce reports that include a description of the sales type in English, fill in the Type of Sale (Lang2) column. 
 

 3 .  Enter the Set Text for Quotes/Orders sub-level form and record set text for this type of sale.
 Dual-currency users: If you are working in a language other than English, and wish to print orders in English, record set text in the Set Text for Quotes/Orders-Lang2 sub-level form. Any orders of this type opened for customers defined as receiving Printouts in Lang 2 will contain set text in English. 
 
# Defining a Default Sales Type for Specific Users

 

Individual users can be assigned default sales types, which will appear automatically on any order they record. 
 
## To assign a default sales type:

 

 1 .  Enter the Personnel File form and retrieve the desired user. 
 

 2 .  Enter the Company-Specific Information sub-level form, and choose the appropriate Type of Sale . The set text for that sale type will appear automatically in every sales order recorded by that user. 
 
## Notes: 

 

 ·        The default sales type will also be assigned automatically to any price quote opened by this user. 
 

 ·        Click to create a check list for a sales type
