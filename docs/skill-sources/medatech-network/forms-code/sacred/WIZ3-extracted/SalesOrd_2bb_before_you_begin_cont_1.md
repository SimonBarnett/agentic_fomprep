# Creating a Check List for a Type of Sale

 

You can predefine a list of tasks that must be performed as part of a standard process when handling a particular type of sales order, such as the sale of software licenses. This check list is linked to a relevant sales type, such that tasks are opened automatically based on the check list whenever that sales type is assigned to a sales order. 
 

Each task that is opened in this manner receives the designated status and appears in the Tasks for Document sub-level form under the sales order for which it was opened. Each of these tasks must be completed before the order can be assigned a status flagged as Allow Shipmt/ProjRep . 
 
## To create a check list for a sales type:

 

 1 .  Enter the Types of Sales form and retrieve the desired sales type. 
 

 2 .  Enter the Check List for Orders sub-level form and select the employee to whom the task will initially be assigned. 
 

 3 .  Record a Subject for the task, and select a Task Code and Task Type , if desired. 
 

 4 .  Do one of the following: 
 

 ·              To open the task for the date on which it is created, leave the Day of Month and Next Month columns blank. 
 

 ·              To open the task for a specific day of the current month, indicate the desired day of the month and leave the Next Month column blank. 
 

 ·              To open the task for the first day of the following month, leave the Day of Month column blank and flag the Next Month column. 
 

 ·              To open the task for a specific day of the following month, indicate the desired day of the month and flag the Next Month column. 
 

 5 .  Select the Status to be assigned to the task, when opened.
