# Copying Price Quote Remarks to Orders

 

The SCpyQuoteTxt constant determines whether remarks recorded for a price quotation are copied automatically into any sales order opened for that quote. 
 
## To set the constant value:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the line for the SCpyQuoteTxt constant, and select the appropriate value.
