# Recording an Order Based on a Price Quotation

 

When basing an order on one or more price quotations, you can choose between three options: 
 

 ·        Open the order from within a price quote, copying all line items. 
 

 ·        Copy all line items from each quote to the order (these items can then be revised). 
 

 ·        Record each part number and its quantity manually; prices and other data are filled in automatically from the quote(s). This option is useful when different prices are quoted for different quantities of the same part. Example. 
 
## What do you want to do?

 

 Open the order from within the quote
