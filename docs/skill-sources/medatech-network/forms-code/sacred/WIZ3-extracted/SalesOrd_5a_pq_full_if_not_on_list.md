# If the price quotation is not in the Choose list:

 

 1 .  Enter the Active Price Quotations sub-level form, which displays all of the customer's active price quotations. Move to the desired quote. 
 

 2 .  A price quote appearing in this form will not appear in the Choose list if its current status does not allow it to open an order. If you still want to base the order on this quote, you must change its status. 
 

 ·              Click to see what statuses allow you to open orders 
 

 ·              Click to change the quote status 
 

 3 .  Return to the Sales Orders upper-level form.
