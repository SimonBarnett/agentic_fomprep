# To check the order items:

 

 1 .  Enter the Order Items sub-level form. The order is itemized automatically according to the price quotation(s). 
 

 2 .  Make sure that the part descriptions are suitable.
 Tip: You can change the description of any part that is flagged in the Change Desc. column of the Part Catalogue form. 
 

 3 .  Make sure that the ordered quantities of each item are correct.
 Tip: To check part availability, use the Inventory for Part and the Part Availability sub-level forms. 
 

 4 .  Make sure that the unit price and discount are correct for each item.
 Tips: 
 

 ·              Select Discounts Applying to Item from the list of Direct Activations to view a breakdown of the discounts awarded for the ordered part. 
 

 ·              You can view expected profit on the item in the Profit column. For more details, see the Profitability Wizard . 
 

 ·              For more information on prices and their sources, see the Prices and Discounts Wizard . 
 

 5 .  The Due Date of each item is based on the number of Supply Days defined in the price quote and appears automatically. Change the date for any item, as required.
