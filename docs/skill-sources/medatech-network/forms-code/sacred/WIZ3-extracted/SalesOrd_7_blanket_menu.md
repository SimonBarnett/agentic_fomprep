# Recording an Order Based on a Blanket Sales Order

 

Blanket sales orders offer the customer special prices for parts, when the customer purchases certain quantities of these parts or goods of a certain total monetary value over a given period. When opening an order based on a given blanket order, part prices are taken from the blanket order. Moreover, any actual sales order updates the balance of parts in the blanket order. 
 

When basing an order on a blanket order, you can choose between two options: 
 

 ·        Copy all line items from the blanket order into the order (these items can then be revised). 
 

 ·        Record each part number and its quantity manually; prices and other data are filled in automatically from the blanket order. This option is useful when the sales order does not contain all of the items listed in the blanket order. 
 
## What do you want to do?

 

 Copy the blanket order to the sales order 
 

 Record an order based on blanket order prices for a quantity of parts 
 

 Record an order based on a blanket order for a given monetary value
