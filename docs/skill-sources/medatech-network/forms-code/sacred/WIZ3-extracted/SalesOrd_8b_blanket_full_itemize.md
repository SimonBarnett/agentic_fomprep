# To itemize the order:

 

 1 .  Enter the Order Items sub-level form. All parts are copied automatically from the blanket order, with their unit price, discount and billing customer. 
 

 2 .  Delete any unnecessary lines (i.e., parts that were not ordered). 
 

 3 .  For each part, do one of the following: 
 

 ·              If the customer ordered packed goods, designate the Crate Type Code and the number of crates. The ordered quantity will be calculated automatically, based on crate capacity. 
 OR 
 

 ·              Record the Quantity manually. 
 

 Note : If you are allowed to record partially packed crates (i.e., the IPartialPack constant is set to 1 in the Logistic Constants form), you can designate the number and type of packing crates and then revise the ordered quantity accordingly. Once you do, however, any revision to the number or type of packing crates will have no effect on the ordered quantity. 
 

 4 .  Make sure that the price and discount are correct for each item.
 Tips: 
 

 ·              Select Discounts Applying to Item from the list of Direct Activations to view a breakdown of the discounts awarded for the ordered part. 
 

 ·              You can view expected profit on the item in the Profit column. For more details, see the Profitability Wizard . 
 

 ·              For more information on prices and their sources, see the Prices and Discounts Wizard .
