# To itemize the order:

 

 1 .  Enter the Order Items sub-level form. It is itemized automatically according to the recorded product bundles and their quantities. 
 

 2 .  The Part Number of each default component for this bundle is filled in automatically. To change the order item, press F6 and select the part in question from the Choose list.
 Note: The Choose list includes all parts defined as substitutes for the default component in this product bundle. 
 

 3 .  Make sure the part quantity is correct.
 Tip: To check part availability, use the Inventory for Part and the Part Availability sub-level forms. 
 

 4 .  If a unit price and/or discount appear automatically, ensure that they are correct and revise when necessary. 
 Tip: For information on prices and their sources, run the Prices and Discounts Wizard . 
 

 5 .  Make sure the Due Date is correct.
