# To cancel an order:

 

 1 .  Enter the Sales Orders form and retrieve the desired order. 
 

 2 .  Enter the Order Items sub-level form and change the quantity of each line item to 0 .
 Tip: If a quantity of crates is specified in the Packing Crates (No.) column, you need to change the value of that column. Return to the upper-level form. 
 

 3 .   Click the Follow-up tab and change the Status to “Canceled”. The Closed column is flagged automatically.
