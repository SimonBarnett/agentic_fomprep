Sales Orders - Closing Orders/Items.2 
 
 
- 
 
 
 

 To close one or more order items manually: 
 

 1 .  Enter the Sales Orders form and retrieve the desired order. 
 

 2 .  Enter the Order Items sub-level form. 
 

 3 .  Move to the desired line and flag the Closed column. 
 
## Note: 

 

If some of the order items are flagged as closed, a check mark appears in the Partially Closed column in the upper-level form (in the Follow-up tab). 
 
## To close orders and/or order items automatically: 

 

 ·        Run the Close Order Items program.

Click to return to the main screen.
