# To view open orders per part:

 

 ·        Enter the View Open Order Items form to retrieve all open items from all existing sales orders, by due date, customer, order number, customer purchase order number and so on. 
 

 ·        Run the Backlog per Part report to view the backlog of parts on order, sorted by due date and order number. 
 

 ·        Run the Backlog per Family report to view the backlog of parts on order, sorted by part family and order number. 
 

 ·        Run the Orders per Part and Due Date report to view all parts on order, sorted by due date and order number, with totals per part. 
 
## Note: 

 

Click to return to the Order Supply menu.
