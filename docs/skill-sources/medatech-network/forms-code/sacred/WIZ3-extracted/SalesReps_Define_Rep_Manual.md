# Defining an Employee or an Independent Agent as a Sales Rep

 
## Before You Begin

 

If the new sales rep is an independent agent that is not already a vendor, you need to open a vendor record and A/P account in order to allow the rep to issue purchase invoices for commissions due. Run the Open Vendors Wizard for details. 
 
## To define a sales rep:

 

 1 .  Enter the Sales Representatives form. 
 

 2 .  Record a Sales Rep Number and Sales Rep Name .
 Note: If the sales rep is an independent agent, use the same number and name assigned to the vendor. 
 

 3 .  Click the Address & Phone tab and record the sales rep's contact info.
