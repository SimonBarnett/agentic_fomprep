# Printing a Commission Document

 
## To print a single commission document:

 

 1 .  Enter the Sales Rep Commission form and retrieve the desired document. 
 

 2 .  Select Print Sales Rep Commission from the list of Direct Activations . 
 
## To print a group of commission documents:

 

 ·        Run the Print Sales Rep Commission report.
