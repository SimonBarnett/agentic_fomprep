# Record Commission Documents Automatically

 

You can create commission documents automatically, either individually or in a batch, on the basis of invoices on which commissions are due. One commission document is created for each sales rep. 
 
## To create commission documents:

 

 1 .  Run the Prepare Commission Documents program. 
 

 2 .  In the form that opens, retrieve the invoices on which commissions are due. When you are finished, close the form.
 Tip: Use the Document Code column to distinguish between the different types of invoices. 
 

 3 .  Enter the Sales Rep Commission form and retrieve the new commission documents.
 Tips: 
 

 ·              Retrieve by the date on which you ran the program. 
 

 ·              At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column. 
 

 4 .  For each document, click the Details tab and designate the Planned Payment Date . 
 

 5 .  If the document is for commission due on sales to a particular customer, record the Customer Number .
