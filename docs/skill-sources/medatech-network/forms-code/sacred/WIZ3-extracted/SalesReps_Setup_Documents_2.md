# Set Text for Commission Documents 

 

If you want certain remarks to appear on all (or most of) the printouts of commission documents, you can designate set text for this purpose. 
 

These remarks will automatically appear in the Remarks sub-level form of each new commission document, but may be revised there. Any remarks appearing in this sub-level form are automatically included in the printout of the commission document. 
 
## To designate set text:

 

 1 .  Enter the Set Text for SalesRep Commission form. 
 

 2 .  Record the desired remarks in the Set Text for Commission sub-level form. 
 Tip for dual-currency users: If you are working in a language other than English and wish to record set text in English, use the Set Text for Commission (Lang 2) sub-level form. Any commission documents opened for sales reps defined as receiving Printouts in Lang 2 will contain set text in English.
