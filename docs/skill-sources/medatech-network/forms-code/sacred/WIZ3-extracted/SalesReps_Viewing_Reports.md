# Viewing Reports For Sales Representatives 

 

The system provides a number of reports relevant to sales representatives. Most appear in the Sales Representatives menu. The following are additional reports of interest to sales reps. 
 
## To view a summary of tasks involving designated sales reps:

 

 ·        Run the Task Summary per Sales Rep report.
 Tip: To customize the report, enter the Task Types form and delete the check mark next to any task types you are not interested in viewing. This will affect all subsequent runs of the report, as well as retrievals of tasks. It will not affect other users. 
 
## To obtain a list of customer contacts per sales rep:

 

 ·        Run the Sales Rep Contact List report.
 Note: The contact information is taken from each customer's most recent task.
