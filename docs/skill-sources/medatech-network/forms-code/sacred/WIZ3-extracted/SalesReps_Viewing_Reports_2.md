# To view commission orders per sales rep:

 

 ·        Run the Commission Orders per Sales Rep report. 
 
## To view unbilled shipments and service calls per sales rep:

 

 ·        Run the Unbilled Docs. by Sales Rep report. 
 
## To view aged receivables over 30-day periods, sorted per sales rep:

 

 ·        Run the Aging by 30-Day Period per Rep report. 
 
## To view receipts of payment:

 

 ·        Run the Receipts per Sales Rep report. 
 
## Note:

 

You can view all commission documents that have been linked to a given customer invoice in its Sales Rep Commiss'n for Document sub-level form.
