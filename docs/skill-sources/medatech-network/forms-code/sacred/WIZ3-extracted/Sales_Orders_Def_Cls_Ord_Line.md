# Closing Order Items With Zero Quantity

 

Sometimes, when supplying services on the basis of a sales order, the quantity of hours is undefined. In such cases, the order item is given a quantity of zero (and a balance of zero), and is closed manually when the service is completed. 
 

If you work in such a way, you need to set up the system so that order items with zero quantities are not closed automatically. 
 
## To do so: 

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the SClsOrdItems constant, and change its value to 0 .
