# Completing Intrastat Information in a Transaction Document or Invoice

 

When importing and/or exporting goods between member states of the European Community, if you are required to submit an Intrastat declaration, you must provide specific Intrastat information in the body of the invoice. You should also record this information in a sub-level of the relevant inventory transaction document or invoice. 
 

You can record Intrastat information that applies to all items in the transaction document or invoice, or you can record separate Intrastat information for each item. 
 

The transaction document in question can be any one of the following: 
 

 ·        Customer Shipments 
 

 ·        Customer Returns 
 

 ·        Goods Receiving Vouchers 
 

 ·        Returns to Vendor 
 
## Note:

 

You can also record Intrastat information for parts that were sent for processing or returned afterwards in a sub-level of the Service Report-Parts form.
