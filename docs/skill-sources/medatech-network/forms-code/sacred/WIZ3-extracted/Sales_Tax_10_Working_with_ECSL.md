# Preparing EC Sales Lists

 

If you are required to submit EC Sales Lists, you must first set up several EC Sales List definitions. You must also define the relevant invoices for inclusion in EC Sales Lists. 
 
## What do you want to do?

 

 Set up EC Sales List definitions 
 

 Define invoices for inclusion in EC Sales Lists 
 

 Run the EC Sales List report
