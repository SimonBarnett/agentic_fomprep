# Recording the Company’s Tax Registration Number

 

The company’s official registration or VAT ID number with the tax authorities will appear on all financial documents printed by the company (e.g., invoices). 
 

If you work in a multi-company environment, you must also specify the VAT number of the consolidated company. 
 
## To record registration number(s):

 

 1 .  Enter the Company Data form. 
 

 2 .  Record the company’s registration number with the tax authorities in the Company Number column. 
 

 3 .  In a multi-company environment, specify the VAT Number of the consolidated company. This will appear next to the company number in financial printouts.
