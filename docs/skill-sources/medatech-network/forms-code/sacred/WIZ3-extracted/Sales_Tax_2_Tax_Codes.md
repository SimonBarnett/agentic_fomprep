# Setting Up Tax Codes

 

 Priority includes the following predefined tax codes: 
 

 ·        000 – Out of State (i.e., tax-exempt) 
 Note : You do not have to set up this tax code. 
 

 ·        001 – Sales Tax 
 

If a given tax is actually made up of two different taxes (e.g., municipal tax and state tax), you need to create tax components. Example . Click for detailed instructions.
