# To change a customer’s VAT code:

 

 1 .  Enter the Financ. Parameters for Customers and retrieve the desired customer. 
 

 2 .  Click the Customer tab. In the VAT Code column, choose the appropriate code. 
 
## To record a customer’s VAT number:

 

 1 .  Enter the Customers and retrieve the desired customer. 
 

 2 .  Click the Company Data tab. Specify the VAT Number . 
 
## Notes:

 

 ·        If you maintain customer sites, you can assign a VAT code per site, in the Customer Sites sub-level form of the Customers form. This will override the VAT code assigned to the customer. Example . 
 

 ·        You can overwrite the default VAT code in each sales document .
