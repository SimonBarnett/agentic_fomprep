Taxes Wizard - Assigning VAT Numbers to Vendors 
 
 
- 
 
 
 
## To record or change a vendor’s VAT code or number:

 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the desired vendor. 
 

 2 .  Click the General tab. In the VAT Code column, choose the appropriate code. 
 

 3 .  Specify the VAT Number . 
 
## Note:

 

You can overwrite the default VAT code in each purchase document .
