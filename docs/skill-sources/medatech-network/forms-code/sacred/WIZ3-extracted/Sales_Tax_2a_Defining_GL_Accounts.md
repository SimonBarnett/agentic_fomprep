# Defining GL Accounts for VAT

 

Before you begin, you need to define the following GL accounts: 
 

 ·        Output VAT 
 

 ·        Input VAT 
 

 ·        VAT on Fixed Expenses 
 

 ·        VAT from Customs Duty 
 

 ·        VAT on Equipment-Customs Manifest 
 

 ·        VAT (Debit and Credit). 
 

Each account must be assigned the appropriate VAT report item to determine the section of the VAT report in which its transactions appear. 
 

Each income account must also be assigned the appropriate VAT report item to indicate whether or not it is taxable (this definition also affects tax prepayments). 
 
## Note: 

 

If the Account Initialization-Intl program was run, the various VAT accounts, a taxable income account and a non-taxable income account have already been defined and associated with the appropriate VAT report item. 
 
## To define VAT and income accounts:

 

 1 .  Enter the Chart of Accounts form and move to Full-Record Display Mode . 
 

 2 .  Open the required income and VAT accounts. 
 Tip : For more information on opening accounts, run the Open GL Accounts Wizard . 
 

 3 .  For each account, click on the Report tab and select the appropriate VAT Report Item .
