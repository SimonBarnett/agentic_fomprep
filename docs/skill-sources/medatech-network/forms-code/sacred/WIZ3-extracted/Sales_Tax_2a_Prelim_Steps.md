# Assigning VAT Codes and Numbers

 

The Output VAT tax code is automatically assigned to new customers, and Input VAT to new vendors, so that VAT can be added automatically to sales and purchasing documents. 
 

You can change the tax code, if necessary (e.g., a customer from which income is tax exempt can be re-assigned the Tax-exempt tax code). 
 

You also need to record each customer’s and vendor’s VAT number. 
 
## What do you want to do?

 

 Record or change a customer ’s VAT code and number 
 

 Record or change a vendor ’s VAT code and number
