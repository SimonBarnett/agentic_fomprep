# To set up tax codes:

 

 1 .  Enter the Taxes form and move to the desired line. 
 

 2 .  In the Account No. column, choose the GL account to be credited for this tax code. Priority credits this account whenever tax with this code is charged on an invoice. 
 Note : If you ran the Account Initialization program, the predefined Sales Tax Payable account (207-0) was automatically assigned to the predefined Sales Tax code (001). You can use that account or a different one of your choosing. If the GL account in question has not yet been set up, you will need to open it. For more information, see the Open GL Accounts Wizard . 
 

 3 .  Enter the Rates per Tax Group sub-level form and choose each tax group to be included in the tax code in question. 
 

 4 .  In the From Date column, record the date from which the tax is effect, and in the Tax Rate column, record the rate of tax to be charged. 
 
## Notes: 

 

 ·        You can create new tax codes, as needed. Simply record a code and description for each one, and follow Steps 2 - 4 above. 
 

 ·        If the rate of tax for a certain tax group changes, copy the tax group on a different line, recording the date it goes into effect and the new rate. This allows you to maintain a history of tax rates per tax group. 
 

 ·        Click to assign tax codes to customers. 
 

 ·        Click to return to the main sales tax screen.
