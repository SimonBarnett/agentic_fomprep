# Setting Up Tax Groups

 

All parts must be assigned to a tax group. Priority includes the following predefined groups: 
 

 ·        Default Group – All parts that are not included in another tax group are automatically considered part of this group. 
 

 ·        Tax-exempt Group – For parts that are not taxed. 
 
## To set up new tax groups:

 

 1 .  Enter the List of Tax Groups form. 
 

 2 .  Record a code and description for each group. 
 
## To assign tax groups to a part:

 

 1 .  Enter the Financial Parameters for Parts form and retrieve the part. 
 

 2 .  In the VAT Group Code column, choose the appropriate group. 
 
## Note:

 

If the part is not taxable, make sure to assign it to the Tax-exempt group.
