# Setting Up Predefined VAT Codes

 

VAT codes must be assigned one or more tax groups, tax rates and GL accounts . Rates are set per tax group (if all goods are taxed by the same rate, set that rate for the default 000 tax group ). GL accounts are assigned automatically to each VAT code when the Account Initialization-Intl program is run. However, you can also define different GL accounts for each tax group. 
 
## To record tax groups and their rates:

 

 Tip: Click to set up tax groups. 
 

 1 .  Enter the Value Added Tax form and move to the VAT code in question. 
 

 2 .  Go to the Rates per Tax Group sub-level form. 
 

 3 .  Choose the code of each tax group, and record the rate of tax to be charged in the % for Sales and/or the % for Purchases column. 
 Note : All parts belonging to this tax group will now be taxed according to this rate when this VAT code is used. 
 
## Tip: 

 

If the tax rate for a given tax group changes, copy the tax group to another line, recording the new rate and the date it goes into effect. This allows you to maintain a history of tax rates per tax group.
