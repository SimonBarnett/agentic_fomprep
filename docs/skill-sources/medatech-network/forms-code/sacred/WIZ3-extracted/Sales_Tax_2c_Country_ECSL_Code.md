# Recording EC Sales List Codes and VAT Number Formats per Country

 

If the country's EC Sales List code differs from the Intrastat code defined for that country, you must record the country code to be used for EC Sales List reports. In addition, to ensure that all VAT numbers recorded for customers registered in each country are valid, you must designate the format of valid VAT registration numbers in that country. 
 
# To record definitions per a country:

 

 1 .  Enter the Countries form and move to the desired country. 
 

 2 .  In the EC Sales List Code column, record the appropriate EC Sales List code. 
 Note : Do not record the EC Sales List code for your own country. 
 

 3 .  Define the appropriate VAT Number Format (e.g., 99 for numeric only) and VAT Number Length . (e.g., 8-10).
 Note : When the Check Customer VAT Numbers report is generated, this format will appear for each EC member state in which you have defined customers, together with the VAT registration numbers defined for these customers, thereby facilitating VAT number validation.
