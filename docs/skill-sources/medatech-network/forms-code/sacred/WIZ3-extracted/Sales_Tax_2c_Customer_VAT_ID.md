# Setting Up VAT Registration Numbers for Customers

 

When preparing an EC Sales List, the VAT registration number recorded for each customer is filled in automatically. 
 
## To record a customer’s VAT number:

 

 1 .  Enter the Customers and retrieve the desired customer. 
 

 2 .  Click the Company Data tab. Specify the VAT Number . 
 
## Tip:

 

If you have defined the format of VAT registration numbers for each EC member state in the Countries form, you can check the validity of a customer's VAT number by running the Check Customer VAT Numbers report.
