# Setting Up for EC Sales List

 

Using Priority , you can produce a quarterly EC Sales List (ECSL), which displays the sales made to VAT registered customers in EC member states. 
 

When preparing the EC Sales List, customs items must be defined and flagged for inclusion in the report, a customs item must be assigned to parts, and ECSL codes must be assigned to countries. In addition, a valid VAT registration number must be defined for any customers whose sales should be included in the report. 
 
## What do you want to do?

 

 Flag customs items for inclusion and assign to imported parts reports 
 

 Record each country’s EC Sales List code and VAT number format 
 

 S e t up VAT registration numbers for customers
