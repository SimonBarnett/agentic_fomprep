# Setting Up VAT Codes

 

 Priority includes a number of predefined VAT codes (e.g., 000 for tax-exempt, 001 for Output VAT, 002 for Input VAT). Each code must be linked to an appropriate GL account, and the percentage of the tax defined. When the VAT code is linked to a financial transaction, its defined percentage of tax is displayed in the transaction and the appropriate VAT account appears in the journal entry. 
 

 Note: If the Account Initialization-Intl program has been run, then the GL accounts have already been set up and assigned to VAT codes automatically.
