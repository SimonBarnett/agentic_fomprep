# To set up tax components:

 

 1 .  Record the main tax (in the Taxes form), including a code and description. Do not assign a GL account. 
 

 2 .  In the same form, record the component taxes (each on a separate line), assigning each a date, code, description and GL account. 
 

 3 .  With the cursor on the line of the main tax, enter the Tax Components sub-level form. 
 

 4 .  In the Tax Code column, choose each tax component (created in Step 2 ) that makes up the main tax. 
 
## Notes:

 

 ·        When assigning tax groups, assign them to the component taxes. Priority automatically calculates the rate for the main tax. 
 

 ·        If you ran the Account Initialization program, the predefined Sales Tax Payable account (207-0) was automatically assigned to the predefined Sales Tax code (001). You can use that account or a different one of your choosing. If the GL account in question has not yet been set up, you will need to open it. For more information, see the Open GL Accounts Wizard . 
 

 ·        Click to set up additional tax codes without components. 
 

 ·        Click to return to the main sales tax screen.
