# Record VAT in Sales and Purchasing Documents

 

The VAT code assigned to a customer or vendor will appear automatically in the initial sales/purchasing document (e.g., the price quote or the order) and can be revised there. The revised code will then be copied to the next document (e.g., if a sales invoice is based on an order, the VAT code will be taken from the order), it can also be manually revised in each individual sales document and purchasing document . It is this code by which Priority calculates the VAT. 
 
## Notes:

 

 ·        When purchasing fixed assets, set the VAT code to VAT on fixed expenses . 
 

 ·        Click to return to the main VAT screen
