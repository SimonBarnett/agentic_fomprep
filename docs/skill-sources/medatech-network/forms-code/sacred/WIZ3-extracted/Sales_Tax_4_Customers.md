# Assigning Taxes to Customers

 

Tax codes are assigned to customer records, so that tax can be automatically added to sales documents. 
 
## To assign tax to a customer record:

 

 1 .  Enter the Financ. Parameters for Customers form and retrieve the customer record. 
 

 2 .  Click the Customer tab. In the Tax Code column, choose the appropriate tax. 
 
## Notes:

 

 ·        If the customer does not pay tax (e.g., is out-of-state), make sure to assign the Out of State tax code. 
 

 ·        If you maintain sites for this customer, you can assign a tax code per site in the Customer Sites sub-level form. This tax code overrides the general tax code assigned for the customer. Example . 
 

 ·        You can overwrite the default tax code in each sales document. 
 

 ·        Click to return to the main sales tax screen.
