# Recording Sales Tax in Sales Documents 

 

The tax code assigned to a customer will appear automatically in the initial sales document (e.g., the price quote or the order) and can be revised there. The revised code will then be copied to the next sales document (e.g., if a sales invoice is based on an order, the tax code will be taken from the order), where it can also be manually revised . It is this code by which Priority calculates the sales tax.
