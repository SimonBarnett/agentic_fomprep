# Running VAT, Intrastat, and EC Sales List Reports

 

A number of reports are available within Priority to report VAT and generate Intrastat and EC Sales List declarations. There is also a program to create adjustment entries that transfer VAT sums to the VAT (Debit and Credit) account. 
 

Before running VAT reports, make sure that all the relevant accounts have been assigned the correct VAT Report Item (in the Chart of Accounts form, move to Full-Record Display Mode and check under the Report tab). 
 
## What do you want to do?

 

 Run VAT reports 
 

 Generat e monthly Intrastat declarations 
 

 Generat e quarterly EC Sales List reports 
 

 Create adjustment entries for VAT sums
