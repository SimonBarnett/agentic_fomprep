# Generating an EC Sales List

 

EC Sales Lists should be produced on a quarterly basis if you sell goods to VAT registered customers in EC member states. 
 
## Before running the report, check that:

 

 Customs items flagged for inclusion in Intrastat & EC Sales List report s have been assigned to the relevant imported parts 
 

 Invoices have been defined for inclusion in the declaration 
 

 Valid VAT registration numbers have been defined for customers included in the declaration 
 
## To generate the EC Sales List:

 

 ·        Run the EC Sales List report. 
 

In addition to specifying the period for which to report EC sales data, you can also specify the file name and path to which to save this data in a comma delimited file (e.g., C:\Priority\ECSL_June.txt). The EC Sales List will be displayed in HTML format in addition to being saved where specified.
