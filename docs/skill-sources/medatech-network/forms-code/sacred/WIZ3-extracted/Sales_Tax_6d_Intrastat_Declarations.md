# Generating Intrastat Declarations

 

Intrastat declarations should be made on a monthly basis if you are part of a member state of the European Community and the declaration is required for your shipments. 
 
## Before running the report, check that:

 

 Customs items flagged for inclusion in the Intrastat report have been assigned to the relevant imported parts 
 

 Intrastat information has been completed for the relevant transactions and invoices 
 
## To generate the Intrastat declaration:

 

 ·        Run the Intrastat report. 
 

In addition to specifying the month for which to report Intrastat data, you can also specify the file name and path to which to save this data in a comma delimited file (e.g., C:\Priority\Intrastat_June.txt). The Intrastat data will be displayed in HTML format in addition to being saved where specified.
