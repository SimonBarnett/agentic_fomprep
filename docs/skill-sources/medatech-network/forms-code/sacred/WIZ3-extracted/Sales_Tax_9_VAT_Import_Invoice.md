# Recording VAT from a Customs Manifest

 

Unlike regular invoices, where VAT is calculated as a percentage of the invoice total, when working with an import invoice (customs manifest), VAT is recorded on a separate item in the invoice, using the predefined part number of Tax . Explanation . The sum recorded here is recorded automatically against the VAT from Customs Duty account (in the case of imported goods) or the Equipmt VAT-Customs Manifest account (in the case of imported equipment), depending on the VAT code defined for the import invoice. 
 

In addition to VAT for the imported goods, the import invoice may include VAT on “regular” items in the invoice (e.g., tax on payment to the customs agent). In order for VAT to be calculated correctly, be sure to indicate which line items are taxable and which are not.
