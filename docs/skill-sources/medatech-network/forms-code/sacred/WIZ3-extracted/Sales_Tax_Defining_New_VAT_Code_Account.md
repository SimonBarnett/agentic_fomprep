## To assign one account per VAT code:

 

 1 .  Return to the upper-level form. 
 

 2 .  If the VAT code is for customers, assign the appropriate GL account in the Acct#: VAT on Income column. If it is for vendors, record a GL account in the Acct#: VAT on Expense column. 
 
## To assign a different account to each tax group:

 

 ·        For each tax group in the Rates per Tax Group form, record the Acct#: VAT on Income if this is a VAT code for customers or the Acct#: VAT on Expense column if this is a VAT code for vendors.
