# Additional Information about Serialized Parts

 
## Servicing and Warranty

 

 ·        To view all service calls opened for this part and the malfunctions reported in them, use the Service Calls for Serial Number and Malfunctions of the Part sub-level forms. 
 

 ·        To view all service contracts covering this part, use the Service Contracts for Item sub-level form. 
 

 ·        To extend the warranty for this part, use the Extend Warranty sub-level form.
 Note : The part warranty may also be extended while recording a receipt from the customer (via a customer receipt or an over-the-counter invoice). 
 

 ·        To view a list of serialized parts due for servicing by a certain date, run the Upcoming Servicing report. You can also inform customers of upcoming servicing for their serialized parts using the Servicing Reminder report.
