# Serialized Components of Serialized Part

 

 ·        If serialized components were recorded for this part during service calls or inventory transactions, you can view these components, using the Serialized Components of Part sub-level form or by selecting the Serialized Components (Indented) report from the list of Direct Activations . 
 
## Inventory Transactions

 

 ·        To view all inventory transactions involving this serialized part, enter the Audit Trail for Item sub-level form or run the Audit Trail for Serial Numbers report. 
 

 ·        To view all inventory transactions involving the components of this serialized part, enter the History of Components sub-level form or run the History of Components report.
