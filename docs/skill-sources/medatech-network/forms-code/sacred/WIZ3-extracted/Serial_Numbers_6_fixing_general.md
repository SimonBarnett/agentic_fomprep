# Handling Repairs of Serialized Parts Returned by Customers

 

You can record the receipt of defective serialized parts for repair in a company laboratory. 
 

There are two methods of handling laboratory repairs: 
 

 ·        Receipt, repair and return of the part to the customer. The original warranty period remains in effect. 
 

 ·        Receipt of a defective part and return of a replacement part to the customer. The customer receives a warranty on the replacement that begins upon receipt. The defective part is repaired and eventually sold to another customer. 
 

In the first case, the damaged part is considered customer inventory, so you need to define a special repairs warehouse in which to store these goods; this warehouse should not undergo inventory valuations. In the second case, the defective part reenters company inventory, so the goods can be stored in any regular warehouse.
