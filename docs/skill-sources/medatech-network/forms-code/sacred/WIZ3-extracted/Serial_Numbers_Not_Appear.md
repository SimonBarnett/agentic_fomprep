# If the serialized part is not on the Choose list 

 

The serial number probably does not appear in the Choose list because the correct warehouse (and bin) was not specified when the serial number was first opened. This can easily be corrected, as follows: 
 
## To change the warehouse (and bin):

 

 1 .  Enter the Catalogue of Parts w/Serial Nos. form and retrieve the desired part number and serial number. 
 

 2 .  Click the Part Location tab and change the warehouse (and bin).
