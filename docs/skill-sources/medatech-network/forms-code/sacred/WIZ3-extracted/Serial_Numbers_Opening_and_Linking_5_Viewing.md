# Viewing and Recording Information about a Serialized Part

 

 Priority allows you to view and record various data regarding a serialized part, such as details of the customer that owns the part, its installation date, and its servicing and warranty data. You can also view a history of the inventory transactions that involved this serialized part, the service calls and malfunctions that were opened for it, and its serialized components, if there are any.
