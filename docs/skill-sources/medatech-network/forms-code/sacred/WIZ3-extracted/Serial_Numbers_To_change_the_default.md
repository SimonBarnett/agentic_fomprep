# Constants Affecting Serialized Parts

 
## Maximum Automatic Serialization 

 

The default maximum amount of serial numbers that can be opened automatically at any one time is 100. 
 
## To change that default: 

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Revise the value of the CMaxSernOpen constant, as necessary. 
 
## Warranty Start Date

 

You can determine whether the warranty for serialized parts begins when the part is shipped or when it is installed. In the first case, the warranty terms are filled in automatically when the serialized part is recorded in a shipping document or a sales invoice. In the second, they are filled in only when an installation date is specified in the Catalogue of Parts w/Serial Nos. form. 
 

 To change the warranty start date: 
 

 ·        In the Logistic Constants form, change the value of the C A utoWarrant constant.
