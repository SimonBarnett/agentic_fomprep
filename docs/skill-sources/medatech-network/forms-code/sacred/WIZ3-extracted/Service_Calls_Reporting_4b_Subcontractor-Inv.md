Service Calls - Linking a Subcontractor Invoice 
 
 
- 
 
 
 
# To link a subcontractor invoice to a service call:

 

 1 .  Enter the Invoices from Subcontractors sub-level form. 
 

 2 .  Select the appropriate Invoice Type . 
 

 3 .  Select the number of the subcontractor invoice in the Invoice column. 
 
## Note:

 

You can also link credit memos received from subcontractors for this call.
