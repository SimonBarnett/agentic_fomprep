# Including Service Calls in a Project

 

You can link a service call to a project or to a specific project activity. The cost of the call is added to the cost of the activity or project to which it is linked. 
 

Once the service call is linked to a project or activity, you can change the account credited by the call slip if it differs from the project's default account. 
 

Project information will appear automatically in the following cases: 
 

 ·        When a single project has been recorded for the customer, and the SLinkProject constant is set to 1 . 
 

 ·        When the service call is based a sales order linked to a project. 
 
## Notes:

 

 ·        When reporting parts and labor, you will also be able to link individual lines to a project or project activity. 
 

 ·        After linking the service call to a project, enter the Attachments for Project Activs. sub-level of the Service Calls form to access files that have been attached to the project's activities. 
 
## What do you want to do?

 

 Link the service call to the entire project or check the linked project 
 

 Link the service call to a project activity or check the linked activity 
 

 Change the account being credited
