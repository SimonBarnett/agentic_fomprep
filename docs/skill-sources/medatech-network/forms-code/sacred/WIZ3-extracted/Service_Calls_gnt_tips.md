# Using the Technician Scheduling Calendar

 

The Technician Scheduling Calendar displays the appointments of company technicians, including service calls for which they are scheduled. It also allows you to schedule new service calls and revise old ones. The program can be run from within a specific service call or from the menu. When you use the former option and you open a new service call, the number of the current call (and its default technician) will be filled in automatically, although this may be revised. 
 
## To run the program from within a service call:

 

 1 .  Enter the Service Calls form and retrieve the call in question. 
 

 2 .  Select Technician Scheduling Calendar from the list of Direct Activations . 
 
## To run the program from the menu:

 

 ·        Run the Technician Scheduling Calendar . 
 
## Note:

 

In addition to the regular scheduling calendar, you can run the Technician Schedule (Read-Only) , either from the menu or from the list of Direct Activations . 
 
## To schedule a service call:

 

 1 .  Make sure the appropriate technician and date appear in the calendar. 
 

 2 .  Double click in the appropriate time slot or press Insert . 
 

 3 .  Revise the details and indicate the call number, as needed.
