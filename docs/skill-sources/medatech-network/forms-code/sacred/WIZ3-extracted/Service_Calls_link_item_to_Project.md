# To link a reported part/labor to a project or an activity:

 

 1 .  Enter the Projects/Accounts sub-level form. 
 

 2 .  In the Project Number column, choose/check the project. 
 

 3 .  The project's default account appears automatically in the Account Number column. Revise it if necessary. 
 

 4 .  If you have linked the document to a project activity, the WBS code of the activity appears in the WBS column. Revise it if necessary. 
 

 5 .  Change the Percent Completed , if necessary.
 Note: To revise the Activity Status , move to the Activity ID column and press F6 , then make the revision in the form that opens. Finally, press Esc to return to Projects/Accounts . 
 

 6 .  Return to the upper-level form.
