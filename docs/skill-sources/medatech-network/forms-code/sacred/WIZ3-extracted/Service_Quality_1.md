# Defining Categories for Questions in a Questionnaire

 

You can define various categories for the questions in a questionnaire (e.g., customer satisfaction). You can then classify questions in a given questionnaire by category. You can also determine the order in which each category of questions appears in the questionnaire. 
 
## To define categories for questions in a questionnaire:

 

 1 .  Enter the Question Categories form. 
 

 2 .  Record each category in a separate line, as well an integer representing the order in which categories appear in the survey.
