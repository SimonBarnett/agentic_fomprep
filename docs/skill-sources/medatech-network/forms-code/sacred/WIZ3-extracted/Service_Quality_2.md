# To create a questionnaire:

 

 1 .  Enter the Customer Survey Formats form. 
 

 2 .  Record a format code and title. 
 

 3 .  Enter the Questions in Questionnaire sub-level form. List the questions, assigning each a number. You can also assign each question a category, and define the order in which questions appear within this category. 
 

 4 .  Record the multiple-choice options (e.g., Yes/No; High/Moderate/Low) in the Possible Responses sub-level form. List the possible answers, assigning each a number. 
 

 5 .  To view all the questions and answers, prepare the Print Customer Survey Formats report. 
 Tip: Use the same report to print a survey form in which to manually record a customer's answers (e.g., by circling the responses).
