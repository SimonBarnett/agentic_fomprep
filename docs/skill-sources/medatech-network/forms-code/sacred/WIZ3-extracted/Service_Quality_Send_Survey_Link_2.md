# Sending Customer Surveys

 

When you send a request to customer contacts to complete a survey, these contacts are sent a link to your web site in the language in which you run the Send Request program. If, in your current installation of Priority , MarketGate is used with more than one language, make sure you are working in the correct language in the user interface before running the Send Request program. Thus, for example, if you are currently working in Priority in English, and you want to send a link to your French site, change the Priority interface language to French, then exit and re-enter Priority before running this program. 
 

You can send a request for survey completion from within the survey form itself, indicating the customer contact(s) in question. You can also use the Customer Work Area to retrieve a large group of customer contacts and send a request to the chosen contacts in a batch. 
 
## To send a request for survey completion from within the survey form:

 

 1 .  Enter the Customer Survey Formats form. 
 

 2 .  Move to the line for the desired survey and select the Send Request to Complete Survey program from the list of Direct Activations. 
 
## To send a request for survey completion to contacts in the Customer Work Area:

 

 1 .  Make sure the desired customer records have been loaded into the Customer Work Area . 
 Tip: See the CRM Wizard wizard for information on loading customer records into the work area. 
 

 2 .  Run the Send Request to Complete Survey program. 
 

 3 .  In the input screen that appears, choose the survey to send to the customers. The Customer Work Area opens. 
 

 4 .  Retrieve the customer contacts to whom you want to send a request for survey completion and exit the form. 
 
## Notes:

 

 ·        The text that will appear in the message being sent is taken from the Set Text for Sending Survey or Set Text-Sending Survey (Lang2) sub-level of the Set Text for Sending Cust Survey form, depending on the language you are currently working with in Priority . 
 

 ·        If the customer contact in question is not defined as a user in Priority , you can choose to have the system send them a new password (for use accessing your web site). Internal Priority users do not need a new password; they use their Priority password.
