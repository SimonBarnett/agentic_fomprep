# To open routine service calls for serialized parts:

 

 1 .  Run the Prepare Servicing Plan program, specifying the period for which you want to create this servicing plan and the serialized parts to be serviced. 
 

 2 .  Enter the Service Calls form and retrieve the service calls that were opened. 
 

 3 .  For each service call, make sure that the correct customer number and serial number are listed.
 Note: If payment for the service call will be made by another customer (that is not defined as a billing customer for the current customer in the Financ. Parameters for Customers form), specify the customer's number in the Billing Customer column in the Customer Details sub-level form. This customer's account will appear automatically in the journal entry that will open when an invoice is finalized for this service call. 
 

 4 .  If the call is covered by a service contract, make sure the contract number is listed. 
 

 5 .  Click the Service Info tab and make sure that the correct servicing package is listed. 
 

 6 .  In the General tab, change the status of the call as needed. In the Scheduling tab, assign it to the next user responsible for handling it. 
 
## Notes:

 

 ·        Click to schedule the call. 
 

 ·        To obtain a listing of parts due for servicing, run the Upcoming Servicing report. 
 

 ·        To print reminder letters to customers, run the Servicing Reminder report. 
 

 ·        Click to return to the main screen.
