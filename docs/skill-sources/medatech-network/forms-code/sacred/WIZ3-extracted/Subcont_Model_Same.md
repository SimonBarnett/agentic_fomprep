# Modeling Operations that are Always Performed by a Single Subcontractor

 

When a specific operation is always performed by a certain subcontractor, you can define a work cell for that subcontractor and assign it to the operation. 
 

Operations of this type are always performed by the designated subcontractor, even when the work order in question is assigned to a different subcontractor. 
 
## To define a work cell at the subcontractor:

 

 1 .  Enter the Work Cells form. 
 

 2 .  Define the work cell in question (or retrieve it, if already defined). 
 

 3 .  In the Warehouse column, choose the subcontractor warehouse. 
 

 4 .  In the Inventory/Costing Control column, choose T . Explanation. 
 
## To define an operation that is always performed by a certain subcontractor:

 

 1 .  Enter the Operations form. 
 

 2 .  Define the operation in question (or retrieve it, if already defined). 
 

 3 .  In the Work Cell column, choose the work cell linked to the subcontractor. 
 

 4 .  Make sure the Inventory/Costing Control column is empty (or set to T ).
