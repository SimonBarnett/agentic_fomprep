# To model a part that is always produced by a turnkey subcontractor:

 

 1 .  In the Parts form, define the part as usual, assigning it type R .
 Note: If the part was manufactured previously, either in the factory or by a subcontractor, and you want to convert it to a turnkey part, you may not be able to change its part type. In such a case, change the part's routing to "Assemb" in the Parts form, and flag the Turnkey column. 
 

 2 .  In the Child Parts sub-level form, record its child parts in the usual manner (including parent-child ratios). 
 

 3 .  Make sure the Info Only column is flagged for each child part.
