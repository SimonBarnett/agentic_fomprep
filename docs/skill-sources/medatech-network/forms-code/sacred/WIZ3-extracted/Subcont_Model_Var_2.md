## To model the production routing:

 

 ·        Define the standard routing according to the most common scenario. That is, if the part is usually manufactured in the factory and only occasionally outsourced to a subcontractor, include the operations defined for the factory warehouse. 
 

When MRP opens work orders, it uses the standard production routing. If it is decided to manufacture the work order differently (e.g., outside the factory instead of in, or vice versa), you can revise the work order accordingly, by specifying (or deleting) the relevant subcontractor before the work order is released. If a special BOM is defined for the subcontractor, the kit list is adjusted automatically when the work order is released, However, the routing itself is not adjusted automatically – you need to revise the relevant operations manually.
