# Subcontractor Bill of Materials

 

When the same parts are processed by more than one subcontractor, or by a subcontractor as well as in the factory, you can adjust the standard BOM for each subcontractor. The BOMs that you define will affect the kit list that opens for a work order recorded for a subcontractor, as well as MRP results (e.g., calculated demand for child parts). 
 

For each part the subcontractor manufactures, you can make the following adjustments: 
 

 ·        If the subcontractor does not require a given child part or purchases it elsewhere (i.e., you do not supply it), you can instruct the system not to include this part in the kit list, and not to reduce quantities of this part when the operation is performed by this subcontractor. 
 

 ·        If the subcontractor produces a needed child part from components that you provide (i.e., the third level down in the BOM), you can instruct the system to regard this child part as a phantom when the operation is performed by a subcontractor. Consequently, when the processed parent parts are received from the subcontractor, the system will not reduce the processed child part itself, but rather its issued components. Example. 
 
## Note:

 

No adjustment is necessary when you supply all child parts for processing of the immediate parent, according to the standard BOM.
