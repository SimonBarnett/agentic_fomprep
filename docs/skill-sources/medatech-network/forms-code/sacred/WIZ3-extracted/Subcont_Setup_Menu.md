# Setting Up Subcontractors

 

Before you can work with subcontractors, you need to define the relevant production parameters, such as those that affect BOMs, production routings and MRP. 
 
## What do you want to do?

 

 Set up warehouse control for subcontractors 
 

 Define a new subcontractor 
 

 Adapt a BOM to a subcontractor 
 

 Record a price list for a subcontractor 
 

 Set up MRP to assign work orders to subcontractors 
 

 Set up business processes (BPM) for shipments to subcontractors (define statuses)
