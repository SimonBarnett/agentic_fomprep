# Shipping Parts that are Issued in Bulk

 

You can itemize the shipment with parts issued in bulk in one of three ways: 
 

 ·        Automatically, based on the minimum floor stock defined for the subcontractor's warehouse. 
 

 ·        Automatically, based on open, released work orders assigned to this subcontractor. 
 

 ·        Manually. 
 
## Note:

 

You cannot itemize the shipment automatically on the basis of the Issues Plan created by MRP. 
 
## Before You Begin

 

 1 .  Make sure the IFloorInv constant is set properly (in the Logistic Constants form).
 Notes: 
 

 ·      This constant also affects calculations of issues in bulk to your own plant floor. 
 

 ·      If the constant is set to use the Issues Plan, shipments to contractors of parts issued in bulk will have to be itemized manually. 
 

 2 .  If you maintain minimum floor stock in the subcontractor's warehouse, make sure the parameters have been correctly defined (in the Minimum Floor Stock form, sub-level of the Purchase/MRP Parameters for Part form).
