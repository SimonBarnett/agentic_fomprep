# Adapting a Work Order for Production by a Subcontractor

 

MRP opens work orders according to the standard routing defined for the manufactured part. If that routing includes an operation defined for the desired subcontractor, there is no need to revise the work order. Otherwise, you need to adapt the work order and its routing to the desired subcontractor before the work order is released, even if only one operation is so defined. 
 
# To adapt a work order for production by a subcontractor:

 

 1 .  Enter the Work Orders form, and retrieve the desired work order. 
 

 2 .  Click the Prod. Data tab and record the Subcontractor Number .
 Note: If you defined production capacity per subcontractor, the subcontractor number appears automatically in the work order opened by MRP.
