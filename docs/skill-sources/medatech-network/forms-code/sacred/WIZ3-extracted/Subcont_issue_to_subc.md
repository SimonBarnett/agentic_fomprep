# Issuing and Shipping Parts to a Subcontractor

 

Three types of parts can be shipped to a subcontractor for production purposes: 
 

 ·        Child parts issued to a kit 
 

 ·        Child parts issued in bulk 
 

 ·        Parent parts in progress 
 

You can include all of the above in one shipping document, but each is recorded in a different way.
