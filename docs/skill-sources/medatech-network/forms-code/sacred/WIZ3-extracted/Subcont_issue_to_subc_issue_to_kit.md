# Issuing to a Kit

 
## Notes:

 

 ·        For detailed instructions on issuing to kits, run the Issues Wizard . 
 

 ·        Issues to kit for a subcontractor require linking the kit warehouse to the subcontractor's warehouse. Click if the kit warehouse has not been linked . 
 
## To issue to a kit for a subcontractor:

 

 1 .  Enter the Work Orders form, and retrieve the desired work order. 
 

 2 .  Enter the Kit List sub-level form and check that the kit list is accurate. 
 

 3 .  Move to the Issues to Kits sub-level form. 
 

 4 .  In each issue line intended for the subcontractor, record the quantity to be issued. This quantity is then transferred to the kit warehouse linked to the subcontractor warehouse.
 Note: Do not issue the parts directly to the subcontractor warehouse. Explanation.
