# To print a shipment to subcontractor document:

 

 1 .  Enter the Shipmt to Subcontr/Issue of Kit form, and retrieve the desired shipping document. 
 

 2 .  Select Print Shipmt to Subcont/KitIssue from the list of Direct Activations .
