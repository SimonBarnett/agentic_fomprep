# To automatically record parts issued in bulk:

 

 1 .  In the Shipmt to Subcontr/Issue of Kit form, select Prepare Bulk Shipments from the list of Direct Activations . 
 

 2 .  Enter the Shipped Items sub-level form. Lines for bulk issues to the subcontractor warehouse appear automatically. Explanation. 
 

 3 .  In each line, make sure that the inventory details are correct (e.g., From Warehouse , Part Revision , Work Order/Lot , Status , Operation ). For assistance, run the Issues Wizard .
 Note: You cannot revise lines that were recorded automatically. If you do not want to issue the part, make sure that the line is not approved or that no quantity is specified.
