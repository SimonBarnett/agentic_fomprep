- 
 
 
 
# To record parts issued to a kit:

 

 1 .  Do one of the following: 
 

 ·      Link the relevant purchase order, if any, to the document in the Order Number column ( References tab). The work orders specified in the purchase order will appear automatically in the Kits to Ship sub-level form. OR 
 

 ·      Enter the Kits to Ship sub-level form, and manually record the relevant work orders. 
 

 2 .  Move to the Shipped Items form, a parallel sub-level. Issues to kits for the specified work orders are listed automatically (provided that issues to the subcontractor's kit warehouse are recorded for the work order). If issues are recorded but inventory is missing from the warehouse (because it was used elsewhere), you will receive a warning message.
