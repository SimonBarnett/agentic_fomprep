Working With Subcontractors - Recording Parent Parts in Progress.1 
 
 
- 
 
 
 
## To record parent parts in progress:

 

 1 .  Enter the Shipped Items sub-level form. 
 

 2 .  For each parent part that you want to ship to the subcontractor, do one of the following: 
 

 ·      Record the Part Number . The Vend./Manuf. Part No. will appear automatically, if one has been defined in the system. OR 
 

 ·      Record the subcontractor's part number, if one has been defined in the system, in the Vend./Manuf. Part No. column. The internal Part Number will appear automatically. 
 

 3 .  In the Work Order/Lot column, record the relevant work order number.
 Notes: 
 

 ·      The Part Revision specified in the work order appears automatically. 
 

 ·      If you do not use work orders, leave the predefined value 0 . In this case, the Part Revision can be changed manually. 
 

 4 .  Specify the last Operation that was performed on the part (i.e., the operation at which it is stored in inventory).
