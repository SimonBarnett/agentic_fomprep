# To manually itemize the shipment with parts issued in bulk:

 

 1 .  Enter the Shipped Items sub-level form. 
 

 2 .  For each part that you want to ship to the subcontractor, do one of the following: 
 

 ·      Record the Part Number . The Vend./Manuf. Part No. will appear automatically, if one has been defined in the system. OR 
 

 ·      Record the subcontractor's part number, if one has been defined in the system, in the Vend./Manuf. Part No. column. The internal Part Number will appear automatically. 
 

 3 .  In the Work Order/Lot column, record the relevant lot or work order number.
 Notes: 
 

 ·      The Part Revision specified in the lot or work order appears automatically. 
 

 ·      If you do not use lots/work orders, leave the predefined value 0 . In this case, the Part Revision can be changed manually. 
 

 4 .  Make sure the Status of the shipped part is correct.
