# Recording a Subcontractor GRV

 

For detailed instructions in recording, finalizing and printing a goods receiving voucher, run the Receipt/Return of Goods Wizard . 
 
## When recording the GRV, note the following:

 

 ·        After specifying the subcontractor (in the Vendor Number column), the warehouse to which the subcontractor is linked appears automatically in the Vendor Warehouse column. Make sure it is the correct warehouse.
 Note: If the subcontractor is not linked to a warehouse, the system will not identify him as a subcontractor, but as a regular vendor. To link the subcontractor to a warehouse, use the Vendors form. 
 
## When itemizing the GRV, note the following:

 

 1 .  For each part received, specify the released work order for which it was produced (in the Internal Lot/Wk Ord column).
 Note: If you do not specify a released work order when receiving a part that was assigned a work order template and flagged for automatic opening of work orders, a new closed work order will open automatically. The work order will open without a kit list and child part inventory will not be reduced for it. 
 

 2 .  Specify the last operation performed on the part in the From Operation column. 
 

 3 .  If the part is being received after rework, do the following: 
 

 ·      Flag the Receipt of Rework column. 
 

 ·      Record the status in which the parts were returned to the subcontractor for rework in the From Status column; the inventory in this status will be reduced from the subcontractor warehouse, while the received inventory (whose status appears in the Status column) is added to the receiving warehouse.
