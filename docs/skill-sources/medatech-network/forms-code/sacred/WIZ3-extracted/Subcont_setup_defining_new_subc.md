# Defining a New Subcontractor

 

In Priority , a subcontractor is simply a vendor linked to a warehouse. Consequently, to define a new subcontractor you must open a vendor record, define a subcontractor warehouse and link the warehouse to the vendor. 
 

To issue materials to the kit of a work order produced by a subcontractor, you need to define a kit warehouse in whch to store these materials until they are shipped to the subcontractor. This kit warehouse must be linked to the subcontractor's warehouse. 
 

Finally, you can record set prices for the parts each subcontractor produces. These prices appear as defaults when recording transactions (e.g., purchase orders, purchase invoices) for subcontractors.
