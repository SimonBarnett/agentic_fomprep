Working With Subcontractors - Defining a Subcontractor Warehouse 
 
 
- 
 
 
 
# To define a subcontractor's warehouse and link it to a kit warehouse:

 

 1 .  Enter the Warehouses form. 
 

 2 .  If the kit warehouse has not yet been defined, do so now (make sure to flag the Type column with an F ).
 Tip: For more information about defining warehouses, run the Open a Warehouse Wizard . 
 

 3 .  Move to a new line and define the subcontractor's warehouse (again, the warehouse Type must be F ). 
 

 4 .  In the Kit Warehouse column (in the General tab), specify the appropriate warehouse. 
 
## To define a subcontractor:

 

 1 .  Enter the Vendors form. 
 

 2 .  Open a new record for the subcontractor.
 Tip: For more information about defining vendors, run the Open Vendors Wizard . 
 

 3 .  Click the Details tab, and choose the appropriate warehouse in the Subcontractor Warehouse column.
