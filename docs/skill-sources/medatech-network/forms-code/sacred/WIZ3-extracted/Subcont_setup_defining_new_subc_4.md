Working With Subcontractors - Defining a Subcontractor Price List 
 
 
- 
 
 
 
# To set up a subcontractor price list:

 

 1 .  Enter the Prices-Subcontracted WIP Parts sub-level form. 
 

 2 .  For each part, record its Part Number or Subcontract Part Number (fill in one of these columns, and the other will be filled in automatically).
 Note: To use the subcontractor's part number, it must be linked to the internal part number in the subcontractor's part list. For more information, run the Vendor Parts and Prices Wizard . 
 

 3 .  Record the Operation at which the part is received from the subcontractor. 
 

 4 .  Record the subcontractor's Unit Price for the current part in the designated operation.
