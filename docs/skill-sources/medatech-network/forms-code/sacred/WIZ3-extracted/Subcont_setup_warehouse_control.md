# Setting Up Warehouse Control

 

In order to work with subcontractors, you need to set a constant that causes MRP to relate to each floor warehouse separately when calculating raw material demand and reducing demand against existing inventory. 
 
## To maintain separate floor warehouse inventory:

 

 1 .  Enter the Production Constants form. 
 

 2 .  Move to the MRPSepFloors constant. 
 

 3 .  Set the Value of the constant to 1 .
