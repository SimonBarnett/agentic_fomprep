# "Manual" Inventory Transactions in the Floor Warehouse for the Child Part that is Missing Issues

 

If manual inventory transactions are recorded from the floor warehouse during the period in question, even if the required quantity was originally transferred to the floor warehouse, the inventory is no longer considered to be there at the time of production reporting. This can result in missing issues. 
 
## Tip: 

 

The Inv Journal - Materials on Floor report can help you pinpoint these instances.
