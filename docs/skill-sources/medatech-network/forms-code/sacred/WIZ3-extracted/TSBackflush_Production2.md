Troubleshooting Backflush Wizard - Checking for Inventory Balances 
 
 
- 
 
 
 
# To check whether there is an inventory balance for these items:

 

 1 .  Enter the Missing Issues form. Make note of the following data: 
 

 ·      Part Number : The number of the child part (i.e., the kit item) 
 

 ·      Operation: The last operation performed on the child part before the work order was released 
 

 ·      Warehouse: The floor warehouse currently attached to the work cell recorded in the work order routing 
 

 ·      Quantity 
 

 2 .  Enter the Part Catalogue form and retrieve the part in question (i.e., each of the kit items). 
 

 3 .  Enter the Inventory for Part sub-level form and move to the line for the operation and warehouse in question. 
 Note: A blank operation refers to the last operation currently defined in the part’s routing. 
 

 4 .  Do one of the following: 
 

 ·      Click if there is no inventory balance . 
 

 ·      Click if there is an inventory balance .
