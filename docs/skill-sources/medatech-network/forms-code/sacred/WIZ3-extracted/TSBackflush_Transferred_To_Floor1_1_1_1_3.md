# Negative Floor Inventory in the Previous Calculation of Past Balances

 

If there were negative inventory balances in the floor warehouse as a result of the previous calculation of past balances, it is possible that the issued quantity was added to the negative balance and so does not exist in full in inventory at the time of production reporting. Consequently, you are again left with a negative balance and with missing issues.
