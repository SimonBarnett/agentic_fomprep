# Manual Additions to the Kit List

 

If you manually add a line to the Kit List form, it is automatically flagged as an Extra Issue . If issued, it is transferred to the floor warehouse with the Reject status. As this status is ignored by the Backflush program, this will create missing issues. 
 
## To resolve this situation:

 

 1 .  If the work order is closed, reopen it. 
 

 2 .  Remove the check mark from the Extra Issue column. 
 

 3 .  Rerun the Backflush program.
