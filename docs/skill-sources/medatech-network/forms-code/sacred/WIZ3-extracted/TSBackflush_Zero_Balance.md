# Zero Inventory Balance: Solution

 

 For an individual work order: Issue the needed part to the floor and work order. Then rerun the Backflush program. 
 

 For all parts: Run the Prepare for Inventory Count program for the floor warehouse, for the date on which you intend to calculate past balances, and perform an inventory count. Then rerun the Backflush program. 
 
## Note: 

 

If the part in question has already been transferred to the floor, and there are still missing issues, click for possible explanation s .
