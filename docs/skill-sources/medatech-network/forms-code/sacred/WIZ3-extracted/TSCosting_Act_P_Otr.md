# Which costing option has been assigned to the part?

 

 W ( based on production and material cost s recorded for work orders closed during the current costing period) 
 

 T ( based on standard production costs and actual material costs as defined in the standard BOM) 
 
## Tips:

 

 ·        If you don’t know which option was assigned, retrieve the part in the Parts - Std Costs form and check the Costing Option column. 
 

 ·        The costing program can be set to calculate work order costs for Option T parts as well. This will allow you to view work order costs, but they will not affect the calculation of the part’s actual cost. To do so, select the W option presented above. Run the View Costing Parameters program to determine how costing was set up.
