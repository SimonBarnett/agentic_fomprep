# To check standard production costs:

 

 ·        Do one of the following: 
 

 ·      Run the Product Cost Components report for the parent part. 
 

 ·      Retrieve the parent part in the Product Costing form, enter the Product Cost Components sub-level form, then view the data in the Std Cost line. 
 
## To check the cost components of sub-assemblies:

 

 ·        Click to repeat the current cost analysis for each Type P child of the current Type P part .
