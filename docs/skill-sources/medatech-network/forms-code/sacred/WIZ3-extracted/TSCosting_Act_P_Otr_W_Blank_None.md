# If no work orders were recorded for the part:

 

 ·        Check the part’s actual cost as it appears in the previous past balance. This value determines the actual cost in the absence of new work orders. 
 

 ·        If no actual cost appears in the previous past balance, the part’s actual cost is calculated from the standard cost. If no standard cost is recorded, no actual cost is calculated for this part. 
 

 ·        Click to view and revise the part’s standard cost.
