# If a work order does not affect the part cost:

 

 1 .  Enter the Work Orders form and retrieve the work order. 
 

 2 .  Click the Details tab. If the work order is not closed, the cumulative costs will not affect the average part cost. 
 

 3 .  Click the Inventory/Costing Data tab and check the Not for Costing column. If it is flagged, the work order will not affect the part cost. 
 

 4 .  Check the Rework column. If the work order is flagged as rework, it will not affect the average part cost.
