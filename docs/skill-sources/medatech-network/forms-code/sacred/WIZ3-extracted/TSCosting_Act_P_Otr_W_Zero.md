# If work orders appear with a cost of zero or an incorrect cost:

 

 1 .  Enter the Work Order Costing form and retrieve the work orders in question. 
 

 2 .  Enter the Work Order Cost Components sub-level form and review the work order's cost components.
 Note: When the DetailedCost constant is set to 1 (in the Financial Constants form), the values you see include the costs of child work orders. Explanation.
