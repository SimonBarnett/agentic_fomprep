# Before you begin:

 

Run the costing program again to make sure you are analyzing the correct data. Choose one of the following options, based on your Priority package and the type of costing run in which you discovered errors. 
 
## In a business setting, do one of the following:

 

 ·        Click to run costing for the current date. 
 

 ·        Click to run costing for the previous past balance. 
 

 ·        To check costing data prior to the last past balance, delete all costing runs as of the date of the one you are checking, then run the costing program for the date of the past balance in question. 
 
## In a manufacturing setting, do one of the following:

 

 ·        Run the Backflush program From Last Past Bal. , then click to run costing for the current date. 
 

 ·        Click to run costing for the previous past balance.
 Tip: To check costing data prior to the last past balance, choose the All Past Balances runtime option.
