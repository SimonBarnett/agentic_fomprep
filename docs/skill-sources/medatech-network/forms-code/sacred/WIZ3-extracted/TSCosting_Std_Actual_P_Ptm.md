Troubleshooting Costing - Std/Actual Cost, Type P.2

# Solution – There Is No Cost

 

Phantom parts are virtual parts that represent groups of actual parts. The costs of a phantom’s child parts are added directly to its parent. No cost is calculated for the phantom itself.
