# Solution – Update Assembly Data

 

The source of the problem could be the standard cost of the assembled product, or the composition of the assembly’s BOM. 
 
## To check the standard cost of the assembled part:

 

 1 .  Enter the Product Costing form and retrieve the part. 
 

 2 .  The form displays a line for the last run of costing for the current date, as well as a line for each run of costing on a past balance date. Check the part’s standard cost in the appropriate costing line. 
 

 3 .  To analyze the standard cost, select Standard Cost Analysis from the list of Direct Activation s , or run the Analysis of Standard Cost report.
 Note : The Analysis of Standard Cost report does not display the standard shipping costs defined for purchased parts in the Financial Parameters for Parts form, whereas the cost calculation in the Standard Cost Analysis report does take them into account.
