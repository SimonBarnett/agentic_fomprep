# Solution – Update Standard Cost Components

 

The standard cost of manufactured goods is composed of raw material costs, subcontractor costs, supply costs, non-standard costs, labor costs and machine costs. 
 

Check the following cost components, revising them where necessary: 
 

 Raw material costs 
 

 Subcontractor, non-standard and supply costs 
 

 Work hour costs (labor and machines)
