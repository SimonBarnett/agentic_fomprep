# Constant work hour costs

 

Use the following formulas to calculate the cost of an operation whose processing parameters are constant (i.e., the operand is C ). Note that the variables L, T, E, and U are defined in minutes, whereas the cost is hourly. Insert the value of the parameter divided by 60 in the equation in order to obtain the time in hours. 
 

 ·        L abor = [E * (direct labor cost + indirect labor cost) * time factor] + [T * number of skilled employees per operation * (direct skill cost + indirect skill cost) * time factor] /100% - scrap percentage 
 

 ·        Machines = T * (direct machine cost + indirect machine cost) * time factor /100% - scrap percentage 
 

 ·        Setup = [(T * setup time percentage) + L + U] * setup cost * time factor /100% - scrap percentage 
 
# Variable work hour costs

 

Use the following equations to calculate the cost of an operation whose processing parameters are variable (i.e., the operand is M or D ): 
 

 ·        Unskilled labor 
 

 ·      When the operand is M = (E coefficient * part value for operation and variable) * (direct labor cost + indirect labor cost) * time factor /100% - scrap percentage 
 

 ·      When the operand is D = (E coefficient/ part value for operation and variable) * (direct labor cost + indirect labor cost) * time factor 
 

 ·        Machines 
 

 ·      When the operand is M = (T coefficient * part value for operation and variable) * (direct machine cost + indirect machine cost) * time factor /100% - scrap percentage 
 

 ·      When the operand is D = (T coefficient/ part value for operation and variable) * (direct machine cost + indirect machine cost) * time factor /100% - scrap percentage 
 

 ·        Skilled labor 
 

 ·      When the operand is M = (T coefficient * part value for operation and variable) * number of skilled employees per operation * (direct skill cost + indirect skill cost) * time factor /100% - scrap percentage 
 

 ·      When the operand is D = (T coefficient/ part value for operation and variable) * number of skilled employees per operation * (direct skill cost + indirect skill cost) * time factor /100% - scrap percentage
