# Solution – Update the Standard Cost 

 

The part cost generated by standard costing is determined by the part’s standard cost and the percentage defined as its shipping cost. Check these values and revise them as necessary. 
 
## To update the standard cost manually:

 

 1 .  Enter the Part Catalogue form and retrieve the part. 
 

 2 .  Click the Prices & Costs tab, and record the correct value in the Std. Cost column. 
 
## To update the standard cost on the basis of existing costs:

 

 ·        Run the Update Part Costs program for the part in question and select the value you want to copy to the Std. Cost column (e.g., last price, vendor price, actual cost). 
 
## To update the default shipping cost:

 

 1 .  Enter the Financial Parameters for Parts form and retrieve the part. 
 

 2 .  In the Shipping Expenses tab, verify that the corrcet default Shipping Cost Type is defined, and that a shipping cost percentage is defined in accordance with the defined type. If no default shipping cost should be added, make sure that the Shipping Cost Type column is blank.
