# Analysis of Demand: Routine Replenishment, Commercial Package

 

Part demand (type R) is determined by the parameters Required/Sold Qty and Freqncy of Need/Sale defined for the part in the Purchase/MRP Parameters for Part form. 
 

MRP does not plan issues for the part; instead, purchase planning will plan purchase requisitions at predetermined intervals according to these parameters. Exception to this rule.
