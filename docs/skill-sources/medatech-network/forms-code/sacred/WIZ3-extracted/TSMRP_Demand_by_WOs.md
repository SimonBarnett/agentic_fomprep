# Analysis of Demand: Dynamic Replenishment by Work Orders

 

Demand for any Type P part flagged for MRP by Work Order is determined by open, released work orders for the part itself. Sales orders for the part are ignored. This demand is added to the demand from open, released work orders and planned work orders for the parent parts, together with any demand generated by the child part's safety stock definitions. 
 
## To review open, released work orders for the part, and check quantities:

 

 1 .  Run the Work Ords to Execute by WorkCell report. 
 

 2 .  During the input stage, retrieve Work Order s for the relevant part number.
