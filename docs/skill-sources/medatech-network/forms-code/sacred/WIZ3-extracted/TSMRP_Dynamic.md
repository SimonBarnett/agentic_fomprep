# Analysis of Demand: Dynamic Replenishment by Part Orders

 

Demand for the part is calculated on the basis of sales orders and forecast orders for the part itself. 
 

 Commercial package: This demand is added to any order demands for the part's direct parent (which has the Assembly routing), together with any demand generated by the child part's safety stock definitions. 
 

 Manufacturing package : This demand is added to the production demand from open, released work orders and planned work orders for the parent parts, together with any demand generated by the child part's safety stock definitions.
