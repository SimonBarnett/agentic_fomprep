# Analysis of Demand: Routine Replenishment, Manufacturing Package

 

Purchase planning opens purchase requisitions and updates the projected balance according to the demand parameters Required/Sold Qty and Freqncy of Need/Sale defined for the part in the Purchase/MRP Parameters for Part form. 
 

Demand for routine usage is added to the production demand from open, released work orders and planned work orders for parent parts, together with any demand generated by the child part's safety stock definitions.
