# What is the Part’s Replenishment Type?

 

How MRP calculates demand for a given part depends first and foremost on its replenishment type: 
 

 ·        In parts with replenishment type R (or no defined replenishment type), replenishment is dynamic, derived from "exploding" the BOM. 
 

 ·        In parts with replenishment type B, replenishment is routine. 
 
## To check the part's replenishment type:

 

 1 .  Enter the Purchase/MRP Parameters for Part form and retrieve the part in question. 
 

 2 .  Click the General tab and check the value recorded in the Replenishment Type column.
