# Analyzing Demand for Parts With Replenishment Type B

 

How demand is calculated for parts with replenishment type B depends on: 
 

 ·        the Priority package in use (Commercial or Manufacturing) 
 

 ·        Commercial package only: the part type (R or P). Specifically, MRP does not take parts of type P into account – with one exception. 
 
## Choose any of the following:

 

 ·        Parts of type R in the Commercial package 
 

 ·        Parts of either type in the Manufacturing package
