# Analyzing Demand for Parts With Replenishment Type R (or No Type)

 

How demand is calculated for parts with this replenishment type depends on: 
 

 ·        the Priority package in use (Commercial or Manufacturing) 
 

 ·        the part type (R or P) 
 

 ·        Manufacturing package, part P only: the MRP by Work Order column in the Purchase/MRP Parameters for Part form. 
 
## Choose any of the following:

 

 ·        P art s of either type (R or P) in the Commercial package 
 

 ·        Parts of type R in the Manufacturing package 
 

 ·        Parts of type P in the Manufacturing package, when the MRP by Work Order column is not flagged . 
 

 ·        Parts of type P in the Manufacturing package, when the MRP by Work Order column is flagged.
