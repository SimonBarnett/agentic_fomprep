# Released Work Orders (for the Parent Part)

 

Issues are planned for the work order's production start date. Issues are only planned for child parts that appear in the work order’s kit list. When the child is included in the kit list, the issue quantity is determined by the part's issue type: 
 

 ·                If the child is issued to kits, the issue quantity is calculated according to the issue balance in the Kit List form. 
 

 ·                If the part is issued in bulk, the issue quantity is calculated according to the quantity in the Kit List form, minus the quantity deducted for production reporting. 
 

From this demand, MRP deducts available floor inventory and alternate part inventory and adds scrap. 
 
## Notes:

 

 ·        Under certain conditions, open, released work orders are ignored by MRP and no issues are planned for them. 
 

 ·        Use of floor inventory and alternate inventory depends on certain definitions.
