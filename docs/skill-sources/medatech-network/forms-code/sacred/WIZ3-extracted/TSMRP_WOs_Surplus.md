# Surplus Work Orders

 

If the due date of the order, or the start and end dates of the work order, are changed after the work order has been released, it may no longer be possible to meet the sales order’s due date. In this case, MRP plans a new work order and treats the old one as a surplus work order. 
 

MRP does not generate issues for surplus work orders.
