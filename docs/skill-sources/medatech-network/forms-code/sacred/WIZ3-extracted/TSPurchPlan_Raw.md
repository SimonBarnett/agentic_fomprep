# Requisitioned Quantities for Raw Materials

 

 1 .  Enter the Purchase/MRP Parameters for Part form and retrieve the part in question. 
 

 2 .  Enter the Projected Balances (buy/sell) sub-level form. The first line displays the available inventory balance calculated when purchase planning was run. Each additional line represents an issue item (that is, the required quantities identified by the program), the purchase requisitions opened accordingly, and any open purchase orders for the part.
