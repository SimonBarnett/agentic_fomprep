# To analyze available inventory:

 

 1 .  Enter the Part Catalogue form and retrieve the part in question. 
 

 2 .  Enter the Inventory for Part sub-level form. The available inventory is the part's inventory balance in type D warehouses, which is not packed for a specific customer and which is assigned a status defined as Basis for Planning .
 Note: Negative inventory balance is treated like zero balance.
