# Analyzing Issue Items

 

The issue items represent the requisitioned quantities of the part, calculated in accordance with the replenishment type, as defined in the Purchase/MRP Parameters for Part form. 
 
## If the replenishment type is B :

 

 ·        Issue items are generated according to the quantity defined in the Required/Sold Qty column, at regular intervals defined in the Freqncy of Need/Sale column.
 Note: Issue items are not created for sales orders for either the part itself or its parent. 
 
## If the replenishment type is R :

 

 ·        The Projected Balances (buy/sell) form displays issue items generated by MRP for Distributors . Each line displays the number of the sales order for which the issue item was opened. 
 Note: To analyze the Issues Plan, run the Troubleshooting MRP Wizard wizard.
