# Setting Up for Tax Prepayment

 

In order to ensure the correct calculation of income tax prepayment, you need to: 
 

 ·        Record the prepayment percentage of monthly revenue 
 

 ·        Indicate which income accounts require tax prepayment 
 

 ·        Define a debit account for withheld tax. 
 
## To record the prepayment percentage of monthly revenue:

 

 1 .  Enter the Financial Constants form. 
 

 2 .  Set the value of the PrePayPerc. constant to the prepayment percentage required from your company. 
 Note: The value set here will automatically appear in the program that prepares the prepayment installment, but may be revised there.
