# Defining an Account for Withholding Tax

 

If customers withhold taxes when paying your company, you must make sure there is a GL account in which to record such withheld tax. 
 

If the Account Initialization-Intl program has been run, then the Federal Withholding account has already been defined. 
 
## To define a withholding account manually:

 

 1 .  Enter the Chart of Accounts form and move to Full-Record Display Mode . 
 

 2 .  Define a new account. 
 Tip: Run the Open GL Accounts Wizard . 
 

 3.  Click the Report tab and select Withheld Tax-Own Co. (value 11 ) in the VAT Report Item column. 
 

 4.  Enter the Withholding Tax Definitions form. 
 

 5.  In the line for Withheld Tax-Own Co. , specify the account you have just set up and the percentage to be deducted from payments to your company.
