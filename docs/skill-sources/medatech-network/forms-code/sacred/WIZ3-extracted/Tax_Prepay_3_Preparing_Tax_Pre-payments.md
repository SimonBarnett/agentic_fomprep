# Calculating Income Tax Prepayments 

 
## To calculate income tax prepayments:

 

 ·        Run the Prepare Tax Prepayments program. 
 Note: If the percentage to be paid this period is different than the default (as defined in the PrePayPerc. constant), record the new percentage. 
 
## To view the results of the calculation:

 

 ·        Enter the Tax Prepayments form and retrieve the payment period by its start or end date. 
 
## To record the journal entry for the prepayment:

 

 ·        Enter the Entry Journal form and record the entry for the prepayment manually. 
 Tip: Run the Manual Journal Entries Wizard .
