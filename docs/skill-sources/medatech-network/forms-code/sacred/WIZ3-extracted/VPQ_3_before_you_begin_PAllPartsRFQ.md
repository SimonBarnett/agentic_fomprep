# Defining How RFQs are Itemized From Purchase Demand Documents

 

If you intend to create RFQs automatically on the basis of purchase demand documents, you can determine which PRs in the document will be included in the RFQ. There are two options: 
 

 ·        include only those PRs that are supplied by the vendor to which the RFQ is addressed 
 

 ·        include all the requisitioned items listed in the demand document. 
 

By default, only those items supplied by the vendor appear in the RFQ. 
 
## To include in RFQs all requisitioned items listed in purchase demand documents:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the PAllPartsRFQ constant and change the value to 1 .
