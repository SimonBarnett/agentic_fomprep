# Comparing Vendor Price Quotations

 

If you have received a number of price quotations from different vendors for the same part, you can run a report that compares them. 
 
## To compare quotes for designated parts:

 

 ·        Run the Comparison of Vendor Quotes report.
 Note: Only quotes that are currently in effect are taken into account.
