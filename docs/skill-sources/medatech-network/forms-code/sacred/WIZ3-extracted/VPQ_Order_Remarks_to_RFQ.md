# Copying Sales Order Remarks to RFQs

 

The PCopyRFQTxt constant determines whether remarks recorded in sales orders are copied automatically into RFQs based on those orders. 
 

By default, the constant is set at 1 , which means that all document and line item remarks are copied automatically. 
 
## To prevent remarks from being copied into RFQs:

 

 ·        Enter the Logistic Constants form, move to the PCopyRFQTxt constant, and change the value to 0 .
