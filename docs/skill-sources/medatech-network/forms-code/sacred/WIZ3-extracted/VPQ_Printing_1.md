# Printing a Price Quotation

 
## Before you begin:

 

 1 .  Enter the Vendor Price Quotations form and retrieve the desired price quote. 
 

 2 .  Enter the Price Quote - Vendor Details sub-level form. The details in this form will appear in the printout. Make sure they are correct. 
 

 3 .  Enter the Vendor Price Quotations - Remark sub-level form. The remarks recorded in this form will appear in the printout. Make sure they are correct. 
 

 4 .  If you are printing quotes with item remarks , move to the parallel Itemized Quotation sub-level form. Make sure that the remarks displayed in its sub-level, Quoted Item - Remarks , are correct for each item.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 5 .  To include these remarks in the printout of the RFQ, select a suitable print format . 
 

 6 .  Return to the Vendor Price Quotations form. 
 
## To print the price quote:

 

 ·        Select Print Vendor Quote from the list of Direct Activations . 
 
## To print more than one price quote:

 

 ·        Run the Print Vendor Quote report. 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen .
