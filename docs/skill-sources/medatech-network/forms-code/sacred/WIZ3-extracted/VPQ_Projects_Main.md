# Working With Projects

 

You can link an RFQ or vendor price quote to a project or to a specific project activity (when the entire document is for a single activity). 
 

Project linkage appears automatically: 
 

 ·        when the RFQ is based on a purchase demand document linked to the project 
 

 ·        when the vendor price quote is based on an RFQ linked to the project. 
 
## Note: 

 

During itemization you can also link single line items to a project or activity. 
 
## What do you want to do?

 

 Link an RFQ or price quote to the entire project or check the linked project 
 

 Link an RFQ or price quote to a project activity
