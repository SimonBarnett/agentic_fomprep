# Copying Part Remarks to RFQs and Vendor Price Quotes

 

You can set up RFQs and vendor price quotes so that part remarks are recorded automatically for individual items when a part number is recorded or revised in an itemized document. These remarks are taken from the relevant record in the Part Catalogue . 
 
## To automatically copy part remarks:

 

 1 .  Enter the Copy Part Remarks to Document form. 
 

 2 .  In the line for "RFQ" and/or "Vendor Price Quote", flag the Copy Part Remarks column.
