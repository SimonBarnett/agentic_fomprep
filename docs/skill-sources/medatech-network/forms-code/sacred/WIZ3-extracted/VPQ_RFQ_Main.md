# Preparing an RFQ

 

You can prepare an RFQ manually, from one or more purchase requisitions, or from a sales order. 
 

There are three ways to record an RFQ based on purchase requisitions: 
 

 ·        You can automatically prepare multiple RFQs to several vendors from individual PRs; 
 

 ·        You can link the RFQ to an entire purchase demand document ; 
 

 ·        You can run a program from within a purchase demand document that automatically creates a separate RFQ to each vendor and buyer for which price quotes are requested. 
 
## What do you want to do?

 

 Prepare an RFQ manually 
 

 Create RFQs automatically based on individual purchase requisitions 
 

 Base an RFQ on a single purchase demand document 
 

 Create RFQs automatically from within a purchase demand document 
 

 Prepare an RFQ based on a sales order 
 

 Print an RFQ
