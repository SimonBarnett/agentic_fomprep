# To prepare an RFQ manually:

 

 1 .  Enter the Requests for Price Quotations form. 
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the Refs & Payment Info tab). 
 

 2 .  Specify the vendor for which the RFQ is intended. The system will automatically assign an RFQ Number , and the RFQ Date will be filled in with the present date, which can be revised.
 Notes: 
 

 ·      In the case of a one-time vendor, specify the one-time vendor number. Then revise the name in the Vendor Name column, and fill in the address and other details in the RFQ - Vendor Details sub-level form. 
 

 ·      To view the vendors that sell each part, run the Vendors per Part or the Parts per Vendor reports. 
 

 3 .  If a default Contact appears, make sure that it is the appropriate contact for this RFQ. Revise if necessary.
 Tip: To define new contacts for the vendor or to assign a default contact for RFQs, use the Vendor Contacts form, a sub-level of the Vendors form.
