# To prepare an RFQ from a sales order:

 

 1 .  Enter the Requests for Price Quotations form.
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the Refs & Payment Info tab). 
 

 2 .  Specify the vendor for which the RFQ is intended. The system will automatically assign an RFQ Number , and the RFQ Date will be filled in with the present date, which can be revised.
 Note: In the case of a one-time vendor, specify the one-time vendor number. Then revise the name in the Vendor Name column, and fill in the address and other details in the RFQ - Vendor Details sub-level form. 
 

 3 .  Specify the number of the Sales Order . The Requested Items sub-level form will automatically list all line items in the sales order. 
 

 4 .  If needed, change the date by which you want to receive the quote in the Send Quote Before column, and specify the desired payment terms in the Requested Terms column. 
 

 5 .  In the Details column, record a brief remark regarding this RFQ. 
 

 6 .  Click if the parts are being purchased for a project. 
 

 7 .  To add or update remarks to the RFQ that will appear on the printout, enter the RFQ - Remarks sub-level form.
 Note: If the PCopyRFQTxt constant is set at its default value of 1 , any remarks in the sales order are copied automatically into the RFQ. 
 

 8 .  To attach a file to the RFQ, enter the Attachments sub-level form.
