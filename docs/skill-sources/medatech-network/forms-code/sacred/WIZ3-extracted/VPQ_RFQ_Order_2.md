# To check the requested items:

 

 1 .  Enter the Requested Items sub-level form. 
 

 2 .  Make sure that the requested Quantity and Date Needed for each item suit your needs.
 Note: The Date Needed is only the date on which the goods will be leaving the vendor's premises; it should be early enough to allow time for shipment and laboratory testing before the actual date on which the goods are required for use. 
 

 3 .  If the vendor for which the RFQ is intended does not supply all of the parts appearing in the order, delete those line items that the vendor does not supply.
 Tip: To delete a line item, enter the line and press Ctl + Delete . 
 

 4 .  If this item is being purchased for a project, click to link it to a project or project activity. 
 

 5 .  Enter the Itemized Request - Remarks sub-level form and check the remarks recorded for this part. Revise them if necessary.
 Notes: 
 

 ·      The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 ·      If the PCopyRFQTxt constant is set at its default value of 1 , any remarks for the order item are copied automatically to the requested item. 
 

 ·      To include these remarks in the printout of the RFQ, select a suitable print format . 
 

 6 .  In the Refs & Payment Info tab of the Requests for Price Quotations form, finalize the RFQ by adjusting its Status .
