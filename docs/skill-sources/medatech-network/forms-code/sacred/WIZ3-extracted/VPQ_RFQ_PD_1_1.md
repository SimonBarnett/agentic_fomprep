# Creating RFQs Automatically From a Purchase Demand Document

 

 Priority provides a program that automatically creates RFQs based on PRs in a designated purchase demand document. RFQs are opened for the buyer specified in each PR. If none are specified, the RFQ is opened for the buyer who runs this program. You can also choose to run this program only for those PRs that are assigned to a specific buyer or for PRs that are not assigned to any buyer. 
 

In order to be taken into account, PRs must fulfill the following conditions: 
 

 ·        A vendor must be specified for the requisitioned parts (in the Vendor for PR column). One RFQ will be opened for each vendor to which purchase requisitions are assigned. 
 

 ·        The demand document to which they belong must have a status that allows it to be linked to an RFQ. 
 

 Note: If one or more PRs in the demand document are flagged in the Open RFQ column, RFQs will be opened only for those items. Otherwise, they will be opened for all items. 
 
# To create RFQs from a purchase demand document:

 

 1 .  Enter the Purchase Demands form and retrieve the desired purchase demand document. 
 

 2 .  Select Open Requests for Price Quotes from the list of Direct Activations . One RFQ will be opened for each vendor and buyer to which purchase requisitions are assigned. 
 Note: You can also run this program only for those PRs that are assigned to a specific buyer or for PRs that are not assigned to any buyer.
