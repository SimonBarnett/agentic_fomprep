# To check the requested items:

 

 1 .  Enter the Requested Items sub-level form. The desired items are displayed with their PR number. 
 

 2 .  Make sure that the requested Quantity and Date Needed of each item suit your needs.
 Note: The Date Needed is only the date on which the goods will be leaving the vendor's premises; it should be early enough to allow time for shipment and laboratory testing before the actual date on which the goods are required for use. 
 

 3 .  If this item is being purchased for a project, click to link it to a project or project activity. 
 

 4 .  Enter the Itemized Request - Remarks sub-level form and check the remarks recorded for this part. Revise them if necessary.
 Notes: 
 

 ·      The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 ·      To include these remarks in the printout of the RFQ, select a suitable print format . 
 

 5 .  Return to the Requests for Price Quotations form, and finalize the RFQ by adjusting its Status .
