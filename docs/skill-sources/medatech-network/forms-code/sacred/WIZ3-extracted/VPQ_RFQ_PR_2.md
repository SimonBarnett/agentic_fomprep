# To view the resulting RFQs:

 

 1 .  Enter the Requests for Price Quotations form.
 Tip : Move to Full-Record Display Mode to display results in tabular format. 
 

 2 .  Retrieve the new RFQs. 
 Tips : 
 

 ·      Enter the RFQ Date column and retrieve by the date the program was run. 
 

 ·      To assign handling of an RFQ to another employee, specify his/her username in the Assigned to column. If you have done so for all prepared documents, you can exit the form and ignore the following instructions. 
 

 3 .  For each RFQ, change the date by which you want to receive the quote in the Send Quote Before column, if needed. 
 

 4 .  Specify the desired payment terms in the Requested Terms column. 
 

 5 .  In the Details column, record a brief remark regarding this RFQ. 
 

 6 .  Click if the parts are being purchased for a project. 
 

 7 .  To add remarks to the RFQ that will appear on the printout, enter the RFQ - Remarks sub-level form. 
 

 8 .  To attach a file to the RFQ, enter the Attachments sub-level form.
