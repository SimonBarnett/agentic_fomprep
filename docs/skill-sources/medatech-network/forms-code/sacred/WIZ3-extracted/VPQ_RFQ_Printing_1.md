# Printing an RFQ

 

Before you begin, check remarks and the vendor's mailing address. 
 
## To check remarks that will appear on the printout:

 

 1 .  Enter the Requests for Price Quotations form and retrieve the desired RFQ. 
 

 2 .  Enter the RFQ - Remarks sub-level form. The text appearing in this form will appear as a remark on the printout. Make sure that it is correct. 
 

 3 .  If you are printing RFQs with item remarks , move to the parallel Requested Items sub-level form. Make sure that the remarks displayed in its sub-level, Itemized Request - Remarks , are correct for each item. Revise them if necessary. 
 Note s : 
 

 ·      Any part remarks recorded in the part catalogue appear in this form automatically if Copy Part Remarks has been flagged for RFQs (in the Copy Part Remarks to Document form). 
 

 ·      The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 4 .  Return to the Requests for Price Quotations form. 
 
## To check the vendor's mailing address:

 

 ·        Enter the RFQ - Vendor Details sub-level form. Make sure that the address recorded is correct. 
 

 Tip: To update the address of a regular vendor (as opposed to a one-time vendor), enter the Vendors form.
