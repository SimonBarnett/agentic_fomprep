# To print one RFQ:

 

 1 .  Retrieve the RFQ in the Requests for Price Quotations form. 
 

 2 .  Select Print RFQ from the list of Direct Activations .
 D ual-currency users: If you wish to print the RFQ in English and are working in another language, click Print RFQ in Foreign Language instead. 
 
## To print multiple RFQs:

 

 ·        Run the Print RFQ report.
 D ual-currency users: To print in English when working in another language, run the Print RFQ in Foreign Language report. 
 
## Notes: 

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen.
