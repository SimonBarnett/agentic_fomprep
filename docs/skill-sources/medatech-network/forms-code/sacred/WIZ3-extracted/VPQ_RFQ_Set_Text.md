# Set Text for RFQs

 

If you want certain remarks to appear on all printouts of RFQs, you can designate set text for this purpose. These remarks will automatically appear in the RFQ - Remarks sub-level form of each new RFQ, but may be revised there. Any remarks appearing in that sub-level form appear automatically in the printout of the RFQ. 
 
## To designate set text:

 

 1 .  Enter the Set Text for RFQs form. 
 

 2 .  Record the desired remarks in the Set Text for RFQs sub-level form.
 Dual-currency users: If you are working in a language other than English, and wish to print out shipping documents in English, record set text in the Set Text for RFQs-Lang 2 sub-level form. Any documents opened for vendors defined as receiving Printouts in Lang 2 will contain set text in English. 
 
## Note: 

 

When an order is copied from a price quotation, the quote's remarks may overwrite the set text for orders (depending on the value of the PCopyRFQTxt constant), but they may be revised.
