# Setting Up RFQs and Vendor Quotes

 

Before you begin working with RFQs and vendor price quotations, you need to set up the following: 
 

 ·        How RFQs are itemized on the basis of purchase demand documents 
 

 ·        Whether sales order remarks are copied into RFQs based on the order 
 

 ·        Set text for RFQs 
 

 ·        Whether part remarks are copied into RFQs and vendor price quotes 
 

 ·        Business processes (BPM) for RFQs and price quotations – i.e., statuses
