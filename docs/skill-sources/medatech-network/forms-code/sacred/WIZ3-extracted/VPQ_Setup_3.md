# Setting Up Business Processes for RFQs and Quotes

 

You set up business processes by defining statuses in BPM flow charts. 
 

There are several predefined statuses for RFQs and vendor quotes, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties . 
 
## To use the flow charts:

 

 ·        Run one of the following programs: 
 

 BPM Flow Chart-RFQs 
 

 BPM Flow Chart-Vendor Quotes 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter one of the following forms: 
 

 ·      Statuses for RFQs 
 

 ·      Statuses for Vendor Quotes 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide . 
 

 ·        Click to return to the main screen.
