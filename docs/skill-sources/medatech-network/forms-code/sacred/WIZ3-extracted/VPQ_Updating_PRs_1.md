# Assigning Price Quotes to Purchase Requisitions

 

There are two methods of importing price quote data into purchase requisitions in order to generate purchase orders that use the quoted prices. The automatic method is useful when an entire purchase demand document is recorded for a single vendor, and all or most of the items it lists are recorded in a single vendor price quote. The manual method is useful when you want to link the same quoted item to multiple PRs, or when multiple prices have been quoted for different amounts of the requisitioned items.
