# Creating a New Version of an Existing Price List

 

You can create several versions of a given price list. Each version has a different effect date and appears on a separate line in the Vendor Price Lists form. 
 
## To create a new version of an existing price list:

 

 ·        Run the Copy Vendor Price List program. In the To Price List input column, specify the code of the original price list. 
 
## Notes:

 

 ·        Click to update prices in the new version. 
 

 ·        Click to use other price list tools.
