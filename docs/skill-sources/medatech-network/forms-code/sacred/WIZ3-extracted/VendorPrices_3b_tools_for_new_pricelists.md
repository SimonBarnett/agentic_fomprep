# Recording New Vendor Price Lists

 

You can create new price lists in several ways: automatically, manually and per manufacturer. 
 
## Tips:

 

 ·        Prepare the price list manually if the vendor offers different prices for different minimum quantities of the same part. 
 

 ·        Prepare manufacturer price lists if the vendor maintains a separate price list per manufacturer. Example. 
 
## What do you want to do?

 

 Prepare a vendor price list automatically 
 

 Record a vendor price list manually
