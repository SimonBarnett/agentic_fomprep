# Determining Whether to Check for Parts in Vendor Part Lists

 

When itemizing a purchasing document, the system can check whether the part is included in the list of parts defined for the vendor in question. The PChkVendPart constant determines whether such a check is performed, and whether the user will see a warning or an error message if the part is not included in the vendor's list of parts. 
 
## To define how the system checks for parts in the vendor part list:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the PChkVendPart constant and select the desired value.
