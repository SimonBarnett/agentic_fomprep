# Assigning Vendor Rankings

 

You can assign a preferred vendor to each part. As a result: 
 

 ·        this vendor will be automatically assigned as the default for purchase requisitions of this part 
 

 ·        you can prepare requests for price quotations (RFQs) from purchase requisitions (PRs) automatically for this vendor 
 

 ·        this vendor's part price will appear in the Part Catalogue . 
 

You can also assign different rankings to various vendors that sell the same part. This is useful if you want to prepare RFQs from PRs for all vendors up to a given rank. 
 
## Notes:

 

 ·        The preferred vendor always has a ranking of 1 . 
 

 ·        If you change the preferred vendor after the vendor's price list has been recorded, run the Update Prices in Part Catalogue program to update the purchase price in the Part Catalogue .
