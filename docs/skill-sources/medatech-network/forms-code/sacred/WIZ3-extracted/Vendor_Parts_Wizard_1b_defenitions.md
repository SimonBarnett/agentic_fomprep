# Defining a Vendor Unit

 

Whenever a vendor sells a part in a different unit than your buy/sell unit, you need to define the vendor unit separately. That is, you need to ensure that the system recognizes this unit and that a conversion ratio is defined between the vendor unit and the buy/sell unit. 
 
## To define a vendor unit:

 

 ·        Enter the Part Units form. If the vendor unit in question does not appear in the predefined list of units, add it to the list. 
 
## To define a conversion ratio between the vendor unit and the buy/sell unit:

 

 ·        Enter the Unit Conversions form. If the ratio between the two units has not yet been defined, specify the conversion ratio.
