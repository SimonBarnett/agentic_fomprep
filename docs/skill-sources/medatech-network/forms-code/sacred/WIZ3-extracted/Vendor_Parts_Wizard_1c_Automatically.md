 ·        Run the Add Parts to Vendor List program. 
 
## Notes:

 

 ·        To add details (e.g., vendor unit) to the obtained list, use the Vendor Parts form (retrieve by vendor and/or part). 
 

 ·        Click to return to the main screen .
