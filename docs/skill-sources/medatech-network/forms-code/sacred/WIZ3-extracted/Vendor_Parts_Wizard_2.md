# Creating Vendor Part Lists

 

Vendor part lists can be created and updated automatically or manually. 
 

Use the automatic facility to: 
 

 ·        add all parts for which manufacturer part numbers have been defined 
 

 ·        add all parts belonging to one or more part families. 
 

Record or update the list manually to: 
 

 ·        add individual parts 
 

 ·        record additional details (e.g., vendor part number and description, vendor unit). 
 

Before beginning, make sure that all vendor units are defined in the system, as well as a list of manufacturers and their parts (for vendors that use the manufacturer's part number). 
 

 ·        Click to set up vendor units . 
 

 ·        Click to set up manufacturers and their parts . 
 
## Notes:

 

 ·        The vendor's list of parts is created or updated automatically when a new vendor price list is recorded. 
 

 ·        You cannot delete a part from a vendor part list once this part appears in any document recorded for that vendor. When the vendor stops supplying this part, you can flag it as invalid.
