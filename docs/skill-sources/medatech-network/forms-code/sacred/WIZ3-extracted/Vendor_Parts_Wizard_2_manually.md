- 
 
 
 
# To create a vendor part list manually:

 

 1 .  Enter the Vendor Parts form. 
 

 2 .  Designate the vendor number. 
 

 3 .  Designate the part number and description as defined by the vendor or manufacturer. 
 

 4 .  Designate the internal part number (as defined in Priority ).
 Tip: If the part is not defined in the system, run the Part Definition Wizard . 
 

 5 .  If the vendor's part unit differs from the part's buy/sell unit, specify the vendor unit. 
 

 6 .  If the part in question is produced by a specific manufacturer, designate the manufacturer code. 
 
## Notes:

 

 ·        You can also create a list of parts for each vendor by using the Parts per Vendor form, sub-level of the Vendors form. 
 

 ·        Any part with a manufacturer's part number is automatically added to the vendor's part list the first time it is recorded in a purchase order to that vendor. Click to record manufacturer part numbers . 
 

 ·        Click to return to the main screen .
