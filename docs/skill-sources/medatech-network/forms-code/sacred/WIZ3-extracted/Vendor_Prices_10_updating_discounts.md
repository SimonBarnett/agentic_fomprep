# Setting/Updating Discounts in an Existing Price List

 

There are several ways to add or update part discounts in an existing price list: 
 

 ·        automatically assign the same discount to all items in a given vendor price list 
 

 ·        automatically assign the same discount to a batch of parts 
 

 ·        automatically raise or lower the discount (by the same percentage) for a group of parts 
 

 ·        automatically update the discount of a group of parts according to a base product 
 

 ·        manually record/update discounts for individual parts. 
 
## To assign the same discount to items in a vendor price list:

 

 1 .  Enter the Vendor Price Lists form and retrieve the desired price list. 
 

 2 .  Select Update Item Discounts from the list of Direct Activations . 
 
## To assign the same discount to a batch of parts:

 

 ·        Run the Revise Discounts in Price List program, choosing the Set Discounts option. 
 
## To update the discount for a batch of parts:

 

 ·        Run the same program, selecting the Raise/Lower Discount option.
