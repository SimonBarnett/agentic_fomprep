# Set Up Vendor Parts and Prices

 

Before you begin to record vendor parts, prices, rankings and quality levels, you need to: 
 

 Choose whether to maintain vendor price lists or record a single purchase price per part 
 

 Create a list of manufacturers and their parts (where applicable) 
 

 Set up vendor units (when they differ from the part's buy/sell unit) 
 

 Define the time period in which to search for a part ' s last price. 
 

 Set whether to check if purchased parts are included in the vendor's list of parts .
