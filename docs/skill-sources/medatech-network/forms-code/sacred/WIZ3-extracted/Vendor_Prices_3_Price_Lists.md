# Vendor Price Lists

 

 Priority uses vendor price lists to record the prices charged by vendors from which you make purchases on a regular basis. 
 

To document price histories, Priority stores all previous invalidated price lists. When part prices are filled in automatically (e.g., in a purchase order), they are always taken from the price list currently in effect. 
 

Vendor price lists contain both prices and discounts (per part). You can record different unit prices for different minimum quantities. Example. If you work with base products , you can define the part's price policy such that changes to the base product price (in a given price list) automatically update the price of all attached parts. 
 

You can create an unlimited number of price lists for each vendor, including one used specifically for commission sales. If the vendor maintains individual price lists per manufacturer, you can record each manufacturer price list separately. Example . 
 
## Notes:

 

 ·        If your vendor sells a part in a different unit of measure than the part's buy/sell unit, include that part, with its vendor unit, in the vendor's list of parts before recording the price list for that vendor. Click for details . 
 

 ·        Vendor price lists can be used as the basis for customer price lists. For more details, see the Prices and Discounts Wizard .
