# Updating an Existing Price List

 

You can update a vendor price list by adding parts or raising and lowering prices and discounts. If you work with base products , you can automatically update all its linked parts in a given price list. 
 
## What do you want to do?

 

 Update prices by a fixed sum or percentage 
 

 Record/update discounts in a price list 
 

 Update prices according to a base product 
 

 Update vendor prices in price lists from the part catalogue
