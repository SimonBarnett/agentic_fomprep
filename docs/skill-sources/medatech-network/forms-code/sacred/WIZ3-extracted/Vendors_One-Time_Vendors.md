# One-Time Vendors

 

If you purchase goods from a number of vendors on a one-time basis, you do not have to open an A/P account for each vendor. Instead, you can create one account for all one-time vendors. 
 
## To open a one-time vendor record:

 

 1 .  Enter the Vendors form. 
 

 2 .  Record a general Vendor Number for one-time vendors (e.g., V000 ), and a general description (e.g., One-times ) in the Vendor Name column.
 Note: At any point in the following process, you can transfer handling of the general vendor to another employee, by specifying his/her username in the Assigned to column. 
 

 3 .  Click the Details tab and flag the Change Name column. This allows you to fill in the names of the actual vendors in purchase orders and invoices. 
 

 4 .   Dual-currency users: If you are working in a language other than English and want to produce documents for this vendor in English: 
 

 ·      Specify the vendor's English name in the Name (Lang 2) column. 
 

 ·      Click the Details tab and flag the Printouts in Lang2 column. 
 

 ·      Enter the Additional Vendor Data sub-level form and record the vendor's address in English. 
 
## To record financial parameters (dual-currency users only):

 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the one-time vendor record. 
 

 2 .  In the General tab, select “Input VAT” in the VAT Code column.
 Note: When recording the purchase of a fixed asset from a one-time vendor, you need to manually change the VAT Code in the purchase document to “VAT on fixed expenses”. Similarly, when recording a purchase that is not subject to VAT, you need to change the code to one that signifies exemption from VAT.
