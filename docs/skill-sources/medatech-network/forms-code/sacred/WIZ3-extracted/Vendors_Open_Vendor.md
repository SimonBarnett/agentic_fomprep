# Opening a Vendor

 

If you are beginning to work in Priority and would like to retain your old vendor numbers, you can open vendor records and number them manually, and matching A/R accounts will be opened automatically. 
 

Otherwise, you can open a new vendor record by name; the system assigns the vendor number based on the pattern defined in the vendor numeration template, then automatically opens a matching A/P account. 
 
## What do you want to do?

 

 Open a new vendor record and A/P account with automatic numeration 
 

 Open new vendor records with account numbers from the previous system 
 
## Notes:

 

 ·        You can also open the A/P account, and the system opens a matching vendor record. 
 

 ·        Click to open a vendor record and A/P account with different numbers. This option is not available if you work with subsidiaries.
