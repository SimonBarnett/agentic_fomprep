# To open a vendor record and A/P account (automatic numeration):

 

 1 .  Enter the Vendors form. 
 

 2 .  Record a Vendor Name . When you leave the column, the system will assign a Vendor Number , based on the pattern defined in the vendor numeration template. When you leave the form, an A/P account with the same number will be opened automatically. 
 Note: At any point in the following process, you can transfer handling of the vendor to another employee, by specifying his/her username in the Assigned to column. 
 

 3 .  If this vendor works with a specific company branch, click the Details tab and designate the branch. All documents opened for this vendor (e.g., purchase orders) will automatically be recorded for this branch and numbered according to its numeration templates.
 Note: If you work with subsidiaries, the vendor's A/P account is automatically assigned to the subsidiary to which the designated branch is linked. For more information, run the Subsidiaries Wizard . 
 

 4 .  Click the Address and Phone tab and fill in the vendor's contact information. 
 

 5 .  Click the Payments tab and select the Payment Terms agreed upon with the vendor.
 Note : To define additional payment terms, run the Set Up Payment Terms Wizard . 
 

 6 .  Fill in any other pertinent information, such as Overall Quality Code ( Details tab) and Shipment Mode ( Shipments tab). 
 

 7 .   Dual-currency users: If you are working in a language other than English and want to produce documents for this vendor in English: 
 

 ·      Specify the vendor's English name in the Name (Lang 2) column. 
 

 ·      Click the Details tab and flag the Printouts in Lang2 column. 
 

 ·      Enter the Additional Vendor Data sub-level form and record the vendor's address in English.
