# Setting Up Business Processes for Vendors

 

You set up business processes by defining statuses in a BPM flow chart. 
 

There are several predefined statuses for vendors, to which you can add as many statuses as you like. You can create work flow rules , define paths between statuses and set status properties . 
 
## Note:

 

Click for an explanation of how BPM statuses and rules affect the To Do list of employees assigned to specific vendors. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Vendors program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Vendors form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
