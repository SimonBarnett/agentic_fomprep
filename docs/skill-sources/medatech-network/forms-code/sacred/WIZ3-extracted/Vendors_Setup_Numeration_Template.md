# Setting Up Numeration Templates

 

You can assign identifying numbers to your vendors manually, or allow the system to do so automatically. If you choose the latter, you need to define numeration templates that reflect the way you want your vendors to be numbered. 
 

Vendor numbers are divided into three parts: a prefix, placeholders for the number itself and a suffix. There are default values for both the prefix and the number of placeholders, which you can change within certain limitations. 
 
## To define vendor numeration templates:

 

 1 .  Enter the Cust & Vend Numeration Templates form. 
 

 2 .  On the Vendors line, adjust the Prefix , Suffix or Place Holders as needed. Example .
 Tip: The prefix and suffix can be any combination of up to five alphanumeric characters. The total number of characters may not exceed sixteen.
