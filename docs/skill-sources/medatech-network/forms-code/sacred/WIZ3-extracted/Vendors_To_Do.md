# Working With the To Do List

 

Each new vendor is assigned to an employee, who is thereafter responsible for handling all business dealings with the vendor. This assignment is subject to change, according to the rules defined for BPM statuses and paths. For example, a vendor that is given a status that blocks payments is likely to be assigned to a different employee. 
 

All tasks affecting a given vendor appear in the To Do list of the employee currently assigned. The Vendors form includes three sub-level forms to assist you in managing vendor-related tasks: 
 

 ·        The To Do List sub-level form displays the details of all To Do list tasks opened for the current vendor, including the relevant assigned employee, the type of transaction, its start date and planned end date. 
 

 ·        The To Do Item form displays the To Do List item currently in effect for the vendor in the upper-level form. This information is also displayed among the other items in the To Do List parallel sub-level form.
 Note: If a status is assigned that renders the vendor inactive or hidden from the To Do list, this form will appear empty. 
 

 ·        The History of Statuses maintains a history of all statuses assigned to the current vendor, the date they were assigned, who assigned them and the number of the To Do list task.
