# Working with One-time Vendors

 

You can record purchase orders, GRVs and invoices for one-time vendors. 
 
## To open a document for a one-time vendor:

 

 1 .  In the Vendor Number column, choose the one-time vendor number. In the Vendor Name column, record the one-time vendor's name. 
 

 2 .  Click the Address and Number column and record the vendor's address and phone number. This information will appear on the printout of the document. 
 
## Note:

 

Click to return to the main screen.
