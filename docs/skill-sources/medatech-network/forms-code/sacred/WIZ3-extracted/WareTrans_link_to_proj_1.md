# Linking the Transfer Document to a Project

 

You can link the document to a project or to a specific project activity (when the entire transfer is for a single activity). When goods are being transferred between a project warehouse and a non-project warehouse, the cost of the transferred goods is added to (or subtracted from) the cost of the project or activity to which it is linked. 
 

Project linkage occurs automatically if the transfer is recorded on the basis of a single sales order linked to a project. 
 
## Note:

 

When itemizing the transfer, you will also be able to link individual items to a project or activity.
