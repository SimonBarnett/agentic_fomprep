# To print a transfer document:

 

 1 .  Enter the Warehouse Transfer form and retrieve the desired document. 
 

 2 .  Select Print Warehouse Transfer Doc. from the list of Direct Activations .
 D ual-currency users: If you wish to print the transfer document in English and are working in another language, click Print Warehs Transf-Foreign Lang instead.
