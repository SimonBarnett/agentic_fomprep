# Transferring Packed Crates

 

If you are transferring crates that have been included in a packing slip, you can itemize the transfer document automatically with the contents of these crates. 
 
## Note:

 

If the transfer of the crates is for an internal order, first make sure the packing slip is linked to the order. For help in revising a final packing slip, run the Packing Slip Wizard . 
 
## To record the transfer of crates:

 

 1 .  Enter the Warehouse Transfer form.
 Note: At any point in the following process, you can transfer handling of the document to another employee, by specifying his/her username in the Assigned to column (in the General tab). 
 

 2 .  Specify the Date of the transfer. An internal Document number is filled in automatically. 
 

 3 .  Click the General tab. The Sending Warehouse (and Bin , if any) from which the goods are being transferred (e.g., the warehouse of the main office) is filled in automatically. Revise if necessary.
 Notes: 
 

 ·      If goods are transferred from more than one bin, designate the main one here. When itemizing the document, indicate the appropriate bin for each part. 
 

 ·      Click to change the default sending warehouse for future transfers.
