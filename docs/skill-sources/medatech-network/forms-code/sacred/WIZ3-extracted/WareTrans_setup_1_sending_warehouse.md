# To define a default sending warehouse:

 

 1 .  Enter the Inv. Transaction Documents form and move to the Warehouse Transfer line. 
 

 2 .  In the Default Warehouse column, choose the desired warehouse. This warehouse will be filled in automatically as the default sending warehouse in every new transfer document. 
 

 3 .  Choose a default sending Bin , if necessary. 
 
## Tip: 

 

To define more warehouses and bins, use the Open a Warehouse Wizard .
