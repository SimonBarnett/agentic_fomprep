# Displaying Original/Copy on Printouts

 

The system can be set up so that final transfer documents display "Original" on the first printout and "Copy" on any subsequent printouts. Definitions are recorded per warehouse and will only affect printouts of transfer documents involving that warehouse (as the sending or receiving warehouse). 
 
## To set up the display of Original/Copy:

 

 1 .  Enter the Warehouses form. 
 

 2 .  Retrieve the warehouse in question. 
 

 3 .  Flag the Print "Original" column. 
 
## Note:

 

The transfer document printout will display Original/Copy only when the transfer is between two different warehouses and not between two different bins within the same warehouse.
