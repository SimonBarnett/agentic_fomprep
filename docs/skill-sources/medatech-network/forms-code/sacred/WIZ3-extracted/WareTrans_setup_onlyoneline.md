# Setting Up the Transfer of Ordered Items

 

When transferring goods on the basis of orders, you must decide how to itemize the transfer document: one line per order item OR multiple lines. Explanation . 
 
## To set this parameter:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Check the value of the SOnlyOneLine constant and change it, if necessary. 
 
## Note:

 

This constant also affects itemization of customer shipments, sales invoices and over-the-counter invoices.
