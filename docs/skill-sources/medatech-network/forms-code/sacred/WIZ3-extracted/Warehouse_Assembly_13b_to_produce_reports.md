# Viewing Scheduled Assemblies

 

There are several reports and forms you can use to view scheduled assemblies and their components. 
 
## To view assemblies assigned to a worker over a given period:

 

 ·        Run the Assembly Plan by Assigned Worker report. 
 
## To view the total number of scheduled assemblies per worker and assembly date:

 

 ·        Run the Assembly Schedule (table) report. 
 
## To view information per assembled part: 

 

 ·        Enter the View Assembly Reports form, and retrieve by assembled part (or any other pertinent criterion). Enter the sub-level form to view details of assembled components and reported assembly hours . 
 
## To view assembled components and reported assembly hours : 

 

 ·        Enter the View Issues to Assemblies form, and retrieve by issued part (or any other pertinent criterion). 
 
## To print assembly documents:

 

 ·        To print a batch of documents, run the Print Reports of Assembly report. 
 

 ·        To print a particular document, retrieve it in the Warehouse Assembly form and run the same report from the list of Direct Activation s .
