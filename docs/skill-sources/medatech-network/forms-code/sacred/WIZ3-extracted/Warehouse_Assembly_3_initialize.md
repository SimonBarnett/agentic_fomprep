# Set Up for Warehouse Assemblies

 
## Setting Up Parts

 

All parts (assembled parent, component children and employee work hours) must be defined in the database. 
 

For information on opening a part and creating a standard bill of materials, see the Part Definition Wizard . 
 
## Setting Up Default Warehouses

 

When you record an assembly, you need to indicate the warehouse in which the parts are assembled ( assembly warehouse ) and the warehouse(s) from which the child parts are issued ( issuing warehouse ). 
 

 Priority allows you to define one of your warehouses as the default assembly warehouse . This warehouse appears automatically when you open an assembly document, though it may be revised. 
 

In regard to the issuing warehouse , there are two options: 
 

 ·        It can be identical to the assembly warehouse for all child parts, OR 
 

 ·        You can define a different default issuing warehouse for each child part.
