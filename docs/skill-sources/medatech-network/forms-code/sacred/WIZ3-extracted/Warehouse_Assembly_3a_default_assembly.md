# To set up a default assembly warehouse:

 

 1 .  Enter the Inv. Transaction Documents form. 
 

 2 .  Move to the line for Assembly Report . 
 

 3 .  In the Warehouse Default column, choose the warehouse in which assemblies are usually carried out. 
 
## Note:

 

Click to define a default issuing warehouse for each child part.
