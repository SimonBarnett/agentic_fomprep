 Setting Up Employee Work Hour Parts 
 

You can assign default work hour parts per employee, which are useful when reporting work time for warehouse assemblies, as well as for other tasks in Priority . The assigned part appears automatically when you record an employee, though it may be revised. The cost assigned to the part determines the labor cost of the assembly. 
 
## Setting Up Serialized Parts

 

When you open an assembly document for serialized parts on the basis of a sales order, the required quantity of serial numbers is opened automatically. The maximum number of serial numbers that can be opened at any one time is determined by a constant, which you can revise. 
 
## Defining Set Text for Assembly Reports

 

You can record set text that will appear on printouts of assembly reports. These remarks can be revised manually for individual assembly documents. 
 
## Setting Up Part Remarks for Assembly Documents

 

You can set up assembly documents so that part remarks are recorded automatically for assembled components when a child part number is recorded or revised. These remarks are taken from the relevant record in the Part Catalogue . 
 
## Setting Up Business Processes (BPM) for Assemblies

 

You set up business processes by defining statuses in a BPM flow chart. A list of predefined statuses is provided, but can be revised and added to. By using statuses, you can improve the handling of assemblies.
