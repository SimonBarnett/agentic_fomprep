# To set up default issuing warehouses per child part:

 

 1 .  In the Logistic Constants form, change the value of the IPartWarhsAs constant to 1 . 
 

 2 .  In the Inventory Parameters for Parts form, retrieve each child part and ensure that the warehouse in question appears in the Warehouse column.
 Note: This column also affects preparation of inventory counts.
