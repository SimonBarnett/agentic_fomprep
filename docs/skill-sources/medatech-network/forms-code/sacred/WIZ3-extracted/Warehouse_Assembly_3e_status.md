# Setting Up Business Processes for Assemblies

 

You set up business processes by defining statuses in a BPM flow chart. 
 

There are several predefined statuses for warehouse assembly documents, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Assemblies program. 
 
## Tips: 

 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Assemblies form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
