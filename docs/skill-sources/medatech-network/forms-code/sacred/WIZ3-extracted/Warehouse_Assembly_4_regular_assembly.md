# To open an assembly document:

 
## Note:

 

Click if the assembly is based on a sales order. 
 

 1 .  Enter the Warehouse Assembly form. 
 

2. Record the expected date of the assembly. The default assembly warehouse is filled in automatically. 
 

3. If the warehouse in which the assembly is to be carried out differs from the default assembly warehouse, change it. Record the Bin , if needed. 
 
## Tip:

 

Stay in the form until you finish using the wizard.
