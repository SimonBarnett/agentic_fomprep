Warehouse Assemblies - Recording Details for Child Parts 
 
 
- 
 
 
 
# To record details for child parts:

 

 1 .  Enter the Assembly Components sub-level form. This form displays the child parts of the assembled part, based on the standard BOM. 
 

 2 .  Do one of the following: 
 

 ·      If you are using the standard BOM (i.e., you left the check mark in the Auto Record Child column), make sure the Required Quantity of each child part is correct. 
 

 ·      If you want to use a custom BOM (i.e., you removed the check mark), record the required quantity for each child part. If desired, add more components and indicate their required quantities. 
 

 Notes: 
 

 ·      If the child part has serial numbers, record each unit on a separate line, with a quantity of 1 . 
 

 ·      If the displayed child part data do not properly reflect the part's standard BOM, you may need to run the Build/Rebuild Planning Data program. Contact the customer support staff before doing so. 
 

 3 .  For each child part, make sure that the Issuing Warehouse is correct; revise it if necessary. The inventory balance of the child in the issuing warehouse appears in the Warehouse Balance column. 
 

 4 .  Record a Serial Number for the child part, if necessary.
 Notes: 
 

 ·      If a serial number was already opened for this part, select the number from the Choose list. 
 

 ·      Recording a serial number for the child part automatically updates the Serialized Components of Part form, sub-level of the Catalogue of Parts w/Serial Nos. form.
