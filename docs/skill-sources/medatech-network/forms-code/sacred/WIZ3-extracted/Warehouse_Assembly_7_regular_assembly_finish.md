Warehouse Assemblies - Changing the Status of an Assembly Document 
 
 
- 
 
 
 
# To change the status of the assembly document:

 

 1 .  Return to the Warehouse Assembly form. 
 

 2 .  Click the References tab and fill in the Details column, if desired. 
 

 3 .  In the General tab, change the status of the assembly. In the Scheduling tab, assign it to the next user responsible for handling it.
