# Recording an Assembly Based on a Sales Order

 

In an assembly that is based on an order, each order item appears on a separate line of the itemized assembly document. Issues of child parts are calculated according to the bill of materials recorded in the order. If a custom BOM was not recorded in the order, issues are made on the basis of the part's standard BOM. 
 

If serial numbers are maintained for the ordered part, the system opens a separate line in the assembly document for each unit of the ordered part. Example . A specific serial number can then be recorded for each unit. When reporting the assembly, you can record serial numbers for its component parts. These will be automatically linked to the serialized parent part. 
 

An assembly document can be created automatically from within the sales order or opened manually.
