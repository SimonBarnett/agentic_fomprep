# Printing Reported Assemblies

 
## Before you begin

 

 1 .  In the Warehouse Assembly form, retrieve the desired document. 
 

 2 .  Enter the Remarks sub-level form. The text recorded here will appear as a remark on the printout. Make sure it is correct. 
 

 3 .  If you are printing reported assemblies with item remarks , move to the parallel Assembly Reporting sub-level form. Make sure that the remarks displayed in its sub-level, Line Items - Remarks , are appropriate. Explanation. Revise as needed.
 Note: The text may not be open to revision (if the IChgPartText constant is set to 1 and the part description is not changeable). 
 

 4 .  Return to the Warehouse Assembly form. 
 
## To print a single assembly report:

 

 ·        Select Print Reports of Assembly from the list of Direct Activation s . 
 
## To print a group of assembly reports:

 

 ·        Run the Print Reports of Assembly report. 
 
## Notes:

 

 ·        To change the current print format, select the desired format (in the Print/Send Options dialog box) before choosing whether to display or print the report. 
 

 ·        Click to return to the main screen.
