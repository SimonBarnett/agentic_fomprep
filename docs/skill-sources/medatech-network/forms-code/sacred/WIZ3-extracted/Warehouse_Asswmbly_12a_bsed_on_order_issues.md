Warehouse Assemblies - Viewing Child Parts 
 
 
- 
 
 
 
# To view child parts:

 

 1 .  Enter the Assembly Components sub-level form. The form displays the child parts of the assembled part, based on the BOM appearing in the order, if there is one, or the parent's standard BOM, if there is not. 
 

 2 .  Make sure that the required quantity of each child part is correct.
 Note: If the displayed child part data do not properly reflect the part's standard BOM, you may need to run the Build/Rebuild Planning Data program. Contact the customer support staff before doing so. 
 

 3 .  Make sure that the Issuing Warehouse for each child is correct (revise if necessary). The inventory balance of each child in the issuing warehouse appears In the Warehouse Balance column.
