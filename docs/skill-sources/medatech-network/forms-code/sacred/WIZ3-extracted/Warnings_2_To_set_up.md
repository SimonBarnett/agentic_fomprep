# To set up e-mail alerts:

 

 1 .  Enter the Form Priv Restrictns + Warn Msgs query form. Retrieve the desired form. 
 

 2 .  Enter the Warning Messages in the Form sub-level form (also a query form). Move to the desired message. 
 

 3 .  Enter the E-mail Alert for Warning form (a sub-level of the Warning Messages in the Form form). 
 

 4 .  Specify one or more of the following: 
 

 ·      A group 
 

 ·      An individual user 
 

 ·      An external e-mail address 
 

 5 .  To limit the alert to warning messages received in a particular company, choose the company code. To set it up for all companies, leave the Company column blank.
 Note: To set up the alert in two or more companies, but not all, record a separate line for each company.
