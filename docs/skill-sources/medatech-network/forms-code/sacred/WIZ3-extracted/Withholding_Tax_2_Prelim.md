# Setting Up for Withholding Tax

 

In order to record taxes withheld from vendors, you need to define an account for withholding tax, set general withholding tax definitions and definitions per vendor and flag transaction types included in withholding tax reports. 
 
## What do you want to do?

 

 Define the withholding tax account 
 

 Set up constants affecting withholding tax 
 

 Define tax brackets for progressive withholding tax 
 

 Set up vendors 
 

 Flag transaction types for inclusion in reports
