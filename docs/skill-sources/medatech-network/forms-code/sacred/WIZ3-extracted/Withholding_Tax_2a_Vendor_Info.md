# Defining Withholding Tax Settings for Vendors

 

The definitions assigned depend on whether the vendor is a local or foreign business. For a local vendor, you need to record the percentage of withholding tax required by the tax authorities, as well as any authorization for a full or partial exemption. You need to define a foreign vendor as exempt from withholding taxes. 
 
## Note:

 

Foreign vendors that are subject to withholding tax should be assigned the same settings as local vendors.
