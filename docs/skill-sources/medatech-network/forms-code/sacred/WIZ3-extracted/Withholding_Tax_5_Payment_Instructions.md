# Recording Payments With Tax Withheld Directly in the Journal Entry

 

When recording payments directly in the entry journal, you must do the following in order for withheld tax to be taken into account in withholding tax reports: 
 

 ·        Make sure the entry code has been flagged for inclusion in the reports. 
 Note: Click to flag the entry code . 
 

 ·        On the line debiting the vendor account, record the bank as the contra account. 
 

 ·        On the lines crediting the bank and crediting the withheld tax, record the vendor as the contra account. Example.
