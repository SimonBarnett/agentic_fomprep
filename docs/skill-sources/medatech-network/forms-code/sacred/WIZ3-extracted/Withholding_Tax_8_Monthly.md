# Preparing Monthly Reports of Withheld Tax

 

You can run monthly reports for a single company and consolidated monthly reports in a multi-company environment. Results can be copied to your official monthly reports of withheld tax. 
 
## In a single company:

 

 ·        Run the Withheld Taxes report in detailed or summary format.
 Note: To check data against recorded payment documents (but not manual journal entries), run the Withheld Tax Versus Payments report. 
 
## In a multi-company environment:

 

 ·        Run the Consolidated Withholding Tax report.
 Note: Consolidated reports will include those companies that have been selected in the Define Multiple Companies dialog box (accessed via the upper File menu). If no companies have been selected, reports are limited to those companies flagged as Multi-company in the Companies form.
