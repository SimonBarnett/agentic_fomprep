# Setting Up Constants That Affect Withholding Tax

 

Three constants affect how withholding tax is calculated . The WTaxCalc constant determines whether withholding tax is calculated for payment amounts including VAT or without VAT. The WTaxPeriod constant determines whether calculations of previous vendor payments and withheld taxes (used to determine progressive withheld tax for the current payment) are for the current month or the current year. The WTaxCheck constant, determines whether the system checks if the withholding tax authorization for the vendor has expired prior to recording a payment. 
 

 To set these constant s: 
 

 ·        Enter the Financial Constants form and move to the appropriate line.
