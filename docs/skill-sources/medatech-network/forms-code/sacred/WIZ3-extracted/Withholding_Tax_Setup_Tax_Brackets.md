# Defining Tax Brackets for Progressive Withholding Tax

 

When the percentage of withholding tax depends on the amount of payment, you need to define the tax brackets used to calculate progressive withholding tax on vendor payments. You can define universal withholding brackets, as well as brackets used to calculate progressive withholding tax for a specific vendor. Tax brackets for the vendor will only be taken into account if the vendor's tax authorization has not expired (as defined in the Expiration Date column of the Financial Parameters for Vendors form, in the Withholding Tax tab). Once they expire, the universal brackets recorded for the vendor's Max. Tax Code (also defined in the Financial Parameters for Vendors form) will be taken into account instead. 
 

 To de fine universal withholding brackets : 
 

 1 .  Enter the Withholding Tax Definitions form and retrieve the withholding tax code in question. 
 

 2 .  Enter the Withholding Brackets sub-level form. 
 

 3 .  Specify the lower limit and the Withheld % for each tax bracket. The Cumulative Withheld amount and upper limit through which the current bracket is in effect are filled in automatically.
 Note: The table must start from 0, with a defined percentage.. 
 

 To define tax brackets for a specific vendor: 
 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the vendor in question. 
 

 2 .  Enter the Progressive Withholding Tax sub-level form and define brackets for withholding tax from the vendor in the same way.
