# To assign tax settings to foreign vendors:

 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the vendor in question. 
 

 2 .  Click the Withholding Tax tab. 
 

 3 .  In the Max . Tax Code column, assign the code that exempts vendors from withheld tax ( 100 ).
