Withholding Tax Wizard - Setup: Local Vendors 
 
 
- 
 
 
 
# To assign tax settings to local vendors:

 

 1 .  Enter the Financial Parameters for Vendors form and retrieve the vendor in question. 
 

 2 .  Click the Withholding Tax tab. 
 

 3 .  Do one of the following: 
 

 ·              If local vendors are subject to progressive withholding tax, click here. 
 

 ·              If the vendor has a partial exemption for withholding taxes, record the reduced percentage in the % Withholding Tax column. If the vendor has a full exemption, leave the value of 0.00 in that column. Then record the Expiration Date of the exemption. 
 

 4 .  In the Max . Tax Code column, assign the code for withheld tax for vendors. The % Maximum Tax column will be filled in with the percentage you have assigned for maximum withheld tax. If the vendor does not have a valid exemption or the vendor's tax bracket definitions have expired, this value will determine the amount that is withheld. 
 

 5 .  Specify the official number of the vendor's tax withholding file in the Registr No.-W. Tax. column and assign the appropriate value in the Type of Tax File column. 
 

 6 .  If tax is to be withheld from the vendor, flag the Must Rep. Income column. If tax is only to be withheld over a specific period, designate start and end dates in the From Date and To Date columns.
