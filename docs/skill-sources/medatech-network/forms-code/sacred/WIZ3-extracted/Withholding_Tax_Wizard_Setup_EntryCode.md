# Flagging Payment Transactions for Inclusion in Withholding Tax Reports

 

In order for a given type of journal entry to be taken into consideration in monthly and annual withholding tax reports, the entry code has to be flagged as such. Predefined entry codes for check payments and bank transfers are already flagged. If any additional entries for payments are used in your company, these must be flagged as well. 
 
## To flag an entry code for inclusion:

 

 1 .  Enter the Financial Parameters for Vendors form. 
 

 2 .  Move to the line for the transaction type in question. 
 

 3 .  Flag the In Withhd Tax Report column.
