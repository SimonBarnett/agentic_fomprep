# Releasing a Work Order

 

By releasing a work order, you authorize its execution; that is, you can only issue parts or report production once the work order has been released. When a work order is released, the Release operation is automatically reported for it. In addition, its kit list and routing are prepared automatically. 
 

Changes made to the part (e.g., to its BOM) after release of the work order do not affect the work order. 
 
## Note: 

 

If the work order was opened automatically, releasing it prevents its deletion by the Production Planning or MRP programs, which will regard it as future inventory (work orders opened manually are not deleted by these programs even if they have not been released).
