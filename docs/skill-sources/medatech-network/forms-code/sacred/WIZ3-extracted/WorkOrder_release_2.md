# To release a work order:

 

 1 .  Enter the Work Orders form and retrieve the desired work order. 
 

 2 .  Click the Details tab and check the Release column. 
 
## Notes:

 

 ·        The status of the work order changes automatically to Released . 
 

 ·        For any work order flagged as opened automatically (i.e., by MRP or production planning), the flag is removed once the work order is released (and you leave the line). 
 

 ·        The kit list appears automatically in the Kit List sub-level form. Click to check and/or revise the kit list. 
 

 ·        The routing appear automatically in the Routing for the Work Order sub-level form. Click to check and/or revise the routing. 
 

 ·        Click to return to the main screen.
