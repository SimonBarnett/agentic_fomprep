 5 . Issue of required materials to the kit: In order to begin production, you need to issue the required kit components to the plant floor. If other materials are required, they will be taken from the general plant-floor inventory or issued manually during production reporting.
 Note: Click for a detailed explanation of types of issues. 
 

 6 . Work plan: Create a work plan by Direct Activation from the work order, based on time and labor parameters used to run MRP for Manufacturers . The work plan starts with your production deadline and schedules your routing operations in reverse order, resulting in a recommended start date. Results can be displayed graphically in a Gantt chart and updated as needed.
 Tip: Run the MRP for Manufacturers Wizard to learn how MRP can create a general work plan based on all open work orders in a specified period. 
 

 7 . Production reporting: Reports of execution of an operation on parts in the work order record the quantity of parts that have undergone the operation (as well as manual issues, if needed). 
 

 8 . Closing the work order: The work order may be closed upon completion of the last production report, or it can be closed manually.
