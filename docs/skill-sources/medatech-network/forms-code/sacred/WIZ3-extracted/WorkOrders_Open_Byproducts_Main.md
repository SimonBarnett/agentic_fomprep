# Opening Work Orders for Byproducts

 

When manufacturing a part with the Byprod routing, it is necessary to open work orders for the source part as well as for each of its resulting byproducts: 
 

 ·        When production is planned by MRP, all the necessary work orders are opened automatically, and the source part appears as a child part of each byproduct in its kit list. 
 

 ·        If you are opening work orders manually, you can use the Prepare Byproduct Work Orders program provided as a Direct Activation in the Work Orders form. 
 
## Note:

 

For instructions regarding the definition of byproducts, run the Factory Modelling Wizard .
