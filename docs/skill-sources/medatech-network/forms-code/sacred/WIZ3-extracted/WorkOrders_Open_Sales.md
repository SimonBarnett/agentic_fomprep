# Opening a Work Order for a Sales Order Item

 

If you want to open a work order for a specific sales order item (without running MRP), you can do so directly from the sales order in question by running the appropriate Direct Activation program. 
 
# Before you begin:

 

Enter the Assign WO/Lot Templates to Parts form. Make sure the part for which you want to open a work order is assigned a work order template and is flagged in the Open Automatically column. 
 
## To open a work order for a sales order item:

 

 1 .  Enter the Sales Orders form, retrieve the desired order and move to the Order Items sub-level form. 
 

 2 .  Move to the line for the order item in question and select Open Work Order for Order Item from the list of Direct Activations.
 Note: You can also indicate whether to release the work order immediately and whether to base its kit list on the bill of materials defined for the order item. 
 
## Note:

 

To view the open work order, retrieve the ordered part in the Work Orders form.
