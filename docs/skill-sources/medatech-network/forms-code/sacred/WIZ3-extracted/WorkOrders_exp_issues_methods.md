# Types of Issues

 
## Issue to Kits

 

When you issue to a kit, the entire issued quantity is intended for a specific work order, and is not available for other work orders. This method is useful when issuing relatively expensive parts that you want to keep track of. 
 

Examples of this type of part: electronic components (e.g., processors, memory chips). 
 
## Bulk Issue

 

Bulk parts are not intended for a specific work order, but are issued to general floor inventory for use in all work orders that require the part. If you work with MRP, the required quantities are calculated by the Issues Plan. Otherwise, they are calculated either according to the total quantities required for all released and open work orders, or according to the minimum floor stock defined for the child. 
 

Examples of this type of part: screws, paint, electrical wire. 
 
## Manual Issues

 

Manual issues are recorded during production reporting. In this case, the required parts are not issued in advance, in preparation for production, but rather are drawn from inventory during the production process. This method is generally used to issue particularly expensive parts or parts that require special storage conditions that are not available on the plant floor. 
 

Examples of this type of part: diamonds, gold.
