# Recording a Kit List

 

Upon release of the work order, the system automatically lists the parts required for production, according to the BOM of the part to be produced (and if BOM revisions are maintained for the part, according to the appropriate BOM revision). The kit list includes the required quantity of each part, its issue type (to a kit or in bulk) and the operation at which it enters its parent part. 
 

You can revise the kit list by adding or deleting lines, or changing quantities.
