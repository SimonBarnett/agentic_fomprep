 7 .  In the Issued to Kit column, a check mark indicates that the part is defined for issues to kits. You cannot change this setting (i.e., to issue in bulk); however, you can flag a part that is issued in bulk, and it will be issued to the kit for this particular work order. 
 Note: Bulk parts that are issued to a kit are still treated as bulk inventory, such that any production report can reduce their balance, even if they were issued to another work order. 
 

 8 .  If you do not want to allow the use of alternates for a given child part in this particular work order, check the Prevent Use of Alt ' s column (in this case, even if the inventory balance is smaller than the required amount, the system will not open an issue line for the alternate part).
 Note: This column is only effective when you have set the UsePartAlt constant to allow the use of alternate parts in general. If you set this constant to 0 , alternate parts are never used and you do not need this flag. 
 

 9 .  A check mark appears automatically in the Extra Issue column in each line that was added manually. Delete it, if necessary. Explanation. 
 

 10 .  If you have a brief remark regarding a specific part, record it in the Remark column. These remarks will appear in the kit list printout. 
 

 11 .  Return to the Work Orders upper-level form and revise the status and assigned user, as needed (in the Details tab).
