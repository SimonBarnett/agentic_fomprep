# Opening a Work Order

 

If you want to perform rework on a part, you can open a new work order and flag it as rework (before reporting production). Click for more information. 
 
## To open a work order:

 

 1 .  Enter the Work Orders form. 
 Note: At any point in the following process, you can transfer handling of the work order to another employee, by specifying his/her username in the Assigned to column (in the Details tab). 
 

 2 .  In the Part Number column, record the number of the part to be produced. 
 

 3 .  If the part is linked to a work order numeration template, the Work Order number appears automatically. If not, record a number manually.
 Note: Click to link the part to a numeration template, which will affect any work orders opened for the part in the future. 
 

 4 .  In the Work Order Desc. column, a description of the part to be produced appears automatically. Revise it, if necessary.
