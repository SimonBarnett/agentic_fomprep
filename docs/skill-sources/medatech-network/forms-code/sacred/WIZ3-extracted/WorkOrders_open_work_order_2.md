 5 .  In the Work Order Qty column, record the quantity of parts to be produced in the current work order.
 Note: Quantity is measured in the factory unit defined for the part, as displayed in the Unit column. 
 

 6 .  Click the Prod. Data tab. If you are maintaining revisions of this part and/or its BOM, the Part Revision and BOM Revision currently in effect appear automatically when the work order is opened. If a new revision is scheduled to go into effect prior to the Begin Production date, it will replace the current one automatically when you specify the date. In any case, revisions may be changed.
 Notes: 
 

 ·              BOM revisions are not updated unless the future revision is fully authorized when you open the work order. If the revision is authorized at a later date and goes into effect before production begins, you will need to update the work order manually. 
 

 ·              The BOM revision assigned to the work order determines the kit list that will be compiled when the work order is released. 
 

 7 .  In the Begin Production column, record the date and time at which execution of the work order is to begin. 
 

 8 .  In the Routing column, the routing assigned to the part (in the Parts form) appears automatically. Revise it, if necessary. 
 

 9 .  Click the Project tab. If the work order is for a project or a project activity, record the Project Number or the WBS Code , respectively.
