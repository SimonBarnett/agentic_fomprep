Work Orders - Opening a Work Order.3 
 
 
- 
 
 
 

 10 .  If the work order is opened for the purpose of filling one or more sales orders, do one of the following: 
 

 ·              For a single sales order, record the order number in the Order column (the number of the relevant line in the order appears automatically). 
 

 ·              For multiple orders, enter the Sales Orders Tied to Work Order sub-level form and record the relevant order numbers. 
 

 11 .  If you want to attach a document or file to the current work order, use the Attachments sub-level form. 
 

 12 .  If you want to record remarks that will appear in the work order printout, record them in the Work Orders - Remarks sub-level form. 
 

 13 .  Return to the Work Orders upper-level form and revise the status and assigned user, as needed (in the Details tab). 
 
## Notes: 

 

 ·        Click to release the work order. 
 

 ·        Click to return to the main screen.
