# Printing a Work Order

 

The work order printout contains the work order details (e.g., part number, start date), routing, kit list, any recorded remarks, production reports, and more. Additional reports allow you to print out the documents attached to the work order, the parts in the kit list, a list of any child parts that have been assigned designations and the work plan. 
 
## To obtain printouts:

 

 1 .  Enter the Work Orders form and retrieve the desired work order. 
 

 2 .  To print the work order or its kit list, select Print Work Order from the list of Direct Activations , and select the appropriate print format.
 Note: If the current status of the work order has been assigned a “Status Once Printed”, the status of the printed work order is updated automatically. 
 

 3 .  To print related documents, select Print Document Set for WorkOrder from the list of Direct Activations . 
 

 4 .  To print a list of child parts with designations, select Designat'n of Components in Assm from the list of Direct Activations . 
 

 5 .  To view, print and/or update the work plan as a Gantt chart, run the Work Plan - Gantt Chart program. 
 
## Notes:

 

 ·        The work order printout contains empty columns to be filled in manually by factory workers. These columns are not updated by production reports for the work order (for example, the Completed column does not display the quantity of completed parts that have already been reported for that work order). 
 

 ·        To print multiple work orders, run the Print Work Order report. 
 

 ·        To print multiple kit lists, run the Kit List for Work Order report.
