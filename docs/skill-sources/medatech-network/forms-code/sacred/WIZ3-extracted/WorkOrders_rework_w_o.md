# Rework

 

You can open a work order for rework on a part after it has already completed its production routing, in order to document the rework operations. 
 

The system will ignore all production reports for work orders flagged as rework; that is, the Backflush program will not reduce child part inventory or record transactions of completed production on the basis of these reports. The work order will receive a cost of zero, and will not affect costing results.
