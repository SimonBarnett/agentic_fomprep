# Work Order Routing

 

Upon release of the work order, the assigned routing appears automatically in the Routing for the Work Order sub-level form. The Release operation appears first, followed by the rest of the operations in the part's routing, in their proper sequence. If necessary, you can change the routing for the current work order (without affecting other work orders or the standard routing). 
 
## To check and/or revise the routing:

 

 1 .  Enter the Work Orders form and retrieve the desired work order. 
 

 2 .  Enter the Routing for the Work Order sub-level form. The list of production operations defined for the routing are displayed. 
 

 3 .  Make any necessary changes to the current work order.
 Notes: 
 

 ·              To replace or delete an operation to which child parts are issued, you must first change the For Operation recorded in the Kit List sub-level form, and only then change the routing. 
 

 ·              You cannot revise an operation for which production has already been reported. You must first delete the production report; you can then revise the operation and report again. For information about deleting production reports, see the Production Report Wizard . 
 

 4 .  To check and/or revise the engineering data for routing operations, use the Engineering Data sub-level form. 
 

 5 .  To check and/or revise the alternate operations defined for a routing operation, use the Alternate Operations for the WO sub-level form.
