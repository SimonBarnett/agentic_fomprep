# Defining the Part's Issue Type

 

For each part, you can define the default method of issue to the plant floor. You can determine whether a given part is always issued to a kit (the system default), issued in bulk to the plant floor or issued manually during production. 
 

A part that is usually issued in bulk can be flagged for issue to a kit for a specific work order. However, you cannot change the issue type of a part that is defined as issued to kits. 
 
## To define the issue type for a part:

 

 1 .  Enter the Parts form and retrieve all parts that are to be issued. 
 

 2 .  Do one of the following: 
 

 ·              If the part is to be issued to a kit, make sure a check mark appears in the Issued to Kits column. 
 

 ·              If the part is to be issued in bulk, remove the check mark. 
 

 ·              If the part is to be issued manually, remove the check in the Issued to Kits column and flag the Manual Issue column.
