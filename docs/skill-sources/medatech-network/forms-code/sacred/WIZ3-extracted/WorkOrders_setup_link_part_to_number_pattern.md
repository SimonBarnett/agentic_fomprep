# Linking a Work Order Template to a Part

 

Use work order numeration templates to automatically number all work orders for a certain part in a specific format. 
 
## Note:

 

Click to define a new numeration template. 
 
## To link a work order numeration template to a part:

 

 1 .  Enter the Assign WO/Lot Templates to Parts form and retrieve the desired part. 
 

 2 .  Choose the appropriate numeration template.
