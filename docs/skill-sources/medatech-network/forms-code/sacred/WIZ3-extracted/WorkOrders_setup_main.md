# Setting Up Work Orders

 
## Before you begin working with work orders, you must define:

 

 Numeration templates for work orders 
 

 How the system works with alternate parts 
 

 Business processes (BPM) for work orders (statuses) 
 

 The issuing warehouse for the plant floor (optional) 
 
## To each processed part, you must assign:

 

 A work order numeration template 
 

 Shelf life 
 
## To each child part, you must assign:

 

 Type of issue 
 

 Alternate parts
