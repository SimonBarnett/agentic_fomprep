# Setting Up Business Processes for Work Orders

 

You set up business processes by defining statuses in a BPM flow chart. 
 

There are several predefined statuses, to which you can add as many statuses as you like. You can define paths between these statuses, create work flow rules and set status properties. 
 
## To use the flow chart:

 

 ·        Run the BPM Flow Chart-Work Orders program. 
 
## Notes: 

 

 ·        To close a work order automatically once the last operation has been reported for the work order quantity, flag the Close Work Order column for the predefined Last Report status. 
 

 ·        When a work order has a Frozen status, you are warned if you issue parts or report production for it. 
 

 ·        You can add more statuses – or re-define them – later, as the need arises. 
 

 ·        To view the defined properties of all statuses together, enter the Statuses for Work Orders form. 
 

 ·        For detailed instructions on using BPM flow charts, see the User Interface Guide .
