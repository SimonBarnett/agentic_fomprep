# Defining the Part's Shelf Life

 

In combination with each work order's start date, the shelf life that you define for each part determines the expiration date of work orders opened for that part. 
 
## To define a part's shelf life:

 

 1 .  Enter the Inventory Parameters for Parts form and retrieve the desired part. 
 

 2 .  Click the Inventory tab. In the Days in Effect and Months in Effect columns, record the shelf life (calculated by combining the values in these columns).
