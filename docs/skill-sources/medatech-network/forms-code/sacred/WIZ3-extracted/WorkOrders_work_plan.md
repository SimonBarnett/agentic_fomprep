# Creating a Work Plan

 

Work plans for specific work orders are based on the same time and labor data required to run MRP. Before you begin, run the MRP for Manufacturers Wizard and perform the necessary setups. 
 
## To create an individual work plan:

 

 1 .  Enter the Work Orders form and retrieve the work order. 
 

 2 .  Click on the Prod. Data tab and make sure you have specified an End Production date. 
 

 3 .  Select Create Work Plan for Work Order from the list of Direct Activations . 
 

 4 .  To view results, enter the Work Plan for Work Order sub-level form. 
 
## Notes:

 

 ·        If necessary, the work order's Begin Production date will be updated to match the work plan. 
 

 ·        Click to view/update the work plan in a Gantt chart . 
 

 ·        You can run MRP to create a general work plan for all open work orders. For more information, run the MRP for Manufacturers Wizard .
