# Performing Automatic Reconciliation

 

The account reconciliation program automatically reconciles the entries in the worksheet, according to a predefined reconciliation code . The program enumerates the entry items, so that items that are reconciled with each other receive the same number. A zero (0) indicates that the item has not been reconciled. 
 

After the program is run, all reconciliations must be checked and approved. 
 
## To perform automatic reconciliation:

 

 1 .  Run the Prepare for Reconciliation program.
 Notes : 
 

 ·              If you get an error message that there are pending reconciliations in the worksheet, click to take care of them. 
 

 ·              If you work on a cash basis and wish to reconcile pro forma entries, select the A/R Ledger in the first input screen and make sure the Pro Forma Entries column is flagged in the second input screen. 
 

 2 .  Run the Automatic Reconciliation program.
