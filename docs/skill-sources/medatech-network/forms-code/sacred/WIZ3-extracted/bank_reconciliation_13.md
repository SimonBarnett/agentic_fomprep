# Viewing the Progress of Reconciliations with a Recorded Bank Statement

 

 Priority provides a variety of reports that allow you to view different cross-sections of reconciled bank transactions, as well as items that have not yet been reconciled: 
 
## To view all journal entries and bank statement items that have not been reconciled up to a given date:

 

 ·        Run the Unreconciled Entries (Banks) report. 
 
## To view all journal entries pending reconciliation:

 

 ·        Run the Pending Reconciliations report. 
 
## To view all journal entries that are unreconciled or pending reconciliation:

 

 ·        Run the Unrecon'd Entries&Pending Recons report. 
 
## To view reconciled journal entries by date:

 

 ·        Run the Final Reconciliations by Date report. 
 
## To view reconciled journal entries by number:

 

 ·        Run the Final Reconciliations by Number report. 
 
## To view problematic reconciliations:

 

 ·        Run the Check Reconciliations for Date report.
 Note: Problematic reconciliations are those in which one transaction falls before a specified date (e.g., the date you produced a balance sheet) and another transaction falls after that date.
