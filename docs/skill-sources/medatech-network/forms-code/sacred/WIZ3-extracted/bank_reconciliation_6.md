# Reconciling a Recorded Bank Statement with Journal Entries

 

Once you have recorded any recent bank statements received from a given bank in Priority , you can run a program that provisionally reconciles a given bank account against journal entries, or reconcile the account manually. In either case, reconciliation is not final until you run the Finalize Reconciliations program. 
 
## Before you begin

 

 ·        For dual-currency users: Run the Cash Postdated Checks program. 
 

 ·        Run the Prepare for Reconciliation program. 
 Note : Click if you get an error message that there are pending reconciliations in the worksheet.
