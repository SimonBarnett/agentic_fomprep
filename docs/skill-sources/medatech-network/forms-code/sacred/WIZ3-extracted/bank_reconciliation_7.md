# To reconcile the account automatically:

 

 ·        Run the Automatic Reconciliation program. 
 
## To review the automatic reconciliation:

 

 1 .  Run the Pending Reconciliations report. 
 

 2 .  Review the report to make sure each reconciliation is correct. 
 

 Note: You can define a different reconciliation method for each bank account. If an automatic reconciliation has been performed that is inappropriate for a given account (e.g., when the default reconciliation method is incompatible with a new account), cancel the reconciliation and do one of the following: 
 

 ·      Redo the reconciliation using a different code. 
 

 ·      Revise the default reconciliation code . 
 

 ·      Create a new code. 
 

 3 .  Remove any incorrect reconciliations by doing the following: 
 

 ·      Enter the Reconciliation Worksheet form. Replace the reconciliation number with 0, in all the involved lines. 
 

 Tip: If many reconciliations are incorrect, cancel them in a batch . 
 

 4 .  Make a note of the last reconciliation number that was assigned. 
 

 5 .  When you are finished reviewing, do not close the Reconciliation Worksheet .
