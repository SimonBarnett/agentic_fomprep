# Reconciling a Paper Statement with Journal Entries

 

If bank statements have not been recorded in Priority , you can still manually reconcile journal entries with the paper statement received from the bank, if desired. 
 

 Note: Reconciliation is not final until you run the Finalize Recon. w/Paper Statemt program. 
 
## Before you begin

 

 ·        For dual-currency users: Run the Cash Postdated Checks program. 
 

 ·        Run the Prep for Recon. w/Paper Statemt program. 
 Note : This program will overwrite any unreconciled entries currently loaded into the Reconcil Work Area-Paper Statemt.
