# To cancel reconciliations after they have been finalized:

 

 1 .  Enter the Reconcil Work Area-Paper Statemt and move to the Reconciled Entries-Paper Statemt sub-level form to view all journal entries that have been reconciled with the current bank statement. 
 

 2 .  Flag the entries for which you want to cancel reconciliation with the current bank statement (in the Cancel column). 
 

 3 .  Return to the upper-level form and select Cancel Reconcil w/Paper Statemt from the list of Direct Activations to cancel the reconciliation of all flagged items. As a result, the amount in the ClosingBal in Ledger column is updated automatically.
