# Viewing the Progress of Reconciliations with a Paper Statement

 

 Priority provides a variety of reports that allow you to view details of paper statements and the journal entries with which they were reconciled, as well as items that have not yet been reconciled: 
 
## To view all journal entries and bank statement items that have not been reconciled up to a given date:

 

 ·        Run the Unreconciled Entries (Banks) report. 
 
## To view all journal entries that have been loaded into the Reconcil Work Area-Paper Statemt:

 

 ·        Run the Entries in Reconcil Work Area report. 
 
## To print an internal copy of paper statements that have been reconciled with internal entries:

 

 ·        Run the Reconciled Paper Statements report.
