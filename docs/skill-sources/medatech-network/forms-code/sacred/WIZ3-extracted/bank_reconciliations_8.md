# Clearing Pending Reconciliations from the Worksheet

 

Pending reconciliations result from a bank reconciliation you or someone else left unfinished. You must either finalize (i.e., accept) or cancel them. 
 

 1 .  Enter the Reconciliation Worksheet . Retrieve all records having a number greater than 0 in the Reconciliation Num . column. 
 

 2 .  Review each pending reconciliation and decide whether to cancel it or finalize it. 
 

 3 .  After reviewing, cancel undesired reconciliations. Do one of the following: 
 

 ·      Run the Cancel Pending Reconcil'ns program, using the appropriate reconciliation numbers as input. OR 
 

 ·      Cancel reconciliations manually in the Reconciliation Worksheet by replacing reconciliation numbers with 0 in all the involved lines. 
 

 4 .  Run the Finalize Reconciliations program to finalize the remaining reconciliations.
