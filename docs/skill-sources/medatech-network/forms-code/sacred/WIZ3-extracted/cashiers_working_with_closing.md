# Closing a Cashier

 

When working with cashiers, it is recommended that you close each cashier on a regular basis (e.g., when you are finished working with it for the day). This ensures that no new transactions to or from this cashier are dated prior to the closing. 
 
## To close a cashier:

 

 1 .  Enter the Cashiers form. 
 

 2 .  Move to the line for the cashier in question and indicate the Closing Date .
