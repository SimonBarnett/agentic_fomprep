# Recording Postdated Checks

 

In the Priority dual-currency package, postdated checks are deposited into a special account defined for such checks in each bank. Upon the redemption date of a postdated check, you can run a program that records the payment in the corresponding checking account. 
 
## Before you begin

 

 1 .  Enter the Bank Accounts form and retrieve the desired bank account. 
 

 2 .  Do one of the following: 
 

 ·      Flag the Post dated as 1 Sum column if you want the sum of all postdated check payments due on a given day to be recorded as a single journal entry item. 
 

 ·      Leave the column empty if you want each check to appear in a separate line. 
 
## Note:

 

Some banks record all checks redeemed on a given day in a single line in the bank statement, while others record a separate line for each check. In order to reconcile your system bank accounts with the corresponding bank statements, make sure that each account follows the same method as its bank. 
 
## To record postdated checks in the ledger:

 

 ·        Run the Cash Postdated Checks program. 
 
## Note: 

 

The program records regular checks as well as postdated checks.
