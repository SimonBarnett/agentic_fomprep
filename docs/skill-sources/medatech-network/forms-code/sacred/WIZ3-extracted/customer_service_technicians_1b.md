# Technicians for Service Calls

 

You have several options for handling the assignment of technicians to service calls. Do one of the following: 
 

 Indicate which technicians are responsible for repairing which part families. This is useful when your company employs many technicians who service many different kinds of parts. You can even restrict technicians to service calls involving their part families. OR 
 

 Assign default technicians to each customer, zone or part family. This is useful when your company employs only a few technicians. 
 
## Note:

 

Click if you do not want to set up either of the above options (i.e., you plan to manually assign technicians when service calls are opened).
