# Using the Default Code

 

 1 .  In the Reconciliation Codes form, move to the line containing Default bank reconciliation . 
 

 2 .  Move to the Itemized Code sub-level form, which contains the predefined reconciliation methods that comprise the code. The methods are listed in the order in which they are used by the automatic reconciliation program. If this order is not satisfactory, or you want to remove or add a method, click to create your own reconciliation code. 
 

 Tip: You can read explanations of the reconciliation methods in the Reconciliation Methods form. 
 

 3 .  For each method, review the following properties and make any desired changes: 
 

 ·              Range in Days 
 

 ·              Num Chars to Compare 
 

 ·              Permitted Variance . You should use 0 . 
 

 ·              Max Number of Items . You should use 2 . 
 

 ·              Force Bnk/Entry Rec . A check mark indicates that reconciliation is restricted to items appearing on opposite sides of the balance sheet. 
 

 Tip: If you need another reconciliation code having the default order but different properties, create your own code. Example
