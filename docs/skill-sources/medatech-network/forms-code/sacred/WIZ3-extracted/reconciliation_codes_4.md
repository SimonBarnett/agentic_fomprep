# Creating Your Own Reconciliation Code

 

You can create as many reconciliation codes as you need. For instance, if you work with different banks, you may need a different code for each bank. 
 

 1 .  Enter the Reconciliation Codes form. 
 

 2 .  On a new line, fill in the Reconcil ' n Code and Code Description columns. In the Type of Reconcil ' n column, select B . 
 

 3 .  Enter the sub-level form. List, in order, the methods you want the program to use. In other words: In the first line, select the method you want the program to use first; in the second line, select the method you want to use second; and so on. 
 

 Tip: You can read explanations of the methods in the Reconciliation Methods form.
