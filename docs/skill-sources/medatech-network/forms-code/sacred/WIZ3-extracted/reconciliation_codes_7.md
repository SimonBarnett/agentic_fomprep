# Using the Default Code

 

 1 .  In the Reconciliation Codes form, move to the line containing Default account reconciliation . 
 

 2 .  Move to the sub-level form, which contains the predefined reconciliation methods that comprise the code. The methods are listed in the order in which they are used by the automatic reconciliation program. If this order is not satisfactory, or you want to remove or add a method, click to create your own reconciliation code. 
 

 Tip: You can read explanations of the reconciliation methods in the Reconciliation Methods form. 
 

 3 .  For each method, review the following properties and make any desired changes: 
 

 ·              Range in Days 
 

 ·              Num Chars to Compare 
 

 ·              Permitted Variance . 
 

 ·              Max Number of Items . 
 

 Tip: If you need another code having the default order but different properties, create your own code.
