# Preparing an Invoice for a Service Call

 

 Priority allows you to prepare a multi-shipment invoice for a service call automatically. 
 
## Note:

 

If you work on a cash basis, you can automatically prepare a pro forma invoice for a service call. For more details, run the Cash-Based Accounting Wizard . 
 
## If you wish to view unbilled service calls (as well as shipments and returns that have not been billed/credited), you have several options: 

 

 ·        To view document totals by customer number, run the Unbilled Docs. by Customer No. report. 
 

 ·        To view part data for individual service calls by customer, run the Unbilled Docs.-Details per Cust. report. 
 

 ·        To view service call data by customer name, run the Unbilled Docs. by Customer Name report. 
 

 ·        To view service call data by document number, run the Unbilled Docs. by Document No. report. 
 

 ·        To view part data for individual service calls, run the Unbilled Docs.-Details per Doc. report. 
 

 ·        To view data per sales rep, run the Unbilled Docs. by Sales Rep report. 
 

 ·        To view service calls that have not been fully billed, run the Partially Billed Documents report.
