# Maintaining FAQs for Service Calls

 

You can record your customers' most frequently asked questions (FAQs) and display them in an Explorer-style window. Furthermore, you can create an FAQ from within a service call, by copying the call's malfunction details directly into an FAQ answer field. 
 
## Note for dual-currency users:

 

If you work in a language other than English and want to create FAQs in English, be sure to record menu titles, questions and answers in English, in the provided columns and forms. 
 
## What do you want to do?

 

 Set up business processes (BPM) for FAQ s (define statuses) 
 

 Record a question manually 
 

 Record a question from within a service call 
 

 Link menus to the FAQ tree 
 

 Run FAQ reports
