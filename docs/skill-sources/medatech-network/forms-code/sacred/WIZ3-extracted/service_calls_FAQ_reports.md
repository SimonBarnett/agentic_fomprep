# FAQ Reports

 

Run the following reports to view and maintain FAQ data: 
 

 ·        FAQ 
 

This report displays the main FAQ tree in an Explorer-style window. Run it to view the various questions and answers in their designated menus and sub-menus. 
 

 Tip: To find an FAQ on a desired topic, specify a key word or phrase in the Search box and click GO . 
 

 ·        Questions Without Answers 
 

Run this report to display any questions for which no answers have been recorded. 
 

 ·        Missing Menu Links 
 

Run this report to display any questions that have not been linked to a menu, as well as any menus that have not been linked to the main FAQ tree.
