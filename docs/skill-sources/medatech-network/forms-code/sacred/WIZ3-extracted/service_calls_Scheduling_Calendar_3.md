# Tips (continued)

 

 ·        To access a scheduled call itself, right-click its time slot and select Zoom . If necessary, change its status (e.g., to Active ) and/or revise the Agreed Start Date . In the Authorized By column, specify the person at the customer site who authorized a late start date.
 Note: This person must be one of the customer's contacts. 
 

 ·        To print a summary of the scheduled call, right-click its time slot and select Print Service Call Form . 
 

 ·        Additional function keys: 
 

 ·      F4 – change view (toggles between horizontal display of hours, vertical display of hours and Gantt chart). 
 

 ·      Ctrl+F11 – refresh screen. 
 

 ·      Tab/Shift+Tab – move to next/previous scheduled appointment. 
 

 ·      Ctrl+ Del – delete scheduled call. 
 
## Notes: 

 

 ·        The Technician Scheduling Calendar allows you to select technicians by group. On how to set up groups for technicians, run the Service Setup Wizard . 
 

 ·        The CSrvCallTask constant determines whether the scheduling of calls is recorded in the Scheduling tab of the Service Calls form or in its sub-level form, Tasks for Document . The latter option allows you to schedule several technicians on different dates and/or times for the same service call. 
 

 ·        You will only be able to revise service calls. All other appointments are read-only. 
 

 ·        For an explanation of all Calendar options (on the Top Bar and Tool Tray), see the User Interface Guide . 
 

 ·        Click to return to the main screen .
