# To open a follow-up service call:

 

 1 .  In the Service Calls form, click the References tab, move to the Follow-up of Call and retrieve the original service call.
 Tip: To see whether any follow-up calls have already been recorded for this call, enter the Follow-up Calls sub-level form. The form displays the call number, its status, and information about the malfunction. For more details about the call, you can zoom from the Call Number column to another copy of the Service Calls form. 
 

 2 .  Select Open Follow-up Call from the list of Direct Activations . You are informed of the number of the follow-up call.
