# Linking Menus to the FAQ Tree

 

The FAQ Menu form allows you to define menus and sub-menus and link them to the main FAQ tree displayed in the FAQ report. You can either open a parent menu and select its sub-menus, or open a menu and assign it to a parent (or both). You can also link questions to the menu, if you have not already done so. 
 
## To link an FAQ menu:

 

 1 .  Enter the FAQ Menu form and retrieve the desired menu. The initial Status appears automatically; revise as necessary. 
 

 2 .  To link questions to this menu, enter the Questions in Menu sub-level form and select the desired questions.
 Note: Only questions flagged as Approved will appear in the FAQ report. 
 

 3 .  To link sub-menus to this menu, enter the Sub-menus sub-level form and select the desired menus. 
 

 4 .  To link this menu to one or more parent menus, enter the Menu Link sub-level form and select the desired menus.
