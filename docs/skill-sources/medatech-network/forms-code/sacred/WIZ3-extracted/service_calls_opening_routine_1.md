# Routine Servicing

 

When a serialized part is installed at the customer site, Priority automatically calculates the date of the first required servicing, based on the servicing requirements that you define for that part. Similarly, once a service call is reported for servicing of the part, the system calculates the next required servicing. 
 

 Priority also allows you to open routine service calls for the serialized part, using the Prepare Servicing Plan program. This program opens service calls for designated serialized parts, based on their particular servicing requirements and the date when each part was last serviced. Such calls are opened with the status that is flagged for servicing plans (in the Statuses for Service Calls form). 
 

 Before you begin: 
 

 1 .  Enter the Catalogue of Parts w/Serial Nos. form to define servicing requirements for each serialized part for which you want to schedule routine service calls. 
 

 2 .  In the Servicing Requirements of Item sub-level form, make sure that all types of servicing required by this serialized part are listed. All servicing packages associated with the part, as well as the frequency (in days) with which the part requires each type of servicing, are copied automatically from the Servicing for Part sub-level of the Service Parameters for Part form, but these may be revised. 
 

 3 .  Indicate the Skill required to perform this type of servicing on the serialized part. 
 

 4 .  Make sure that the correct date appears in the Last Serviced On column. This is filled in automatically, based on the latest service call reported for this part and servicing package, but may be revised. 
 

 5 .  Select each day of the week on which this type of servicing can be performed.
