# Printing Price Quotes

 
## To print a single price quote:

 

 1 .  Enter the Service Calls form and retrieve the call in question. 
 

 2 .  Select Print Service Quote from the list of Direct Activations . 
 
## To print several quotes:

 

 ·        Run the Print Service Quote report.
