# Reporting Service Calls

 

Click to report routine servicing. 
 
## After the service call is completed, you need to report the details of the repair that was carried out, including: 

 

 ·        The type of malfunction 
 

 ·        How the malfunction was resolved 
 

 ·        Parts used for the call (including returns) 
 

 ·        Labor invested in the call (including travel time). 
 

 ·        Purchase invoices from subcontractors 
 
## Notes:

 

 ·        Run the Print Service Call Form report to print a form for the service call (to be filled in manually by the technician). 
 

 ·        D ual-currency users: If you work in a language other than English, run the Print Service Call-Foreign Lang. report to print a form for the service call in English. 
 

 ·        If the entire part being serviced is returned to the factory for repair, this is recorded in a separate customer return document. For details, see the Serial Numbers Wizard .
