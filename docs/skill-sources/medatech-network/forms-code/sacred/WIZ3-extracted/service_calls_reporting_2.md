# Reporting the Malfunction and Its Resolution

 

 1 .  Enter the Service Calls form and retrieve the service call. 
 

 2 .  Click the Service Info tab and select a Malfunction and its Resolution. 
 

 Tips: 
 

 ·      To add a new malfunction code, use the Malfunction Codes form. 
 

 ·      If you are unsure about the malfunction code, select one and then select Malfunction History from the list of Direct Activations . You will see all earlier calls in which this malfunction was reported. If necessary, try again with another code. 
 

 ·      To add a new resolution code, use the Resolution Codes form. 
 

 3 .  You can add any remarks about the malfunction in the Details of Malfunction sub-level form. These remarks are added to the information displayed in the Malfunction History report, for future reference and analysis regarding the malfunction.
