# Reporting Part Usage 

 

You need to report the parts used during the service call (e.g., replacement parts, machine oil). This information is used to determine charges for the call and to update warehouse balances for these parts. 
 

Click if the service call is based on an order. 
 
## To report part usage:

 

 1 .  Make sure the data appearing in the Spare Pts Warehouse columns is correct. 
 Note: If it is correct for some parts but not for others, record what is correct for the greatest number of parts. You will change the information for individual parts in the next screen.
