Service Calls - Charging for Travel Time 
 
 
- 
 
 
 
# To charge for travel time:

 

 1 .  In the Service Report-Labor form, flag the Charge for Travel Time column. The default time set up for this customer appears in the Travel Tm to Charge column. 
 Note: See the Service Setup Wizard for more details. 
 

 2 .  By flagging the Charge for Travel Time column, an item for mileage (called Miles ) is opened automatically in the Service Report-Parts form. The default number of miles set up for this customer appears as the actual quantity.
 Notes: 
 

 ·      To charge for travel time but not for miles, flag the Miles line as not billable. 
 

 ·      If you flagged more than one line in the Service Report-Labor form, multiple lines are opened for miles. If the technicians traveled together and you only want to charge the customer once for mileage, delete the additional line(s). 
 

 3 .  If you work with projects, click to link the charges to a project or project activity.
