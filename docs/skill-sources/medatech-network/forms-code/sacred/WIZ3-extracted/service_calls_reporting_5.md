# Closing the Call

 

 1 .  Check that all data in the Service Report-Parts and Service Report-Labor sub-level forms are correct and final. 
 

 2 .  Return to the upper-level form and make sure prices, discounts and the tax code are correct. 
 

 3 .  Revise the call's status to Closed . 
 
## Tip:

 

If an error is discovered in a closed service call, select Reopen Document from the list of Direct Activations . You can reopen the call as long as an invoice has not yet been prepared for it.
