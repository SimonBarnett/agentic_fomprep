# Warning About Reporting Service Calls Based on Orders

 

If you report actual quantities of parts used in the service call, the following happens: 
 

 ·        The order balance is reduced 
 

 ·        The order is closed 
 

 ·        Warehouse balances are updated 
 

Therefore, do not record both the service call and a customer shipment.
