# Reporting Returned Component Parts

 

If the service call involved the return of any component parts, you need to report the return. 
 
## Notes: 

 

 ·        This is instead of recording a customer return document. 
 

 ·        If the entire part being serviced is returned to the factory for repair, that transaction is recorded in a separate customer return document. For details, see the Serial Numbers Wizard . 
 
## To report the return of component parts:

 

 1 .  Return to the upper-level form. If the RMA Number column is empty, select Assign New RMA Number from the list of Direct Activations . The newly assigned RMA number appears. 
 

 2 .  Enter the Service Report-Parts sub-level form. Record each returned component and the date it was returned. 
 

 3 .  In the Billable column, remove the check mark. Specify a billing exemption type (e.g., Returns ).
 Tip: To add a new exemption type, use the Types of Billing Exemptions form. 
 

 4 .  If desired, change the part status to Reject . 
 

 5 .  Specify the warehouse and bin to which the part is being returned. 
 

 6 .  In the Actual Quantity column, specify a negative quantity.
