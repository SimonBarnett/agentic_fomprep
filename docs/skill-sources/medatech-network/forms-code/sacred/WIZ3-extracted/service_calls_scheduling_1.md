# Scheduling Service Calls 

 

Once you are ready to assign one or more technicians to a service call and to set a date and time: 
 

 ·        You can schedule the call via the Technician Scheduling Calendar . 
 

 ·        You can schedule technicians manually within the service call. 
 

The first option also allows you to view and change assignments to calls that have already been scheduled, and provides information on the technicians' existing appointments and regular work hours. 
 

The second option is useful when you know in advance which technician you need to assign and at what date and time. 
 
## Note:

 

Regardless of the method used, any scheduled service call automatically opens a task for all assigned technicians and is automatically added to their calendars.
