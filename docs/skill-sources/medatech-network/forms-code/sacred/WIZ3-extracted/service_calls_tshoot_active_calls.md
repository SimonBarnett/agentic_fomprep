# Keeping Track of Active Service Calls

 

Enter the Active Service Calls form to view all service calls that are still being processed (i.e., that are flagged in the Active column of the Service Calls form). 
 

Calls that are flagged in the Exception column have exceeded the time limit assigned to the current status. They are displayed first, followed by service calls with the most urgent status. 
 

It is highly recommended either to color-code service calls according to their status, or to designate a color for calls flagged as exceptions. 
 
## Notes:

 

 ·        To define statuses for service calls, run the Service Setup Wizard . 
 

 ·        For more information regarding color-coding, see the User Interface Guide .
