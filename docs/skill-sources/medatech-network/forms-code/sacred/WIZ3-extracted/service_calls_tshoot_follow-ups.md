# To view follow-up calls:

 

 ·        In the Service Calls form, retrieve the call in question and then enter the Follow-up Calls sub-level form. 
 
## Note:

 

If the call you have retrieved is itself a follow-up, any other follow-up calls based on the same original call are displayed instead.
