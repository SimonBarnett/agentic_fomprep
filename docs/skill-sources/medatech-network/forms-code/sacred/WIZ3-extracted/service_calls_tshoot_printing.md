# Printing a Service Call

 

 To print a single service call: 
 

 1 .  Enter the Service Calls form and retrieve the call. 
 

 2 .  Select Print Service Call Form from the list of Direct Activations . 
 
## To print several service calls:

 

 ·        Run the Print Service Call Form report.
