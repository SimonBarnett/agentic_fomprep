# Viewing Data for Returned Parts

 
## To view a list of RMA documents:

 

 ·        Use the Return Material Authoriz. (RMA) form. 
 
## To view a list of the service calls related to a given RMA document (and their required parts): 

 

 ·        Run the RMA Log report. 
 
## To view a list of all parts replaced at a given customer (per service call):

 

 ·        Run the Parts Replaced report. 
 
## To view a list of parts that were replaced but not returned, or returned but not replaced:

 

 ·        Run the Surplus/Shortage of Issued Parts report. 
 
## Note:

 

Run the BPM Flow Chart-RMAs program to define and maintain statuses for RMA documents. Statuses can be viewed in the Statuses for RMAs form.
