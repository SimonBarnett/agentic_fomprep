# Viewing the Service History of Serialized Parts

 

 1 .  Enter the Service Calls form. Retrieve a service call involving the desired part. 
 

 2 .  Select Repair History per Serial Number from the list of Direct Activations . The report displays all service calls recorded for the part, including the following information: 
 

 ·      Date 
 

 ·      Call number 
 

 ·      Malfunction 
 

 ·      Technician who handled the call 
 

 ·      Details about the repair.
