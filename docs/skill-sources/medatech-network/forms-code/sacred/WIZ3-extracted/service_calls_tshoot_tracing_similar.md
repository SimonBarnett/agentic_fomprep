# Tracing Calls with a Similar Malfunction and/or Repair

 

 Priority enables you to find those service calls that have a similar malfunction and/or repair. Specifically, you designate a key word or phrase and Priority finds any service calls in which the given text appears in the description of the malfunction and/or the repair. This way, you can save time finding the appropriate solution to a given problem. 
 
## To find calls with a similar malfunction and/or repair:

 

 ·        Run the Search Calls for Malfunctions report.
