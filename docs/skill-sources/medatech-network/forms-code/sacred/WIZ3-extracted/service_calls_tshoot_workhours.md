# Keeping Track of Reported Work Hours

 

Two reports display reported work hours (billable and unbillable) per technician and service call, as well as totals. 
 
## To view work hours over a period of time:

 

 ·        Run the Analysis of Tech. Hours-Detailed report. 
 
## To view work hours per day:

 

 ·        Run the Analysis of Tech. Hours-Table report.
