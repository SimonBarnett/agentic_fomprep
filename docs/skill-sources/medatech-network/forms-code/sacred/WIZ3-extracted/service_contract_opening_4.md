# Printing the Contract – Before you Begin

 
## Remarks Appearing on the Printout

 

If you have recorded set text, that will appear in the form of remarks on all printouts of service contracts. For each individual contract, you can add to or change these remarks before you print out the contract. 
 
## To view and/or revise the remarks:

 

 1 .  Enter the Remarks form (sub-level of the Service Contracts form). 
 

 2 .  The set text appears. Make any desired changes. 
 
## Note:

 

If you don't use set text, you can use this form to record any remarks you want to appear on the printout for this particular contract. 
 
## Changing the Contract Status

 

Before you print the contract, it is recommended to change its status to one that does not allow revisions. 
 
## To change the status of a contract:

 

 1 .  Return to the upper-level form. 
 

 2 .  Click the Dates in Effect tab and update the Status .
