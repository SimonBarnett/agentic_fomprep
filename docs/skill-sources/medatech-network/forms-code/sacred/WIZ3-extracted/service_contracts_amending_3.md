# Printing an Amended Service Contract

 
## Before you begin:

 

 1 .  Return to the Service Contracts form. 
 

 2 .  Click the Dates in Effect tab and update the Status to one that does not allow revisions. 
 
## To print the service contract:

 

 ·        Select Print Service Contract from the list of Direct Activation s . 
 Tip for dual-currency users: If you wish to print the contract in English and are working in another language, select Print Serv. Contract-ForeignLang instead.
