# Calculating Payment Installments for Service Contracts 

 

Payment installments determine what portion of the year to bill. For example, an installment covering three months generates a bill for one fourth of the full contract price. 
 

You calculate payment installments each time you bill customers, before you prepare invoices. 
 
## Note for dual-currency users:

 

You can also link contract payments to a foreign currency, currency basket or price index. For details, see the Price Adjustment Wizard . 
 
## Default Payment Frequency

 

You need to set up one payment frequency option as the default for the payment installment utility. If you have not yet set this up, do it now: 
 

 ·        In the Payment Frequency Options form, flag the desired Default Option .
