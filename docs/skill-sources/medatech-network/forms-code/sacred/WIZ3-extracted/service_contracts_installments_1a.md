# Defining the Payment Date Option

 

By default, the automatic utility calculates and dates payments according to set calendar periods. Example. However, Priority also allows you to calculate and date payments dynamically, according to the date on which each contract goes into effect. Example. 
 

A constant determines whether you work system-wide with set calendar periods or with dynamic service periods. However, you can override this definition for individual contracts. 
 
## To set the constant:

 

 1 .  Enter the Logistic Constants form. 
 

 2 .  Move to the line for the CContPayPrd constant. 
 

 3 .  To use set calendar periods, leave the pre-set value of 1 . To define the period dynamically for each contract, change the constant value to 0 . 
 
## To change the definition in a particular contract:

 

 1 .  Enter the Service Contracts form and retrieve the contract in question. 
 

 2 .  Click the Terms tab and flag the Set Pay Date column to use set calendar periods, or remove the check mark to define the service period according to the contract's effect date.
