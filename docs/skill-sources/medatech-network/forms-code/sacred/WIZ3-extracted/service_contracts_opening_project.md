# Itemizing a Contract Based on a Project

 

 1 .  Enter the Projects form. Retrieve the desired project. 
 

 2 .  Make sure the information in the Installation Date column is correct. 
 

 3 .  Click the Additional Details tab and make sure the information recorded in the Months Under Warranty column is correct. 
 

 4 .  Enter the Finished Products sub-level form. 
 

 5 .  Make sure the following information is correct for each part: Installation date (if different from the project's installation date), quantity, unit price and prorate or flat rate service charge. 
 

 6 .  Return to the Service Contracts form, click the Contract Source tab and select the project number. 
 

 7 .  Enter the Items in Contract sub-level form. Make any desired changes and additions (e.g., delete a part; record a discount for a part).
