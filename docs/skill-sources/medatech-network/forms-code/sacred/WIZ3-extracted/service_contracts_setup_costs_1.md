# Defining Service Costs for Parts

 

You can predefine service costs per part within any given time period, and run a Direct Activation from the service contract that calculates its total cost on the basis of these predefined costs. These costs can then be updated at any time. 
 
## To set up service costs per part:

 

 1 .  Enter the Parts form and retrieve those parts that are covered by service contracts. 
 

 2 .  For each part, enter the Service Cost per Period sub-level form. 
 

 3 .  Using the From Date and To Date columns, define the period in which the current cost is in effect.
 Note: If a start date on one line overlaps with the end date in the previous line, that end date is adjusted automatically. 
 

 4 .  Specify the Annual Cost in effect during the defined period. 
 
## Tip: 

 

Use the Service Cost per Period form to easily retrieve service costs defined for a batch of parts and/or periods.
