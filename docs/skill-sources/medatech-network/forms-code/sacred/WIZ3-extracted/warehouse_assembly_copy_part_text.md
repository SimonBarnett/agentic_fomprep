# Copying Part Remarks to Assembly Documents

 

You can set up assembly documents so that part remarks are recorded automatically for assembled components when a child part number is recorded or revised. 
 
## To automatically copy part remarks to assembly components:

 

 1 . Enter the Copy Part Remarks to Document form. 
 

 2 . In the line for "Warehouse Assembly", flag the Copy Part Remarks column.
