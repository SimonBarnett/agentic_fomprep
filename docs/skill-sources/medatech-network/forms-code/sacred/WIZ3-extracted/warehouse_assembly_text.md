# To define set text for assembly documents:

 

 1 . Enter the Set Text for Warehouse Assemb. form. 
 

 2 . Record the desired remarks in the Set Text for Warehouse Assemb. sub-level form. 
 
## Note: 

 

The set text will automatically appear in the Remarks sub-level form of each new assembly document, but may be revised there. Any remarks appearing in that sub-level form appear automatically in the printout of the assembly report.
