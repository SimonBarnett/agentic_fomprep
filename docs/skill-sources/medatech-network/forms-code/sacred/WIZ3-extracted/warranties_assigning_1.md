# Starting Warranties

 
## Assigning Warranties to Serialized Parts

 

Click to run the Service Setup Wizard if you have not yet set up warranties and/or serviced parts. 
 

When you open a new serial number for a part and install the serialized part at the customer site, it is automatically assigned the warranty code that was designated for the part in the Service Parameters for Part form. Also, the system calculates the start and end dates of the warranty for the serialized part based on the warranty code in the Service Parameters for Part form. Example. 
 
## Note:

 

If you want warranties to be assigned when parts are shipped rather than when they are installed, change the value of the CAutoWarrant constant to 1 (in the Logistic Constants form).
