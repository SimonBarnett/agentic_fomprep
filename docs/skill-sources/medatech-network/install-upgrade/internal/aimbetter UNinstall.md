# aimbetter UNinstall

- **Source:** `aimbetter UNinstall.docx`

Gemma’s Guide for uninstalling Aimbetter

Go on the customers DB server.

Stop the AimBetter service:

Open the Control Pannel and uninstall the AimBetter:

This is everything done on the server side.

Next, login to Aimbetter: https://app.aimbetter.com/login

Select “Servers” from the settings menu:

Find the server that you uninstalled from and choose “Disable”:

In the upgrades Trello, https://trello.com/b/6dIlfP4U/upgrades, move the customers card to “Uninstalled”, change the labels, and comment the uninstall date.

In Medatech Priority, against the AimBetter vendor (S000521 (click here)), find the task for the customer and set the status to “Completed”.

Tell the customer that AimBetter is uninstalled.

Update the service call we have opened for AIMBETTER and set to Answered. Record hours against the service call.
