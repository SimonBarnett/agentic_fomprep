# web licences

- **Source:** `web licences.docx`

Changing to complete web licence

Before installing your new licence

Go to System Management > System Maintenance > Users > User Permissions

Search for any users that have “Priority Web Licence” ticked, and remove the tick

After installing your licence

Search for all users you have defined as “Active Users”

Make sure the number of active users does not exceed the number of user licences you have

If necessary, untick users as active to reduce the number of licences you are consuming
