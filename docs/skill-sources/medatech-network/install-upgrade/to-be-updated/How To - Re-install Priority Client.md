# How To - Re-install Priority Client

- **Source:** `How To - Re-install Priority Client.docx`

Re-installing Priority Client Users Guide

It would be recommended to logged in as an Administrator to do this.

Note: You will have to delete tabula.ini file once Priority has been uninstalled, if you’re unsure of the location, please refer here to see the location of this file.

When in Priority in the top menu press Help > About Priority to check tabula.ini file location

Go to Control Panel\All Control Panel Items\Programs and Features and Uninstall or change a Program. Find Priority in the list. Right click on it and then Uninstall/Change and follow the instructions to uninstall Priority.

Note: Windows 10 users not to mistake Applications with Programs.

Once the program has been uninstalled. You will need to find the tabula file and delete it.

Then run the Setup file as an Administrator, you should be able to find it in the directory where Priority has been installed on the server in Client folder.

Priority will open up and this window will pop up, press ‘Install’ to continue and proceed with the installation.

You will need to specify the priority location on server, it it’s incorrect you will get the following error message. If unsure you can check that on your server.

Now you’ll be required to specify the location of where you’d like Priority to be installed on this machine.

Press okay and open Priority.
