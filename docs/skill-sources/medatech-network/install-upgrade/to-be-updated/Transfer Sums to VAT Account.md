# Transfer Sums to VAT Account

- **Source:** `Transfer Sums to VAT Account.docx`

Financials > Nominal Ledger > Financial Statements > Taxes > Value Added Tax > Sums for Transfer to VAT Account will only show what needs to be transferred.

You need to make checks before and make sure what you’re transferring is correct. If you’re happy with the amounts, run the program to transfer. This program will transfer everything up this date as one monthly sum.

Financials > Nominal Ledger > Financial Statements > Taxes > Value Added Tax > Transfer Sums to VAT Account

In order to run this program, you will need to open all the periods starting from the earliest (14/09/15) Invoice date otherwise it won’t transfer anything as the periods are closed.
