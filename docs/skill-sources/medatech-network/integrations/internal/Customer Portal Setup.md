Setting Up a User on the Portal 
 
 
1 Project Form Checks: 
Project > Projects 
1.1 Check that the Customer has a project ticked as portal default in the Misc. tab of the Projects form. 
 
 
 
 
 
 
 
 
1.2 If there is no Project marked as “Portal Default?” then an existing one must be ticked, or a new Project 
created. 
 
2 Service Contract Form Checks: 
Service > Service Contracts > Service Contracts 
 
2.1 Check that the Customer has a service contract ticked as portal default in the Misc. tab of the Projects 
form. 
 
 
 
 
 
 
 
 
 
2.2 If there is no Service Contract marked as “Portal Default?” then an existing one must be ticked, or a new 
Contract created.

3 Customer Contact Subform Checks: 
CRM > Customers > Customers 
 
3.1 Customer must have a contact ticked as “Approved Service Call Contact” in the  customer contacts 
subform. 
 
3.2 All contacts who have this tickbox marked will then be selectable in the contact field on the customer 
portal for any service calls raised for this particular customer. 
 
 
4 Customer Portal Users form setup:  
CRM > Customer Portal > Customer Portal Users 
 
4.1 Create a new entry on the Customer Portals Users form. 
4.2 Select the Customer Number from the drop down. 
4.3 Create a User Name in the User Name field, the username should be the email address we have on record 
for the contact who will make use of the customer portal account being created. 
4.4 Link to a Contact in the Contact field by using the drop-down 
4.5 Tick Generate Password. 
4.6 A password will be generated. This is to be provided to the user to allow them to log in for the first time. 
 
4.7 Tick as Active.

6 Alternative Setup Method: 
 
Customers can manually create their accounts by selecting the “Sign Up” option on the Customer Portal. To complete the 
process, they will need to provide their Customer Number and Customer Code to verify their company. These details will 
be provided by Medatech. 
 
CRM > Customers > Customers
