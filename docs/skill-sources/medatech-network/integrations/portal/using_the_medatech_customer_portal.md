Using the Medatech Customer Portal

Logging in to the Portal:

1.1 First-Time Login

If you are logging into the new Customer Portal (launched in 2023) for the first time, you will need to create a new account. This applies even if you have previously used an earlier version of the portal.

1.2 Registering Your Account

Contact support@medatechuk.com to request your Customer Number and Customer Code, which are required to complete registration.

Go to https://priority.medatecherp.co.uk/customer_portal/#/login and click “Sign Up.”

1.3 Verifying Your Company

After clicking "Sign Up," you will be prompted to enter your Customer Number and Company Code to verify your company.

1.4 Completing the Registration

Fill in the required details on the registration form. Once submitted, your username and temporary password will be emailed to you.

1.5 Logging in for the First Time

Use the temporary credentials provided in the email to log in. Upon your first login, you will be prompted to set a new password.

1.6 Future Logins

For all subsequent logins, use your new password to access the portal from the same URL.

Creating a new Service Call:

From the Customer Portal homepage select “Create Select Service Call” from the left hand pane.

You will then need to fill in the fields detailed in the below screenshot

Enter a Subject for the Service Call with sufficient detail to summarise the issue / request.

The Customer Reference field can be used to include your own reference.

Call Type is selected from the drop down menu. If you are unsure what to select, then choose “General”.

Call Severity is selected from the drop down list. The severity of each call is relative to the number of users the issue affects and its impact on users ability to work in Priority. Some examples of the criteria of each severity level are provided below:

Critical – the entire Priority system is inaccessible to all users.

Major – a particular function of Priority has ceased working, impacting some users ability to work.

Minor – the system is not performing as required, although users are still able to work.

Enquiry – the system is working OK but you want to pose a question or request a change.

Undefined – avoid selecting this option.

Select the contact from the list of users who have been set up on the Portal. Updates on the service call will be sent to the email address held for this user.

Use this button to insert pictures into the body of the service call. Currently it is not possible to paste images directly into service calls raised on the Customer Portal. If the image is saves on your PC you can drag and drop it into the menu (see below screenshot), or alternatively input a URL address if you have one available.

Once an image has been added to the service call you can align it using the buttons below the image.

Fill in the main body of the service call with details of the issue / request. It is helpful to include the following:

Describe the system behaviour in detail and explain how it differs from expected behaviour

Is this a new issue or has it occurred before?

How many users is the issue affecting?

When did the issue start?

Include screenshots of any warning or error messages displayed in Priority

You can add files to the service call using the paperclip icon at the bottom of the page.

When you have finished writing the service call and all the required fields have been filled in with sufficient detail then click the submit icon. The Service Call will then be loaded directly in to Medatech’s Priority system and you can await a response from the Medatech Support team.

Reviewing Current and Past Service Calls

Select Service Calls from the left hand pane

This will open the Service Calls screen where you can view current and past Service Calls (see below screenshot).  By default the Show Only Active Ticketstickbox is marked (highlighted in the below screenshot). Unticking this will allow you to view Closed service calls.

Each column can be sorted alphanumerically  or filtered

To update an existing call locate it in the list and select the hyperlink Ticket ID, on then next screen you can add a new entry to the service call and click the Update button

Forgot Password

In the event that you forget your password and become locked out of the customer portal you can enter your Username and then select the Forgot Password button from the login page

As soon as Forgot Password? Is selected an e-mail will be automatically sent to the e-mail address associated with your contact record on the Medatech system.

The e-mail will contain a temporary password which can be used to login to the customer portal, after which you will prompted to change your password again.

If you forget your Username then please contact Medatech Support for help.
