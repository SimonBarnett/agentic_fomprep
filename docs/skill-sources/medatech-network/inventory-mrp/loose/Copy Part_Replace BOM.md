# Copy Part_Replace BOM

- **Source:** `Copy Part_Replace BOM.docx`

Copy Part – Replace in BOM Users Guide

Description

This module will allow you to copy a Part, make changes to the copy (such as changing the part type) and then replace the copied part with new one. All occurrences of the 'From Part' will be replaced by the 'To Part'.

Run Procedure from Menu.

Production > Factory Modelling > Parts > Replace Part - Occurences in BOM or

Inventory > Parts > Part Maintenance > Replace Part - Occurences in BOM

Confirm you wish to proceed.

Enter Part to Copy and Replace in BOM

Optionally include copy of Manufacturing Data

Enter New Parts’ Number and then escape from form

Parts Form opens and user may amend new part as required.

Confirm you wish to proceed and replace parts in BOM

A Report then shows the Parent parts on which the BOM was amended.
