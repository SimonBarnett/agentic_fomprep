# ZEMG_CONST Rich

- **Source:** `ZEMG_CONST Rich.docx`

Medatech Constants Tables/Form/Triggers

You need to write an SQLI to insert any constant data you wish pre-loaded, remembering for Company Constants to insert for all environments.

Two triggers are installed in the func form to retrieve constant values: -

ZEMG_CPYCONST and ZEMG_SYSCONT

NOTE

If you start your constant with the letters LIC (uppercase is important) then this constant does NOT display in the form(s) but can be retrieved using the func triggers.
