# COPY USER MENU Rich

- **Source:** `COPY USER MENU Rich.docx`

COPY USER MENU

Different Copy User Favourites Option which has the ability to copy from one user to a group of users and option to just add to existing favourites.

Procedure allows copy from single user to single user or single user to user group. If group chosen matches from user, then the group leaders favourites are copied to members of that group.

If Overwrite existing option not chosen, then just options in the ‘from users’ favourites not already in the ‘to users’ favourites are added to the end of his/her list.
