# MEDATECH SUPPORT MENU Rich

- **Source:** `MEDATECH SUPPORT MENU Rich.docx`

EMERGE SUPPORT MENU

Puts a new Emerge Support Menu option in the main menu

NOTE: The Run Teamviewer option depends on qs.exe being in the local machines bin.95 directory. This can be done by putting in the bin.95 and client/bin.95 directories of the main server and then when a user upgrades their client executables  it is included in the copy to the client machine.
