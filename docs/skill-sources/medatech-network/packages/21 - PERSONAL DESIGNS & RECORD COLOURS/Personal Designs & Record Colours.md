# Personal Designs & Record Colours

- **Source:** `Personal Designs & Record Colours.docx`

Personal Form/Report Designs & Record Colours

Must already have R:\INSTALLED AS STANDARD\13 - COPY USER FORM DESIGN installed

R:\INSTALLED AS STANDARD\21 – USER DESIGNS & RECORD COLOURS\ZEMG_FRMRPTGENDESIGN.sh

Installs a new sub-level forms which allows you to view and make limited changes to user form/ report designs and record colour rules within the standard form generators.

System Management > Generators > Forms > Form Generator -> Form Columns User Designed

You may amend the field position (NB. Change this in single record designs to move to different Tab header), hidden tick-box, revised title (NB. Once changed this cannot be blanked to revert title within this form), Merge Lines tick-box and Split Block tick-box. You may not delete or create new records.

Changes are applied upon exiting the form, the Position number remains with the value you have given it unless the “Design->Organise Fields” drop down is used then these are renumbers sequentially by the system.

System Management > Generators > Forms > Form Generator -> Form Record Colours

You may amend RGB colour values, Display Order (NB. Strongly recommend you ensure no two rules with same Display Order exist but system will operate if they do.), Value and if applicable Value 2. You may delete records but not create new records.

System Management > Generators > Reports > Report Generator -> Report Columns User Design

You may amend the report column position, hidden flag, date format and the alignment values. You may not delete or create new records. NB. When user creates a report design the revised title in the design is always set for all columns but matches the report title unless changed. NB2. Priority will also override the report title but this is not held in the design table!

Changes are applied upon exiting the form.
