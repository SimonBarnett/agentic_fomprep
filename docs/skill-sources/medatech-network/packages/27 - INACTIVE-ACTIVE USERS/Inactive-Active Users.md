# Inactive-Active Users

- **Source:** `Inactive-Active Users.docx`

Inactive-Active User

To Ensure Users can not log back on when waiting to install a shell file:-

System Management > Revisions >

System Management > Revisions > Make users inactive

Procedure indicates how many users details have been stored and set to inactive

Then a report shows a list of the users.

If you try to run a second time, you are warned but can continue!

System Management > Revisions > Make users active

Procedure indicates how many users details have been restored as active

Then a report shows a list of the users.

System Management > Revisions > Users Changed

Shows the current report output:-
