# Vendor ESD VAT Install

- **Source:** `Vendor ESD VAT Install.docx`

How to Install Vendor ESD VAT discount Journal Adjustments

System must have the ‘ERROR MESSAGE LOGGING’ add-on already installed

Install the ZEMG_SUPESDVATDISC shell file.

Optionally: Run Priority

Adjust Direct Activation order on:-

Financials > Accounts Payable > Vendor Invoices > Vendor Invoices > Vendor Invoices

Financials > Accounts Payable > Vendor Invoices > Multi-GRV Invoices > Multi-GRV Invoices

Financials > Accounts Payable > Vendor Invoices > Debit Memos > Debit Memos

Adjust Menu order on:-

Financials > Accounts Payable > Vendor Invoices > Vendor Invoices

Financials > Accounts Payable > Vendor Invoices > Multi-GRV Invoices

Financials > Accounts Payable > Vendor Invoices > Debit Memos

Ensure Customer has the User Guide to set-up the data required.
