# Privileges by Entity Users Guide - Rich

- **Source:** `Privileges by Entity Users Guide - Rich.docx`

Privileges by Entity Report Guide

Description

New Privilege by Entity report. Shows which users/user groups have access to a form, report or procedure.

Run report from:

System Management > System Maintenance > Privileges > Reports on Privileges > Privileges per Entity

Enter single or F6 to select multiple forms, report or procedures, limit to just forms, report or procedures or leave blank for all.

Report shows each entity, its type, the user/user group with access and their inactive flag, if a form whether no delete or query only is set, then a list of all the users with this user/group as their group leader and their inactive flag.
