# Posting Accruals Users Guide

- **Source:** `Posting Accruals Users Guide.docx`

Posting Accruals Users Guide

Description

This module will give you the ability to create a journal entry for the current month that will automatically have an equal and opposite entry created in the next fiscal period. Please refer to the section 2 of the document ‘Creating Journal Entries’ for instruction on how to do so.

Accruals are generally adjustments for

Revenues that have been earned but are not yet recorded in the accounts,

Expenses that have been incurred but are not yet recorded in the accounts.

Adding an accrual is the same as adding a standard journal entry. The only difference is that the ‘Journal Template’ (Field on the Misc tab) which can be set to ‘Accrual’ or ‘Standard’. Before an Accrual can be posted it is vital that the next fiscal period has been opened.

Once an entry has been created it can be posted via 2 methods;

‘Post Journal entry Accrual’ (direct activation on the journal entries sub form) this is used for single entry creation.

‘Post Journal entry Accrual’ (shown in the menu ‘Financials > Nominal Ledger > Entry Journal’) this is used for multiple entry creation.

When using the multiple creation method the user is given a dialogue box to pick one or more specific journal records, alternatively T* can be used to check all invoices that haven’t yet been finalised. Both methods can be used for creating Standard or Accrual entries (the System will work out whether the negative entries need to be created or not)

After the entry has been posted Priority will have the following ledger transactions;

If the entry was set to ‘Standard’ there will be 1 entry in the ledger as per what was entered.

If the entry was ‘Accrual’ there will be 2 entries 1 as per what was entered and 1 equal but opposite entry in the next fiscal period.

Creating Journal Entries

Once the Date for the transaction is selected press enter and the next available Entry No will be automatically populated. The Transaction will be set to Miscellaneous but this can be updated.  (this list can be updated with additional types if required)

The Details can be updated on the references tab. (This will help when reconciling) you can specify if the entry is standard or if it need to be an accrual.

For a simple entry, the Debit and Credit accounts can be set using the dropdown arrows. The value can be added to the Sum field.

For a complex entry, the accounts can be set in the “Itemised Entry” form. The Profit/Cost centre, Account No., Details can be set against each line. On entering the last line, the Amount to Balance can then be checked and priority will automatically generate the value to balance.

Prior to posting an entry to the ledger, it is possible to see its affect using the Direct Activation “Acct Bals Once Entry is Posted”

Once the entry is complete, it can be posted to the journal or converted to a provisional entry using relevant item on the Direct Activations menu.

If it is no longer required, it can be deleted prior to being posted from the same menu “Delete Pending Entry”.

Alternatively it is possible to post multiple entries using the following procedure Financials > Nominal Ledger > Entry Journal > Post journal Entries Accruals. If a template type of Accrual has been selected for any of the entries to be posted both methods will automatically generate an equal and opposite entry for the next period providing it has been opened.
