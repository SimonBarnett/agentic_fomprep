1. Description 
 
This enables the parameters for the “Purchasing > MRP for Manufacturers > Material Requirements 
Planning” procedure to be stored and a new version “Purchasing > MRP for Manufacturers > MRP run with 
no prompts” to run or be run on the task scheduler and process with the defined parameters with no user 
intervention.
