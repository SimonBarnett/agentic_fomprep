- **Source:** `Bulk Rel. WO Users Guide - Rich.docx`

Bulk Release Users Guide

Description

This procedure enables multiple work orders to be released based on varied criteria.

Bulk Release Work Orders

Production > Production Control > Bulk Release Work Orders

Enter or F6 to select criteria of work orders to be released, From and To Production Start Date fields are mandatory.

Any valid selected work orders are set to release status.
