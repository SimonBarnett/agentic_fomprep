Direct Ship PO from SO Users Guide

Description

This procedure enables a purchase order to be created from a sales order directly shipping the goods to the customer from the supplier.

Direct Ship PO from S.Order

Sales > Orders > Sales Orders

Direct Activation offers option to direct ship.

Purchase Order Created

Will either use the Sales Order shipping address if entered or the Customer address as the Purchase Order shipping address.
