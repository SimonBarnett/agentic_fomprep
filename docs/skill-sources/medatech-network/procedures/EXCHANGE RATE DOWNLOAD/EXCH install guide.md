# EXCH install guide

- **Source:** `EXCH install guide.docx`

How to Install Exchange Rate Feed Downloader Installation Guide

Install the ZEMG_EXCHRATEDNL.sh shell file in Priority

Copy the file [R:\Emerge-IT EXE Setup\setup_emgEXCH.exe] into a valid directory then execute

Click Next

Check this is the appropriate Priority directory (uses the value from tabula.ini) and adjust if necessary, click next

Adjust the start menu name if you need to, click next

Click Install

Click Finish
