Part Analysis Update Users Guide

Description

This procedure enables changes made to Lab. Analysis Code to be repeated on selected parts which are linked to the analysis code. Also adds a sub-level showing the parts linked to the analysis code.

Update Part Lab. Analysis Code Direct Activation

Inventory > Quality Assurance > Laboratory > Laboratory Definitions > Lab Analysis Codes

Direct Activation offers selection of parts to update

Warns how many parts would be updated, click Ok to proceed, click cancel to abort.

Then informs how many parts were updated.

Any Parts with the Required Analysis will be updated,

Parts with Analysis Code Sub-level

New sub-level shows the parts linked to the analysis code
