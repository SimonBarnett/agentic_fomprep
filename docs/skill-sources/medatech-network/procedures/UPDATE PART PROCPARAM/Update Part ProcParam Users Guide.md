Update Part Processing Parameters

Users Guide

Description

This new procedure will update the part and operation processing parameters for all parts, based upon the values in their routing. Therefore ensuring that standard costing picks up the correct values.

Update Part Processing Parameters

Production > Factory Modelling > Routings > Update Part Processing Parameter

Select Routing and part (you may F6 to select multiple records)

Tick the required options:-

Then click approve

Production > Factory Modelling > Parts > Parts

The operations ‘T’ processing parameters will be set with the time calculated using the formula Prod Qty/Prod Time
