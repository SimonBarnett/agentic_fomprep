- **Source:** `Age Debt Reports Rich.docx`

Age Debt Reports Users Guide

Description

New detailed report displays all overdue invoices for designated customers, sorted by payment due date. Variance between the Invoice Sum and the Outstanding Sum indicates a partial payment.

Tip: Run the reconciliation programs before running this report, so that as many invoices and payments as possible are reconciled.

Run report from:

Financials > Accounts Receivable > Accounts Receivable Reports > Aging and Open Invoices > Aging by Invoice (Trans Curr)

Description

New detailed report displays all overdue invoices for designated customers, sorted by invoice currency then payment due date. Invoices are grouped and totalled by Invoice currency.  Invoice value and outstanding value in the Invoice currency are shown followed by the values in the account base currency.

Variance between the Invoice Sum and the Outstanding Sum indicates a partial payment.

Tip: Run the reconciliation programs before running this report, so that as many invoices and payments as possible are reconciled.

Run report from:

Financials > Accounts Receivable > Accounts Receivable Reports > Aging and Open Invoices > Aging by Invoice (Multi-Curr)
