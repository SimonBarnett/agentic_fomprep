# BOM Cost Compare Rich

- **Source:** `BOM Cost Compare Rich.docx`

BOM Cost Comparison Report Users Guide

Description

New report displays costing based on two user selectable costing dates for all the parts in a Bill of Materials. The costs compared may be standard or actual costs.

Run report from:

Financials > Cost Analysis for Manufacturers > Costing Results > Costing Reports - Parts > Part Cost Comparison full BOM

Select costing dates from the lists supplied

Select how you want the dates compared

Select Top level part(s)
