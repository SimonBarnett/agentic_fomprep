# Make Part Check Users Guide - Rich

- **Source:** `Make Part Check Users Guide - Rich.docx`

Make Part Check Users Guide

Description

New detailed report checks the required data for a Make (Type ‘P’) part reporting any discrepancies.

Run report from:

Production > Factory Modelling > Parts > Part Reports > Process Params & Set-up Reports > Make Part Checks

Or from Direct Activation on forms: -

Production > Factory Modelling > Parts > Parts

Inventory > Parts > Part Catalogue

Or

Inventory > Parts > Part Parameters > Purchase/MRP Parameters for Part
