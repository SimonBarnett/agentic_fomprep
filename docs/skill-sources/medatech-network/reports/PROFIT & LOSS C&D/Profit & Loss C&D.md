# Profit & Loss C&D

- **Source:** `Profit & Loss C&D.docx`

Profit & Loss C&D Report Users Guide

Description

Run this report to display profit and loss in Credit and Debit columns from the beginning of the fiscal year until the designated period. Choose between a standard report and a schedule. Also determine whether journal entries are to be included according to their transaction dates or reference dates.

Run report from:

Financials > Nominal Ledger > Financial Statements > Profit and Loss > Profit and Loss C&D
