# Trace Lot Use Users Guide - Rich

- **Source:** `Trace Lot Use Users Guide - Rich.docx`

Trace Work Order/Lot Number Use Report Users Guide

Description

New report allows you to see traceability from customer Shipment back to all items issued to the product or from the work order or lot number see all products it was used in.

Run report from:

Production > Production Control > Production Control Reports > Work Order Traceability Reports > Trace Lot Number on Work Orders
