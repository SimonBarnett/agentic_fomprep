# VAT Report

- **Source:** `VAT Report.docx`

VAT Report

New fields are added to the Tax Codes form.

Financials > Maintenance of Financials > Basic Data > Financial Attributes > Value Added Tax

Boxes 1 – 9 (excl. 3 & 5) should be ticked for each VAT Code accordingly.

The above example shows the different types of accounts and how they should be marked in Priority.

You must also ensure that the VAT accounts are marked in the Chart of Accounts.

When these boxes have been ticked you can run the VAT Report from the menu:

Financials > Nominal Ledger > Financial Statements > Taxes > VAT Reports (Europe) > VAT Report - Emerge > VAT Return

The report can be output as Detailed to show all items included in calculations, or Non-Detailed to just show the values for the VAT Return.

Once you run ‘Transfer Sums to VAT Account’ the report will not show the same figures. So ensure you are happy with the report and figures and have saved a copy before you run the Transfer Sums.
