# How To - Reset Solon Website Admin Password

- **Source:** `How To - Reset Solon Website Admin Password.docx`

How to reset http://redlinesecurity.co.uk/admin/ password.

Log onto their web server (please refer to customer connection details).

Open Internet Information Services (IIS) Manager

In there go to SOLONSEC\Sites

Choose the website that needs password reset and then .Net Users

Find ‘admin’ user. Then Remove it.

Add a new user and set a new password.

User Name: admin
