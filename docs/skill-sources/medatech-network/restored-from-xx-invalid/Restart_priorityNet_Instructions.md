# Restart_priorityNet_Instructions

- **Source:** `Restart_priorityNet_Instructions.docx`

In unprepared forms error pops up and re-preparing forms program doesn’t work, access the server.

Open Task manager.

Find Priority .Net Service on the list.

Restart the Priority .Net Service and I’d suggest to wait few minutes before trying to access Rich as sometimes it doesn’t restart instantly and takes few minutes. If you get Priority 500 error, don’t worry. Just click OK, wait a minute and try to log in again.

Then run the form preparation program again and it should fix the issue.
