Priority Mobile – SOTI Interface Installation

Introduction

The following document describes how to install the SOTI Remote Support Interface onto Windows Mobile devices. This Interface is used for the remote support of Windows Mobile Devices running the Priority Mobile Application.

Installing the SOTI Interface

From the Mobile Device’s main menu, open Internet Explorer.

Once Internet Explorer has opened, enter the following URL into the address bar:

soti.emerge-it.co.uk/client/Tingdene/ and click ‘GO’. There you will find soti.cab

You will be prompted to save the file ‘soti.CAB’; Select ‘Open file after download’ and click ‘Yes’ to save the file. Note the location where the file is saved.

If the file does not open automatically after downloading, browse to the location where the file has been saved using the ‘File Explorer’. (In your case file will be called soti.cab)

Double click the file to install the interface onto the device. Once the installation is complete, the SOTI Interface will be installed, and requires no further configuration.
