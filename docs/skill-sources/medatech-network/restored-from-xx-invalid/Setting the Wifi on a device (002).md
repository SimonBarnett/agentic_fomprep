# Setting the Wifi on a device (002)

- **Source:** `Setting the Wifi on a device (002).docx`

A device with Internet access should look similar to the image below

If the wifi is not enabled, the network image may have a X through it looking like the image below

Check Wifi

Click  Then Programs then Summit

Then SCU This will bring up the Summit Client Utility (Wifi)

The screen should look like the one above, but if it has not been setup, may have Default and no association for its status

To look for networks, click the Profile Tab

Then Scan for networks

This will show you the Wifi networks it can see.

Select your wifi (will show negative numbers for signal strength, lower number better)

It will ask you for a password

Enter this

The  button will be with Black writing, click it

Go back to the main tab

Select form the this Wifi  from the dropdown menu.
