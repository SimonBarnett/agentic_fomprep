Priority Web Installation Guide 1 
PRIORITY WEB INSTALL ATION GUIDE  
Before you begin installing Priority Web, make sure you are login into Windows as 
ADMINISTRATOR (do not run the installation file as ADMINISTRATOR, this is not enough.)  
STEP 1  
20.0 and below 
Go into a web browser (Chrome) and enter the Priority URL including HTTPs:// at the 
beginning.  
e.g. https://priority.medatechuk.com 
 
20.1 and above 
You will already be able to log in without installing but some features will be unavailable. 
Add “installpage=1” to your URL to reach the install page.  
E.g. https://priority.medatechuk.com/?_installpage=1
