- **Source:** `BREMONT.docx`

Multi Factor Authentication

On test, Bremont have the MFA module installed.

When you run a bin update, you will be prompted to login to Microsoft. You can use our Medatech user, medatech@bremont.com, the password for which is in our customer connection details for Bremont.

If you don’t get asked to login to Microsoft or see errors, go to office.com and sign out. Then try the bin file again.

When logging into Microsoft, if asked to “Stay Signed In?” choose “No”.

To reinstall the app server, you need to be logged in as tabula. There is an “emergency” access to Priority that uses tabula. There is an icon on the desktop. Details in SC240623.

Otherwise, we can login to Client using our Medatech user. To login to client, the IIS and app services need to be running. As above, if you don’t get asked to login to Microsoft or see errors, go to office.com and sign out. Then try again to open client.
