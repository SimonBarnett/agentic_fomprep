Introduction (00:00-01:41) 
Priority's CRM module provides a variety of powerful tools to assist you in 
identifying and targeting potential customers, tracking sales opportunities and 
managing relations with existing customers and their contacts. In this clip, we are 
going to demonstrate how to work with the Customer Work Area. 
The Customer Work Area acts as a temporary storage facility for customer records 
and their contacts, based on a variety of retrieval criteria (e.g., marketing contacts, 
participation in marketing events). Once records are loaded in the work area, you 
can perform various activities for these customers and/or contacts in a batch; for 
instance: 
 Record the same task for a group of customers 
 Synchronize contacts with MS-Outlook 
 Create groups of contacts  
 Prepare mailing labels 
 Assign business classifications  
 Record participants in marketing events 
 Create and send personalized letters 
You can also use the work area to maintain customer records (e.g., assign prices 
and discounts). This may be more convenient than using the Customers form, as 
you can load and edit a batch of records based on a variety of cross-sections, and 
continue to refine the results until you are finished working with them. 
Note: To take full advantage of the power of the work area, make sure to define 
values for the various customer and contact properties that you'll be using to load 
records into the Customer Work Area, as well as contact information such as phone 
and fax numbers and e-mail addresses. 
Let's begin by demonstrating one of the programs offered by Priority to help make 
loading the work area quick and easy.

The Contacts form that opens enables you to retrieve contacts based on a variety of 
criteria, such as the area code in their Phone Number and their Position at the 
company. Alternatively, you can retrieve all contacts that are associated with 
temporary customers  and have provided an E-Mail Address. In still another 
scenario, you can retrieve all contacts that are defined as the Marketing Contact for 
the customer in question. Use F7 to clear any unwanted lines. Once this form is 
populated with all the desired customer contacts, press Esc to exit the form and 
continue running the program. 
Once the program finishes running, the Customer Work Area is loaded with the 
pertinent customer records; Priority then reports how many records were loaded. 
At this point, you can load additional records into the work area using any of a 
number of similar programs or proceed directly to the Customer Work Area form in 
order to work with these records. Alternatively, if too many records were retrieved, 
you can clear individual records by activating the Delete Record from Work Area 
program from the line in question. If you need to remove a number of records, you 
may prefer to simply clear the entire work area and rerun the loading program using 
additional criteria in order to narrow the results. 
Using the Customer Work Area (03:39-04:49) 
Now that the desired customer records have been loaded, you can use the work 
area and any of its sub-level forms to work with the loaded customer records. For 
instance, you can use the relevant sub-level forms to assign a special part price or a 
part discount to each of the loaded customers. Note that while records in the work 
area are currently saved in a temporary database, any information you record or 
modify in the sub-level forms will automatically affect the permanent customer 
database. 
You can also run any of the programs or reports in the Customer Work Area menu 
to perform various activities for these customers and/or contacts in a batch. For 
instance, the Prepare Group from Work Area program enables you to add some or 
all of the loaded customers to a new or existing customer group. In this video, we're 
going to demonstrate the Letter to Contact tool, which is used to create and send 
personalized letters to the loaded customer contacts. When used in combination with 
the Letter Generator, this tool enables you to include contact data that is taken from 
the relevant Priority forms in real time in the letters and e-mails you send to your 
customer contacts. 
Using the Letter Generator (04:50-08:49) 
Priority's Letter Generator allows you to produce an infinite variety of pre-formatted 
letters, which can then be populated with Priority data and sent to customers, 
vendors, and contacts. You can also include attachments and a personalized 
signature in each letter. Let's open the Letter Generator form to view an example of 
a pre-formatted letter used to offer customers a special holiday promotion. Note the 
name of the program defined for the letter in the Create Letters Using column; this 
selection determines which program can be used to create this letter for a specific 
recipient or group, as well as the types of data fields you'll be able to include in the 
letter. For instance, letters to vendors can include data such as the vendor's name 
and internal number, while letters to customers or customer contacts cannot.

Once you are finished designing the letter, you can easily create multiple letters to 
each of a group of contacts. Let's demonstrate how to create and send letters to the 
contacts that were loaded previously into the Customer Work Area. 
One option is to create a letter for a single contact, directly from the relevant line in 
the work area itself. Alternatively, you can run the same program from the main 
menu in order to create a batch of letters for some or all of the contacts that are 
currently loaded in the work area. 
When the program is run in this fashion, the Customer Work Area opens 
automatically, enabling you to clear any unnecessary records before continuing, for 
example, by pressing F7 from the line in question or by performing a query. Letters 
will be created for all customer contacts that appear in the form upon exiting. 
In the dialog box that opens, we'll choose the letter we just designed and flag the 
Incl. Attachments option. You can then can choose whether to simply display the 
letter in your browser, to print hard copies to be sent via postal mail, to open an e-
mail message or Word file for each letter, which can be further edited before sending, 
or to send the letters immediately using the Automatic Fax or Automatic Mail 
options. 
As we can now see in the "Sent Items" folder in Outlook, two letters have been 
created, one for each customer, together with the attached order form. If you open 
one of these messages, you can see that the fields we selected earlier have in fact 
been populated with the corresponding system data. 
Finally, you may want to return to Priority and clear the work area at this point, so 
that you can start again from scratch the next time you need to work with it. 
Otherwise, any records you load during a later session will be added to those 
already there. 
This concludes our demonstration of working with the Customer Work Area in 
Priority.
