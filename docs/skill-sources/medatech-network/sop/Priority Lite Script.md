Introduction (00:00-02:33) 
This clip demonstrates Priority Lite, our lighter, more mobile-friendly user interface, 
designed for easy access to a wide variety of Priority tools and data from your 
desktop, laptop or mobile device. This interface is ideally suited to providing access 
to existing data and data analysis tools and performing light or infrequent data entry 
tasks, whereas frequent, intensive data entry is best performed using the full Priority 
interface.  
The Priority Lite interface runs entirely in your browser, but the browser itself can be 
running on your desktop, laptop, mobile device, or in Microsoft Outlook. We'll begin 
by demonstrating how to access Priority Lite on a couple of these platforms. 
Before you begin, you or your system manager will need to log into the Priority's 
Rich interface and send a link to the relevant URL, by running the Send Link to 
Tablet/Smartphone program. In the parameter input dialog box, choose the user to 
whom the link should be sent and click OK. Note that the program sends this e-mail 
to the address defined in the user's Personnel File. 
Once you receive the e-mail, you can open the link directly from your mobile device 
and save the URL to your Favorites for future reference. When accessed on a 
mobile device, the page opens in a mobile-friendly format that has been adapted for 
a smaller screen. We'll return to our mobile device a bit later on. 
Of course, you can open the same link from your laptop or desktop computer as well, 
using the browser of your choice. Here, too, we recommend that you save the URL 
to your Favorites. Let's go ahead and log in, using the same username and 
password assigned to you in Priority's Rich interface. We're now looking at the main 
menu in Priority Lite.  
The interface and work processes in Priority Lite are fairly uniform for all types of 
data and on all platforms, so we're not going to demonstrate Priority Lite on Outlook 
at this time. A full demonstration of Priority's interface with Microsoft Outlook is 
available in our clip on Office Connectivity. Instead, we'll continue our demonstration 
of Priority Lite on a desktop computer, working with CRM data.

In addition, you can return to the previous screen at any time using the Back arrow, 
adjacent to the question mark. 
Note that when you access the same report using a mobile device, the report opens 
in a mobile-friendly format: rather than providing different record types in two or more 
report tabs that appear in a single tabbed report, the different options are presented 
as a list of buttons – click any button to access the desired type of data. 
Let's start by looking at two report tabs that are available in all reports throughout the 
Priority Lite interface. One contains your To Do List, which enables you to view all 
documents, orders, tasks and the like for which you are responsible. The other 
contains the To Do List History, which enables you to view recent activity involving 
any to-do items that are of interest to you. When you first open report tabs such as 
these, data are displayed for the last View format used in that tab. In this 
demonstration, we're viewing data for a View format called "Today." You can define 
and save multiple View formats to easily retrieve the desired data in each report tab. 
Let's click More to see the criteria that determine what data are currently being 
displayed for this View format, and use it as a basis for creating our own custom 
View format. 
As you can see, the current View format is defined by the range of dates when each 
item was updated. Click New to create a new View format using different criteria. 
Record a name for the new View format and then use the available fields to filter the 
items that will be retrieved by their Status or the employee in charge of follow up at 
the time the record was last updated. You can also indicate the maximum number of 
lines to display. When you are done specifying the desired criteria, click Go to 
retrieve the corresponding records. The next time you enter this report tab, you will 
be able to use these criteria to retrieve data by simply choosing the desired View 
format from the Choose list.  
Priority Records in Lite Interface (05:25-08:36) 
Once data are displayed, you can click on any column title to sort the displayed data 
by the values in that column. You can view additional data for any of the displayed 
records by simply clicking on a document number.  
The form that opens displays additional data for the document in question – in this 
case, a price quotation – and can also be used to modify the existing document. As 
you can see, the forms used in this interface are compact and mobile-friendly, 
utilizing multiple tabs in order to minimize the need to scroll up and down within a 
small screen to access the required fields. All Choose lists in these forms are 
populated with the relevant Priority data, just as if you were working in full Priority 
interface. Use the provided buttons to save any changes to this record directly to the 
Priority database.  
Let's proceed to the Sales Opportunities tab next. Here, too, data are initially 
displayed for the last View format used in this tab, but you can click More to define 
and save additional View formats. If you know the number of the sales opportunity in 
question, you can also enter its number directly in the provided field and then click 
Go. 
You can also use this interface to open a new sales opportunity, either manually or 
by copying an existing opportunity. Select the customer for which to open the 
opportunity and then use the form that opens to update any other data, much as you

Dashboards (08:37-10:58) 
Let's use the back arrow to return to the main screen, from which you can access a 
number of Priority's built-in advanced analytical and business intelligence tools. 
For instance, Dashboards give you a look at condensed information from within 
Priority in real time so that you can view live data on sales opportunities, orders, 
budgets and more. Let's have a quick look at the Sales Manager Dashboard. 
Notice that the Dashboard is composed of a number of predefined web parts, which 
can be arranged at will using a built-in design tool, accessed via the pencil icon in 
the corner of each window. Note that when accessing a Dashboard from a mobile 
device, each web part is displayed separately. 
Each web part in the Dashboard displays different types of data in different formats, 
such as charts, graphs, pies or tabular reports. Additionally, some web parts offer 
multi-colored gauges and control lamps, whic h represent key performance indicators, 
or KPIs, of select matrices of your data. Graphic tools in Priority allow you to alter 
the display of any of these visual representations by clicking on the graph icon in the 
selected web part. You can also click the calendar icon to modify the range of dates 
for which data are displayed and use the provided Choose lists and radio buttons to 
modify the variables used to generate each graph or report. 
Clicking within a graph takes you to a tabular report or BI report from which you can 
examine the underlying values presented in that area of the graph in greater detail. 
You can proceed to work with these reports in much the same fashion as you would 
within the full Priority interface; for instance, you can drill down within a BI report to 
view pertinent data in different cross-sections and click on any of the provided links 
to view more detailed information, or even access individual records in Priority's 
Rich interface.

ones, while taking into account defined office hours, holidays and employee
