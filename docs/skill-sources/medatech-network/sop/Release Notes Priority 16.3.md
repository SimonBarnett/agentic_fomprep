Release Notes Priority 16.3 
Payroll/Time and Attendance 
 New Salary Work Area for full treatment of monthly pay slips, incorporating pay class 
definitions, employee payroll data and monthly salary data in a single form. In addition, 
you can: 
 Open a personnel file for a new employee while preparing the pay slip. 
 Add/update personal employee data (e.g., children). 
 Record/update employee pension funds. 
 New option for reporting project hours (Project Hour Reports menu): 
 Support for long-term project planning: The Alloc. Of Wk Hrs to Projects form 
serves as a tool for distributing expected work hours among projects, based on 
Expected Employee Absences and employees' standard work hours. 
 Daily Work Hours-Work Area facilitates assignment of employees' daily reported 
work hours to individual projects (thereby creating automatic project work hour 
reports), including display of the balance of hours to be assigned. 
 A set of auxiliary reports reveal discrepancies between an employee's reported 
work hours and project hour reports. 
 New Payroll Reporting sub-level of the Monthly Salaries form allows you to record 
and view payroll reports in each monthly salary. 
 Users of the Time and Attendance system can open a payroll record for an employee 
via his/her personnel file. 
 You can update, view and approve attendance reports via the HR Dashboard 
(Attendance portal). 
 You can assign a payroll group to a department. Changes in an employee's 
department will generate revision of the employee's payroll group. New program run 
from the Departments form updates the  payroll group of all employees in a given 
department. 
 Support for automatic closure of the salary reporting period, based on the 
ClosedRepDays constant in the Payroll Definitions form. Salary reporting periods 
can still be closed manually by running the Close Reporting Period program. 
 Pay classes: 
 You can link attachments to pay classes. 
 The Use Weekend SickDays column enables you to determine whether sick days 
reported over the weekend will be included in the usage count of permitted number 
of sick days. 
 You can block employees in a given pay class from recording absence reports.

 You can define a separate employee e-mail address in the Payroll Data per 
Employee form that will appear on pay slips. 
 New Earnings and Deductions report, displays information similar to that appearing 
on pay slips. 
 New Daily Attendance per Branch report. 
 You can run the Employer Costs by Pay Slip report per department and print data 
for each department on a separate page. 
 The Employee Work Hours in Period report can be run with or without a breakdown 
per department. 
 Various improvements made to the Employee Work Hours in Month report, including 
added data and input of start and end dates. 
 New Prepare Standing Payroll Reps program allows you to prepare standing 
payments for employees, based on data in the Monthly Earnings & Deductions sub-
level of the Payroll Data per Employee form. You can then make minor changes 
(e.g., price, quantity) to the resulting payroll reports. Useful for payroll reports that are 
recreated monthly with slight revisions. 
 You can define a given work hour code to Ignore Addit'l Hours. Consequently, hours 
reported for the payroll component will not be included in calculations of employee 
entitlement to daily overtime. 
 Support for loading time clock data involving reports of exceptional logins and logouts: 
 You can load reasons for late arrivals and early departures. 
 The Record Except. Absence/Wk Hr Rep program creates automatic attendance 
reports in Priority to cover the missing time. 
 Load Work Hours and Absences: New interface for loading reports from an external 
attendance system that is not a time clock application. 
 Branch and department added to the Load Time and Attendance interface. 
 Sick days can now be divided into first, second, third and fourth consecutive days, for 
use in an outgoing interface to an external program. 
 You can define a Monthly Limit (Sum) for daily earnings/deductions, appearing in the 
Monthly Earnings & Deductions sub-level of the Payroll Data per Employee form 
and flagged as Add'l Daily Pay. 
 New DailyOverTime constant in the Payroll Definitions form impacts the calculation 
of overtime when an employee worked both the morning and the night shift. 
 The ShowSickDays constant in the Payroll Definitions form determines whether 
employees' sick day quotas and balances appear on pay slips. 
 New DisabledTaxExempt and DisabledTaxExempt2 constants in the Payroll 
Constants form: applies to tax benefits for blind and other handicapped employees. 
 You can define a yearly ceiling (as well as a monthly one) for coordinated income tax 
in the Tax Benefits sub-level of the Payroll Data per Employee form. 
 Payroll expense entries can be distributed among departments (including definitions 
for employees working in multiple departments).

 For employees paid by the hour, special rates can be defined, by percentage or sum, 
that will apply when employees work in a different department than their usual one. 
Can be defined per department, both for entire pay classes and for individual 
employees. 
 Support for paid breaks. 
 You can limit additional hours offered to the employee so that standard daily hours are 
not exceeded. 
 New payroll components for various types of unpaid absences and holidays, and new 
tax credit codes (e.g., for the handicapped). 
 New auxiliary program updates the status of yearly payroll summaries. 
 You can recalculate monthly salaries as you run various work hour reports and pay 
slip printouts. 
 Dual-currency users: You can link monthly salaries to a price index, a foreign currency 
or a fixed percentage. 
Warehouse Management System (WMS) 
 Optimization of inventory document preparation via the mobile device. 
 You can prepare inventory documents while loading WMS data via the mobile device. 
 PIK tasks: 
 New flag, defined per pick strategy, allows you to limit PIK recommendations to the 
work order linked to the order item. 
 You can use the new Auto Aggregate flag in the Warehouse Task Types form to 
define that quantities of order items for the same part number will be combined on a 
single line in PIK tasks opened by mobile device. 
 You can now define, per pick strategy, whether to produce an inventory log, run hot 
replenishment and/or ignore the customer's pick strategy. 
 You can now designate the transport type when creating a PIK wave. You can also 
define the number of slots for the transport type, which will limit the number of 
customers that can be included in a given task. 
 New Delete Historical Wave Data program. 
 You can report quantities by mobile device in buy/sell units. 
 Quality levels can be assigned to pallets via the mobile device.  
 New sub-level of the Pallets form allows you to define customers who may (or may 
not) receive goods from specific pallets. 
 BI and Dashboard for warehouse tasks now includes Total Time – Actual and total 
crates per task. 
 Support for analysis of duration of warehouse task (KPI). 
 New warehouse task (PMV) for moving crates via a warehouse transfer. 
 WMS and the Fashion module:

Finance 
 When preparing account reconciliations, you can indicate how to handle adjustment 
entries for reconciliations in a closed fiscal period – whether to record the transaction 
date in the closed period or in the next open one. 
 In an adjustment entry for account or bank reconciliations, you can now define 
profit/cost centers for the entry items of the reconciled account. 
 Automatic recording of bank transactions not appearing in the entry journal, based on 
the bank statement: The Record Bank Transactns in Ledger program allows you to 
create journal entries for a designated bank account and bank transaction code and 
reconciles them with the bank statements of that account. 
 You can now reverse a batch of journal entries together via the new Reverse Journal 
Entries program. Use the MaxReversing constant to limit the number of entries that 
can be reversed at a time. 
 You can now run a weekly cash flow report. 
 Dual-currency users: New WTaxDay constant determines the day in the month after 
which you cannot revise or add payment for the previous month (affecting withheld 
taxes). 
Accounts Receivable 
 Support of credit card payments by Direct Connect. 
 New Split Among Profit/Cost Centers sub-level of orders, various invoice forms and 
service terms allows you to apportion income among multiple income accounts for 
project or contract payments. 
 New Customer Documents sub-level of the Financ. Parameters for Customers 
form. 
 Outstanding Debts per Rep (No.) report can be sorted by customer's address (city). 
 New History of Credit Card Payments form displays such payments that were 
deleted from receipts and over-the-counter invoices. 
 Customer invoices can now be copied for a different customer when running the Copy 
Invoice program from within invoice forms. 
 You can flag a customer so that payment terms in any invoice are always taken from 
the terms defined for that customer (different terms in the original order or shipment 
are ignored).

CRM and Sales 
 You can define check lists for a variety of documents (e.g., sales opportunities, price 
quotes, sales orders) based on their status definitions in the Open Check List Task 
column of the relevant status forms. Used to create a set of fixed tasks when the 
document in question receives the designated status. 
 You can record a billing customer for a price quotation, which is then copied to the 
order and ultimately to the customer invoice. 
 You can now copy a price quote to the same customer or a different one by running 
the Copy Price Quotation program from within a given quote. 
 When itemizing a quote based on a custom BOM, you can now include child parts 
defined as Info Only. 
 New Check Prepaid Order Items report helps you identify items flagged as prepaid 
that have not been billed. 
 Sales rep commission can now be approved via the status of the invoice, as defined in 
the Approved for Commiss column of the invoice status forms. 
 You can assign leads to a territory. When the lead is converted to a customer, the 
territory is copied to the customer record. 
 The system now alerts you of a task opened for a customer whose status is defined as 
restricted. 
 History of Changes sub-level added to the Customers form. Includes relevant 
changes made to leads and in the Financial Params. for Custs form. 
 New status definitions for commission sales orders: you can define a closing and a 
reopening status. 
 Addition of numerous columns to the Sales Opportunity Rep. Generator. 
 Columns added to the Sales Order Report Generator: advance payment and (for 
dual-currency users) value of balance in the second currency. 
Customer Service 
 New single-level query form, View Serv. Contract Payments, displays individual 
service contract payments from multiple contracts/customers. 
 New Check Contract Payments report identifies service contracts whose payment 
installments do not cover the full contract period. 
 New Recalculate Tax Amount program changes the tax percentage appearing on 
the contract printout when calculating new payments for a renewed contract. Useful 
after changes in tax rates. (In dual-currency package, called Recalculate VAT 
Amount.)

Purchasing 
 New PCopyPOrdTxt constant determines how remarks in the purchase order are 
copied in the GRV. 
 Purchase orders can now be copied for a different vendor by running the Copy 
Purchase Order program from within a given order. 
 The Open Purchase Demand for Order program, run from within a sales order, 
allows you to open a purchase demand document for the order, creating PRs for all 
order items. PRs linked to a given order item are displayed in the item's sub-level form. 
 Widening of quantities for demand forecasts to a width of 10. 
 The new MRP Gantt Chart Display Settings form and its sub-level allow you to 
define the chart for MRP for Manufacturers as read-only for individual users and list 
the work order statuses to be displayed. 
 Dual-currency users: Printout of vendor return now includes the vendor's VAT number. 
Inventory  
 You can view the previous expiration date of lots/work orders in the Expiration Date 
Extensions form. 
 New flag allows you to return packed goods to the warehouse while recording a 
customer return for a bill of lading.  
 You can revise the number of a vendor lot; change is stored in the History of 
Changes sub-level form. 
 Quality levels can now be assigned to pallets. A pallet opened while reporting 
production will receive the quality level assigned to the work order for which the pallet 
was opened. 
 You can run a summary Inventory Valuation per Family report. 
Human Resources 
 Support for defining the organizational structure of your company. 
 Support for shift rotations, including reports on employees assigned/not assigned to 
shifts. 
COGS 
 Entries created by the COGS program are now flagged as such in the entry journal. 
 New COGS Transactions for Document sub-level of the List of Inventory 
Transactions form displays journal entries created by the COGS program as a result 
of the current inventory transaction.
