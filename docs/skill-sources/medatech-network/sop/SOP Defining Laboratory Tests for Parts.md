# SOP Defining Laboratory Tests for Parts

- **Source:** `SOP Defining Laboratory Tests for Parts.pdf`

Cat.No.LB09000372 1 Ver.1 – June 2,’10 
 
SOP: Defining Laboratory Tests for Parts* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To define how to test the quality of goods (for quality assurance). 
Procedure 
Stage I: Defining Methods of Analysis 
1. Enter the Methods of Analysis form. 
2. List all of the methods used to perform laboratory tests. 
3. In the Methods of Analysis - Text sub-level form, record instructions or comments 
relating to each analysis method. 
Stage II: Defining Possible Values for Analysis Results 
1. Enter the Possible Results - Choose List form. 
2. List each value that can be used to describe the results of any laboratory tests on a 
separate line. 
Stage III: Defining Types of Laboratory Tests and Possible Results 
1. Enter the Lab Analysis Codes form. 
2. For each type of test, specify an Analysis Code  and Analysis Description and 
select the Method of Analysis to be used to execute the current test. 
3. Do one or both of the following: 
 Record a Minimum Value and Maximum Value within which a laboratory result 
for any part will be considered acceptable for this test. 
 Enter the Possible Results sub-level form and indicate all possible result values. 
Specify whether each value is Acceptable or Unacceptable.  
Tip: You can also select possible result values from the Choose list. 
Stage IV: Defining a Laboratory Test for a Part 
1. Enter the Parts form and retrieve the desired part.
