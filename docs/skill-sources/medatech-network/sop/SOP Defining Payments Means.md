# SOP Defining Payments Means

- **Source:** `SOP Defining Payments Means.pdf`

Cat.No. A8000230 1 Ver.2 – Jun.29,’08 
 
SOP: Defining Payment Means* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
• To define payment means in the system. 
Working Assumptions 
• Cashiers have been defined in the system (see the relevant standard operating 
procedure). 
• Credit card companies have been defined in the system (see the relevant standard 
operating procedure). 
• Banks and bank accounts have been defined in the system (see the relevant 
standard operating procedure). 
Procedure 
1. Enter the Payment Means form. 
2. For each new means, record a Payment Code and Means of Payment (description). 
3. Flag the Credit Card column and/or the Allow Negative Value column, as needed. 
4. If you work with branches, enter the Cashier/Bk Acc/Cred Cd for Branch sub-level 
form: 
• For each branch, select the Branch Code. 
• Select the appropriate value in the Cash/Bank/Credit Cd column. 
5. Optional, and only in consultation with an implementor: 
• Fill in the Cash/Bank/Credit Cd column in the upper-level form by pressing F6 
and selecting the appropriate value from the Choose list. 
• Enter the  Paymt Receipt Dates for CreditCd sub-level form. For each date in the 
Day on Voucher column, specify the Day of Payment. Flag the Next Month 
column if the payment date falls in the following month. 
                                                 
* Standard Operating Procedures should be used as guidelines for customers (and their consultants) to 
develop their own operating procedures. As you will note, the following procedures are very specific 
and customers are strongly advised not to use them without prior testing to make sure that they fit their own 
requirements and work practices.

Cat.No. A8000230 2 Ver.2 – Jun.29,’08 
Results 
• When you record a payment or receipt, the journal entry will debit/credit the cashier 
linked to the designated payment means. 
• The date of payment is calculated according to the values defined in the Paymt 
Receipt Dates for CreditCd sub-level form.
