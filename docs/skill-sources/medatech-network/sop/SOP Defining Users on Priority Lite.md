# SOP Defining Users on Priority Lite

- **Source:** `SOP Defining Users on Priority Lite.pdf`

Cat.No.LB130453 1 Ver.1 – Oct. 21,’13 
 
SOP: Defining Users on Priority Lite* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To define users authorized to work on Priority Lite. 
Procedure 
1. Enter the Users form and define all authorized users, including the following details: 
 User Name 
 Full Name 
 Group Leader (it is recommended to link each user to a group leader, in order to 
assign the appropriate system permissions). 
 Mail Profile (if the user receives external mail via the system) 
2. Enter the Personnel File form and link each user to an employee, including the 
following details: 
 First Name and Last Name 
 Social Security Number (ID Number in the dual-currency system). 
 User (the defined user name) 
 E-mail (the employee's e-mail address) 
 Department (in the Company-Specific Information sub-level form). 
3. Select Define as Internet User from the list of Direct Activations. 
4. Define Internet permissions and password in the following manner: 
 Update the permissions of the group leader to which the user is assigned. 
 Define permissions for the Demo Site-Main Menu, for the required sub-module. 
 Define a password in the Users menu by running the Change Passwords 
program. 
                                                
* Standard Operating Procedures should be used as guidelines for customers (and their consultants) to 
develop their own operating procedures. As you will note, the following procedures are very specific 
and customers are strongly advised not to use them without prior testing to make sure that they fit their own 
requirements and work practices.
