# SOP Defining a GL Account

- **Source:** `SOP Defining a GL Account.pdf`

Cat.No. LB10000434 1 Ver.1 – Sep.14,’10 
 
SOP: Defining a GL Account* 
Customer:  Company Inc. 
Assigned to: Dept./Position 
Aim 
 To define your company's GL accounts. A GL account is any account that is 
debited and credited by the accounting system, and is not linked to a vendor or 
customer.  
Note: Some of the details defined here can be updated as you work in the 
system. 
Procedure 
1. Enter the Chart of Accounts form and press F4. 
2. Record an Account Number and Account Description.  
Note: Dual-currency users can also use the Acct Desc (Lang 2) column to record 
the account description in English.  
3. Specify the Currency in which the account is managed. 
4. If you only want authorized users to view this account, flag the  Secured Account 
column (in the General tab). 
5. Click the Report tab. The Trial Bal Item column displays the default value "000" 
(for unlinked items). Change it as needed. 
6. Select the appropriate Bal Sheet/P&L Item. Dual-currency users should also 
select a VAT Report Item. 
7. Click the Add'l Definitions tab. If you want a certain budget item to appear 
automatically in every journal entry recorded for this account, select the item in the 
Default Budget column.  
8. To assign a branch to the account, specify the Branch Code. 
Note: This is useful, for instance, when you want use the Data Authorization 
mechanism to restrict access by branch. 
9. If the account is for prepaid expenses or deferred income: 
 Flag the Prepaid Exp/Inc Acct column. 
 Specify in the Default Target Acct column the default P&L account to which 
the expenses/income will be transferred when they come due.
