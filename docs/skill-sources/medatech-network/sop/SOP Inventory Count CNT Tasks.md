SOP: Inventory Count (CNT) Tasks* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To perform an inventory count, from the creation of a wave of inventory count 
tasks, to the task reporting, to the creation of the relevant inventory document 
(Inventory Count). 
Working Assumptions 
 The necessary setups have been performed for the WMS module (see the 
relevant standard operating procedure). 
 A Status has been defined which is assigned automatically to inventory 
documents prepared upon completion of an inventory count task (in the 
Document Types per Task Type form, a sub-level of Warehouse Task Types). 
Otherwise, the default initial status is assigned to these documents. 
 A count frequency has been defined for each part in the Inventory in Storage 
Zone sub-level of the Storage Zones form. 
Procedure 
Stage I: Creating an Inventory Count Wave 
Aim: To create CNT tasks, with which to perform an inventory count. 
1. Run the Create Inventory Count Wave program. 
2. In the input screen, fill in the following details: 
 Warehouse No. – Choose the warehouse in which inventory will be counted. 
 Strategy Code – Determines how the wave is split into tasks. Specify 005 to 
create separate tasks Per Aisle. 
 Retrieval Type – Indicate the method of retrieval to use when choosing 
inventory to be counted in this wave. Specify 3 to retrieve by inventory. 
Note: This value determines what input you will be requested to provide in the 
next screen. 
 Task Date – Designate the date on which tasks generated by this wave will be 
opened. Today's date is filled in automatically but can be revised. 
 Make sure the Auto Release column is flagged, and the Auto Flagging and 
No Auto Flag Check columns are not flagged.
