Cat.No. LB110477 1 Ver.1 – Aug. 7,’11 
 
SOP: Inventory Disposal (DSP) Tasks* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To dispose of unusable inventory. This process begins with the creation of a 
wave of inventory disposal tasks, continues with task reporting, and ends with the 
creation of the relevant inventory document (Inventory Disposal). 
Working Assumptions 
 The necessary setups have been performed for the WMS module (see the 
relevant standard operating procedure). 
 A Status has been defined which is assigned automatically to inventory 
documents prepared upon completion of an inventory disposal task (in the 
Document Types per Task Type form, a sub-level of Warehouse Task Types). 
Otherwise, the default initial status is assigned to these documents. 
Procedure 
Stage I: Creating an Inventory Disposal Wave 
Aim: To create DSP tasks, with which to dispose of unusable inventory. 
1. Run the Create Disposal Wave program. 
2. In the input screen, fill in the following details: 
 Task Date – Designate the date on which tasks generated by this wave will be 
opened. Today's date is filled in automatically but can be revised. 
 Priority – Indicate the relative importance to be assigned to warehouse tasks 
created by this wave. 
 To restrict the number of line items that can be included in each disposal task 
created by this wave, specify the Max No. of Lines. 
 Make sure the Auto Release column is flagged. 
3. The Flag Inventory form opens. Perform a query in order to retrieve the 
inventory items to be discarded. 
4. For each item, do one of the following: 
 To dispose of the entire quantity listed for the current item, flag the Select 
column.

Result 
 
Inventory Disposal (DSP) tasks have been opened with the "Execute" status. 
Stage II: Manually Reporting to a DSP Task 
Aim: To report performance of an Inventory Disposal (DSP) task. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices 
for reporting. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Execute" Status. 
3. If necessary, you can print the task by selecting Print Warehouse Tasks from 
the list of Direct Activations. 
4. Enter the Warehouse Task Items sub-level form. 
5. In the Actual Qty column, specify the discarded quantity for each part. 
6. In the upper-level form, change the task Status to "Fully Reported". 
Stage III: Preparing Inventory Documents 
Aim: To update inventory balances in the system, as a result of the task reported by 
warehouse personnel. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices 
to prepare inventory documents. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Fully Reported" Status. 
3. To create an Inventory Disposal document, select Prepare Documents from the 
list of Direct Activations. 
Note: The disposal document will be finalized if a final status was defined for 
inventory documents prepared upon completion of an inventory disposal task (in the 
Document Types per Task Type sub-level of the Warehouse Task Types form). 
Otherwise, see the relevant standard operating procedure for further instructions on 
handling this document. 
Result 
 
Inventory balances have been updated in the system, and an Inventory Disposal 
document has been created, recording the disposal of unusable goods. 
Process Summary 
As a result of the reported Inventory Disposal (DSP) tasks, inventory has been 
discarded on the basis of actual task reports.
