# SOP Inventory Disposal

- **Source:** `SOP Inventory Disposal.pdf`

Cat.No. A8000064 1 Ver.2 – Aug.24,’08 
 
SOP: Inventory Disposal* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
To remove parts from inventory in the process of quality control, handling dead 
inventory, etc. 
Setup 
• At least one inventory status should be flagged with the  Disposable attribute. 
Procedure 
1. Enter the Inventory Disposal form. 
2. Specify the Date the inventory was disposed of. The Document Number is filled in 
automatically, and the document is assigned the "Draft" Status. 
3. Record a brief remark regarding the disposal in the Details column. 
4. In the General tab, the system's default warehouse appears. Revise the Warehouse 
and Bin columns, as needed. 
5. Enter the Disposed Items sub-level form and list the disposed items: 
• Specify the Part Number. The Part Description appears automatically. 
• Specify the Status of the disposed inventory. 
Note: Only inventory with a status that allows disposal can be recorded. 
• The Warehouse and Bin are filled in automatically according to the values in the 
upper-level from, but may be revised. 
• Specify the Quantity of parts to be disposed of. 
Note: Once you leave this line, this quantity will be removed from inventory. 
6. Return to the upper-level form and change the Status to "Final". 
7. To print the document, select Print Inventory Disposal Doc.  from the list of Direct 
Activations.

8. To revise the document after it's been finalized, select Reopen Document from the 
list of Direct Activations. The program returns the document to the "Draft" status. 
After making the necessary revisions, change the status back to "Final". 
Result 
• Inventory levels in the defined warehouse are automatically reduced in keeping with 
the recorded disposed items.
