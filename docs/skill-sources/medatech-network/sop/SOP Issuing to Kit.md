Aim 
Issuing a child part to a work order kit list dedicates the entire quantity of parts 
exclusively to that work order. That is, no other work order can use the issued inventory. 
Working Assumptions 
. 
 
 
• The child parts to be issued can be counted and measured
• The correct issue method has been defined for all child parts (see the Standard
Operating Procedure for factory modeling). This should be checked before releasing
any given work order. 
• The parts are always issued from a regular (Type D) warehouse to a floor (Type F) 
warehouse. 
Setup 
• Define child parts as issued to kits: Enter the Parts  form and make sure each part to 
be issued is flagged in the Kit Component column (in the Additional Details tab).
