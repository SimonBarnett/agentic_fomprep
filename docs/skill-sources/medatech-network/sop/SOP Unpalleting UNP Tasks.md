# SOP Unpalleting UNP Tasks

- **Source:** `SOP Unpalleting UNP Tasks.pdf`

Cat.No. LB110475 1 Ver.1 – Aug. 7,’11 
 
SOP: Unpalleting (UNP) Tasks* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To remove inventory from the pallet on which it is stored and transfer these 
goods to the relevant storage zone. This process begins with the creation of a 
wave of unpalleting tasks, continues with task reporting, and ends with the 
creation of the relevant inventory document (Warehouse Transfer). 
Working Assumptions 
 The necessary setups have been performed for the WMS module (see the 
relevant standard operating procedure). 
 A Status has been defined which is assigned automatically to inventory 
documents prepared upon completion of an unpalleting task (in the Document 
Types per Task Type form, a sub-level of Warehouse Task Types). Otherwise, 
the default initial status is assigned to these documents. 
 There are palleted parts (i.e., inventory that is linked to a pallet) in at least one bin 
in the relevant warehouse. 
Procedure 
Stage I: Creating an Unpalleting Wave 
Aim: To create UNP tasks, with which to remove inventory from pallets. 
1. Run the Create Unpalleting Wave program. 
2. In the first input screen, designate the warehouse to which the goods in this wave 
will be transferred once they are removed from their pallet(s). 
3. In the next input screen, fill in the following details: 
 To Zone/Main Zone – Designate the storage zone (or main zone) to which the 
goods in this wave will be transferred. 
 To Velocity – Designate the velocity of the bins to which the goods in this 
wave will be transferred. 
Note: If you do not specify a velocity, and no velocity restrictions apply based 
on the part's put strategy, bins will be recommended for putaway irrespective of 
their velocity. 
                                                 
* Standard Operating Procedures should be used as guidelines for customers (and their consultants) to 
develop their own operating procedures. As you will note, the following procedures are very specific 
and customers are strongly advised not to use them without prior testing to make sure that they fit their 
own requirements and work practices.

 Task Date – Designate the date on which tasks generated by this wave will be 
opened. Today's date is filled in automatically but can be revised. 
 Priority – Indicate the relative importance to be assigned to warehouse tasks 
created by this wave. 
 Make sure the Auto Release column is flagged. 
4. The Flag Inventory form opens. Perform a query (e.g., by From Warehouse) to 
view palleted items. 
5. For each item, do one of the following: 
 To unpallet the entire quantity listed for the current item, flag the Select 
column. 
 To unpallet only part of this quantity, specify the desired quantity in the Qty 
column. 
6. Exit the form to finish creating the unpalleting wave. 
Result 
 
Palleting (PLT) tasks have been opened with the "Execute" status. 
Stage II: Manually Reporting to a UNP Task Item 
Aim: To report performance of an Unpalleting (UNP) task. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices 
for reporting. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Execute" Status. 
3. If necessary, you can print the task by selecting Print Warehouse Tasks from 
the list of Direct Activations. 
4. Enter the Warehouse Task Items sub-level form.  
5. In the Actual Qty column, specify the unpalleted quantity of each part. 
6. In the upper-level form, change the task Status to "Fully Reported". 
Result 
 
The unpalleted quantity has been reported, but inventory balances have not yet 
been updated in the system. 
Stage III: Preparing Inventory Documents 
Aim: To update inventory balances in the system, as a result of the task reported by 
warehouse personnel. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices 
to prepare inventory documents. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Fully Reported" Status. 
3. To create a warehouse transfer document, select Prepare Documents from the 
list of Direct Activations.

Note: The warehouse transfer document will be finalized if a final status was defined 
for inventory documents prepared upon completion of an unpalleting task (in the 
Document Types per Task Type sub-level of the Warehouse Task Types form). 
Otherwise, see the relevant standard operating procedure for further instructions on 
handling this document. 
Result 
 
Inventory balances have been updated in the system, and a warehouse transfer 
document has been created, removing the inventory in the reported task from the 
relevant pallet (inventory is "transferred" from a palleted to a non-palleted state). 
Process Summary 
As a result of the reported Unpalleting (UNP) tasks, inventory in the warehouse has 
been removed from pallets and stored in the appropriate bins on the basis of system 
recommendations and actual task reports.
