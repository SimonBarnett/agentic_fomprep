SOP: Vendor Return (RET) Tasks* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To return goods to a designated vendor. This process begins with the creation of 
a wave of vendor return tasks, continues with task reporting, and ends with the 
creation of the relevant inventory document (vendor return). 
Working Assumptions 
 The necessary setups have been performed for the WMS module (see the 
relevant standard operating procedure). 
 A Status has been defined which is assigned automatically to inventory 
documents prepared upon completion of a vendor return task (in the Document 
Types per Task Type form, a sub-level of Warehouse Task Types). Otherwise, 
the default initial status is assigned to these documents. 
 There is inventory in at least one warehouse bin in the relevant storage zone. 
Procedure 
Stage I: Creating a Vendor Return Wave 
Aim: To create RET tasks, with which to return inventory to a designated vendor. 
1. Run the Create Vendor Return Wave program. 
2. In the input screen, fill in the following details: 
 Task Date – Designate the date on which tasks generated by this wave will be 
opened. Today's date is filled in automatically but can be revised. 
 Priority – Indicate the relative importance to be assigned to warehouse tasks 
created by this wave. 
 To restrict the number of line items that can be included in each return task 
created by this wave, specify the Max No. of Lines. 
 Make sure the Auto Release column is flagged. 
3. The Flag Inventory form opens. Retrieve the items to be returned. 
4. For each item, do one of the following: 
 To return the entire quantity listed for the current item, flag the Select column.

 To return only part of this quantity, specify the desired quantity in the Return 
Qty column. 
5. In the Return to Vendor column, designate the vendor to which each item will be 
returned. 
6. Exit the form to finish creating the vendor return wave. 
Result 
 
Vendor Return (RET) tasks have been opened with the "Execute" status. 
Stage II: Manually Reporting to an RET Task 
Aim: To report performance of a Vendor Return (RET) task. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices 
for reporting. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Execute" Status. 
3. If necessary, you can print the task by selecting Print Warehouse Tasks from 
the list of Direct Activations. 
4. Enter the Warehouse Task Items sub-level form. 
5. In the Actual Qty column, specify the returned quantity for each item. 
6. Make sure that the correct source warehouse and bin appear in the From 
Warehouse and From Bin columns; these can be revised as necessary. 
7. In the upper-level form, change the task Status to "Fully Reported". 
Result 
 
The returned quantity has been reported, but inventory balances have not yet 
been updated in the system. 
Stage III: Preparing Inventory Documents 
Aim: To update inventory balances in the system, as a result of the task reported by 
warehouse personnel. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices 
to prepare inventory documents. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Fully Reported" Status. 
3. To create a Vendor Return document, select Prepare Documents  from the list of 
Direct Activations. 
Note: The return document will be finalized if a final status was defined for inventory 
documents prepared upon completion of a vendor return task (in the Document 
Types per Task Type sub-level of the Warehouse Task Types form). Otherwise, see 
the relevant standard operating procedure for further instructions on handling this 
document.

Result 
 Inventory balances have been updated in the system, and a Vendor Return 
document has been created, recording the return of goods to the designated 
vendor. 
Process Summary 
As a result of the reported Vendor Return (RET) tasks, inventory has been returned 
on the basis of actual task reports.
