Aim 
This document explains how to build a hierarchy for balance sheets and P&L reports, and how to 
use them in Priority. 
Brief Explanation of the Reports 
The balance sheet and P&L report are each made up of several sections. Each section contains 
one or more headings. Under each heading fall a number of sub-headings (items). 
Balance sheet: 
The report has two main sections (which cannot be changed, deleted or added to): 
 ASSETS. This section should include all report headings and items dealing with various types of 
assets (e.g., CURRENT ASSETS is a heading in this section). 
 LIABILITIES & EQUITY. This section should include all report headings and items dealing with 
liabilities or with equity. 
P&L report: 
The report has three main sections (which cannot be changed, deleted or added to): 
 INCOME. This section should include all report headings and items dealing with income. 
 COST OF GOODS SOLD. This section should include all report headings and items dealing with 
the cost of sold goods. 
 EXPENSES. This section should include all report headings and items dealing with expenses. 
Procedure 
Stage I: Creating Report Headings and Items 
1. Enter the Bal. Sheet/P&L Report Headings form. 
2. In the Heading column, record or revise the title. 
3. In the Section column, select the section under which this heading falls (see explanation of 
structure, above). 
4. Use the Order column to set the order in which headings appear within their respective sections. 
The heading with the lowest number will appear first.

5. Enter the Items per Heading sub-level form. This form displays all items that fall under the 
current heading. 
6. Change the value in the Order column, as desired. This determines the sequence in which items 
appear under each heading. 
7. To add or revise items, enter the appropriate form (based on the account type): 
 Bal. Sheet/P&L Items-GL Accounts 
 Bal. Sheet Items - A/R Account 
 Bal. Sheet Items - A/P Account 
In the Item column, add/revise the title. This will appear in all financial statements that you 
create. 
Result: 
 When running a balance sheet or P&L report, headings and items will appear in the order defined 
above. 
Stage II: Assigning Accounts to P&L Items 
1. Enter the Chart of Accounts form. 
2. Press F4 to move to full-record display mode. 
3. Click the Report tab and attach the account to the appropriate Bal Sheet/P&L Item. 
Result: 
 The Bal Sheet/P&L Item assigned to a given account determines the line in the balance sheet or 
P&L report in which the account is included.
