 SOP: Service Quality Control 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To monitor service quality by creating surveys and recording customer responses, and to use a 
variety of reports to analyze results. 
Procedure 
Stage I: Creating a Customer Survey 
1. Enter the Customer Survey Formats form. 
2. Record a Format Code and Questionnaire Title. 
3. Enter the Questions in Questionnaire sub-level form. Record a number for each question in 
the No. (Question) column and record the Question.  
4. For each question, enter the Possible Responses sub-level form. Record a number for each 
possible response in the No. Response column and record the Response. 
5. To view all the questions and responses, return to the upper-level form and select Print 
Customer Survey Formats from the list of Direct Activations. 
Stage II: Recording Customer Responses 
1. Enter the Customer Survey Responses form. 
2. Specify the Date of Survey, the Format Code of the survey and the Customer Number of the 
customer responding to the survey. 
3. Enter the Responses to Questions sub-level form. All the questions in the survey appear 
automatically. 
4. Select the customer's response to each question in the No. Response column. 
5. To record a longer response, use the parallel Respondent's Remarks sub-level form. 
Stage III: Analyzing the Survey Results 
1. Run the Responses to Surveys report to view customer responses to selected surveys over a 
given period of time. 
2. Run the Customer Survey Analysis report to view the number and percentage of customers that 
chose each possible answer to each question in selected surveys over a given period of time. 
3. Run the Customer Remarks report to view the text remarks recorded for customers for a given 
survey.
