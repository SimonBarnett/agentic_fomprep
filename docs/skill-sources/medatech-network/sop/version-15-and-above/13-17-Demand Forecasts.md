Aim 
Priority allows you to plan your annual sales cycle and prepare for it using demand forecasts and 
forecast orders. The demand forecast reflects expected part demands in each month of the year. 
If you want MRP and purchase planning to take demand forecasts into account, you must also open 
forecast orders; otherwise they are purely informative. 
You can create one or more demand forecasts for a given year. You can also prepare separate 
annual demand forecasts for specific customers, and thereby record their anticipated orders 
throughout the year. 
Setups 
 Enter the Logistic Constants form and define the SFcastOrdDay constant to determine the 
default due date for the forecast orders opened for each month. 
 Enter the Production Constants form and define the MnthForecast constant to determine how 
forecast orders will be used to reduce the demand generated by sales orders.  
Procedure 
Stage I: Preparing an Automatic Demand Forecast 
You can prepare an itemized demand forecast automatically, with or without quantities. Forecasted 
monthly quantities that are added to an automatic forecast are calculated based on the monthly 
average of sales orders whose due dates fall during a designated period. 
Preparing an automatic demand forecast without quantities 
1. Run the Prepare Demand Forecast program. The program prepares a demand forecast for the 
specified customer, year, and part numbers. 
2. Enter the Demand Forecasts form and move to the Itemized Forecast sub-level form to 
designate forecasted monthly quantities for each part. 
Prepare an automatic demand forecast with quantities 
1. Run the Generate Demand Forecast program. 
2. Specify an Add/Subt Coefficient if you expect an increase or decrease in orders relative to the 
calculated monthly average. 
3. You can also specify the number of months ahead for which to record a forecast. 
Note: If the forecast period exceeds the end of the calendar year, two forecasts are opened: one 
until the end of the current year, and another from the beginning of the following year.

Stage II: Preparing a Demand Forecast Manually 
5. Enter the Demand Forecasts form. 
6. Indicate the Year of the forecast. 
7. Record a Forecast Description. 
8. To link the forecast to a specific customer, indicate the customer number in the For Customer 
column. 
9. The Order Due Date determines the day of the month on which all forecast order items will be 
due. It is filled in automatically on the basis of the SFcastOrdDay constant. Revise as 
necessary. 
10. Enter the Itemized Forecast sub-level form. 
11. On each line, specify the Part Number of the part for which the forecast is being recorded. 
12.  For each month in which you expect to sell this part, indicate the forecasted quantity.  
Stage III: Preparing a Forecast Order 
1. Enter the Demand Forecasts form and retrieve the forecast in question. 
2. Select Prepare Forecast Order from the list of Direct Activations. The program will notify you 
regarding the number of the new order and the number of items it contains. A forecast order is 
identical to a regular sales order, except that it is numbered using the forecast code (starting 
with an F), and the Forecast/Stock column (in the Follow-up tab) F. 
Note: If the forecast was prepared for a specific customer, the order is opened for that 
customer. Otherwise, the Customer No. column receives the value "Forecast". 
Stage IV: Updating the Forecast 
You can update the demand forecast, even if a forecast order has already been opened for it. 
However, after revising the forecast you must run a program to replace the existing forecast order 
with an updated version that reflects the changes made. The new forecast order will retain the same 
order number as the previous one. 
1. Enter the Demand Forecasts form and retrieve the forecast in question. 
2. Make the necessary revisions to the forecast. 
3. To delete entire lines from a forecast, run the Delete Demand Forecasts program and select the 
parts in question in the input screen. 
4. From the Demand Forecasts form, select Prepare Forecast Order from the list of Direct 
Activations to replace the existing forecast order with the updated version. 
Stage V: Deleting an Entire Forecast 
1. Make sure its forecast order has been closed. 
2. Run the Delete Demand Forecasts program.
