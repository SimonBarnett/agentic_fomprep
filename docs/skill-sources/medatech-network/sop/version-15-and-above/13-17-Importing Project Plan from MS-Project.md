 SOP: Importing the Project Plan from MS-Project 
 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To copy a project plan from MS-Project into the project planning form in Priority. 
Setup 
 Ensure that the resource names assigned to the project in MS-Project are identical to the 
employees’ full name as it appears in their Personnel File in Priority. 
Procedure 
1. Enter the Projects form and retrieve the desired project. 
2. Enter the Planning Versions sub-level form and open a new line. 
3. Indicate the version Date. A Version number appears automatically. 
4. In the MS-Project File column, record the full file name, including the path. 
5. Select Input MS-Project File Data from the list of Direct Activations. Data from the MS-Project 
file (e.g., activity number, activity name, start and end dates) will be loaded into the MS-Project 
File Data sub-level form. 
6. Check the imported data in the MS-Project File Data sub-level form. Then return to the 
Planning Versions form and select Check MS-Project Data from the list of Direct Activations 
for a more thorough review. If errors are detected, repair them in the MS-Project file and re-
import the file. 
7. Once there are no errors, select Copy MS-Project Data to Plan from the list of Direct 
Activations. 
8. Enter the Project Planning sub-level form to review the project plan that was created. It can be 
modified, and activities and sub-activities can be added as needed. 
9. To put the planning version into effect, select Put Planning Version Into Effect from the list of 
Direct Activations. 
Result 
 The MS-Project file was loaded in its entirety into the system to the saved project plan. In the 
Project Planning sub-level of the Planning Versions form, you can view all planned project 
activities.
