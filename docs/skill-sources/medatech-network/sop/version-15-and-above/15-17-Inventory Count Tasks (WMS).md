SOP: Inventory Count (CNT) Tasks* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To perform an inventory count, from the creation of a wave of inventory count tasks, to the task 
reporting, to the creation of the relevant inventory document (Inventory Count). 
Working Assumptions 
 The necessary setups have been performed for the WMS module (see the relevant standard 
operating procedure). 
 A Status has been defined which is assigned automatically to inventory documents prepared 
upon completion of an inventory count task (in the Document Types per Task Type form, a 
sub-level of Warehouse Task Types). Otherwise, the default initial status is assigned to these 
documents. 
 A count frequency has been defined for each part in the Inventory in Storage Zone sub-level of 
the Storage Zones form. 
Procedure 
Stage I: Creating an Inventory Count Wave 
Aim: To create CNT tasks, with which to perform an inventory count. 
1. Run the Create Inventory Count Wave program. 
2. In the input screen, fill in the following details: 
 Warehouse No. – Choose the warehouse in which inventory will be counted. 
 Strategy Code – Determines how the wave is split into tasks. Specify 005 to create separate 
tasks Per Aisle. 
 Retrieval Type – Indicate the method of retrieval to use when choosing inventory to be 
counted in this wave. Specify 3 to retrieve by inventory. 
Note: This value determines what input you will be requested to provide in the next screen. 
 Task Date – Designate the date on which tasks generated by this wave will be opened. 
Today's date is filled in automatically but can be revised. 
 Make sure the Auto Release column is flagged, and the Auto Flagging and No Auto Flag 
Check columns are not flagged. 
3. In the Flag Inventory form that opens, retrieve the inventory to be transferred. 
Tip: You can retrieve parts by bin, part number, status, etc.

Stage II: Manually Reporting to a Count Task 
Aim: To report performance of an inventory count task. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices for reporting. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Execute" Status. 
3. If necessary, you can print the task by selecting Print Warehouse Tasks from the list of Direct 
Activations. 
4. Enter the Warehouse Task Items sub-level form. 
5. In the Actual Qty column, specify the actual quantity of each part as counted. Indicate the 
relevant To Pallet, if any. 
6. In the upper-level form, change the task Status to "Fully Reported". 
Result 
 Counted quantities have been reported, but inventory balances have not yet been updated in 
the system. 
Stage III: Manually Reporting to a Blind CNT Task 
Aim: To report completion of a count task in which planned quantities were not recorded by the 
system (i.e., the task is itemized manually rather than automatically). 
Note: This stage is relevant for warehouse personnel who do not use mobile devices for reporting. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Execute" Status. 
3. Enter the Warehouse Task Items sub-level form. 
4. Create a new line for each counted item and fill in the following columns: Part Number, Actual 
Qty, To Warehouse and To Bin. Indicate the relevant To Pallet, if any. 
5. In the upper-level form, change the task Status to "Fully Reported". 
Result 
 The counted quantity has been reported in a new task item. 
Stage IV: Preparing an Inventory Count Document 
Aim: To update inventory balances based on reported count tasks.

Note: This stage is relevant for warehouse personnel who do not use mobile devices to prepare 
inventory documents. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the “Fully Reported” Status. 
3. To create an inventory count document, select Prepare Documents from the list of Direct 
Activations. A document is opened with the default "Draft" status. 
4. To continue processing the reported inventory count, see Stage II of the Routine Inventory 
Count section in the SOP for Inventory Counts. 
Result 
 An inventory count document has been created on the basis of the reported inventory count 
(CNT task). This document is used to perform a routine inventory count. 
Process Summary 
As a result of the reported CNT tasks, an inventory count document has been created on the basis 
of actual task reports.
