SOP: Palleting (PLT) Tasks* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To load inventory onto pallets and transfer these pallets to the relevant storage zone. This 
process begins with the creation of a wave of palleting tasks, continues with task reporting, and 
ends with the creation of the relevant inventory document (Warehouse Transfer). 
Working Assumptions 
 The necessary setups have been performed for the WMS module (see the relevant standard 
operating procedure). 
 A Status has been defined which is assigned automatically to inventory documents prepared 
upon completion of a palleting task (in the Document Types per Task Type form, a sub-level of 
Warehouse Task Types). Otherwise, the default initial status is assigned to these documents. 
 Pallet types have been defined and assigned a numbering template. 
 There are non-palleted parts (i.e., inventory that is not linked to a pallet) in at least one bin in the 
relevant warehouse. 
Procedure 
Stage I: Creating a Palleting Wave 
Aim: To create PLT tasks, with which to load inventory onto pallets. 
1. Run the Create Palleting Wave program. 
2. In the first input screen, designate the warehouse to which the palleted goods in this wave will 
be transferred. 
3. In the next input screen, fill in the following details: 
 To Zone/Main Zone – Specify the storage zone (or main zone) to which the palleted goods in 
this wave will be transferred. 
 To Velocity – To put away pallets only in those bins with a specific part velocity, designate the 
velocity in question.  
Note: If you do not specify a velocity, and no velocity restrictions apply based on the part's put 
strategy, bins will be recommended for putaway irrespective of their velocity. 
 Choose the desired Pallet. Or select a Pallet Type and the pallet number will be generated 
automatically, although it can be revised. 
 Task Date – Designate the date on which tasks generated by this wave will be opened. 
Today's date is filled in automatically but can be revised.

 Make sure the Auto Release column is flagged. 
4. The Flag Inventory form opens. Perform a query (e.g., by From Warehouse) in order to

5. For each item, do one of the following:

 To pallet only part of this quantity, specify the desired quantity in the Qty column. 
6. Exit the form to finish creating the palleting wave. 
Result 
 Palleting (PLT) tasks have been opened with the "Execute" status. 
Stage II: Manually Reporting to a PLT Task 
Aim: To report performance of a Palleting (PLT) task. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices for reporting. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Execute" Status. 
3. If necessary, you can print the task by selecting Print Warehouse Tasks from the list of Direct 
Activations. 
4. Enter the Warehouse Task Items sub-level form. 
5. In the Actual Qty column, specify the palleted quantity. 
6. In the upper-level form, change the task Status to "Fully Reported". 
Result 
 The palleted quantity has been reported, but inventory balances have not yet been updated in 
the system. 
Stage III: Preparing Inventory Documents 
Aim: To update inventory balances in the system, as a result of the task reported by warehouse 
personnel. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices to prepare 
inventory documents. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Fully Reported" Status. 
3. To create a warehouse transfer document, select Prepare Documents from the list of Direct 
Activations. 
Note: The warehouse transfer document will be finalized if a final status was defined for inventory 
documents prepared upon completion of a palleting task (in the Document Types per Task Type 
sub-level of the Warehouse Task Types form). Otherwise, see the relevant standard operating 
procedure for further instructions on handling this document.

Result 
 Inventory balances have been updated in the system, and a warehouse transfer document has 
been created, linking the inventory in the reported task to the relevant pallet (inventory is 
"transferred" from a non-palleted to a palleted state). 
Process Summary 
As a result of the reported Palleting (PLT) tasks, inventory in the warehouse has been linked to the 
designated pallets and stored in the appropriate bins on the basis of system recommendations and 
actual task reports.
