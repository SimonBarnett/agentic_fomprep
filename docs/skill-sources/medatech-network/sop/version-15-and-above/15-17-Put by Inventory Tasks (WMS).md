SOP: Putaway (PUT) by Inventory Tasks* 
Customer:   Company Inc. 
Assigned to: Dept./Position 
Aim 
 To transfer inventory or pallets from the warehouse or bin in which they are received to the 
warehouse or bin in which they are put away. This process begins with the creation of a wave of 
putaway tasks for designated parts, continues with task reporting, and ends with the creation of 
the relevant inventory document (Warehouse Transfer). 
Working Assumptions 
 The necessary setups have been performed for the WMS module (see the relevant standard 
operating procedure). 
 A status has been defined for documents that are prepared automatically upon completion of the 
task (in the Document Types per Task Type form, a sub-level of Warehouse Task Types). 
Otherwise, the default initial status is assigned to these documents. 
Procedure 
Stage I: Creating a Put by Inventory Wave 
Aim: To open a PUT task, with which to perform putaway of received inventory. 
1. Run the Create Put Wave (by Inventory) program. 
2. In the first input screen, choose the warehouse in which inventory will be put away. 
3. In the next input screen, fill in the following details: 
 To Zone/Main Zone – Specify the storage zone (or main zone) in which inventory will be put 
away. 
 Store at Velocity – To put away inventory only in those bins with a specific part velocity, 
designate the velocity in question.  
Note: If you do not specify a velocity, and no velocity restrictions apply based on the part's put 
strategy, bins will be recommended for putaway irrespective of their velocity. 
 Task Date – Designate the date on which tasks generated by this wave will be opened. 
Today's date is filled in automatically but can be revised. 
 To put away an entire pallet, specify the pallet number in the Put Away Pallet column. If this 
is a mixed pallet, flag the Break Mixed Pallets column. 
 Priority – Indicate the relative importance to be assigned to warehouse tasks created by this 
wave. 
 Indicate the Max No. of Lines that can be included in each putaway task created by this 
wave. This value affects the number of tasks created by the wave.

4. The Flag Inventory form opens (unless you specified a Put Away Pallet in the previous input

5. For each item, do one of the following: 
 To include the entire inventory balance in this wave, flag the Select column.

6. Exit the form to finish creating the put wave. 
7. If there is insufficient room for all goods to be put away, a message is displayed alerting you of

put away. 
Result 
 Putaway (PUT) tasks have been opened with the "Execute" status. 
Stage II: Manually Reporting to a PUT Task 
Aim: To report performance of a PUT task. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices for reporting. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Execute" Status. 
3. If necessary, you can print the task by selecting Print Warehouse Tasks from the list of Direct 
Activations. 
4. Enter the Warehouse Task Items sub-level form. 
5. For each part, indicate the Actual Qty being put away. 
6. Make sure that the target warehouse and bins specified in the To Warehouse and To Bin 
columns are those that were actually used for the task. 
7. In the upper-level form, change the task Status to "Fully Reported". 
Result 
 The transferred quantity has been reported, but inventory balances have not yet been updated 
in the system. 
Stage III: Preparing Inventory Documents 
Aim: To update inventory balances in the system, as a result of the task reported by warehouse 
personnel. 
Note: This stage is relevant for warehouse personnel who do not use mobile devices to prepare 
inventory documents. 
1. Enter the Warehouse Tasks form. 
2. Retrieve the task assigned to you with the "Fully Reported" Status. 
3. To create a warehouse transfer document, select Prepare Documents from the list of Direct 
Activations. 
Note: The transfer document will be finalized if a final status was defined for inventory documents
