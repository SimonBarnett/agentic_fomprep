# Setting up calls to divert to Gemma

- **Source:** `Setting up calls to divert to Gemma.docx`

Setting up calls to divert to Gemma’s mobile

Connect to 172.29.10.7 using Administrator credentials

Open Phone manager from task bar

Login    password is Medatech123!

Select Auto Attendant on Left and Actions tab on right

Highlight Cherry in list and click Edit button on right.

Change destination in lower section to be 258 Gemma.

Then click ok to save locally.

A save icon will highlight on the top bar click on it (looks like diskette) Do not change any settings on the popup screen just click OK

Enter password as above and click ok

It will now commit the local changes to the Phone system.

Gemma phone will automatically divert to her mobile.
