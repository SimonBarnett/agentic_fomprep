17.1 Rich problem

Replicating in IE 11

Open any form e.g. customers and toggle the sidebar to be hidden

Now close and re-open the browser

Re open the form you were in before closing the browser

The sidebar will be hidden and does not toggle back into view when you hit the arrow.

The only way to see it is to drag the thin black line that is below the arrow.

This produces a fully grey sidebar

The grey sidebar only populates if you click the arrow again

Then if you click the arrow again, the sidebar will become hidden as it is supposed to.
