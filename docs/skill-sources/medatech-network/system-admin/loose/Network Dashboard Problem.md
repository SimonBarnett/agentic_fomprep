Network Dashboard Problem

If the laptop has not yet been attached to the internet today …

Connecting to the network (i.e. the Internet) and refreshing the page …

Disconnecting from the Internet/network (i.e. switching off wireless) and refreshing gives no change.

Rebooting makes no change.

Changing the PC’s date to tomorrow …

This does not just affect Dashboards, but also BI graphs and User Report Generators.
