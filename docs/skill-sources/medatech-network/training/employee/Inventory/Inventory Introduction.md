Aims of the training session

This training session aims to give you an insight into the inventory module within Prioirty software. This is not a full list of functionality but instead a selection of functionalities that are currently used by our customers and therefore will be useful when supporting or implementing Prioirty.

Objective

At the conclusion of this training, you will be able to:

Create and Maintain Parts

Create and maintain warehouses

Part Traceability

Run Past balances

Work with the below documents:

Inventory Counts

Warehouse Transfers

ECO

Inventory Disposals
