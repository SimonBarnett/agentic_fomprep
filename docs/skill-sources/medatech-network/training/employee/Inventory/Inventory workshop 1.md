Inventory Workshop 1

Part and warehouse Creation

Setup the below parts in your system. When defining the Buy/Sell unit and Factory Unit ensure that there is a correct conversion ratio in place.

Use a part numeration template in order to generate the oil part number.

For seasoning use part- spec fields to define the new part number.

For all other parts set the part number manually.

Create two New Warehouses, one warehouse to receive goods that have been sent to you by a supplier and one to send finished goods to customers from. Make sure all relevant flags are ticked and the correct Warehouse types are used.

Assign a default entry status to all goods which will be ordered in, this status should be ‘Goods’

Using the inventory transaction documents form set the default warehouse for GRV’s to be your receiving warehouse which was set up in step 2

Using the inventory transaction documents form set the default warehouse for customer shipments and customer returns to be your sales warehouse which was set up in step 2
