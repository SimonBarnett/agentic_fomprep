Inventory Workshop 3

QA

The CEO has decided that he would like to run a QA check on the potatoes that are received into the warehouse as over the last few months a lot of inventory has been disposed of. He would like to understand if this is a supplier issue or an issue with the way it is being handled internally.

Amend the Potatoes part’s default entry status to be ‘MRB’ This will ensure that whenever we receive this part into stock it will not be available for sale straight away, instead it will go to a status of MRB and awaiting testing.

All Current stock of potatoes need to be made not available for sale. In order to do this we will record a Warehouse transfer. We will convert all potatoes of a goods status to be potatoes with a status of MRB.

Now Record a receipt of potatoes into inventory and make sure it assigned the correct status.

Open A Laboratory Release document based on the GRV from step 3. The potatoes have been found to be in good condition so can be changed to a status of ‘goods’

A new fussy customer has decided they want their inventory to be separated from everyone elses. It has been decided that a new part will be created called – ‘Fode packet of crisps’. Create this part in the part catalogue

We will now convert 10 units of the salt and pepper crisps to be 10 units of Fode packet of crisps. Use an inventory conversion in order to do this.
