# Terminology

- **Source:** `Terminology.docx`

Production Terminology

Operation – An Operation is any step within production for example if the product you were producing was a cup of tea then adding milk would be an operation.

Work Cell – A work cell is a location/machine where an operation takes place. For example if the product you were producing was a cake, then a work cell you would need would be an oven

Routing – A routing is a series of operations, usually a produced part must go through lots of operations. These operations are grouped together in a routing

Parent Part – A parent part is any part that has child parts assigned. For example if the product you were producing was a cake, then the parent part would be the cake

Child Part - A Child part is any part that belongs to a parent part. For example if the product you were producing was a cake, then the child parts would be the flour, eggs, sugar etc.

Manual issue – Using/issuing child parts during production of a Parent part

Issue to Kit – Transferring stock to the floor warehouse before reporting production so the stock can be used when producing the parent part
