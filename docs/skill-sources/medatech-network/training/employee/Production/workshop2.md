Production EXERCISE 2

Factory Modeling

Create the below workcells within your system.

Create a list of operations that will take place in each of the workcells. Think about what process’s will take place at each one of the workcells

Create a new routing called ‘Make Crisps’

Using the sub level ‘Operations in Routing’ reference each of the operations that you setup in order. When numbering the steps ensure that there is adequate space between them (10, 20 , 30 rather than 1, 2, 3)

On the last operation ensure that you have specified the warehouse and bin to which the stock will be transferred once production has been completed. Also make sure that the ‘Remove Oper. Number?’ and ‘Remove Wk Ord. Number?’ checkboxes are ticked.

Assign the routing you have just created to the Salt and Pepper Crisp Part.

Go to the ‘ Work Order & Lot No. Templates’ form and create a new Work order template as shown below

Open the  ‘Assign WO/Lot Templates to Parts’ form and assign the new work order template to the Salt and Pepper Crisp part.
