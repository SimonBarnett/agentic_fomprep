Production EXERCISE 3

Work Orders and Reporting Production

Create a new work order for 1000 packets of Salt and Pepper crisps. Set the begin production date as today and release the works order.

Issue all items to the floor warehouse.

Begin reporting production, when reporting production reference the works order number and the quantity completed. When you have fully reported an operation it should automatically move onto the next operation.

Once you report the final operation a to warehouse should be populated, check this warehouse to ensure that all 1000 packets of crisp are now in stock with no operation or lot number against them.

Run the backflush program.

Check for any missing issues, if any missing issues are present the resolve these before running backflush again. You should receive a message stating that floor inventory has been successfully calculated’.
